# P2-5.4 Checking Probability and Statistics with Small Data

> Section ID: `P2-5.4`
> Version: `v2026.07.09`

P2-5.1 to P2-5.3 built the conceptual language. This Section checks the same ideas again through a small list of values and simple code output.

## Scope of This Section

This Section uses small data to check mean, median, variance, and sample-mean variation. It is not a full statistics-library tutorial.

## Central Question

How do the concepts from the previous Sections show up again in actual numbers and output?

![Flow for separating raw data, center, spread, and sample estimates on small data](../../../assets/part-02/chapter-05/small-data-statistics-check-en.svg)

The example file for this Section is [p2_5_4_small_statistics.py](../../../assets/part-02/chapter-05/p2_5_4_small_statistics.py).

## Perspective to Keep

- Small data is enough to inspect center, spread, and sample variation separately.
- Code makes the calculation visible, but interpretation still matters.
- The purpose is concept recovery, not library memorization.
