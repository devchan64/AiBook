# P2-7.6 Supplemental Learning: Using Terminals on Windows, macOS, and Linux

> Section ID: `P2-7.6`
> Version: `v2026.07.07`

P2-7.2 explained the idea of terminal, shell, and working directory. This supplement shows how those ideas are encountered on actual operating systems.

## Scope of This Supplement

This Section covers the minimum entry workflow for Windows, macOS, and Linux terminals. It does not go deep into shell scripting or permission systems.

## Perspective to Keep

- Terminal entry points differ by OS, but the core ideas stay the same.
- Location checks come first: where am I, what files are here, where should I move next?
- Command names can differ between PowerShell and Unix-like shells even when the purpose is similar.

## Short Check

- Can you explain why the terminal concept is the same even if the app name changes by OS?
- Can you explain why checking current location is the first useful step?
- Can you explain why copied commands should be read carefully across OS differences?
