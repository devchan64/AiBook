# P2-7.7 Supplemental Learning: When Is Python Installation Actually Needed?

> Section ID: `P2-7.7`
> Version: `v2026.07.07`

After terminal entry and location checks, another beginner question remains: do I need to install Python right now?

## Scope of This Supplement

This Section explains when Python installation matters and when hosted environments such as Colab let you delay that step.

## Central Question

When is installation necessary, and when can practice begin without making installation the first obstacle?

## Perspective to Keep

- Colab can lower the entry barrier for first practice.
- Local installation becomes necessary when you want your own files, environments, and repeatable local workflows.
- “Install now” is not always the first learning requirement.
