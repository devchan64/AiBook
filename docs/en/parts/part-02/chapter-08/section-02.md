# P2-8.2 Lists: Ordered Groups of Values

> Section ID: `P2-8.2`
> Version: `v2026.07.09`

After values, variables, and types, the next basic structure is the list.

## Scope of This Section

This Section introduces `list`, `index`, `item`, mutability, and nested lists.

## Central Question

When should several values be read as an ordered group, and what does that order let us do?

## Perspective to Keep

- A list is an ordered collection.
- Index is position-based access.
- Lists are mutable, so later copy/reference confusion is not accidental.
- Python lists are not automatically the same thing as numerical arrays.
