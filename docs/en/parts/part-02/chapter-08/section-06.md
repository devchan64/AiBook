# P2-8.6 Supplemental Learning: First Meeting Classes and Objects

> Section ID: `P2-8.6`
> Version: `v2026.07.09`

After functions, another Python pattern appears often: `value.method()` and `object.attribute`.

## Scope of This Supplement

This Section gives a first reading of `class`, `object`, `method`, and `attribute`. It does not try to turn this into a full object-oriented-programming course.

## Central Question

How should we first read dot-based expressions without collapsing everything into “just another function call”?

## Perspective to Keep

- An object can be read as something that has state and behavior.
- A method call and attribute access are related but not identical.
- This supplement is about reading code confidently, not mastering every design pattern.

## Short Check

- Can you explain the difference between `object.attribute` and `object.method()`?
- Can you explain class and object at an entry level?
- Can you explain why dot expressions appear so often in library code?
