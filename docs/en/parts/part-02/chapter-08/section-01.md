# P2-8.1 Values, Variables, and Types

> Section ID: `P2-8.1`
> Version: `v2026.07.09`

Chapter 7 recovered where code runs. Chapter 8 starts recovering what the basic Python expressions mean.

## Scope of This Section

This Section introduces `value`, `variable`, `type`, `assignment`, and basic built-in types.

## Three Sentences to Keep

- A value is the actual data computation handles.
- A variable is a name attached to a value.
- A type tells us what operations make sense for that value.

## Perspective to Keep

- `=` in Python is assignment, not a school-style equation.
- Types explain why the same-looking operation can behave differently.
- Many later errors become easier once value, variable, and type are separated early.
