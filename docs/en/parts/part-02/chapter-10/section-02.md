# P2-10.2 The Difference Among Jupyter, Colab, and Local Execution

> Section ID: `P2-10.2`
> Version: `v2026.07.09`

P2-10.1 treated notebooks as computational documents. This Section separates three execution styles that often look mixed together: Jupyter, Colab, and local execution.

## Scope of This Section

This Section focuses on execution location, runtime, file access, and sharing. It is not a feature-by-feature user manual.

## Central Question

Why can the same notebook-looking file behave differently depending on where it is executed?

## Perspective to Keep

- Jupyter is a notebook tool ecosystem.
- Colab is a hosted notebook service built on the Jupyter notebook style.
- Local execution means using your own machine's Python, files, and packages directly.
- A notebook file and a running runtime are not the same thing.
