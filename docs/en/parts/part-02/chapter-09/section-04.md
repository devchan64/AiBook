# P2-9.4 Supplemental Learning: How to First Read Traditional Data Structure Names

> Section ID: `P2-9.4`
> Version: `v2026.07.09`

Once data structure study expands, many names suddenly appear: array, linked list, stack, queue, tree, graph, hash table. This supplement is for reading those names through the questions they solve.

## Scope of This Supplement

This Section gives a first reading frame for traditional structure names. It does not try to replace a full data-structures course.

## Central Question

What kind of question does each traditional structure make easier?

## Perspective to Keep

- Array: position-oriented access
- Stack: last in, first out
- Queue: first in, first out
- Tree: hierarchy
- Graph: relationship traversal
- Hash table: key-based lookup
