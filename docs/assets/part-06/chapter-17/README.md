# Part 6 Chapter 17 Assets

- Korean public manuscript pages can include the `-ko.mmd` files through `pymdownx.snippets`.
- The matching `-en.mmd` and `-zh.mmd` files remain in this directory as translated derivatives for multilingual manuscript work.
- When updating a Mermaid diagram set, revise the English structure first, then sync the Korean and Chinese derivatives so all files keep the same conceptual flow.
- P6-17 operations language pairs:
  - `p6-c17-s01-service-constraint-flow-en.mmd` / `p6-c17-s01-service-constraint-flow-ko.mmd` / `p6-c17-s01-service-constraint-flow-zh.mmd`
  - `p6-c17-s02-failure-recovery-flow-en.mmd` / `p6-c17-s02-failure-recovery-flow-ko.mmd` / `p6-c17-s02-failure-recovery-flow-zh.mmd`
  - `p6_17_1_service_candidates.csv` stores the P6-18.1 service candidate inputs used by the manuscript example and chart.
  - `p6_17_1_evaluate_service_candidates.py` evaluates P6-18.1 service candidates against quality, latency, cost, and throughput constraints.
  - `p6_17_1_evaluate_service_candidates_en.py` is the English companion script for the P6-18.1 translated manuscript.
  - `p6_17_1_evaluate_service_candidates_zh.py` is the Chinese companion script for the P6-18.1 translated manuscript.
  - `p6_17_1_service_constraint_matrix_chart.py` reads the same CSV-backed evaluation and generates `service-constraint-matrix-ko.png`, `service-constraint-matrix-en.png`, and `service-constraint-matrix-zh.png`.
  - `p6_17_2_failure_cases.csv` stores the P6-18.2 failure scenario inputs used by the manuscript example and chart.
  - `p6_17_2_evaluate_failure_recovery.py` uses a bounded LLM-grader step for suggested failure tags, then evaluates P6-18.2 failure cases into retry, fallback, approval, human review, stop, and model fix routes.
  - `p6_17_2_failure_recovery_split_chart.py` reads the same CSV-backed evaluation and generates condition-based recovery routing charts, `failure-recovery-routing-ko.png`, `failure-recovery-routing-en.png`, and `failure-recovery-routing-zh.png`.
