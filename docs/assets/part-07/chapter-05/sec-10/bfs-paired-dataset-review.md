## 데이터셋 구성

현재 **217개를 한 목록에서 관리**한다. 기존 193쌍은 준비 완료이며, 추가 24개는 입력 활용이 확정되었으며, 11개는 기존 목표를 재사용하고 13개만 새 목표 생성·검수를 기다린다. 아래 기존 193쌍 표와 끝의 추가 24개 표는 같은 통합 JSON에 대응한다. 기존 193쌍은 입력 → 목표 순서로 보여 준다. 사용자 채택 판단에서 최종 폐기 27건을 제외한 구성으로, 기존 AI 검수 의견과는 구분한다. 데이터셋 구성이며 학습 완료나 성능 검증 결과를 뜻하지 않는다.

- 학습: **174쌍**, 중복을 제외한 Mira 목표 **37장**.
- 검증: **19쌍**, 중복을 제외한 Mira 목표 **4장**.
- 기존 준비 완료: **193쌍**, 중복을 제외한 Mira 목표 **41장**. 같은 목표에 서로 다른 입력이 대응하므로 쌍 수와 목표 이미지 수는 다르다.
- 추가 생성 목표 후보 **123장**은 대응 입력이 아직 없어 이 데이터셋에 포함하지 않았다.

같은 목표에서 파생된 입력은 같은 분할에 둔다. 다만 공통 Mira 기준 이미지에서 파생된 자료이므로 이 분할만으로 외부 장면에 대한 독립 검증을 보장하지 않는다. 관리번호는 기존 `P711-IN-NNN`을 유지하며 폐기 번호를 재사용하지 않는다.

## 학습 방향과 확인 기준

`control_image`는 모델에 주는 입력이고 `image`는 학습 목표다. 얼굴·헤어는 Mira 아이덴티로, 전체 화풍은 Mira 목표 화풍으로 바꾼다. **입력 표정·얼굴 방향·포즈·의상 디자인·카메라와 구도·배경 사물과 배치는 보존**한다. 배경의 화풍 변화와 사물 손실·추가·배치 변경을 구분하여 확인한다.

모든 쌍에 적용하는 학습 지시(`caption`)는 다음과 같다.

> Transform the woman into mira_person with Mira's facial identity and hairstyle, and render the entire image in Mira's target illustration style. Preserve the input facial expression, head direction, pose, clothing design, camera viewpoint, perspective, framing, subject position, apparent body scale, background objects and scene layout.

이미지를 클릭하면 원본을 확인할 수 있다. 각 행의 목표 그룹은 같은 목표를 공유하는 입력을 식별하며, JSON에는 이미지 경로와 해시·분할·채택 이유가 기록되어 있다.
