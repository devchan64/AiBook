# P7-5.10 캐릭터 일관성을 위한 LoRA 자산

완료된 생성·학습 준비·평가 자산은 이 디렉터리에서 관리한다. 이전 파일명의 `p7-5-11`·`p7-5-12`와 `p7_5_11`·`p7_5_12`를 `p7-5-10`·`p7_5_10`으로 변경했다.

## 현재 경로와 실행 이력

- [자산 이관 목록 JSON](p7-5-10-asset-migration.json)은 sec-11/sec-12의 과거 경로와 현재 파일을 대응시킨다.
- [경로 해석 Python](p7_5_10_asset_paths.py)은 생성 조건과 과거 기록에 남은 경로를 현재 파일로 연결한다.
- 기존 생성 조건·결과·평가 계획 JSON의 내부 경로, 관리번호와 지문은 당시 실행 이력이다. 바이트와 해시를 보존하며 파일명만 변경했다. 현재 후보 카탈로그와 문서 링크는 새 경로를 사용한다.
- 생성 조건이나 실행 코드가 변경된 새 실험은 별도 출력 폴더에서 시작한다.

## 진행 중 평가로 인해 sec-12에 유지한 자산

- `../sec-12/codex-camera-inputs-v1/`: 45장 입력과 JSON.
- `../sec-12/codex-camera-lora-v1/`: 생성 중인 출력·계획·상태·비교표.
- `../sec-12/p7_5_12_evaluate_bfs.py`: 현재 평가 실행 코드.
- `../sec-12/p7_5_12_camera_report.py`: 진행 비교표 갱신 코드.
- [기준 데이터셋 JSON](../sec-12/p7-5-11-bfs-paired-dataset-v1.json): 현재 실행 계획의 데이터셋 지문을 유지한다. 내부의 이전 이미지 경로는 새 학습 준비 코드에서 이관 목록으로 해석한다.

이 파일들은 이번 이관에서 내용과 이름을 변경하지 않았다. 현재 실행 중인 새 입력 평가는 기존 학습 이미지 경로를 열지 않고 데이터셋의 해시·캡션을 읽는다. 기존 평가 코드의 19쌍 모드를 다시 실행하기 전에는 이관 경로 해석을 반영해야 한다. 이관은 로컬 저장소에만 반영했으며 외부에 게시된 모델 카드와 체크포인트는 변경하지 않았다.
