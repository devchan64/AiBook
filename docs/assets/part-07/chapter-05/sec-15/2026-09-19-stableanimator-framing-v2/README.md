# P7-5.15 StableAnimator 캐릭터 유지 실패의 구도 비교 준비

상태: **원 실험 폐기로 실행 불가**. 원 모션·참조·기준 실행 자료가 사용자 지시로 삭제됐다. 아래 조건과 절차는 준비 당시 이력이며 새 입력·새 계획 없이 실행하지 않는다. 이전 실험은 캐릭터를 정상적으로 유지하지 못했다. 걷기의 다리 겹침·분리는 동작 전달의 부분 관찰이며, 캐릭터 영상의 성공 판정이 아니다. 이번 실험은 현재 모델을 채택하기 위한 절차가 아니라 실패 원인을 좁히는 비교다.

## 발 교대에 관한 추가 관찰

사용자는 포즈 비교판의 발 바뀜이 부자연스럽다고 지적했다. 기존 비교판의 6장은 비연속 공중 후보이므로 교대 자체의 검수판으로 적절하지 않다. 연속 원 관절을 확인하면 좌우 매핑은 고정되어 있으며 주요 발목 앞뒤 교차는 출력 13·20·26번(원 49·56·62번)에 있다. 그러나 교차가 있다는 사실은 자연스러운 접지와 달리기를 입증하지 않는다. body-only 입력에는 발끝과 깊이·가림 라벨이 없어 원 관절의 정보도 일부 사라진다. 원 모션과 투영 중 어느 쪽이 부자연스러움의 주원인인지는 확정하지 않았다.

사용자가 연속 20fps 영상을 확인한 뒤, 앞서 문제로 보였던 현상은 관측되지 않는다고 평가했다. 이 관찰을 반영해 발 교대 우려에 따른 추론 보류를 해제하고 구도 비교에 사용할 수 있도록 했다. 생체역학적 타당성 전체를 검증한 것은 아니며, 캐릭터 유지 실패와 v2 걷기의 부유·하강은 별도 문제로 남는다.

## 1차 질문과 비교 조건

작게 표시되거나 화면 가장자리로 이동하는 포즈가 캐릭터 붕괴와 관련되는가? 같은 달리기 원 모션 36~67번과 기존 참조를 재사용한다. 기존 몸 높이 범위는 약 165px다. 이동·크기를 동시에 바꾸지 않고 아래 두 비교를 구분한다.

| 조건 | 수평 위치 | 크기 | 상태 |
| --- | --- | --- | --- |
| 이전 달리기 | 원 모션의 이동 유지 | 기존 1배 | 기존 실패 결과 재사용 |
| centered-small | 매 프레임 골반을 화면 중앙에 놓음 | 기존 1배 | 32개 입력 포즈 준비 |
| centered-large | 위와 동일 | 2배, 높이 범위 약 330px | 32개 입력 포즈 준비 |

기존 결과와 centered-small은 수평 추적의 효과를, centered-small과 centered-large는 크기의 효과를 비교한다. 중앙 추적은 카메라 조건 변경이며 고정된 세계 좌표 카메라가 아니다. 바닥 높이 기준과 골반의 수직 이동은 유지한다. 매 프레임 발을 바닥에 붙이지 않는다. 확대 조건에서도 유효 관절이 화면 안에 있는지 확인했다.

참조 이미지, body-only 관절 매핑, 512×512, 32프레임, seed 23123134, 25 steps, CFG 3, tile 16·overlap 4, decode chunk 1, CPU 스레드 4를 유지한다. 얼굴 관절·타일 길이·시드는 이번 비교에서 바꾸지 않는다. 이전 결과와 원 모션·참조는 경로로 연결하고 복사하거나 다시 생성하지 않는다.

## 판정 순서

1. **캐릭터 유지가 우선이다.** 전체 32프레임을 참조와 비교해 머리색·머리 형태, 얼굴의 가시 부분, 의상 색·구성·실루엣, 몸 비율, 전신과 팔다리의 연속성을 기록한다. 첫 이탈 프레임과 구체적인 변형을 남긴다. 작은 측면 얼굴처럼 판별할 수 없는 항목은 성공으로 처리하지 않는다.
2. 신체 소실, 팔다리 추가·융합, 의상의 큰 변형이 있으면 캐릭터 유지 실패다. 동작 전달이 일부 보여도 사용 가능한 캐릭터 영상의 성공으로 판정하지 않는다.
3. 캐릭터 유지 상태를 기록한 뒤 다리 겹침·분리와 입력 포즈 추종을 별도로 본다. 공중 후보 출력 8·16·22·23·29·30번은 원 포즈와 대조한다. 배경에 실제 바닥 기준이 없어 접지 성공을 확정할 수 없다.
4. 두 조건에서도 유지에 실패하면 확대 조건을 성공으로 채택하거나 같은 설정의 시드만 대량 탐색하지 않는다. 다음 단계는 참조와 목표 시점의 차이, 누락된 얼굴 조건, 모델의 정체성 보존 경로를 별도 비교하는 것이다. 이번 두 조건만으로 실패의 유일한 원인을 단정하지 않는다.
