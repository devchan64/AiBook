## 本节范围

本节入门介绍 `notebook`、`code cell`、`markdown cell`、`output`。

## 中心问题

为什么 notebook 在通过小实验、计算、表格、图形学习时特别有用？

## 记住的视角

- notebook 是一种计算文档。
- code cell、markdown cell、output 各自承担不同角色。
- notebook 很适合学习与探索，但并不能在所有场景替代脚本。

## 简短检查

- 能说明 notebook 不只是“写代码的地方”。
- 能区分 code cell、markdown cell、output。
- 能说明为什么 notebook 适合小步学习。
