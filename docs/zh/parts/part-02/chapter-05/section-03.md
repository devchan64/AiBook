# P2-5.3 样本、估计与误差

> Section ID: `P2-5.3`
> Version: `v2026.07.09`

在分布、均值、方差之后，下一个问题自然会出现：如果我们看不到总体怎么办？

## 本节范围

本节入门介绍 `population`、`sample`、`estimation`、`error`、`sampling bias`。

## 中心问题

如果我们手里的数据只是整体的一部分，这些数字可以信到什么程度，又该从哪里开始谨慎？

## 先固定的结构

| 术语 | 核心问题 |
| --- | --- |
| population | 我们真正想知道的整体是什么？ |
| sample | 我们实际上观察到的部分是什么？ |
| estimation | 如何用部分去猜整体？ |
| error | 这个猜测可能离真实值多远？ |

## 记住的视角

- 数据集通常只是现实的一部分，不是全部。
- 估计是在用样本推测总体。
- 误差、波动、偏差不能混成一个概念。

## 简短检查

- 能区分 population 与 sample。
- 能说明 estimation 是“用部分猜整体”。
- 能说明为什么不同样本会得到不同估计。
- 能说明为什么 variation 与 bias 不是同一个问题。
