# P2-2.1 重新阅读变量(variable)、函数(function)、表达式(expression)

> Section ID: `P2-2.1`
> Version: `v2026.07.09`

P2-1.2 已经抓住了“公式、代码、数据是同一个计算的不同外形”这一视角。现在要恢复的是：读公式时最先遇到的基础记号。

\[
x
\]

\[
y = f(x)
\]

\[
\mathrm{loss} = f(\mathrm{prediction}, \mathrm{target})
\]

这些表达在以前的数学里可能太基础，以至于被直接跳过。但在 AI 文档里，如果读不懂变量、函数与表达式，就很难给模型、输入、输出、损失、参数找到位置。

## 本节范围

这里首先要解决的问题是：看见一行公式时，怎样区分什么是值、什么是关系、什么是计算？

所以这里只先固定四个位置。

- 变量是什么样的名字？
- 函数是什么样的关系？
- 表达式表示什么样的计算？
- 代码里的变量和数学里的变量，像在哪里，不像又在哪里？

## 三个基准

| 基准 | 为什么重要 | 本节所需理解水平 |
| --- | --- | --- |
| 变量是值的名字，不是值本身 | 可以避免把符号和对象混在一起 | 理解变量是在给值命名 |
| 函数是把输入变成输出的关系 | 能把模型和规则放在同一个结构里阅读 | 理解 `y = f(x)` 是输入-变换-输出 |
| 表达式是计算或关系的压缩写法 | 它是阅读预测、损失、误差公式的起点 | 理解表达式在压缩计算过程 |

## 变量是指向值的名字

变量(variable)是指向某个值的名字。数学里常用 `x`、`y`、`n`、`w` 这样的短符号。

\[
x = 3,\quad y = 2,\quad n = 4
\]

在 AI 文档里，这些名字往往还带着更多语义。比如 `x` 常表示输入数据，`y` 表示目标值，`w` 表示权重，`b` 表示偏置，`ŷ` 表示预测值，`L` 表示损失。

同一个符号在不同文档里含义也可能不同，因此读公式时，第一步通常是先问：这篇文字里把这个符号定义成了什么？

## 代码里的变量与数学里的变量

```python
x = 3
y = 2
total = x + y
```

示例结果：

```text
x 指向 3，y 指向 2，total 指向 5。
```

数学变量与代码变量之所以相像，是因为它们都在给值起名字。但两者并不完全一样。

| 视角 | 数学里的变量 | 代码里的变量 |
| --- | --- | --- |
| 主要角色 | 简洁表达关系 | 在执行过程中保存并引用值 |
| 值是否变化 | 依语境可能固定或变化 | 可以重新赋值 |
| 类型 | 通常靠语境推断 | 有明确类型，如整数、浮点数、字符串、数组 |

```python
import numpy as np

x = np.array([1, 2, 3])

print(x)
print(x.shape)
print(x.dtype)
```

示例输出：

```text
[1 2 3]
(3,)
int64
```

在代码里，名字本身不够，值、`shape`、类型都要一起读。

## 函数是把输入变成输出的关系

\[
y = f(x)
\]

这可以读成：`x` 进入后，经过关系或规则 `f`，再作为 `y` 出来。

在 AI 语境里，`f` 可能是人手写的规则，也可能是训练后的模型。

```python
def is_adult(age):
    return age >= 19

print(is_adult(20))
```

示例输出：

```text
True
```

模型也可以从宽泛意义上读成函数：

```python
prediction = model(input_data)
```

## 表达式表示计算关系

表达式(expression)是由值、变量、运算符与函数组合起来，用来表示某种计算或关系的写法。

\[
x + y
\]

\[
2x + 1
\]

\[
f(x)
\]

\[
(\mathrm{prediction} - \mathrm{target})^2
\]

例如：

```python
prediction = 2.8
target = 3.0
error = prediction - target
squared_error = error ** 2

print(squared_error)
```

示例输出：

```text
0.04000000000000007
```

表达式并不是符号装饰。它决定了哪些值被比较、哪些差异被放大，以及最终要得到什么结果。

## 本节要记住的视角

变量是值的名字，函数是输入到输出的关系，表达式是计算的压缩写法。只要这三个区分固定下来，后面的预测、损失、学习公式就更容易定位。

## 简短检查

- 能把变量解释成值的名字。
- 能把函数解释成输入到输出的关系。
- 能把表达式解释成计算的压缩表示。
- 能把 `y = f(x)` 读成最简单的输入-变换-输出结构。
