# P2-2.4 为什么 log 与 exp 会反复出现

> Section ID: `P2-2.4`
> Version: `v2026.07.09`

当极限也重新接上之后，在后面的机器学习与深度学习说明里，仍然还有一类记号会反复把读者卡住：`log`、`exp`、`e^x`。它们不是高级数学装饰，而是在说明“值增长或缩小得有多快”“怎样把乘法关系重新读成加法关系”“怎样处理像概率一样的分数”时反复会出现的语言。

## 本节范围

这里首先要解决的问题是：为什么后面的 Part 在讲概率、分数、损失时，会不断把 `log` 与 `exp` 叫回来？

因此这里只先固定四个位置。

- 指数在表达什么样的变化？
- 为什么会把对数说成“反过来读指数”的函数？
- 为什么乘法与除法到了对数空间里，会变成加法与减法？
- 为什么这种记号后来会在损失、概率分数、softmax 里再次出现？

## 先抓住的一个场景

| 表达 | 现在先这样读 | 后面会再次出现的位置 |
| --- | --- | --- |
| `exp(2) \approx 7.39` | 分数 2 会被展开成更大的权重 | `sigmoid`, `softmax` |
| `log(exp(2)) = 2` | 送进指数空间的值会被重新读回原坐标 | logit, log-odds |
| `0.9 x 0.8 x 0.7 = 0.504` | 概率直接相乘会很快变小 | likelihood, joint probability |
| `log(0.9) + log(0.8) + log(0.7)` | 乘法会被重新读成加法 | log loss, log-likelihood |

## 三个基准

| 基准 | 为什么重要 | 本节所需理解水平 |
| --- | --- | --- |
| 指数是“相同比率变化”的语言 | 能避免把线性增长与倍数增长混在一起 | 理解 `e^x` 是在表达比率式增长速度 |
| 对数是反过来读指数 | 不会把 `log` 当成孤立的新符号死记 | 理解 `exp` 与 `log` 是相反方向的角色 |
| log 与 exp 是后面“分数解释语言”的一部分 | 能避免损失、概率、softmax 看起来像突然冒出的符号 | 这里先抓住连接关系就够了 |

## 指数表达的是重复的比率变化

\[
e^x
\]

这就是以 `e` 为底的指数函数。重点不是先背定义，而是先感受到：`x` 每增加一点，`e^x` 的增长并不是线性的，而是会越来越拉开。

| 步骤 | 线性增长：每次 `+10` | 比率增长：每次 `x1.1` |
| --- | --- | --- |
| 起点 | 100 | 100 |
| 第 1 步后 | 110 | 110 |
| 第 2 步后 | 120 | 121 |
| 第 3 步后 | 130 | 133.1 |

## 对数是在反过来读指数

\[
\log(x)
\]

例如：

- `exp(2)` 是 `e^2`
- `log(e^2)` 会回到 `2`

所以对数与指数，其实是在同一个关系上往相反方向读取。

## 为什么乘法会在对数空间里看起来像加法

如果把三个概率相乘：

\[
0.9 \times 0.8 \times 0.7 = 0.504
\]

继续乘更多值时，结果会很快变小。取对数之后，同样的乘法可以被读成加法：

\[
\log(0.9 \times 0.8 \times 0.7)
=
\log(0.9) + \log(0.8) + \log(0.7)
\]

这就是为什么机器学习里，比起直接把很多概率相乘，更常见的是在对数空间里去读它们。

## 它会在什么地方再次出现

| 后面再次出现的场景 | 现在先留下的直觉 |
| --- | --- |
| 逻辑回归里的 `sigmoid` | 指数可以帮助把分数压到 0 到 1 之间 |
| log loss | 对数能更强地惩罚“错得很自信”的概率预测 |
| softmax | 指数与对数帮助把多个分数重新变成可比较的比率 |

## 一个很短的计算例子

假设两个候选的分数是 `2` 和 `1`。它们本身还不是概率。做指数变换后：

\[
e^2 \approx 7.39,\quad e^1 \approx 2.72
\]

较大的分数会得到更大的权重。

| 步骤 | 计算 | 现在在读什么 |
| --- | --- | --- |
| 原始分数 | `2`, `1` | 还只是分数 |
| 指数变换后 | `exp(2) \approx 7.39`, `exp(1) \approx 2.72` | 较大的分数被赋予更大的权重 |
| 归一化后 | `7.39 / (7.39 + 2.72)` | 开始变成可比较的比率 |

同样的直觉也会出现在 log loss：

| 正确概率 `p` | `-log(p)` 的感觉 |
| --- | --- |
| `0.9` | 损失小 |
| `0.5` | 损失更大 |
| `0.1` | 损失非常大 |

## 本节要记住的视角

- 指数读的是重复的比率变化，而不是重复加同样的量。
- 对数是在把指数变化重新拉回原坐标来读。
- 当许多小概率相乘时，对数让你能把它重新读成加法。
- `sigmoid`、`softmax`、`log loss` 都会再次调用这套“分数 -> 比率 -> 损失”的语言。

## 简短检查

- 能把 `exp(x)` 读成 `e` 的幂。
- 能说明为什么 `log(x)` 是反过来读指数。
- 能说明固定加法增长与固定比率增长的差别。
- 能说明为什么对很多小概率取 log 后更容易读。
- 能说明为什么 softmax 与 log loss 会再次把 log/exp 叫回来。
