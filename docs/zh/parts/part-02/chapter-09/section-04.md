# P2-9.4 补充学习：第一次阅读传统数据结构名称

> Section ID: `P2-9.4`
> Version: `v2026.07.09`

一旦数据结构学习展开，很多名字会突然一起出现：array、linked list、stack、queue、tree、graph、hash table。这个补充节是为了把这些名字先和它们想解决的问题连起来。

## 本补充节范围

本节给出传统数据结构名称的第一层阅读框架，不替代完整的数据结构课程。

## 中心问题

每一种传统结构，到底让哪一类问题更容易？

## 记住的视角

- array：按位置读取
- stack：后进先出
- queue：先进先出
- tree：层级
- graph：关系遍历
- hash table：按键查找

## 简短检查

- 能把每个结构名称和一个代表性问题对应起来。
- 能说明为什么 Python 的 list 与 dict 只是更一般结构思想的方便表面。
- 能说明为什么这些结构名称会在 AI 实践里再次出现。
