# P2-9.1 为什么需要数据结构

> Section ID: `P2-9.1`
> Version: `v2026.07.07`

Chapter 8 恢复了 Python 的值、列表、字典、循环、函数。现在问题变大了：为什么我们还需要“数据结构”这个概念？

## 本节范围

本节先把数据结构当成“存放和处理数据的形状”，再进入具体结构比较。

## 中心问题

为什么数据的组织方式会改变“什么问题更容易问、什么操作更容易做”？

## 记住的视角

- 数据结构不只是存放方式，也是阅读方式。
- 位置、行列、层级、关系会分别让不同问题变得容易。
- 结构问题往往先于算法问题。

## 简短检查

- 能说明为什么“同一份数据”仍然可能需要不同结构。
- 能说明组织形状一变，什么东西会跟着变。
- 能说明为什么结构名称最好通过问题来记，而不是只背标签。
