# P2-13.1 图表能揭示什么

> Section ID: `P2-13.1`
> Version: `v2026.07.08`

P2-13.1 把 plot 当成一种工具：它能比单纯表格更快地看出形状、变化、分布与比较关系。

## 本节范围

本节介绍 plot 的角色、`Figure` 与 `Axes` 的区别，以及“图表从问题开始”这件事。

## 中心问题

图表能比“精确数值表”更快揭示什么？

## 记住的视角

- 表格擅长精确值，图表擅长可见形状。
- 图表应从读取问题开始，而不是从死记图表名称开始。
- `Figure` 是整体画布，`Axes` 是真正放数据的坐标区域。
- 图表可以提示模式，但不会自动证明原因。

## 简短检查

- 能说明为什么线图可能比表格更快暴露训练趋势。
- 能说明 `Figure` 与 `Axes` 的区别。
- 能说明为什么看到模式不等于已经得到最终结论。
