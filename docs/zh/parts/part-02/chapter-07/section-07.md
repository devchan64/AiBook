# P2-7.7 补充学习：什么时候真的需要安装 Python

> Section ID: `P2-7.7`
> Version: `v2026.07.07`

终端与位置感建立之后，另一个初学者问题也会回来：我现在就必须安装 Python 吗？

## 本补充节范围

本节解释什么时候安装 Python 是必要的，什么时候可以先用 Colab 之类的托管环境开始。

## 中心问题

什么时候安装是必须的，什么时候又可以不把安装变成学习的第一道门槛？

## 记住的视角

- Colab 可以降低第一次练习的门槛。
- 当你需要自己的文件、环境和可重复的本地流程时，本地安装会变得有意义。
- “现在就安装”不一定是最早的学习要求。

## 简短检查

- 能说明什么时候 Colab 就够了。
- 能说明什么时候值得开始本地安装。
- 能说明为什么安装时机也是学习策略的一部分。
