# P2-7.2 终端、Shell 与工作目录

> Section ID: `P2-7.2`
> Version: `v2026.07.07`

把执行位置分清之后，本地机器上最先遇到的画面通常就是终端。

## 本节范围

本节入门介绍 `terminal`、`shell`、`working directory`、`path`、`command`。

## 中心问题

当教程说“打开终端，进入项目文件夹，再执行这个命令”时，这几个词各自到底是什么意思？

## 记住的视角

- terminal 和 shell 有关，但不是同一个东西。
- 很多初学者问题其实首先是“位置问题”，不是“代码问题”。
- `pwd`、`cd`、`ls` 重要，是因为命令会以当前工作目录为基准来解释。

## 简短检查

- 能区分 terminal 与 shell。
- 能说明为什么 working directory 很重要。
- 能说明为什么命令文本对了、位置错了仍然会失败。
