# P2-8.2 列表：有顺序的值集合

> Section ID: `P2-8.2`
> Version: `v2026.07.09`

在值、变量、类型之后，下一个基本结构就是列表。

## 本节范围

本节入门介绍 `list`、`index`、`item`、可变性、嵌套列表。

## 中心问题

什么时候应该把多个值读成“有顺序的一组”，而这个顺序又让我们能做什么？

## 记住的视角

- list 是有顺序的集合。
- index 是按位置访问。
- 列表是 mutable，所以后面的复制/引用混乱并不是偶然。
- Python list 不能自动和数值 array 读成同一个东西。

## 简短检查

- 能把 list 解释成有顺序的值集合。
- 能把 index 解释成位置。
- 能说明为什么 mutable 很重要。
- 能说明为什么 Python list 不该直接等同于 NumPy array。
