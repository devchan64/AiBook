# P2-8.1 值、变量与类型

> Section ID: `P2-8.1`
> Version: `v2026.07.09`

Chapter 7 恢复了代码在哪里运行，Chapter 8 则开始恢复 Python 最基础的表达到底是什么意思。

## 本节范围

本节入门介绍 `value`、`variable`、`type`、`assignment` 与基本内置类型。

## 记住的三句话

- value 是计算真正处理的数据。
- variable 是贴在 value 上的名字。
- type 告诉我们这个 value 可以做什么操作。

## 记住的视角

- Python 里的 `=` 是 assignment，不是学校里的等式。
- type 解释了为什么看起来一样的运算会有不同表现。
- 后面的许多错误，一旦先分清 value、variable、type，就更容易理解。

## 简短检查

- 能分别解释 value、variable、type。
- 能说明为什么 `score = 82` 更像“命名”而不是“证明相等”。
- 能说明为什么 `"82"` 和 `82` 不是同一种 value。
