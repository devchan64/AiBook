# P2-8.6 补充学习：第一次遇到类与对象

> Section ID: `P2-8.6`
> Version: `v2026.07.09`

函数之后，Python 里还会频繁出现另一种写法：`value.method()` 和 `object.attribute`。

## 本补充节范围

本节只给出 `class`、`object`、`method`、`attribute` 的第一层读法，不把它变成完整面向对象课程。

## 中心问题

面对点号表达式时，怎样先读懂它，而不是把所有东西都混成“又一种函数调用”？

## 记住的视角

- object 可以先读成“带有状态和行为的东西”。
- method call 和 attribute access 有关，但不是同一件事。
- 这个补充节目标是帮你读代码，不是立刻掌握所有设计模式。

## 简短检查

- 能说明 `object.attribute` 和 `object.method()` 的区别。
- 能用入门方式解释 class 与 object。
- 能说明为什么库代码里点号表达式这么常见。
