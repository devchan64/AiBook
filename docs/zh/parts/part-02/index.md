# Part 2. 基础恢复

> Section ID: `P2-index`
> Version: `v2026.07.09`

Part 2 是在重新学习机器学习与深度学习之前，恢复数学、Python、数据工具与文档记录感的一段。这里不追求把所有证明做完，也不要求把 Python 语法全部背下来。重点是为后面的 Part 3 打下最小基础，让你能读懂训练、评估、过拟合与泛化，并用小段代码亲自验证。

这里最核心的目标，是让“AI 文档与示例代码里反复出现的计算语言”重新变得可读。公式、数组、表格、图像、运行环境与 Git 历史并不是分散主题，而是一起被用来读模型计算、检查数据集、可视化结果并留下可复现学习记录的工具。

所以 Part 2 重新连接基础：

1. 重新阅读公式记号。
2. 恢复线性代数、导数、概率、统计与优化的直觉。
3. 复习 Python 运行环境与语法。
4. 用 NumPy、Pandas、Matplotlib 检查小计算。
5. 用 Git 管理文档与代码变化历史。
6. 在进入 Part 3 前建立检查标准。

## 这一 Part 的目的

Part 2 是把你很久以前学过、或者只零散接触过的数学与软件工具，重新整理成 AI 再学习语言的一段。

很多人会卡住，并不只是因为数学难，而是因为 \(x\)、\(\sum\)、\(\frac{1}{n}\)、向量、矩阵、导数、梯度、概率、平均、损失这些表达，会同时出现在代码、数据与模型说明里。

## 读完这一 Part 会得到的理解

读完之后，你可以不再把数学与软件工具看成互不相干的科目，而把它们看成一条共同的学习流程。

1. 公式记录计算意图。
2. Python 执行小计算。
3. NumPy 复用向量与矩阵计算。
4. Pandas 让你把数据集读成表。
5. Matplotlib 让你检查数字的形状。
6. Git 留下原稿、代码与结果的变更历史。

有了这层理解，到了 Part 3，`X`、`y`、`fit`、`predict`、loss、metric、train、validation、test 这些表达就不会再像完全陌生的语言。
