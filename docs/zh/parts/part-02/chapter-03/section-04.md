# P2-3.4 点积、范数、距离与相似度

> Section ID: `P2-3.4`
> Version: `v2026.07.09`

读完向量和矩阵乘法之后，下一个问题自然会出现：我们怎么比较两个向量？

这里就会遇到 `dot product`、`norm`、`distance`、`similarity`。它们不是同一个问题，后面的 AI 主题会反复用到这种区分。

## 本节范围

本节只处理比较直觉，不展开余弦相似度证明或高维几何细节。

## 先抓住的一个场景

| 比较对象 | 先看到什么 | 现在要抓住的问题 |
| --- | --- | --- |
| `q = [1, 1]`, `a = [2, 2]` | 方向相同，大小更大 | 方向重要，还是大小也重要？ |
| `q = [1, 1]`, `b = [1, 0]` | 少了一个方向分量 | 它们是近，还是只是部分对齐？ |
| `q = [1, 1]`, `c = [10, 10]` | 很远，但方向几乎相同 | 距离与方向相似会不会给出不同答案？ |

## 记住的视角

- 点积把两个向量折叠成一个数。
- 范数读的是大小。
- 距离和相似度回答的不是同一个问题。
- 当方向比绝对大小更重要时，余弦相似度会很有用。

## 简短检查

- 能说明点积是“对应位置相乘再相加”。
- 能说明为什么范数不等于相似度。
- 能说明为什么距离与相似度可能给出不同判断。
