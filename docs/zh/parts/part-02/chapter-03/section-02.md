# P2-3.2 向量空间与位置直觉

> Section ID: `P2-3.2`
> Version: `v2026.07.09`

P2-3.1 把向量看成有顺序的值列表。这里再向前一步：在 AI 文档里，向量经常会被读成“某个空间中的位置”。

这很重要，因为后面会不断出现这些语言：

- 距离
- 相似度
- 邻近
- 嵌入空间

## 本节范围

本节用直觉方式介绍 `vector space`、`dimension`、`position`、`distance`、`similarity`。

## 先固定的术语

| 术语 | 很短的意思 | 本节中的作用 |
| --- | --- | --- |
| vector space | 按共同规则比较向量的地方 | 本节背景 |
| dimension | 坐标轴数量或值的个数 | 读取向量形状 |
| position | 一个向量在空间里的位置 | 为什么向量能像点一样读 |
| distance | 两个向量相隔多远 | 近与远的比较 |
| similarity | 两个向量有多像 | 搜索与嵌入的连接点 |

## 为什么向量会变成位置

如果向量有坐标，它就可以像点一样放在空间里。多个向量放进同一空间后，就能问：

- 谁更近？
- 谁更远？
- 谁方向更像？

这正是嵌入、检索、推荐里经常使用的读法。

## 记住的视角

- 向量不只是列表，也可以读成位置。
- 距离和相似度必须在同一空间里比较。
- 嵌入可以理解成“把数据放进一个可比较的位置空间”。

## 简短检查

- 能说明为什么向量可以被看成位置。
- 能把维度先读成“坐标个数”。
- 能说明为什么比较必须先在同一空间里进行。
