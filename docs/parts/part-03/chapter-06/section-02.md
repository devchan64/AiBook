# 3.12 최근 구간과 기준선 비교표는 어떻게 읽는가

기준선 비교표가 만들어지면 이제 숫자가 많이 보이기 시작합니다. 최근 평균, 기준선 평균, 차이값, 비율 차이, 최근 변동성, 기준선 변동성 같은 열이 한꺼번에 나타날 수 있습니다. 이때 초심자는 종종 가장 눈에 띄는 차이값 하나만 보고 곧바로 결론을 내립니다. 하지만 비교표는 읽는 순서가 중요합니다.

비교표는 보통 다음 순서로 읽는 편이 안전합니다.

1. 최근 구간이 몇 건으로 만들어졌는지 본다.
2. 비교 대상 기준선이 무엇인지 본다.
3. 절대값보다 차이값과 비율 차이를 함께 본다.
4. 평균뿐 아니라 변동성과 패턴 열도 함께 본다.
5. 마지막에야 운영 문장으로 요약한다.

| 열 | 먼저 읽을 때의 질문 |
| --- | --- |
| 최근 구간 건수 | 이 숫자를 말할 만큼 사례가 모였는가 |
| 기준선 기간 또는 조건 | 무엇과 비교하고 있는가 |
| 평균 차이 | 전체 수준이 달라졌는가 |
| 변동성 차이 | 흔들림의 크기도 달라졌는가 |
| 패턴 또는 세그먼트 요약 | 평균이 가린 구조 차이가 있는가 |

예를 들어 최근 구간 평균이 기준선보다 낮다고 해 봅시다. 이때 바로 `성능이 나빠졌다`고 말하기보다, 먼저 최근 구간 건수가 충분한지 보고, 그 다음 변동성도 함께 커졌는지 확인하고, 마지막으로 패턴 요약에서 후반 하강이 반복되는지까지 봐야 합니다. 이런 순서를 거치면 같은 숫자 차이도 `단발성 튐`, `완만한 변화`, `반복적 상태 변화`로 더 다르게 읽을 수 있습니다.

운영 문장도 비교표를 그대로 복사하듯 쓰기보다 비교 구조를 반영해 정리하는 편이 좋습니다. 예를 들면 다음처럼 쓸 수 있습니다.

- 최근 20건은 기준선 대비 후반 하강률이 더 크게 나타났다.
- 최근 구간의 변동성도 함께 커져 단발성보다 반복적 변화 가능성을 먼저 본다.
- 원인 확정은 보류하고 검토 우선순위를 높인다.

간단한 장난감 비교표도 같은 읽기 순서를 보여 줄 수 있습니다.

```python
import pandas as pd

report = pd.DataFrame(
    [
        {"process_type": "type-A", "recent_count": 20, "recent_mean": 2.10, "baseline_mean": 2.45, "recent_std": 0.22, "baseline_std": 0.11},
        {"process_type": "type-B", "recent_count": 3, "recent_mean": 2.05, "baseline_mean": 2.45, "recent_std": 0.35, "baseline_std": 0.12},
    ]
)
report["diff"] = report["recent_mean"] - report["baseline_mean"]

print(report[["process_type", "recent_count", "recent_mean", "baseline_mean", "diff", "recent_std", "baseline_std"]])
```

예상 출력:

```text
  process_type  recent_count  recent_mean  baseline_mean  diff  recent_std  baseline_std
0       type-A            20         2.10           2.45 -0.35        0.22          0.11
1       type-B             3         2.05           2.45 -0.40        0.35          0.12
```

두 행 모두 차이값은 비슷하게 커 보입니다. 하지만 `type-B`는 최근 구간이 3건뿐이라 더 조심스럽게 읽어야 합니다. 이런 예시를 보면 왜 `차이값만 먼저 보면 안 된다`는 말을 하는지 더 쉽게 이해할 수 있습니다.

이 절에서 기억해야 할 핵심은 다음과 같습니다. `비교표는 차이값 하나가 아니라 비교 구조 전체로 읽어야 한다.` 최근 구간, 기준선, 차이값, 변동성, 패턴 열을 함께 읽을 때 오해가 줄어듭니다.
