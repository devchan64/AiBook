# P3-8.3 保守解释应按什么顺序、用什么措辞写成？

> Section ID: `P3-8.3`
> Version: `v2026.09.20`

如果只留下“怀疑存在异常，需要复核”，读者无法知道比较了什么、应该检查什么。保守写作并不是模糊观察到的数值，而是准确写出已确认的[比较结果](/AiBook/zh/reference/concept-glossary-pinyin/s/#output-structure)，并将未知内容与下一步核查行动分开传达。

## 从比较表的一行提取写作信息

取[P3-7.2](../chapter-07/section-02.zh.md)虚拟汇总中的type-A：基线为过去200次动作，近期为20次已完成动作。继续采用类型、运行条件与测量定义相同、所需测量值齐备的假设。这些是句子写作练习用的汇总值，并非由实际原始日志计算的结果。

| 句子中需要的信息 | type-A的数值与含义 |
| --- | --- |
| 比较对象 | 相同条件下过去200次与近期20次动作 |
| 后段均值差 | 近期2.2−基线2.8=−0.6 L/min |
| 动作间的分散程度 | 各动作后段均值的标准差：0.2→0.4 L/min |
| 动作内部下降 | 后段均值−前段均值 ≤ −0.30 L/min的动作有14/20次，即70% |

总体均值对各动作的后段均值采用等权平均。下降规则包含边界值，每次动作只计一次。“均值低0.6”与“14次满足规则”是不同观察，不能互相替代。

## 分别写出观察、不确定性与核查行动

不必把所有条件塞进一个长句。将报告分成下面三个部分，更容易确认各自的作用。

1. **观察：** 与相同条件下过去200次动作相比，近期type-A 20次动作的后段均值从2.8降至2.2 L/min，低0.6 L/min；各动作后段均值的标准差从0.2增至0.4 L/min。20次中有14次满足动作内部下降规则。
2. **不确定性：** 该汇总缺少发生顺序与基线下降次数，因此无法判断是否连续下降或下降比例增加，原因也尚未确认。
3. **核查行动：** 复核者将近期20次动作按时间排列的原始记录与逐次设置历史对照，并确认按相同规则统计的基线下降次数。

第一部分为便于阅读分成了两句。重点是区分三个作用，而不是限定句子数量。“核查”是接下来要做的工作，并非报告已经完成核查。实际报告还应附上比较时段、设备、基线版本与原始记录位置，方便他人找到同一证据。不要擅自填入虚拟表中没有的日期或版本。

## 补回缺失依据，而不只是更换形容词

| 待修改的表达 | 修改后的表达 | 修改理由 |
| --- | --- | --- |
| 流量严重恶化 | 近期20次动作的后段均值比基线200次低0.6 L/min | 保留对象、次数与单位，不附加恶化判断 |
| 近期动作有70%发生故障 | 近期20次中有14次满足规定的动作内部下降规则 | 区分规则满足与故障判定 |
| 可能持续连续下降 | 14次动作满足规则，但发生顺序尚未确认 | 加上“可能”不会产生连续性的证据 |
| 需要进一步确认 | 将近期20次按时间排列的原始记录与设置历史对照 | 指定检查对象与工作内容 |

“怀疑”“可能”也不能代替依据。尤其在没有解释为何选择传感器这一候选原因时，“可能是传感器故障”会把注意力引向特定原因。提出候选原因时，应同时写明理由与有助于区分它的记录。候选检查方式可参考[P3-8.2](section-02.zh.md)。

## 分开写小样本限制与必要处置

同一P3-7.2案例的type-B有近期3次、基线200次，后段均值从2.8降至1.9 L/min，近期有1次满足下降规则。不要写“只有3次，所以推迟处置”，可以改为：

> 近期type-B 3次动作的后段均值比基线200次低0.9 L/min，满足下降规则的比例为1/3。仅凭三次观察，对持续状态变化或原因的判断依据有限。立即核查这三次动作的原始测量值，以及另行制定的允许限值和响应程序。

最后一句不表示已经确认超限，也不是自动停机命令。它要求核查是否超限，并按结果适用已有程序。表中没有允许限值，因此不能据此新定警告等级。**持续性依据不足**与**执行必要核查**可以同时写出。

## 自己写一遍

请修改这句针对type-A的报告：“20次已经足够，70%连续发生故障，因此更换传感器。”加入比较差值、动作次数和规则满足次数，再分别写出未确认事项与下一步要看的记录。

参考答案：“相对于相同条件下过去200次动作，近期type-A 20次的后段均值低0.6 L/min，14/20次满足下降规则。仅凭20次这一数量不能保证代表性，发生顺序、是否存在故障及原因尚未确认。将近期动作按时间排列的原始记录与设置历史对照，并检查判断传感器状态所需的额外测量记录。”这样删除了缺乏依据的连续故障主张与更换传感器决定，同时保留了核查工作。

## 检查清单

- 是否写明比较对象、次数、单位与规则满足次数？
- 是否用具体缺失信息表达不确定性，而非笼统修饰语？
- 是否指定待查记录与任务，且没有仅因样本小而推迟必要处置？
