# P3-5.3 원시 시계열이 있어도 왜 바로 학습 입력이라고 말할 수 없는가

> Section ID: `P3-5.3`
> Version: `v2026.09.19`

원시 시계열도 [학습 입력](../../../reference/concept-glossary-parts/05-mieum.md#model-input)으로 사용할 수 있습니다. 다만 기록이 있다는 사실만으로 한 입력의 경계·순서·길이·목표가 정해지지는 않습니다. **수작업 요약은 표현의 선택이고, 어떤 정보를 한 입력으로 묶을지는 어느 표현에서도 정해야 합니다.**

## 같은 네 관측에서 두 입력을 만들기

다음은 두 동작의 가상 유량 기록입니다. 각 동작은 시작 0초부터 종료 3초까지 1초 간격으로 네 번 측정했으며, 여기서는 네 값 모두 그 동작의 종료 시점에 이용 가능하다고 가정합니다. 유량 단위는 L/min입니다.

| event_id | 0초 | 1초 | 2초 | 3초 |
| --- | ---: | ---: | ---: | ---: |
| A | 1 | 3 | 3 | 1 |
| B | 3 | 1 | 1 | 3 |

동작 종료 시점에 나중에 확정될 검토 결과를 예측하는 문제를 생각해 보겠습니다. [샘플](../../../reference/concept-glossary-parts/07-siot.md#glossary-sample)은 동작 1회입니다. 결과 라벨은 같은 `event_id`에 연결하되 입력 값에 섞지 않습니다. 아래 표는 입력 후보만 보여 주며 실제 결과 라벨이나 학습된 모델은 제공하지 않습니다.

| 표현 | A의 입력 | B의 입력 | 입력 요소의 뜻 |
| --- | --- | --- | --- |
| 요약 벡터 | `[2, 3]` | `[2, 3]` | 순서대로 `[평균 유량, 최대 유량]` |
| 시계열 입력 | `[[1], [3], [3], [1]]` | `[[3], [1], [1], [3]]` | 바깥쪽은 0→3초, 안쪽은 유량 1개 |

벡터는 정해진 순서로 늘어놓은 값 묶음입니다. A의 평균은 `(1+3+3+1)/4 = 2`, 최대값은 3입니다. B도 같은 두 값이므로 이 요약만으로 A와 B의 순서 차이를 구별할 수 없습니다. 평균·최대값만을 입력으로 받는 모델에는 두 사례가 같은 입력으로 보입니다.

시계열 입력은 **4시점 × 시점당 1개 값**의 형태입니다. A는 가운데 두 관측이 높고, B는 첫째·마지막 관측이 높다는 차이를 남깁니다. 다만 네 번의 관측 사이에서 실제로 무슨 일이 있었는지까지 보존하는 것은 아닙니다. 또한 순서를 남겼다는 사실만으로 어떤 모델이든 그 차이를 잘 학습한다고 보장할 수는 없습니다.

## 요약 벡터는 시계열 입력의 필수 경유지가 아니다 {#_5}

아래 두 가지는 같은 관측에서 나오는 대안입니다. 시계열 입력을 만들기 위해 먼저 평균·최대값 벡터를 거칠 필요는 없습니다.

```mermaid
--8<-- "assets/part-03/chapter-05/p3-5-3-mermaid-01-ko.mmd"
```

평균과 최대값으로 답할 수 있는 질문에는 작은 요약 벡터가 비교하기 쉽습니다. 높은 값이 언제 나타났는지가 중요하다면 시계열이나 순서를 반영한 다른 특징이 필요할 수 있습니다. 원시 순서를 보존하는 입력과 검토용 요약 표를 함께 유지하는 것도 가능합니다. 요약 표가 사람의 비교 도구라는 점을 모델의 필수 입력 조건으로 바꾸지 않습니다.

## 두 표현에 공통으로 남길 입력 명세

| 정할 항목 | 이 사례의 선택 | 정하지 않으면 생기는 문제 |
| --- | --- | --- |
| 샘플 경계와 식별자 | 한 동작의 0~3초, `event_id` | 서로 다른 동작의 기록을 한 입력으로 합칠 수 있음 |
| 값과 순서 | 유량 L/min, 시간 오름차순 | 열 순서나 시간 순서가 뒤섞일 수 있음 |
| 입력 길이 | 이 사례는 4시점 | 관측이 3개인 경우에도 같은 입력인 척할 수 있음 |
| 예측 시점과 정보 범위 | 종료 3초까지 도착한 관측 | 예측 시점 뒤의 정보가 입력에 들어갈 수 있음 |
| 목표와 연결 | 이후 확정된 검토 결과를 같은 사건에 연결 | 다른 사건의 결과를 붙이거나 결과를 입력에 섞을 수 있음 |

네 시점은 이 사례의 선택이지 모든 시계열 모델의 필수 길이가 아닙니다. 동작 길이가 다르면 가변 길이를 지원하는 형식, 구간 자르기, 빈자리 채우기 중 무엇을 쓸지 정합니다. 값을 채운다면 실제 관측과 구분하는 표시도 필요합니다. 길이를 맞추는 과정이 어떤 정보를 버리거나 추가하는지도 기록합니다.

연습으로 A의 2초 관측이 없다고 가정해 보세요. `[1, 3, 1]`만 남기면 원래 3초 값이 세 번째 자리에 당겨집니다. 없던 값을 0으로 넣어 `[1, 3, 0, 1]`로 만들면 평균은 1.25가 되지만, 이것은 실제 유량 0을 관측한 결과가 아닙니다. 이 사례에서는 해당 입력을 보류하고 누락 위치를 기록한다고 정하겠습니다. 값을 채워 사용하는 설계라면 채움 규칙과 누락 표시를 함께 정의해야 합니다.

## 예측 시점을 앞당기면 쓸 수 있는 값도 달라진다

이번에는 종료 뒤의 결과를 1초 시점에 미리 예측한다고 해 보겠습니다. 그때 사용할 수 있는 A의 관측은 `[1, 3]`, B는 `[3, 1]`입니다. 2초·3초 값은 아직 사용할 수 없습니다. 전체 네 관측의 요약 벡터도 그 시점에는 계산할 수 없으므로 입력 후보에서 제외합니다.

두 시점만 요약하면 A·B 모두 `[평균 2, 최대 3]`이지만, 순서를 유지한 두 입력은 여전히 다릅니다. “순서를 남길 것인가”와 “어디까지 관측할 수 있는가”는 별개의 결정입니다. 이후에 붙이는 결과 라벨을 미리 입력에 포함하지 않는 것처럼, 예측 시점 뒤의 관측도 경계를 넘어 넣지 않습니다.

외부 검토 라벨이 모든 학습의 필수 조건은 아닙니다. 같은 A 기록으로 다음 값을 예측하는 별도 문제를 만들면 `0~2초 입력 [1, 3, 3] → 3초 목표 1`로 정할 수 있습니다. B는 `[3, 1, 1] → 3`입니다. 사람이 붙인 검토 결과 없이도 목표를 기록에서 만들지만, 입력과 미래 목표의 시간 경계는 여전히 필요합니다.

## 체크리스트

- A와 B가 같은 `[2, 3]`으로 요약되는 계산과 잃는 정보를 설명할 수 있는가?
- 시계열 입력의 4×1에서 두 숫자가 뜻하는 것을 말할 수 있는가?
- 수작업 요약 없이도 샘플 경계·값 순서·길이·목표를 정했는가?
- 누락을 실제 0이나 시간 순서의 당김과 구별하는가?
- 1초 예측에 2~3초 관측 또는 그 관측의 요약을 넣지 않는가?
- 외부 검토 라벨과 기록에서 만든 미래 목표를 구분하는가?
