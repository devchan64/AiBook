# 3.3 원천데이터를 처음 보면 왜 바로 모델을 떠올리게 되는가

> Section ID: `P3-2.1`
> Version: `v2026.07.05`

원천데이터를 처음 받으면 많은 사람이 거의 반사적으로 `이걸로 무엇을 예측할까`부터 떠올립니다. 표가 있고 값이 많고 시간이 흐르며 측정된 기록도 보이니, 곧바로 분류기나 회귀 모델을 붙이면 될 것처럼 느껴지기 때문입니다. 하지만 이 반응은 대개 너무 빠릅니다. 눈앞의 표는 아직 `학습용 데이터셋`이 아니라 `기록된 원천데이터`일 가능성이 더 크기 때문입니다.

자동으로 실행되는 동작 1회마다 제어 파라미터 시계열과 센서 시계열이 남는 상황을 떠올려 봅시다. 초심자는 이 표를 보자마자 다음 같은 생각을 하기 쉽습니다.

- 센서 값이 있으니 이상 탐지 모델을 만들 수 있겠다.
- 동작 결과가 조금 다르니 분류 문제로 바꾸면 되겠다.
- 시계열이 길면 딥러닝 모델이 더 잘 맞을 것 같다.

이 생각들 자체가 틀린 것은 아닙니다. 문제는 `무엇을 한 건으로 볼지`, `무엇을 맞히려는지`, `라벨이 실제로 있는지`도 정하지 않은 상태에서 모델 이름이 먼저 등장한다는 점입니다. 이 상태에서는 아직 데이터 문제를 정의한 것이 아니라, 데이터보다 모델을 먼저 떠올린 것입니다.

왜 이런 일이 자주 생길까요. 첫째, 표가 보이면 사람은 쉽게 `이미 정리된 데이터셋`이라고 느낍니다. 둘째, AI 학습 경험이 모델 이름 중심으로 남아 있으면 문제 표현보다 알고리즘 선택이 먼저 떠오릅니다. 셋째, 원천 시계열이 길고 복잡할수록 `어차피 모델이 알아서 패턴을 찾지 않을까`라는 기대가 생기기 쉽습니다.

하지만 원천데이터를 곧바로 데이터셋처럼 읽으면 중요한 질문이 빠집니다.

| 먼저 떠올리기 쉬운 질문 | 실제로 더 먼저 필요한 질문 |
| --- | --- |
| 어떤 모델을 쓸까 | 무엇을 한 건의 샘플로 볼까 |
| 라벨을 무엇으로 둘까 | 지금 라벨이 정말 안정적으로 있는가 |
| 정확도를 어떻게 올릴까 | 어떤 표로 다시 묶어야 비교가 가능한가 |

이 차이는 단순한 순서 문제가 아닙니다. 원천데이터를 처음 볼 때 필요한 일은 모델 선택이 아니라 `표의 정체를 다시 묻는 일`입니다. 지금 보고 있는 것이 시점별 측정 기록인지, 동작 1회 요약인지, 최근 구간 집계인지에 따라 뒤의 특징(feature), 기준선(baseline), 목표 라벨(target) 설명이 모두 달라집니다.

예를 들어 다음처럼 원천데이터의 일부만 보고도 너무 빨리 모델 이름이 튀어나올 수 있습니다.

| event_id | second | pressure | flow |
| --- | --- | --- | --- |
| A | 0 | 1.0 | 0.0 |
| A | 1 | 2.0 | 1.4 |
| A | 2 | 2.4 | 1.6 |

이 표만 보면 `분류기`, `회귀`, `딥러닝` 같은 말을 쉽게 떠올릴 수 있습니다. 하지만 아직 이 표가 `한 시점 기록`인지, `동작 1회 표`인지조차 정하지 않았습니다. 따라서 여기서 바로 모델을 고르면 문제보다 알고리즘이 먼저 앞서게 됩니다.

```python
import pandas as pd

raw = pd.DataFrame(
    [
        {"event_id": "A", "second": 0, "pressure": 1.0, "flow": 0.0},
        {"event_id": "A", "second": 1, "pressure": 2.0, "flow": 1.4},
        {"event_id": "A", "second": 2, "pressure": 2.4, "flow": 1.6},
    ]
)

print(raw)
print("row meaning candidate: one measurement at one second")
print("sample meaning candidate: not decided yet")
```

예상 출력:

```text
  event_id  second  pressure  flow
0        A       0       1.0   0.0
1        A       1       2.0   1.4
2        A       2       2.4   1.6
row meaning candidate: one measurement at one second
sample meaning candidate: not decided yet
```

마지막 두 줄이 중요합니다. 지금은 `행 의미`만 보일 뿐, `샘플 의미`는 아직 정해지지 않았습니다. 이 상태에서 모델부터 고르면, 뒤에서 데이터셋 구조를 다시 바꿔야 하는 일이 거의 반드시 생깁니다.

즉 원천데이터를 처음 받았을 때 가장 흔한 실수는 `기록 구조`를 `학습 구조`로 착각하는 것입니다. 시점별 로그가 있다는 사실만으로 아직 예측 문제가 정해진 것은 아닙니다. 그 로그를 어떤 단위로 묶고, 무엇을 남기고, 무엇과 비교할지 정해야 비로소 데이터셋이라는 말을 쓸 수 있습니다.

이 절에서 먼저 고정할 문장은 다음과 같습니다. `원천데이터가 보인다고 해서 데이터셋이 이미 주어진 것은 아니다.` 눈앞의 표를 바로 모델 입력처럼 읽는 습관을 늦추는 것이 데이터 모델링의 출발점입니다.

바로 다음 절에서는 이 문장을 더 분명히 만들기 위해, 데이터셋이 `주어진 표`가 아니라 `다시 만든 구조`라는 뜻을 구체적으로 살펴보겠습니다.
