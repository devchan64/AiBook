# P3-1.2 数据建模按什么顺序推进

> Section ID: `P3-1.2`
> Version: `v2026.09.20`

[P3-1.1](section-01.zh.md)把各时点流量记录组合成每个动作一行，并保留适合问题的指标和复核结果。构造表格时有一系列相连的决定：问题决定所需区间，样本单位决定均值和斜率的计算对象。本节讨论这些决定的顺序，以及资料不符合预期时应回到哪里。

## 从问题到复核结果，要保留什么

继续使用前节 A-101，0、1、2 秒的流量分别为 24.8、25.1、23.9 L/min。末段出现下降，于是提出“在相同条件下，末段流量是否比平常动作下降得更快”。这是确定要观察的差异，而非先假设发生故障。

把问题转成一行结果，可分为六项决定。计算式与前节相同。

| 决定 | A-101 中要确认的内容 | 保留的小产物 |
| --- | --- | --- |
| 1. 确定问题 | 与平常比较的是整体水平还是末段下降？ | 在相同条件下比较末段斜率 |
| 2. 确定样本单位 | 哪些记录构成一个案例？ | 一次动作，ID 为 `A-101` |
| 3. 组合并检查记录 | 时间与流量是否对应，所需区间是否保留？ | 组合 0、1、2 秒记录的动作资料 |
| 4. 确定特征与基线 | 计算哪个区间、如何计算、与什么比较？ | 1～2 秒斜率 −1.2 L/min/s、假设基线 0.0 L/min/s、差值 −1.2 L/min/s |
| 5. 确定输出结构 | 人以何种形式接收比较结果？ | 差值低于 −0.5 L/min/s 则标 `review` 的规则及结果 |
| 6. 写明解释边界 | 结果能支持什么？ | 比假设参照下降更陡，应复核；故障原因尚不清楚 |

这里的[输出结构](/AiBook/zh/reference/concept-glossary-pinyin/s/#output-structure)是人继续阅读的形式，如标识、比较值和复核结果。`review` 是按规则给出的标记，不同于确认实际故障后赋予的学习标签。基线 0.0、阈值 −0.5 仍是说明性假设，不是经过设备验证的标准。

本问题选择末段斜率。能够计算均值和标准差，不代表每张结果表都必须包含它们。若还需检查整体流量或分散程度，再增加相应问题及计算对象。

## 最后一条记录缺失时，应回到哪个决定

与前节不同，假设收到的 A-101 资料缺少 2 秒记录，只剩 0 秒的 24.8 和 1 秒的 25.1 L/min。计算得到 `(25.1−24.8)/(1−0) = +0.3 L/min/s`，但这是 **0～1 秒斜率**，无法回答原本的 **1～2 秒下降**问题。

若无条件使用“最后剩下的两行”，区间虽改变，却仍叫 `late_drop_rate`，缺少必要信息就被变成了上升结果。完成计算前，应回到组合并检查记录的决定。

| 重新检查发现什么 | 返回的决定与行动 | 当前保留的结果 |
| --- | --- | --- |
| 原日志有 2 秒值，但提取时遗漏 | 修正提取范围，恢复该值并计算同一区间 | 使用恢复值生成比较结果 |
| 传感器未记录 2 秒值 | 检查采集状态，注明当前无法计算 1～2 秒斜率 | 斜率和基线差未计算，输出信息不足 |
| 决定把目的改为检查初期上升 | 将问题和区间改为 0～1 秒，另定相同区间的基线 | 作为新问题的结果，不与原末段下降混合 |

“信息不足”不是第三种故障等级，而是缺少比较记录，无法应用现有复核规则。将空斜率填为 0 或改为 `no_flag`，会把未观测误读成没有变化。

即使计算值齐全，也可能要重看比较条件。例如后来发现 A-101 设置为结束前降低流量，而基线动作设置为保持恒定，就应先找相同设置的历史动作，重新确定参照。找不到时，应注明当前基线不能支持同条件比较。发现设置差异本身也不证明下降原因。

## 为什么探索结果会改变前面的决定

探索和整理记录不是表格做完后才执行一次。本例在计算斜率时发现缺失，回到记录范围；检查比较条件时重新选择基线。改变问题，也会改变所需区间和输出含义。

最初“检查末段下降”的预期提出了待验证问题。看到实际记录后，要判断保留问题、改成其他问题，还是说明当前资料无法回答。预期并不保证正确，也不保证减少工作次数。

保留决定，不是为了以后永远不改，而是为了区分“问题不变，只恢复遗漏记录”和“改变区间，回答另一个问题”。保留动作 ID、使用区间、计算规则、基线条件、复核规则及未确认事项，才能追踪需要重新检查什么。

## 检查清单

- 针对 A-101，按问题→样本→记录组合→特征与基线→输出→解释，各写一行。
- 能否解释缺少 2 秒值时，为何 0～1 秒斜率 +0.3 不能回答原问题？
- 提取时遗漏与传感器未记录两种情况，各应重新检查什么？
- 两个动作的结束设置不同，应返回哪个决定？没有相同设置记录时，结果应写什么？
- 问题改为初期上升时，区间与基线应如何一起改变？

第二问的关键是区分“算得出数字”和“回答了原问题”；区间改变，计算意义也改变。最后一问不仅要改区间，还要重新确定匹配的基线。必要信息不可得时，保留“信息不足”。
