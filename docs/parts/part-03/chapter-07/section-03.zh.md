# P3-7.3 基准线到底是拿来和什么比较的标准

> Section ID: `P3-7.3`
> Version: `v2026.07.25`

[基准线(baseline)](/AiBook/zh/reference/concept-glossary-pinyin/b/#glossary-baseline)，是决定 `当前状态应该拿去和什么比较` 的参考标准。Part 3 里之所以需要基准线，是因为最近区间、特定动作、特定对象的状态，不能只被读成一个绝对值，而应该和“平时结构”并排放在一起去读。

例如，即使最近 20 条样本的平均流量是 2.1，这个值本身也不够。我们还需要一起看到：平时区间平均值是不是 2.45，最近波动性是不是比平时更大，后段下降模式是不是比平时更明显。只有这些一起出现，才能真正说出 `到底是什么变了`。所以，基准线不是 `模型评估基准`，而是 `状态比较基准`。

## 为什么首先需要基准线

Part 3 还没有进入模型评估阶段。这里首先需要做的是：用同一单位比较最近区间和平时区间，然后读出到底有没有变化。所以，基准线会作为一种比较前提出现，帮助我们做出最近平均值、波动性、模式、区间差异这样的列。

例如，如果最近 20 条样本的平均流量是 2.1，而 [基准线区间(baseline window)](/AiBook/zh/reference/concept-glossary-pinyin/b/#glossary-baseline-window) 平均值是 2.45，那么我们首先会读到的是 `-0.35 的差异`。这个差异还不是模型性能，而是状态比较结果。

| 有基准线时能读出的东西 | 没有基准线时会变模糊的东西 |
| --- | --- |
| 最近区间和平时区间的差异 | 只能看到当前值大还是小 |
| 差值、波动性差异、模式差异 | 很难说明什么地方和以往不同 |
| 需要复核的信号 | 为什么要提出警告候选会变弱 |

只有先经过这一步，才能再去决定 `什么可以变成预测问题`，以及什么应该继续留在 [比较报告(comparison report)](/AiBook/zh/reference/concept-glossary-pinyin/c/#glossary-comparison-report) 里。Part 3 在这里要抓住的“基准线”的意思，也就到这里为止。也就是说，这一节里的基准线，就是 `把当前状态和“平时结构”并排放在一起，读出差异的参考`。

## 两种常见误解

最常见的误解有两个。

第一，有些人会觉得，只要有了基准线，解释就已经自动完成了。但基准线本质上只是一个比较参考，解释句子和复核判断仍然是后面要另外建立的阶段。

第二，有些人会觉得绝对值本身已经够了，于是对基准线轻轻带过。但这样一来，从一开始就会削弱：什么才算真正发生了变化，什么可以上升成预测问题。

| 误解 | 更准确的说法 |
| --- | --- |
| 只要有基准线，结论也会自动被定下来 | 基准线是状态比较参考，解释和判断还在后一步 |
| 只看绝对值就足够判断变化 | 想看出什么和平时不同，首先需要比较参考 |

这一节与其从“基准线”的词典定义来理解，不如更准确地把它读成：为了读出变化，应该放入什么样的 `参考测量(reference measurement)`。因此，基准线应该被读成一种 `用于状态比较的参考测量`，并与模型评估术语分开。
