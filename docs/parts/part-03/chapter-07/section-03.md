# P3-7.3 기준선 비교와 기준 모델은 왜 다른데 둘 다 필요한가

> Section ID: `P3-7.3`
> Version: `v2026.07.07`

Part 3을 읽다가 `기준선(baseline)`이라는 말을 익히기 시작하면, 곧 Part 4에서 `기준 모델(baseline model)`이라는 말을 다시 만나게 됩니다. 이름이 비슷해서 같은 뜻처럼 느껴지기 쉽지만, 둘은 서로 다른 단계의 기준입니다. 이 차이를 미리 정리해 두지 않으면 Part 3의 비교 구조와 Part 4의 평가 구조가 한꺼번에 섞여 버립니다.

가장 짧게 말하면, Part 3의 기준선은 `지금 상태를 무엇과 비교할 것인가`를 정하는 기준이고, Part 4의 기준 모델은 `학습한 모델이 정말 나아졌는가`를 정하는 기준입니다.

| 구분 | 먼저 묻는 질문 | 쓰이는 자리 |
| --- | --- | --- |
| 기준선 비교 | 지금 상태는 평소와 얼마나 다른가 | 비교 리포트, 검토 후보, 해석 경계 |
| 기준 모델 | 지금 학습 결과는 쉬운 출발점보다 얼마나 나은가 | 학습, 평가, 모델 선택 |

즉 하나는 `데이터 비교 기준`이고, 다른 하나는 `모델 평가 기준`입니다.

## 왜 Part 3에서 먼저 기준선을 다루는가

Part 3에서는 아직 모델을 평가하지 않습니다. 여기서 먼저 필요한 것은 최근 구간과 평소 구간을 같은 단위로 비교해, 변화가 있는지 없는지를 읽는 일입니다. 그래서 기준선은 최근 평균, 변동성, 패턴, 구간 차이 같은 열을 만들기 위한 비교 전제로 등장합니다.

예를 들어 최근 20건의 평균 유량이 2.1이고 기준선 구간 평균이 2.45라면, 우리는 먼저 `-0.35의 차이`를 읽습니다. 이 차이는 아직 모델 성능이 아니라, 상태 비교 결과입니다.

| Part 3에서 먼저 보는 것 | 여기서 아직 하지 않는 것 |
| --- | --- |
| 최근 구간 vs 평소 구간 차이 | 분류기 성능 비교 |
| 차이값, 변동성 차이, 패턴 차이 | 정확도, 재현율, 손실 비교 |
| 검토 필요 신호 | 모델 후보 간 점수 경쟁 |

이 단계를 먼저 거쳐야 `무엇을 예측 문제로 만들 수 있는가`와 `무엇은 비교 리포트로 남겨야 하는가`를 정할 수 있습니다.

## 왜 Part 4에서는 기준 모델이 다시 필요한가

Part 4로 넘어가면 질문이 달라집니다. 이제는 `무엇이 평소와 다른가`보다 `학습한 모델이 단순한 출발점보다 정말 나은가`를 묻게 됩니다. 그래서 기준 모델이 필요합니다.

예를 들어 어떤 라벨 예측 문제를 만든 뒤, 항상 다수 클래스만 찍는 아주 단순한 모델이나 기본 선형 모델을 먼저 두고 비교할 수 있습니다. 이때의 기준은 `최근 vs 평소`가 아니라 `복잡한 모델 vs 쉬운 출발 모델`입니다.

| Part 4에서 먼저 보는 것 | Part 3의 기준선과 다른 점 |
| --- | --- |
| 다수 클래스 기준, 단순 선형 모델, 얕은 트리 같은 출발 모델 | 데이터 구간 비교가 아니라 모델 성능 비교다 |
| 정확도, 재현율, 오류 사례 비교 | 최근 구간 차이값을 읽는 일이 아니다 |
| 복잡한 모델이 정말 의미 있는 개선을 냈는가 | 상태 변화 해석과는 질문이 다르다 |

즉 기준 모델은 `모델을 하나 세워 두는 일`이고, 기준선 비교는 `비교 열을 만들기 위해 평소 구조를 함께 두는 일`입니다.

## 둘이 어떻게 이어지는가

둘은 같은 일이 아니지만, 완전히 끊어져 있지도 않습니다. Part 3의 기준선 비교가 먼저 있어야 무엇을 문제로 삼을지 정할 수 있고, 그 뒤에야 Part 4에서 기준 모델과 평가를 붙일 수 있습니다.

순서를 한 번에 쓰면 다음과 같습니다.

1. Part 3에서 최근 구간과 기준선을 비교해 변화 구조를 읽는다.
2. 그 결과를 바탕으로 비교 리포트로 남길지, 목표 라벨 후보를 만들지 정한다.
3. 목표 라벨 후보가 비교적 안정적이면 Part 4로 넘긴다.
4. Part 4에서는 그 문제 위에 기준 모델을 두고, 더 복잡한 모델이 정말 나은지 비교한다.

이 흐름을 보면 같은 `baseline`이라는 단어가 나오더라도, 앞은 데이터 비교 단계이고 뒤는 모델 평가 단계라는 점이 분명해집니다.

## 한 장면으로 비교하기

예를 들어 동작 1회 요약 표에서 최근 구간과 평소 구간을 비교했다고 해 보겠습니다.

- Part 3 질문: `최근 20건은 기준선보다 후반 하강이 더 큰가`
- Part 3 결과: `차이값`, `변동성 차이`, `검토 필요 여부`

여기서 나중에 `review_needed` 같은 라벨 후보가 비교적 안정적으로 쌓였다고 하겠습니다.

- Part 4 질문: `이 라벨을 예측하는 모델은 단순 출발 모델보다 나은가`
- Part 4 결과: `기준 모델 점수`, `새 모델 점수`, `오류 사례 비교`

같은 데이터에서 이어지지만, 앞 질문과 뒤 질문은 분명히 다릅니다.

| 단계 | 대표 질문 | 대표 산출물 |
| --- | --- | --- |
| Part 3 기준선 비교 | 평소와 지금이 다른가 | 비교표, 차이값, 검토 문장 |
| Part 4 기준 모델 비교 | 단순 모델보다 학습 모델이 나은가 | 평가 지표, 오류 사례, 모델 비교 |

## 자주 생기는 오해

가장 흔한 오해는 두 가지입니다.

첫째, Part 3에서 기준선 비교를 했으니 이미 `baseline`을 다 배운 것처럼 느끼는 경우입니다. 하지만 Part 4의 기준 모델은 전혀 다른 층위의 개념입니다.

둘째, Part 4의 기준 모델만 신경 쓰고 Part 3의 기준선 비교를 대충 넘기는 경우입니다. 그러면 애초에 무엇이 변화였는지, 무엇이 예측 문제로 올라갈 수 있었는지의 근거가 약해집니다.

| 오해 | 더 정확한 정리 |
| --- | --- |
| 기준선과 기준 모델은 같은 말이다 | 하나는 데이터 비교, 다른 하나는 모델 평가다 |
| 기준 모델만 있으면 앞 비교 구조는 덜 중요하다 | 무엇을 문제로 삼을지 정하는 근거는 여전히 Part 3 기준선 비교에 있다 |

## 짧은 점검

- 왜 Part 3의 기준선은 `최근 vs 평소` 비교이고, Part 4의 기준 모델은 `새 모델 vs 쉬운 출발점` 비교인지 설명할 수 있는가
- 기준선 비교 없이 바로 기준 모델 이야기로 넘어가면 무엇이 흐려지는지 말할 수 있는가
- 같은 `baseline`이라는 단어가 나와도 데이터 비교 층위와 모델 평가 층위를 구분할 수 있는가

## 언제 이 관점을 먼저 떠올려야 하는가

- `baseline`이라는 단어가 같은 뜻처럼 느껴질 때 Part 3 기준선과 Part 4 기준 모델의 질문 차이를 먼저 떠올립니다.
- 기준선 비교를 끝냈다고 해서 곧바로 모델 평가 기준까지 같은 개념으로 넘겨 읽으려 할 때 이 절로 돌아옵니다.
- Part 4를 읽기 전에 왜 Part 3의 비교 구조가 여전히 필요한지 다시 확인할 때 이 절이 기준이 됩니다.
