# Part 4 마무리. 딥러닝 정리

Part 4는 머신러닝의 공통 질문 위에 신경망(neural network)이라는 더 큰 함수 계열이 어떻게 쌓였는지를 실제로 설명하는 구간이었습니다. Part 3가 데이터 분리, 일반화, 평가를 중심으로 모델을 읽는 기준을 세웠다면, Part 4는 그 기준을 유지한 채 `표현(representation)을 더 깊게 학습하는 구조`와 `그 구조를 실제로 학습시키는 절차`를 회수해야 하는 파트였습니다.

이 Part의 핵심은 딥러닝을 단지 `층이 많은 모델`로 외우는 것이 아니라, 입력이 가중치(weight)와 활성화 함수(activation function)를 거쳐 점점 다른 표현으로 바뀌고, 손실(loss)과 역전파(backpropagation)를 통해 그 표현을 조정하는 반복 구조로 읽는 것입니다.

즉, Part 4는 Part 1~3에서 `후속에서 설명한다`고 남겨 둔 퍼셉트론, 표현 학습, 손실 함수, 역전파, optimizer, CNN, Transformer를 실제로 설명해야 하는 첫 본문 파트였습니다.

## 이 Part에서 다룬 핵심 흐름

Part 4의 흐름은 다음처럼 정리할 수 있습니다.

> 퍼셉트론과 다층 신경망
> -> 활성화 함수, 출력층, 손실, 역전파
> -> 학습과 모델 실행의 구분
> -> 옵티마이저, 정규화, 드롭아웃
> -> GPU, 배치, 텐서 계산과 표현 학습
> -> CNN, RNN, LSTM, GRU
> -> Attention과 self-attention
> -> Transformer
> -> 생성 모델과 샘플링
> -> Part 5의 LLM과 생성형 AI

이 흐름을 한 문장으로 줄이면 다음과 같습니다.

`딥러닝은 큰 함수 하나를 외우는 기술이 아니라, 데이터를 점점 더 적절한 표현으로 바꾸고 그 과정의 오차를 다시 뒤로 보내 조정하는 학습 체계다.`

현재 목차 기준으로 보면 이 흐름은 `신경망의 출발점 -> 출력, 손실, 역전파 -> 학습 루프와 안정화 -> 계산 환경과 표현 학습 -> 구조 분기 -> 생성`으로 다시 묶여 읽히는 편이 더 자연스럽습니다.

## 반드시 기억할 개념

Part 4를 지나며 가장 오래 남겨야 할 개념은 다음입니다.

| 구분 | 기억할 관점 |
| --- | --- |
| 퍼셉트론 | 입력과 가중치의 선형 결합 위에 판단 구조를 얹는 가장 작은 출발점입니다. |
| 은닉층 | 중간층은 단순한 계산 단계가 아니라 입력을 다른 표현으로 바꾸는 자리입니다. |
| 활성화 함수 | 비선형성이 없으면 깊게 쌓아도 표현력 증가가 제한됩니다. |
| 출력층과 손실 | 출력 해석과 손실 함수는 문제 유형에 맞게 함께 선택해야 합니다. |
| 역전파 | 역전파는 신경망 전체를 마법처럼 학습시키는 이름이 아니라, 오차 기여도를 효율적으로 전달하는 계산 절차입니다. |
| 옵티마이저 | 손실을 줄이는 방향은 같아도 실제 업데이트 규칙은 다를 수 있습니다. |
| 정규화 | 좋은 학습은 단순히 더 오래 맞추는 일이 아니라, 보지 못한 데이터에서도 무너지지 않게 만드는 일입니다. |
| GPU와 배치 | 딥러닝 확산은 좋은 아이디어만이 아니라 병렬 계산 환경과 함께 일어났습니다. |
| 표현 학습 | 사람이 특징을 쓰는 대신 모델이 특징을 직접 학습한다는 점이 딥러닝 전환의 핵심입니다. |
| CNN / RNN / Attention | 데이터 종류와 의존성 구조에 따라 유리한 모델 설계가 달라졌습니다. |
| Transformer | self-attention과 병렬 처리 구조가 LLM 시대의 기반이 되었습니다. |
| 생성과 샘플링 | 생성형 AI는 출력 자체를 만들며, 실제 결과는 샘플링 전략의 영향을 받습니다. |

## 오해하기 쉬운 지점

Part 4에서 특히 조심해야 할 오해는 다음입니다.

- 딥러닝은 `머신러닝과 완전히 다른 것`이 아니라, 머신러닝의 한 계열을 더 큰 표현 학습 구조로 확장한 것입니다.
- 층이 많아진다고 자동으로 더 좋은 모델이 되는 것은 아닙니다.
- 손실이 내려간다고 바로 실제 품질이 좋아진다고 단정할 수는 없습니다.
- 역전파는 학습 전체의 이름이 아니라 기울기 계산 절차입니다.
- GPU는 단순한 속도 향상 장치가 아니라, 딥러닝 연구 방향 자체에 영향을 준 계산 환경입니다.
- Attention이 생겼다고 RNN 계열이 완전히 무의미해진 것은 아닙니다. 다만 대규모 언어 모델의 주류 구조가 바뀐 것입니다.
- Transformer를 이해했다고 바로 LLM 전체를 이해한 것은 아닙니다. Part 5에서는 토큰(token), 사전학습(pretraining), 정렬(alignment), 도구 연결까지 함께 봐야 합니다.
- 생성 결과가 이상하면 모델이 `모른다`고만 해석하면 부족합니다. 샘플링 방식, 문맥 길이, 입력 구조도 함께 봐야 합니다.
- Part 4가 구조 이름만 소개하고 지나가면 Part 5의 LLM 설명도 다시 표면적인 용어 소개로 약해질 수 있습니다.

## 다음 Part와 연결되는 관점

Part 5에서는 딥러닝 구조 설명을 LLM과 생성형 AI의 실제 사용 경험으로 이어갑니다. Part 4에서 이미 구조적 기반은 마련되었습니다.

이제 질문은 다음처럼 바뀝니다.

> 입력 문장은 실제로 어떤 단위로 잘리는가?
> 임베딩은 그 단위를 어떤 벡터로 바꾸는가?
> 사전학습은 무엇을 대규모로 배우는가?
> GPT, BERT, instruction tuning, RAG, tool use, agent는 어느 지점에서 갈라지는가?

즉, Part 5는 Part 4의 구조를 버리고 새로 시작하는 파트가 아닙니다. 오히려 Part 4에서 본 신경망, attention, Transformer, 생성, 샘플링이 어떻게 실제 LLM 서비스 경험으로 이어지는지를 구체적으로 설명하는 확장 파트입니다.

## Part 4를 마치며

Part 4를 지나면 딥러닝을 더 이상 `가중치가 많은 복잡한 블랙박스`로만 보지 않게 됩니다. 입력이 표현으로 바뀌고, 손실이 계산되고, 오차가 다시 전달되고, 병렬 계산 자원이 이를 떠받치며, attention과 Transformer가 긴 문맥과 생성 문제를 열었다는 큰 흐름이 잡히기 시작합니다.

이 흐름이 잡혀 있어야 Part 5에서 LLM을 단지 유명한 제품 이름이나 API 호출 대상으로 보지 않고, 어떤 입력 단위와 계산 구조 위에서 작동하는지 설명할 수 있습니다.

Part 4의 목적은 바로 그 기반을 만드는 것이었습니다.
