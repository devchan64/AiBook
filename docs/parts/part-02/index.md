# Part 2. 기초 복구

> Section ID: `P2-index`
> Version: `v2026.09.15`

[Part 1](../part-01/summary.md)에서 AI의 주요 분야와 학습·실행의 차이를 살펴봤다면, Part 2에서는 그 설명에 쓰이는 수식과 코드를 직접 읽을 기반을 만듭니다. 수학을 처음 접하거나 배운 내용을 잊었어도 작은 계산부터 시작할 수 있습니다. 수식의 계산 규칙을 Python으로 실행하고, 배열과 표에서 데이터를 확인하며, 그래프와 변경 이력으로 결과를 남기는 흐름을 익힙니다.

예를 들어 공부 시간으로 시험 결과를 예측하려면 입력으로 쓸 값과 정답을 구분하고, 예측이 얼마나 틀렸는지 계산해야 합니다. 이때 수학은 계산 기준을, Python은 실행 절차를, 데이터 도구는 값의 구조와 결과를 보여 줍니다. Part 2의 여러 도구는 이 과정을 함께 확인하는 데 쓰입니다.

## 수식에서 실행과 기록까지

Part 2는 15개 Chapter로 구성됩니다. 처음부터 읽을 때는 수식의 의미를 잡고 작은 계산을 실행한 뒤, 데이터의 모양과 기록 방법으로 이어갑니다.

| 학습 흐름 | 확인할 질문 | 본문 |
| --- | --- | --- |
| 수식 읽기 | 변수와 함수, 합과 평균, 로그는 어떤 계산을 나타내는가? | [수학과 AI 계산](chapter-01/section-01.md), [변수·함수·식](chapter-02/section-01.md) |
| 여러 값의 계산 | 벡터·행렬은 데이터를 어떻게 묶고 비교하는가? | [스칼라·벡터·행렬](chapter-03/section-01.md), [내적·거리](chapter-03/section-04.md) |
| 변화와 불확실성 | 값을 바꾸면 결과가 어떻게 달라지며, 데이터의 퍼짐은 어떻게 읽는가? | [미분·그래디언트](chapter-04/section-03.md), [확률](chapter-05/section-01.md), [최적화](chapter-06/section-01.md) |
| Python 실행 | 코드는 어디에서 실행되며, 값·반복·함수는 어떤 역할을 하는가? | [실행 환경](chapter-07/section-01.md), [Python 기초](chapter-08/section-01.md) |

| 배열·표·그래프 | 값의 모양을 확인하고 필요한 데이터를 골라 시각화할 수 있는가? | [NumPy](chapter-11/section-01.md), [Pandas](chapter-12/section-01.md), [Matplotlib](chapter-13/section-01.md) |
| 변경 이력과 종합 점검 | 어떤 조건에서 계산했고 무엇을 바꿨는지 다시 확인할 수 있는가? | [Git](chapter-14/section-01.md), [수식을 코드로 옮기기](chapter-15/section-01.md) |

수학에서는 선형대수·미분·확률·통계·최적화의 입문 개념과 작은 계산을 다룹니다. Python에서는 실행 환경과 기본 문법을 익히고, NumPy는 배열 계산, Pandas는 표의 선택과 정리, Matplotlib은 시각화, Git은 변경 이력 관리에 사용합니다. 고급 수학 증명이나 각 도구의 전체 기능보다 이후 모델 학습 예제를 읽고 실행하는 데 필요한 내용을 중심으로 연결합니다.

## 모델 학습을 읽을 준비

이 Part를 마치면 수식의 입력·계산·출력을 작은 코드와 연결하고, 배열과 표의 행·열이 무엇을 뜻하는지 설명할 수 있어야 합니다. 평균 하나와 분포 전체가 알려 주는 차이, 손실의 크기와 그 손실을 줄이는 방향의 차이도 구분합니다. 실행 결과에는 코드뿐 아니라 데이터와 실행 환경, 변경 조건을 함께 남깁니다.

[Part 3](../part-03/index.md)에서는 이 기반 위에서 데이터로 규칙을 배우는 모델을 다룹니다. 모델을 어떻게 학습시키고, 학습에 쓰지 않은 데이터에서 무엇으로 성능을 판단할지가 다음 질문입니다. 이동 전에는 [종합 점검](chapter-15/section-02.md)과 [Part 2 마무리](summary.md)의 작은 계산으로 준비 상태를 확인할 수 있습니다.
