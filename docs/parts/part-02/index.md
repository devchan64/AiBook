# Part 2. 기초 복구

> Section ID: `P2-index`
> Version: `v2026.07.12`

Part 2는 머신러닝과 딥러닝을 다시 공부하기 전에 수학, Python, 데이터 도구, 문서 관리 감각을 회복하는 구간입니다. 여기서는 수학을 깊게 증명하거나 Python 문법을 모두 외우지 않습니다. 대신 이후 Part 3에서 모델 학습, 데이터 분리, 평가, 과적합, 일반화를 읽고 작은 코드로 확인할 수 있는 기반을 만듭니다.

Part 2도 같은 Part 안에서는 주요 개념의 상세 설명을 가능한 한 한 Section에 먼저 둡니다. 이후 절에서는 현재 맥락에 필요한 최소 연결만 남깁니다. 수식 읽기, 벡터와 행렬, 미분, 확률, 최적화, 배열과 표 데이터처럼 반복해서 다시 만나는 개념은 먼저 대표 Section를 읽고, 다시 등장할 때는 [개념사전](../../reference/concept-glossary.md)과 함께 확인합니다.

여기서 핵심 목적은 “AI 문서와 예제 코드에서 반복해서 등장하는 계산 언어를 다시 읽을 수 있게 되는 것”입니다. 수식, 배열, 표, 그래프, 실행 환경, Git 이력은 서로 따로 떨어진 주제가 아닙니다. 모델 계산을 읽고, 데이터셋을 확인하고, 결과를 시각화하고, 학습 기록을 남기기 위해 함께 쓰이는 도구들입니다.

`이 수식은 무엇을 계산하는가`, `이 코드는 어떤 값을 넣어 어떤 결과를 확인하는가`, `이 도구는 왜 지금 필요한가`를 계속 확인하며 읽습니다. 수학, Python, NumPy, Pandas, Git은 Part 3의 머신러닝 본문을 읽기 위한 같은 준비물로 연결됩니다.

그래서 Part 2는 기초를 다시 연결합니다.

1. 수식 표기를 다시 읽습니다.
2. 선형대수, 미분, 확률, 통계, 최적화의 직관을 복구합니다.
3. Python 실행 환경과 문법을 복습합니다.
4. NumPy, Pandas, Matplotlib으로 작은 계산을 확인합니다.
5. Git으로 문서와 코드 변경 이력을 관리합니다.
6. Part 3 머신러닝으로 넘어가기 전 점검 기준을 세웁니다.

## 이 파트의 목표

Part 2를 읽고 나면 다음 정도의 이해를 갖는 것이 목표입니다.

- 변수(variable), 함수(function), 식(expression), 시그마(sigma), 극한(limit)을 AI 문서 독해용으로 다시 읽을 수 있습니다.
- 로그(log), 지수(exp), 로그 손실(log loss) 같은 표현이 왜 반복해서 등장하는지 설명할 수 있습니다.
- 스칼라(scalar), 벡터(vector), 행렬(matrix), 벡터 공간(vector space), 행렬 곱(matrix multiplication)을 데이터와 모델 계산 관점으로 설명할 수 있습니다.

- Pandas DataFrame을 행(row), 열(column), 인덱스(index)로 읽고, 데이터셋 준비의 직관을 가질 수 있습니다.
- Matplotlib으로 수식, 분포, 관계, 손실 곡선을 시각적으로 확인할 수 있습니다.
- Git 커밋과 브랜치를 학습 문서의 재현성 관리 도구로 이해할 수 있습니다.

## 무엇을 설명하는가

Part 2는 15개 Chapter로 구성됩니다.

먼저 수학을 계산 언어로 다시 읽습니다. 변수, 함수, 식, 시그마, 극한을 복구하고, 로그와 지수도 뒤 Part의 확률 점수 언어로 다시 붙잡습니다. 수식을 코드와 데이터에서 다시 확인하는 관점을 잡습니다.

그다음 모델 계산을 읽기 위한 핵심 수학을 다룹니다. 선형대수에서는 스칼라, 벡터, 행렬, 벡터 공간, 행렬 곱을 보고, 이어서 내적, 길이, 거리, 유사도처럼 `벡터를 어떻게 비교할 것인가`도 붙잡습니다. 미분에서는 변화율, 기울기, 그래디언트, 학습에서 미분이 필요한 이유를 보고, 합성함수와 연쇄 법칙을 통해 역전파 앞단의 최소 연결도 보강합니다. 확률과 통계에서는 불확실성을 숫자로 표현하고, 데이터 묶음의 모양을 평균, 분산, 분포, 표본, 오차로 읽는 법을 정리합니다. 이때 확률 해석은 빈도주의와 베이지안을 전면 비교하는 대신, `장기 빈도(long-run frequency)`와 `믿음의 정도(degree of belief)`를 최소 구분으로만 복구하고, 베이즈 규칙(Bayes' rule)은 믿음 갱신의 직관까지만 맡깁니다. 최적화에서는 좋은 답을 직접 쓰는 것이 아니라 더 나은 값을 찾는 문제로 접근합니다.

중간에서는 실행 환경과 Python 기초를 다룹니다. Colab과 로컬 PC, 터미널과 셸, Python 인터프리터와 스크립트, 가상환경과 패키지, 의존성과 재현성을 구분합니다. 이어서 Python의 값, 변수, 타입, 리스트, 딕셔너리, 반복, 함수, 클래스의 기본 감각을 복구합니다.

후반부에서는 자료구조와 데이터 도구를 다룹니다. 배열, 표, 트리, 그래프의 직관을 잡고, Jupyter와 Colab 노트북으로 코드와 설명을 함께 남기는 방법을 봅니다. NumPy로 벡터와 행렬을 계산하고, Pandas로 표 형식 데이터를 다루며, Matplotlib으로 숫자의 모양을 확인합니다.

마지막으로 Git과 문서 관리를 다룹니다. 문서, 예제 코드, 이미지, 실험 기록이 함께 바뀌는 프로젝트에서는 변경 이력과 재현성이 중요합니다. Part 2의 끝에서는 수식을 코드로 옮기는 작은 절차를 정리하고, Part 3로 넘어가기 전에 필요한 감각을 점검합니다.

## 왜 필요한가

머신러닝을 공부할 때 많은 설명은 다음 형태로 나타납니다.

1. 입력 데이터 \(X\)가 있고, 라벨 \(y\)가 있습니다.
2. 모델은 예측값 \(\hat{y}\)를 만듭니다.
3. 손실 함수는 예측과 실제값의 차이를 숫자로 만듭니다.
4. 학습은 그 손실을 줄이는 방향으로 파라미터를 조정합니다.
5. 평가는 보지 못한 데이터에서 결과를 확인합니다.

이 설명을 읽으려면 여러 기반이 동시에 필요합니다. \(X\)와 \(y\)를 배열과 표로 볼 수 있어야 하고, 손실을 평균과 합산으로 읽을 수 있어야 하며, 그래프를 보고 학습 흐름을 점검할 수 있어야 합니다. 또한 예제 코드가 어느 환경에서 실행되는지, 결과 이미지와 원고가 어떤 커밋에서 함께 바뀌었는지도 추적할 수 있어야 합니다.

Part 2는 이 기반을 과도하게 깊게 파지 않습니다. 대신 Part 3에서 모델과 데이터 흐름을 읽다가 막히지 않도록 최소한의 언어와 실습 감각을 마련합니다.
