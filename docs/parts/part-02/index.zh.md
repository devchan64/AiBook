# Part 2. 基础恢复

> Section ID: `P2-index`
> Version: `v2026.09.15`

[Part 1](../part-01/summary.zh.md)介绍了 AI 的主要领域以及学习与执行的区别，Part 2 则为直接阅读这些说明中使用的公式和代码打下基础。无论是初次接触数学，还是已经忘记学过的内容，都可以从小规模计算开始。我们将用 Python 执行公式中的计算规则，在数组和表格中检查数据，并通过图表和变更历史记录结果。

例如，要根据学习时间预测考试结果，就需要区分输入值与正确答案，并计算预测错了多少。数学提供计算标准，Python 提供执行步骤，数据工具则呈现数值的结构与结果。Part 2 的各种工具将共同帮助我们检查这一过程。

## 为理解模型训练做好准备

完成本 Part 后，应能将公式的输入、计算和输出与小段代码联系起来，并解释数组和表格的行列含义。还应能区分单个平均值与完整分布所提供的信息，以及损失大小与减小损失方向之间的区别。记录执行结果时，除了代码，也要保留数据、运行环境和发生变化的条件。

[Part 3](../part-03/index.zh.md)将在此基础上介绍从数据中学习规则的模型。接下来的问题是如何训练模型，以及用什么标准在未参与训练的数据上判断性能。继续之前，可以通过[综合检查](chapter-15/section-02.zh.md)和 [Part 2 总结](summary.zh.md)中的小规模计算确认准备情况。

## 检查清单

- 能否根据公式中的符号识别输入以及需要执行的计算？

- 能否运行小规模 Python 计算，并用数组、表格和图表检查结果？
