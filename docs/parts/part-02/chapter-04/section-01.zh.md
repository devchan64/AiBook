# P2-4.1 回顾我们怎样学习微分

> Section ID: `P2-4.1`
> Version: `v2026.09.14`

每个人对学习微分的记忆可能不同。你可能先想起给曲线画切线的图，位置求导得到速度的说明，或者 `x²` 求导得到 `2x` 的公式。这些分别用图形、物理现象和符号表达同一种计算。如果你第一次接触微分，也可以把这三个场景联系起来理解其含义。

三个场景提出的是同一个问题：**输入改变时，输出变化得有多快？** 在图中，输入和输出是横坐标与纵坐标；在运动中，它们是时间与位置。微分求的是某个输入值附近的瞬时变化率。输出值本身与输出变化的快慢是不同的信息。

## 从速度认识微分

考虑一个沿直线运动的物体。以参考点向右为正方向，时间 `t` 用秒表示，位置 `s` 用米表示。假设位置遵循以下规律。`s(t)` 表示时刻 `t` 的位置，下面的式子描述分别以秒和米表示的时间数值与位置数值之间的关系。

\[
s(t)=t^2
\]

| 时刻 | 位置 |
| --- | --- |
| 1秒 | 1m |
| 2秒 | 4m |
| 3秒 | 9m |

从1秒到2秒，位置在1秒内改变了 `4−1=3m`，所以平均速度为 `3m/s`。从2秒到3秒，位置改变了 `9−4=5m`，平均速度为 `5m/s`。同样是1秒的时间段，后一段移动得更多。这个物体的速度并不恒定。

那么，恰好在2秒时，速度是多少？`4m` 是该时刻的位置，并不是速度的答案。前一段的平均值 `3m/s` 和后一段的平均值 `5m/s` 也各自只是对一个时间段的概括。

## 用短时间段观察一个瞬间

以2秒为基准缩小观察区间。平均速度按 `位置变化量 ÷ 时间变化量` 计算。

| 观察区间 | 时间变化量 | 位置变化量 | 平均速度 |
| --- | --- | --- | --- |
| 2秒 → 3秒 | 1秒 | `9−4=5m` | `5m/s` |
| 2秒 → 2.1秒 | 0.1秒 | `4.41−4=0.41m` | `4.1m/s` |
| 2秒 → 2.01秒 | 0.01秒 | `4.0401−4=0.0401m` | `4.01m/s` |
| 1.9秒 → 2秒 | 0.1秒 | `4−3.61=0.39m` | `3.9m/s` |
| 1.99秒 → 2秒 | 0.01秒 | `4−3.9601=0.0399m` | `3.99m/s` |

从2秒之后缩短区间，平均速度以 `4.1`、`4.01` 等数值接近4。从2秒之前看，也以 `3.9`、`3.99` 接近同一个值。说瞬时速度是 `4m/s`，并不是把时间间隔设为0再去做除法，而是**保持间隔非零，不断缩小它，观察平均速度趋近哪个值**。

这样趋近的值称为极限。表中的几个数并不能证明极限存在，但对于 `s(t)=t²`，继续这一过程时，平均速度会趋近4。这就是2秒时的瞬时速度。足够短的时间段内的平均速度是瞬时速度的近似值，而瞬时速度是区间不断缩小时的极限。

## 从切线认识微分

把同一个运动画成图，横轴为时间，纵轴为位置。例如，`(2, 4)` 表示2秒时的位置为4米。连接图上两点的直线称为**割线**，其斜率是纵向变化量除以横向变化量。因此，在位置—时间图上，割线斜率就是该区间的平均速度。

固定 `(2, 4)`，让另一个点沿曲线靠近它，割线的斜率也会改变。上表中的 `5`、`4.1`、`4.01` 同时也是这些割线的斜率。如果斜率趋近一个有限值，这个值就是该点的**切线斜率**。在这张图上，2秒时的切线斜率为 `4m/s`，与瞬时速度相同。

如果只把切线记成“与曲线只相交一次的直线”，遇到其他曲线时可能会混淆。切线也可能在别处再次与曲线相交。关键在于它的斜率表达了曲线在某一点附近的变化方向。

## 从公式认识微分

你可能记得 `x²` 求导得到 `2x` 的公式。对于位置为 `s(t)=t²` 的运动，这个公式写成 `s′(t)=2t`。撇号 `′` 表示求导后得到的函数。

\[
s'(t)=2t,\qquad s'(2)=4
\]

`s′(2)=4` 表示2秒时的瞬时速度为 `4m/s`，与前面缩小区间得到的值相同。`s′(t)=2t` 不仅给出2秒时的瞬时速度，也给出其他时刻的瞬时速度：1秒时为 `2m/s`，3秒时为 `6m/s`。

| 表达式 | 在这个运动中的含义 |
| --- | --- |
| 函数 `s(t)=t²` | 输入时刻，得到位置 |
| 某点的导数值 `s′(2)=4` | 特定时刻2秒处的瞬时变化率 |
| 导函数 `s′(t)=2t` | 给出每个时刻的瞬时变化率的函数 |

某点的导数值是对应一个输入值的**数**，导函数则是为各个输入值给出这个数的**函数**。公式让我们不必每次重复缩小区间的计算，就能求出变化率。不过，还需要理解：把时刻代入这个导函数，得到的是速度，而不是位置。

## 对位置求两次导数

这个运动的速度为 `v(t)=2t`。从1秒到2秒，速度从 `2m/s` 变为 `4m/s`；从2秒到3秒，速度从 `4m/s` 变为 `6m/s`。速度每秒增加 `2m/s`。

速度的变化率称为加速度，这里是 `2m/s²`。本例中速度随时间以恒定的变化率增加，所以任何区间的平均加速度都相同，瞬时加速度也相同。位置对时间求导得到速度，速度再对时间求导得到加速度。

| 物理量 | 提出的问题 | 单位 |
| --- | --- | --- |
| 位置 | 相对参考点，在哪个方向、相距多远 | `m` |
| 速度 | 位置随时间变化得有多快 | `m/s` |
| 加速度 | 速度随时间变化得有多快 | `m/s²` |

这里物体向右运动，但如果向左运动、位置减小，速度就可能为负。速率不考虑方向，只表示运动的快慢；在直线运动中，它是速度的绝对值。需要区分位置的导数所表示的速度与总路程变化率所表示的速率。

## 累积与变化率的联系

通过堆叠截面求体积，是从累积的角度思考。一个截面积恒为 `2m²` 的柱体，增加 `0.1m` 的高度，体积就增加 `2×0.1=0.2m³`。增加 `0.01m` 的高度，体积则增加 `0.02m³`。

无论哪种情况，`体积增加量 ÷ 高度增加量` 都是 `2m²`。从堆叠的角度，求的是随高度累积的体积；从变化率的角度，求的是单位高度的体积增加量，也就是截面积。微分并不只用于以时间为输入的情况。在本例中，输入是高度，输出是体积。

## 订单记录能告诉我们什么

假设每天100笔订单时，平均配送时间为24小时；每天110笔订单时，平均配送时间为26小时。两条记录之间的平均变化率为 `(26−24)/(110−100)=0.2小时/笔`，即 `12分钟/笔`。

这表示在该区间内，订单量增加所对应的平均配送时间变化，并不意味着每增加一笔订单就一定多花12分钟。订单量以整数记录，仅凭这两个观测值，也无法无限缩小间隔。要讨论某一点的导数，需要增加假设，例如用连续函数近似订单量与配送时间的关系。如果地区或人员配置也变了，就不能把配送延迟的原因仅归于订单量。

即使知道切线和导函数的公式，也需要另行判断观测资料能说明哪一种变化率。这些记录直接支持的计算，是两个观测值之间的平均变化率。

## 练习：区分位置与速度

对于同一个运动 `s(t)=t²`，分别求出3秒时的位置、2秒到3秒的平均速度，以及3秒时的瞬时速度，并写出单位。再说明这三个数是否表示同一种量。

??? note "计算与解析"
    位置为 `s(3)=9m`，平均速度为 `(9−4)/(3−2)=5m/s`，瞬时速度为 `s′(3)=2×3=6m/s`。位置是某时刻的坐标，平均速度是整个区间的位置变化率，瞬时速度则是该时刻的位置变化率。由于物体越来越快，区间末端的瞬时速度大于该区间的平均速度。
