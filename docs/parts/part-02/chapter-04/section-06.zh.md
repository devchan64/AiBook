# P2-4.6 复合函数与链式法则

> Section ID: `P2-4.6`
> Version: `v2026.09.08`

复合函数(composite function)把一个函数的输出作为下一个函数的输入。当各阶段都可微时，链式法则(chain rule)通过将各阶段的变化率相乘，求出整体变化率。

## 两阶段计算与复合函数

\[
y = 2x + 1,\qquad z = y^2
\]

先由 `x` 计算中间值 `y`，再将 `y` 平方得到 `z`。合成一个式子就是 `z = (2x + 1)²`。

| 阶段 | 公式 | x = 1 时 |
| --- | --- | --- |
| 第一次计算 | `y = 2x + 1` | y = 3 |
| 下一次计算 | `z = y²` | z = 9 |
| 整体计算 | `z = (2x + 1)²` | z = 9 |

一般而言，`z = f(g(x))` 表示先计算 `g(x)`，再把结果输入 `f`。神经网络中，一层的输出也会成为下一层的输入。

## 各阶段变化率的乘积

将链式法则应用于上述计算，得到：

\[
\frac{dz}{dx} = \frac{dz}{dy}\cdot\frac{dy}{dx}
\]

第一阶段 `y = 2x + 1` 的变化率为 `dy/dx = 2`。下一阶段 `z = y²` 的变化率为 `dz/dy = 2y`。整体变化率因此为 `2y × 2 = 4y`，代入 `y = 2x + 1`，得到 `8x + 4`。

`x = 1` 时，`y = 3`，因此得到以下数值。

| 变化区间 | 该点的变化率 |
| --- | --- |
| x → y | 2 |
| y → z | 6 |
| x → z | 6 × 2 = 12 |

当 `x` 发生很小的变化时，变化在第一阶段约放大两倍，在下一阶段约放大六倍，因此最终变化量约为输入变化量的十二倍。

## 用小幅输入变化验证

把 `x` 从 `1` 改为 `1.01`，中间值 `y` 从 `3` 变为 `3.02`，最终值 `z` 从 `9` 变为 `9.1204`。

- 用链式法则近似的变化量：`12 × 0.01 = 0.12`
- 实际变化量：`9.1204 − 9 = 0.1204`

导数描述一个点的瞬时变化率，因此近似值可能与有限区间内的变化量略有差异。把输入增量减小到 `0.001`，实际变化量为 `0.012004`，用导数得到的近似值为 `0.012`。

## 反向传播中的变化率计算

反向传播(backpropagation)从后往前计算各层参数变化对最终损失(loss)的影响。它用链式法则结合后面阶段与前面阶段的变化率。

若把上例中的 `z` 视为最终损失，先求后面阶段的变化率 `dz/dy = 6`，再乘以前面阶段的 `dy/dx = 2`，得到 `dz/dx = 12`。计算数值时按 `x → y → z` 的顺序，而计算相对于最终值的变化率时，则从后面阶段向前连接。

链式法则是复合函数的求导规则，反向传播则利用此规则高效计算多个参数的梯度。实际改变参数的工作，由使用这些梯度的优化方法完成。

## 检查清单

- 能把复合函数解释为一个函数的输出成为下一个函数输入的结构。
- 在 `y = 2x + 1`、`z = y²` 中，能算出 `x = 1` 时整体变化率为 12。
- 能区分用瞬时变化率近似的变化量与有限区间的实际变化量。
- 能区分链式法则与反向传播的作用。
- 能说明反向传播计算参数变化对损失的影响。
