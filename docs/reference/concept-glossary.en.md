# Concept Glossary

The project currently keeps one shared concept glossary as the source of truth across language editions.

Glossary headwords are intentionally written in Korean and English together because a single Korean term can map to different English concepts depending on context. The glossary is also used to observe ambiguity, polysemy, and incorrect section references through its `Core Section` and `Appears In` lists.

Use the shared glossary here:

- [Shared Concept Glossary](concept-glossary.md)

When the English Part 1 pages refer to glossary terms, treat that shared glossary and its common `Section ID` references as the canonical anchor.
