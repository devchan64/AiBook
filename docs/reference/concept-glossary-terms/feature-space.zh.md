## 特征空间(feature space)

- 含义: 数据按照 feature 值被放置的计算空间。每个轴可以表示一个 feature 或 feature combination，classification boundary 和 distance calculation 都在这个空间里解释。
- 为什么重要: 同一批数据，在不同 feature space 中可能会让 linear boundary 看起来容易，也可能显得别扭。要理解 kernel，就要区分 `数据变了` 和 `读取数据的空间变了`。
- 相关概念: `表示(representation)`, `核函数(kernel)`, `特征(feature)`, `决策边界(decision boundary)`
