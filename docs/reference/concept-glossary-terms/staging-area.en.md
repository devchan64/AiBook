## staging area

- Meaning: A staging area is an intermediate space where changes are selected before they become part of a commit. It is not every change in the working files; it is the chosen set for the next recorded change unit.
- Why it matters: The staging area lets a writer choose a meaningful bundle of changes instead of recording every modified file automatically. It makes version history a selected explanation unit rather than a raw save operation.
- Related concepts: `commit`, `version control`, `repository`
