## comparison plot

- Meaning: A comparison plot places two or more values, trends, or conditions side by side or on the same axis so their differences can be read visually.
- Why it matters: Many learning results make sense only when compared, such as loss and accuracy or training loss and validation loss. Comparison plots help readers decide which values can share an axis and which should be separated.
- Related concepts: `visualization`, `loss curve`, `accuracy`
