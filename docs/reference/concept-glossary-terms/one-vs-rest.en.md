### one-vs-rest

- Meaning: One-vs-rest handles multiclass classification by turning each class into a separate binary question: `is this class or not?`
- Why it matters: It gives a different comparison structure from multinomial logistic regression. The distinction helps readers separate `checking each class separately and comparing later` from `comparing all classes together at once`.
- Related concepts: `multinomial logistic regression`, `softmax`, `classification`
- Core Section: `P4-11.4`
