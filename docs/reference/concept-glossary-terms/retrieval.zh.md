### RAG 检索(retrieval)

- 含义：RAG 检索是在 RAG 流程中，把可能与用户问题相关的外部文档或文档片段找回来的阶段。它比一般的搜索、探索算法或人在网页上找资料更窄，重点是为生成输入准备证据候选。
- 为什么重要：`检索`可能指状态空间搜索、文档搜索、网页搜索，也可能指 RAG 中的 retrieval。在 RAG 中，retrieval 不是直接生成答案，而是选择生成模型可以参考的外部材料。这个区分能说明检索结果不是答案本身，而是额外输入上下文的材料。
- 相关概念：`检索增强生成(RAG)`, `信息检索(information retrieval)`, `生成(generation)`
