## 决策树

- 含义: 决策树通过连续提问条件并沿分支到达叶节点来做预测。
- 为什么重要: 决策树直观，但过深时容易记住训练数据偶然模式，体现可解释性与过拟合风险的权衡。
- 相关概念: `树`, `过拟合`, `划分`

- 出现 Section: `P4-14.2`
