## 训练模式

- 含义: 训练模式是模型在学习过程中使用的执行状态。在这个状态下，dropout、batch normalization 等层会按训练时的规则工作，参数更新所需的计算也会被保留。
- 为什么重要: 同一个模型在训练时和评估/执行时可能有不同的行为。如果不区分训练模式与评估模式，就容易把学习阶段的随机性或 batch 统计误读成部署时的输出规则。
- 相关概念: `评估模式`, `dropout`, `batch normalization`
