## 策略(policy)

- 含义: 策略是在当前 state 或 observation 下决定选择哪个 action 的标准或函数。它不是只给一次答案的规则，而是随着情况变化反复选择行动的方式。
- 为什么重要: 强化学习不是一次性猜答案，而是在不同状态下持续选择行动并改进这种选择方式的问题。理解 policy，才能区分 `这一次答对了吗` 和 `多步过程中是否持续做出较好的选择`。
- 相关概念: `reinforcement learning`, `state`, `action`
