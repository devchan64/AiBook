## XGBoost

- 含义：XGBoost 是梯度提升家族中的树提升系统。 它强调正则化、稀疏数据处理、近似树学习、cache-aware 结构、数据压缩和分布式扩展。
- 为什么重要：XGBoost 能帮助读者把 boosting 不只读成一个模型名字，而是读成能在更大规模上稳定运行的实现系统。 它说明在选择梯度提升实现时，扩展性、稀疏输入和计算结构也会成为判断标准。
- 相关概念：`梯度提升(gradient boosting)`，`稀疏性(sparsity)`，`分布式训练(distributed training)`
