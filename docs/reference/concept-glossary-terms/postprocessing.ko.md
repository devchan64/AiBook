### 모델 후처리(model postprocessing)

- 뜻: 모델이 만든 출력이나 모델 점수를 사람이 쓰는 결과, 서비스 결정, 표시 형식으로 바꾸는 모델 바깥 단계입니다. 일반적인 작업 후처리가 아니라, 라벨 선택, 임계값 적용, 라우팅, 문구 정리, 정책 확인처럼 모델 출력 뒤에 붙는 변환·결정 단계입니다.
- 왜 중요한가: 모델 inference 결과와 서비스 전체 처리는 같지 않기 때문입니다. 이 개념이 있어야 모델이 계산한 점수나 문장이 곧바로 최종 업무 결정이라고 단정하지 않고, 그 뒤에 붙는 규칙과 운영 절차를 따로 점검하게 됩니다.
- 함께 볼 개념: `추론(inference)`, `모델 점수(model score)`, `AI 앱(application)`
- 중심 Section: `P1-5.2`
