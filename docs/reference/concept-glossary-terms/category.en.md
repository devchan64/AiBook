## category

- Meaning: A category is a group name used to place multiple cases under the same class or type.
- Why it matters: Categories connect data values to classification, labels, grouping, and categorical features. This concept helps readers distinguish a named group from a numeric measurement or an individual identifier.
- Related concepts: `classification`, `label`, `categorical feature`
