### 输入窗口(input window)

- 含义：输入窗口是从源时间序列或连续记录中切出，并作为一条学习输入来处理的时间区间。它同时包含起点、终点、长度标准和对齐标准，因此比单纯把数组长度调成一样更宽。
- 为什么重要：输入窗口一变，模型能看到的信号、被切掉的区间、可比较的样本范围都会变化。这个概念帮助读者区分直接把原始记录放进去，和根据当前问题定义一条输入边界。无论后面做成汇总特征，还是保留顺序的输入，都必须先说明窗口规则，解释和可复现性才不会摇晃。
- 相关概念：`输入(input)`, `输入单元(input unit)`, `样本(sample)`, `汇总表(summary table)`, `特征(feature)`, `源数据(source data)`
