## 离线强化学习(offline reinforcement learning)

- 含义: offline reinforcement learning 是一种强化学习分支，尽量不做大量新的 exploration，而是主要从已经收集好的数据中学习 policy。
- 为什么重要: 当直接尝试很贵或很危险时，首先要问的是已有数据里能先评估和改进什么。
- 相关概念: `safe reinforcement learning`, `exploration cost`, `policy`
