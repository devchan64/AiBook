### 교차검증(cross-validation)

- 뜻: 주어진 데이터를 여러 번 나누어, 서로 다른 검증 구간에서 모델이나 설정을 반복해서 평가하는 방법입니다. 보통 데이터가 작거나 한 번의 분리 결과가 우연에 크게 흔들릴 때 검증 결과를 더 안정적으로 읽기 위해 사용합니다.
- 왜 중요한가: 한 번의 검증 점수만 보고 모델을 고르면 특정 분리의 우연에 끌릴 수 있습니다. 교차검증은 여러 분리에서 비교를 반복하게 해 후보 선택을 더 신중하게 만들지만, 최종 테스트 데이터를 완전히 대체하는 마법은 아닙니다.
- 함께 볼 개념: `검증 데이터(validation data)`, `테스트 데이터(test data)`, `모델 선택(model selection)`, `일반화(generalization)`
