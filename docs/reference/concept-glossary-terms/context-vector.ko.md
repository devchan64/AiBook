### 문맥 벡터(context vector)

- 뜻: attention에서 현재 출력 위치가 참고해야 할 입력 정보들을 가중합해 만든 요약 표현입니다. 모든 입력을 똑같이 압축한 하나의 고정 벡터가 아니라, 현재 단계에서 더 중요한 입력 위치에 더 큰 비중을 두어 만든 문맥 표현이라고 볼 수 있습니다.
- 왜 중요한가: attention이 고정 길이 벡터 병목을 어떻게 완화했는지 이해하게 해 주는 핵심 중간 표현이기 때문입니다. 이 개념이 있어야 `문맥`이라는 일반 표현이 단순 주변 문장이 아니라, 현재 예측을 위해 입력 표현들을 가중치로 섞은 계산 결과일 수 있다는 점을 구분할 수 있습니다. 또한 문맥 벡터를 이해해야 어텐션 가중치가 단지 설명용 점수가 아니라 실제 표현을 만드는 데 쓰인다는 점도 분명해집니다.
- 함께 볼 개념: `어텐션(Attention)`, `어텐션 가중치(attention weight)`, `고정 길이 벡터(fixed-length vector)`, `인코더-디코더(Encoder-Decoder)`
