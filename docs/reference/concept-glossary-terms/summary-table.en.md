### summary table

- Meaning: A summary table keeps only the key columns needed to scan several values and observations in one place. It is not a replay of the whole source table, but a reading table that gathers the aggregates, comparison values, and notes needed for the current question.
- Why it matters: As a source table grows, it becomes easier to lose where the difference appeared and which unit is being compared. A summary table helps separate raw records, aggregate results, comparison tables, and interpretation tables, so readers do not confuse `there are many numbers` with `the numbers have been organized to answer this question`.
- Related concepts: `aggregation`, `comparison table`, `result interpretation table`, `sample`, `indicator`
