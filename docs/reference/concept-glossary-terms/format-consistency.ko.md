### 형식 정합성(format consistency)

- 뜻: 같은 의미의 값이 같은 형식, 단위, 표기 규칙으로 적혀 있어 뒤의 비교와 정렬이 흔들리지 않는 상태입니다.
- 왜 중요한가: 키 형식, 시간 형식, 단위, 문자열 규칙이 섞이면 같은 대상을 다른 대상으로 읽거나 시간 순서를 잘못 읽을 수 있습니다. 형식 정합성을 먼저 확인해야 데이터 품질 문제와 문제 표현 설계 문제를 구분할 수 있습니다.
- 함께 볼 개념: `데이터 품질 점검(data quality check)`, `식별자(identifier)`, `행(row)`
- 중심 Section: `P3-2.3`
