### 기대 출력(expected output)

- 뜻: 어떤 입력에 대해 모델이 내야 한다고 기대하는 정답 또는 목표 출력입니다. 지도학습에서는 보통 라벨이나 타깃 값으로 주어지며, 생성형 AI의 바람직한 답변이라는 일반적 기대와는 구분해서 사용합니다.
- 왜 중요한가: 기대 출력이 분명해야 학습 문제가 `무엇을 맞히는 문제인가`로 닫히기 때문입니다. 이 개념이 있어야 출력 형식, 라벨 정의, 평가 기준이 서로 연결되어 있다는 점을 이해할 수 있습니다.
- 함께 볼 개념: `출력(output)`, `라벨(label)`, `타깃(target)`
