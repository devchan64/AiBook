### 최적(optimal)

- 뜻: 정해진 후보 범위, 기준, 제약 안에서 가장 좋다고 판단된 상태입니다. 현실의 모든 조건에서 완벽하다는 뜻이 아니라, 현재 문제 설정 안에서의 더 나은 해석입니다.
- 왜 중요한가: `최적`이라는 말이 절대적 완벽함처럼 읽히면 모델 평가와 최적화 결과를 과하게 믿게 되기 때문입니다. 이 개념이 있어야 어떤 기준에서, 어떤 제약 아래서, 어떤 후보들 사이에서 최적이라고 했는지 다시 묻게 됩니다.
- 함께 볼 개념: `최적화(optimization)`, `비교 기준(criterion)`, `제약(constraint)`
