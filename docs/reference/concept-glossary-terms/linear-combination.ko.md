### 선형 결합(linear combination)

- 뜻: 여러 벡터에 스칼라 값을 곱한 뒤 더해 새 벡터를 만드는 계산입니다. 예를 들어 \(2\mathbf{a}+3\mathbf{b}\)는 \(\mathbf{a}\)를 2배, \(\mathbf{b}\)를 3배 한 뒤 더한다는 뜻입니다. 즉 선형 결합은 스칼라배와 벡터 덧셈을 묶어 새 표현을 만드는 방식입니다.
- 왜 중요한가: 행렬 곱과 신경망 계산의 바탕에 같은 구조가 반복되기 때문입니다. 입력값과 가중치를 곱해 더해 새 값을 만들고, 이런 계산을 여러 번 반복하면 행렬 곱과 선형 변환으로 이어집니다. 이 개념이 있어야 `곱하고 더한다`는 작은 계산이 어떻게 새 표현을 만드는 기본 블록이 되는지 볼 수 있습니다.
- 함께 볼 개념: `벡터 덧셈(vector addition)`, `스칼라배(scalar multiplication)`, `가중합(weighted sum)`
- 중심 Section: `P2-3.2`
