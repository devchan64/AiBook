### 模型输入定义(model input)

- 含义：模型输入定义说明模型在一次计算中实际接收哪些信息。它不是整个外部世界或全部原始数据，而是被带入当前运行的值。
- 为什么重要：模型只能使用实际给它的证据。模型输入设计决定模型能看到哪些线索、看不到哪些线索，以及预处理或特征设计如何影响性能。
- 相关概念：`模型输出(model output)`，`数据(data)`，`模型(model)`，`特征(feature)`，`任务定义(task definition)`

- 出现 Section：`P1-4.1`, `P4-index`, `P3-5.3`, `P3-5.4`, `P4-4.1`
