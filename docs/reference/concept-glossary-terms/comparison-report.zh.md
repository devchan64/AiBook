## 比较报告

- 含义: 比较报告是整理近期状态与基准线差异的输出结构，让人决定先检查什么。
- 为什么重要: 当数据或标签还不足以直接做预测任务时，比较报告很有用。它把“让模型直接决定”和“让人先读差异”区分开。
- 相关概念: `基准线`, `审查`, `目标`, `输出结构`
- 核心 Section: `P3-9.2`
- 出现 Section: `P3-index`, `P3-1.1`, `P3-3.2`, `P3-8.2`, `P3-9.1`, `P3-9.3`, `P3-9.4`, `P3-9.5`, `P3-9.6`, `P3-summary`
