### 문제 표현 구조(problem-representation structure)

- 뜻: 저장된 기록을 현재 질문에 답할 수 있도록 샘플, 파생 열, 비교 기준, 출력 형식으로 다시 표현한 구조입니다.
- 왜 중요한가: 문제 표현 구조가 있어야 저장된 기록을 단순 보관 표가 아니라 비교, 해석, 학습 준비에 쓰는 표로 읽을 수 있습니다. 이 구분이 없으면 저장 구조의 한 행을 곧바로 학습 샘플로 착각하기 쉽습니다.
- 함께 볼 개념: `저장 구조(storage structure)`, `데이터셋 후보(dataset candidate)`, `데이터 모델링(data modeling)`, `모델 출력 구조(model output structure)`
- 중심 Section: `P3-2.1`
- 등장 Section: `P3-index`, `P3-3.1`, `P3-3.2`, `P3-3.3`, `P3-summary`
