### 위치별 곱(element-wise multiplication)

- 뜻: 같은 shape의 두 배열이나 벡터에서 같은 위치의 값끼리 곱하는 계산입니다. `[1, 2, 3] * [4, 5, 6]`이 `[4, 10, 18]`이 되는 것처럼 각 위치가 서로 독립적으로 계산됩니다. 즉 위치별 곱은 행과 열을 조합하는 행렬 곱과 다른 연산입니다.
- 왜 중요한가: NumPy에서 `*`는 보통 위치별 곱이고, `@`는 행렬 곱이라는 차이를 모르면 수식과 코드 해석이 함께 어긋나기 때문입니다. 이 개념이 있어야 같은 숫자들이 있어도 `같은 위치끼리 곱하는가`, `곱하고 더해 새 표현을 만드는가`를 먼저 구분하게 됩니다. shape가 맞아야 한다는 점도 함께 확인하는 기본 예입니다.
- 함께 볼 개념: `행렬 곱(matrix multiplication)`, `shape`, `배열(array)`
