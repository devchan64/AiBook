## random threshold

- Meaning: A random threshold is a split cutoff value drawn randomly instead of being chosen only through an exhaustive best-split search.
- Why it matters: It is the central reason Extra Trees is described as more randomized than random forest. Randomness is added not only to feature selection, but also to where a node is cut.
- Related concepts: `Extra Trees`, `best split`, `threshold`, `variance`
