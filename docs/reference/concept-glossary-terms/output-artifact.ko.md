### 출력 산출물(output artifact)

- 뜻: 생성형 AI가 조건에 맞춰 만들어 낸 문장, 이미지, 코드, 오디오, 계획 초안 같은 결과물입니다. 단일 라벨이나 점수와 달리, 사람이 읽고 수정하거나 다른 작업에 다시 사용할 수 있는 형식의 산출물을 가리킵니다.
- 왜 중요한가: 생성형 AI의 출력은 `정답 하나`보다 사람이 검토하고 재사용할 대상에 가깝기 때문입니다. 이 개념이 있어야 분류 결과와 생성 결과를 같은 출력으로 뭉개지 않고, 산출물의 품질·근거·권리·사용 맥락을 따로 검토해야 한다는 점을 이해할 수 있습니다.
- 함께 볼 개념: `생성(generation)`, `생성형 AI(generative AI)`, `품질(quality)`
- 중심 Section: `P1-10.1`
- 등장 Section: `P1-10.2`, `P1-10.3`, `P6-1.1`
