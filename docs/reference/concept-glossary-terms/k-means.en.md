## k-means

- Meaning: k-means is a clustering algorithm that chooses a fixed number of clusters and repeatedly assigns points to the nearest centroid, then updates those centroids.
- Why it matters: k-means shows that unsupervised learning still contains human choices, such as the number of clusters and the feature space used for distance. Its result is a useful baseline grouping, but not an automatic discovery of real-world category names.
- Related concepts: `clustering`, `cluster`, `centroid`
