## bar chart

- Meaning: A bar chart compares values across categories by using bar lengths.
- Why it matters: Bar charts are useful for comparing category-level summaries such as counts, averages, or model scores. They should be distinguished from line plots for change, scatter plots for relationships, and histograms for distributions.
- Related concepts: `category`, `aggregation`, `plot`
