### 입력 창(input window)

- 뜻: 원천 시계열이나 연속 기록에서 무엇을 한 번의 학습 입력으로 볼지 정해 잘라 낸 시간 구간입니다. 시작점, 끝점, 길이 기준, 정렬 기준을 함께 포함하므로 단순히 배열 길이를 맞추는 기술보다 넓은 데이터 모델링 결정입니다.
- 왜 중요한가: 입력 창이 달라지면 같은 기록에서도 모델이 보는 단서, 빠지는 구간, 비교 가능한 샘플 범위가 달라집니다. 이 개념이 있어야 원천데이터를 그대로 넣는 것과 질문에 맞게 한 입력의 경계를 정하는 일을 구분할 수 있습니다. 또한 요약 특징이든 순서가 남은 입력이든 먼저 어떤 창에서 나온 것인지 설명할 수 있어야 뒤의 해석과 재현성이 흔들리지 않습니다.
- 함께 볼 개념: `입력(input)`, `입력 단위(input unit)`, `샘플(sample)`, `요약표(summary table)`, `특징(feature)`, `원천데이터(source data)`

- 등장 Section: `P3-5.4`, `P3-5.6`
