### 交叉验证(cross-validation)

- 含义：交叉验证是在已有数据中多次拆分，并在不同验证部分上反复评估模型或设置的方法。它常用于数据较小，或者一次拆分结果可能受偶然因素影响很大的情况。
- 为什么重要：如果只看一次 validation score 来选模型，结果可能被某一次拆分的偶然性带偏。交叉验证通过多次 validation 让比较更谨慎，但它并不是完全替代最终 test 检查的魔法。
- 相关概念：`验证数据`，`测试数据`，`模型选择`，`泛化`
