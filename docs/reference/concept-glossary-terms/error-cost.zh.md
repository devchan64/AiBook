### 错误成本

- 含义：错误成本是模型出错时在真实运营中产生的损失或负担。不同错误的成本可能不同，例如漏掉风险案例、增加不必要复核，或触发错误的自动处置。
- 为什么重要：即使准确率相同，只要哪种错误更贵不同，更合适的阈值和复核队列策略也会改变。这个概念把 false negative 和 false positive 从简单计数，转成“当前问题更想减少什么”的判断。
- 相关概念：`假阴性`，`假阳性`，`阈值`，`复核候选队列`
