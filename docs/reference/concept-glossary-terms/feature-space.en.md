## feature space

- Meaning: The computational space where data are placed according to feature values. Each axis can represent a feature or a feature combination, and classification boundaries or distance calculations are interpreted inside this space.
- Why it matters: The same data can look easy or awkward for a linear boundary depending on the feature space used to read it. To understand kernels, the reader must distinguish `the data changed` from `the space used to read the data changed`.
- Related concepts: `representation`, `kernel`, `feature`, `decision boundary`
