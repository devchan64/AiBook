## index

- Meaning: An index is a position number in an ordered collection, and in Pandas it can also be a label used to identify rows. The same visible value may therefore refer to position or to a row label depending on context.
- Why it matters: Lists, strings, arrays, and tables all rely on index-like selection, but the meaning changes across contexts. Understanding index prevents confusion between choosing the first row and choosing the row labeled `1`.
- Related concepts: `list`, `value`, `loop`
