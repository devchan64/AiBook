## 学习率

- 含义：学习率控制优化沿着降低损失的方向移动时，每次更新步子有多大。 在梯度提升里，它控制每个 weak learner 的修正会被多强地反映到当前预测里。
- 为什么重要：学习率在稳定前进和速度之间调节。 在梯度提升中，较大的 learning rate 会让单阶段修正影响更大，较小的 learning rate 往往需要更多阶段。 因此它是同时阅读训练稳定性和修正强度的核心超参数。
- 相关概念：`梯度下降`，`梯度`，`优化`，`梯度提升(gradient boosting)`
