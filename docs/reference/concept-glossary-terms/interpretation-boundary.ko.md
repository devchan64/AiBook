### 해석 경계(interpretation boundary)

- 뜻: 데이터나 비교 결과를 보고 어디까지 말할 수 있고, 어디서부터 추가 근거가 필요하다고 멈춰야 하는지 정한 설명의 한계선입니다. 단순히 조심스럽게 말하자는 태도가 아니라, 관찰된 결과와 원인 확정, 자동 진단, 예측 문제 사이의 층위를 나누는 기준입니다.
- 왜 중요한가: 비교표가 변화 신호를 보여 주더라도 원인이나 미래 결과를 바로 확정할 수는 없습니다. 해석 경계를 세워야 `검토 필요` 같은 보수적 출력과 `이상 확정` 같은 강한 주장을 구분하고, 데이터 모델링 결과를 실제보다 더 크게 말하지 않게 됩니다.
- 함께 볼 개념: `근거(evidence)`, `비교 가능성(comparability)`, `모델 출력 구조(model output structure)`, `인간 감독(human oversight)`
