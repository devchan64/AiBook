### 可比较的参考群体(comparable reference group)

- 含义: 可比较的参考群体，是在为当前样本选择基准线时，因样本单位和运行条件相同而被保留下来的过去案例集合。它不是随便很多旧数据，而是为了回答当前问题，按条件筛出的参照对象。
- 为什么重要: 如果参考群体混入了不同工艺、不同长度或不同运行状态，差值虽然仍然可以算出来，但解释会变得不稳定。这个概念让读者把基准线选择看成“收窄可比较候选”的设计工作，而不是挑一个旧平均值。
- 相关概念: `基准线`, `可比性`, `样本`, `比较表`
