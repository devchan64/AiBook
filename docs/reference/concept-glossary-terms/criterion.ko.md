### 비교 기준(criterion)

- 뜻: 여러 후보 가운데 무엇이 더 나은지 판단하기 위해 쓰는 기준입니다. 일반적인 좋은 느낌이 아니라, 후보를 비교할 수 있도록 정한 계산·판단의 기준점입니다.
- 왜 중요한가: 후보가 여러 개 있어도 기준이 없으면 더 나은 값을 말할 수 없기 때문입니다. 이 개념이 있어야 최적화에서 `무엇을 좋다고 볼지`를 먼저 정해야 하며, 손실 함수와 평가 지표도 서로 다른 기준일 수 있음을 구분하게 됩니다.
- 함께 볼 개념: `후보(candidate)`, `목적 함수(objective function)`, `평가 지표(metric)`
