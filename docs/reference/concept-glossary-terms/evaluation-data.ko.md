### 평가 데이터(evaluation data)

- 뜻: 모델 학습에 직접 쓰지 않고, 학습된 모델의 동작을 확인하기 위해 따로 남겨 둔 데이터입니다. 이 항목에서는 검증 데이터와 테스트 데이터를 더 나누기 전의 넓은 의미로 사용합니다.
- 왜 중요한가: 모델이 이미 본 데이터만 잘 맞히는지, 아직 보지 않은 사례에도 어느 정도 일반화되는지 확인하려면 학습에 쓰지 않은 데이터가 필요합니다. 평가 데이터를 구분해야 학습 점수와 새 데이터 성능 추정값을 섞어 읽지 않을 수 있습니다.
- 함께 볼 개념: `학습 데이터(training data)`, `검증 데이터(validation data)`, `테스트 데이터(test data)`, `일반화(generalization)`, `평가 지표(metric)`
- 중심 Section: `P4-4.1`
- 등장 Section: `P4-4.1`, `P4-4.2`
