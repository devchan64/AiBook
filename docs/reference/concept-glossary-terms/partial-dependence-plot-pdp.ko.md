### 부분 의존도 플롯(PDP, partial dependence plot)

- 뜻: PDP는 한 특징 값을 바꿀 때 모델 예측이 평균적으로 어떻게 달라지는지 보여 주는 해석 도구입니다.
- 왜 중요한가: 특징 중요도가 `무엇을 많이 썼는가`를 묻는다면, PDP는 `그 값이 커지거나 작아질 때 예측 방향이 어떻게 움직이는가`를 더 직접 묻습니다.
- 함께 볼 개념: `특징 중요도(feature importance)`, `SHAP`, `인과 추론(causal inference)`
- 중심 Section: `P4-15.2`
- 등장 Section: `P4-15.2`
