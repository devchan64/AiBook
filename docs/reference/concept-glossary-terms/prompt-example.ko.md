### 프롬프트 예시(prompt example)

- 뜻: 프롬프트 안에 넣어 원하는 입력-출력 패턴이나 판단 기준을 보여 주는 시범입니다. 데이터셋의 개별 사례(example)와 달리, 프롬프트 예시는 모델을 다시 학습시키는 데이터가 아니라 현재 입력 안에서 참고할 형식과 기준을 보여 주는 구성 요소입니다.
- 왜 중요한가: `예시(example)`라는 일반 표현이 데이터 한 건, 설명 보조 장면, 프롬프트 안의 task demonstration을 모두 가리킬 수 있어 오해가 생기기 쉽기 때문입니다. 프롬프트 예시를 분리하면 few-shot prompting이 모델 가중치를 바꾸는 학습이 아니라, 현재 입력 안에서 원하는 패턴을 보여 주는 방식임을 더 정확히 이해할 수 있습니다. 또한 예시가 답의 형식뿐 아니라 판정 기준까지 유도할 수 있다는 점도 함께 보게 됩니다.
- 함께 볼 개념: `프롬프트(prompt)`, `퓨샷 프롬프팅(few-shot prompting)`, `문맥 내 학습(in-context learning)`, `사례(example)`
