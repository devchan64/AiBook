### 중첩 리스트(nested list)

- 뜻: 리스트 안에 다시 리스트가 들어 있는 구조입니다. 표나 행렬처럼 보일 수 있지만, Python 기본 문법 단계에서는 수치 계산용 다차원 배열(array)이 아니라 `리스트의 항목으로 리스트가 들어간 구조`로 먼저 읽어야 합니다.
- 왜 중요한가: 중첩 리스트를 배열이나 행렬과 바로 같은 말로 보면 계산 성질과 복사 동작을 오해하기 쉽기 때문입니다. 특히 `[[]] * 3`처럼 같은 안쪽 리스트를 여러 번 참조하는 초기화는 모든 행이 함께 바뀌는 것처럼 보일 수 있습니다. 중첩 리스트를 이해해야 리스트, NumPy 배열, 행렬을 서로 다른 층위의 구조로 구분하게 됩니다.
- 함께 볼 개념: `리스트(list)`, `얕은 복사(shallow copy)`, `배열(array)`
