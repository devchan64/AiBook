### 사전학습 LLM(pretrained LLM)

- 뜻: 대규모 말뭉치에서 일반적인 언어 패턴과 표현을 먼저 학습한 뒤, 여러 작업에 활용되거나 추가 조정을 거치는 대규모 언어 모델입니다. 즉 사전학습 LLM은 특정 서비스 지시를 막 받은 빈 모델이 아니라, 배포 전 큰 학습 단계를 통해 이미 넓은 언어 능력을 갖춘 모델입니다.
- 왜 중요한가: 현대 LLM의 기본 능력이 프롬프트 순간에 새로 생기는 것이 아니라, 사전학습에서 만들어진 표현과 패턴 위에서 작동한다는 점을 이해하게 해 주기 때문입니다. 이 개념이 있어야 사전학습, 미세조정, 문맥 내 학습을 서로 다른 적응 층위로 구분할 수 있습니다. 또한 `LLM`이라는 일반 표현이 모델 구조, 학습된 모델, 서비스 제품을 모두 가리킬 수 있으므로, 사전학습된 모델 자체를 말하는지 배포 서비스까지 말하는지 구분해야 합니다.
- 함께 볼 개념: `대규모 언어 모델(LLM, large language model)`, `사전학습(pretraining)`, `미세조정(fine-tuning)`, `문맥 내 학습(in-context learning)`
