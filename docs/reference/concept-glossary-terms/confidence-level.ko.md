### 신뢰 수준(confidence level)

- 뜻: 모델이 낸 확률 출력이나 점수를 어느 정도 믿을 수 있는지 해석할 때 쓰는 수준 표현입니다. 보정된 분류기에서는 예측 확률을 신뢰 수준에 가깝게 읽을 수 있지만, 모든 모델 점수가 자동으로 그런 의미를 갖는 것은 아닙니다.
- 왜 중요한가: `0.80` 같은 숫자를 그대로 믿어도 되는지와, 단지 후보 비교용 점수로만 봐야 하는지를 구분해야 하기 때문입니다. 이 개념이 있어야 확률 출력의 크기와 실제 신뢰 가능성을 섞지 않고, 보정(calibration)이 왜 필요한지 이해하게 됩니다.
- 함께 볼 개념: `보정(calibration)`, `확률 추정값(probability estimate)`, `점수(score)`
