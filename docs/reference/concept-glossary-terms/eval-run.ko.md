### 평가 실행(eval run)

- 뜻: 정해 둔 입력 세트와 평가 기준으로 모델이나 AI 에이전트 흐름을 한 번 돌려 결과를 기록하는 실행 단위입니다. 단순 테스트 한 건이 아니라, 어떤 버전의 프롬프트, 모델, 검색 설정, 도구 구성이 어떤 평가 결과를 냈는지 묶어 남기는 단위입니다.
- 왜 중요한가: AI 서비스는 한 번의 출력만으로 품질을 판단하기 어렵기 때문에, 같은 조건에서 다시 비교할 수 있는 실행 기록이 필요합니다. 평가 실행을 구분해야 변경 전후의 품질 차이, 비용 차이, 실패 양상을 추적하고 회귀 여부를 판단할 수 있습니다.
- 함께 볼 개념: `평가(evaluation)`, `하네스(harness)`, `그레이더(grader)`, `추적(trace)`
