### 반복 누적(iterative accumulation)

- 뜻: 반복 중 현재까지의 결과를 변수나 자료구조에 계속 쌓아 하나의 결과를 만드는 패턴입니다. 일반적인 누적 상태가 아니라, 합계를 더하거나 개수를 세거나 키별 빈도를 딕셔너리에 모으는 반복 계산 방식입니다.
- 왜 중요한가: 데이터 처리에서는 단순히 값을 출력하는 반복보다, 반복 결과로 새 요약이나 집계를 만드는 일이 더 많기 때문입니다. 반복 누적을 이해해야 `total = total + score`나 `label_counts[label] = ...` 같은 코드가 현재 항목 하나가 아니라 지금까지 본 전체 흐름을 반영한다는 점을 읽게 됩니다. 이 감각은 손실 누적, 라벨 분포 확인, 평가 결과 집계로 이어집니다.
- 함께 볼 개념: `프로그램 코드(program code)`, `자료구조(data structure)`, `평균(mean)`
