### 키 기반 구조(key-based structure)

- 뜻: 위치보다 키를 기준으로 값을 찾고 관리하는 구조 감각입니다. 딕셔너리나 해시 테이블처럼 `이름표로 찾는다`는 질문이 중심일 때 쓰는 분류입니다.
- 왜 중요한가: 선형 구조와 비선형 구조만으로는 딕셔너리처럼 키 조회가 중심인 구조를 설명하기 부족하기 때문입니다. 키 기반 구조를 구분하면 순서 처리, 관계 이동, 이름표 조회가 서로 다른 자료구조 질문이라는 점이 분명해집니다.
- 함께 볼 개념: `딕셔너리(dictionary)`, `해시 테이블(hash table)`, `키(key)`

- 등장 Section: `P2-9.4`
