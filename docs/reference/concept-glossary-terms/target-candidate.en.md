### target candidate

- Meaning: A target candidate is a provisional result column that might later become the target a model should predict, even though it is not yet a confirmed answer label.
- Why it matters: A comparison report, review queue, or operational note should not be promoted directly into a learning target. Target candidates separate promising result columns from stable target definitions that are repeatable, consistent, and traceable.
- Related concepts: `target`, `output structure`, `comparison report`, `label`
