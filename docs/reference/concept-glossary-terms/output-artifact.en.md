## output artifact

- Meaning: An output artifact is a result created by generative AI, such as a sentence, image, code snippet, audio script, or draft plan, that a person can read, revise, or reuse in another task. Unlike a single label or score, it is a result object that must be inspected as work material.
- Why it matters: Generative-AI output is closer to something people must review and reuse than to one finished answer. This concept prevents classification results and generated artifacts from being collapsed into the same kind of output, and it makes quality, evidence, rights, and usage context separate review questions.
