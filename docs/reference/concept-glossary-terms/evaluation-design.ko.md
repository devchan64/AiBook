### 모델 평가 설계(evaluation design)

- 뜻: 모델이나 규칙을 어떤 데이터 분할, 어떤 지표, 어떤 비교 기준으로 평가할지 정하는 설계입니다. 단순히 점수를 계산하는 단계가 아니라, 현재 문제 구조에 맞는 시험 조건을 먼저 정하는 일입니다.
- 왜 중요한가: 같은 모델도 시간 순서 분할, 그룹 분할, 순위화 지표, 회귀 지표 중 무엇을 쓰느냐에 따라 전혀 다르게 평가됩니다. 평가 설계가 문제 구조와 어긋나면 높은 점수도 실제 운영 성능을 설명하지 못하므로, 모델 선택보다 먼저 평가 조건을 닫아야 합니다.
- 함께 볼 개념: `시간 순서 분할(time split)`, `그룹 분할(group split)`, `데이터 누수(data leakage)`, `순위화(ranking)`
