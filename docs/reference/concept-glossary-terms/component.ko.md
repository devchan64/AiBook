### 성분(component)

- 뜻: 여러 값이나 구조를 더 작은 구성 단위로 나누어 볼 때의 한 부분입니다. PCA에서는 원래 특징을 새 축으로 다시 표현했을 때 각 새 축을 하나의 성분으로 읽습니다.
- 왜 중요한가: 성분이라는 말은 원래 특징 하나와 새로 계산된 표현 축을 구분하게 해 줍니다. PCA의 첫 번째 성분은 원래 열 하나가 아니라 데이터의 큰 변동 방향을 담은 새 표현입니다.
- 함께 볼 개념: `차원 축소(dimensionality reduction)`, `PCA(principal component analysis)`, `특징(feature)`
