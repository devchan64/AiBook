### 코드(code)

- 뜻: 컴퓨터가 실행할 수 있도록 계산 절차를 프로그래밍 언어로 적은 문장과 구조입니다. 수식이 계산 구조를 압축한다면, 코드는 값을 준비하고, 계산하고, 결과를 확인하는 실행 순서를 더 구체적으로 펼쳐 둡니다.
- 왜 중요한가: AI 학습에서는 수식을 읽는 데서 끝나지 않고 작은 데이터로 직접 계산을 확인해야 합니다. 코드를 이해해야 수식, 데이터, 출력이 실제 실행에서 어떻게 이어지는지 볼 수 있습니다.
- 함께 볼 개념: `수식(formula)`, `데이터(data)`, `출력(output)`, `코드 셀(code cell)`
