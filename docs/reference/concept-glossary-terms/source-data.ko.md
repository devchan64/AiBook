### 원천데이터(source data)

- 뜻: 분석이나 학습 문제로 다시 구성하기 전의 출발 기록입니다. 로그, 센서 측정값, 업무 기록처럼 나중에 샘플, 특징, 기준선, 출력 구조로 재구성될 수 있지만, 그 자체가 곧바로 데이터셋이나 학습 문제는 아닙니다.
- 왜 중요한가: 원천데이터와 데이터셋을 구분하지 않으면 `데이터가 있다`를 `학습 가능한 문제 구조가 준비됐다`로 오해하기 쉽습니다. 이 개념이 있어야 같은 기록도 질문에 따라 서로 다른 샘플 단위와 표 구조로 다시 읽을 수 있다는 점을 이해하게 됩니다.
- 함께 볼 개념: `데이터셋(dataset)`, `데이터 모델링(data modeling)`, `샘플 단위(sample unit)`, `특징(feature)`
