## max_features

- 含义：`max_features` 是在随机森林中控制每个 split 能查看多少特征，或查看多大比例特征的超参数。
- 为什么重要：`max_features` 会影响树和树之间有多像。太大时，许多树可能都被同一个强特征带走；太小时，单棵树本身又可能太弱。
- 相关概念：`随机森林(random forest)`，`特征(feature)`，`超参数(hyperparameter)`，`集成(ensemble)`
