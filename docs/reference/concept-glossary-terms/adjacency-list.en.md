## adjacency list

- Meaning: An adjacency list represents a graph by listing the directly connected neighbors for each node. It turns drawn edges into a table-like or dictionary-like structure that shows where each node can move next.
- Why it matters: Graphs are not only pictures; they must also be stored and queried. An adjacency list makes relationship data concrete as neighbors by node, which prepares readers for search, recommendation, and link analysis.
- Related concepts: `graph`, `node`, `edge`
