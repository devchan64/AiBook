### 점수(score)

- 뜻: 모델이 후보 출력이나 판단 대상에 부여하는 수치 값입니다. 점수는 후보를 비교하거나 임계값을 적용하는 데 쓰일 수 있지만, 항상 보정된 확률과 같은 뜻은 아닙니다.
- 왜 중요한가: inference 결과가 하나의 라벨만이 아니라 여러 후보의 점수로 나오는 경우가 많기 때문입니다. 이 개념이 있어야 모델 출력, 확률, 최종 업무 결정을 구분하고, 점수가 높다는 사실만으로 곧바로 실제 결정을 확정하지 않게 됩니다.
- 함께 볼 개념: `확률(probability)`, `예측(prediction)`, `모델링 과제(modeling task)`
- 중심 Section: `P1-5.2`
- 등장 Section: `P2-11.1`, `P2-11.2`, `P2-11.3`, `P2-11.4`
