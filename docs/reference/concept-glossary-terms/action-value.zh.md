## 行动价值(action value)

- 含义: 行动价值表示在某个状态下采取某个行动时，预期能得到的长期回报。它问的是`在这里做这个行动有多好`。
- 为什么重要: 强化学习中的实际选择，通常是在一个状态里比较多个行动候选。理解 action value，才能把价值型更新和 on-policy 更新标准放进同一个框架里读。
- 相关概念: `state value`, `value-based reinforcement learning`, `on-policy`
