### 源事件(source event)

- 含义：源事件是在被切成输入窗口或汇总行之前，实际发生的原始事件单位。例如一次动作、一条告警、一次会话，都可以成为派生输入片段的出发点。
- 为什么重要：如果从同一个源事件中切出许多重叠输入窗口，模型输入片段数会增加，但真实事件数并没有增加。这个概念可以避免把派生窗口数误读成更强的证据，也有助于在代表性判断和评估划分中追踪来自同一事件的相关片段。
- 相关概念：`输入窗口(input window)`, `源数据(source data)`, `样本(sample)`, `数据集(dataset)`, `数据泄漏(data leakage)`
