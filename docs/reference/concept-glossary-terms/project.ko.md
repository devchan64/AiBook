### 프로젝트(project)

- 뜻: 하나의 질문이나 목표를 정하고, 필요한 자료와 절차를 묶어 검증 가능한 산출물을 만드는 작업 단위입니다. 입문 단계에서는 기술 이름을 크게 내세우기보다, 작게 닫힌 질문 하나를 실제 결과로 확인하는 학습 단위로 보는 편이 좋습니다.
- 왜 중요한가: AI를 이해했다는 느낌은 빠르게 생기지만, 실제 이해는 작은 산출물을 만들어 검증할 때 드러납니다. 프로젝트를 이해해야 학습, 검색, 자동화, 평가를 하나의 검증 가능한 흐름으로 묶을 수 있습니다.
- 함께 볼 개념: `성공 기준(success criteria)`, `평가(evaluation)`, `기록(record)`, `실패 유형(failure type)`
