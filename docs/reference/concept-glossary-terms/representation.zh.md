## 表示(representation)

- 含义: 把输入整理成模型可以计算的内部形式。它不是原始数据本身，而是为了当前任务，把有用的差异和关系重新组织后的计算用形态。
- 为什么重要: 要理解 deep learning 和 representation learning，读者需要区分人看到的输入和模型实际计算的内部形式。如果 feature 是输入线索，representation 更接近这些线索在模型内部被怎样重新组织。好的 representation 可以让后续 classification 或 generation 变得更容易。
- 相关概念: `特征(feature)`, `向量(vector)`, `激活值(activation)`, `嵌入(embedding)`, `表示学习(representation learning)`
