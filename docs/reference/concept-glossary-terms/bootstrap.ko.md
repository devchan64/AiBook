### 부트스트랩(bootstrap)

- 뜻: 원래 데이터에서 중복을 허용해 샘플을 다시 뽑아 여러 학습 집합이나 추정 집합을 만드는 재표본추출 방법입니다.
- 왜 중요한가: 같은 데이터에서도 여러 표본 변형을 만들어 모델이나 추정값이 얼마나 흔들리는지 볼 수 있습니다. 랜덤포레스트에서는 각 트리가 서로 다른 부트스트랩 표본을 보면서 다양성을 갖게 됩니다.
- 함께 볼 개념: `랜덤포레스트(random forest)`, `앙상블(ensemble)`, `OOB 점수(out-of-bag score)`, `표본(sample)`
- 중심 Section: `P4-15.1`
- 등장 Section: `P4-15.3`, `P4-15.4`
