### 질의(query)

- 뜻: 지금 비교하거나 예측하려는 새 입력입니다. k-NN에서는 저장된 학습 데이터와 거리를 비교해 이 입력 주변의 이웃을 찾고, 검색에서는 후보를 찾기 위해 시스템에 던지는 기준 표현이 됩니다.
- 왜 중요한가: query를 분명히 구분해야 `이미 저장된 기준 사례`와 `지금 판단할 새 사례`를 헷갈리지 않습니다. 같은 학습 데이터라도 query의 위치나 표현 방식이 달라지면 선택되는 이웃과 결과가 달라질 수 있습니다.
- 함께 볼 개념: `최근접 이웃(nearest neighbor)`, `거리(distance)`, `검색(search)`
