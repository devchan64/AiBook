### 일변수 함수(single-variable function)

- 뜻: 입력 변수가 하나인 함수입니다. \(y=f(x)\)처럼 하나의 입력 \(x\)가 출력 \(y\)로 이어지는 구조가 대표적입니다. 즉 일변수 함수에서는 변화율도 기본적으로 한 입력 방향에 대한 질문으로 시작합니다.
- 왜 중요한가: 고등학교 미분 기억과 그래디언트 사이의 간격을 설명하는 기준점이기 때문입니다. 일변수 함수의 접선 기울기와 순간 변화율을 먼저 이해하면, 다변수 함수에서 편미분과 그래디언트가 왜 필요한지 더 자연스럽게 확장할 수 있습니다. 이 개념은 `기울기 하나`에서 `기울기 묶음`으로 넘어가는 출발점입니다.
- 함께 볼 개념: `미분(derivative)`, `다변수 함수(multivariable function)`, `기울기(slope)`
- 중심 Section: `P2-4.5`
