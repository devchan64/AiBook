## 激活函数

- 含义：激活函数会在中间分数或加权和传给下一层或输出前，对它进行变换。它引入非线性反应，而不是把简单线性组合原样传下去。
- 为什么重要：如果只反复做线性组合，深层网络的表达力不会增加太多。激活函数让层能够形成更复杂的决策边界和表示，同时也影响梯度流动和训练稳定性。它解释了深度网络为什么既需要堆叠层，也需要非线性反应曲线。
- 相关概念：`线性组合`，`激活值`，`隐藏层`
