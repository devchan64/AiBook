## set

- Meaning: A set is a data structure focused on membership rather than order or duplicates. It is useful when the main question is whether a value is included, what two groups share, or what remains after duplicates are removed.
- Why it matters: A set asks whether something is included before it asks where it is. This helps separate membership checks, duplicate removal, and category comparison from sequential list processing.
