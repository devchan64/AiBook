### OOB 점수(out-of-bag score)

- 뜻: 부트스트랩 표본에 뽑히지 않은 데이터를 이용해 랜덤포레스트가 학습 중에 거칠게 확인하는 내부 검증 점수입니다.
- 왜 중요한가: 랜덤포레스트는 각 트리마다 보지 않은 표본이 남기 때문에, 별도의 검증 절차와 완전히 같지는 않아도 학습 중 자기 점검 신호를 얻을 수 있습니다. 이 점수는 최종 테스트를 대체하기보다 모델 상태를 빠르게 읽는 보조 기준으로 봐야 합니다.
- 함께 볼 개념: `랜덤포레스트(random forest)`, `부트스트랩(bootstrap)`, `검증 데이터(validation data)`, `평가 지표(metric)`
- 중심 Section: `P4-15.3`
- 등장 Section: `P4-15.4`
