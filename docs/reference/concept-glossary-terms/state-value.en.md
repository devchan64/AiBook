## state value

- Meaning: State value is the expected long-term return associated with being in a state. It asks how good the state is overall, before focusing on one specific action.
- Why it matters: It separates the value of being in a situation from the value of taking a particular action there. That separation prepares the reader to understand action value and Q-value as more direct standards for choosing actions.
- Related concepts: `reinforcement learning`, `state`, `action value`, `Q-value`
