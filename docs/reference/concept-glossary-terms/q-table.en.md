## Q-table

- Meaning: A Q-table stores Q-values directly in a table for each state-action combination.
- Why it matters: It is intuitive in small reinforcement-learning examples, but it grows quickly as the number of states increases, showing why function approximation becomes necessary.
- Related concepts: `Q-value`, `Q-learning`, `function approximation`
