### 프로토콜(protocol)

- 뜻: 서로 다른 프로그램이나 시스템이 어떤 형식으로 요청하고 응답할지 정한 통신 규칙입니다. 단순한 제품 이름이나 라이브러리 사용법이 아니라, 데이터를 어떤 모양으로 주고받고 어떤 절차로 기능을 발견하고 호출할지 맞추는 약속에 가깝습니다.
- 왜 중요한가: AI 앱이 외부 도구와 리소스를 안정적으로 연결하려면, 각 시스템이 제각각 말하는 대신 공통 규칙을 따라야 하기 때문입니다. 이 개념이 있어야 MCP를 `새 모델`이나 `새 앱`이 아니라, 연결 방식을 표준화하려는 규칙 묶음으로 읽을 수 있습니다.
- 함께 볼 개념: `모델 컨텍스트 프로토콜(Model Context Protocol, MCP)`, `클라이언트(client)`, `서버(server)`
