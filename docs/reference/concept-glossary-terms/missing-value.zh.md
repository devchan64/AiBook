### 缺失值(missing value)

- 含义：缺失值是本应有观测值或记录值的位置为空的状态。它可能只是一个空白，也可能来自传感器失效、记录缺漏、样本边界不确定，或运行条件变化。
- 为什么重要：如果所有缺失值都用同一种方式填补或删除，就可能看不见样本结构或特征含义是否已经被破坏。这个概念帮助读者区分可以填补的值、应保留成标记的信息，以及应从比较中撤回的样本。它也让预处理不再只是清洗，而是和数据建模判断连接起来。
- 相关概念：`数据质量检查(data quality check)`, `样本(sample)`, `特征(feature)`, `预处理(preprocessing)`, `源数据(source data)`
