## reward design

- Meaning: Reward design is the work of defining, through a reward function and constraints, what a reinforcement-learning agent should treat as doing well. It is a form of goal definition, not only a numeric implementation detail.
- Why it matters: If the reward only roughly stands in for the real goal, the AI agent can raise the number while missing the human intention. Reward design is therefore the starting point for checking reward hacking, safe exploration, and deployment risk.
- Related concepts: `reward`, `true objective`, `reward hacking`, `proxy target`
