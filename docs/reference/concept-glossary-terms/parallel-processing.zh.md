## 并行处理

- 含义: 并行处理不是把许多计算一个接一个排队完成，而是把相似或相互独立的计算分给多个计算资源同时处理。关键不是“机器更快”这一句话，而是把问题整理成适合同时计算的形状。
- 为什么重要: 深度学习经常把同一种运算重复应用到许多数据片段和许多参数上。理解并行处理，才能把 GPU、batch 计算、矩阵乘法和 tensor 运算放在同一条计算效率轴上阅读。
- 相关概念: `GPU`, `batch`, `矩阵乘法`
