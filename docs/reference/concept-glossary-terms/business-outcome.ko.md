### 업무 성과(business outcome)

- 뜻: 모델을 시스템이나 서비스에 넣은 뒤 실제 업무가 얼마나 나아졌는지를 보는 바깥 결과입니다. 모델 점수 자체가 아니라 처리 시간, 비용, 안전성, 고객 경험, 사람 검토 부담처럼 실제 운영 목표와 연결된 변화입니다.
- 왜 중요한가: 모델 평가 지표가 좋아져도 업무 성과가 자동으로 좋아지는 것은 아니기 때문입니다. 분류 정확도가 높아도 라우팅 규칙이 틀리거나, 답변 생성 품질이 좋아도 정책 검토가 약하면 실제 업무는 나아지지 않을 수 있습니다. 이 개념이 있어야 모델 성능, 시스템 품질, 실제 운영 결과를 분리해서 확인하게 됩니다.
- 함께 볼 개념: `평가(evaluation)`, `평가 지표(metric)`, `서비스(service)`, `영향(impact)`
