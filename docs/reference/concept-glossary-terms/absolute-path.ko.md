### 절대 경로(absolute path)

- 뜻: 파일 시스템의 시작점부터 파일이나 폴더 위치를 모두 적은 경로입니다. macOS/Linux에서는 `/Users/...`나 `/home/...`처럼 보이고, Windows에서는 `C:\Users\...`처럼 보일 수 있습니다. 상대 경로가 현재 작업 폴더에 따라 달라진다면, 절대 경로는 어디에서 실행하더라도 같은 위치를 가리키려는 표기입니다.
- 왜 중요한가: 운영체제와 사용자 환경이 다르면 같은 예제 경로를 그대로 복사해도 맞지 않을 수 있기 때문입니다. 절대 경로를 이해해야 문서의 `/Users/someone/...` 예시를 자기 컴퓨터의 실제 위치로 바꿔 읽을 수 있고, 경로 오류를 Python 코드 오류와 분리해 점검할 수 있습니다. 또한 절대 경로는 편리한 해결책처럼 보이지만, 다른 사람 컴퓨터에서는 그대로 재현되지 않을 수 있어 재현성 관점에서도 주의해야 합니다.
