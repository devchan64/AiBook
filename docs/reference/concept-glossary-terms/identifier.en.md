## identifier

- Meaning: An identifier is a value used to distinguish an individual row, case, user, student, event, or object. It usually tells which item something is, not what general pattern the model should learn.
- Why it matters: If an identifier is used as an input feature without care, a model may follow names or IDs instead of learning reusable patterns. This concept helps readers separate input features, targets, and identifier columns when preparing a dataset.
- Related concepts: `sample`, `feature`, `target`
