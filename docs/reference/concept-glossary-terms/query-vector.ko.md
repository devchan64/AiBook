### 질문 벡터(query vector)

- 뜻: 사용자의 질문이나 검색 요청을 임베딩으로 바꾼 벡터입니다. 유사도 검색에서는 이 질문 벡터를 기준으로 문서 벡터들과 비교해 가까운 후보를 고릅니다. 즉 질문 벡터는 검색 시스템이 `무엇과 비슷한 문서를 찾을 것인가`를 나타내는 기준 표현입니다.
- 왜 중요한가: 질문 자체와 검색 기준 표현을 구분하게 해 주기 때문입니다. 사용자가 입력한 문장은 사람이 읽는 텍스트이고, 질문 벡터는 그 문장을 계산 가능한 위치로 바꾼 표현입니다. 이 개념이 있어야 검색이 단순 문자열 찾기가 아니라, 질문과 문서 조각을 같은 벡터 공간에 놓고 비교하는 절차라는 점을 이해할 수 있습니다.
- 함께 볼 개념: `문서 벡터(document vector)`, `임베딩(embedding)`, `유사도 검색(similarity search)`, `벡터 공간(vector space)`
