### kernel PCA

- 뜻: 커널(kernel)을 사용해 원래 공간에서 직선 축으로 잘 보이지 않는 구조를 다른 공간에서 펼쳐 보려는 비선형 차원 축소 방법입니다.
- 왜 중요한가: PCA가 선형 새 축으로 큰 분산 방향을 잡는다면, kernel PCA는 비선형 구조까지 더 잘 보려는 확장으로 읽을 수 있습니다. 그래서 둘을 같은 `차원 축소` 안에서도 다른 질문에 대한 답으로 구분해야 합니다.
- 함께 볼 개념: `커널(kernel)`, `PCA(principal component analysis)`, `차원 축소(dimensionality reduction)`
