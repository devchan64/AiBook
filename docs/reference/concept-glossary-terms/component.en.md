## component

- Meaning: A component is one part of a larger representation. In PCA, each component is a newly computed axis used to reexpress the original features.
- Why it matters: The term separates original features from newly built axes. The first principal component is not one original column; it is a new direction that captures large variation.
- Related concepts: `dimensionality reduction`, `PCA`, `feature`
