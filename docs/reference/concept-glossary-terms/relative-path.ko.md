### 상대 경로(relative path)

- 뜻: 현재 작업 폴더를 기준으로 파일이나 폴더 위치를 가리키는 경로입니다. `/`나 드라이브 이름 같은 파일 시스템 시작점부터 모두 쓰는 대신, 지금 서 있는 위치에서 어디로 가야 하는지를 짧게 적는 방식입니다. 예를 들어 프로젝트 루트에서 `docs/parts`라고 쓰면 현재 작업 폴더 아래의 `docs/parts`를 찾습니다.
- 왜 중요한가: 상대 경로는 짧고 편하지만 현재 작업 폴더가 바뀌면 의미도 함께 바뀌기 때문입니다. 이 개념이 있어야 같은 `python example.py`나 `pd.read_csv("scores.csv")`가 어떤 폴더에서는 성공하고 다른 폴더에서는 실패하는 이유를 이해할 수 있습니다. 결국 상대 경로는 파일 이름보다 `지금 어디를 기준으로 찾고 있는가`를 먼저 확인하게 만드는 경로 개념입니다.
- 함께 볼 개념: `파일 경로(file path)`, `절대 경로(absolute path)`, `작업 폴더(working directory)`

- 등장 Section: `P2-7.6`, `P2-7.9`
