### 기본값(default value)

- 뜻: 함수 호출에서 인자를 따로 주지 않았을 때 자동으로 사용되는 미리 정한 값입니다. Python 함수 정의에서는 `threshold=60`처럼 매개변수에 기본값을 붙여, 호출자가 값을 생략해도 기본 동작을 유지하게 할 수 있습니다.
- 왜 중요한가: 라이브러리 함수와 모델 API는 많은 설정값에 기본값을 두기 때문에, 인자를 생략해도 실제 동작은 특정 값에 의해 결정되기 때문입니다. 기본값을 이해해야 `아무 설정도 안 했다`가 `설정이 없다`는 뜻이 아니라 `기본 설정을 사용했다`는 뜻일 수 있음을 읽게 됩니다. 또한 기본값이 mutable value일 때 생기는 주의점도 이후 Python 문서 읽기에서 중요해집니다.
- 함께 볼 개념: `매개변수(parameter)`, `인자(argument)`, `함수(function)`
