## action value

- Meaning: Action value is the expected long-term return from taking a particular action in a particular state. It asks how good this action is here.
- Why it matters: Real reinforcement-learning choices compare action candidates inside a state. Action value is therefore the bridge to value-based updates and on-policy updates.
- Related concepts: `state value`, `value-based reinforcement learning`, `on-policy`
