### representative target

- Meaning: A representative target is the target chosen as the central result to solve first among several target candidates. Even when multiple result columns come from the same events, it fixes what the current modeling question is trying to predict.
- Why it matters: Without a representative target, the same data can be used to mix different problems such as review need, final status, and priority. This concept separates `having many columns` from `having one closed problem`, and it anchors evaluation and error interpretation to one result definition.
- Related concepts: `target`, `target candidate`, `target definition version`, `label`
