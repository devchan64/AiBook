### 확률분포(probability distribution)

- 뜻: 가능한 값이나 결과에 확률을 배정한 수학적 표현입니다. 이미 관측한 데이터의 모양을 그대로 부르는 말이 아니라, 어떤 값이 나올 가능성이 얼마나 되는지 표현하는 틀입니다.
- 왜 중요한가: 데이터 분포와 확률분포를 구분해야 관측값의 모양과 모델링 가정을 섞어 읽지 않기 때문입니다. 이 개념이 있어야 실제 데이터로부터 분포를 추정하거나 가정할 수는 있어도, 관측 데이터 자체가 곧 완전한 확률분포는 아니라는 점을 이해하게 됩니다.
- 함께 볼 개념: `확률(probability)`, `분포(distribution)`, `데이터 분포(data distribution)`
