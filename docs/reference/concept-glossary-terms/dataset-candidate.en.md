### dataset candidate

- Meaning: A dataset candidate is a provisional table structure that regroups samples and columns for one question, but is not yet confirmed as a dataset ready for training or evaluation.
- Why it matters: Stored records do not automatically become a dataset. Dataset candidates make readers check what one row means, which samples are comparable, and which records should still be excluded.
- Related concepts: `dataset`, `source data`, `sample`, `problem-representation structure`
