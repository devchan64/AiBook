### 마스크드 언어 모델(masked language model)

- 뜻: 문장 일부 토큰을 가리고, 주변 문맥을 이용해 가려진 토큰을 맞히도록 학습하는 언어 모델 방식입니다. 입력 전체 문맥을 보는 표현 학습 목표로 알려져 있으며, 왼쪽에서 오른쪽으로 다음 토큰만 맞히는 방식과 구분됩니다.
- 왜 중요한가: 사전학습 언어 모델이 모두 같은 방향으로 다음 토큰을 생성하는 것은 아니라는 점을 보여 주기 때문입니다. 이 개념이 있어야 자기회귀 언어 모델과 양방향 문맥 표현 학습을 구분할 수 있고, `언어 모델`이라는 일반 표현 안에도 학습 목표와 사용 방식이 다른 계열이 있음을 이해하게 됩니다.
- 함께 볼 개념: `사전학습(pretraining)`, `언어 모델(language model)`, `문맥적 표현(contextual representation)`, `인코더(encoder)`
