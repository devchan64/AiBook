## partial dependence plot(PDP)

- Meaning: A partial dependence plot shows how model predictions change on average as one feature value changes.
- Why it matters: Feature importance asks `what did the model use a lot?`; PDP asks more directly `in which direction does the prediction move as this value changes?`
- Related concepts: `feature importance`, `SHAP`, `causal inference`
