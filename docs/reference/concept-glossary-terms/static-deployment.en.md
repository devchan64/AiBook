## static deployment

- Meaning: Static deployment is the publication of prebuilt files such as HTML, CSS, images, and other assets as a site result. The page normally serves prepared files rather than recalculating the document content on every request.
- Why it matters: In a document project, a deployment-branch update can directly change the public result. Static deployment explains why links, images, generated files, and navigation settings must be aligned before publication.
- Related concepts: `deployment`, `branch`, `document reproducibility`
