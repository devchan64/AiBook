### 시간 순서 분할(time split)

- 뜻: 시간 순서가 있는 데이터에서 과거 구간을 학습 쪽에, 더 나중 구간을 검증이나 테스트 쪽에 두는 분할 방식입니다. 무작위로 섞어 나누지 않고, 실제 예측 시점에서 아직 알 수 없는 미래 정보가 학습에 들어가지 않도록 시간 경계를 먼저 지킵니다.
- 왜 중요한가: 시간 순서가 중요한 문제를 무작위 분할로 평가하면 미래 패턴을 미리 본 것처럼 되어 성능이 과장될 수 있습니다. 시간 순서 분할은 `나중 데이터를 맞히기 위해 그보다 앞선 정보만 썼는가`를 확인하게 해, 데이터 누수와 평가 설계 문제를 더 빨리 드러냅니다.
- 함께 볼 개념: `데이터 누수(data leakage)`, `모델 평가 설계(evaluation design)`, `예측 계약(prediction contract)`
