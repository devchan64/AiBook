## safe reinforcement learning

- Meaning: Safe reinforcement learning is a reinforcement-learning branch that treats safety constraints together with policy improvement in order to reduce dangerous actions, damage, or liability. It includes limiting exploration so that new actions do not create unacceptable failures.
- Why it matters: In real applications, exploration can itself create cost and risk, so performance must be read together with failure tolerance and constraints.
- Related concepts: `exploration`, `offline reinforcement learning`, `error cost`
