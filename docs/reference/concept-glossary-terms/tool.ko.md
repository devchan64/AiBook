### 외부 도구(external tool)

- 뜻: 모델이나 AI 앱이 자체 계산만으로 처리하지 못하는 조회, 저장, 실행, 전송을 위해 연결해 쓰는 바깥 기능입니다. 일반적인 도구 전체가 아니라, 검색 API, 파일 시스템, 데이터베이스, 업무 시스템처럼 모델 밖에 있는 실행 단위입니다.
- 왜 중요한가: 외부 도구를 이해해야 AI 서비스가 답변 생성에 그치지 않고 파일 수정, API 호출, 상태 조회 같은 실제 작업으로 이어지는지 구분할 수 있습니다. 이 개념이 있어야 `모델이 안다`와 `시스템이 조회했다`를 나누고, 응답 생성과 실제 실행을 다른 개념으로 설명할 수 있습니다. 또한 실패가 모델 추론 한계에서 온 것인지, 연결된 외부 시스템 조회 실패에서 온 것인지도 더 정확히 나누어 읽게 됩니다.
- 함께 볼 개념: `AI 앱(application)`, `AI 에이전트(AI agent)`, `모델 컨텍스트 프로토콜(Model Context Protocol, MCP)`
