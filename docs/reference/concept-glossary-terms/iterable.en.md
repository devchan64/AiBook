## iterable

- Meaning: An iterable is an object that can be looped over to produce values one at a time. Lists, strings, dictionaries, files, and generators can all be iterable.
- Why it matters: Iterability is a shared behavior rather than a single data type. It explains why different objects can be used in the same `for` loop pattern.
- Related concepts: `iterator`, `loop`, `list`
