## RLHF

- 含义: RLHF, reinforcement learning from human feedback, 是一种训练流程，把人类反馈或偏好解释成类似 reward 的信号，用来调整模型的输出 policy。
- 为什么重要: 它是强化学习的 reward 语言和 LLM alignment 中人类偏好问题相遇的代表位置。
- 相关概念: `preference optimization`, `reward model`, `alignment`, `policy`
