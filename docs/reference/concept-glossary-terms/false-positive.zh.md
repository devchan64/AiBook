### 假阳性

- 含义：假阳性是实际为阴性的案例被模型或规则判断为阳性的错误。例如不需要复核的案例被放进复核队列，就是 false positive。
- 为什么重要：当假阳性的成本很高时，阈值设得太低可能会增加人工复核负担或不必要的行动成本。这个概念说明，减少漏判和减少误报往往对应不同的运营选择。
- 相关概念：`假阴性`，`错误成本`，`阈值`，`精确率`
