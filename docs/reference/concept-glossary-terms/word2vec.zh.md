## word2vec

- 含义：word2vec 是一类根据单词共同出现的上下文来高效学习词嵌入的方法。它不是手工写入词典式意义，而是从语料中的邻近词模式学习单词向量。
- 为什么重要：word2vec 让许多学习者第一次具体感受到，单词意义可以从使用上下文中学成向量表达。它不能解释现代 LLM 的全部上下文表达，但它是理解“把单词放进向量空间，并让相似单词变近”这一表达学习直觉的重要前置概念。
- 相关概念：`embedding`，`distributed representation`，`corpus`
