### 생성 설정값(generation setting)

- 뜻: 학습된 모델이 실제 생성 시점에 출력을 고르는 방식을 조절하는 바깥 설정값입니다. temperature, top-p, max tokens처럼 모델 내부에 학습되어 저장된 파라미터가 아니라, 이미 학습된 모델을 사용할 때 후보 선택 방식과 출력 길이 등을 조정하는 값입니다.
- 왜 중요한가: 생성 설정값을 모델 파라미터와 섞으면 `모델이 무엇을 배웠는가`와 `이번 실행에서 어떻게 꺼내 쓰는가`를 혼동하게 됩니다. 이 개념이 있어야 같은 모델이라도 설정에 따라 출력 다양성, 길이, 안정성이 달라질 수 있음을 이해하고, 생성 결과를 비교할 때 모델 이름뿐 아니라 설정값도 함께 기록해야 한다는 점을 읽게 됩니다.
- 함께 볼 개념: `파라미터(parameter)`, `하이퍼파라미터(hyperparameter)`, `temperature`, `샘플링(sampling)`
- 중심 Section: `P1-4.3`
- 등장 Section: `P1-6.3`, `P6-6.2`
