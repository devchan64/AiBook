### 입력 명세(input specification)

- 뜻: 모델이나 학습 단계에 넘길 입력을 어떤 단위, 열, 순서, 구조로 볼지 미리 정리한 설명입니다. 단순히 파일을 넣는 일이 아니라, 무엇을 사례로 볼지, 어떤 특징을 남길지, 순서나 구간 정보를 어떤 형태로 표현할지 정하는 작업입니다.
- 왜 중요한가: 입력 명세가 분명해야 사람이 만든 특징과 모델이 뒤에서 학습할 표현을 구분할 수 있습니다. Part 3의 특징 설계는 `모델이 무엇을 입력으로 받아야 하는가`를 먼저 정하는 단계이고, 표현 학습은 그 입력 안에서 모델이 더 유용한 내부 표현을 배우는 단계입니다. 이 구분이 흐려지면 특징 설계를 낡은 전처리로만 보거나, 반대로 모델이 문제 구조까지 자동으로 정해 준다고 오해하기 쉽습니다.
- 함께 볼 개념: `특징(feature)`, `중간 표현(intermediate representation)`, `표현 학습(representation learning)`
