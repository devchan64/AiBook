## SHAP

- Meaning: SHAP is a model-interpretation method that tries to attribute one prediction to contributions from individual features.
- Why it matters: Unlike feature importance, which summarizes whole-model usage, SHAP is used when we ask which features pushed one specific prediction up or down.
- Related concepts: `feature importance`, `partial dependence plot(PDP)`, `interpretation boundary`
