## kernel PCA

- Meaning: Kernel PCA is a nonlinear dimensionality-reduction method that uses kernels to expose structure that may not be easy to read with straight axes in the original space.
- Why it matters: It helps distinguish linear reexpression by PCA from attempts to unfold nonlinear structure through a kernel space.
- Related concepts: `kernel`, `PCA`, `dimensionality reduction`
