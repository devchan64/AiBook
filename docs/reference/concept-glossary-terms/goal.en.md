## goal

- Meaning: A goal states the result to reach or the work to finish in a form that can guide action. It is more concrete than a broad wish because it helps decide when the current run can be considered complete.
- Why it matters: In AI agent execution, an unclear goal makes planning, tool choice, and stopping conditions unstable. A goal sets the boundary before detailed planning begins and separates the wider problem from what this execution should actually finish.
