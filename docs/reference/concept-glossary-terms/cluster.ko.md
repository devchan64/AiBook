### 군집(cluster)

- 뜻: 데이터 안에서 서로 비슷하다고 판단되어 한 묶음으로 놓인 사례들의 집합입니다. 여기서 군집은 사람이 미리 붙인 분류 이름이 아니라, 거리·유사도·밀도 같은 기준으로 알고리즘이 찾아낸 묶음입니다.
- 왜 중요한가: 군집을 분류 라벨과 혼동하면 비지도학습 결과를 과하게 해석하기 쉽기 때문입니다. 이 개념이 있어야 `0번 군집`, `1번 군집` 같은 번호가 곧 의미 있는 사람 언어 이름은 아니며, 묶인 뒤에 해석이 필요하다는 점을 이해할 수 있습니다.
- 함께 볼 개념: `군집화(clustering)`, `분류(classification)`, `지도학습 라벨(supervised learning label)`, `유사도(similarity)`
