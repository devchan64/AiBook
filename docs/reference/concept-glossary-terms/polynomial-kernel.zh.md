## 多项式核(polynomial kernel)

- 含义: 更容易读出平方、乘积、更高次 feature combination 等多项式交互的 kernel。
- 为什么重要: 当 class 的分离更依赖 feature 之间的组合，而不是单个 feature 时，polynomial kernel 可以在 representation space 中更强地强调这些 interaction。
- 相关概念: `核函数(kernel)`, `特征空间(feature space)`, `交互特征(interaction feature)`, `SVM`
