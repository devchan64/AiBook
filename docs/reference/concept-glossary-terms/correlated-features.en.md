## correlated features

- Meaning: Correlated features are features that move together in similar directions or carry nearly the same information.
- Why it matters: Even when one feature appears to have low importance, another correlated feature may already be providing similar information. Reading importance only as a per-column ranking can therefore mislead interpretation.
- Related concepts: `feature importance`, `correlation`
