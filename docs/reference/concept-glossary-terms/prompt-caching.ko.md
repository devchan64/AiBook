### 프롬프트 캐싱(prompt caching)

- 뜻: 반복해서 쓰이는 프롬프트 앞부분이나 입력 맥락을 다시 계산하지 않도록 저장해 재사용하는 최적화 방식입니다. 일반 캐싱이 계산 결과를 저장해 재사용하는 개념이라면, 프롬프트 캐싱은 특히 모델 호출의 입력 토큰 처리 비용과 시간을 줄이는 데 초점을 둡니다.
- 왜 중요한가: 긴 시스템 지시문이나 반복되는 문서 맥락을 매번 새로 처리하면 비용과 지연 시간이 커집니다. 프롬프트 캐싱을 이해해야 프롬프트 구조, 비용, 지연 시간, 서비스 제약이 서로 연결된 운영 문제라는 점을 더 구체적으로 볼 수 있습니다.
- 함께 볼 개념: `프롬프트(prompt)`, `캐싱(caching)`, `토큰(token)`, `비용(cost)`
