### 명령(command)

- 뜻: 터미널이나 셸에게 지금 수행하라고 요청하는 실행 문장입니다. 자연어 문장이 아니라 셸이 정한 규칙에 따라 프로그램 실행, 폴더 이동, 파일 목록 확인 같은 작업으로 해석되는 입력입니다. 따라서 명령은 Python 코드와 모양이 비슷해 보여도, 어디에 입력하고 누가 해석하는지에 따라 전혀 다른 층위의 실행 요청이 됩니다.
- 왜 중요한가: 초심자는 `python example.py`, `python -m pip install numpy`, `print("hello")`를 모두 Python 관련 문장으로 묶어 오해하기 쉽기 때문입니다. 명령을 구분하면 터미널에서 셸이 읽는 실행 요청과 Python 인터프리터가 읽는 코드 문장을 나누어 볼 수 있고, 오류가 났을 때 입력 위치 문제인지 코드 문법 문제인지도 더 빨리 판단할 수 있습니다. 결국 명령은 로컬 실습에서 `무엇을 실행하라고 요청했는가`를 읽는 가장 작은 단위입니다.
- 함께 볼 개념: `터미널(terminal)`, `셸(shell)`, `Python 인터프리터(interpreter)`
