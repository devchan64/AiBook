### one-vs-rest

- 含义：one-vs-rest 会把 multiclass classification 拆成多个二元问题：`是不是这个 class`。
- 为什么重要：它和 multinomial logistic regression 的比较结构不同。这个概念能帮助读者区分 `每个 class 分开检查后再比较` 和 `所有 class 一次性放在一起比较`。
- 相关概念：`multinomial logistic regression`, `softmax`, `classification`
- 中心 Section：`P4-11.4`
