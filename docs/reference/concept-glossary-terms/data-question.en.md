### data question

- Meaning: A data question is a problem-design sentence that states what counts as one case, what should be compared, and what the analysis ultimately wants to know.
- Why it matters: If the question starts with model choice, the dataset can be forced to fit that choice later. A data question fixes the sample unit, table structure, features, baseline, and output structure before model names take over.
- Related concepts: `data modeling`, `sample`, `baseline`, `output structure`, `task definition`
