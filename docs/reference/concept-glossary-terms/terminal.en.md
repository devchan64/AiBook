## terminal

- Meaning: 명령을 입력하고 결과를 보는 문자 기반 창 또는 앱입니다. 셸이 명령을 해석한다면, 터미널은 그 셸과 사람이 만나는 작업 창에 가깝습니다. 초심자 입장에서는 `코드를 적는 편집기`와 달리 `코드를 실행하고 시스템 상태를 확인하는 창`으로 구분해 이해하면 됩니다.
- Why it matters: Python 실행, 가상환경 활성화, 패키지 설치, 파일 확인처럼 로컬 실습의 많은 단계가 터미널에서 시작되기 때문입니다. 터미널을 알아야 코드 작성과 환경 운영이 서로 다른 층위라는 점이 분명해지고, `프로그램 안의 오류`와 `실행 전에 준비가 안 된 문제`도 더 잘 구분하게 됩니다. 즉 터미널은 단순 입력창이 아니라, 코드를 둘러싼 실행 환경을 다루는 기본 작업장이라는 감각을 만들어 줍니다. AI 에이전트나 자동화 도구가 실행한 명령을 읽을 때도, 실제로 무엇이 시스템에 적용되는지 이해하는 기본 문해력이 됩니다.
