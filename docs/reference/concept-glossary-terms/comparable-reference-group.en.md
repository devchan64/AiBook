### comparable reference group

- Meaning: A comparable reference group is the set of past cases kept as the baseline comparison because they share the same sample unit and operating conditions as the current sample. It is not just a large pile of old data; it is a filtered reference group that answers what the current sample may fairly be compared against.
- Why it matters: If the reference group mixes different processes, lengths, or operating states, a difference value may still be calculated, but its interpretation becomes unstable. This concept frames baseline selection as narrowing comparable candidates, not as picking one old average.
