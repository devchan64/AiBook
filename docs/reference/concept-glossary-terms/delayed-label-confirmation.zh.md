### 标签确认延迟

- 含义：标签确认延迟是指真实结果可能已经发生，或之后才会被确认，但在当前时点还没有闭合成答案标签。它是确认时间的问题，不等于结果没有发生。
- 为什么重要：如果把确认延迟和 0 或缺失值混在一起，最近案例可能会显得过早安全，临时状态也可能被当成已确认标签使用。这个概念帮助区分“结果晚一点才闭合”和“可以说没有发生结果”，并要求记录贴标签的截止时点和追踪期。
- 相关概念：`标签`，`目标标签候选`，`观察未完成的负例`，`provenance`
- 核心 Section：`P3-9.10`
- 出现 Section：`P3-9.10`
