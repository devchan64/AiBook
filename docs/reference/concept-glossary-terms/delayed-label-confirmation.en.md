### delayed label confirmation

- Meaning: Delayed label confirmation is the state where the real outcome may exist or become known later, but it has not yet closed as an answer label at the current point in time. It is a timing problem, not the same as saying the result did not occur.
- Why it matters: If delayed confirmation is mixed with 0 or missing values, recent cases can look safer than they are, or temporary states can be used as confirmed labels. This concept separates late-closing outcomes from true negatives and makes the label cutoff time and follow-up period explicit.
- Related concepts: `label`, `target candidate`, `incomplete negative`, `provenance`
