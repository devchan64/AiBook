### 서비스(service)

- 뜻: 사용자가 실제로 이용하는 제공 형태와 운영 구조입니다. 모델 하나나 내부 시스템 부품 하나가 아니라, 화면, 입력 수집, 결과 표시, 저장, 권한, 오류 처리, 사람 검토, 외부 연결까지 포함해 사용자가 경험하는 전체 제공 단위라고 볼 수 있습니다.
- 왜 중요한가: `모델이 좋다`와 `서비스가 좋다`는 같은 말이 아니기 때문입니다. 좋은 모델이 있어도 입력 화면이 부실하거나, 정책 규칙이 낡았거나, 사람 검토와 오류 처리가 약하면 실제 서비스 품질은 흔들릴 수 있습니다. 이 개념이 있어야 모델, 시스템, 앱, 운영을 한 덩어리로 섞지 않고, 사용자가 만나는 AI 기능이 여러 층의 조합이라는 점을 읽게 됩니다.
- 함께 볼 개념: `모델(model)`, `시스템(system)`, `앱(application)`, `서비스 운영(service operation)`
