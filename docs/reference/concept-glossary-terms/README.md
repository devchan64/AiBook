# Concept Glossary Term Sources

This directory holds source files for individual concept glossary entries.

Each entry file is named with the English base term as a kebab-case slug and a language suffix:

- `<english-slug>.ko.md`
- `<english-slug>.en.md`
- `<english-slug>.zh.md`

Language-specific glossary index pages keep their own ordering structure and include these files through `pymdownx.snippets`.
