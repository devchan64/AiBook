## axis label

- Meaning: An axis label explains what the horizontal or vertical axis of a plot represents. It names the value, quantity, or unit placed along that direction.
- Why it matters: Without axis labels, a plot can show a shape while hiding the question it answers. Axis labels provide the minimum context needed to interpret a visualization.
