## off-policy

- Meaning: Off-policy learning learns values for a policy that is not necessarily the same as the policy currently producing behavior. Q-learning is a common example because it updates from the best-looking next action.
- Why it matters: It explains how learning can aim toward a target or optimal policy even while the actual behavior includes exploration. This is the key contrast with on-policy learning.
- Related concepts: `Q-learning`, `on-policy`, `policy`, `exploration`
