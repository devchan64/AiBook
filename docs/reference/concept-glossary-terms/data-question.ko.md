### 데이터 질문(data question)

- 뜻: 데이터로 무엇을 한 건으로 보고, 무엇을 무엇과 비교하며, 최종적으로 무엇을 알고 싶은지 드러내는 문제 설계 문장입니다. 단순한 궁금증이 아니라, 뒤의 샘플 단위, 표 구조, 특징, 기준선, 출력 구조를 결정하게 만드는 질문입니다.
- 왜 중요한가: 질문이 `어떤 모델을 쓸까`로 먼저 닫히면 데이터셋 설계가 뒤따라 끼워 맞춰지기 쉽습니다. 데이터 질문을 먼저 쓰면 같은 원천데이터도 어떤 샘플과 비교 구조로 다시 읽어야 하는지 분명해지고, 검토 후보 큐와 목표 라벨 후보의 방향도 갈라집니다.
- 함께 볼 개념: `데이터 모델링(data modeling)`, `샘플(sample)`, `기준선(baseline)`, `출력 구조(output structure)`, `문제 정의(task definition)`
