### 실제 값(true value)

- 뜻: 추정하려는 대상의 실제 값입니다. 통계 추정에서는 모집단의 실제 평균이나 비율처럼 우리가 알고 싶지만 직접 알기 어려운 값으로 등장합니다.
- 왜 중요한가: 추정값과 실제 값의 차이를 오차로 읽기 위한 기준점이기 때문입니다. 실제 값을 모르는 경우가 많다는 점을 이해해야, 추정값을 확정 진실이 아니라 불확실성을 가진 판단 근거로 읽게 됩니다.
- 함께 볼 개념: `추정(estimation)`, `오차(error)`, `모집단(population)`
