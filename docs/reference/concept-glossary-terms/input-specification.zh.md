### 输入说明(input specification)

- 含义：说明要把什么样的单位、列、顺序和结构交给模型或后续学习阶段作为输入。它不只是把一个文件交给模型，而是先决定什么算一个样本、保留哪些特征、顺序或区段信息要用什么形式表示。
- 为什么重要：输入说明清楚之后，才能区分人工设计的特征和模型后面学到的表示。在 Part 3 中，特征设计先回答 `模型应该接收什么输入`；表示学习则是在这个输入之内，由模型在后续训练中发生的事。如果这个边界不清楚，就容易把特征设计误读成过时的预处理，或者误以为模型会自动替人决定整个问题结构。
- 相关概念：`特征`，`中间表示`，`表示学习`

- 出现 Section：`P3-6.3`
