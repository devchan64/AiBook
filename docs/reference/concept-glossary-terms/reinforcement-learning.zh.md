## 强化学习

- 含义: 强化学习是让强化学习AI 智能体或强化学习智能体在状态中选择行动，并根据行动之后得到的奖励来调整策略的机器学习问题。
- 为什么重要: 强化学习的信号不是监督学习中的标签，而是行动之后返回的奖励。这个区别能防止把强化学习误读成“自动尝试很多次就会变好”的简单过程。
- 相关概念: `智能体状态(state)`, `行动(action)`, `奖励(reward)`, `强化学习策略(reinforcement learning policy)`, `强化学习智能体(reinforcement learning agent)`
