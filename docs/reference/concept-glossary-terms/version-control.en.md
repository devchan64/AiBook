## version control

- Meaning: Version control is a way to record how files and folders change over time, why those changes happened, and how to find an earlier state again. It is closer to a traceable history of decisions than to a pile of backup copies.
- Why it matters: Saving a file preserves the current content, but it does not explain the change. Version control keeps writing, code, assets, review, rollback, and deployment history readable as connected change units.
- Related concepts: `commit`, `repository`, `change history`
