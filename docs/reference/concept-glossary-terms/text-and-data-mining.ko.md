### 텍스트·데이터 마이닝(text and data mining, TDM)

- 뜻: 많은 텍스트나 데이터를 분석해 패턴, 통계, 관계를 찾는 처리 방식입니다. AI 학습 데이터 논쟁에서는 자료를 읽고 분석하는 행위가 어느 범위까지 허용되는지와 연결되어 논의됩니다.
- 왜 중요한가: 일부 지역에서는 연구나 데이터 분석을 위한 예외 규정으로 텍스트·데이터 마이닝을 다루지만, 모든 자료 사용이 자동으로 허용된다는 뜻은 아닙니다. 이 개념을 구분해야 모델 학습, 자료 분석, 원문 재배포를 같은 문제로 묶지 않게 됩니다.
- 함께 볼 개념: `학습 데이터(training data)`, `저작권(copyright)`, `공정 이용(fair use)`
