## linear combination

- Meaning: A linear combination is a calculation that multiplies several values or vectors by scalar weights and then adds the results. In a perceptron, it appears as a score such as \(w_1x_1 + w_2x_2 + b\).
- Why it matters: This is the basic calculation pattern behind matrix multiplication, linear layers, and the first score a neural network makes before applying activation. It helps readers see that `multiply and add` is not just arithmetic, but a way to create a new representation or decision score from inputs.
- Related concepts: `weighted sum`, `scalar multiplication`, `vector addition`, `activation function`
