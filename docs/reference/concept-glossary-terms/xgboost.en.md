## XGBoost

- Meaning: XGBoost is a tree-boosting system in the gradient-boosting family. It emphasizes regularization, sparse-data handling, approximate tree learning, cache-aware structure, data compression, and distributed scalability.
- Why it matters: XGBoost helps readers see boosting not only as a model name, but as an implementation system for running boosting stably at larger scale. It shows why scalability, sparse inputs, and computation structure can become criteria when choosing among gradient-boosting implementations.
- Related concepts: `gradient boosting`, `sparsity`, `distributed training`
