### 검증 데이터(validation data)

- 뜻: 학습 중 모델 설정을 확인하고 조정하는 데 쓰는 데이터입니다. 훈련 데이터처럼 직접 학습에 쓰는 데이터도 아니고, 최종 확인용 테스트 데이터와도 구분됩니다.
- 왜 중요한가: 낮은 훈련 손실만으로 현실 성능을 보장할 수 없기 때문입니다. 검증 데이터를 이해하면 학습 중 모델이 새 데이터에도 잘 맞는지 중간 점검하고, 하이퍼파라미터나 학습 중단 시점을 판단하는 별도 표본이 필요하다는 점을 볼 수 있습니다.
- 함께 볼 개념: `훈련 데이터(training data)`, `테스트 데이터(test data)`, `일반화(generalization)`
- 중심 Section: `P2-6.2`
- 등장 Section: `P4-4.1`, `P4-4.2`, `P4-5.1`, `P4-5.2`
