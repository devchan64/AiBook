## tanh

- Meaning: Tanh is a zero-centered S-shaped function that compresses an input score into a value between -1 and 1. Negative inputs remain negative, positive inputs remain positive, and 0 maps to 0.
- Why it matters: It gives a simple contrast with the sigmoid. Both compress values, but tanh preserves direction around 0, which helps explain how hidden-layer representations can carry signed signals.
- Related concepts: `activation function`, `sigmoid`, `ReLU`, `hidden layer`
