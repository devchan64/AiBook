### 외부 시스템(external system)

- 뜻: 모델이나 앱 내부가 아니라, 도구 호출을 통해 연결되는 바깥 서비스, 파일 시스템, 데이터베이스, API 같은 실행 대상입니다. 외부 시스템은 참고 정보를 돌려줄 수도 있고 실제 상태를 바꿀 수도 있으므로, 단순한 배경 지식과는 구분해야 합니다.
- 왜 중요한가: AI 서비스의 실패와 책임은 모델 안에서만 생기지 않습니다. 외부 시스템을 구분해야 검색 실패, 권한 문제, 상태 변경, API 오류를 모델 답변 품질 문제와 나누어 볼 수 있고, 승인과 로그가 왜 필요한지도 더 분명해집니다.
- 함께 볼 개념: `도구 사용(tool use)`, `도구 호출(tool call)`, `권한(permission)`, `로그(log)`
