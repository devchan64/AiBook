## 学习型方法

- 含义: 学习型方法不是由人写出所有判断规则，而是从案例数据中拟合输入和输出之间的关系，形成模型的判断标准。
- 为什么重要: 它能避免把机器学习误解成“直接发现人能读懂的规则”。因为判断标准来自数据拟合，所以数据质量、标签和评估设计会变得关键。
- 相关概念: `机器学习(machine learning)`, `特征(feature)`, `监督学习标签(supervised learning label)`, `模型(model)`, `模型评估设计(evaluation design)`
