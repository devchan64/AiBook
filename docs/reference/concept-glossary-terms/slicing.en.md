## slicing

- Meaning: Slicing is a selection method that keeps a continuous range from an array, list, or similar structure by using start and stop positions. Unlike indexing, it keeps a span rather than one exact location.
- Why it matters: Slicing changes whether code reads one value, one range, or a sub-array. In array computation, that distinction affects shape and can also affect whether the result shares data with the original.
- Related concepts: `indexing`, `axis`, `shared view`
