## 评估模式

- 含义: 评估模式是为了稳定测量或实际使用模型而采用的执行状态。与训练模式不同，它通常会关闭 dropout 这类随机行为，并使用已积累的统计量来得到更稳定的输出。
- 为什么重要: 验证、测试和部署时，需要把训练中的随机扰动和 batch 依赖性降到更低，才能更公平地读模型表现。理解评估模式也有助于区分模型本身的问题和执行模式设置错误。
- 相关概念: `training`, `training mode`, `test`
