### 가중치 행렬(weight matrix)

- 뜻: 여러 입력값을 여러 출력값으로 바꾸기 위해 가중치들을 행과 열 구조로 모아 놓은 행렬입니다. 한 열이나 한 행은 특정 출력값을 만들기 위한 가중치 묶음으로 읽을 수 있으며, 입력 벡터와 곱해 새 출력 벡터를 만듭니다. 즉 가중치 행렬은 여러 가중합을 한꺼번에 재사용하게 하는 계산 구조입니다.
- 왜 중요한가: 신경망 층과 선형 변환을 읽을 때 `입력 차원과 출력 차원이 어떻게 연결되는가`를 보여 주는 핵심 대상이기 때문입니다. 가중치 행렬을 이해하면 shape 오류도 단순 코드 문제가 아니라 입력 개수와 출력 개수의 대응 문제로 읽을 수 있습니다. 이 개념이 있어야 모델 파라미터가 벡터나 행렬 형태를 가질 수 있다는 설명도 자연스럽게 이어집니다.
- 함께 볼 개념: `가중합(weighted sum)`, `행렬 곱(matrix multiplication)`, `가중치(weight)`
