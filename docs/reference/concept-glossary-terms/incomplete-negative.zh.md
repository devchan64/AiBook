### 观察未完成的负例

- 含义：观察未完成的负例，是指因为必要的追踪期还没有结束，所以暂时看起来像 0 的案例。已闭合负例表示经过充分观察后仍然没有结果；观察未完成的负例则表示现在还没有足够观察依据来说没有结果。
- 为什么重要：如果把观察未完成的负例当成已闭合的 0 来训练，模型可能会把最近案例学得过于安全。这个概念要求把必要追踪期、`pending` 状态和标签确认规则作为数据建模条件留下来。
- 相关概念：`标签确认延迟`，`标签`，`目标标签候选`，`选择性标签`

- 出现 Section：`P3-9.10`
