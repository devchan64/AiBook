## 期望奖励(expected reward)

- 含义: expected reward 是 policy 在可能的 actions、outcomes 或 trajectories 上平均预期得到的 reward。
- 为什么重要: policy-based reinforcement learning 常把 policy parameters 朝 expected reward 增大的方向调整，所以公式不能只按一次 observed reward 来读。
- 相关概念: `reward`, `policy-based reinforcement learning`, `policy`
