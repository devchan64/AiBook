### 원천 사건(source event)

- 뜻: 입력 창이나 요약 행으로 잘라 내기 전 실제로 발생한 원래 사건 단위입니다. 예를 들어 동작 1회, 알람 1건, 세션 1회처럼 파생 입력 조각의 출발점이 되는 실제 사례를 가리킵니다.
- 왜 중요한가: 같은 원천 사건에서 겹치는 입력 창을 많이 만들면 모델 입력 조각 수는 커지지만 실제 사건 수가 늘어난 것은 아닙니다. 이 개념이 있어야 파생된 창 수를 증거 수처럼 과장해서 읽지 않고, 대표성 판단과 평가 분할에서 같은 사건에서 나온 조각들을 함께 추적할 수 있습니다.
- 함께 볼 개념: `입력(input)`, `원천데이터(source data)`, `샘플(sample)`, `데이터셋(dataset)`, `데이터 누수(data leakage)`
- 중심 Section: `P3-5.6`
- 등장 Section: `P3-5.6`, `P3-5.7`
