## 状态价值(state value)

- 含义: 状态价值表示处在某个状态时，之后预期能得到多少长期回报。它关注的不是某一个具体行动，而是`处在这个状态整体上有多好`。
- 为什么重要: 它帮助读者区分状态本身的好坏与在该状态下采取某个行动的好坏。理解 state value 之后，action value 为什么更直接服务于行动选择也会更清楚。
- 相关概念: `reinforcement learning`, `state`, `action value`, `value-based reinforcement learning`
