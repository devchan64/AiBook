## shape

- Meaning: Shape describes how many dimensions an array or tensor has and how many values lie along each axis.
- Why it matters: Shape is the first structural check for vector, matrix, batch, broadcasting, slicing, and matrix multiplication operations.
- Related concepts: `dimension`, `vector`, `matrix`
