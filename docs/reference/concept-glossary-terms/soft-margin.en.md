## soft margin

- Meaning: The SVM viewpoint that allows some errors or boundary intrusions instead of insisting that every training case be separated perfectly, while still searching for an overall meaningful margin.
- Why it matters: Real data can contain noise, exceptions, and overlapping cases. If perfect separation is forced, the boundary can become too tight. Soft margin helps the reader read the balance between `a boundary with room` and `acceptable error`.
