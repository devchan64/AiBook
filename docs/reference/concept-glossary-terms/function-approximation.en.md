## function approximation

- Meaning: Function approximation expresses values with a function or model that estimates the value from an input, instead of storing every value directly in a table.
- Why it matters: When the state space becomes large, a Q-table becomes difficult to manage, so function approximation carries the value-based intuition into larger problems.
- Related concepts: `Q-table`, `DQN`, `value-based reinforcement learning`
