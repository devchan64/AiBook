### 目标定义版本

- 含义：目标定义版本记录同名目标采用的是哪一套标准、哪一个时间段的定义。判定标准、标注规则或运营政策变化时，同一个列名也可能指向不同的目标定义。
- 为什么重要：如果把标准变化前后的值当成同一个答案来混用，模型可能会同时学习几个不同问题。这个概念要求记录标签规则及其开始适用的时点，而不只是记录列名。
- 相关概念：`代表目标`，`目标`，`版本控制`，`provenance`
- 核心 Section：`P3-9.11`
- 出现 Section：`P3-9.11`
