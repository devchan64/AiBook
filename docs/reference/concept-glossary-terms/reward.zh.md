## 奖励

- 含义: 奖励是在强化学习中，强化学习智能体采取行动后从环境返回的反馈信号。它表示当前行动结果在任务目标上有多好或多坏。
- 为什么重要: 奖励不是监督学习里的正确答案标签。它通常在行动之后出现，并通过长期结果影响策略调整。
- 相关概念: `reinforcement learning`, `action`, `state`, `reinforcement learning policy`
