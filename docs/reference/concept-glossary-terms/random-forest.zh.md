## 随机森林

- 含义: 随机森林是把许多决策树组合起来进行预测的集成模型。每棵树只看到部分数据或部分特征，最后把多个树的判断合并起来。
- 为什么重要: 随机森林通常比单棵决策树更稳定，也能处理不少表格数据问题。它帮助读者理解为什么多个有差异的树组合后可以得到更可靠的预测，也能和按顺序修正错误的梯度提升区分开来。
- 相关概念: `决策树(decision tree)`, `集成(ensemble)`, `bootstrap`, `基准模型(baseline model)`
