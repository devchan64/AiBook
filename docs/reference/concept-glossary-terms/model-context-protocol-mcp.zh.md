## 模型上下文协议，MCP

- 含义：模型上下文协议是一种开放协议，用共同方式把 AI 应用连接到外部工具、资源和提示。
- 为什么重要：MCP 让AI 智能体和 AI 应用系统中的外部能力发现与调用更一致。
- 相关概念：`工具使用(tool use)`，`AI 智能体(AI agent)`，`权限(permission)`，`最小权限(least privilege)`
- 中心 Section：`P6-16.1`
- 出现 Section：`P1-14.3`, `P1-14.4`, `P1-14.5`, `P6-16.2`
