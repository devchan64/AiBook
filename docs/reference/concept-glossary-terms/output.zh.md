## 输出(output)

- 含义: 输出是代码、模型或计算过程返回给读者或下一步处理的结果。它可以是数字、文本、表、图、错误消息，也可以是模型生成的回答。
- 为什么重要: 读代码或模型结果时，必须区分输入、处理过程和输出。理解输出也能帮助读者判断结果是最终答案、中间结果，还是需要继续解释的信号。
- 相关概念: `输入(input)`, `输出格式(output format)`, `结果解释表(result interpretation table)`

- 出现 Section: `P1-5.2`, `P1-12.1`, `P2-10.3`
