### 접기 규칙(folding rule)

- 뜻: 여러 행, 여러 사건, 여러 값을 하나의 대표 결과 열로 줄일 때 쓰는 명시적 기준입니다. 예를 들어 후속 사건 여러 개를 `any`, `first`, `worst`, `count` 가운데 무엇으로 남길지 정하는 규칙입니다.
- 왜 중요한가: 같은 원천 사건 뒤에 같은 후속 사건이 있어도 접기 규칙이 다르면 결과 열의 뜻이 달라지기 때문입니다. 이 개념이 있어야 결과 열이 단순히 `데이터에서 나온 값`이 아니라, 어떤 대표 기준과 임계값을 적용해 만든 해석 구조라는 점을 읽을 수 있습니다. 접기 규칙을 적어 두면 보고용 결과와 목표 라벨 후보를 섞어 읽는 위험도 줄어듭니다.
- 함께 볼 개념: `원천 사건(source event)`, `샘플(sample)`, `라벨(label)`, `목표 라벨 후보(target candidate)`, `임계값(threshold)`
