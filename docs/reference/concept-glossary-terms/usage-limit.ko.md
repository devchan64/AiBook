### 사용량 제한(usage limit)

- 뜻: 일정 기간이나 계정 범위 안에서 사용할 수 있는 요청 수, 토큰 수, 비용, 기능 접근 범위를 제한하는 운영 규칙입니다. 레이트 리밋이 짧은 시간의 호출 속도에 초점을 둔다면, 사용량 제한은 더 넓은 기간의 총 사용량과 할당량을 보는 경우가 많습니다.
- 왜 중요한가: AI 서비스 운영에서는 실패가 모델 품질이 아니라 계정 한도, 예산 한도, 기능 제한에서 생길 수 있습니다. 이 개념이 있어야 요청 설계, 배치 처리, 캐싱, 예산 관리가 모두 서비스 품질과 연결된다는 점을 이해할 수 있습니다.
- 함께 볼 개념: `레이트 리밋(rate limit)`, `비용(cost)`, `처리량(throughput)`, `운영(operation)`
