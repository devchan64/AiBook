## ReLU(rectified linear unit)

- Meaning: ReLU is an activation function that cuts negative inputs to 0 and passes nonnegative inputs through almost unchanged. It is usually written as \(f(z)=\max(0,z)\).
- Why it matters: ReLU is a standard activation function in modern deep learning. Unlike sigmoid and tanh, it does not saturate in the positive range, so it is a key comparison point when reading how signals survive through hidden layers.
- Related concepts: `activation function`, `sigmoid`, `tanh`, `hidden layer`
