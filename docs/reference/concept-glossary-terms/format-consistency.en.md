### format consistency

- Meaning: Format consistency is the state where values with the same meaning use stable formats, units, and notation rules so later comparison and ordering do not drift.
- Why it matters: If key formats, time formats, units, or string rules are mixed, the same object can be read as different objects or time order can be misread. Checking format consistency first helps separate data-quality problems from problem-representation design problems.
- Related concepts: `data quality check`, `identifier`, `row`
- Core Section: `P3-2.3`
