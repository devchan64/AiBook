### 앙상블(ensemble)

- 뜻: 여러 모델의 예측을 모아 하나의 최종 판단을 만드는 방법입니다. 단일 모델 하나의 판단보다 더 안정적이거나 더 강한 결과를 얻기 위해 평균, 투표, 순차 보정 같은 결합 방식을 사용합니다.
- 왜 중요한가: 앙상블을 이해해야 랜덤포레스트, 그래디언트 부스팅, 배깅처럼 여러 모델을 쓰는 방법을 같은 이름으로 뭉개지 않고 구분할 수 있습니다. 핵심은 `모델을 여러 개 쓴다`가 아니라 `어떤 방식으로 결합하느냐`입니다.
- 함께 볼 개념: `랜덤포레스트(random forest)`, `그래디언트 부스팅(gradient boosting)`, `평균(averaging)`, `투표(voting)`
