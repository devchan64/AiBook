### 앙상블(ensemble)

- 뜻: 여러 모델의 예측을 모아 하나의 최종 판단을 만드는 방법입니다. 단일 모델 하나의 판단보다 더 안정적이거나 더 강한 결과를 얻기 위해 평균, 투표, 순차 보정 같은 결합 방식을 사용합니다.
- 왜 중요한가: 앙상블을 이해해야 독립적으로 만든 모델을 평균내는 방식, 여러 모델의 투표를 모으는 방식, 앞 단계 오류를 다음 단계가 보정하는 방식처럼 결합 구조를 구분할 수 있습니다. 핵심은 `모델을 여러 개 쓴다`가 아니라 `어떤 방식으로 결합하느냐`입니다.
- 함께 볼 개념: `결정트리(decision tree)`, `과적합(overfitting)`, `오차(error)`

- 등장 Section: `P4-15.1`, `P4-16.1`
