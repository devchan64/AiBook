### 집합(set)

- 뜻: 값의 중복보다 포함 여부를 중심으로 다루는 자료구조입니다. 어떤 값이 들어 있는지, 두 묶음이 무엇을 공유하는지, 중복을 제거하면 무엇이 남는지를 볼 때 쓰는 구조 감각입니다.
- 왜 중요한가: 리스트처럼 순서대로 읽는 구조와 달리, 집합은 `있는가 없는가`를 먼저 묻기 때문입니다. 이 개념이 있어야 중복 제거, 라벨 종류 확인, 공통 항목 비교처럼 포함 여부가 중심인 작업을 순서 처리 문제와 구분할 수 있습니다.
- 함께 볼 개념: `자료구조(data structure)`, `연산(operation)`, `딕셔너리(dictionary)`
