### 라벨 예측(label prediction)

- 뜻: 입력 사례에 대해 이미 정의된 목표 라벨을 맞히도록 문제를 세우는 단계입니다. 경고나 검토 후보보다 더 강한 문제 설정이며, 안정된 라벨과 학습·평가 구조가 필요합니다.
- 왜 중요한가: 결과 메모가 조금 있다는 이유만으로 라벨 예측을 시작하면, 약한 라벨 품질을 복잡한 분류 문제로 덮어 버릴 수 있습니다. 라벨 예측은 앞 단계의 비교 신호와 검토 구조를 거쳐 목표 라벨이 충분히 안정된 뒤에 검토해야 합니다.
- 함께 볼 개념: `라벨(label)`, `타깃(target)`, `분류(classification)`, `인간 감독(human oversight)`

- 등장 Section: `P3-9.1`, `P3-9.2`
