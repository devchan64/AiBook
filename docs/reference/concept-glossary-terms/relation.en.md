## relation

- Meaning: A relation is structural information about how two entities are connected or correspond to each other. A table can record one relation per row, while a graph can represent relations as edges between nodes.
- Why it matters: Data structure choices change depending on whether a relation is treated as an attribute record or as a connection to follow. This concept helps readers distinguish table questions from graph questions.
- Related concepts: `graph`, `edge`, `data structure`
