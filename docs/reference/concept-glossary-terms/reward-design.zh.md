## 奖励设计(reward design)

- 含义: reward design 是用 reward function 和约束条件定义强化学习 强化学习智能体到底应该把什么看成做得好。它不是单纯实现一个数字，而是在定义系统目标。
- 为什么重要: 如果 reward 只是粗糙代替真实目标，强化学习智能体可能把数字抬高，却错过人的意图。因此 reward design 是检查 reward hacking、安全性和部署风险的起点。
- 相关概念: `奖励(reward)`, `真实目标(true objective)`, `奖励黑客(reward hacking)`, `代理目标(proxy target)`
