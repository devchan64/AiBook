### target definition version

- Meaning: A target definition version records which criteria and time period a target with the same name follows. If judgment criteria, labeling rules, or operating policy change, the same column name may refer to a different target definition.
- Why it matters: Mixing values from before and after a criteria change can train one model on several different problems at once. This concept makes the label rule and the point from which it applies part of the target record, not just the column name.
- Related concepts: `representative target`, `target`, `version control`, `provenance`
