## 强化学习智能体

- 含义：在强化学习中，强化学习智能体是根据当前状态或观察选择行动、接收奖励并调整策略的学习主体。它不只是执行器，而是在环境中互动、积累经验，并用这些经验改变之后行动标准的主体。
- 为什么重要：这个词把环境中通过行动结果进行学习的主体，和连接工具调用、任务流程的服务型 AI 智能体区分开来。同一个普通英语词 `agent` 可能出现在两个语境里，但它们的学习角色、运行层位和失败模式并不相同。
- 相关概念：`强化学习`，`行动`，`奖励`
