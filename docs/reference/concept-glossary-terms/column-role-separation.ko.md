### 열 역할 분리(column-role separation)

- 뜻: 하나의 작업 표 안에 있는 열을 모두 같은 종류로 보지 않고, 특징 열, 비교 열, 결과 후보 열, 식별·문맥 열처럼 역할별로 나누어 읽는 일입니다. 열의 값 형식이 숫자인지 문자인지보다 `왜 이 열을 만들었는가`를 먼저 확인합니다.
- 왜 중요한가: 요약 표에는 사람이 읽기 위한 비교 정보와 모델 입력 후보, 나중에 맞히고 싶은 결과 후보가 잠시 함께 들어갈 수 있습니다. 열 역할 분리를 하지 않으면 숫자 열을 모두 특징으로 착각하거나, 결과 후보를 입력 특징에 섞어 데이터 누수로 이어질 수 있습니다. 이 구분이 있어야 Part 3의 작업 표를 모델 입력 표로 넘기기 전에 어떤 열을 남기고 제외할지 설명할 수 있습니다.
- 함께 볼 개념: `요약표(summary table)`, `특징(feature)`, `타깃(target)`, `데이터 누수(data leakage)`
- 중심 Section: `P3-6.4`
- 등장 Section: `P3-6.4`, `P3-8.5`
