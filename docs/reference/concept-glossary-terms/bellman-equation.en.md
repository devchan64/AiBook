## Bellman equation

- Meaning: The Bellman equation is a recursive value expression that connects the value of a state or action to the reward now and the future value that continues from the next state.
- Why it matters: It is a basic handle for understanding why value-based reinforcement learning updates action values and state values repeatedly.
- Related concepts: `action value`, `state value`, `reward`, `convergence`
