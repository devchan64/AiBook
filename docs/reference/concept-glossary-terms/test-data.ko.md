### 테스트 데이터(test data)

- 뜻: 모델 학습에 직접 쓰지 않고, 학습된 모델이 새 데이터에서 얼마나 잘 동작하는지 확인하기 위해 따로 둔 데이터입니다. 현실 전체 성능을 직접 증명하는 자료가 아니라, 평가를 위한 별도 표본입니다.
- 왜 중요한가: 학습 데이터에서 잘 맞는 모델이 실제로 일반화되는지 확인하는 기본 장치이기 때문입니다. 테스트 데이터를 표본으로 읽으면 테스트 점수도 현실 성능의 추정값이며, 테스트 데이터 구성에 따라 해석이 흔들릴 수 있음을 이해하게 됩니다.
- 함께 볼 개념: `학습 데이터(training data)`, `표본(sample)`, `일반화(generalization)`
- 중심 Section: `P2-5.3`
- 등장 Section: `P2-6.2`, `P2-15.2`
