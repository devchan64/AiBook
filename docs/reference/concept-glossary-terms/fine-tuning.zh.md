## 微调

- 含义: 微调是在预训练模型上继续用任务或领域数据训练。
- 为什么重要: 微调把大规模预训练得到的通用能力和特定任务、领域、格式的适应阶段分开。理解它后，才能判断问题是应该通过提示词处理，还是需要用数据进一步调整模型本身。
- 相关概念: `预训练(pretraining)`, `上下文学习(in-context learning)`, `语言模型(language model)`
- 核心 Section: `P6-8.1`
- 出现 Section: `P1-11.3`, `P1-12.1`, `P6-8.2`, `P6-9.3`, `P6-9.5`
