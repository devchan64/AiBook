## orthogonal

- Meaning: Orthogonal directions do not overlap; in a simple 2D picture, they can be imagined as perpendicular axes.
- Why it matters: PCA uses orthogonal components so later components do not repeat the variation already explained by earlier components.
- Related concepts: `component`, `PCA`, `variance`
