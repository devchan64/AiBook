### 역방향 패스(backward pass)

- 뜻: 순전파(forward pass)로 출력과 손실을 계산한 뒤, 손실에서 거꾸로 각 계산 단계와 파라미터의 그래디언트를 계산하는 방향의 실행입니다. 딥러닝 문맥에서는 역전파 과정에서 뒤쪽 층에서 앞쪽 층으로 변화 정보를 되돌려 계산하는 흐름으로 볼 수 있습니다. 즉 역방향 패스는 학습 중 그래디언트를 되돌려 계산하는 실행 방향입니다.
- 왜 중요한가: 역전파와 순전파의 역할을 구분하게 해 주기 때문입니다. 순전파는 입력에서 출력과 손실을 계산하고, 역방향 패스는 손실에서 출발해 각 파라미터가 손실에 얼마나 영향을 주는지 계산합니다. 이 구분이 있어야 학습 계산이 단순히 모델을 한 번 실행하는 일이 아니라, 값 계산과 변화율 계산이 이어진 과정임을 이해하게 됩니다.
- 함께 볼 개념: `순전파(forward pass)`, `역전파(backpropagation)`, `연쇄 법칙(chain rule)`
