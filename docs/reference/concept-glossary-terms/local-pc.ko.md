### 로컬 PC(local PC)

- 뜻: Colab 같은 원격 노트북 환경이 아니라, 독자 자신의 컴퓨터에서 Python, 터미널, 파일, 가상환경을 사용해 코드를 실행하는 자리입니다. 즉 로컬 PC는 코드가 내 컴퓨터의 설치 상태와 파일 경로, 터미널 환경 위에서 돌아가는 실행 위치를 뜻합니다.
- 왜 중요한가: 같은 NumPy 예제라도 Colab 코드 셀에서 실행할 때와 로컬 터미널에서 실행할 때 설치 명령과 파일 경로가 달라지기 때문입니다. 로컬 PC를 구분하면 `%pip`와 `python -m pip`, 노트북 셀과 `.py` 파일 실행을 섞지 않게 됩니다. 이 개념이 있어야 실습 오류를 코드 문법 문제와 환경 준비 문제로 나누어 볼 수 있습니다.
- 함께 볼 개념: `터미널(terminal)`, `파이썬 인터프리터(Python interpreter)`, `로컬 환경(local environment)`
- 중심 Section: `P2-3.5`
