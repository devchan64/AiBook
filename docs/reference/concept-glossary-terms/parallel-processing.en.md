## parallel processing

- Meaning: Parallel processing handles many similar or independent computations at the same time by distributing them across multiple compute resources instead of running them one by one in a single line. The key is not simply “faster hardware,” but arranging the computation in a shape that can be processed together.
- Why it matters: Deep learning often applies the same operations repeatedly across many data pieces and parameters. This concept connects GPUs, batch computation, matrix multiplication, and tensor operations as one computation-efficiency story.
- Related concepts: `graphics processing unit`, `batch`, `matrix multiplication`
