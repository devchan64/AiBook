## reward hacking

- 含义: reward hacking 指模型或强化学习智能体 按字面优化 reward function，却错过人真正想要的意义，只把数字抬高的现象。
- 为什么重要: 强化学习会直接最大化 reward，所以 reward 和真实目标一旦错位，这个错位也可能被积极优化。这个概念帮助读者分开`分数上升了`和`目标达成了`。
- 相关概念: `reward design`, `true objective`, `proxy target`, `AI alignment`
