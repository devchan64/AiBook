### 파일 경로(file path)

- 뜻: 파일이나 폴더가 어디에 있는지 가리키는 위치 문자열입니다. 이 항목의 경로는 탐색 문제의 이동 경로(route)나 PATH 환경 변수와 다르며, 로컬 파일 시스템에서 `어느 폴더의 어느 파일을 가리키는가`를 표현하는 실행 환경 용어입니다. 예를 들어 `docs/parts`나 `/Users/someone/ws/project-name/docs/parts`는 파일과 폴더 위치를 나타내는 파일 경로입니다.
- 왜 중요한가: 같은 파일 이름도 현재 작업 폴더가 다르면 다른 대상을 가리키거나 아예 찾지 못할 수 있기 때문입니다. 파일 경로를 이해해야 `파일이 없다`는 오류를 실제 파일 부재와 위치 기준 오류로 나누어 읽을 수 있습니다. 또한 파일 경로를 PATH 환경 변수나 그래프 탐색의 경로와 섞지 않아야, 설치 문제와 파일 위치 문제를 서로 다른 실행 환경 문제로 정확히 분리하게 됩니다.
- 함께 볼 개념: `작업 폴더(working directory)`, `상대 경로(relative path)`, `절대 경로(absolute path)`
