### 분기(split)

- 뜻: 결정트리에서 어떤 질문이나 기준에 따라 데이터를 둘 이상의 가지로 나누는 일입니다. 숫자 특징에서는 보통 `x <= threshold` 같은 조건으로 왼쪽과 오른쪽 묶음을 만듭니다.
- 왜 중요한가: 결정트리는 좋은 분기를 반복해서 만들며 예측 구조를 세웁니다. 분기를 이해하면 트리가 단순히 사람이 적은 규칙 목록이 아니라, 현재 node 안의 사례를 더 덜 섞인 묶음으로 나누는 질문을 고르는 모델이라는 점을 읽을 수 있습니다.
- 함께 볼 개념: `결정트리(decision tree)`, `노드(node)`, `잎(leaf)`, `불순도(impurity)`, `임계값(threshold)`
