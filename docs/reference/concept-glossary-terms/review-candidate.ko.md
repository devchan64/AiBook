### 검토 후보(review candidate)

- 뜻: 변화 신호가 있을 뿐 아니라 사람이 실제로 다시 확인할 가치가 있다고 판단된 사례입니다. 단순 경고보다 강하지만, 아직 안정된 목표 라벨을 맞히는 예측 문제는 아닙니다.
- 왜 중요한가: 모든 경고를 같은 무게로 처리하면 검토 자원이 낭비되고, 모든 검토 후보를 곧바로 라벨 예측으로 올리면 라벨 품질이 약한 상태에서 문제를 과하게 정의하게 됩니다. 검토 후보는 비교 리포트와 사람의 우선순위 판단 사이를 잇는 중간 단계입니다.
- 함께 볼 개념: `경고(alert)`, `검토 후보 큐(review queue)`, `비교 리포트(comparison report)`, `라벨 예측(label prediction)`
