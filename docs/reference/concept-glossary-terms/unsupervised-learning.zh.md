## 无监督学习

- 含义: 无监督学习是在没有人工给定正确标签的数据中寻找结构、相似性或表示的机器学习问题。
- 为什么重要: 聚类和降维不是先给出标准答案再训练，而是帮助人阅读数据内部结构。这个概念能把“预测答案”和“发现结构”分开。
- 相关概念: `聚类(clustering)`, `降维(dimensionality reduction)`, `表示(representation)`, `监督学习标签(supervised learning label)`
