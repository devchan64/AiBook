### 트리(tree)

- 뜻: 부모와 자식의 계층 관계로 항목을 조직하는 구조입니다. 한 항목이 위쪽의 더 큰 범주 아래에 놓이고, 다시 그 아래에 더 작은 하위 항목이 이어지는 `가지형 계층 구조`로 이해하면 됩니다. 즉 트리는 앞뒤 순서보다 `누가 누구 아래에 속하는가`가 더 중요한 비선형 구조입니다.
- 왜 중요한가: 목차, 폴더, 분류 체계처럼 상위와 하위가 분명한 데이터를 읽을 때 가장 기본적인 계층 감각을 제공하기 때문입니다. 그래프보다 더 제한된 구조이지만 그만큼 `어디에 속하는가`를 읽기 쉬워, 분류와 의사결정 흐름의 기본 틀이 됩니다. 예를 들어 파일 시스템은 상위 폴더 아래 하위 폴더가 붙는 트리로 읽을 수 있고, 결정트리는 질문이 아래로 분기되는 판단 구조로 읽을 수 있습니다. 결국 트리를 이해해야 `관계가 있다`는 말 안에서도 순서 구조, 표 구조, 그래프 구조와 달리 `계층과 분기`가 중심인 경우를 따로 분리해 보게 됩니다.
- 함께 볼 개념: `그래프(graph)`, `선형 구조(linear structure)`, `비선형 구조(non-linear structure)`
