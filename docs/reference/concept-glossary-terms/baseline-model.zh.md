## 基准模型

- 含义: 基准模型是为了检查复杂模型是否真的带来有意义改进而先设定的最简单比较模型或分数标准。它先建立一个可解释的起点，再判断是否值得增加复杂度。
- 为什么重要: 分数看起来高，可能只是任务本身容易，而不一定是建模方法更好。基准模型固定候选模型至少需要超过的起点，使执行摘要和错误样本比较能够说明新模型到底改变了什么。
