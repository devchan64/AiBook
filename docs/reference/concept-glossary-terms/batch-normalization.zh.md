## 批归一化

- 含义: 批归一化利用一个批次中的均值和方差重新整理激活值分布，使下一层接收到更容易处理的数值范围。它不是只用于输入预处理，而是网络内部的稳定化步骤。
- 为什么重要: 在深层网络中，激活值分布不断变化会让训练变得不稳定。批归一化帮助稳定计算，也帮助读者理解为什么同一层在训练模式和评估模式下会使用不同的统计规则。
- 相关概念: `训练模式`, `评估模式`, `数值稳定性`
