### reference maintenance strategy

- Meaning: Reference maintenance strategy is the operating choice of whether to keep a baseline or reference range fixed for a while, or update it as the recent-usual range moves. It decides how the reference itself is maintained, so the same change can be read differently depending on what it is compared against.
- Why it matters: If a baseline is kept fixed too long, it may stop reflecting current operation. If it moves too often, the baseline itself can become unstable and weaken change signals. This concept frames baseline maintenance as a reference-management choice matched to the comparison question, not as a preference.
- Related concepts: `baseline`, `baseline window`, `comparison report`, `comparable reference group`
