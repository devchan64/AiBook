## 检索增强生成(retrieval-augmented generation, RAG)

- 含义：检索增强生成先查找和问题相关的外部资料，把检索结果接到模型输入上下文中，再生成回答。核心在于 `检索` 和 `生成` 是分开的两个阶段，让模型同时使用参数中已有的知识和刚取回的依据。
- 为什么重要：RAG 是减少模型只依赖内部参数回答这一限制的代表方式，也能让回答基于较新的资料或组织内部文档。但如果检索质量、chunk 设计、来源追踪很弱，即使生成步骤写得流畅，整体回答质量也会动摇。
- 相关概念：`嵌入(embedding)`，`相似度检索`，`检索(retrieval)`，`出处追踪(provenance)`，`搜索索引(search index)`
