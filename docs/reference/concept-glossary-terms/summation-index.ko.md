### 반복 인덱스(summation index)

- 뜻: 시그마(sigma) 표기에서 반복 위치를 나타내는 이름입니다. \(\sum_{i=1}^{n} x_i\)에서 `i`처럼 시작값부터 끝값까지 바뀌며, 지금 몇 번째 항을 보고 있는지 알려 줍니다. 즉 반복 인덱스는 자료구조의 위치 번호(index)와 닮았지만, 여기서는 합을 펼쳐 읽기 위한 수학 표기 안의 반복 변수입니다.
- 왜 중요한가: `index`라는 단어를 Python 리스트나 Pandas 행 라벨의 인덱스와만 연결하면 시그마 표기를 잘못 읽을 수 있기 때문입니다. 반복 인덱스를 구분하면 `무엇을 몇 번 더하는가`, `아래 첨자가 어떤 값으로 바뀌는가`, `x_i`가 왜 매번 다른 항을 가리키는가를 안정적으로 따라갈 수 있습니다. 이 개념이 있어야 시그마를 단순 합계 기호가 아니라 반복 범위와 더할 대상을 함께 적은 압축 표기로 읽게 됩니다.
- 함께 볼 개념: `시그마(sigma)`, `항(term)`, `인덱스(index)`
