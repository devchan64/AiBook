### 입력 조건(input condition)

- 뜻: 모델이 현재 출력을 만들 때 참고하도록 입력 안에 배치된 지시, 맥락, 예시, 제약, 출력 형식 같은 조건입니다. 일반적인 조건(condition)이 생성 후보를 좁히는 넓은 표현이라면, 입력 조건은 사용자가 이번 실행에서 프롬프트로 제공한 작업 조건을 가리킵니다.
- 왜 중요한가: 프롬프트를 단순한 질문 문장이 아니라 현재 응답을 만드는 조건 묶음으로 이해하게 해 주기 때문입니다. 이 개념이 있어야 모델 가중치를 바꾸는 학습과, 같은 모델에 다른 입력 조건을 주어 출력 행동을 바꾸는 사용 단계를 구분할 수 있습니다. 또한 입력 조건을 분리하면 `무엇을 하라`, `무엇을 참고하라`, `어떤 형식으로 내라`를 각각 점검할 수 있어 긴 문서 작업의 검토성이 높아집니다.
- 함께 볼 개념: `프롬프트(prompt)`, `지시(instruction)`, `맥락(context)`, `제약(constraint)`, `출력 형식(output format)`
