## 稀疏注意力

- 含义：稀疏注意力是一种 attention 设计方向，它不让所有 token 对都以同样密度互相比较，而是只保留部分连接来降低计算负担。可以把它看成在完整 self-attention 和只优先连接附近或重要位置之间的结构性折中。
- 为什么重要：上下文越长，attention 比较数量增长越快，因此长输入系统需要现实的折中。稀疏注意力帮助读者看到，长上下文支持不只是模型大小问题，也是在决定保留哪些关系、跳过哪些关系的结构设计问题。
- 相关概念：`multi-head attention`，`上下文窗口`，`长上下文`
