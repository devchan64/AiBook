## 支持向量(support vector)

- 含义: 在 SVM 中离 classification boundary 最近、实际支撑 boundary 位置的数据案例。直观地说，它们是 boundary 稍微移动时最先受到影响的那些 `最紧的点`。
- 为什么重要: 并不是每个 training case 都以同样程度决定 boundary。支持向量能显示哪些案例缩窄 margin、影响 boundary 稳定性，因此也能让 near-boundary review 和 error analysis 更具体。
- 相关概念: `SVM`, `间隔(margin)`, `决策边界(decision boundary)`
