## LightGBM

- Meaning: LightGBM is a boosting library designed for efficient gradient boosting decision tree training on large tabular data. It is often discussed through histogram-based splitting, leaf-wise growth, GOSS, and EFB.
- Why it matters: LightGBM shows that even inside boosting, some implementations prioritize faster and lighter repetition. When stage count and data size grow, speed and memory tradeoffs can become part of model selection.
- Related concepts: `gradient boosting`, `overfitting`
