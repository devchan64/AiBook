### 인접 리스트(adjacency list)

- 뜻: 그래프에서 각 노드마다 바로 연결된 이웃 노드 목록을 적어 두는 표현 방식입니다. 그림의 선을 표나 딕셔너리처럼 바꾸어, 한 노드에서 어디로 갈 수 있는지 빠르게 읽게 해 줍니다.
- 왜 중요한가: 그래프를 그림으로만 보면 연결 관계를 코드나 데이터로 어떻게 담을지 놓치기 쉽기 때문입니다. 인접 리스트를 이해하면 `노드별 이웃 목록`이라는 형태로 관계 데이터를 다시 정리할 수 있고, 검색, 추천, 링크 분석에서 연결을 따라가는 질문을 더 구체적으로 만들 수 있습니다.
- 함께 볼 개념: `그래프(graph)`, `노드(node)`, `엣지(edge)`
