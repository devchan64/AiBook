### 경로(route, path)

- 뜻: 탐색이나 계획에서 목표까지 지나갈 상태, 위치, 도로, 노드의 순서를 뜻합니다. 파일 시스템이나 셸의 `PATH 환경 변수`가 아니라, 문제 해결 과정에서 `어디를 거쳐 갈 것인가`를 나타내는 공간적 또는 상태적 흐름입니다.
- 왜 중요한가: 한국어 `경로`와 영어 `path`는 파일 위치, 실행 환경 변수, 그래프 탐색 경로, 자율주행 이동 흐름을 모두 가리킬 수 있어 문맥 구분이 필요하기 때문입니다. 이 개념이 있어야 탐색에서 말하는 경로를 터미널 설정의 PATH와 섞지 않고, 큰 이동 흐름과 실제 시간별 움직임인 궤적(trajectory)도 나누어 읽게 됩니다.
- 함께 볼 개념: `탐색(search)`, `탐색 공간(search space)`, `궤적(trajectory)`
