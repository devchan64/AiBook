### 비교 그래프(comparison plot)

- 뜻: 둘 이상의 값, 흐름, 조건을 나란히 놓거나 같은 축에 올려 차이를 읽게 만든 그래프입니다.
- 왜 중요한가: 손실과 정확도, 학습 손실과 검증 손실처럼 함께 봐야 의미가 분명해지는 결과가 많기 때문입니다. 비교 그래프를 이해해야 같은 축에서 비교할 값과 따로 나누어 볼 값을 구분할 수 있습니다.
- 함께 볼 개념: `범례(legend)`, `손실 곡선(loss curve)`, `정확도(accuracy)`
- 중심 Section: `P2-13.3`
