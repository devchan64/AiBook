### 변경 가능한 값(mutable value)

- 뜻: 만든 뒤에도 내부 항목이나 상태를 바꿀 수 있는 값입니다. Python 리스트나 딕셔너리처럼 같은 객체를 유지한 채 항목을 추가하거나 수정할 수 있는 구조가 대표적입니다. 숫자나 문자열처럼 새 값을 만들어 다시 연결하는 경우와 달리, 변경 가능한 값은 같은 대상을 여러 이름이 함께 보고 있을 때 한쪽 수정이 다른 쪽에서도 보일 수 있습니다.
- 왜 중요한가: 리스트를 다른 변수에 대입했다고 해서 자동으로 독립 복사본이 생기지 않는다는 점을 이해하게 해 주기 때문입니다. 이 개념이 있어야 `append()`나 항목 대입이 단순히 이름을 바꾸는 것이 아니라 객체 내부 상태를 바꿀 수 있음을 읽게 됩니다. 결국 변경 가능한 값은 참조, 얕은 복사, 깊은 복사의 차이를 이해하기 위한 출발점입니다.
- 함께 볼 개념: `리스트(list)`, `참조(reference)`, `얕은 복사(shallow copy)`
