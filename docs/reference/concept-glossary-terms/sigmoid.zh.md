## sigmoid

- 含义: sigmoid 是一种 S 形函数，会把实数分数压缩到 0 与 1 之间。它常用于把一个分数读成偏向二元决策某一侧的值。
- 为什么重要: 它能帮助读者区分模型分数与像概率一样的输出。模型先形成分数，再经过 sigmoid 变成更容易解释的值，而阈值或运行策略属于后续步骤。
- 相关概念: `激活函数(activation function)`, `阈值(threshold)`, `二元分类(binary classification)`, `逻辑回归(logistic regression)`
