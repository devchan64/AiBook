## 残差

- 含义：残差是实际值与当前预测值之间剩下的差。 在回归(regression)语境里，通常可以读成 `实际值 - 当前预测值`。 在梯度提升里，它是下一阶段要继续压低的剩余误差信号。
- 为什么重要：残差能显示模型还没有解释掉的方向和大小。 梯度提升不是一次性消灭这部分，而是顺序加入小学习器来减少它，所以理解 residual 才能理解为什么这种方法会被解释成 `下一阶段修正前一阶段`。
- 相关概念：`梯度提升(gradient boosting)`，`弱学习器(weak learner)`，`加性模型(additive model)`
