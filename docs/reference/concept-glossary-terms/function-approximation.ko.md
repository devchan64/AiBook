### 함수 근사(function approximation)

- 뜻: 함수 근사는 값을 표에 모두 직접 저장하지 않고, 입력을 받으면 값을 추정하는 함수나 모델로 표현하는 방식입니다.
- 왜 중요한가: 상태 공간이 커질수록 값을 표 형태로 모두 저장하기 어려워지므로, 가치 기반 강화학습의 직관을 더 큰 문제로 옮길 때 함수 근사가 필요해집니다.
- 함께 볼 개념: `Q-learning`, `가치 기반 강화학습(value-based reinforcement learning)`, `다층 신경망(multilayer neural network)`
