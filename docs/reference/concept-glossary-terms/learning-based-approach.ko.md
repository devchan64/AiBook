### 학습 기반 접근(learning-based approach)

- 뜻: 사람이 모든 판단 규칙을 직접 쓰는 대신, 사례 데이터에서 입력과 출력의 관계를 맞추어 모델의 판단 기준을 만드는 접근입니다.
- 왜 중요한가: 머신러닝을 `사람이 읽는 규칙을 찾아내는 과정`으로 오해하지 않게 해 줍니다. 학습 기반 접근은 데이터 품질, 라벨, 평가 설계에 의존하므로 규칙 기반 접근과 다른 방식으로 검증해야 합니다.
- 함께 볼 개념: `머신러닝(machine learning)`, `특징(feature)`, `라벨(label)`, `모델(model)`, `평가(evaluation)`
