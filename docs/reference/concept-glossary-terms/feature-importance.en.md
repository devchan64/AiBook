## feature importance

- Meaning: Feature importance is a summary value that indicates which features a trained model used relatively more for prediction. In tree-based models, it can be computed from split-quality improvement or from the performance drop after shuffling a feature.
- Why it matters: It is a starting point for inspecting what the model relied on. However, importance is a trace of model usage, not a direct ranking of real-world causes or causal effects.
- Related concepts: `decision tree`, `feature`, `model selection`
