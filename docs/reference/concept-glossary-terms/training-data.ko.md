### 학습 데이터(training data)

- 뜻: 모델이 패턴이나 규칙을 배우는 데 직접 사용하는 데이터입니다. 지도학습에서는 입력과 정답을 함께 담은 데이터일 수 있고, 생성형 AI 논의에서는 대규모 문서, 이미지, 코드 같은 학습 재료를 가리킬 수도 있습니다.
- 왜 중요한가: 모델은 학습 데이터에서 본 구조를 기준으로 동작하므로, 어떤 데이터로 배웠는지가 성능, 편향, 일반화, 저작권, 개인정보 논의에 모두 영향을 줍니다. 학습 데이터를 구분해야 훈련에 쓴 데이터와 성능 확인용 데이터를 섞지 않고 읽을 수 있습니다.
- 함께 볼 개념: `데이터셋(dataset)`, `테스트 데이터(test data)`, `일반화(generalization)`, `편향(bias)`

- 등장 Section: `P2-5.3`, `P2-6.2`, `P2-15.2`
