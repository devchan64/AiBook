### RBF 커널(radial basis function kernel)

- 뜻: 두 점 사이의 거리와 지역적 유사도를 강하게 반영하는 대표적인 커널입니다. 가까운 점은 더 비슷하게, 멀어진 점은 빠르게 덜 비슷하게 읽는 감각을 줍니다.
- 왜 중요한가: 데이터가 원형, 군집, 곡선 경계처럼 지역 구조를 강하게 보일 때 RBF 커널은 선형 경계만으로는 답답한 패턴을 더 유연하게 읽는 후보가 됩니다.
- 함께 볼 개념: `커널(kernel)`, `특징 공간(feature space)`, `거리(distance)`, `SVM(support vector machine)`
