## 子采样

- 含义：子采样是在一次学习或修正步骤中只使用全部样本的一部分。 在梯度提升里，它可以让每一阶段的 base learner 只看训练数据的一个子集，避免每一阶段都完全贴住完整数据。
- 为什么重要：如果每一阶段都对完整训练数据反应得太紧，模型就可能不断追随偶然模式。 subsampling 会给阶段修正加入随机性，帮助缓和方差和过拟合风险。
- 相关概念：`梯度提升(gradient boosting)`，`过拟合(overfitting)`，`方差(variance)`
