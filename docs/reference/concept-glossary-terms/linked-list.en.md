## linked list

- Meaning: A linked list is a linear data structure where each item points to the next item. Instead of assuming that values sit in consecutive positions, it reads order by following links.
- Why it matters: A linked list separates being in order from being stored in adjacent slots. This helps readers distinguish array-style positional access from link-based traversal, and prepares them to read terms such as node, pointer, and link as descriptions of connection structure.
- Related concepts: `linear structure`, `node`, `data structure`
