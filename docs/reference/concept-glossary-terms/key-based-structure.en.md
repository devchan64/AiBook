## key-based structure

- Meaning: A key-based structure organizes lookup around keys rather than positions. Dictionaries and hash tables are typical examples where the main question is which value belongs to this name or ID.
- Why it matters: Linear and non-linear structure are not enough to explain structures whose main strength is key lookup. This concept separates sequential processing, relationship traversal, and name-based retrieval.
- Related concepts: `dictionary`, `hash table`, `mapping`
