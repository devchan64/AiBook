# 개념사전

이 문서는 책 본문에서 반복해서 등장하는 핵심 개념을 가나다순으로 정리하는 원고입니다. 각 항목은 한 번 더 빠르게 복습할 수 있도록 짧게 정의하고, 어느 Section에서 중심적으로 다루는지도 함께 기록합니다. 같은 Part 안에서는 가능한 한 하나의 대표 Section를 상세 설명 위치로 삼고, 이 문서는 그 연결 지점을 다시 찾게 하는 색인 역할도 맡습니다.

중복을 줄이기 위해 하나의 개념은 가능한 한 하나의 대표 표제어로만 세우고, 비슷한 표현은 같은 항목 안에서 함께 설명합니다.

## ㄱ

### 과적합(overfitting)

- 뜻: 학습 데이터에 너무 맞춰져 새 데이터에서는 성능이 떨어지는 상태입니다.
- 왜 중요한가: 데이터에서 패턴을 배운다는 것이 단순 암기가 아님을 설명할 때 핵심이 됩니다.
- 대표 반대 개념: `과소적합(underfitting)`, `일반화(generalization)`
- 중심 Section: `P1-3.2`

### 과소적합(underfitting)

- 뜻: 데이터 안의 관계를 충분히 배우지 못해 학습 데이터와 새 데이터 모두에서 성능이 약한 상태입니다.
- 왜 중요한가: 학습이 잘 안 된 경우와 너무 많이 맞춘 경우를 구분할 때 필요합니다.
- 대표 반대 개념: `과적합(overfitting)`, `일반화(generalization)`
- 중심 Section: `P1-3.2`

### 규칙 기반 시스템(rule-based system)

- 뜻: 현재 사실과 사람이 작성한 규칙을 대조해 결론이나 행동을 정하는 시스템입니다.
- 왜 중요한가: 설명 가능성, 통제 가능성, 정책·권한·절차 자동화의 강점과 한계를 이해하는 출발점이 됩니다.
- 함께 볼 개념: `기호 기반 AI(symbolic AI)`, `추론 엔진(inference engine)`
- 중심 Section: `P1-2.1`, `P1-3.1`

### 기호 기반 AI(symbolic AI)

- 뜻: 기호, 규칙, 논리, 명시적 지식 표현을 사용해 문제를 풀려는 AI 접근입니다.
- 왜 중요한가: 머신러닝 이전의 대표 흐름을 이해하고, 명시적 규칙과 지식 표현의 위치를 잡는 데 필요합니다.
- 함께 볼 개념: `규칙 기반 시스템(rule-based system)`, `지식 표현(knowledge representation)`
- 중심 Section: `P1-2.1`

## ㄷ

### 데이터(data)

- 뜻: 모델이 참고하거나 학습할 과거 사례의 모음입니다.
- 왜 중요한가: 모델이 무엇을 배우는지는 결국 어떤 데이터를 준비했는지와 연결됩니다.
- 함께 볼 개념: `입력(input)`, `출력(output)`, `라벨(label)`, `사례(example)`
- 중심 Section: `P1-2.3`, `P1-3.2`, `P1-4.2`

### 딥러닝(deep learning)

- 뜻: 여러 층의 신경망을 사용해 표현과 예측 기준을 함께 학습하는 접근입니다.
- 왜 중요한가: 사람이 특징을 많이 설계하던 흐름에서 표현 학습 중심으로 이동한 변화를 보여 줍니다.
- 함께 볼 개념: `표현 학습(representation learning)`, `파라미터(parameter)`, `특징(feature)`
- 중심 Section: `P1-1.3`, `P1-2.3`

## ㄹ

### 라벨(label)

- 뜻: 데이터 사례에 사람이 붙인 정답이나 목표 출력입니다.
- 왜 중요한가: 지도학습에서는 모델이 무엇을 맞혀야 하는지를 라벨이 정해 줍니다.
- 함께 볼 개념: `사례(example)`, `데이터(data)`, `출력(output)`
- 중심 Section: `P1-2.1`, `P1-3.2`, `P1-4.2`

## ㅁ

### 머신러닝(machine learning)

- 뜻: 데이터나 경험을 사용해 모델의 성능을 개선하는 접근입니다.
- 왜 중요한가: 사람이 모든 규칙을 직접 쓰기 어려운 문제에서 중심 설명이 학습 기반으로 이동하는 이유를 이해하게 해 줍니다.
- 함께 볼 개념: `모델(model)`, `학습(training)`, `파라미터(parameter)`
- 중심 Section: `P1-1.3`, `P1-2.3`, `P1-3.2`

### 모델(model, 모형)

- 뜻: 현실 전체를 그대로 복사한 것이 아니라, 목적에 맞게 줄여 만든 계산용 모형입니다.
- 왜 중요한가: AI 모델을 사람 같은 존재로 오해하지 않고, 무엇을 입력으로 받아 무엇을 출력하는지 묻는 출발점이 됩니다.
- 함께 볼 개념: `입력(input)`, `출력(output)`, `시스템(system)`
- 중심 Section: `P1-4.1`

## ㅅ

### 사례(example)

- 뜻: 데이터 안의 한 건을 이루는 관찰 사례입니다.
- 왜 중요한가: 데이터가 단순 파일 모음이 아니라 입력과 출력이 연결된 사례 묶음이라는 점을 보여 줍니다.
- 함께 볼 개념: `데이터(data)`, `라벨(label)`, `입력(input)`
- 중심 Section: `P1-3.2`, `P1-4.2`

### 시스템(system)

- 뜻: 모델뿐 아니라 입력 처리, 규칙, 사람 검토, 저장, 실행 절차까지 포함한 전체 구조입니다.
- 왜 중요한가: 모델 출력이 곧 현실 문제의 최종 해결은 아니라는 점을 설명할 때 필요합니다.
- 함께 볼 개념: `모델(model)`, `입력(input)`, `출력(output)`
- 중심 Section: `P1-3.1`, `P1-4.1`

## ㅇ

### 일반화(generalization)

- 뜻: 학습하지 않은 새 데이터에도 어느 정도 맞는 관계를 찾는 상태입니다.
- 왜 중요한가: 학습이 단순 암기와 다르다는 점을 설명하는 핵심 기준입니다.
- 함께 볼 개념: `과적합(overfitting)`, `과소적합(underfitting)`
- 중심 Section: `P1-3.2`

### 입력(input)

- 뜻: 모델이 실제로 받는 정보입니다.
- 왜 중요한가: 모델이 무엇을 근거로 판단할 수 있는지는 어떤 입력을 보여 주는지에 달려 있습니다.
- 함께 볼 개념: `출력(output)`, `데이터(data)`, `모델(model)`
- 중심 Section: `P1-4.1`, `P1-4.2`

### 출력(output)

- 뜻: 모델이 내야 하는 결과입니다.
- 왜 중요한가: 같은 현실 문제도 어떤 출력을 정의하느냐에 따라 전혀 다른 모델링 과제가 됩니다.
- 함께 볼 개념: `입력(input)`, `라벨(label)`, `모델(model)`
- 중심 Section: `P1-4.2`

## ㅈ

### 지식 표현(knowledge representation)

- 뜻: 사실, 관계, 규칙, 제약을 컴퓨터가 다룰 수 있는 형식으로 정리하는 일입니다.
- 왜 중요한가: 기호 기반 AI와 규칙 기반 접근이 무엇을 저장하고 조작하려 했는지 이해하게 해 줍니다.
- 함께 볼 개념: `기호 기반 AI(symbolic AI)`, `규칙 기반 시스템(rule-based system)`
- 중심 Section: `P1-2.1`, `P1-2.2`

## ㅊ

### 추론(inference)

- 뜻: 문맥에 따라 두 뜻으로 쓰입니다. 기호 기반 AI에서는 주어진 지식에서 결론을 이끌어 내는 과정이고, 머신러닝에서는 학습된 모델을 새 입력에 실행해 출력을 얻는 과정일 수 있습니다.
- 왜 중요한가: 같은 한국어 표현이 서로 다른 영어 문맥을 가리킬 수 있어 혼동을 줄여야 합니다.
- 함께 볼 개념: `추론 엔진(inference engine)`, `학습(training)`
- 중심 Section: `P1-2.1`, `P1-3.2`

### 추론 엔진(inference engine)

- 뜻: 현재 사실에 맞는 규칙을 찾아 적용하는 장치입니다.
- 왜 중요한가: 규칙 기반 시스템이 단순 규칙 목록이 아니라 적용 절차를 가진 시스템임을 보여 줍니다.
- 함께 볼 개념: `규칙 기반 시스템(rule-based system)`, `사실(fact)`
- 중심 Section: `P1-3.1`

## ㅌ

### 특징(feature)

- 뜻: 모델이 입력으로 사용하는 값이나 단서입니다.
- 왜 중요한가: 전통적 머신러닝에서는 사람이 많이 설계했고, 딥러닝에서는 더 깊은 표현으로 바뀌는 출발점이 됩니다.
- 함께 볼 개념: `표현(representation)`, `입력(input)`, `파라미터(parameter)`
- 중심 Section: `P1-2.3`, `P1-3.2`, `P1-3.3`

## ㅍ

### 파라미터(parameter)

- 뜻: 학습 과정에서 조정되는 모델 내부 값입니다.
- 왜 중요한가: 같은 입력에 대한 출력이 어떻게 달라지는지를 결정하는 내부 기준이기 때문입니다.
- 함께 볼 개념: `모델(model)`, `학습(training)`, `표현(representation)`
- 중심 Section: `P1-2.3`, `P1-3.2`, `P1-3.3`

### 표현(representation)

- 뜻: 입력을 모델이 다룰 수 있게 바꾼 내부 형태입니다.
- 왜 중요한가: 딥러닝과 표현 학습을 이해하려면 사람이 읽는 입력과 모델이 계산하는 내부 형태를 구분해야 합니다.
- 함께 볼 개념: `특징(feature)`, `벡터(vector)`, `활성값(activation)`
- 중심 Section: `P1-2.3`, `P1-3.3`

### 표현 학습(representation learning)

- 뜻: 모델이 입력을 더 유용한 내부 표현으로 바꾸는 방식을 데이터에서 함께 학습하는 접근입니다.
- 왜 중요한가: 사람이 특징을 직접 설계하는 흐름과 딥러닝의 차이를 이해하게 해 줍니다.
- 함께 볼 개념: `딥러닝(deep learning)`, `특징(feature)`, `표현(representation)`
- 중심 Section: `P1-2.3`, `P1-3.3`

## ㅎ

### 학습(training)

- 뜻: 과거 사례를 사용해 모델 내부 기준과 값을 조정하는 과정입니다.
- 왜 중요한가: 규칙 작성과 달리, 학습 기반 모델은 데이터를 통해 기준을 맞춘다는 점이 핵심입니다.
- 함께 볼 개념: `모델(model)`, `파라미터(parameter)`, `추론(inference)`
- 중심 Section: `P1-3.2`, `P1-4.1`
