# 개념사전 단어별 항목 slug 디렉터리

이 디렉터리는 개념사전의 단어별 canonical 항목 파일을 모아 두는 곳이다.

- 파일명은 영어 기준 용어를 kebab-case slug로 만든다.
- 같은 영어 표면형이 서로 다른 개념을 가리키면 의미 구분자를 붙인다. 예: `parameter-function.md`, `parameter-model.md`
- 한 파일에는 원칙적으로 하나의 대표 표제어만 둔다.
- 한국어 자음별 색인, 영어 알파벳별 색인, 중국어 병음별 색인은 이 디렉터리의 항목 파일을 include해 구성한다.
- 항목 파일의 제목 수준은 색인 파일에 include될 때의 문서 구조를 고려해 `###`를 기본으로 한다.

예시:

```md
### 모델(model, 모형)

- 뜻: ...
- 왜 중요한가: ...
- 함께 볼 개념: `입력(input)`, `출력(output)`
- 중심 Section: `P1-4.1`
- 등장 Section: `P1-14.1`, `P1-14.3`
```
