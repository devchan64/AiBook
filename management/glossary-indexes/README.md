# 개념사전 인덱스 운영 메모

이 폴더는 `docs/reference/concept-glossary.md`의 표제어를 언어별로 빠르게 찾기 위한 보조 관리 파일을 둔다.

개념사전 본문은 독자용 기준 원고이고, 이 폴더의 인덱스는 집필·번역·검수 중 컨텍스트를 줄이기 위한 탐색 장치다. 정의를 중복해서 다시 쓰지 않고, 대표 표제어와 `Section ID`, 앵커, 검증 레퍼런스만 추적한다.

운영 기준은 `management/guidelines/concept-glossary-guidelines.md`를 따른다.

## 파일

- `concept-glossary-index.ko.md`: 한국어 표면형과 대표 표제어 대응
- `concept-glossary-index.en.md`: 영어 표준 용어, 약어, 원문 레퍼런스 표제어 대응
- `concept-glossary-index.zh.md`: 중국어 번역어 후보와 대표 표제어 대응

## 권장 항목 형식

```md
| 인덱스 표기 | 대표 표제어 | 영어 기준 용어 | 중심 Section | 앵커 | 검증 레퍼런스 | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |
```
