# 개념사전 인덱스 운영 메모

이 폴더는 `docs/reference/concept-glossary-terms/`의 단어별 원고와 `docs/reference/concept-glossary-parts/`, `docs/reference/concept-glossary-alpha/`, `docs/reference/concept-glossary-pinyin/`의 언어별 색인을 빠르게 찾기 위한 보조 관리 파일을 둔다.

개념사전 항목 본문은 영어 기준 slug를 파일명으로 쓰는 단어별 원고 디렉터리에 둔다. 언어별 공개 색인은 자음, 알파벳, 병음 구조를 유지하되, 단어별 원고를 include해 페이지를 조립한다. 이 폴더의 인덱스는 집필·번역·검수 중 컨텍스트를 줄이기 위한 탐색 장치다. 정의를 중복해서 다시 쓰지 않고, 대표 표제어와 `Section ID`, 영어 기준 slug, 앵커, 검증 레퍼런스만 추적한다.

인덱스는 용량 관리가 중요하다. 한 항목은 원칙적으로 표 한 행으로 유지하고, 정의 문단, 사례, 원문 인용, 작업 로그를 넣지 않는다. 비고가 길어지면 인덱스에 계속 누적하지 않고 관련 Section 또는 별도 근거 분석 문서로 보낸다.

운영 기준은 `management/guidelines/concept-glossary-guidelines.md`를 따른다.

## 파일

- `concept-glossary-index.en.md`: 영어 표준 용어, 약어, 원문 레퍼런스 표제어 대응
- `concept-glossary-index.zh.md`: 중국어 번역어 후보와 대표 표제어 대응
- `korean-general-expression-review.md`: 한국어 표제 중 일반 사전적 의미와 원고 안의 의미가 분리되어 쓰이는 표현을 `표제 관리 제외`와 `표제 통일 관리`로 나누어 정리한 검토 리포트

## 권장 항목 형식

```md
| 인덱스 표기 | 대표 표제어 | 영어 기준 용어 | 파일 slug | 중심 Section | 앵커 | 검증 레퍼런스 | 비고 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |
```

## 용량 관리 기준

- 같은 개념의 표기 변형은 새 행으로 늘리기보다 한 행 안에 압축한다.
- `검증 레퍼런스`에는 출처 식별자와 URL만 짧게 남긴다.
- 여러 출처의 차이를 비교해야 하면 인덱스에 요약하지 말고 관련 Section의 `출처와 참고 자료`나 근거 분석 문서에서 처리한다.
- 끝난 작업 기록, 검토 로그, 긴 판단 이유는 인덱스에 남기지 않는다.

## 갱신 기준

- 새 개념사전 항목을 추가하거나 대표 표제어를 바꾸면 단어별 원고 파일과 공개 색인 include를 같은 작업에서 갱신한다.
- 한국어 공개 단어별 원고와 한국어 자음별 공개 색인은 같은 표제 집합을 가리켜야 한다. 공개 원고가 있는데 색인에 없으면 `색인 누락`, `표제 변경 후보`, `상위 표제 흡수 후보` 중 하나로 판정한다.
- 한국어 표제가 기준이므로 같은 slug의 한국어 단어 파일이 없는 영어·중국어 단어 파일과 공개 색인 include, 보조 인덱스 행은 유지하지 않는다.
- 영어·중국어 본문에서 이미 쓰였거나 곧 쓸 용어라면 해당 언어 인덱스도 같은 작업에서 갱신한다.
- 아직 해당 언어 본문에 노출되지 않은 용어는 억지로 번역어를 만들지 않는다.
- 번역본에서 용어를 새로 고정하거나 바꾸면 해당 언어 인덱스에 먼저 대응 관계를 남긴다.
- 인덱스 파일끼리 충돌하면 영어 기준 용어, 파일 slug, `Section ID`를 먼저 기준점으로 삼고, 필요하면 개념사전 표제어 분리 여부를 다시 검토한다.
- 일반 표현을 표제로 계속 관리할지 판단할 때는 `korean-general-expression-review.md`에서 `표제 관리 제외` 대상과 `표제 통일 관리` 대상을 먼저 구분한다. 표제 통일 관리 대상은 즉흥 표현이 아니라 영어 기준 용어와 일반화된 학술·기술 표현을 기준으로 대표 표제어를 맞춘다.
