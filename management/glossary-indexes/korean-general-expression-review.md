# 한국어 개념사전 표제 검토 리포트

작성일: 2026-07-27

## 목적

이 리포트는 현재 `management/glossary-indexes/concept-glossary-index.ko.md`에 남아 있는 한국어 개념사전 표제를 다시 검토해, 일반 사전적 의미와 원고 안의 의미가 분리될 수 있는 표현을 관리하기 위한 문서다.

표제 검토의 목적은 링크 여부를 판단하는 데 있지 않다. 표제만 보면 독자가 일반 사전적 의미로 읽기 쉽지만 원고에서는 특정 기술 문맥, 학습 문맥, 실행 절차, 평가 구조 안에서 좁게 쓰이는 경우가 혼란을 만든다. 이런 표현은 독립 표제로 계속 둘지, 더 큰 대표 개념의 하위 설명으로 돌릴지, 아니면 일반화된 학술·기술 표현으로 표제어를 바꿀지 구분해야 한다.

따라서 후속 처리는 두 갈래로 나눈다.

- 삭제 후보: 원고 내부의 산출물명, 상태명, 절차명, 옵션명, 문서 필드명에 가까워 독립 표제로 관리할 실익이 낮은 표현이다. 필요한 설명은 대표 항목의 하위 설명이나 본문 문맥으로 흡수한다.
- 표제 변경 후보: 독립 연결점은 필요하지만 현재 표제가 너무 일반적이거나 문맥이 드러나지 않는 표현이다. 즉흥적인 새 이름을 만들지 않고, 영어 기준 용어와 일반화된 학술·기술 표현을 확인해 대표 표제어를 통일한다.

이 리포트는 자동 삭제 목록이 아니라 표제 정리 우선순위다. 실제 삭제, 병합, 표제 변경, slug 변경은 각 항목의 중심 Section과 등장 Section을 다시 확인한 뒤 별도 작업으로 처리한다.

## 판정 기준

표제 검토는 개별 예시 목록이 아니라 다음 표준 범주로 판정한다.

- 등재 가능: 표준 개념, 문맥 분리 개념, 대표 연결점, 대표 모델·방법 계열처럼 문서 전체의 용어 기준점이 되는 표현이다.
- 제외: 운영·절차·상태명, 도구·구현명, 구성요소·속성명, 분석 설계 필드, 단발성 표현, 임시 표현처럼 상위 표제나 본문 설명으로 충분한 표현이다.
- 변경: 독립 연결점은 필요하지만 현재 표제가 단독 일반어이거나 문맥이 부족한 표현이다. 영어 기준 용어와 학술·기술 표현을 확인해 문맥 한정 표제로 바꾼다.
- 병합: 둘 이상의 표제가 같은 개념 흐름을 중복 관리하는 경우다. 대표 항목 하나를 세우고 나머지는 그 항목 안의 표현으로 흡수한다.

판정 순서는 `상위 표제 흡수 가능성 확인 -> 중복 표제 제거 -> 단독 일반어 문맥 한정 -> 표준 용어 확인 -> 보류`를 기본으로 한다.

## 재검토 결과 요약

강화된 기준을 적용하면 현재 `표제 통일 관리 검토` 항목은 모두 처리되었다.

- 표제 변경 누적: 4개. 단독 일반어·형용사 표제를 피하고 대상 영역, 기술 층위, 성질 개념을 드러내는 표제로 좁힌다.
- 2026-07-27 추가 확인: `강화학습 환경(reinforcement learning environment)`은 단독 `환경`이 아니라 강화학습의 표준 상호작용 대상이므로 유지한다. 다만 새 표제를 만들 때 `환경` 단독 표제는 금지하고, `실행 환경(runtime)`처럼 문맥 한정 표제로만 관리한다.

남아 있는 기초 표제는 다음 묶음 기준으로 관리한다.

| 유지 묶음 | 대표 slug | 유지 기준 | 확산 제한 |
| --- | --- | --- | --- |
| 계산 언어 기초 | `variable`, `function`, `expression`, `limit`, `rate-of-change` | 변수·함수·식·극한·변화율은 Part 2의 수학 언어를 읽게 하는 최소 기준점이다. | 반환값, 기본값, 접선, 곡선, 기울기 같은 하위 설명은 독립 표제로 만들지 않는다. |

| 완료 | 데이터 | `data` | 일반어지만 학습 재료, 평가 자료, 검색 근거, 운영 기록의 역할을 구분하는 최상위 기준점이다. 하위 데이터 역할 표제 확산은 제한한다. |
| 완료 | 디코더 | `decoder` | 출력 시퀀스를 생성하는 모델 구성 역할이다. 인코더·인코더-디코더·GPT 계열을 구분하기 위해 유지한다. |
| 완료 | 차원 축소 | `dimensionality-reduction` | 고차원 표현을 더 적은 축으로 옮겨 구조를 읽는 표준 비지도학습 방법 계열이다. t-SNE, UMAP 같은 알고리즘명은 하위 사례로 흡수한다. |
| 완료 | 분산 표현 | `distributed-representation` | 의미를 여러 수치 차원에 나누어 담는 표현 학습의 핵심 개념이다. 임베딩과 함께 현대 언어 모델 표현을 설명하는 기준점이다. |
| 완료 | 표현 | `representation` | 입력을 계산용 내부 형태로 재구성한 모습이다. 특징, 임베딩, 표현 학습을 연결하는 최상위 표현 계열 표제로 유지한다. |
| 완료 | 특징 선택 | `feature-selection` | 입력 후보 중 남길 특징을 고르는 표준 모델링 과정이다. 개별 열 선택 기준은 이 항목과 전처리 안에서 설명한다. |
| 완료 | 커널 | `kernel` | 더 풍부한 표현 공간의 비교를 함수 계산으로 다루는 표준 방법 개념이다. 특정 알고리즘 구현보다 표현 공간 관점으로 유지한다. |
| 완료 | 마진 | `margin` | 분류 경계와 가까운 사례 사이의 여유 폭을 가리키는 표준 경계 기반 분류 개념이다. 결정 경계와 함께 유지한다. |
| 완료 | 최대우도추정 | `maximum-likelihood-estimation-mle` | 관찰 데이터가 가장 그럴듯해지도록 파라미터를 찾는 표준 추정 방식이다. 로그 손실과 로지스틱 회귀 설명의 기준점으로 유지한다. |
| 완료 | 데이터 희소성 | `sparsity` | 가능한 조합 공간에 비해 관측 사례가 적어 안정적 추정이 어려운 표준 문제다. 데이터 부족 일반 의미가 아니라 언어 모델·통계 모델의 희소성 문맥으로 유지한다. |
| 완료 | 표준화 | `standardization` | 평균과 표준편차로 특징 범위를 맞추는 표준 전처리 변환이다. 일반 표준 만들기가 아니라 거리·모델 계산 전처리로 범위를 좁혀 유지한다. |
| 완료 | 인코더 | `encoder` | 입력을 문맥 반영 내부 표현으로 바꾸는 모델 구성 역할이다. 디코더와 역할을 분리하기 위해 유지한다. |
| 완료 | 인코더-디코더 | `encoder-decoder` | 입력 읽기와 출력 생성을 나누는 표준 시퀀스 모델 구조다. 고정 길이 벡터 병목과 attention 설명의 기준점으로 유지한다. |
| 완료 | 순환 신경망 | `recurrent-neural-network` | 숨은 상태를 다음 계산으로 넘기며 순서 데이터를 처리하는 표준 신경망 구조다. Transformer 전환 배경을 설명하기 위해 유지한다. |
| 완료 | 장기 의존성 | `long-term-dependency` | 오래전 정보가 뒤 판단에 중요하지만 전달되기 어려운 순차 모델 문제다. RNN 한계와 attention 전환을 잇는 기준점으로 유지한다. |
| 완료 | 다층 신경망 | `multilayer-neural-network` | 여러 층을 쌓아 중간 표현을 단계적으로 만드는 기본 신경망 구조다. 딥러닝의 깊이 개념을 설명하는 기준점으로 유지한다. |
| 완료 | 전문가 시스템 | `expert-system` | 규칙 기반 AI의 역사적 대표 응용 사례다. 특정 제품명이 아니라 규칙·지식 기반 접근의 한계를 설명하는 표제로 유지한다. |
| 완료 | 활용 | `exploitation` | 강화학습에서 이미 얻은 정보를 바탕으로 현재 좋은 행동을 고르는 표준 선택 축이다. 탐험과의 균형을 설명하기 위해 유지한다. |
| 완료 | 탐험 | `exploration` | 강화학습에서 새로운 행동을 시험해 정보를 얻는 표준 선택 축이다. 활용과의 균형을 설명하기 위해 유지한다. |
| 완료 | 정규화 | `regularization` | 과적합을 줄이기 위한 표준 학습 제약 개념이다. 드롭아웃, 가중치 감쇠 같은 개별 기법은 하위 사례로 흡수한다. |
| 완료 | 과소적합 | `underfitting` | 데이터 관계를 충분히 배우지 못한 일반화 실패 표제다. 과적합과 원인·대응 방향이 다르므로 별도 기준점으로 유지한다. |

| 완료 | 프롬프트 엔지니어링 | `prompt-engineering` | 입력 조건을 실험적으로 설계해 모델 반응을 안정화하는 실천 표제다. 단순 문장 작성이 아니라 실패 관찰 기반 설계로 유지한다. |
| 완료 | 결정 경계 | `decision-boundary` | 분류 모델이 클래스 영역을 나누는 표준 해석 표제다. 임계값·모델 점수와 구분되는 경계 개념으로 유지한다. |
| 완료 | 선형회귀 | `linear-regression` | 연속값 예측의 기본 회귀 모델 표제다. 회귀 일반 표제 안의 대표 기준선 모델로 유지한다. |

| 완료 | 모델 선택 | `model-selection` | 문제와 데이터 조건에 맞는 후보 모델군을 좁히는 표준 판단 과정이다. 특정 모델명을 늘리지 않기 위한 상위 관리 표제로 유지한다. |

## 후속 작업 순서

1. 평가 관련 표현은 `평가 지표`, `검증`, `인간 감독`, `사실성` 안에서 역할 분담으로 설명하고 단독 `평가` 또는 평가 방식별 표제가 다시 생기지 않게 한다.
2. 새 표제 후보는 단어별 예시 목록이 아니라 `운영 단위`, `구현 단위`, `구성 단위`, `설계 필드`, `국소 표현`, `임시 표현` 중 어디에 속하는지 먼저 판정한다.
3. 제외 범주가 주된 역할이면 인덱스에 추가하지 않고, 필요한 설명만 상위 표제나 본문 문맥으로 흡수한다.
