# 출처와 저작권 가이드라인

이 문서는 `AGENTS.md`에서 분리한 근거, 출처, 저작권, 예측성 내용 기준을 다룬다. 사실 주장, 외부 자료 반영, 인용, 자료 다운로드, 전망 문장을 다룰 때 먼저 확인한다.

## 근거와 출처

- AI가 생성한 문장은 기본적으로 초안이다. 사실 주장에는 근거가 필요하다.
- 외부 자료를 참조하거나 인용하면 반드시 출처를 남긴다.
- 출처에는 가능한 한 제목, 작성자 또는 기관, URL, 확인 날짜를 포함한다.
- 배포 본문에서 외부 URL 링크는 새 창에서 열리도록 Markdown 링크에 `{: target="_blank" rel="noopener noreferrer" }` 속성을 붙인다.
- 내부 문서, 로컬 예제 파일, 같은 사이트 안의 자산 링크에는 새 창 속성을 붙이지 않는다.
- 직접 인용은 따옴표 또는 인용 블록으로 구분한다.
- 요약이나 재서술도 출처를 남긴다.
- 출처가 없는 AI 생성 설명은 검증된 사실처럼 단정하지 않는다.
- 근거 검토는 URL을 붙이는 일이 아니라, 출처가 실제 주장과 연결되는지 확인하는 일이다.
- 자료를 본문에 반영할 때는 다음을 함께 판단한다.
  - 학술적 일반화 가능성
  - 해당 Section 중심 질문과의 관련성
  - 출처의 신뢰도
  - 최신성
- 기술 정의와 개념은 공식 문서, 표준 문서, 교과서, 학술 논문, 널리 쓰이는 교육 자료를 우선한다.
- 역사 설명은 1차 문헌, 논문, 학술 백과, 연구기관 자료, 신뢰 가능한 교재를 우선한다.
- 현재 동향, 제품 기능, 법률, 정책, 가격, 배포 제한처럼 바뀔 수 있는 정보는 작성 시점에 다시 확인한다.
- 참고 자료는 가능한 한 원문, PDF, HTML, 메타데이터를 `.tmp/` 아래에 내려받아 확인한 뒤 분석한다.
- 다운로드가 불가능하거나 접근 권한이 없는 자료는 원문 미확인 자료로 표시한다.
- 서로 다른 출처가 충돌하면 한쪽을 단정하지 말고 차이를 드러낸다.

## 저작권

- 한국 출판물, 국내 교재, 번역서, 서점 목차, 강의 자료, 블로그 글, 기사, 이미지, 도표, 코드 예제를 사용할 때는 대한민국 저작권법을 기준으로 검토한다.
- 이 저장소의 문서는 법률 자문이 아니다. 판단이 애매하면 `검증 필요`로 표시하고 원문 사용을 보류한다.
- 대한민국 저작권법 제28조의 공표된 저작물 인용 기준을 검토하되, 인용 가능 여부를 자동으로 단정하지 않는다.
- 이 저장소에서 외부 저작물을 인용할 때는 다음 작업 기준을 확인한다.
  - 인용 대상은 이미 공표된 저작물이어야 한다.
  - 인용 목적은 보도, 비평, 교육, 연구 등 인용의 필요성을 설명할 수 있는 목적이어야 한다.
  - 출처는 저자, 제목, 출판사 또는 매체, URL, 확인 날짜 등 가능한 범위에서 명확히 표시한다.
  - 내 글이 주가 되고, 인용된 타인의 표현은 보조 자료로만 사용되어야 한다.
  - 인용 분량은 필요한 범위로 제한하고, 원저작물의 핵심 가치나 시장 수요를 대체하지 않아야 한다.
  - 인용 부분은 본문과 구분되도록 따옴표, 인용 블록, 각주, 출처 표기 등을 사용한다.
  - 목차, 문제, 해설, 도표, 이미지, 번역문, 긴 문단은 특히 보수적으로 검토한다.
- 특정 책의 목차 배열, 장 제목, 설명 문구를 그대로 복제하지 않는다.
- 유료 전자책, 스캔본, 폐쇄형 강의자료, 무단 복제 PDF를 AI 도구에 입력해 요약하거나 변형하지 않는다.
- 교재나 강의의 연습문제, 풀이, 시험문제는 재사용하지 않고 자체 예제를 새로 만든다.
- 외부 도표, 이미지, 표지, 스크린샷은 라이선스나 이용 허락을 확인하지 않으면 사용하지 않는다.
- 공개 배포되는 GitHub Pages 문서는 개인 학습 메모보다 더 엄격하게 검토한다.
- 커리큘럼 통계를 만들 때는 공개된 합법 자료를 바탕으로 주제 수준에서 정규화하고, 원문 목차를 길게 옮기지 않는다.

## 예측성 내용

- `앞으로의 AI`, 기술 전망, 시장 전망, 사회적 영향 예측은 명확한 외부 근거를 기반으로 작성한다.
- 예측성 내용은 언론 보도, 뉴스, 칼럼, 연구기관 보고서, 기업 공식 발표, 학술 자료처럼 확인 가능한 자료를 우선한다.
- 개인적 추측, AI가 생성한 창작적 전망, 근거 없는 시나리오를 사실처럼 작성하지 않는다.
- 예측 문장에는 가능한 한 `누가`, `언제`, `어떤 맥락에서` 말했는지 드러낸다.
- 여러 출처가 다른 전망을 내놓으면 관점 차이를 비교한다.
