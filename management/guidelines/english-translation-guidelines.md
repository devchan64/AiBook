# 영문 번역 작성 가이드

작성일: 2026-07-07

## 목적

- 이 문서는 한국어 본문을 영어 본문으로 옮길 때 반복해서 확인할 기준을 정리한다.
- 목적은 `직역`보다 `개념 대응`, `Section ID 정합성`, `공통 릴리즈노트 추적`, `개념사전 연결`, `언어별 링크 품질`을 안정적으로 유지하는 것이다.
- 영어판은 별도 책이 아니라 같은 책의 다른 언어판이므로, 학습 순서와 개념 구조는 한국어판과 대응되어야 한다.

## 언제 이 문서를 보는가

- 새 영어 Section 파일을 처음 만들 때
- 기존 한국어 Section을 영어로 번역할 때
- 기존 영어 Section 파일이 이미 있을 때, 대응 한국어 원문의 `Version`과 비교해 업데이트 필요 여부를 판단할 때
- 영어판 `index.md`, `summary.md`, `mkdocs.yml`의 영어 `nav`를 구성할 때
- 개념사전 링크, 내부 링크, 외부 링크를 영어판 경로에 맞출 때
- 공통 릴리즈노트에 번역 반영 상태를 기록할 때

## 기본 원칙

- 영어 번역본의 기준 키는 파일명이 아니라 항상 `Section ID`다.
- 영어 번역본의 `Section ID`와 `Version`은 대응 한국어 본문과 같은 값을 유지한다.
- 영어 번역본 때문에 별도 Section 릴리즈노트 파일을 만들지 않는다. 릴리즈노트는 한국어·영어 공통 파일을 유지한다.
- 번역은 문장을 영어로만 바꾸는 일이 아니라, 같은 중심 질문과 같은 설명 책임을 영어 독자에게 다시 전달하는 일이다.
- 한국어 원고의 구조적 역할을 바꾸지 않는다.
  - 대표 설명 Section는 대표 설명 Section로 유지한다.
  - 후속 Section는 후속 Section로 유지한다.
  - 요약 페이지를 새 대표 설명 위치처럼 확장하지 않는다.
- 한국어판의 메타 진행 멘트를 영어판에서 임의로 늘리지 않는다.
- 영어 문장은 자연스럽게 다듬되, 한국어판에 없는 주장, 사례, 판단, 범위 확장을 임의로 추가하지 않는다.

## 파일 구조 원칙

- 영어판 본문은 기본적으로 `docs/en/` 아래에 둔다.
- Part 구조는 한국어판과 같은 `Part > Chapter > Section` 체계를 유지한다.
- 파일 경로가 달라도 대응 관계는 `Section ID`로 추적한다.
- 영어판 `nav`는 영어판에 실제 존재하는 파일만 연결한다.
- 영어판에서 아직 없는 본문을 한국어 경로로 섞어 연결하지 않는다. 언어 전환이 꼭 필요할 때만 명시적으로 다른 언어 문서로 이동시킨다.

## Section 메타데이터 원칙

- 영어 Section 제목 바로 아래에는 한국어판과 같은 두 줄만 둔다.
  - `Section ID`
  - `Version`
- `Section ID`는 번역 과정에서 바꾸지 않는다.
- `Version`은 한국어 원문을 기준으로 유지하되, 영어판만 별도 내용 수정이 생기면 공통 릴리즈노트에 그 차이를 기록한다.
- 제목 앞 인덱스도 한국어판과 같은 `Section ID` 체계를 유지한다.

## 기존 영어판 업데이트 판단 원칙

- 기존 영어 Section 파일이 있으면, 먼저 대응 한국어 원문의 `Version`과 영어 Section의 `Version`을 비교한다.
- 두 `Version`이 다르면, 영어판은 업데이트 필요 상태로 판단한다.
- 두 `Version`이 같아도 바로 최신이라고 단정하지 않는다.
  - 같은 날짜 안에서 한국어 원문과 영어판이 모두 손본 적이 있다면 공통 릴리즈노트의 최신 항목을 함께 확인한다.
  - `번역 동기화 메모`, `번역 반영 상태`, `원문 기준 버전`에 영어판이 실제로 최신 원문을 반영했는지 판단할 근거가 남아 있어야 한다.
- 기존 영어판이 있는데 공통 릴리즈노트에 번역 반영 근거가 없으면, 최소한 `확인 필요` 상태로 보고 대조 확인 후 갱신한다.
- 한국어 원문 `Version`이 올라갔고 영어판 `Version`이 이전 값에 머물러 있으면, 새 번역 작성이 아니라 기존 번역 업데이트 작업으로 처리한다.
- 한국어 원문 `Version`은 같고 영어판만 문장 다듬기나 링크 수정이 있었다면, 영어판 본문의 `Version`을 임의로 바꾸지 말고 공통 릴리즈노트에 언어별 추가 수정 사실을 남긴다.

## 번역 단위 원칙

- 기본 번역 단위는 문단이 아니라 `Section의 중심 질문`이다.
- 먼저 다음 네 가지를 고정한 뒤 문장을 번역한다.
  - 이 Section이 답하는 질문
  - 이 Section이 다루는 범위
  - 이 Section이 대표 설명 위치인지 후속 연결 위치인지
  - 이 Section에서 남겨야 할 최소 이해
- 표, 목록, 사례, 점검 질문은 한국어판의 학습 역할을 유지하는 방향으로 번역한다.
- 같은 의미를 영어에서 더 짧게 표현할 수 있더라도, 설명 단계가 사라지지 않게 한다.

## 용어 원칙

- 영어판은 한국어판의 `한국어(English)` 병기 규칙을 기계적으로 뒤집지 않는다.
- 영어 본문에서는 기본적으로 `English (Korean)` 병기를 강제하지 않는다.
- 영어 독자에게 필요한 경우에만 한국어 용어를 보조 표기로 둔다.
  - 예: 한국어판에서 같은 한국어 표면형이 다른 영어 개념으로 갈라지는 경우
  - 예: 개념사전 표제어와 직접 대응을 보여 주어야 하는 경우
- 다음처럼 혼동 가능성이 큰 용어는 영어판에서도 문맥을 분명히 나눈다.
  - `inference`
  - `reasoning`
  - `prediction`
  - `generation`
  - `model`
  - `parameter`
  - `level`
  - `layer`
- 영어 용어를 새로 단정하지 않는다. 한국어판의 의도를 보존하되, 영어권 표준 표현인지 확인한다.
- 한국어판에서 영어 원어를 병기한 이유가 `표준 용어 대응`이라면, 영어판에서는 그 표준 용어를 중심 표현으로 삼는다.

## 개념사전 연결 원칙

- 영어판도 개념사전 연결 정책을 그대로 따른다.
- 한 Section 안에서 같은 용어의 개념사전 직접 링크는 기본적으로 1회만 둔다.
- 가능하면 개념사전 페이지 전체가 아니라 해당 표제어 앵커로 연결한다.
- 영어판에서 같은 언어의 개념사전 페이지가 준비되어 있으면 그 경로를 우선 사용한다.
- 영어판 개념사전이 아직 완성되지 않았더라도, 표제어 대응 기준과 `Section ID` 기준점은 공통 개념사전과 공통 릴리즈노트에 맞춘다.
- 개념사전 표제어는 한국어와 영어를 함께 쓰는 원칙을 유지한다. 이는 번역 장식이 아니라 동음이의어, 다의어, 잘못된 위치 표기를 관찰하기 위한 기준이기 때문이다.

## 링크 원칙

- 영어판 내부 링크는 가능한 한 영어판 경로를 우선 가리킨다.
- 영어판 대응 문서가 아직 없으면 다음 셋 중 하나를 택한다.
  - 링크를 잠시 생략한다.
  - 영어판 안내 페이지로 연결한다.
  - 언어 전환 링크임을 명시하고 한국어판으로 연결한다.
- 외부 URL 링크는 한국어판과 동일하게 새 창 속성을 붙인다.
- 같은 사이트 내부 문서, 자산, 릴리즈노트 경로에는 새 창 속성을 붙이지 않는다.

## 도식과 표 원칙

- 도식 원본은 가능한 한 공용 영문 자산을 유지한다.
- 영어판 본문은 가능하면 기존 영문 라벨 도식을 그대로 사용한다.
- 한국어 설명문을 영어로 옮길 때, 도식 안의 라벨을 본문에서 다시 풀어 설명한다.
- 한국어 도식 파생본만 있는 경우에는 영문 도식이 꼭 필요한지 먼저 판단하고, 필요할 때만 영문 파생본을 만든다.

## 공통 릴리즈노트 원칙

- 릴리즈노트는 언어별로 분리하지 않는다.
- 영어 번역이 반영되면 기존 `management/release-notes/sections/` 파일 안에 기록한다.
- 최소한 다음 항목을 갱신한다.
  - `번역 동기화 메모`
  - `번역 반영 상태`
  - 필요하면 `원문 기준 버전`
- 영어판만 별도 문장 조정이 생겼다면, 공통 릴리즈노트에 `언어별 추가 수정` 성격이 드러나게 적는다.

## 권장 작업 순서

1. 대응 한국어 Section의 `Section ID`, `Version`, 중심 질문을 확인한다.
2. 기존 영어판이 있으면 영어 `Version`과 공통 릴리즈노트의 최신 번역 반영 기록을 먼저 대조해 업데이트 필요 여부를 판단한다.
3. 영어판 대응 경로를 만들거나 기존 파일을 연다.
4. 제목, `Section ID`, `Version`을 먼저 맞춘다.
5. 범위, 목표, 핵심 개념, 사례, 점검 질문 순서로 Section 구조를 번역하거나 갱신한다.
6. 개념사전 직접 링크가 1회 규칙을 지키는지 확인한다.
7. 영어판 내부 링크가 영어 경로를 우선 가리키는지 확인한다.
8. 공통 릴리즈노트의 번역 동기화 메모와 번역 반영 상태를 갱신한다.
9. 영어 `nav`가 실제 존재 파일만 가리키는지 확인한다.

## 번역 품질 점검 질문

- 이 영어 Section도 한국어판과 같은 중심 질문에 답하는가?
- 기존 영어판이 있었다면 한국어 원문의 현재 `Version`을 실제로 반영했는가?
- 한국어판의 설명 범위를 넘는 새 주장이나 새 사례를 임의로 추가하지 않았는가?
- 영어 용어 선택이 개념사전 표제어와 충돌하지 않는가?
- `inference`, `reasoning`, `prediction`, `generation` 같은 다의어를 문맥별로 분리했는가?
- 내부 링크가 영어판 우선 원칙을 지키는가?
- 개념사전 직접 링크가 Section 안에서 1회 규칙을 지키는가?
- 공통 릴리즈노트에서 이 번역 반영 사실을 추적할 수 있는가?
