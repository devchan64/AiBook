# 중국어 번역 작성 가이드

작성일: 2026-07-09

## 목적

- 이 문서는 한국어 본문을 중국어 본문으로 옮길 때 반복해서 확인할 기준을 정리한다.
- 목적은 `직역`보다 `개념 대응`, `Section ID 정합성`, `공통 릴리즈노트 추적`, `개념사전 연결`, `언어별 링크 품질`을 안정적으로 유지하는 것이다.
- 현재 중국어판은 한국어 원문과 같은 폴더의 `.zh.md` 언어 접미사 파일을 기준으로 관리한다.
- 중국어판은 별도 책이 아니라 같은 책의 다른 언어판이므로, 학습 순서와 개념 구조는 한국어판과 대응되어야 한다.

## 언제 이 문서를 보는가

- 새 중국어 Section 파일을 처음 만들 때
- 기존 한국어 Section을 중국어로 번역할 때
- 기존 중국어 Section 파일이 이미 있을 때, 대응 한국어 원문의 `Version`과 비교해 업데이트 필요 여부를 판단할 때
- 중국어판 `index.md`, `summary.md`, `mkdocs.yml`의 중국어 `nav`를 구성할 때
- 개념사전 링크, 내부 링크, 외부 링크를 중국어판 경로에 맞출 때
- 공통 릴리즈노트에 번역 반영 상태를 기록할 때

## 기본 원칙

- 중국어 번역본의 기준 키는 파일명이 아니라 항상 `Section ID`다.
- 중국어 번역본의 `Section ID`와 `Version`은 대응 한국어 본문과 같은 값을 유지한다.
- 중국어 번역본 때문에 별도 Section 릴리즈노트 파일을 만들지 않는다. 릴리즈노트는 언어별로 분리하지 않고 Section 공통 파일을 유지한다.
- 번역은 문장을 중국어로만 바꾸는 일이 아니라, 같은 중심 질문과 같은 설명 책임을 중국어 독자에게 다시 전달하는 일이다.
- 한국어 원고의 구조적 역할을 바꾸지 않는다.
  - 대표 설명 Section는 대표 설명 Section로 유지한다.
  - 후속 Section는 후속 Section로 유지한다.
  - 요약 페이지를 새 대표 설명 위치처럼 확장하지 않는다.
- 한국어판의 메타 진행 멘트를 중국어판에서 임의로 늘리지 않는다.
- 중국어 문장은 자연스럽게 다듬되, 한국어판에 없는 주장, 사례, 판단, 범위 확장을 임의로 추가하지 않는다.

## 파일 구조 원칙

- 중국어판 본문은 기본적으로 한국어 원문과 같은 폴더에 `.zh.md` 언어 접미사 파일로 둔다.
- 예: `docs/parts/part-04/chapter-19/section-01.md`에 대응하는 중국어판은 `docs/parts/part-04/chapter-19/section-01.zh.md`로 둔다.
- Part 구조는 한국어판과 같은 `Part > Chapter > Section` 체계를 유지한다.
- 파일 경로가 달라도 대응 관계는 `Section ID`로 추적한다.
- 중국어판 `nav`는 중국어판에 실제 존재하는 파일만 연결한다.
- 중국어판에서 아직 없는 본문을 한국어 기본 파일 경로로 섞어 연결하지 않는다. 언어 전환이 꼭 필요할 때만 명시적으로 다른 언어 문서로 이동시킨다.

## Section 메타데이터 원칙

- 중국어 Section 제목 바로 아래에는 한국어판과 같은 두 줄만 둔다.
  - `Section ID`
  - `Version`
- `Section ID`는 번역 과정에서 바꾸지 않는다.
- `Version`은 한국어 원문을 기준으로 유지하되, 중국어판만 별도 내용 수정이 생기면 공통 릴리즈노트에 그 차이를 기록한다.
- 제목 앞 인덱스도 한국어판과 같은 `Section ID` 체계를 유지한다.

## 기존 중국어판 업데이트 판단 원칙

- 기존 중국어 Section 파일이 있으면, 먼저 대응 한국어 원문의 `Version`과 중국어 Section의 `Version`을 비교한다.
- 두 `Version`이 다르면, 중국어판은 업데이트 필요 상태로 판단한다.
- 두 `Version`이 같아도 바로 최신이라고 단정하지 않는다.
  - 같은 날짜 안에서 한국어 원문과 중국어판이 모두 손본 적이 있다면 공통 릴리즈노트의 최신 항목을 함께 확인한다.
  - `번역 동기화 메모`, `번역 반영 상태`, `원문 기준 버전`에 중국어판이 실제로 최신 원문을 반영했는지 판단할 근거가 남아 있어야 한다.
- 기존 중국어판이 있는데 공통 릴리즈노트에 번역 반영 근거가 없으면, 최소한 `확인 필요` 상태로 보고 대조 확인 후 갱신한다.
- 한국어 원문 `Version`이 올라갔고 중국어판 `Version`이 이전 값에 머물러 있으면, 새 번역 작성이 아니라 기존 번역 업데이트 작업으로 처리한다.
- 한국어 원문 `Version`은 같고 중국어판만 문장 다듬기나 링크 수정이 있었다면, 중국어판 본문의 `Version`을 임의로 바꾸지 말고 공통 릴리즈노트에 언어별 추가 수정 사실을 남긴다.

## 번역 단위 원칙

- 기본 번역 단위는 문단이 아니라 `Section의 중심 질문`이다.
- 먼저 다음 네 가지를 고정한 뒤 문장을 번역한다.
  - 이 Section이 답하는 질문
  - 이 Section이 다루는 범위
  - 이 Section이 대표 설명 위치인지 후속 연결 위치인지
  - 이 Section에서 남겨야 할 최소 이해
- 표, 목록, 사례, 점검 질문은 한국어판의 학습 역할을 유지하는 방향으로 번역한다.
- 같은 의미를 중국어에서 더 짧게 표현할 수 있더라도, 설명 단계가 사라지지 않게 한다.

## 번역 검수 규칙

- 번역 검수는 항상 대응 한국어 원문과 대조해서 진행한다.
- 검수할 때는 한국어 원문과 중국어 번역본의 `빈 줄을 제외한 본문 라인 수`를 함께 확인한다.
- 중국어 번역본의 라인 수 차이는 한국어 원문 대비 `5% 미만`을 기본 기준으로 삼는다.
- 라인 수 차이가 `5% 이상`이면 번역을 바로 확정하지 않고, 다음 가능성을 먼저 점검한다.
  - 설명 단계 누락
  - 표나 목록의 과도한 압축
  - 사례, 점검 질문, 링크 문장의 생략
  - 문단 병합 과정에서 빠진 문장
- 이 기준은 `라인 수를 기계적으로 맞추기 위한 규칙`이 아니라, 과축약·누락을 빠르게 찾기 위한 검수 신호로 사용한다.
- 코드 블록, 인용 블록, 표 재배치처럼 번역보다 서식 영향이 큰 경우에는 차이 원인을 메모로 남기고 예외를 판단한다.

## 용어 원칙

- 중국어판은 한국어판의 `한국어(English)` 병기 규칙을 기계적으로 `중국어(English)`로 바꾸지 않는다.
- 중국어 본문에서는 표준 중국어 번역어가 안정적일 때 이를 우선 쓰고, 필요한 경우에만 영어 원어를 병기한다.
- 중국어 독자에게 필요한 경우에만 한국어 용어를 보조 표기로 둔다. 다만 중국어 개념사전 페이지에서는 한국어 표제어·한국어 병기·한국어 설명 문장을 독자용 항목 본문에 노출하지 않는다.
  - 예: 일반 중국어 Section에서 한국어판의 같은 한국어 표면형이 다른 영어 개념으로 갈라지는 경우
  - 예: 일반 중국어 Section에서 번역상 혼동을 막기 위해 한국어 표현을 한 번만 짧게 확인해야 하는 경우
- 다음처럼 혼동 가능성이 큰 용어는 중국어판에서도 문맥을 분명히 나눈다.
  - `inference`
  - `reasoning`
  - `prediction`
  - `generation`
  - `model`
  - `parameter`
  - `level`
  - `layer`
- 중국어 용어를 새로 단정하지 않는다. 한국어판의 의도를 보존하되, 중국어권 표준 표현인지 확인한다.
- 한국어판에서 영어 원어를 병기한 이유가 `표준 용어 대응`이라면, 중국어판에서도 필요시 영어 원어를 함께 남겨 다시 찾을 수 있게 한다.
- 중국어 용어를 새로 고정하거나 바꾸면 중국어 개념사전 단어별 원고와 병음별 공개 색인에 대응 관계를 반영하고, 필요한 경우 표준화된 외부 레퍼런스를 확인한다.

## 개념사전 연결 원칙

- 중국어판도 개념사전 연결 정책을 그대로 따른다.
- 한 Section 안에서 같은 용어의 개념사전 직접 링크는 기본적으로 1회만 둔다.
- 가능하면 개념사전 페이지 전체가 아니라 해당 표제어 앵커로 연결한다.
- 중국어판 본문에서 개념사전으로 연결할 때는 한국어 자음별 개념사전이 아니라 `docs/reference/concept-glossary-pinyin/*.zh.md`의 병음별 중국어 전용 페이지 앵커를 우선 사용한다.
- 중국어판 개념사전은 영문 개념사전과 같은 원칙으로 운영한다. 한국어 원문으로 되돌아가는 중간 링크가 아니라, 중국어 독자가 바로 읽을 수 있는 전용 본문 페이지여야 한다.
- 중국어판 개념사전 연결과 항목 구조는 `concept-glossary-guidelines.md`의 slug, 단어별 원고, 공개 색인 원칙을 따른다.
- 중국어판 개념사전 항목은 중국어 독자 기준으로 작성한다. 항목 본문에는 `Korean term:`에 해당하는 행, 한국어 병기, 한국어 설명 문장을 넣지 않는다.
- 한국어 개념사전의 `뜻`, `왜 중요한가`, `함께 볼 개념`, `중심 Section`, `등장 Section` 구조는 중국어판에서도 대응시키되, 필드명과 설명 문장은 중국어로 작성한다.
- 중국어판 개념사전의 관련 개념도 중국어 표제어를 우선 쓰고, 필요한 경우에만 영어 원어를 짧게 병기한다. 한국어 표기와 중국어·영어 표기를 함께 나열하지 않는다.
- 중국어판 개념사전이 아직 충분히 번역되지 않은 항목은 한국어 항목으로 되돌려 연결하지 않고, 해당 중국어 단어 파일을 보강 대상으로 남긴다.
- 중국어판에서 용어 대응이 흔들리면 먼저 중국어 개념사전 페이지와 단어별 원고에서 대표 표제어, 영어 기준 용어, `核心 Section`을 확인한다.
- 공개 배포 경로와 strict 빌드 기준의 실제 링크 형식은 `management/guidelines/repository-management-guidelines.md`와 `concept-glossary-guidelines.md`의 다국어 링크 원칙을 따른다.

## 링크 원칙

- 중국어판 내부 링크는 가능한 한 같은 폴더의 `.zh.md` 파일이나 중국어 공용 페이지를 우선 가리킨다.
- 중국어판 대응 문서가 아직 없으면 다음 셋 중 하나를 택한다.
  - 링크를 잠시 생략한다.
  - 중국어판 안내 페이지로 연결한다.
  - 언어 전환 링크임을 명시하고 한국어판으로 연결한다.
- 외부 URL 링크는 한국어판과 동일하게 새 창 속성을 붙인다.
- 같은 사이트 내부 문서, 자산, 릴리즈노트 경로에는 새 창 속성을 붙이지 않는다.

## 도식과 표 원칙

- 도식 원본은 가능한 한 공용 영문 자산을 유지한다.
- 중국어 공개 본문에는 중국어 라벨이 들어간 `.zh` 계열 도식을 직접 배치한다.
- SVG 링크와 Mermaid include 경로의 구체 규칙은 `management/guidelines/chart-guidelines.md`를 따른다.
- 한국어 도식 파생본만 있는 경우에는 중국어 도식이 실제 학습 흐름에 필요한지 먼저 판단하고, 필요하면 `.zh` 계열 파생본을 함께 만든다.

## 공통 릴리즈노트 원칙

- 릴리즈노트는 언어별로 분리하지 않는다.
- 중국어 번역이 반영되면 기존 `management/release-notes/sections/` 파일 안에 기록한다.
- 최소한 다음 항목을 갱신한다.
  - `번역 동기화 메모`
  - `번역 반영 상태`
  - 필요하면 `원문 기준 버전`
- 중국어판만 별도 문장 조정이 생겼다면, 공통 릴리즈노트에 `언어별 추가 수정` 성격이 드러나게 적는다.

## 권장 작업 순서

1. 대응 한국어 Section의 `Section ID`, `Version`, 중심 질문을 확인한다.
2. 기존 중국어판이 있으면 중국어 `Version`과 공통 릴리즈노트의 최신 번역 반영 기록을 먼저 대조해 업데이트 필요 여부를 판단한다.
3. 중국어판 대응 파일을 만들거나 기존 `.zh.md` 파일을 연다.
4. 제목, `Section ID`, `Version`을 먼저 맞춘다.
5. 범위, 목표, 핵심 개념, 사례, 점검 질문 순서로 Section 구조를 번역하거나 갱신한다.
6. 한국어 원문과 중국어 번역본의 `빈 줄 제외 라인 수` 차이가 `5% 미만`인지 확인하고, 넘으면 누락·과축약 여부를 다시 점검한다.
7. 개념사전 직접 링크가 1회 규칙을 지키는지 확인한다.
8. 개념사전 링크가 한국어 자음별 페이지가 아니라 중국어 전용 개념사전 항목 앵커를 가리키는지 확인한다.
9. 중국어판 내부 링크가 `.zh.md` 파일이나 중국어 공용 페이지를 우선 가리키는지 확인한다.
10. 공통 릴리즈노트의 번역 동기화 메모와 번역 반영 상태를 갱신한다.
11. 중국어 `nav`가 실제 존재 파일만 가리키는지 확인한다.

## 번역 품질 점검 질문

- 이 중국어 Section도 한국어판과 같은 중심 질문에 답하는가?
- 기존 중국어판이 있었다면 한국어 원문의 현재 `Version`을 실제로 반영했는가?
- 한국어판의 설명 범위를 넘는 새 주장이나 새 사례를 임의로 추가하지 않았는가?
- 한국어 원문과 비교했을 때 중국어 번역본의 `빈 줄 제외 라인 수` 차이가 `5% 미만`인가?
- 5%를 넘었다면 서식 차이인지, 실제 설명 누락이나 과축약인지 확인했는가?
- 중국어 용어 선택이 개념사전 표제어와 충돌하지 않는가?
- `inference`, `reasoning`, `prediction`, `generation` 같은 다의어를 문맥별로 분리했는가?
- 내부 링크가 중국어판 우선 원칙을 지키는가?
- 개념사전 직접 링크가 Section 안에서 1회 규칙을 지키는가?
- 개념사전 링크가 한국어 항목으로 우회하지 않고 중국어 전용 항목 본문으로 이어지는가?
- 중국어 개념사전 항목에 한국어 표제어, 한국어 설명 문장, 한국어와 중국어·영어를 함께 나열한 관련 개념이 남아 있지 않은가?
- 공통 릴리즈노트에서 이 번역 반영 사실을 추적할 수 있는가?
