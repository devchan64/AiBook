# Section Release Note

- Section ID: `P4-14.2`
- Source File: `docs/parts/part-04/chapter-14/section-02.md`

### v2026.07.11

- 변경 이유: 트리 과적합 절의 예제가 깊이에 따른 train/test 차이 설명까지는 있었지만, 복잡도 손잡이를 직접 비교하고 기록 언어로 남기는 연습까지는 이어지지 않아 학습 밀도가 부족했음. / Section 말미 표지도 `체크리스트`로 통일할 필요가 있었음. / `ccp_alpha`를 설명만 하고 실제로 한 번도 흔들어 보지 않는 공백과 사례 상위 제목 중복이 남아 있었음.
- 본문 반영: `max_depth` 예제 뒤에 `min_samples_leaf`를 함께 바꾸는 추가 비교 실습을 넣어 깊이와 leaf 크기를 같이 읽게 했다. 이어서 `복잡도 손잡이를 기록 언어로 남기기` 연습, `Part 4 목표 회수` 문단, `보인 구조 / 해석 경계 / 다음 질문` 표를 추가해 과적합 설명이 depth 숫자 암기보다 복잡도 판단 흐름으로 읽히게 정리했다. / `짧은 점검` 표지는 `체크리스트`로 통일했다. / 추가로 `ccp_alpha`를 바꾸는 pruning 비교 실습과 기록 표를 넣었고, 사례 상위 제목 중복을 정리했으며 도입부 질문형 단문도 일반 본문 문장으로 다시 묶었다. / 마지막에는 단일 트리 손잡이 조정에서 랜덤포레스트로 넘어가는 다음 절 연결 문장을 보강했다. / 사례 구간에는 leaf 장면을 기준으로 과적합을 읽는 짧은 판정 표를 추가해, 점수표 이전에 구조 신호를 읽게 했다.
- 번역 동기화 메모: 추가 실습과 기록 표, 체크리스트 표지 통일, pruning 비교 실습, 도입부 문장 재구성이 반영되었으므로 번역 시 `depth-only vs leaf-size`, `ccp_alpha` 비교 구조와 `보인 구조 / 해석 경계 / 다음 질문` 틀을 유지해야 한다. / pending
