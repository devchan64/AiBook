- Section ID: `P4-14.1`

### v2026.07.11

- 변경 이유: 결정트리 도입 절의 예제와 연습이 `첫 split 찾기`에서 멈춰 있어, 초심자가 데이터 변화에 따른 구조 흔들림과 다음 판단 질문까지 직접 따라가기에는 학습 밀도가 부족했음. / Section 말미 표지를 `체크리스트`로 통일하고 사례-예제-회수 흐름을 더 단단하게 닫을 필요가 있었음. / 도입부의 인용형 질문·정의 문장을 일반 본문 흐름으로 낮출 필요가 있었음.
- 본문 반영: 기존 `좋은 첫 질문 찾기` 예제를 유지하면서 label 하나를 바꿔 첫 split이 어떻게 달라지는지 비교하는 추가 실습을 넣었다. 또한 `직접 작은 트리 기록 남기기` 연습, `Part 4 목표 회수` 문단, `보인 구조 / 해석 경계 / 다음 질문` 기록 표를 추가해 예제 실행 뒤의 판단 흐름을 더 직접적으로 드러냈다. / 실무 장면 하위 제목 구조를 정리했고, `짧은 점검` 표지도 `체크리스트`로 통일했다. / 도입부는 질문형 단문과 사전식 정의를 일반 본문 문장으로 다시 묶었고, P4-13.2의 표현 공간 관점에서 `질문 순서` 관점으로 넘어오는 연결 문장을 보강했다. / 추가로 원래 데이터와 label 변경 뒤를 바로 비교하는 요약 표와 짧은 기록 예시를 넣어, 예제 결과를 기록 언어로 더 빨리 회수하게 했다.
- 번역 동기화 메모: 추가 실습과 기록 표, 체크리스트 표지 통일, 도입부 문장 재구성이 반영되었으므로 번역 시 `원래 데이터 vs label 변경 뒤` 대비 구조와 `보인 구조 / 해석 경계 / 다음 질문` 틀을 유지해야 한다. / pending
