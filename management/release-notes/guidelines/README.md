# 가이드라인·관리 문서 릴리즈노트

작성일: 2026-07-06

이 디렉터리는 Section 본문이 아닌 문서의 개정 이력을 관리한다. 현재 범위에는 개념사전 원고, 개념사전 규칙, 소개 페이지, Part 시작/마무리 페이지, 목차 문서가 포함되어 있다.

## 어떤 문서를 여기서 관리하는가

- 개념사전 원고
- 개념사전 작성 규칙
- 사이트 소개 페이지
- Part 시작 페이지와 Part 마무리 페이지
- 독자용 목차 문서

## 기본 형식

- 문서 상단에는 `Document ID`와 `Source File`을 둔다.
- 각 개정 이력은 `### vYYYY.MM.DD` 또는 같은 날짜 안의 세부 버전 항목으로 기록한다.
- 각 항목에는 다음을 우선 남긴다.
  - 변경 이유
  - 문서 반영 내용
  - 번역 동기화 메모
  - 번역 반영 상태
  - 관련 자산
  - 원문 기준 버전

## 현재 파일

- `concept-glossary.md`
- `concept-glossary-guidelines.md`
- `index-page.md`
- `part-01-index.md`
- `part-01-summary.md`
- `part-02-index.md`
- `table-of-contents.md`

## 후속 확장 기준

- 새 가이드라인 문서에 개정 이력이 필요하면 이 디렉터리에 같은 형식으로 추가한다.
- Section 본문과 직접 대응하는 문서는 `sections/`로 보내지 않고, 문서 성격이 가이드라인·관리 문서인지 먼저 확인한다.
