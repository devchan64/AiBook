# 릴리즈노트 인덱스

작성일: 2026-07-06

이 디렉터리는 책 본문 문서의 개정 이력만 관리한다. 원칙 문서, 가이드라인, 분석 메모, 작업 메모의 리비전노트는 이곳에 두지 않는다.

## 구조

- `sections/`
  - 책 본문 Section, Part 시작 페이지, Part 마무리 페이지의 개정 이력을 둔다.
  - `Section ID` 또는 Part 단위 식별자를 기준으로 버전과 번역 동기화를 추적한다.

## 운영 원칙

- 책 본문을 수정할 때만 이 디렉터리의 릴리즈노트를 갱신한다.
- 원칙 문서와 가이드라인 문서를 수정할 때는 문서 자체를 직접 갱신하고, 별도 리비전노트는 만들지 않는다.
- 새 릴리즈노트를 추가할 때는 먼저 그 문서가 배포 대상 본문인지 확인한다.
- 세부 형식과 파일명 규칙은 `sections/README.md`와 `sections/section-release-note-template.md`를 따른다.
