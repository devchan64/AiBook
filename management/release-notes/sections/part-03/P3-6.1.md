### v2026.07.07

- 변경 이유: 도입부가 `여기서는 ... 고정합니다`라는 절 역할 안내를 먼저 두어, 특징 설계 개념보다 편집 메타가 앞섰다.
- 본문 반영: 특징 설계를 `요약 표 숫자 사용`이 아니라 `비교 구조를 숫자 표현으로 다시 고르는 일`로 바로 설명하도록 첫 문단을 정리했다.
- 변경 이유: 특징 유형 표는 있었지만, 초심자가 `현장의 질문`을 `특징 설계`로 어떻게 옮겨야 하는지 즉시 연결하기에는 한 단계 더 필요했다.
- 본문 반영: `현장에서 먼저 나오는 질문 -> 우선 만들 특징 -> 그 특징이 먼저 필요한 이유` 대응표와 보강 문단을 추가해, 전체 수준, 후반 붕괴, 흔들림, 타이밍 차이가 각각 어떤 특징으로 옮겨지는지 직접 연결했다.
- 변경 이유: 특징 설계 대표 Section 도입에 남아 있던 `Part 3 안에서 ... 대표 설명 위치` 문구를 직접 설명형 기준으로 맞출 필요가 있었다.
- 본문 반영: 어떤 구조를 숫자 특징으로 남길지 정하는 도입을 `여기서는 ... 기준을 먼저 고정합니다`로 바꾸어, 개념사전 연결과 함께 이 Section의 기준점 역할이 메타 문구 없이 읽히게 정리했다.
- 변경 이유: 특징 설계 도입 절도 마지막 자기점검 구간을 특징 선택 관점 재호출과 확인 항목으로 분리해 Part 3 기준선을 맞출 필요가 있었다.
- 본문 반영: 어떤 구조를 어떤 특징으로 남길지 다시 떠올려야 하는 상황을 `언제 이 관점을 먼저 떠올려야 하는가`로 추가하고, 기존 `짧은 점검`은 유지했다.

- 번역 동기화 메모: when translated, keep the feature-design recall prompts separate from the short self-check bullets. / pending

### v2026.07.06

- 변경 이유: 특징 설계 절이 평균·기울기·변동성을 소개하고 있었지만, 어떤 구조에 어떤 특징을 먼저 붙일지와 절 끝 점검 장치가 초심자 기준에서 더 필요했다.
- 본문 반영: 전체 수준, 구간 차이, 흔들림, 급격한 변화에 대응하는 특징 선택 기준표를 추가하고, 절 끝에는 특징 설계 기준을 확인하는 짧은 질문을 넣었다.
- 변경 이유: 특징 설계 대표 설명 위치 문장에 남아 있던 `다시 돌아오면 됩니다` 표현을 직접 설명형으로 정리할 필요가 있었다.
- 본문 반영: 3.11의 숫자 특징 설계 큰 축과 개념사전 연결을 기준 위치 설명으로 바꾸어, 뒤 절들이 참조하는 대표 설명 위치가 더 직접적으로 읽히게 다듬었다.
- 변경 이유: 특징 도입 절에서도 `초심자는 종종`, `도움이 된다` 같은 메타 표현을 줄이고, 특징이 설계된 표현이라는 논리가 본문 전개 안에서 직접 드러나게 정리.
- 본문 반영: 도입의 독자 호명 표현을 일반 서술로 바꾸고, 특징 유형 표와 설계 질문의 도입도 역할 설명 중심으로 다듬었다. 평균/기울기/변동성 예시 구조는 유지했다.
- 변경 이유: 특징 도입 절의 도입과 다음 절 연결에 남아 있던 `생각하기 쉽습니다`, `해 봅시다`, `살펴보겠습니다` 같은 유도형 표현을 직접 설명형 문장으로 정리할 필요가 있었다.
- 본문 반영: 특징을 많이 넣는 발상을 `받아들이기 쉽습니다`로 조정하고, 동작 1회 예시 도입을 `하겠습니다`로 바꾸었다. 다음 절 연결 문장도 `다룹니다`로 정리해 특징 설계에서 세그먼트 표현으로 넘어가는 흐름을 더 직접적으로 읽히게 했다.
- 변경 이유: Part 3 앞단에 데이터 모델링 진입 챕터를 추가하면서 기존 Section의 번호 체계와 파일 경로를 한 칸씩 뒤로 재배치할 필요가 있었다.
- 본문 반영: Section 제목 번호, Section ID, 본문 경로, 목차 대응 위치를 새 Part 3 번호 체계에 맞춰 갱신했다. 본문 설명 구조와 사례 흐름은 유지했다.
- 변경 이유: 특징 도입 Section이 개별 특징 정의보다 `원시 로그에서 남긴 구조를 어떤 특징으로 비교 가능하게 만들 것인가`라는 리팩터링 흐름 안에서 읽혀야 했다.
- 본문 반영: Section 제목을 `비교할 구조는 어떤 특징으로 남기는가`로 조정하고, 요약 표 이후 어떤 구조를 남길지 정하는 단계라는 문장을 도입에 보강했다. 마지막 연결도 숫자 특징에서 중간 표현으로 이어지도록 정리했다.
- 변경 이유: 3.11과 3.12를 연속으로 읽을 때 3.11이 `특징 설계`의 대표 설명 위치라는 점이 더 분명해야, 뒤 절이 같은 특징 정의를 다시 반복하지 않고 중간 표현으로 자연스럽게 좁혀질 수 있었다.
- 본문 반영: 3.11을 Part 3 안에서 숫자 특징으로 비교 구조를 남기는 대표 설명 위치라고 명시했다. 또한 핵심 문단에서 `특징이 무엇인가`를 다시 정의하기보다 어떤 구조를 숫자 특징으로 남길지 고르는 일이 중심이라는 점을 보강했다.
- 변경 이유: Part 3 Section 제목 인덱스를 `Section ID`와 같은 `P3-6.1` 형식으로 맞추는 규칙을 적용할 필요가 있었다.
- 본문 반영: 제목 앞 인덱스를 `3.11`에서 `P3-6.1`로 바꿔 본문 제목과 `Section ID` 표기가 같은 체계를 가리키도록 맞췄다.
