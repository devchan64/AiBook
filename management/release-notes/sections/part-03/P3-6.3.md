### v2026.07.08

- 변경 이유: 제목과 도입이 `뒤에서 학습될 표현`, `나중에 내부 패턴을 배우는 일`을 전면에 세워, 현재 절의 경계 설명보다 뒤 단계 예고가 먼저 보였다.
- 본문 반영: 제목을 `사람이 만든 특징과 모델이 학습하는 표현은 어떻게 구분되는가`로 바꾸고, 도입도 입력 구조를 정하는 일과 그 입력 안에서 표현을 학습하는 일을 구분하는 현재 질문으로 다시 열었다.

- 변경 이유: 중간 표가 `표 데이터용 모델`, `기본 신경망`, `순차 모델`, `attention 계열` 같은 뒤 학습 구조 명칭을 세워, 현재 입력 구조 차이 설명보다 모델 계열 예고처럼 읽혔다.
- 본문 반영: 해당 표를 `지금 더 잘 남는 것` 중심으로 다시 써서, 요약 벡터·구간별 특징·토큰 시퀀스가 각각 어떤 정보 구조를 더 직접 보존하는지 비교하게 바꾸었다.

- 변경 이유: 도입과 중간 표현 설명이 `뒤에서 딥러닝이...`, `Part 5에서...`를 먼저 호출해, 현재 절의 입력 명세 설명보다 뒤 Part handoff가 앞에 보였다.
- 본문 반영: 도입을 사람이 정하는 입력 구조와 모델이 나중에 배우는 내부 패턴의 차이로 바로 열고, 중간 표현 문단도 현재 구조 보존 효용 중심으로 정리했다.

- 변경 이유: 후속 Section 도입부가 `중간 표현`을 반복 핵심 개념으로 다시 세우면서도 개념사전 직접 앵커로 되돌리지 않아, 후속 Section 축약 규칙이 느슨하게 보였다.
- 본문 반영: 도입 첫 문장과 핵심 구분 문장에서 `중간 표현(intermediate representation)`을 개념사전 직접 앵커로 연결했다.

- 변경 이유: `상위 프레임` 재진술 표가 다른 Section들과 같은 마감 템플릿으로 반복되어, 본문이 교안형으로 굳어 보였다.
- 본문 반영: 말미의 `상위 프레임` 표를 제거하고, 현재 설명을 표 재진술 없이 직접 마무리하도록 정리했다.

- 변경 이유: `이 프레임을 쓰면` 식의 결론 문장이 다른 Section들과 같은 어조로 반복되어, 마감 문체가 다시 템플릿형으로 굳어 보였다.
- 본문 반영: 상위 프레임 표는 유지하고, 마지막 문장을 직접 진술형 결론으로 바꿨다.

- 변경 이유: `일반화된 상위 프레임으로 다시 보면` 제목이 Part 3 전반에 반복되어, 현재 절 설명도 같은 템플릿형 마감으로 굳어 보였다.
- 본문 반영: 반복 제목을 제거하고, 상위 프레임 표와 정리 문장을 현재 설명 흐름 안에 직접 이어 붙였다.

- 변경 이유: 이 절이 `뒤 Part 인계`와 책임 분할 설명을 너무 크게 전면에 세워, 현재 Section이 다뤄야 할 `입력 명세와 표현 학습의 차이`보다 구조 인계 메모처럼 읽히는 문제가 있었다.
- 본문 반영: 도입부의 `지금 하는 일 / 뒤 Part에서 이어지는 일` 표를 `세 표현 방식의 역할` 표로 줄이고, `어디까지가 Part 3이고, 어디서부터가 뒤 Part인가` 절을 `입력 명세와 표현 학습은 어디서 갈리는가` 절로 바꿨다. 마무리 예시도 `Part 4`, `Part 5` 인계 설명 대신 입력이 만들어진 뒤 모델이 그 안에서 패턴을 학습한다는 흐름으로 고쳐, Section 중심 질문 안에서 설명이 닫히도록 정리했다. 기존의 상위 프레임 표와 출처는 유지했다.
