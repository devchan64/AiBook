### v2026.07.19
- 예제 보강: `label_column_to_try` 조작값과 라벨 후보 존재 여부 출력을 추가해, 원천데이터를 학습 문제로 읽기 전에 샘플 단위와 라벨 후보를 실제 열 기준으로 확인해야 한다는 점을 코드와 해설에서 확인하게 했다.
- 예제 보강: 라벨 후보 판정을 `열 존재 여부`만 보지 않고 `candidate unit`, `same unit as one event`, `stable label meaning known`, `usable label candidate`로 나누어 출력하도록 조정했다. `label_column_to_try`를 `"flow"`로 바꾸면 열은 있어도 시점별 센서값이므로 라벨 후보로는 탈락한다는 점이 출력과 해설에서 드러나게 했다.
- 예제 보강: 원시 로그 입력을 `docs/assets/part-03/chapter-03/p3_3_1_source_operation_log.csv`로 분리하고, 예제 코드가 `pd.read_csv()`로 실제 CSV 자산을 읽어 원시 입력 크기와 동작 단위 요약표를 출력하도록 조정했다.
- 예제 보강: CSV 입력을 36행으로 확장하고 9개 이벤트, 여러 recipe/batch 조건을 포함해 샘플 단위와 라벨 후보 점검이 더 충분한 원시 로그 위에서 보이도록 했다.
