### v2026.07.08

- 변경 이유: 데이터 질문 구조를 설명하는 대표 Section인데도 `출처와 참고 자료`가 빠져 있어, 샘플 단위·비교 기준·결과 구조를 함께 드러내야 한다는 일반 원리가 본문 끝에서 직접 회수되지 않았다.
- 본문 반영: Google ML Glossary, BLS `Base period`, Fayyad의 KDD 개관 글을 `출처와 참고 자료`에 추가해, 좋은 데이터 질문이 example 단위, reference comparison, problem framing을 함께 여는 문장이라는 점을 보강했다.

- 변경 이유: 도입부가 `Part 3 초반을 읽을 때 가장 자주 생기는 막힘` 같은 독자 상태 메타와 모델 이름 예시를 먼저 세워, 현재 절의 질문 구조 설명보다 메타 상황이 앞에 보였다.
- 본문 반영: 첫 문단을 `무엇을 한 건으로 볼지`, `무엇을 무엇과 비교할지`, `최종적으로 무엇을 알고 싶은지`라는 데이터 질문의 구조 설명으로 바로 다시 열었다.

- 변경 이유: 좋은 질문 예시 표에 `Part 5 연결`을 직접 적어, 현재 질문의 효용보다 뒤 Part 예고가 먼저 보이는 한 줄이 남아 있었다.
- 본문 반영: 해당 예시의 설명을 샘플 단위와 입력 구조를 바로 정하게 해 준다는 현재 절의 효용 중심 문장으로 바꾸었다.

- 변경 이유: 말미가 `이 절은 ... 연결 절`처럼 절의 배치 역할을 직접 설명해, 데이터 질문 자체의 정의보다 편집자 메타 문장이 먼저 보였다.
- 본문 반영: `질문을 고쳐 쓰는 일`이 저장 구조를 샘플과 표 구조로 다시 읽는 출발점이라는 직접 설명으로 바꾸고, 같은 뜻을 절의 역할 소개 없이 개념 전개 안에서 정리했다.

- 변경 이유: `상위 프레임`을 전면 삭제하면 현재 절의 일반화된 메타 전개까지 함께 약해질 수 있어, 기준점 자체는 남기되 표 템플릿 의존만 줄일 필요가 있었다.
- 본문 반영: 반복 `상위 프레임` 표는 유지하지 않고, 현재 절의 판단을 더 넓은 개념 축으로 다시 묶는 산문 문장을 말미에 보강했다.

- 변경 이유: `상위 프레임` 재진술 표가 다른 Section들과 같은 마감 템플릿으로 반복되어, 본문이 교안형으로 굳어 보였다.
- 본문 반영: 말미의 `상위 프레임` 표를 제거하고, 현재 설명을 표 재진술 없이 직접 마무리하도록 정리했다.

- 변경 이유: 후속 Section가 `검토 후보 큐`와 `목표 라벨 후보`를 반복 핵심 개념으로 다시 쓰면서도 개념사전 대표 표제어로 바로 되돌아가는 직접 앵커가 없었다.
- 본문 반영: 도입부에서 `검토 후보 큐(review queue)`와 `목표 라벨 후보(target candidate)`를 개념사전 직접 앵커로 연결해, 질문 설계 설명에서도 핵심 산출물 표제어로 바로 복귀할 수 있게 했다.
- 변경 이유: `일반화된 상위 프레임으로 다시 보면` 제목이 Part 3 전반에 반복되어, 현재 절 설명도 같은 템플릿형 마감으로 굳어 보였다.
- 본문 반영: 반복 제목을 제거하고, 상위 프레임 표와 정리 문장을 현재 설명 흐름 안에 직접 이어 붙였다.

- 변경 이유: 말미의 `짧은 점검`, `언제 이 관점을 먼저 떠올려야 하는가`, 본문 중간의 `이 절은 ... 문제로 다시 볼 수 있습니다`, `이 프레임을 잡아 두면`, `왜 이 절이 ... 필요한가` 같은 메타 템플릿이 설명보다 먼저 보이는 문제가 남아 있었다.
- 본문 반영: 반복적인 메타 템플릿을 걷어내고, 중심 개념 설명과 사례 흐름만 남기도록 Section 말미와 중간 메타 문장을 정리했다. 상위 프레임 뒤의 결론 문장은 직접 진술형으로 바꾸고, `왜 이 절이 앞단에 필요한가` 소제목은 일반 설명 문단으로 흡수했다.
- 변경 이유: 데이터 질문의 세 요소는 잘 설명하고 있었지만, 이를 더 일반적인 problem framing 프레임으로 다시 묶고 최소 외부 근거와 연결하는 보강이 부족했다.
- 본문 반영: `대상 단위 -> 알고 싶은 결과 -> 비교 또는 산출물 구조`라는 상위 프레임을 추가하고, Google ML Glossary의 `labeled example`, `label leakage`와 BLS `Base period`를 `출처와 참고 자료`에 반영했다.

### v2026.07.07

- 변경 이유: `작은 예시로 보기`라는 소제목이 남아 있어, 이미 Python 예제를 제거하고 Mermaid 흐름도로 바꾼 현재 구성과 이름이 어긋나 있었다.
- 본문 반영: 해당 소제목을 `작은 도식으로 보기`로 바꿔, 이 구간이 코드 예제가 아니라 질문 문장과 다음 표 구조의 대응을 보여 주는 시각 예시임을 더 분명히 했다.
- 변경 이유: Part 3 앞단에는 `질문을 먼저 정한다`는 원칙은 있었지만, 초심자가 실제로 어떤 문장을 데이터 질문으로 써야 하는지는 별도 Section으로 고정돼 있지 않았다.
- 본문 반영: 모델 이름 중심의 빠른 표현을 샘플 단위, 알고 싶은 것, 비교 기준/결과 형식이 드러나는 데이터 질문으로 고쳐 쓰는 새 Section을 추가했다. 좋은 질문과 아직 이른 질문을 비교하고, 질문 문장이 바뀌면 바로 뒤의 표 구조가 달라진다는 대응 관계를 보강했다.
- 변경 이유: `작은 예시로 보기` 구간의 Python 코드는 질문 문장을 고쳐 쓰는 현재 절의 중심 질문과 직접 연결되지 않았고, 단순 문자열 대응을 출력해도 독자가 왜 여기서 Python을 봐야 하는지 이해하기 어려웠다.
- 본문 반영: 질문 문장과 다음 표 구조의 대응은 표와 해설 문장만으로 충분하다고 보고 Python 예제와 예상 출력을 제거했다. 대신 같은 원천데이터라도 질문이 달라지면 바로 뒤의 표 구조가 달라진다는 설명 문장을 남겨 절의 핵심을 더 직접적으로 읽히게 정리했다.
- 변경 이유: Python 예제를 제거한 뒤에도 `질문 문장 -> 다음 표 구조` 대응을 시각적으로 바로 읽을 보조 장치가 있으면 초심자가 흐름을 더 빨리 잡을 수 있었다.
- 본문 반영: `작은 예시로 보기` 표 아래에, 질문 유형이 달라질 때 바로 이어지는 표 구조가 달라지는 대응을 보여 주는 Mermaid 흐름도를 추가했다. 코드 실행 예제 대신 절의 중심 질문과 직접 연결되는 시각 보조로 바꿨다.
