# Section Release Note

- Section ID: `P3-9.11`

### v2026.07.11

- 변경 이유: 대표 target, 정의 버전, 병존 후보를 항목으로는 정리했지만, 서로 다른 후보가 실제로 어떻게 질문을 갈라놓는지 사례가 부족해 별도 절로서의 설득력이 약했다.
- 본문 반영: `review_needed`, `final_status`, `status_type`, `priority_bucket`가 함께 있는 표를 추가하고, 같은 사건도 대표 target을 어디에 두느냐에 따라 같은 정답이 되기도 하고 다른 정답이 되기도 한다는 설명을 보강했다.
- 변경 이유: 도입 첫 문장에 `운영 데이터`, `failure_type` 같은 표현이 남아 있어, 여러 target 후보의 병존과 정의 버전 관리라는 현재 절의 핵심보다 특정 업무 라벨 체계가 먼저 떠오를 수 있었다.
- 본문 반영: 도입을 `현실 데이터`와 `status_type` 기준으로 일반화해, 대표 target 고정과 정의 버전 관리가 어떤 도메인에서도 읽히는 문제 정의 판단으로 보이도록 정리했다.
- 변경 이유: `보조 target 후보` 설명이 `나중에 비교하거나 확장할 가능성`을 먼저 호출해, 현재 절의 핵심인 여러 target 후보의 현재 병존 상태 관리보다 후속 활용 뉘앙스가 남아 있었다.
- 본문 반영: 해당 항목을 `함께 관리할 다른 target 후보`로 바꾸어, 지금 어떤 결과 후보들이 병존하는지와 정의 버전을 어떻게 묶어 둘지에 초점을 맞추도록 정리했다.
- 번역 동기화 메모: English and Simplified Chinese translations now include the representative-target rationale, the conflicting-scene table, and the coexistence-management framing for multiple target candidates. / reflected in `docs/parts/part-03/chapter-09/section-11.en.md`, `docs/parts/part-03/chapter-09/section-11.zh.md`
- 번역 반영 상태: 영문·중국어 간체 반영 완료
- 관련 자산: 없음.

### v2026.07.08

- 변경 이유: `상위 프레임`을 전면 삭제하면 현재 절의 일반화된 메타 전개까지 함께 약해질 수 있어, 기준점 자체는 남기되 표 템플릿 의존만 줄일 필요가 있었다.
- 본문 반영: 반복 `상위 프레임` 표는 유지하지 않고, 현재 절의 판단을 더 넓은 개념 축으로 다시 묶는 산문 문장을 말미에 보강했다.

- 변경 이유: `상위 프레임` 재진술 표가 다른 Section들과 같은 마감 템플릿으로 반복되어, 본문이 교안형으로 굳어 보였다.
- 본문 반영: 말미의 `상위 프레임` 표를 제거하고, 현재 설명을 표 재진술 없이 직접 마무리하도록 정리했다.

- 변경 이유: 핵심 판단을 백틱 독립 문장으로 따로 세워 본문 흐름보다 강조 문구가 먼저 보였다.
- 본문 반영: 대표 target과 정의 버전 고정 문장을 일반 문단 안으로 흡수해 현재 절의 문제 정의 설명과 자연스럽게 이어지도록 정리했다.
- 변경 이유: `일반화된 상위 프레임으로 다시 보면` 제목이 반복되면서, 대표 target과 정의 버전 설명도 다른 Section과 같은 템플릿형 마감으로 보였다.
- 본문 반영: 반복 제목을 제거하고, 대표 결과 정의·정의 버전 관리·확장 후보 관리 표를 현재 논지 안에 바로 이어 붙였다.

- 변경 이유: 대표 target과 정의 버전을 고정하는 절에 메타 템플릿이 남아 있었고, 이를 더 일반적인 target governance 프레임과 외부 근거로 다시 받쳐 줄 필요가 있었다.
- 본문 반영: 메타 문구를 직접 설명형으로 정리하고, `대표 결과 정의 -> 정의 버전 관리 -> 확장 후보 관리` 프레임과 출처를 추가해 이름 문제가 아니라 문제 정의와 버전 관리의 문제임을 더 분명히 했다.
- 변경 이유: 도입 문장이 여전히 `Part 4로 넘길 문제`를 직접 호출해 현재 절의 대표 target·정의 버전 설명보다 handoff 목적이 먼저 보였다.
