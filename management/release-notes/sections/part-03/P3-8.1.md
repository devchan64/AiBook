### v2026.07.08

- 변경 이유: Chapter 7의 비교표가 Chapter 8에서 어떻게 `해석 강도 판단`으로 바뀌는지 도입에서 한 줄로 회수되지 않아, 표본 수와 반복성 판단이 새 층위처럼 읽힐 여지가 있었다.
- 본문 반영: `이전 Chapter에서 남긴 것 / 이번 Chapter에서 추가로 정하는 것 / 다음 Chapter로 넘길 구조` 표를 추가해, 비교표가 해석 문장 강도와 보수적 멈춤 기준을 만나 다음 장의 산출물 구분으로 이어지는 현재 장의 역할을 더 직접적으로 읽히게 정리했다.

- 변경 이유: 새 Python 예제가 해석 강도 판단은 보여 주지만, 그 강도 조절로 운영적으로 무엇을 얻는지는 본문에서 바로 회수하지 못하고 있었다.
- 본문 반영: 예제 해설 뒤에 과잉 경보 감소, 검토 후보 보존, `기록-검토-강한 경고` 구분의 설명 가능성이라는 세 가지 효과를 짧게 보강해, 해석 강도 조절의 실익이 바로 읽히도록 정리했다.

- 변경 이유: 기존 Python 예제는 `같은 diff, 다른 표본 수`와 `반복성 점수`를 따로 다시 출력하는 수준에 머물러, Section의 중심 질문인 `해석 강도는 무엇으로 조절하는가`를 직접 밀어주지 못했다.
- 본문 반영: 두 개로 분리된 예제를 하나의 작은 판단 예제로 교체해, 같은 `diff`라도 `event_count`와 `repeat_ratio`에 따라 `record_only`, `review_candidate`, `stronger_warning`처럼 해석 강도가 실제로 달라지는 표를 바로 보여 주도록 정리했다.

- 변경 이유: `상위 프레임` 재진술 표가 다른 Section들과 같은 마감 템플릿으로 반복되어, 본문이 교안형으로 굳어 보였다.
- 본문 반영: 말미의 `상위 프레임` 표를 제거하고, 현재 설명을 표 재진술 없이 직접 마무리하도록 정리했다.

- 변경 이유: `이 프레임으로 보면` 식의 결론 문장이 다른 Section들과 같은 어조로 반복되어, 마감 문체가 다시 템플릿형으로 굳어 보였다.
- 본문 반영: 상위 프레임 표는 유지하고, 마지막 문장을 직접 진술형 결론으로 바꿨다.

- 변경 이유: `일반화된 상위 프레임으로 다시 보면` 제목이 Part 3 전반에 반복되어, 현재 절 설명도 같은 템플릿형 마감으로 굳어 보였다.
- 본문 반영: 반복 제목을 제거하고, 상위 프레임 표와 정리 문장을 현재 설명 흐름 안에 직접 이어 붙였다.

- 변경 이유: 같은 날 여러 차례 수정하면서 메타 문장과 템플릿 표현은 줄였지만, 최종 형태에 맞는 출처 연결을 같은 날짜 항목으로 통합해 정리할 필요가 있었다.

- 본문 반영: 반복성 예제 해설을 `감각을 주기에는 충분합니다`에서 `점은 분명히 보여 준다`로 바꾸어 서술을 직접화했다.
