- 변경 이유: 한국어판에만 반영되어 있던 label-selection 출처를 영어·중국어 간체 본문까지 동기화하고, 세 언어의 출처 확인일과 저작권 검토 기록을 최신화할 필요가 있었다.
- 본문 반영 내용: 세 언어 본문 `Version`을 `v2026.07.20`으로 맞추고, Google ML Glossary, W3C PROV, Corbin/Baiocchi/Chen 논문의 출처 확인일을 `2026-07-20`으로 갱신했다. 영어와 중국어 간체 본문에도 Corbin/Baiocchi/Chen 논문 출처를 추가했다.
- 저작권 검토: 본문의 라벨 확정 지연/관측 미완료 음성 비교표와 Mermaid 도식은 자체 작성 설명 자산이다. 외부 표·도식·이미지·문제·코드의 복제나 변형 사용은 확인되지 않았다. Corbin/Baiocchi/Chen 논문은 class label이 관측되지 않을 수 있다는 논지를 짧게 요약해 근거로만 사용했고, 논문의 표·그림·시뮬레이션 수치·임상 사례 세부 구조는 재사용하지 않았다.
- 출처 확인: Google ML Glossary에서 `label`과 `proxy labels` 용어 기준을 확인했다. W3C `PROV-Overview`에서 처리 단계, 재현 가능성, 버전 관리, 파생 관계를 남기는 provenance 축을 확인했다. Corbin/Baiocchi/Chen 논문에서 label selection 상황에서는 관측된 라벨 집합이 배포 모집단의 부분집합일 수 있고, 예측 시점 뒤 충분한 추적 기록이 없으면 일부 class label이 관측되지 않을 수 있다는 설명을 확인했다.
- 번역 동기화 메모: 영어와 중국어 간체 본문은 한국어 본문의 label-selection 출처 보강, 출처 확인일 갱신, 저작권 검토 범위를 반영했다.
