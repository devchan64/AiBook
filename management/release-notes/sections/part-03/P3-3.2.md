### v2026.07.07

- 변경 이유: Python 예제가 절의 핵심인 `질문에 따라 표 구조가 갈라진다`는 주장보다 구현 절차에 시선을 빼앗아, 이 위치의 설명 장치로는 맞지 않았다.
- 본문 반영: 코드와 출력 블록을 제거하고, 같은 원천데이터에서 질문별로 `샘플 단위`, `남길 열`, `바로 읽히는 출력`이 어떻게 달라지는지 비교하는 비코드 표로 교체했다.
- 변경 이유: 기존 Python 예제는 `동작 단위 표`와 `비교 리포트 표`의 차이는 보여 줬지만, 왜 질문이 바뀌면 표 구조도 함께 바뀌는지 단계적으로 따라가기는 아직 약했다.
- 본문 반영: 같은 원천데이터에서 `동작 1회 비교`, `기준선 비교`, `나중의 학습 후보 준비`라는 서로 다른 질문이 각각 어떤 표를 만들게 하는지 단계별 출력으로 보이도록 예제를 다시 구성했다.
- 변경 이유: 도입부가 질문 중심 재설계 개념보다 이 절의 대표 위치를 먼저 설명해 본론 진입이 늦어졌다.
- 본문 반영: 데이터셋 재설계를 `파일 사용`이 아니라 `샘플 단위와 열 구조 재선정`으로 직접 설명하고, 표 종류 차이가 그 재설계에서 나온다는 문장으로 바꿨다.
- 변경 이유: 같은 원천데이터에서 여러 표를 다시 만들 수 있다는 설명은 있었지만, 초심자가 `내 질문에는 어느 표를 먼저 만들어야 하는가`를 즉시 매칭하기는 아직 어려웠다.
- 본문 반영: `질문 -> 표 구조 선택` 대응표와 보강 문단을 추가해, 동작 1회 비교, 최근 구간 비교, 원인 시점 추적, 예측 문제 후보 준비가 각각 어떤 표를 먼저 요구하는지 직접 연결했다.
- 변경 이유: 데이터셋 재설계 절도 대표 설명 위치 문장을 더 직접 설명형으로 맞출 필요가 있었다.
- 본문 반영: `이 절은 ... 대표 위치입니다`를 `여기서는 ... 대표 위치를 맡습니다`로 다듬어 질문 중심 데이터셋 재설계 앵커가 더 직접적으로 읽히게 정리했다.
- 변경 이유: 데이터셋 재설계 절도 마지막 점검 구간을 표 재설계 관점 재호출과 확인 항목으로 분리할 필요가 있었다.
- 본문 반영: 질문에 맞는 표 구조를 다시 떠올려야 하는 상황을 `언제 이 관점을 먼저 떠올려야 하는가`로 추가하고, 기존 `짧은 점검`은 유지했다.

- 번역 동기화 메모: when translated, keep the dataset-redesign recall prompts separate from the short checklist items. / pending

### v2026.07.06

- 변경 이유: 데이터셋 재설계 절이 같은 원천데이터에서 표를 여러 번 다시 만드는 이유를 더 직접적으로 설명하고, 절 끝 점검 장치도 보강할 필요가 있었다.
- 본문 반영: 동작 단위 특징 표, 비교 리포트 표, 예측 문제 후보 표가 각각 왜 따로 필요한지 정리한 보강 표를 추가하고, 절 끝에는 재설계 관점을 확인하는 짧은 점검 질문을 넣었다.
- 변경 이유: 데이터셋 재설계 대표 설명 위치 문장에 남아 있던 `다시 돌아오면 됩니다` 표현을 직접 설명형으로 정리할 필요가 있었다.
- 본문 반영: 3.6의 큰 정의 축과 개념사전 연결을 기준 위치 설명으로 바꾸어, 뒤 절들이 참조할 대표 설명 위치가 더 직접적으로 읽히게 다듬었다.
- 변경 이유: 데이터셋 재구성 절에서도 반복되는 초심자 메타 안내를 줄이고, 원천 파일과 분석용 구조의 차이가 바로 드러나는 서술로 정리.
- 본문 반영: `초심자에게는`, `...움직여도 충분합니다` 같은 진행 문장을 걷어내고, 원시 파일과 샘플 표의 구분 및 4단계 절차를 본문 흐름 안에서 직접 읽히게 다듬었다. 비교 표와 예제 코드는 유지했다.
- 변경 이유: 데이터셋 재구성 핵심 문단에 남아 있던 `느끼기 쉽습니다`, `조금 더 쉽게 벗어날 수 있습니다`, `훨씬 분명해집니다` 같은 완화형 표현을 더 직접적인 설명형 문장으로 정리할 필요가 있었다.
- 본문 반영: 원천데이터와 데이터셋의 차이 문장을 `받아들이기 쉽습니다`로 조정하고, 예제 해설을 `목적에 따라 다시 설계되는 구조를 보여 준다`는 진술로 바꾸었다. 마지막 4단계 절차 정리 문장도 `분명해집니다`로 간결하게 정리했다.
- 변경 이유: Part 3 앞단에 데이터 모델링 진입 챕터를 추가하면서 기존 Section의 번호 체계와 파일 경로를 한 칸씩 뒤로 재배치할 필요가 있었다.

- 변경 이유: 데이터셋 재구성 절도 `정의 설명`보다 `질문에 맞는 데이터셋을 어떻게 다시 설계하는가`라는 절차 중심 역할이 더 선명해지도록 리팩터링 축에 맞출 필요가 있었다.
