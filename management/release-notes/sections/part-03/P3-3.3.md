### v2026.07.07

- 변경 이유: 이 절의 목적은 코드를 읽는 일이 아니라 `질문 -> 첫 표 초안` 변환을 눈으로 바로 따라가게 하는 데 있으므로, Python 예제가 오히려 설명의 초점을 흐렸다.
- 본문 반영: 코드와 출력 블록을 제거하고, 질문별로 `식별`, `특징`, `비교`, `결과` 열 초안이 어떻게 달라지는지 한눈에 비교하는 표로 교체했다.
- 변경 이유: 이 절의 예시는 열 목록 비교보다 `질문이 어떤 열 흐름을 밀어내는가`를 보여 주는 쪽이 더 중요하므로, 도식이 더 직접적으로 설명을 지지한다.
- 본문 반영: 질문별 열 초안 비교를 Mermaid 도식으로 바꾸어 `질문 -> 식별 열 -> 특징 열 -> 비교 열 -> 결과 열` 흐름이 질문마다 어떻게 달라지는지 시각적으로 보강했다.
- 변경 이유: 도식으로 바꾼 뒤에도 소제목이 `작은 예시`로 남아 있어, 예시 형태 기준이 섞여 보일 수 있었다.
- 본문 반영: 소제목을 `작은 도식으로 보기`로 정리해, 이 절의 예시가 질문과 열 흐름을 보여 주는 도식임을 제목에서도 바로 드러내게 했다.
- 변경 이유: 기존 Python 예제는 한 번 정한 열 묶음 딕셔너리를 출력하는 수준이어서, 이 절의 핵심 주장인 `질문이 바뀌면 첫 표 초안도 함께 바뀐다`는 점을 충분히 보여 주지 못했다.
- 본문 반영: 서로 다른 질문 3개에 대해 `식별`, `특징`, `비교`, `결과` 열 초안이 어떻게 달라지는지 단계별로 출력하는 예제로 교체하고, 해설도 `열 이름 나열`보다 `질문이 밀어내는 표 구조`에 맞춰 보강했다.
- 변경 이유: 도입부에 `모델 이름이 먼저 오면 안 된다`는 표현이 남아 있어, 앞선 Section들에서 정리한 것처럼 독자의 주의가 다시 `이름` 자체로 쏠릴 여지가 있었다.
- 본문 반영: 도입 문장을 `학습 문제의 틀을 너무 빨리 정하면 안 된다`는 더 일반화된 표현으로 바꾸어, 이 절의 초점이 질문에서 표 구조로 넘어가는 브리지 역할에 남도록 정리했다.
- 변경 이유: 도입부가 표 초안의 역할 구분보다 `이 절의 목적`을 먼저 말해 AGENTS의 직접 설명 원칙과 어긋났다.
- 본문 반영: 편집자 메타 문장을 걷어내고, 첫 표 초안에서 왜 식별·설명·비교·결과 열을 먼저 나누어야 하는지로 바로 들어가도록 정리했다.
- 변경 이유: Chapter 3에는 모델 이름을 늦추는 경고와 질문에 맞는 데이터셋 재설계 설명은 있었지만, 질문을 실제 첫 표 초안으로 어떻게 옮길지는 별도 Section으로 고정돼 있지 않았다.
- 본문 반영: `샘플 식별 열`, `특징 후보 열`, `비교 열`, `결과 열`의 네 묶음으로 첫 표 초안을 스케치하는 새 Section을 추가했다. 질문 문장이 바뀌면 열 구조도 함께 달라진다는 점과, Chapter 4의 샘플/요약 표 설명 앞에 필요한 브리지 역할을 보강했다.
