### v2026.07.10

- 변경 이유: 변화 신호와 원인 주장 경계를 보여 주는 Mermaid가 영어 중심 라벨로 남아 있어, 현재 절의 핵심 해석 경계가 한국어 본문과 바로 맞물리지 않았다.
- 본문 반영: 비교 결과에서 신호 문장, 검토 문장, 인과 근거 확인으로 이어지는 도식을 한국어 중심 라벨로 다시 정리했다.

- 변경 이유: 시각화 해석 보강 이후에도 초반에 `변화 신호와 원인 확정의 경계`가 한 문장으로 충분히 빨리 닫히지 않아, 도입 정보량에 비해 핵심 경계가 조금 늦게 보였다.
- 본문 반영: 도입과 시각화 문단에서 `차이가 보인다`와 `원인이 확정되었다`를 같은 문장으로 묶지 않는다는 경계를 더 직접적으로 적고, 말미의 시각화 프레임도 별도 문단으로 다시 분리하지 않고 현재 결론 안에 흡수했다. `Version`도 `v2026.07.10`으로 갱신했다.

- 번역 동기화 메모: English and Simplified Chinese translations now preserve the explicit boundary between visible change signals and confirmed causes, including the caution around visual interpretation in charts and plots. / reflected in `docs/en/parts/part-03/chapter-08/section-02.md`, `docs/zh/parts/part-03/chapter-08/section-02.md`

### v2026.07.08

- 변경 이유: 말미에 `이 상위 프레임을 잡아 두면` 템플릿 문장이 남아 있어, 현재 절의 해석 경계 설명을 다시 교안형 어조로 감싸고 있었다.
- 본문 반영: 해당 문장을 `비교표는 관찰과 검토 단계까지는 잘 지지하지만 원인 주장을 자동으로 완성해 주지는 않는다`는 직접 진술로 바꿔, 현재 판단 경계가 본문 자체로 닫히도록 정리했다.

- 변경 이유: `상위 프레임` 재진술 표가 다른 Section들과 같은 마감 템플릿으로 반복되어, 본문이 교안형으로 굳어 보였다.
- 본문 반영: 말미의 `상위 프레임` 표를 제거하고, 현재 설명을 표 재진술 없이 직접 마무리하도록 정리했다.

- 변경 이유: `일반화된 상위 프레임으로 다시 보면` 제목이 Part 3 전반에 반복되어, 현재 절 설명도 같은 템플릿형 마감으로 굳어 보였다.
- 본문 반영: 반복 제목을 제거하고, 상위 프레임 표와 정리 문장을 현재 설명 흐름 안에 직접 이어 붙였다.

- 변경 이유: Chapter 8의 해석 경계는 충분히 설명하고 있었지만, 기준 계획서가 요구한 `시각화 해석` 관점은 같은 절 안에서 직접 전면화되지 않아 `대푯값 한계`보다 회수 강도가 약했다.
- 본문 반영: 비교표 해석 경계에 더해, 선 그래프·막대그래프·상자그림처럼 그림에서 먼저 보이는 차이를 어디까지 말할 수 있는지 설명과 표를 추가했다. 시각화도 `관찰된 신호`를 빠르게 보여 줄 뿐 원인 확정을 자동으로 보장하지 않는다는 점을 보강했다.

- 변경 이유: 같은 날 여러 차례 수정하면서 메타 템플릿은 걷어냈지만, 최종 형태에 맞는 최소 근거 연결을 같은 날짜 항목으로 통합해 정리할 필요가 있었다.
- 본문 반영: `관찰 -> 검토 -> 원인 주장` 상위 프레임을 유지하면서, W3C PROV와 NIST 설명을 `출처와 참고 자료`에 반영해 변화 신호와 원인 확정의 경계를 일반화된 근거와 연결했다. 메타 문장은 직접 설명형 문장으로 정리한 상태를 유지했다.

- 번역 동기화 메모: preserve the observation-review-causal-claim frame and keep the source-backed boundary between signal evidence and causal claims explicit. / pending

### v2026.07.07

- 변경 이유: 커리큘럼 계획에서 아직 본문에 직접 흡수되지 않은 `상관관계 해석 주의`와 `금융 모형화 위험` 항목을 해석 경계 절 안에서 실제로 반영할 필요가 있었다.
- 본문 반영: 함께 움직인 값과 원인 확정을 구분하는 상관관계 주의 문단을 추가하고, 금융 모형화처럼 해석 비용이 큰 영역에서는 예측 점수와 실제 의사결정을 더 엄격히 분리해야 한다는 설명을 덧붙였다.
- 변경 이유: 이 절의 중심은 예측 문장보다 `어디까지 말하고 어디서 멈추는가`라는 해석 경계이므로, 코드 예시보다 분기 도식이 더 직접적으로 설명을 지지한다.
- 본문 반영: 작은 코드 예시를 Mermaid 도식으로 교체했다. 비교 결과에서 변화 신호와 검토 필요 수준까지는 갈 수 있지만, 원인 주장은 별도 근거가 있을 때만 다음 단계로 넘어간다는 판단 흐름을 시각적으로 보강했다.
- 변경 이유: 변화 신호와 원인 확정 경계 절도 마지막 점검 구간을 해석 경계 재호출과 확인 항목으로 분리할 필요가 있었다.
- 본문 반영: 변화 신호와 원인 확정을 구분해야 하는 상황을 `언제 이 관점을 먼저 떠올려야 하는가`로 추가하고, 기존 `짧은 점검`은 유지했다.

- 번역 동기화 메모: when translated, keep the signal-vs-cause recall prompts separate from the short checklist items. / pending

### v2026.07.06

- 변경 이유: 변화 신호와 원인 확정의 경계는 설명하고 있었지만, 어떤 문장이 어느 층위에 속하는지와 절 끝 점검 장치가 더 필요했다.
- 본문 반영: `변화 신호`, `검토 후보`, `원인 확정` 문장을 층위별로 나누는 보강 표를 추가하고, 절 끝에는 해석 경계를 확인하는 짧은 질문을 넣었다.
- 변경 이유: 변화 신호와 원인 확정 경계 절에서도 독자 반응을 직접 지시하는 메타 문장을 줄이고, 비교 결과와 원인 확정의 층위 차이가 본문 논리로 바로 드러나게 정리.
- 본문 반영: 도입의 `초심자가 자주 하는 착각` 표현을 일반 서술로 바꾸어, 변화 신호와 원인 확정의 분리를 더 직접적으로 읽히게 했다. 비교 표와 운영 문장 예시는 유지했다.
- 변경 이유: 변화 신호와 원인 확정 절의 예시 설정, 문장 비교 도입, 다음 장 연결에 남아 있던 `합시다`, `비교해 봅시다`, `정리하겠습니다` 같은 유도형 표현을 직접 설명형으로 정리할 필요가 있었다.
- 본문 반영: 최근 20건 예시를 `하겠습니다`로 바꾸고, 문장 비교 도입을 `비교합니다`로 조정했다. 운영 문장 해설의 마지막도 `신호라는 점을 유지해야 한다`로 다듬고, 다음 장 연결 문장은 `정리합니다`로 정리했다. 변화 신호와 원인 확정의 층위 차이, 비교 표, 운영 문장 예시는 유지했다.
- 변경 이유: Part 3 앞단에 데이터 모델링 진입 챕터를 추가하면서 기존 Section의 번호 체계와 파일 경로를 한 칸씩 뒤로 재배치할 필요가 있었다.
- 본문 반영: Section 제목 번호, Section ID, 본문 경로, 목차 대응 위치를 새 Part 3 번호 체계에 맞춰 갱신했다. 본문 설명 구조와 사례 흐름은 유지했다.
- 변경 이유: 변화 신호와 보수성 Section도 `왜 함께 봐야 하는가` 설명보다 `어디까지 말하고 어디서 멈출 것인가`라는 해석 경계 질문을 더 직접적으로 드러내도록 조정할 필요가 있었다.
- 본문 반영: Section 제목을 `변화 신호를 어디까지 말하고 원인은 어디서 멈추는가`로 바꾸고, 도입에 해석 강도 다음 단계로 말할 수 있는 범위를 정하는 절이라는 연결 문장을 추가했다. 비교 표와 운영 문장 예시는 유지했다.
- 변경 이유: Part 3 Section 제목 인덱스를 `Section ID`와 같은 `P3-8.2` 형식으로 맞추는 규칙을 적용할 필요가 있었다.

- 변경 이유: 변화 신호와 원인 경계 절의 운영 문장 절차와 마지막 핵심 정리에 남아 있던 `더 안전합니다`, `기억해야 할 핵심` 같은 안내형 표현을 직접 설명형으로 맞출 필요가 있었다.
