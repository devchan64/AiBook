- 본문 반영: Python 예제를 유지하지 않고 제거했으며, 본문에 남아 있던 `이 예제는` 문장도 `이 비교표는`으로 바꿔 현재 설명 단위가 표와 문장 해설이라는 점이 자연스럽게 이어지도록 정리했다.

- 변경 이유: Python 예제가 바로 위 비교표를 코드로 다시 출력하는 수준에 머물러, Section의 중심 질문인 `무엇과 비교해야 변화가 보이는가`에 새 이해를 거의 더하지 못했다.
- 본문 반영: Python 예제와 예상 출력을 제거하고, 최근 구간과 기준선이 만나야 `diff` 같은 비교 열이 생긴다는 현재 절의 핵심을 표와 설명 문장으로 직접 읽게 정리했다.

- 변경 이유: `상위 프레임` 재진술 표가 다른 Section들과 같은 마감 템플릿으로 반복되어, 본문이 교안형으로 굳어 보였다.
- 본문 반영: 말미의 `상위 프레임` 표를 제거하고, 현재 설명을 표 재진술 없이 직접 마무리하도록 정리했다.

- 변경 이유: `이 프레임을 쓰면` 식의 결론 문장이 다른 Section들과 같은 어조로 반복되어, 마감 문체가 다시 템플릿형으로 굳어 보였다.
- 본문 반영: 상위 프레임 표는 유지하고, 마지막 문장을 직접 진술형 결론으로 바꿨다.
