- 본문 반영: 반복되는 변화와 관측 부족 사례를 구분해 `warning_level`, `review_needed`, `priority_score`로 옮기는 도식을 한국어 중심 라벨로 다시 정리했다.

- 변경 이유: `숫자 -> 문장 -> 운영 열`의 핵심 흐름이 도입, 층위 표, 도식 뒤 결론에서 비슷한 말로 다시 반복되어, 설명 자체보다 재진술 비중이 다소 커졌다.

- 번역 동기화 메모: English and Simplified Chinese translations now reflect the tightened `numbers -> sentence -> operational columns` flow, including the review-queue bridge and the distinction between conservative sentences and structured operational output. / reflected in `docs/en/parts/part-03/chapter-08/section-04.md`, `docs/zh/parts/part-03/chapter-08/section-04.md`

### v2026.07.08

- 변경 이유: 초반 설명이 `검토 큐나 예측 문제로 넘기면`이라고 말해, 현재 절의 운영 열 구조보다 handoff 인상이 더 크게 남았다.
- 본문 반영: 해당 문장을 `비교표 -> 구조화된 운영 출력` 사이의 판단 이유를 설명하는 현재 절 내부 구조 문장으로 바꾸고, 운영 우선순위와 재정렬 문제를 직접 다루도록 정리했다.

- 변경 이유: 마무리가 현재 `숫자 -> 문장 -> 운영 열` 설명을 넘어 `Chapter 9의 경고, 검토 후보, 라벨 예측 구분`을 다시 전면 예고해, handoff 메모 성격이 커 보였다.
- 본문 반영: 끝부분의 `Chapter 9` 예고 문장을 제거하고, `무엇이 달라졌는가 -> 얼마나 강하게 말할 것인가 -> 어떤 운영 열로 압축할 것인가`라는 현재 절의 순서를 직접 진술하는 마감으로 바꾸었다.

- 변경 이유: `상위 프레임` 재진술 표가 다른 Section들과 같은 마감 템플릿으로 반복되어, 본문이 교안형으로 굳어 보였다.
- 본문 반영: 말미의 `상위 프레임` 표를 제거하고, 현재 설명을 표 재진술 없이 직접 마무리하도록 정리했다.

- 변경 이유: 후속 Section가 `검토 후보 큐`를 구조화된 운영 출력의 대표 예로 다시 설명하면서도 개념사전 직접 앵커로 되돌아가지 않았다.
- 본문 반영: 도입부에서 `검토 후보 큐(review queue)`를 개념사전 직접 앵커로 연결해, 보수적 해석과 운영 산출물의 관계를 대표 표제어 기준으로 다시 찾을 수 있게 했다.
- 변경 이유: 핵심 판단을 백틱 독립 문장으로 따로 세워 본문 흐름보다 강조 문구가 먼저 보였다.
- 본문 반영: 보수적 해석 문장의 위치를 일반 문단 안으로 흡수해 비교 결과와 운영 출력 사이 설명이 자연스럽게 이어지도록 정리했다.
- 변경 이유: `일반화된 상위 프레임으로 다시 보면` 제목이 Part 3 전반에 반복되어, 현재 절 설명도 같은 템플릿형 마감으로 굳어 보였다.
- 본문 반영: 반복 제목을 제거하고, 상위 프레임 표와 정리 문장을 현재 설명 흐름 안에 직접 이어 붙였다.

### v2026.07.07

- 변경 이유: Chapter 8에는 비교표를 보수적으로 읽고 문장 강도를 조절하는 설명이 있었지만, 그 문장이 실제 운영 열과 검토 큐 기준으로 어떻게 구조화되는지는 별도 절로 닫혀 있지 않았다.
- 본문 반영: 새 Section `P3-8.4 보수적 해석 문장은 어떻게 경고 열과 검토 큐 기준으로 바뀌는가`를 추가했다. 비교 결과, 보수적 해석 문장, 구조화된 운영 출력의 세 층위를 나누고, `warning_level`, `review_needed`, `priority_score` 같은 열이 어디서 오는지 브리지 예시로 정리했다.
- 변경 이유: 기존 예시는 `warning_level`, `review_needed`, `priority_score`를 바로 출력해, 보수적 해석 문장이 운영 열로 어떻게 바뀌는지 중간 다리가 충분히 드러나지 않았다.
- 본문 반영: 같은 차이값 사례를 사람 해석 표와 운영 열 표로 나눠 출력하도록 예시를 바꿨다. `conservative_sentence`를 먼저 보여 준 뒤 `warning_level`, `review_needed`, `priority_score`로 압축되는 순서를 드러내어 `숫자 -> 문장 -> 운영 열` 흐름을 직접 읽을 수 있게 했다.
- 변경 이유: 이 절의 중심은 계산 예시보다 `비교 결과 -> 사람 문장 -> 운영 열`이라는 판단 구조에 있으므로, 코드 예시보다 도식이 더 직접적으로 설명을 지지한다.
- 본문 반영: 작은 코드 예시를 Mermaid 도식으로 교체했다. 같은 차이값 사례가 해석 강도 조절을 거쳐 `warning_level`, `review_needed`, `priority_score`로 나뉘는 흐름을 세 단계 도식으로 보여 주도록 정리했다.
- 변경 이유: 표 예시와 도식 예시가 함께 남은 상태에서 소제목이 모두 `예시`로 보이면 역할 차이가 흐려질 수 있었다.
