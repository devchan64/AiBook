### v2026.07.08

- 변경 이유: 도입부가 `앞 절까지 읽으면`, `한 번 더 고정할 필요가 있습니다` 같은 독서 흐름 메모로 열려, 현재 문장 작성 원리보다 편집자 문장이 먼저 보였다.

- 변경 이유: 말미가 현재 문장 작성 원리 설명을 넘어 `Chapter 9 산출물 구분`을 다시 크게 예고해, 마무리가 handoff 메모처럼 읽혔다.
- 본문 반영: 끝부분의 `Chapter 9` 예고 문단을 걷어내고, `비교 결과 -> 강도 조건 -> 다음 행동` 순서를 먼저 고정해야 비교 근거와 판단 강도가 뒤엉키지 않는다는 현재 절의 설명으로 직접 마무리했다.

- 변경 이유: `상위 프레임` 재진술 표가 다른 Section들과 같은 마감 템플릿으로 반복되어, 본문이 교안형으로 굳어 보였다.
- 본문 반영: 말미의 `상위 프레임` 표를 제거하고, 현재 설명을 표 재진술 없이 직접 마무리하도록 정리했다.

- 변경 이유: 안전한 문장 골격을 백틱 독립 문장으로 따로 세워 본문 설명보다 템플릿 문구가 먼저 보였다.
- 본문 반영: 문장 골격을 일반 설명 문장으로 풀어 넣어, 앞뒤 예시와 자연스럽게 이어지도록 정리했다.
- 변경 이유: `일반화된 상위 프레임으로 다시 보면` 제목이 Part 3 전반에 반복되어, 현재 절 설명도 같은 템플릿형 마감으로 굳어 보였다.
- 본문 반영: 반복 제목을 제거하고, 상위 프레임 표와 정리 문장을 현재 설명 흐름 안에 직접 이어 붙였다.

- 변경 이유: 같은 날 여러 차례 수정하면서 메타 표현은 줄였지만, `이 절의 목적`, `다리 역할`처럼 배치 의도를 직접 호출하는 문장이 남아 있었다.
- 본문 반영: `관찰 결과 진술 -> 확신 강도 조절 -> 다음 행동 연결` 상위 프레임과 W3C/NIST 출처 단락은 유지하면서, 해당 메타 문장을 일반 설명 문장으로 바꾸어 Chapter 9 연결이 설계 메모보다 개념 설명으로 읽히도록 다듬었다.
- 변경 이유: 문장 골격 설명은 충분했지만, 왜 이 골격이 특정 운영 습관이 아니라 더 일반적인 관찰 보고 구조인지와 이를 받치는 최소 외부 근거는 드러나지 않았다.
- 본문 반영: `관찰 결과 진술 -> 확신 강도 조절 -> 다음 행동 연결`이라는 상위 프레임을 추가하고, NIST의 signal/investigation 구조와 BLS의 base period 설명을 `출처와 참고 자료`에 붙여 보고 문장의 일반 구조를 보강했다.
