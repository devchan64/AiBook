### v2026.08.03

- 구조 재배치: 이 Section을 `화풍·연속성 보정` 단계로 명시했다. 컷신 생성의 실패를 inpaint로 숨기지 않으며, full-frame gate를 통과한 컷에만 구조 조건과 국소 보정을 적용한다.
- 변경 이유: identity 참조가 pose·camera·장면 변화를 막는지 판단하려면, 먼저 구조 제어만 독립적으로 실제 검증해야 했다.
- 실행 결과: 캐시된 `control_v11p_sd15_openpose`와 표준 SD 1.5로 네 held-out 장면의 OpenPose map을 만들고, 같은 prompt·seed에서 ControlNet scale `0.0`·`1.0`을 비교했다. scale `1.0`은 팔·몸통·다리 방향과 주방·난간·영화관·작업대의 큰 구조를 off보다 더 따랐고 peak VRAM 약 `3,211 MiB`로 실행됐다.
- 판정: identity 입력을 넣지 않았으므로 얼굴·머리·의상·가방은 Mira와 일치하지 않는다. 이 결과는 structure 부분 통과일 뿐 최종 웹툰 컷이나 character consistency 통과가 아니다.
- 호환성 확인: WD 1.5 base는 text context `1024`, 이 OpenPose ControlNet은 `768`을 사용해 직접 결합할 수 없었다. WD와 이 ControlNet의 결합 경로를 제외했다.
- 실행 결과: 캐시된 Animagine XL, SDXL IP-Adapter, SDXL OpenPose ControlNet을 새 Mira 기준과 네 pose map으로 결합했다. `512 x 768`은 model CPU offload에서 OOM이었지만 sequential CPU offload로 15 step을 완료했다. IP-Adapter on은 큰 pose·장면 구조를 유지한 채 청록 단발·흰 재킷·청록 바지·가방을 더 자주 남겼다. 얼굴·가방 geometry·손·일부 camera와 장소는 미통과이므로 combined-condition 부분 통과로만 기록한다.
- 검수 결과: 결합 출력의 IP-Adapter on 네 panel을 identity·structure·style·local detail로 분리해 검토했다. 네 panel 모두 full-frame identity 또는 structure가 `partial`/`fail`이라 inpaint 가능 panel은 `0`개다. 얼굴·가방·손 보정은 전체 frame 통과 뒤에만 허용하도록 review ledger와 checker를 추가했다.
- 실행 결과: 정면·3/4·얼굴·가방 detail의 다섯 승인 reference를 한 IP-Adapter 입력 묶음으로 비교했지만 얼굴·가방 geometry는 안정화되지 않았고 일부 출력은 옅어졌다. reference 수 증가는 단일 reference 실패의 해결책이 아니므로 이 경로도 품질 미통과로 기록했다.
- 교체 검증: SDXL Plus와 Plus Face를 ViT-H 인코더와 별도 adapter slot으로 실제 실행했다. 두 조합 모두 Animagine XL·SDXL OpenPose·`512 x 768`·15 step·sequential CPU offload에서 생성돼 모델 계열과 8 GB 실행 경로는 호환됐다. 그러나 Plus 단독은 가방·색 일관성을 충분히 개선하지 못했고 Plus Face는 잘못된 옆얼굴 세부와 배경 약화를 만들었다. PNG는 품질 미통과로 제거하고 실행 코드와 로컬 판정 기록으로만 남겼다.
- 카메라 구조 검증: 캐시된 SDXL Canny ControlNet과 기존 범용 IP-Adapter를 저각도 cinema 컷에 결합했다. Canny scale `0.75`는 몸의 굽힘 방향과 foyer 원근을 off보다 더 따랐지만 얼굴·가방·손·전신 비례는 모두 품질 미통과였다. Canny는 camera·silhouette 보조 조건으로만 부분 통과이며 최종 웹툰 컷 후보가 아니다.
- 구조 단독 검증: IP-Adapter, LoRA, inpaint, source RGB를 모두 제외하고 옆면 turnaround의 Canny edge만 SDXL Canny ControlNet에 전달했다. 같은 seed에서 scale `0.75`는 `0.0`보다 side profile, head-neck-shoulder 방향, 전신 frame, 가방과 손의 큰 상대 위치를 더 따랐다. `512 x 768`, 15 step, sequential CPU offload에서 `33.5초`, peak VRAM `1,733MiB`였다. 이는 camera·silhouette structure 통과만 뜻하며 identity·style 통과가 아니다.
- 관련 자산 추가: `p7_5_4_sdxl_canny_structure_only_probe.py`, `p7-5-4-sdxl-canny-structure-only-contact-sheet.png`.
- identity-anchor 결합 검증: 같은 Canny structure 조건에 IP-Adapter scale `0.35`를 추가했다. 정면/3-4 reference와 angle-matched side reference 모두 side profile·전신 frame은 남겼지만, hair가 옅은 흰색으로 변하고 face·가방 geometry를 복원하지 못했다. 두 결과 모두 full-frame identity 실패이므로 inpaint, scale sweep, reference 추가, 두 번째 ControlNet으로 확장하지 않는다. PNG와 임시 script는 제거하고 판정은 로컬 기록으로만 보관한다.
- 관련 자산: `p7_5_4_sd15_openpose_structure_probe.py`, `p7-5-4-sd15-openpose-controlnet-on-off-contact-sheet.png`.
- 번역 반영 상태: 한국어 원문만 반영됨.
