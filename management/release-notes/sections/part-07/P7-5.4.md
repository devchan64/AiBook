# Section Release Note

- Section ID: `P7-5.4`
- Source File: `docs/parts/part-07/chapter-05/section-04.md`

### v2026.09.05

- P7-5.5에 함께 있던 최초 T2I 장면 생성과 Multiple-angles 카메라판 생성 문단을 P7-5.4로 분리했다. P7-5.4는 `장면 → 카메라판` 입력 계약과 A·B·C 실행 기록을 맡고, 이후 인물 마스크·캐릭터 이식·배경·조명 통합은 P7-5.5로 넘긴다.
- P7-5.4 전용 씬 생성기를 추가했다. 기본 A 프롬프트는 Mira가 도시 거리에서 카메라 쪽으로 달리는 장면이고, B는 해질녘 해변의 grand jeté, C는 도시 전망 언덕에서 책을 읽는 두 사람 장면으로 계약을 교체했다.
- 씬 생성기를 `Qwen/Qwen-Image-2512` 공식 Diffusers 직접 실행으로 전환했다. 기본 캔버스는 1280×1280이며, BF16 순차 CPU 오프로딩으로 ComfyUI 서버 없이 실행하도록 기록했다.
- 씬 생성기를 `Qwen-Image-Edit-2511`의 Mira 전신·정면 머리 다중 참조 경로로 다시 전환했다. A·B·C 프롬프트에서는 Mira의 외형·착장 설명을 제거하고 장면·동작·구도만 남겼다.
- Mira 전신·머리 두 장만으로 Scene A를 만들 때 인물이 중복된 관찰을 반영해, 생성기의 첫 입력을 장면 레이아웃으로 고정했다. 프롬프트는 단일 중앙 주인공을 레이아웃의 Mira identity로 교체하도록 바꿨다.
- Mira의 외형 설명을 되살리지 않고도 선화 특징을 반영하도록, 전신·머리 참조(Pictures 2·3)의 깨끗하고 섬세한 선화·부드러운 얼굴 렌더링을 중앙 주인공에 적용하는 참조 지시를 추가했다.
- 장면 레이아웃 이미지는 현재 생성기 입력에서 제거했다. 장면의 장소·동작·구도는 Scene A·B·C 프롬프트가 맡고, 이미지 참조는 Mira 전신 착장(Picture 1)과 정면 머리(Picture 2)만 사용한다.
- 정면 머리 참조와 수채화 스타일 계약을 제거해, 현재 A·B·C는 Mira 전신 착장(Picture 1) 한 장만 참조한다. 원고의 기존 Q4 Scene A·B·C 표와 result.json 링크도 이 1280 정사각형 2511 v7 산출물로 교체했다.
- Chapter 5 목차와 독자용 목차에 P7-5.4를 추가했다. 번역 동기화 메모: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.05`.
