### v2026.07.19
- 변경 이유: Part 7 연습 Section의 학습 리듬을 `중심 질문 -> 직접 실행 -> 출력 해석 -> 회고 기록`으로 더 일관되게 맞추기 위해 보강했다.
- 본문 반영: 도입부에 `경고 등급이 가르는 질문`, `연습 뒤 남겨야 할 판단`을 추가해 경고 등급을 진단 확정이 아니라 검토 우선순위로 읽는 기준을 먼저 고정했다.
- 추가 반영: `이 절에서 직접 할 일`, `관찰 포인트`, `기록 템플릿`을 추가하고 `출력 읽기`를 `결과를 어떻게 읽는가`로 맞춰, 등급 변화와 첫 점검 위치를 함께 남기게 했다.
- 번역 동기화 메모: Future translations should preserve the added practice scaffold that separates threshold-only alerts from evidence-based review priority.
- 번역 반영 상태: 한국어 원문만 반영됨.
- 원문 기준 버전: `v2026.07.19`

### v2026.07.18

- 본문 반영 내용: gap 하나로 경고를 확정하지 않고, `event_count`, `repeatability_score`, `recency_weight`, `reader_impact`가 검토 우선순위를 어떻게 바꾸는지 Python 예제와 회고 문장으로 닫았다.
