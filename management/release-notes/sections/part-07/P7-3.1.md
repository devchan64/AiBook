### v2026.07.07

- 변경 이유: 이미지 분류 예제의 실행 요약과 샘플별 출력에 `sample_id`, `pred_label`, `confidence_margin` 같은 내부 스키마형 영어 키가 남아 있었다.
- 본문 반영: 공개 출력 키를 `평가 샘플`, `예측 라벨`, `확신 차이`, `추가 검토 샘플`처럼 독자용 설명형 표현으로 바꾸고, 실행 요약 제목도 한국어로 정리했다.
- 번역 동기화 메모: 향후 번역본도 P7-3.1 공개 출력 키를 모델 내부 필드명이 아니라 독자용 설명 레이블로 유지해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.07`

### v2026.07.07

- 변경 이유: 이미지 프로젝트 입구 설명의 질문 표와 보조 표에 `review`, `shape`, `margin` 같은 영어 공통 레이블이 남아 있어 초반 독서 흐름을 약하게 만들었다.
- 본문 반영: 입구 설명을 `추가 검토 대상`, `입력 모양(shape)`, `확신 차이(margin)` 같은 한국어 중심 표현으로 정리해 공개 독자용 설명이 먼저 읽히게 맞췄다.
- 번역 동기화 메모: 향후 번역본도 P7-3.1 초반 입구 설명에서는 한국어 개념 설명을 먼저 두고 영어 병기는 보조로 유지하는 편이 좋다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: `docs/reference/concept-glossary.md`
- 원문 기준 버전: `v2026.07.07`

### v2026.07.12

- 추가 반영: 메타형 연결 예고 제거와 말미 자기 확인 구조 통합을 같은 기준으로 맞췄다.
- 변경 이유: 이미지 분류 프로젝트 도입 절의 말미 `이 절에서 기억할 관점`과 `짧은 점검`이 중복된 자기 확인 구조를 만들고 있었다.
- 본문 반영: 입력 모양, 라벨, 예측값, 오류 사례, 평가 분리 기준을 `체크리스트` 하나로 재구성했다.
