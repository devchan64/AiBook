### v2026.09.21

- P7-5.16의 임시 OpenPose·SDXL 비교 원고를 Qwen-Image-Edit-2511과 AnyPose의 참조 포즈 전이 보충학습 초안으로 교체했다. 캐릭터 기준 이미지와 포즈 안내 이미지의 역할, AnyPose 비적용/적용/배경 보존 지시 비교 계약, 자세·카메라·캐릭터·장면 보존의 분리 검수 기준을 구성했다.
- 이전 P7-5.16 전용 OpenPose 준비 코드와 SDXL·OpenPose 결과 PNG·JSON은 폐기했다. 실제 AnyPose 실행 결과·이미지 자산·실행 JSON은 아직 없으며, 이후 실행에서는 입력 출처·해시, 모델과 LoRA 버전·강도, 워크플로, 검수 JSON을 함께 보존한다.
- 목차, Part 7 소개, Part 체크포인트를 새 초안의 학습 초점으로 맞췄다. 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.21`.

### v2026.09.13

- 기존 P7-5.8 원고를 P7-5.16으로 임시 이관했다. Section ID·원고·릴리즈노트와 전용 코드·자산을 5.16 및 sec-16 기준으로 변경했다. 5.8은 후속 신규 집필을 위해 비워 두며 기존 이력의 번호는 당시 기록으로 유지한다. 원문 기준 버전: `v2026.09.13`.
- OpenPose 맵 준비 코드를 `sec-08/p7_5_8_prepare_openpose_maps.py`로 복원·리네임했다. 삭제된 기본 입력 5개 대신 `--reference-image`를 필수로 받고, 출력 경로·내부 모듈 이름을 5.8 기준으로 변경했다. 원고에 맵 추출용 코드 링크와 역할을 반영했다. GPU 생성은 실행하지 않았다.
- 5.8에서 사용하는 이미지 7장·JSON 7개의 파일명 접두사를 p7-5-11에서 p7-5-8로 바꾸고 sec-08로 이동했다. 원고·실행 기록의 참조를 갱신하고 기존 상위 폴더의 심볼릭 링크 14개를 제거했다. 이미지 내용은 유지한다. 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.13`.

### v2026.09.11

- 보충학습을 OpenPose·ControlNet 입력 역할 설명 → 동작 배치에 효과가 있었던 결과 → 외형·구도 반영이 부족했던 결과로 재구성했다. LoRA 강도와 스텝 반복 비교를 본문에서 걷어내고, 미완료 실행은 출력 품질 비교에서 구분했다. 이미지·JSON 자산 파일은 삭제하지 않았다. 체크리스트를 학습 질문 3개로 정리했다. 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.11`.
- P7-5.13을 P7-5.8 보충학습으로 이동했다. 앞선 Qwen 편집 흐름과 별도로 SDXL·ControlNet 결과에서 구조 입력의 역할을 읽도록 도입·비교 항목을 정리했다. 기존 실험 이미지·JSON은 유지하고 목차·관리 문서·다른 절의 번호 참조를 갱신했다. 원문 기준 버전: `v2026.09.11`. 번역 반영 상태: 한국어 원문만 반영됨.
- 출처와 참고 자료를 작성자·자료명·게시처·URL·확인일 중심으로 통일하고, 실행 조건·검수 설명과 구분했다. 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.11`.

### v2026.09.05
