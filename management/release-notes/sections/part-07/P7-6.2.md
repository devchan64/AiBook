# Section Release Note

- Section ID: `P7-6.2`

### v2026.07.07

- 변경 이유: agent 권한·로그 절 후반의 적용 상황과 점검 문장이 `permission`, `approval`, `scope`, `next action`, `step/tool/result`, `blocked` 같은 영어 운영 키 나열로 끝나 공개 독자용 설명을 약하게 만들었다.
- 본문 반영: 후반 점검 문장을 `권한 범위`, `승인 필요 여부`, `허용 범위`, `다음 행동`, `단계/도구/결과`, `보류(blocked)` 같은 한국어 중심 표현으로 정리했다.
- 번역 동기화 메모: 향후 번역본도 P7-6.2 후반 점검 문장에서는 운영 키를 그대로 나열하기보다 한국어 설명을 먼저 두고 영어는 병기로만 유지하는 편이 좋다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: `docs/reference/concept-glossary.md`
- 원문 기준 버전: `v2026.07.07`

### v2026.07.12

- 추가 반영: 메타형 연결 예고 제거와 말미 자기 확인 구조 통합을 같은 기준으로 맞췄다.
- 추가 반영: `운영 관점의 연결`을 `왜 권한과 로그가 운영 문제인가`로 바꿔 권한·로그 설명의 초점을 직접 드러내도록 정리했다.
- 변경 이유: 권한·로그 절의 말미 `이 절에서 기억할 관점`과 `짧은 점검`이 중복된 자기 확인 구조를 만들고 있었다.
- 본문 반영: 권한 범위, 승인, 로그, 보류 상태, 운영 안전장치 해석 기준을 `체크리스트` 하나로 통합했다.
