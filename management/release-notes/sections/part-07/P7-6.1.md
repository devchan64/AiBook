### v2026.07.07

- 변경 이유: 일반화한 agent 예제에도 `inspect_request`, `run_validation`, `share_result`, `success`, `finish`, `next_action` 같은 영어 상태 키와 도구 이름이 공개 본문에 그대로 남아 있어 현재 에이전트 작업 흐름처럼 읽힐 수 있었다.
- 본문 반영: 예제 도구 이름, 상태 키, 출력 제목, 최종 보고를 `요청 확인`, `결과 점검`, `결과 공유`, `성공`, `종료`, `다음 행동` 같은 독자용 한국어 표현으로 바꾸어 실행 루프 개념이 먼저 읽히게 정리했다.
- 번역 동기화 메모: 향후 번역본도 P7-6.1 예제의 공개 상태 키와 도구 이름은 일반 개념 중심 표현으로 유지하고 내부 영어 상태 문자열은 노출하지 않는 편이 좋다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.07`

### v2026.07.12

- 추가 반영: 메타형 연결 예고 제거와 말미 자기 확인 구조 통합을 같은 기준으로 맞췄다.
- 추가 반영: `MCP와의 연결`을 `왜 도구 인터페이스 표준화가 필요한가`로 바꿔 소제목만 읽어도 현재 절의 설명 초점이 드러나게 했다.
- 변경 이유: 에이전트 도입 절의 말미 `이 절에서 기억할 관점`과 `짧은 점검`이 자기 확인 구조를 중복시키고 있어 기준서에 맞춘 통합이 필요했다.
- 본문 반영: 목표-도구-관찰 루프, RAG와의 차이, 도구 결과의 근거 역할, 권한 절로 이어지는 기준을 `체크리스트` 하나로 정리했다.
- 번역 동기화 메모: 대응 번역본이 생기면 같은 메타 표지 제거와 단일 checklist 구조를 함께 반영해야 한다.
- 번역 반영 상태: 향후 번역 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.12`
