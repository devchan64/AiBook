### v2026.08.01

- 변경 이유: 로컬 LLM 실습이 기록 양식만 제시하고 실제 모델 출력, 양자화 실패, 실행 환경 차이를 보여 주지 못해 실행 증거를 보강했다.
- 본문 반영: `Qwen/Qwen2.5-0.5B-Instruct`를 CPU에서 FP32와 동적 INT8 `Linear` 조건으로 각각 36회 실행한 결과를 추가했다. 짧은/긴 입력, 기대 사실 포함 여부, 지연 시간, 모델 적재 뒤 RSS를 표로 비교하고, 빠른 설정이 사실 회수에 실패할 수 있음을 실제 응답 사례로 설명했다.
- 추가 반영: 36행 질문 입력 CSV, 재실행 Python 스크립트, 72개 원문 응답 스냅샷 CSV를 연결하고, 모델·PyTorch 버전·device·input token·생성 길이를 기록 양식에 추가했다.
- 번역 동기화 메모: 번역본에도 FP32, dynamic INT8 Linear, expected fact, RSS, snapshot log의 의미와 수치가 같은 실행 조건을 가리키도록 반영한다. 실제 결과 표의 수치는 원문 자산을 공용으로 참조한다.
- 번역 반영 상태: 한국어 원문만 반영됨.
- 관련 자산: `docs/assets/part-07/chapter-06/p7-6-1-prompts.csv`, `docs/assets/part-07/chapter-06/p7_6_1_local_llm_experiment.py`, `docs/assets/part-07/chapter-06/p7-6-1-local-llm-results.csv`
