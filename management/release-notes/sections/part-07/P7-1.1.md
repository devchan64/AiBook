### v2026.08.01
- 변경 이유: P7-1.1의 중심 학습 산출물인 질문, 행의 의미, 비교 구간을 반복 설명이나 메타 기록보다 실제 집계 단위 비교로 더 직접 확인하게 정리했다.
- 본문 반영: 불필요한 기록 필드와 별도 동작 시계열 사례는 제거하되, 기준선 경계와 오류 신호를 각각 바꿔 보는 두 비교 실습은 출력표와 함께 보강했다. 일자 집계, 채널별 기간 비교, 최근 채널-일자 세 건을 서로 다른 표로 나눠 비교 축을 분명히 했다. `summarize()`가 단순 일별 평균 대신 방문자·가입·오류 합계로 비율을 계산하는 이유와, 원본 행을 세 분석 단위로 읽는 방법을 설명했다. Python 예제가 모든 채널의 기준선·최근 변화를 함께 출력하도록 바꿨고, 중복된 ads 출력은 제거했다. 저장소 최상위에서 실행한다는 조건, 오류율 조작이 기본 최근 ads 행 7건 모두에 적용된다는 설명을 추가했다. cutoff와 오류율 조작은 코드 변수로 실행하게 했고, 빈 비교 구간과 0명 방문자 행에는 원인을 설명하는 오류를 추가했다. cutoff 변경 시 비교 기간도 바뀐다는 설명으로 수정했고, 사용하지 않는 `statistics` 참고 자료를 제거했다. 채널-일자 전환율·오류율의 기준선 전후 추이를 함께 그린 2패널 그래프를 추가해, 기간 요약표가 놓치는 변화 시작 위치를 확인하게 했다. 기존 단위 확인 Mermaid를 본문에 연결해 `전체 하락 -> 행 단위 확인 -> 채널 비교 -> 다음 검토`의 읽기 순서를 보강했고, 그래프 해설은 관찰·미확정 지점·다음 확인을 분리해 원인 단정을 막도록 고쳤다. GitHub Pages의 `/AiBook/` 하위 경로에서도 그래프가 열리도록 이미지 링크를 상대 경로로 수정했다.
- 번역 동기화 메모: 향후 번역본은 일자 집계와 채널-일자 집계의 결론 차이, cutoff 변경에 따른 기간 변화 설명을 함께 반영한다.
- 번역 반영 상태: 한국어 원문만 반영됨.
