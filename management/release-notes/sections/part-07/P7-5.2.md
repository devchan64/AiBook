### v2026.08.05

- 기준 생성 소스를 정면 얼굴, 방향 얼굴, 표정 detail, 소품 기준, 정면 전신, 방향 전신의 여섯 개로 확정했다. 검수 JSON은 이 생성기들의 사람 판정 기록이며 별도 생성 경로가 아니다.
- 머리핀과 이전 얼굴·전신 기준을 폐기하고, 턱에서 끝나는 정면 얼굴과 V3 좌우 쿼터·좌우 측면·후면 얼굴을 사람 승인했다. 승인 범위는 얼굴 회전 identity이며 pose·camera·전신까지 확장되지 않는다.
- 일반 핏 회색 마이크로 크롭탑-허리선 관계, 바지·신발·자켓·가방과 정면 전신을 사람 승인했다. 정면 전신은 165cm·55kg·7.5등신 비례와 기본 복장까지만 승인한다.
- 정면 전신과 승인된 좌측 측면 얼굴을 입력으로 좌측면 전신을 생성하고 사람 승인했다. 복장 통일까지 마친 최종 PNG만 `p7-5-2-fullbody-profile-left-v3.png`로 등록했으며, 회전·비례 보정 중간 PNG는 실행 이력만 남기고 제거했다. 표정과 나머지 방향 전신은 새 후보 생성·사람 검수가 남아 있다. P7-5.3 컷신과 P7-5.4 연속성 보정은 이 미승인 범위를 입력으로 사용할 수 없다.
- 우측면 후보에서 앞·뒤 팔 윤곽이 함께 남은 결함을 기록했다. 좌우 엄격 측면 규칙은 가까운 쪽 팔 한 개의 어깨·팔꿈치·손목·손 실루엣과 먼쪽 팔의 몸통 뒤 가림을 세 생성 단계의 공통 계약으로 추가했다.
- 다섯 방향에 같은 직접 회전 prompt를 적용하면 방향별 완성도가 낮아진다는 검토에 따라 분기했다. 후면은 기존 직접 회전 패턴을 유지하고, 좌우 측면에는 몸통·사지의 전후 가림과 lateral depth 계약을, 좌우 전면 쿼터에는 가까운 쪽·먼 쪽의 얼굴·어깨·골반·다리 깊이 계약을 적용한다.
- 압축한 방향 전용 prompt와 단계별 다중참조를 적용해 좌우 쿼터·좌우 측면 전신을 재생성하고 사람 승인했다. 후면은 기존 직접 회전 결과를 유지했다. 후면은 1회, 좌우 측면은 방향 결정·복장 보강 2회, 좌우 쿼터는 방향 결정·깊이 보강·복장 보강 3회로 구성하며, 두 번째 단계부터는 정면 전신을 다시 입력하지 않는다. 정면과 다섯 방향 전신은 기본 비례·복장·신발 범위에서만 승인한다.
- V2·V3 미승인 후보와 V4 중간 단계 PNG, 구형 좌측면 전신 기준을 제거했다. V4 방향별 마지막 PNG와 V13 실행·승인 기록만 유지한다.
- 정면 얼굴·방향 얼굴·표정·소품·정면 전신·방향 전신의 여섯 생성기는 실행 JSON에 전체 prompt와 `prompt_word_count`를 함께 기록하도록 통일했다. 이 값은 프롬프트 비대화 점검용이며 품질 승인 점수는 아니다.
- P7-5.1의 승인 manifest에서는 타일 비교 이미지가 아닌 개별 화풍 원본 하나만 선택해 사용한다. P7-5.2의 인물 기준은 화풍 입력과 별도로 검수한다.
- 원고의 첫 생성·검수 블록을 정면 얼굴 기준으로 옮기고, 이후 방향 얼굴·소품·전신이 이 앵커를 받는 순서를 표와 본문에서 일치시켰다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.08.05`. 생성 실행 리포트는 로컬 작업공간에서만 관리하며 커밋하지 않는다.

### v2026.08.06

- 통합 전신 보강으로 만든 전면 쿼터·후면·측면 PNG를 사람 승인해 안정 전신 기준으로 대체했다. 측면은 전면·후면 통합 착장 기준을 함께 참조하고, 재킷 몸판·소매·옆등판을 짧은 전용 계약으로 고정해 재킷 누락을 해소했다. 정면까지 포함한 네 방향은 자켓·가방 보강 범위가 승인됐다.
- 원고 흐름을 얼굴 기준 → 소품 기준 → 방향 전신 → 전신 얼굴·소품 보강 순서로 재배치했다. 소품의 색·형태·착장 관계 계약을 먼저 확인한 뒤 전신 입력과 검수 범위를 읽도록 정리했다.
- Chapter 5 생성 리포트는 저장소에서 제거하고 ignore 처리했다. 원고에는 승인 기준 이미지, 입력 목록을 정하는 manifest, 재실행 가능한 생성 코드만 연결한다.
- 전신 턴어라운드는 시트 생성 대신 방향별 개별 PNG 생성으로 전환했다. 승인 정면 전신과 P7-5.1 화풍 참조를 제거하고, 얼굴 턴어라운드와 크롭탑·바지·신발 소품만 입력으로 둔다. 승인 PNG만 후속 조합 단계에서 검수 시트로 배열한다.
- 측면 후보의 추정값이 약 5.95등신, 정면 후보가 약 6.50등신으로 목표 7.5등신에 미달한 것을 확인했다. 등신 수치·작은 상체·높은 골반·긴 다리 지시는 단일 생성에서 안정적인 제어가 되지 않아 전신 prompt에서 제거하고, 실제 비율은 사람 검수 항목으로만 유지한다.
- 같은 입력·시드로 개별 생성한 정면·전면 쿼터·측면·후면 네 PNG를 사람 승인하고, 이전 여섯 방향 전신 기준을 대체했다. 승인 범위는 자연스러운 비례, 전신 프레이밍, 기본 복장·신발, 청록 단발의 연속성이다.
- 원고의 생성 순서를 정면 얼굴 생성 → 얼굴 회전 시트 → 전신 회전 개별 PNG로 재배치했다. 소품 기준은 전신 단계가 참조하는 독립 계약으로 연결한다.
- 승인된 전신 방향 PNG를 composition 앵커로, CodeFormer로 복원·2배 확대한 정면 얼굴 패널을 identity 앵커로, 흰색 크롭 유틸리티 자켓과 짙은 네이비 크로스백을 추가 소품으로 쓰는 보강 생성기를 추가했다. 보강 출력은 기본 전신 기준을 대체하지 않으며 별도 사람 검수 대상이다.
- 얼굴 회전 시트 뒤에 CodeFormer `w=1.0` 복원과 Lanczos `2x` 확대 단계를 추가했다. 이는 화풍 변환이 아니라 정면 얼굴 identity 입력 준비이며, 홍채·눈·코·입·턱·헤어라인이 바뀌면 보강 입력으로 사용하지 않는다. 후면 패널은 얼굴이 없어 확대만 적용한다.
- 전신 얼굴·소품 보강의 첫 검수에서 정면·전면 쿼터는 통과 후보였지만 측면·후면은 자켓이 누락됐다. 측면에는 자켓 외곽·소매·옆/후면 패널을, 후면에는 흰 등판·소매·밑단을 방향 전용 prompt로 추가하고 가방이 자켓 외곽을 대체하지 않도록 보강했다.
- 정면 얼굴 앵커와 기본 시드 `62377`로 생성한 정면·쿼터뷰·측면·후면 4패널 턴어라운드 시트를 사람 승인했다. 홍채·동공 비율, 시선-코 정렬, 콧대·코끝, 단발 실루엣을 얼굴 회전 identity 범위에서 대조하며, pose·camera·표정·전신 범위는 승인하지 않는다.
- 승인 PNG와 검수 JSON을 타임스탬프 후보명 대신 `p7-5-2-face-turnaround-reference` 안정 이름으로 정리하고, 원고의 이전 V3 좌우 방향 자산·옵션 설명을 새 4패널 시트와 현재 CLI 옵션으로 교체했다.
- 표정 detail과 정면 전신 생성기를 폐기하고, 현재 기준 이미지 생성 소스를 정면 얼굴·방향 얼굴·소품·방향 전신 네 개로 축소했다. 승인된 정면 전신 PNG는 방향 전신의 입력 자산으로만 유지한다.
- 얼굴 턴어라운드·정면 전신·소품을 한 번에 넣은 전신 4패널 시트 실험은 상단 패널의 전신 프레이밍과 쿼터뷰 방향 계약에 실패해 거절했다. 후보 PNG와 실행 리포트는 커밋하지 않는다. 다음 실험은 방향별 개별 생성 뒤 검수 시트 조합으로 분리한다.
- 삭제된 v3 정면 앵커는 prompt만으로 재생성·사람 승인한 `p7-5-2-face-front-reference.png` 안정 자산으로 교체했다. 이후 얼굴 턴어라운드는 이 정면 기준을 앵커로 사용한다.
- 소품 통합 생성기에 `jacket_rear` 대상을 추가했다. 이는 포켓·단추·가방·인물을 제외한 흰 등판·중심 등 솔기·소매·짧은 밑단만 생성해, 전면 자켓 기준을 후면 전신에 오용하지 않는지 검수하는 review-only 후보다. 사람 승인 전에는 소품 manifest와 전신 보강 입력에 넣지 않는다.
- 전신 얼굴·소품 보강기는 방향별 자켓 입력을 선택하도록 수정했다. 정면·전면 쿼터·측면은 승인 전면 자켓 기준을 유지하고, 후면만 `jacket_rear` 검수 후보를 사용한다. 실행 JSON에는 방향별로 실제 사용한 자켓 파일명을 남기며, 결과는 계속 review-only다.
- high waist 크롭 길이와 평면 등판이 확인된 후면 자켓을 `p7-5-2-prop-reference-v2-jacket-rear.png`로 사람 승인해 소품 manifest에 추가했다. 전신 보강기의 후면 입력도 이 승인 자산으로 교체했으며, 보강 출력 자체의 사람 검수는 별도로 유지한다.
- 전신 보강에서 자켓 몸판 대신 크롭탑과 흰 소매만 남은 결함을 분리하기 위해, 자켓과 크롭탑을 하나의 레이어 관계로 생성하는 전면·후면 torso-only 후보 대상을 추가했다. 이 소품은 두 옷의 경계와 크롭 길이의 입력 계약을 검수하는 후보이며, 승인 전에는 manifest에 넣지 않는다.
- 자켓-크롭탑 전면·후면 torso-only 레이어 PNG를 사람 승인해 manifest에 추가했다. 전신 보강기의 기본 소품도 자켓 단독에서 이 방향별 레이어 기준으로 교체했으며, 보강 출력은 별도 사람 검수 대상으로 유지한다.
- 후면 레이어 PNG는 더 짧은 회색 크롭탑이 자켓 밑단 아래에 보이는 길이 계약 오류로 승인 취소하고 manifest에서 제거했다. 새 후면 후보는 회색 상의가 흰 자켓 등판·밑단에 완전히 가려지는지 다시 검수한다.
- 피부 띠가 보이는 새 후면 자켓-크롭탑 레이어 PNG를 사람 승인해 manifest에 추가했다. 전신 보강기의 후면 레이어 입력도 이 안정 자산으로 교체했으며, 후면 전신에서는 회색 상의가 보이지 않고 자켓 밑단과 바지 사이에 피부가 보여야 한다.

- 전면 통합 착장 PNG도 사람 승인해 manifest에 추가했다. 전면의 가방 본체·오른쪽 어깨에서 왼쪽 외측 골반으로 이어지는 스트랩과 후면의 제한된 가방 노출을 한 쌍의 소품 계약으로 사용한다. 전신 보강 출력은 계속 별도 사람 검수 대상이다.
