### v2026.08.05

- 일반 핏 회색 마이크로 크롭탑과 딥틸블루 하이웨이스트 바지의 착장 관계 상세컷을 사람 승인했다. 이 기준은 짧은 밑단·노출된 복부 간격·바지 허리선까지만 승인하며, 얼굴·손·전신 identity를 승인하지 않는다. 정면 전신 후보 생성은 이 새 관계 기준을 복장 입력으로 사용하고, 후보용 검수 JSON을 기존 승인 정면 전신 검수 기록과 분리한다.
- 회색 크롭탑 목선을 소품 참조로 사용해 새 정면 얼굴과 좌우 쿼터·좌우 측면·후면 얼굴을 사람 승인했다. V2 얼굴 기준은 넓고 낮은 광대, 더 분명한 볼살, 고양이 눈매의 위로 향한 눈꼬리, 밤갈색·호박색 홍채, 딥틸블루 단발을 승인 범위로 기록하며 후면의 귀 끝 일부 노출을 허용한다.
- 165cm·55kg·7.5등신 조건으로 생성한 정면 전신을 사람 승인해 `p7-5-2-fullbody-front-reference.png`로 등록했다. 이 기준은 정면 얼굴 화풍·identity와 회색 크롭탑·바지·신발의 기본 복장만 승인하며, 표정·방향 전신·컷신 범위는 계속 별도 검수를 요구한다.
- 정면 얼굴 기준을 identity와 선화·수채화 화풍의 동시 입력으로, 회색 크롭탑·바지·신발을 정면 전신의 기본 복장 입력으로 원고에 명시했다.
- 얼굴 기준 표를 정면·좌우 전면 쿼터·좌우 측면·후면의 3열 2행 배치로 정리하고, 소품 표는 정면 전신용 기본 복장과 후속 단계용 확장 소품으로 분리했다.
- 회색 라운드넥 크롭탑을 prompt-only 소품 기준으로 사람 승인해 `소품 기준 v2`에 추가했다. 새 기준은 이후 방향 전신 복장 통일 단계의 개별 소품 입력으로 사용한다.
- 정면 얼굴 앵커에서 한 번 적재한 파이프라인으로 생성한 좌우 쿼터·좌우 측면·후면 얼굴을 사람 승인했다. 새 V2 방향 얼굴은 넓고 평평한 광대, 약간의 볼살, 회색 라운드셔츠 목선 범위를 기준으로 등록했으며, 방향 전신 생성 입력을 새 파일명으로 갱신했다.
- 새 방향 얼굴 재생성은 정면 얼굴을 고정 앵커로 두고, 요청한 모든 방향을 하나의 적재된 파이프라인에서 연속 생성하도록 준비했다. 정면·회전 prompt에는 넓고 평평한 광대와 약간의 볼살을 공통 계약으로 추가했으며, 일관성은 가설로만 취급하고 사람 검수로 확인한다.
- 기존 승인 표정·방향 얼굴·정면 전신·전신 회전 이미지를 폐기하고, 정면 얼굴과 소품 기준만 남겨 새 기준 세트를 생성·검수하는 상태로 전환했다.
- 원고의 참조 관계와 실습 표를 여섯 생성기 기준으로 재구성했다. 각 생성기의 입력 계약과 최종 PNG 검수 항목을 대응시켜, 자산 검수 표는 생성 결과의 근거로 읽도록 정리했다.
- P7-5.2의 기준 이미지 생성 소스를 정면 얼굴·방향 얼굴·표정·소품·정면 전신·방향 전신의 여섯 개로 한정했다. 기준 체인 밖의 실행 순서 구성기와 옛 얼굴·신체 detail 실험 소스·참고 자산은 제거했다.
- 표정 detail 생성은 하나의 스크립트에서 `--targets`로 중립·기쁨·우려·분노·슬픔·놀람의 재생성 범위를 선택하도록 정리했다. 범위를 생략하면 전체 후보를 만들며, 후보 생성과 사람 승인을 분리한다.
- 방향 얼굴→몸통→전신→비례 보정→복장·특징 장치 통일의 단계 분리가 소품 구조를 고정하는 데 유효했음을 기록했다. 후면 가방은 마지막 단계에서 단일 가방·스트랩 시작점·등 중앙선 통과를 별도 계약으로 검수하며, 자동 생성 결과는 사람 검수를 거쳐야 한다.
- 소품 생성 소스를 하나의 prompt-only 생성기로 통합했다. `--targets`로 자켓·바지·신발·가방의 생성 범위를 선택하며, 소품별 고정 seed와 후보 전용 검수 JSON으로 재실행 범위와 승인 기록을 분리한다.
- 방향 전신 후보의 생성 순서를 방향 얼굴→몸통→전신→비례 보정→정면 전신·개별 소품 기준에 의한 복장 통일로 재구성했다. 단계는 하나의 `--views` 호출 안에서 연속 실행된다.
- 몸통과 중간 전신은 재현 기록이며, 마지막 복장 통일 출력만 사람 검수 대상임을 원고에 명시했다. 후보가 생성됐다는 사실은 새 방향 기준 승인이나 P7-5.3 입력 허용을 뜻하지 않는다.
- 얼굴 정면, 전신 정면, 얼굴 방향별, 전신 방향별 생성 소스를 lazy-load 링크로 정리했다.
- 번역 반영 상태: 한국어 원문만 반영됨.
- 관련 자산: `p7_5_2_generate_face_front_reference.py`, `p7_5_2_generate_fullbody_front_reference.py`, `p7_5_2_generate_face_direction_references.py`, `p7_5_2_generate_fullbody_direction_references.py`, `p7_5_2_expression_detail_multiref_flux.py`, `p7_5_2_generate_no_style_prop_masters.py`.

### v2026.08.04

- 사람 승인한 청색 우세 딥틸블루 와이드 팬츠로 `소품 기준 v2`의 기존 바지 기준을 교체했다. 얼굴·머리카락의 딥틸블루 통일 후보는 머리핀 배치가 흔들려 미승인으로 유지했다.

- 우측면 얼굴을 우측 전신과 정면 얼굴 참조로 새로 생성해 사람 승인했다. 우향 한쪽 눈 프로필, 보이는 귀·머리카락 실루엣, 정면보다 앞머리 쪽으로 이동한 단일 다이아형 헤어핀을 기준으로 등록했다.
