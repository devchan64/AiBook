### v2026.08.09

- 얼굴·전신·리파인 기준 재승인: `seed=62294`로 정면 얼굴(`6 step`), 다섯 방향 얼굴(`3 step`), 다섯 방향 전신(`6 step`), 여섯 방향 전신 리파인(`3 step`)을 사람 승인하고 안정 PNG와 `review.json`을 교체했다.
- 생성 구조 단순화: 방향 전신은 승인 정면과 좌·우 방향 얼굴 시트를 쓰는 단일 단계로, 전신 리파인은 승인 전신·방향별 얼굴 PNG·통합 착장을 개별 입력으로 쓰는 단일 단계로 정리했다. 폐기된 2차 얼굴 보정, identity JSON 입력, 중간 후보와 옛 4방향 사례는 제거했다.
- 우측 전면 쿼터 리파인은 앞가슴의 단일 스트랩과 먼쪽 골반 뒤로 가려져 외곽만 보이는 가방을 승인 범위로 고정해 안정 자산을 교체했다.
- 원고의 생성 코드·승인 이미지·검수 JSON 배치를 현재 여섯 방향 구조에 맞춰 정리하고, JSON 링크는 일반 2열 표로 분리했다.
- 후보 파일명에서 계약 해시를 제거하고 프로세스별 6자리 실험 코드와 seed·step을 기록하도록 통일했다. 전체 입력 계약과 prompt는 실행 JSON에 보존한다.
- 번역 동기화 메모: 한국어 원문만 반영됨. 번역본은 여섯 방향 승인 구조, 우측 쿼터 가림 관계, 파일명 규칙을 동기화해야 한다.

### v2026.08.08

- 정면 전신은 `960×1440`, 전신 `3 step`과 얼굴 보강 `6 step` 결과를 승인해 방향 생성의 유일한 정면 앵커로 등록했다.
- 좌·우 전면 쿼터·좌·우 측면·후면 전신을 방향별 PNG로 승인했다. 당시 방향 생성은 1차 `3 step`, 2차 얼굴 identity `9 step`을 기본으로 사용했으며 후면은 얼굴 비노출 계약을 따랐다.
- 얼굴 기준을 정면과 좌·우 쿼터·좌·우 측면·후면의 개별 원본 PNG로 교체하고 CodeFormer 복원·`2x` 확대 의존을 폐기했다. 얼굴 공용 identity JSON은 정면·방향 얼굴의 prompt 계약으로 설명했다.
- 소품 기준은 회색 크롭탑, 바지, 신발, 흰 크롭 자켓 전·후면, 레이어 관계, 전·후면 통합 착장과 가방으로 정리하고 `seed=62294` 후보를 승인했다.
- 전신 리파인은 여섯 방향, `960×1440`, 기본 `3/3 step` 구조로 정리해 정면과 좌·우 쿼터·좌·우 측면·후면 안정 사례를 승인했다. 이후 단일 단계화의 근거가 된 2단계 실행 기록은 이 날짜의 이력으로만 남긴다.
- 정면 생성기와 방향 생성기를 분리하고, 원고의 방향별 이미지·라벨을 3열 배치로 정리했다. 미승인 후보, 구형 시트, 동적 앨리웁 실험 자산은 승인 체인에서 제외했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.08.08`.

### v2026.08.06

- 실제 파일이 없는 전체 캐릭터 manifest 대신 얼굴·소품·전신의 개별 승인 PNG와 검수 기록으로 사용 범위를 설명하도록 원고를 재구성했다.
- 얼굴 턴어라운드와 전신은 시트 출력에서 방향별 개별 PNG 생성으로 전환했다. 정면 얼굴을 앵커로 사용하며 결과는 얼굴 회전 또는 전신 방향 범위에서만 승인했다.
- 자켓 전·후면, 자켓-크롭탑 레이어, 전·후면 통합 착장과 가방의 가림 관계를 분리해 승인하고 방향별 전신 리파인 입력으로 연결했다.
- CodeFormer `2x` 얼굴 입력과 다중참조 전신 보강을 시험했으며, 정면·쿼터는 통과 후보를 얻고 측면·후면의 자켓 누락은 방향 전용 prompt와 소품 기준으로 보강했다. 이 구조는 이후 원본 얼굴 직접 참조 방식으로 교체됐다.
- 화풍 참조 농구 점프 예제는 P7-5.3 pose·scene 승인과 분리한 review-only 사례로 기록했으며, 이후 화풍 입력과 관련 자산은 현재 캐릭터 기준 체인에서 제외했다.
- 생성 리포트와 중간 후보는 저장소에서 제거하고, 승인 이미지·입력 기준·재실행 코드만 원고에 연결했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.08.06`.

### v2026.08.05

- 정면 얼굴에서 시작해 방향 얼굴·소품·정면 전신·방향 전신으로 확장하는 생성·검수 순서를 확정하고, 각 생성 기록에 전체 prompt와 `prompt_word_count`를 남기도록 통일했다.
- 머리핀을 폐기하고 얼굴형·홍채·단발을 기준으로 정면과 방향 얼굴을 승인했다. 회색 크롭탑·바지·신발·자켓·가방과 정면 전신도 기본 비례·복장 범위에서 승인했다.
- 방향별 prompt를 후면·측면·쿼터로 분기해 몸통·사지의 가림과 깊이를 보강하고, 최종 방향 PNG만 승인 자산으로 유지했다.
- 미승인 후보와 중간 단계 PNG를 제거하고, P7-5.1 화풍 원본과 P7-5.2 인물 기준의 역할을 분리했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.08.05`.
