### v2026.08.05

- 소품 생성 소스를 하나의 prompt-only 생성기로 통합했다. `--targets`로 자켓·바지·신발·가방의 생성 범위를 선택하며, 소품별 고정 seed와 후보 전용 검수 JSON으로 재실행 범위와 승인 기록을 분리한다.
- 방향 전신 후보의 생성 순서를 방향 얼굴→몸통→전신→정면 전신 기준에 의한 복장 통일로 재구성했다. 단계는 하나의 `--views` 호출 안에서 연속 실행되며, workflow 소스는 입력·중간 산출물·최종 출력의 관계를 JSON으로 기록한다.
- 몸통과 중간 전신은 재현 기록이며, 마지막 복장 통일 출력만 사람 검수 대상임을 원고에 명시했다. 후보가 생성됐다는 사실은 새 방향 기준 승인이나 P7-5.3 입력 허용을 뜻하지 않는다.
- 얼굴 정면, 전신 정면, 얼굴 방향별, 전신 방향별 생성 소스와 실행 순서 구성 소스를 lazy-load 링크로 정리했다.
- 번역 반영 상태: 한국어 원문만 반영됨.
- 관련 자산: `p7_5_2_generate_face_front_reference.py`, `p7_5_2_generate_fullbody_front_reference.py`, `p7_5_2_generate_face_direction_references.py`, `p7_5_2_generate_fullbody_direction_references.py`, `p7_5_2_compose_fullbody_direction_workflow.py`.
- 원문 기준 버전: `v2026.08.05`

### v2026.08.04

- 머리핀 없는 prompt-only 정면 얼굴 기준을 사람 승인했다. 딥틸블루 bob, 고양이 눈매, 밤갈색·호박색 방사형 물결 홍채, 높은 콧대와 무장식 범위만 승인했다.
- 머리핀 관련 자산·생성 코드·검수 기록을 폐기했다. 머리핀을 포함한 정면·우측면·우측 전면 3/4 얼굴 기준과 이에 의존한 미승인 전신 실험도 제거했으며, 소품 패키지는 자켓·바지·신발·가방 네 장만 유지한다.
- 사람 승인한 청색 우세 딥틸블루 와이드 팬츠로 `소품 기준 v2`의 기존 바지 기준을 교체했다. 얼굴·머리카락의 딥틸블루 통일 후보는 머리핀 배치가 흔들려 미승인으로 유지했다.
- 사용자 노출 용어를 `master` 대신 `기준`으로 정리했다. 화풍 입력 없이 prompt-only로 생성한 재킷·바지·신발·가방을 사람 승인해 `소품 기준 v2`에 등록했으며, 머리핀은 보류로 남겼다.
- 이전 머리핀을 폐기하고, 날카로운 가로 긴 마름모 외곽과 같은 방향의 중앙 타공을 가진 새 prompt-only 머리핀을 `소품 기준 v2`에 등록했다.
- 정면 얼굴 master와 별도 정면 기준을 하나의 정면 얼굴 기준으로 통합했다. 화풍·기존 얼굴·전신 이미지는 입력에서 제거하고, 승인된 머리핀 기준 한 장과 기존 얼굴 prompt만으로 새 정면 기준을 생성·사람 승인했다. 기존 정면 홍채 detail은 눈 규격 대조용으로 유지했다.
- 사람 승인한 짙은 청록 와이드 팬츠, 짙은 네이비 캔버스 크로스백, 은색 긴 마름모 타공 머리핀을 소품 master에 추가했다. 이 master는 이제 신발·자켓·바지·가방·머리핀을 개별 PNG로 가리키며, 미승인 중복 소품 후보는 제거했다.
- 승인된 흰색 스니커즈와 흰색 크롭 유틸리티 자켓을 개별 PNG로 가리키는 `p7-5-2-prop-master-v1.json`을 추가했다. 헤어핀·크로스백·바지 후보는 아직 소품 master에서 제외했다.
- 화풍 원본만을 참조해 만든 흰색 크롭 유틸리티 자켓 detail을 사람 승인했다. 칼라·양쪽 flap pocket·단추·소매·재단선만을 승인 범위로 등록하고, 기존 미승인 자켓 hardware 후보는 제거했다.
- 화풍 원본만을 참조해 만든 흰색 스니커즈 detail을 사람 승인하고 기존 신발 detail 자산을 교체했다. 헤어핀과 이전 신발 후보는 미승인으로 삭제했으며, 원고의 lazy-load source를 새 생성 스크립트로 갱신했다.
- 정면 전신 master 하나만을 생성 기준으로 한 우측 전면 3/4 얼굴 detail을 사람 승인해 기존 원고 표의 우측 쿼터 얼굴 기준을 교체했다. 두 눈, 턱선, 단발 실루엣만을 이 view-specific 범위에서 승인했다.
- 정면 전신 master를 단일 identity 기준으로 사용해 좌우 전면 쿼터 전신을 사람 승인했다. 좌측은 좌향 전신 방향을, 우측은 몸 우향 30도·얼굴 정면의 view-specific 방향을 고정했으며, 기존 4방향 측면 baseline은 유지했다. 미승인 회전 후보와 중간 생성 스크립트는 제거하고 사람 검수 기록만 보관했다.
- 우측면 얼굴을 우측 전신과 정면 얼굴 참조로 새로 생성해 사람 승인했다. 우향 한쪽 눈 프로필, 보이는 귀·머리카락 실루엣, 정면보다 앞머리 쪽으로 이동한 단일 다이아형 헤어핀을 기준으로 등록했다.
- P7-5.2 원고에 `참조 관계와 생성 순서` 표를 추가했다. 화풍·정면·후면을 먼저 검수하고 좌측 전신·좌측면 얼굴을 파생하는 관계와, 우측면 얼굴은 별도 view-specific 검수 뒤에만 참조 체인에 편입하는 범위를 기록했다.
- 좌측면 얼굴을 정면 얼굴·후면 머리·화풍 참조로 새로 생성해 사람 승인했다. 헤어핀과 가르마가 없는 한쪽 눈 좌측 프로필을 기준으로 등록하고, 기존 미승인 좌측면 후보를 제거했다.
- 승인된 좌측 전신 측면을 정면·후면·화풍 참조 순서의 새 로컬 GPU 생성본으로 교체했다. 사람 검수에서 좌향 전신, 무헤어핀, 가르마 없음, 무가방을 확인했으며, 원문 lazy-load source와 turnaround manifest를 같은 참조·seed·검수 조건으로 갱신했다.
- P7-5.2 본문에 승인된 정면·좌측 측면·후면·우측 측면 전신 PNG를 2×2 비교 표로 추가했다.
- 홍채·동공·다이아형 헤어핀을 함께 검수한 새 정면 얼굴 detail을 사람 승인해 기존 정면 얼굴과 별도 헤어핀 detail을 대체했다. 이전 얼굴 후보와 실패한 헤어핀 위치 후보는 제거했다.
- 기존 좌측 3/4·좌측 측면·후면 얼굴 자산을 폐기하고, 새 정면 기준에서 좌우 3/4·좌우 측면·후면 머리 후보를 생성했다. 이 방향 후보들은 아직 사람 승인 전이다.
- 헤어핀을 보이지 않게 한 후면 머리 후보를 사람 승인해 정면 얼굴 detail과 함께 머리 방향 기준으로 등록했다. 좌우 3/4·좌우 측면은 계속 미승인이다.
- 우측 전면 3/4 얼굴 후보를 사람 승인해 정면의 갈색 홍채·동공·단일 다이아형 헤어핀 기준을 해당 방향까지 확장했다. 좌측 전면 3/4과 좌우 측면은 계속 미승인이다.
- 다이아형 은색 헤어핀·귀 detail과 흰 끈 운동화 detail을 사람 승인해 별도 검수 manifest와 원고 이미지로 등록했다. 눈·피부, 손·손목, 재킷 hardware는 미승인으로 남겼다.
- 놀람 표정을 사람 승인해 표정 기준으로 등록했다. 우려·슬픔은 재생성 대상으로 유지했다.
- 분노 표정을 사람 승인해 중립·기쁨과 함께 캐릭터 표정 기준으로 등록했다.
- 정면·좌측 전면 3/4·좌측 측면·후면 얼굴 detail 네 장을 사람 승인했다. 걱정·슬픔은 승인 범위에서 제외했다.
- 얼굴 방향과 표정 detail의 FLUX.2 생성 원문을 lazy-load source로 연결하고, 별도 검수 JSON에서 우측 얼굴 방향·감정 표정·동적 컷과의 경계를 기록했다.
- 캐릭터 master와 정면·좌측 측면·후면·우측 측면의 로컬 GPU 전신 원본을 사람 승인한 4방향 baseline으로 기록했다. 이 승인은 3/4 view, 동작, camera yaw, 컷신 입력까지 뜻하지 않는다.
- 좌측 측면을 Canny·OpenPose·depth 없이 승인 정면 master와 P7-5.1 화풍 원본만 참조하는 FLUX.2 다중 참조 생성으로 재구성했다. 기존 Canny 레이아웃 자산은 제거하고, prompt 계약과 사람 검수의 역할을 원고에 설명했다.
- 기준 생성 소스를 얼굴 정면, 전신 정면, 얼굴 방향별, 전신 방향별의 네 파일로 분리했다. 방향별 스크립트는 `--views` 배열로 여러 방향을 받고, 공통 생성 규칙·공통 제약·방향 전용 규칙을 분리했다. 전신 방향별 생성은 얼굴→몸통→전신→정면 전신 기준에 의한 복장 통일을 한 호출 안에서 연속 실행한다. 별도 workflow 소스는 이 고정 실행 순서와 최종 검수 gate를 JSON으로 구성한다.
- 이전 화풍 조건 character master 이미지와 전용 스크립트는 현재 정면 얼굴 기준 기반 회전 생성과 중복되어 제거했다.
- 기존 local character anchor contact sheet, turnaround 원본, manifest와 생성 코드는 현재 화풍 기반 실험과 중복되어 제거했다.
- 번역 반영 상태: 한국어 원문만 반영됨.
- 관련 자산: `p7-5-2-face-front-v2.png`, `p7_5_2_generate_face_front_reference.py`, `p7_5_2_generate_fullbody_front_reference.py`, `p7_5_2_generate_face_direction_references.py`, `p7_5_2_generate_fullbody_direction_references.py`.
- 원문 기준 버전: `v2026.08.04`

### v2026.08.03

- 원고를 local-GPU-only 캐릭터 참조 셋 생성 단계로 재구성했다. 외부 생성 서비스 원본, 그 원본을 학습 또는 직접 참조로 사용한 비교 결과, 관련 LoRA·FLUX 실험은 P7-5.2의 근거와 자산에서 제외했다.
- 화풍 참조 팩은 P7-5.1에서만 생성·승인하도록 경계를 정리했다. P7-5.2의 neutral character anchor는 identity·전신 비례용이며, P7-5.1 화풍 참조 팩을 대체하지 않는다.
- 캐릭터 패키지의 기준·표정·전신 이미지, train scene, held-out scene, 실행·검수 기록 구성을 유지했다. 현재 local-only로 제한 승인된 것은 무소품·대칭 의상의 neutral full-body turnaround이며, 표정·손·소품 detail과 train·held-out 장면은 아직 미승인 상태로 기록했다.
- 기존 캐릭터셋 체크리스트의 등록·분리·비례·비교·품질·전체 컷·다음 단계 항목을 유지하고, local GPU 출처와 mirror의 대칭 범위 점검을 추가했다.
- local master, view 확장, strict profile, manifest builder Python 원문을 lazy-load source로 연결했다. 긴 코드 줄은 공통 source viewer의 줄바꿈 규칙을 따른다.
- 번역 반영 상태: 한국어 원문만 반영됨.
- 관련 자산: 이후 화풍 기반 master 실험으로 대체되어 제거됨.
- 원문 기준 버전: `v2026.08.03`
