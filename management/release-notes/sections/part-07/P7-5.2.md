### v2026.09.11

- P7-5.1의 입력·모델 내부·산출 흐름에 맞춰 Qwen Edit 파이프라인 도식을 자체 작성했다. 이미지·지시의 Qwen2.5-VL 조건 경로, VAE 이미지 latent, noise 출발점, transformer·scheduler 반복과 VAE decode를 구분했다. 로컬 Diffusers의 `pipeline_qwenimage_edit_plus.py`와 상반신·다각도 생성 코드로 연결 관계를 대조했다. 자산: `p7-5-2-qwen-edit-pipeline-ko.mmd`. 번역 동기화: 한국어 원문과 도식만 반영.

- 1024px 결과로 교체한 아이레벨 +45°·엘리베이티드 +45°의 기존 1280px PNG와 개별 JSON 총 4개를 삭제했다. 다른 원고·코드의 참조가 없음을 확인했다.

- 엘리베이티드 +45° 이미지와 개별 실행 JSON도 1024×1024·seed 62294·4 step의 native1024-v1 결과로 교체했다. 표에는 1024px 결과 2장과 기존 1280px 결과 13장이 포함됨을 명시하고 해당 방향의 실행 옵션을 추가했다.

- 아이레벨 +45° 이미지와 개별 실행 JSON을 토르소 참조·1024×1024·seed 62294·4 step의 native1024-v1 결과로 교체했다. 나머지 14방향은 기존 채택 결과를 유지하며, 표의 해상도 차이와 생성기의 공통 기본 설정을 명시했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.11`.

### v2026.09.10

- 일괄 실행·선택 목록 링크 대신 각 5방향 이미지 표 아래에 개별 실행 JSON을 독립 문단으로 배치했다. 15개 링크에 `lazy-source`를 적용하고 불필요해진 선택 목록 파일을 제거했다.

- 교체 전 로우앵글 0° seed 62294 PNG·JSON과 기존 일괄 실행 목록을 폐기했다. 현재 채택한 15방향의 개별 실행 기록을 원고에 직접 연결하고, 이전 BFS 비교 생성기의 해당 참조도 seed 62295 결과로 변경했다.

- 로우앵글 0°를 seed 62295·4 step 결과로 교체하고 개별 실행 기록을 연결했다. 생성기에서 시드 생략 시 해당 방향만 62295, 나머지는 62294를 적용하며 명시적 `--seed`는 전체 선택 방향에 우선하도록 수정했다.

- 문장 안의 소스코드·JSON 링크 2개를 설명 문장과 분리해 각각 독립 문단으로 배치했다. 링크 대상과 기존 `lazy-source` 속성은 유지했다. 번역 동기화: 한국어 원문만 반영. 원문 기준 버전: `v2026.09.10`.

- 새 1280px Direct V1 토르소로 생성한 15방향 1280×1280·4 step 결과로 표를 교체했다. 생성기 기본 해상도·실행 라벨과 전체 실행 기록을 맞추고 기존 640px PNG 15장 및 짝 JSON 15개를 삭제했다. 배경 변경과 전신 프레이밍 사례를 새 결과 기준으로 기록했다.

- Direct V1 상반신 생성기의 출력 `width`·`height` 누락을 수정하고 저장 전 크기 검사를 추가했다. 같은 프롬프트·시드 62294·30 step으로 실제 1280×1280 결과를 생성해 원고의 PNG와 result JSON을 대체했다.
- 정면 상반신 생성기 링크와 실행 조건을 추가하고, 기존 640×640 카메라 참조 15장은 교체 전 상반신으로 생성한 결과임을 구분했다.
- 원고 미사용 neutral-gray-v3 상반신 자산을 폐기하고, 미사용 상수를 제거하고 이전 카메라 실험 코드의 기본 참조를 Direct V1으로 변경했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.10`.

### v2026.09.05

- 정면 머리 identity 기준과 상반신 카메라 참조라는 학습 흐름을 남기고, 이 절에 직접 쓰이지 않는 착장 계약 세부, 15개 개별 실행 기록 링크·이전 경로 비교·세부 오프로딩 설명을 본문에서 제거했다. 실행 조건은 생성기와 필요한 이미지의 result JSON으로 확인한다.
- 15방향 비교표와 프레이밍 이탈을 해석하는 기준은 유지했다.
- 얼굴 화풍·일러스트 prompt 계약을 Mira identity 계약의 `rendering_contract`로 통합했다. 정면 머리·착장 생성기는 단일 계약 경로를 사용하도록 맞췄다.
- 정면 T2I 생성기와 상반신 I2I 생성기의 구현 역할, 고정·조작 조건, 결과 기록 방식을 보강했다. Qwen-Image, Qwen-Image-Edit-2511, Multiple-Angles LoRA, Lightning 4-step LoRA의 역할과 해석 한계도 공식 모델 카드 기준으로 구분했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.05`.

### v2026.09.04

- Mira 정면 상반신 기준을 유일한 입력으로 삼아, Multiple-Angles LoRA와 Lightning 4-step LoRA를 적용한 `640×640` 카메라 참조 15장을 본문에 추가했다. 로우앵글·아이레벨·엘리베이티드와 yaw `−90°`, `−45°`, `0°`, `+45°`, `+90°`를 5열씩 배치하고, 로우앵글 `−90°`의 프레이밍·배경 이탈을 결과 해석 범위에 명시했다.
- 상반신 멀티뷰 생성기를 원고에 연결하고, 실제 출력 해상도를 명시하는 `height`·`width`, 카메라 LoRA `0.9`, Lightning 4-step 저비용 프로필, 방향별 선택·제외 인자를 기록했다. 아이레벨 쿼터 두 장과 나머지 13장 배치의 result JSON은 lazy-source 링크로 분리했다.
- Multiple-Angles 생성기가 활성 LoRA 어댑터 하나를 확인하고 `adapter_weight=0.9`를 명시해 적용하도록 보완했다. 같은 정면 참조·시드·10 step에서 좌전방·우전방 쿼터뷰가 서로 다른 방향으로 생성된 결과와 두 result JSON을 본문에 반영했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.04`.

### v2026.09.03

- 정면 머리·어깨 확장 단계와 그 산출물을 제거하고, Multiple-Angles 생성기의 기본 Picture 1을 BF16 정면 머리 기준으로 되돌렸다. 어깨 참조에 의존한 멀티뷰 실험 기록도 원고에서 제거했다.
- Mira BF16 정면 머리 하나를 참조로 한 20 step 엘리베이티드 좌전방 쿼터뷰를 반영했다. 15방향 Multiple-Angles 생성기의 수평 5단계·수직 3단계 토큰과, 단일 머리 참조에서 상반신·옷·헤어가 새로 합성되는 한계를 함께 기록했다.
- 토르소 다중참조·Multiple-Angles 생성기와 체스트 기준·회전 비교 문단을 제거했다. P7-5.2는 Mira 정면 머리 identity 기준과 그 단일 참조 실험만 유지한다.
- Mira 정면 머리 T2I 생성기의 기본 경로를 `Qwen/Qwen-Image` BF16 직접 Diffusers 실행과 `sequential CPU offload`로 전환했다. Mira identity·얼굴 일러스트 계약을 읽어 prompt와 result JSON에 함께 기록하며, ComfyUI·GGUF·HTTP 서버는 이 기본 경로에 포함하지 않는다.
- 정면 얼굴 기준 이미지를 BF16 1280px·30 step 생성물로 교체했다. 이 산출물은 Mira identity 계약과 얼굴 일러스트 계약을 함께 기록한 result JSON과 한 쌍으로 둔다.
- 체스트·다중 앵글의 기본 품질 경로를 공식 `Qwen-Image-Edit-2511` BF16 직접 실행과 `sequential CPU offload`로 명시했다. GGUF는 OOM·실행 시간 비교에만 사용하며, BF16 직접 실행 결과와 품질 기준을 섞어 판단하지 않는다.
- 캐릭터명을 Mira로 정의하고, 공용 `p7-5-2-character-identity-contract.json`을 `p7-5-2-mira-identity-contract.json`으로 변경했다. 계약에는 Mira의 얼굴·헤어·기본 착장 범위와 자세·카메라·장면을 맡기지 않는 경계를 명시했다.
- Mira 머리 생성기를 서버리스 Comfy 노드 직접 호출 구조로 교체했다. `Q3_K_S`와 `Q4_K_S`를 512px·10스텝·동일 시드와 CFG로 비교한 실행 기록을 남겼으며, Q4가 정면 구도를 더 안정적으로 유지했다.
- 정면 기준 이미지를 1280px·30 step Q4 출력으로 대체하고, 20대 초반 성인 Mira의 얼굴 비율을 identity 계약과 후속 착장·얼굴 이식 코드의 기본 참조로 연결했다.
- 체스트 기준 생성기를 `Qwen-Image-Edit-2511`의 두 이미지 참조 방식으로 교체했다. 새 1280px·10 step 결과는 정면 Mira 얼굴을 identity로, 기존 체스트를 프레이밍으로 사용한다. 이너 크롭탑은 `inner_top_identity`에서 핏·중성 미디엄 그레이(`#5B5B5B`)·넥라인·소매·기장을 읽어 기록한다. 카메라 앵글 생성기의 기본 입력도 이 결과로 대체했다.
- 체스트 회전 생성기를 `fal/Qwen-Image-Edit-2511-Multiple-Angles-LoRA`를 직접 로드하는 2511 다중참조 경로로 반영했다. Picture 1 체스트·Picture 2 정면 얼굴의 입력 순서와 `<sks> [azimuth] [elevation] [distance]` 카메라 prompt 계약, `--no-angle-lora` 비교 옵션, result JSON의 LoRA·입력·카메라 기록 범위를 본문과 모델 인벤토리에 함께 정리했다. 기존 1024 카메라 표는 새 1280px 결과로 대체하기 전까지 이전 비교 이력으로 유지한다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.03`.
