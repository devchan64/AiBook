- 원고의 이미지·lazy source 경로를 사이트 루트 기준으로 정리해 `/parts/assets/...` 404를 해소하고, Markdown과 CSS Grid로 원본 비교를 표시했다.

### v2026.08.04

- 과거 후보·sidecar·중복 ledger 기록을 정리하고, 지속적으로 남길 사람 판정은 review ledger와 승인 manifest로 일원화했다. contact sheet는 만들지 않는다.
- 반복 생성에서도 공간 조건을 안정적으로 만족하지 못한 여객기 행은 폐기하고, 창밖의 밤과 작은 스탠드 조명을 가진 창가 독서실로 대체했다. 이 장면과 courtyard를 포함한 아홉 local-GPU 원본은 모두 사람 승인을 받았다.
- ledger와 manifest를 `approved_for_character_reference`로 전환하고, gate 통과를 확인했다. P7-5.2는 타일 비교 이미지가 아니라 manifest의 개별 원본 하나만 화풍 입력으로 사용한다.
- 모델 도식·해설을 tokenizer/text encoder, latent, FlowMatch scheduler·transformer 반복, VAE decode, 사람 검수로 정교화했다. 8 GB VRAM에서의 BF16·sequential CPU offload와 행별 생성의 운용 경계, 모델·프롬프트·토큰화·임베딩·트랜스포머의 연결도 보강했다.
- 원고의 승인 원본은 3×3 Markdown 표로, Python 원문은 lazy-load 코드 패널로 정리했다. 사이트 루트 기준 자산 경로와 `Diffusers Reduce memory usage` 근거도 보완했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.08.04`. 관련 자산: `p7-5-1-style-reference-pipeline-ko.mmd`, `p7-5-1-ai-model-inference-pipeline-ko.mmd`, `p7_5_1_regenerate_local_gpu_style_references.py`, `p7_5_1_local_style_pack_gate.py`, `p7-5-1-approved-style-reference-pack.json`.
