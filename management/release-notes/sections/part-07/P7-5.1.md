### v2026.08.01

- 변경 이유: CUDA 실행 환경에서 P7-5.1 Python 예제를 실제로 실행해, LoRA weight 비교가 동작하는지와 8 GB VRAM에서의 실행 경계를 확인했다.
- 본문 반영: 8 GB VRAM 환경에서도 실행할 수 있도록 CPU offload 전략을 예제에 반영하고, LoRA 로드에 필요한 `peft` 의존성을 명시했다.
- 추가 반영: 기준 이미지는 `adapter_weight=0.0` 설정에만 의존하지 않고 `disable_lora()`로 adapter를 명시적으로 끄도록 예제를 보완했다. LoRA 로드에 필요한 `peft` 의존성도 명시했다.
- 실험 설계 보완: 한 seed의 세 이미지로 weight 효과를 판단하지 않고, seed `42`·`43`·`44`와 weight `-3.0`·`0.0`·`3.0`을 교차한 아홉 이미지에서 반복되는 변화를 기록하도록 바꿨다.
- 예제 조합 교체: 반복 변화가 확인되지 않은 제품 사진 LoRA 대신, SDXL pixel-art LoRA slider와 weight `-3.0`·`0.0`·`3.0` 조합으로 교체했다. 세 seed 검토에서 반복된 사진풍·일러스트풍 변화를 설명하고, seed `42`의 세 이미지를 공개 자산으로 추가했다.
- 번역 동기화 메모: 번역본도 CPU offload와 기준 결과의 LoRA 비활성화 의미를 같은 조건으로 유지한다.
- 번역 반영 상태: 한국어 원문만 반영됨.
