### v2026.08.06

- 생성 검수 ledger는 로컬 실행 기록으로 전환하고, 리포트 JSON의 링크와 커밋 대상을 제거했다. 다음 단계 입력을 정의하는 승인 manifest와 승인 PNG만 저장소에 유지한다.
- 배경 화풍 계약과 인물 화풍 계약의 경계를 보강했다. 인물 화풍을 얼굴·선·비율·색면의 반복 가능한 표현 규칙으로 설명하고, P7-5.1의 배경 참조 셋만으로는 이를 승인할 수 없으며 P7-5.2에서 별도로 검수함을 명시했다.
- 승인 manifest를 배경 화풍 계약의 근거로 유지하되, 인물 후보 생성은 배경 PNG를 image input으로 넣지 않고 텍스트 화풍 계약만 prompt로 전달하도록 원고와 코드 설명을 맞췄다. review-only 사람 검수 경계도 함께 기록했다.
- 성별·나이 조건이 다른 `--cast` 프롬프트를 추가했다. 단일 22세 여성, 단일 29세 남성, 27세 여성·34세 남성 2인, 19세 여성·46세 남성·67세 여성 3인 구성을 선택할 수 있다. `--compositions`는 거리·카페·옥상·공원·아트리움 장면 범위만 고르며, 후보 파일명에는 cast ID·장면 ID·실행 타임스탬프·seed를 포함한다. JSON에는 P7-5.1 텍스트 화풍 계약의 선·수채화 색층·안료 질감과 프레임 없는 단일 장면 유지 여부를 확인하는 검수 항목을 남긴다. 출력은 turnaround나 동일 identity 증거로 사용하지 않는다.
- 화풍 조건 cast 후보 생성 스크립트를 `p7_5_1_generate_style_conditioned_cast_candidates.py`로 옮겨 P7-5.1의 화풍 계약·검수 흐름에 귀속했다.
- cast 프롬프트에서 얼굴·머리·의상 등 캐릭터 묘사와 추가 인물 금지 조건을 제거하고 성별·나이·인원수만 유지했다.
- 후보별 확산 반복 횟수를 기록하는 `--steps` 옵션을 추가했다. 기본값은 기존 P7-5.1 기준인 50이며, 낮은 값으로 만든 빠른 후보는 별도 검수 대상이다.
- cast 프롬프트와 화풍·구도 지시를 압축하고, 인원수·소실점·원근·카메라 표현을 생성·승인 기준에서 제거했다. 후보 검수는 P7-5.1 화풍 텍스트 계약과 장면 구성 유지 여부만 확인한다.
- 무문자·무로고 제한을 화풍 계약에서 제거하고, 전 장면에 보이는 풍부한 자연색·수채화 색층·부드러운 색 번짐을 명시적으로 강화했다.
- 인물 후보의 화풍 설명을 배경 `COMMON_CONTRACT`와 같은 수채화·먹선·안료·광원·제외 기준으로 통일했다. 인물·장면 내용만 별도 조건으로 둔다.
- 인물 후보 검수 범위를 P7-5.1 화풍 계약으로 한정했다. 얼굴 일관성·연령·성별·인원수·동일 인물 여부는 이 절에서 판정하지 않는다.
- 거리·옥상·카페·공원·아트리움의 화풍 승인 PNG 다섯 장과 그 manifest를 원고에 반영하고, 반려·중복 후보와 로컬 실행 검수 기록은 정리했다.
- 화풍 참조 셋 Mermaid 도식에서도 manifest를 다음 모델 입력 이미지가 아니라 승인 원본과 텍스트 화풍 계약의 근거로 읽히게 정리했다.
- 독자가 P7-5.1 cast 후보 예제를 학습 단위로 읽을 수 있도록 입력·cast 조건·장면 조건·검수 기준을 표로 묶고, 반복되던 제외 범위 설명을 줄였다.
- 문단 순서를 `모델 선택 → 화풍 판정 기준 → 최소 행렬 → 실행 코드 → 모델 내부 처리 → 승인 결과` 흐름으로 조정해, 독자가 검수 기준을 먼저 잡은 뒤 `Flux2KleinPipeline` 내부 도식을 읽도록 재배치했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.08.06`.

### v2026.08.03

- 원고를 `화풍 계약 → 장면 행렬 → local GPU 생성 → 사람 검수 → 승인 manifest → 다음 단계 입력` 흐름으로 재구성하고, Mermaid 도식·표·코드 발췌로 생성 조건과 사람 판정의 경계를 설명했다.

- 내장 이미지 생성 원본을 입력·승인 범위에서 제외하고, 다섯 필수 행과 네 보조 행의 local-GPU 후보·ledger·검수 gate를 도입했다. gate는 행렬과 사람의 최종 상태만 확인한다.
- 원고의 이미지·lazy source 경로를 사이트 루트 기준으로 정리해 `/parts/assets/...` 404를 해소하고, Markdown과 CSS Grid로 원본 비교를 표시했다.

### v2026.08.04

- 과거 후보·sidecar·중복 ledger 기록을 정리하고, 지속적으로 남길 사람 판정은 review ledger와 승인 manifest로 일원화했다. contact sheet는 만들지 않는다.
- 반복 생성에서도 공간 조건을 안정적으로 만족하지 못한 여객기 행은 폐기하고, 창밖의 밤과 작은 스탠드 조명을 가진 창가 독서실로 대체했다. 이 장면과 courtyard를 포함한 아홉 local-GPU 원본은 모두 사람 승인을 받았다.
- ledger와 manifest를 `approved_for_character_reference`로 전환하고, gate 통과를 확인했다. P7-5.2는 타일 비교 이미지가 아니라 manifest의 개별 원본 하나만 화풍 입력으로 사용한다.
- 모델 도식·해설을 tokenizer/text encoder, latent, FlowMatch scheduler·transformer 반복, VAE decode, 사람 검수로 정교화했다. 8 GB VRAM에서의 BF16·sequential CPU offload와 행별 생성의 운용 경계, 모델·프롬프트·토큰화·임베딩·트랜스포머의 연결도 보강했다.
- 원고의 승인 원본은 3×3 Markdown 표로, Python 원문은 lazy-load 코드 패널로 정리했다. 사이트 루트 기준 자산 경로와 `Diffusers Reduce memory usage` 근거도 보완했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.08.04`. 관련 자산: `p7-5-1-style-reference-pipeline-ko.mmd`, `p7-5-1-ai-model-inference-pipeline-ko.mmd`, `p7_5_1_regenerate_local_gpu_style_references.py`, `p7_5_1_local_style_pack_gate.py`, `p7-5-1-approved-style-reference-pack.json`.
