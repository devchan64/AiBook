### v2026.08.03

- 구조 재배치: Chapter 5의 첫 단계를 `화풍 참조 셋 생성`으로 명시했다. 이 단계의 승인 산출물은 프레임 없는 화풍 원본과 사람 검수 기록이며, 캐릭터·컷신·보정 결과를 대신하지 않는다.
- 변경 이유: 웹툰 캐릭터 참조와 컷 생성보다 앞서, 로컬 GPU에서 만든 화풍 참조 팩 자체의 프레임·선·수채화·공간·카메라 다양성을 검수하는 독립 경계가 필요해졌다.
- 본문 반영: 8 GB급 로컬 GPU와 sequential CPU offload를 전제로, frame-free 원본, line-preserving watercolor, 실내/실외·시간대·camera family의 입력 행렬, 사람 검수 조건을 P7-5.1으로 분리했다.
- 검증 결과: 기존 flat-color pack과 수채화 후보는 장소·시간·camera 폭이 좁거나, outer frame을 post-generation crop으로 제거해야 하거나, 해칭이 과도해 승인하지 않았다. 미통과 PNG는 참조 자산으로 보존하지 않고 review ledger에 실패 원인만 남겼다.
- 부분 실행: `FLUX.2-klein-base-4B`, `768 x 1152`, 50 step, guidance `4.0`, seed `420601`의 고각도 하향 실내 후보는 frame-free 원본과 실제 high-angle 조건을 통과했다. 다만 나머지 camera family가 없어 style pack 전체는 여전히 `BLOCKED`다.
- 부분 실행: 같은 local GPU 조건에서 seed `420602`의 야외 해질녘 저각도 후보는 `150.1초`, peak `1,928 MiB`로 생성됐다. 원본에 outer frame이 없고 curb-height 상향 원근, 얇은 charcoal 구조선, 투명 수채화 색층을 보여 low-angle 행을 조건부 통과했다. 나머지 세 행이 없어 전체 style pack은 여전히 `BLOCKED`다.
- 장소 비교: 도심, 중국 장가계, 이탈리아 베니스, 여객기 실내, 우천 야간 기차 플랫폼을 `768 x 1152`, 50 step으로 같은 batch에서 생성했다. 총 `749.8초`, peak `2,888 MiB`였다. 베니스만 frame-free 사선 운하·수채화 계약을 조건부 통과해 PNG와 실행 기록을 보존했다. 도심은 중앙 소실점·표지, 장가계는 과도한 해칭, 여객기와 기차 플랫폼은 야간 조건 실패로 판정 기록만 남기고 PNG를 폐기했다.
- 실패 보정: 부정 프롬프트만 추가한 재시도는 장가계의 해칭과 항공기의 검은 패널 프레임을 각각 남겨 불합격 처리했다. 이어 장면 구도를 바꾼 `FLUX.2-klein-base-4B` 재실행(`768 x 1152`, 50 step, guidance `4.0`)은 총 `301.8초`, peak `2,886 MiB`였다. 도심은 측면 교차로, 여객기는 창가 close view로 바꿔 frame-free·무문자·시간·camera 조건을 조건부 통과했다. 장가계·우천 야간 플랫폼·첫 항공기 보정본은 PNG를 보존하지 않고 ledger에 실패 원인만 남겼다.
- 원고 개선: 후보 이미지 나열을 `화풍 계약 → 다섯 행 입력 행렬 → 행별 판정표 → 실패 원인의 구도 전환 → 사람 판정과 gate` 흐름으로 재구성했다. 조건부 통과 이미지와 전체 승인 상태를 분리하고, gate의 실제 `BLOCKED` 출력과 해석을 본문에 추가했다.
- 화풍 샘플 보강: 철로·빗줄기 선이 해칭으로 읽히는 문제와 플랫폼의 검은 프레임을 피하기 위해, 옥상 광장의 우천 야간 overhead 구도를 별도 생성했다. `768 x 1152`, 50 step, guidance `4.0`, seed `420631`은 `150.8초`, peak `1,700 MiB`에서 실행됐으며, frame-free 원본·젖은 바닥 반사광·indigo 야간·하향 시점을 조건부 통과해 마지막 행의 근거로 보존했다. 같은 배치의 플랫폼·장가계 후보는 불합격 기록만 남겼다.
- 화풍 채도 개선: 화면 표시 CSS 보정은 원본 화풍 샘플을 개선하지 못하므로 제거했다. 다음 샘플은 실제 생성 원본에서 안료 농도와 wet-on-wet 번짐을 함께 검수한다. 채도는 석양 팔레트로 고정하지 않고, 낮에는 teal·green, 석양은 제한된 apricot 역광, 밤·우천 야간은 indigo·navy와 작은 tungsten 반사로 시간대를 구분한다.
- 시간대별 채도 검증: clear daytime 공원 연못을 `768 x 1152`, 50 step, guidance `3.5`, seed `420641`로 `150.9초`, peak `1,924 MiB`에 생성했다. frame-free 원본의 teal 연못·leaf green·cool off-white·pale blue sky가 석양색 없이 낮 광원을 구분하고 수채화 번짐을 유지해 조건부 통과했다. 같은 날·우천 야간 대조 batch는 검은 외곽 프레임을 생성해 보존하지 않았다.
- 통과 샘플 재생성: 기존 조건부 통과 행을 `768 x 1152`, 50 step, guidance `3.5`로 다시 생성했다. 6행 batch는 `900.8초`, peak `2,888 MiB`였으며 낮은 teal·green·cool off-white, 석양은 제한된 apricot, 밤·우천 야간은 indigo·navy와 작은 반사광으로 구분했다. 첫 새벽 고각도 결과의 검은 패널 프레임은 제외했고, top-down 재시도(seed `420648`, `150.9초`, peak `2,366 MiB`)를 frame-free 고각도 원본으로 채택했다.
- 표적 재생성: 도심·비행기 실내·고각도·베니스를 같은 조건으로 다시 생성했다(총 `601.2초`, peak `2,888 MiB`). 도심은 낮의 teal glass·leaf green·pale-blue daylight를 조건부 통과로 교체했다. 베니스는 중앙 소실점과 과도한 apricot 하늘로 불합격 처리해 기존 사선 후보를 유지했다. 첫 고각도 아트리움도 닫힌 외곽선으로 불합격 처리했다.
- 광원·장소 보강: 열차 승강장·광원 보강 비행기 실내·야외 courtyard 고각도를 `450.8초`, peak `2,886 MiB`에 생성했다. 우천 야간 승강장은 작은 tungsten 램프와 냉백색 점광원의 젖은 바닥 반사, 비행기 실내는 천장·창틀·팔걸이의 절제된 광원, 새 고각도는 frame-free 하향 구도를 각각 조건부 통과로 보존했다. 승강장은 기존 overhead 행을 대체하지 않는 보조 장소 검증으로 기록했다.
- 사람 검수: 야외 courtyard 고각도 후보(seed `420659`)를 행 단위로 승인했다. 이는 high-angle 원본의 프레임·시점·팔레트 계약 승인이고, 전체 style pack의 최상위 승인이나 P7-5.2 진입 승인은 아니다.
- 사람 검수: 광원 보강 여객기 실내 후보(seed `420658`)를 실내·밤·oblique 행으로 승인했다. 이는 해당 원본의 야간·사선 시점·실내 광원 계약 승인이고 전체 style pack gate는 계속 차단한다.
- 사람 검수: 도심 clear-day 후보(seed `420651`)를 실외·낮·wide eye-level 행으로 승인했다. teal glass·leaf green·pale-blue daylight의 분리와 frame-free 원본을 확인했으며, 전체 style pack gate는 계속 차단한다.
- 승강장 조도 보정: 우천 야간 열차 승강장을 더 밝게 재생성했다. 세 번의 중간 시도는 각각 white margin·중앙 복도, readable marking·긴 원근, 철도 식별성 부족으로 제외했다. 네 번째 시도(seed `420663`, `150.8초`, peak `1,927 MiB`)는 full-bleed 원본에서 cool-white 캐노피 조명·pale-cyan 젖은 바닥·국소 tungsten 반사·짧은 대각 철로를 함께 보여 조건부 통과 후보로 교체했다.
- 원고 배열 개선: 세로로 이어진 후보 이미지를 반응형 2열 그리드로 재배치했다. 각 셀에 장소·시간·camera와 `행 승인` 또는 `조건부` 상태를 붙여, 이미지 나열과 전체 style pack 승인을 구분하도록 했다.
- 사람 검수: curb-height 주택가 후보(seed `420644`)를 실외·해질녘·low-angle 행으로 승인했다. 제한된 apricot 하늘과 상향 시점, frame-free 원본을 확인했으며 전체 style pack gate는 계속 차단한다.
- 사람 검수: 베니스 사선 운하 후보(seed `420645`)를 보조 oblique 구도 근거로 승인했다. 이 승인은 frame-free 원본·대각 운하·제한된 apricot 하늘을 확인한 것이며, 다섯 행의 필수 조건이나 전체 style pack gate를 대체하지 않는다.
- 사람 검수: 공원 연못 낮 후보(seed `420641`)를 자연 공간의 보조 낮 팔레트 근거로 승인했다. teal 연못·leaf green·cool off-white·pale-blue sky가 석양색 없이 유지되는지를 확인했으며, 도심의 필수 `outdoor-day-wide` 행과 전체 style pack gate는 별도로 관리한다.
- 사람 검수: 밝은 우천 야간 열차 승강장 후보(seed `420663`)를 보조 장소 근거로 승인했다. cool-white 캐노피 조명과 젖은 바닥 반사, 짧은 대각 철로를 확인했으며, 필수 `outdoor-rainy-night-overhead` 행과 전체 style pack gate는 별도로 관리한다.
- 사람 검수: 옥상 광장 우천 야간 후보(seed `420647`)를 필수 `outdoor-rainy-night-overhead` 행으로 승인했다. frame-free 원본, 하향 시점, indigo·navy 그림자와 작은 teal 반사를 확인했으며 전체 style pack gate는 별도로 관리한다.
- 추가 반영: Python gate가 review ledger의 status와 장소·시간·camera 행렬을 검사해 현재 `BLOCKED style pack`을 출력하도록 구성했다. character reference generation은 이 gate 통과 뒤에만 진행한다.
