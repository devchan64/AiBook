# Section Release Note

- Section ID: `P7-5.1`
- Source File: `docs/parts/part-07/chapter-05/section-00.md`

### v2026.08.03

- 구조 재배치: Chapter 5의 첫 단계를 `화풍 참조 셋 생성`으로 명시했다. 이 단계의 승인 산출물은 프레임 없는 화풍 원본과 사람 검수 기록이며, 캐릭터·컷신·보정 결과를 대신하지 않는다.
- 변경 이유: 웹툰 캐릭터 참조와 컷 생성보다 앞서, 로컬 GPU에서 만든 화풍 참조 팩 자체의 프레임·선·수채화·공간·카메라 다양성을 검수하는 독립 경계가 필요해졌다.
- 본문 반영: 8 GB급 로컬 GPU와 sequential CPU offload를 전제로, frame-free 원본, line-preserving watercolor, 실내/실외·시간대·camera family의 입력 행렬, 사람 검수 조건을 P7-5.1으로 분리했다.
- 검증 결과: 기존 flat-color pack과 수채화 후보는 장소·시간·camera 폭이 좁거나, outer frame을 post-generation crop으로 제거해야 하거나, 해칭이 과도해 승인하지 않았다. 미통과 PNG는 참조 자산으로 보존하지 않고 review ledger에 실패 원인만 남겼다.
- 부분 실행: `FLUX.2-klein-base-4B`, `768 x 1152`, 50 step, guidance `4.0`, seed `420601`의 고각도 하향 실내 후보는 frame-free 원본과 실제 high-angle 조건을 통과했다. 다만 나머지 camera family가 없어 style pack 전체는 여전히 `BLOCKED`다.
- 추가 반영: Python gate가 review ledger의 status와 장소·시간·camera 행렬을 검사해 현재 `BLOCKED style pack`을 출력하도록 구성했다. character reference generation은 이 gate 통과 뒤에만 진행한다.
- 번역 반영 상태: 한국어 원문만 반영됨.
- 관련 자산: `p7-5-1-local-style-pack-review.json`, `p7_5_1_local_style_pack_gate.py`.
