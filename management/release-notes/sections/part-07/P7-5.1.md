### v2026.08.06

- 생성 검수 ledger는 로컬 실행 기록으로 전환하고, 리포트 JSON의 링크와 커밋 대상을 제거했다. 다음 단계 입력을 정의하는 승인 manifest와 승인 PNG만 저장소에 유지한다.
- 배경 화풍 계약과 인물 화풍 계약의 경계를 보강했다. 인물 화풍을 얼굴·선·비율·색면의 반복 가능한 표현 규칙으로 설명하고, P7-5.1의 배경 참조 셋만으로는 이를 승인할 수 없으며 P7-5.2에서 별도로 검수함을 명시했다.
- 승인 manifest에서 개별 배경 화풍 원본 하나를 선택해 인물 후보의 style input으로 쓰는 실행 예시와 코드를 P7-5.1에 연결했다. 선택적 identity 입력, 정면 인물 후보 뒤의 전신 후보 생성, review-only 사람 검수 경계를 함께 기록했다.
- 성별·나이·인원수가 다른 `--cast` 프롬프트를 추가했다. 단일 22세 여성, 단일 29세 남성, 27세 여성·34세 남성 2인, 19세 여성·46세 남성·67세 여성 3인 구성을 선택할 수 있다. `--compositions` 생성 범위 목록으로 저각·고각·사선·상부 시점과 1·2·3점 소실 구도를 코드 수정 없이 선택할 수 있다. 후보 파일명에는 cast ID·구도 ID·실행 타임스탬프·seed를 포함하고, JSON에는 선택한 P7-5.1 배경 원본과 같은 선·수채화 색층·안료 질감, 요청 구도·성별·나이·인원수가 유지되는지 확인하는 검수 항목을 남긴다. 출력은 turnaround나 동일 identity 증거로 사용하지 않는다.
- 배경 PNG를 인물 생성 모델의 입력에서 제거하고, P7-5.1 화풍 텍스트 계약만 prompt로 전달하도록 바꿨다. 이에 따라 배경 장소·카메라가 후보에 복사되지 않으며, 기존 배경 원본은 화풍 계약의 사람 검수 근거로만 유지한다.
- 화풍 조건 cast 후보 생성 스크립트를 `p7_5_1_generate_style_conditioned_cast_candidates.py`로 옮겨 P7-5.1의 화풍 계약·검수 흐름에 귀속했다.
- cast 프롬프트에서 얼굴·머리·의상 등 캐릭터 묘사와 추가 인물 금지 조건을 제거하고 성별·나이·인원수만 유지했다.
- 후보별 확산 반복 횟수를 기록하는 `--steps` 옵션을 추가했다. 기본값은 기존 P7-5.1 기준인 50이며, 낮은 값으로 만든 빠른 후보는 별도 검수 대상이다.
- cast 프롬프트와 화풍·구도 지시를 압축하고 인원수 조건을 생성·승인 기준에서 제거했다. 검수는 소실점과 구도, 화풍 텍스트 계약, 성별·나이 정보를 우선한다.
- 생성 프롬프트와 `--compositions` 옵션에서 저각·고각·시점 같은 카메라 표현을 제거하고, 공간 구성과 소실점 구조만 남겼다.
- 소실점·원근 표현도 생성 프롬프트와 `--compositions` 옵션에서 제거했다. 후보 검수는 장면 구성, 화풍 텍스트 계약, 성별·나이 정보만 확인한다.
- 무문자·무로고 제한을 화풍 계약에서 제거하고, 전 장면에 보이는 풍부한 자연색·수채화 색층·부드러운 색 번짐을 명시적으로 강화했다.
- 인물 후보의 화풍 설명을 배경 `COMMON_CONTRACT`와 같은 수채화·먹선·안료·광원·제외 기준으로 통일했다. 인물·장면 내용만 별도 조건으로 둔다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.08.06`.

### v2026.08.04

- 과거 후보·sidecar·중복 ledger 기록을 정리하고, 지속적으로 남길 사람 판정은 review ledger와 승인 manifest로 일원화했다. contact sheet는 만들지 않는다.
- 반복 생성에서도 공간 조건을 안정적으로 만족하지 못한 여객기 행은 폐기하고, 창밖의 밤과 작은 스탠드 조명을 가진 창가 독서실로 대체했다. 이 장면과 courtyard를 포함한 아홉 local-GPU 원본은 모두 사람 승인을 받았다.

- 원고의 승인 원본은 3×3 Markdown 표로, Python 원문은 lazy-load 코드 패널로 정리했다. 사이트 루트 기준 자산 경로와 `Diffusers Reduce memory usage` 근거도 보완했다.
