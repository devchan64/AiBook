# Section Release Note

- Section ID: `P7-5.5`
- Source File: `docs/parts/part-07/chapter-05/section-05.md`

### v2026.08.04

- 신규 Section 작성: FLUX.2 Klein 4B의 multi-reference editing을 P7-5 웹툰 생성 파이프라인의 보충학습으로 분리했다.
- 목적 명확화: 이 Section의 목적을 FLUX 다중참조 기능으로 여러 참조 이미지를 하나의 참조 묶음으로 구성하고 사용하는 방법을 설명하는 것으로 조정했다.
- 초심자 보강: 도입부에 prompt-only, single-reference, multi-reference의 차이와 웹툰 컷 기준 참조 역할 예시를 추가해 다중참조를 먼저 직관적으로 이해할 수 있게 했다.
- 본문 반영: text-to-image 중심 실습, 보조 조건 분리, FLUX.2의 통합 생성·편집 계열로 이어지는 역사적 흐름을 짧게 설명했다.
- 본문 반영: 대표 다중참조 모델 비교를 추가해 FLUX.2 Klein 4B를 중심 실험 모델로 두고, FLUX.2 상위 API 계열, Gemini Image, Seedream 4.0, IP-Adapter 계열의 역할 차이를 구분했다.
- 본문 반영: 다중참조를 참조 수 증가가 아니라 `style`, `character_identity`, `pose_structure`, `scene_context`, `local_detail` 역할을 분리해 검수하는 입력 설계 문제로 설명했다.
- 경계 설정: P7-5.1~P7-5.4의 승인 manifest와 gate를 우회하지 않으며, 8 GB VRAM에서는 참조 입력을 하나씩 추가하는 ablation으로 다룬다고 명시했다.
- 예제 반영: 실제 실행 없이도 실험 설계를 검수할 수 있도록 `style + character`, pose 추가, scene 추가의 세 단계 ablation 예제와 관찰 항목, 중단 신호를 추가했다.
- 연습 반영: 모델 실행 없이 참조 후보의 주 역할, 허용 범위, 금지 범위, 실패 신호를 손으로 채우는 참조 역할표 연습을 추가했다.
- 검수 반영: 말미에 참조 역할, 승인 범위, override 금지, 단계적 추가, 실패 추적을 확인하는 체크리스트를 추가했다.
- 개념사전 연결 검수: `다중참조`, `참조 묶음`, `manifest`, `FLUX.2 Klein 4B`는 특정 실험 표현이라 새 표제어로 만들지 않고, 본문 첫 등장 중심으로 `생성`, `모델`, `프롬프트`, `모델 출력` 기존 항목 링크를 보강했다.
- 근거자료 검수: BFL의 multi-reference editing guide를 추가해 여러 참조 이미지의 역할을 설명해야 한다는 본문 핵심 주장과 직접 연결했다. Seedream 4.0 설명은 공식 문서의 이미지 생성·편집 통합, 여러 reference image 입력, reference consistency 표현에 맞춰 좁혔다.
- 출처 반영: LoRA, ControlNet, IP-Adapter, FLUX.2 공개 저장소, FLUX.2 Klein 4B 모델 카드, BFL FLUX.2 image editing 문서, BFL multi-reference editing guide, Gemini image generation 문서, Seedream 4.0 문서, Hugging Face Diffusers Flux2 문서를 참고 자료로 연결했다.
- 번역 반영 상태: 한국어 원문만 반영됨.
