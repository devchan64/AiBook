### v2026.08.21

- 기반 모델 `Qwen/Qwen-Image-Edit-2509`과 다중 앵글 LoRA `dx8152/Qwen-Edit-2509-Multiple-angles`의 역할·근거를 원고에 추가했다. 공식 Qwen 모델 카드의 이미지 편집·인물 일관성 설명과 LoRA 모델 카드의 카메라 명령·일관성 한계를 각각 출처로 연결했다. 로컬 Nunchaku·Lightning 구성은 8GB GPU 실행 조건일 뿐 일반 성능 비교가 아니라는 경계도 명시했다.
- P7-5.2에 섞여 있던 Qwen 정면 얼굴 기준과 identity·화풍·일러스트 계약, 정면 얼굴 생성기, Qwen Edit 2509 다중 앵글 LoRA 생성기, yaw·pitch 얼굴 회전 후보를 P7-5.7로 분리했다. 정면 얼굴은 identity·헤어·화풍을, 다중 앵글 LoRA와 짧은 중국어 카메라 명령은 카메라 회전만 맡는 역할 분리를 명시했다.
- 승인 정면 얼굴 하나를 입력으로 쓴 `seed=62294`, `768×768`, 8-step 좌·우 측면(`yaw −90°/+90°`, `pitch 0°`)을 사람 승인해 안정 PNG·review JSON으로 등록했다. 각 승인은 해당 측면에만 한정하며, 다른 yaw·pitch·표정·전신·장면 조건을 승인하지 않는다.
- 우측 측면은 같은 조건의 v2 후보로 안정 기준을 교체했다. 이전 v1 PNG·review JSON은 현재 승인 체인에서 제거하고 Git 이력으로만 보존한다.
- 같은 입력 조건의 우측 쿼터(`yaw +45°`, `pitch 0°`) v3 8-step 결과도 사람 승인해 안정 PNG·review JSON으로 등록했다. 이 승인은 우측 쿼터 한 장에만 한정한다.
- 같은 입력 조건의 좌측 쿼터(`yaw −45°`, `pitch 0°`) v2 8-step 결과도 사람 승인해 안정 PNG·review JSON으로 등록했다. 이 승인은 좌측 쿼터 한 장에만 한정한다.
- 그림자·하이라이트 지시를 제거한 10-step 정면 얼굴 후보를 사람 승인해 정면 기준 PNG·review JSON으로 교체했다. 승인 범위의 렌더링 기준은 네 값 음영·강한 하이라이트가 아니라 어두운 윤곽선과 평면 색이다.
- 정수리 전체와 머리 위 빈 여백을 명시한 10-step `front-flat-color-crown-margin-v1` 후보를 사람 승인해 정면 기준을 다시 교체했다. 이 기준은 상단이 잘리지 않은 정면 얼굴에만 적용한다.
- P7-5.7 자산은 실행 조건과 사람 판정을 별도 run JSON·review JSON으로 나누지 않고 review JSON 하나로 관리하도록 정리했다. 승인 기준의 실행 원본은 `execution` 필드에 보존한다.
- 회전 후보와 정면 기준 T2I는 사람 승인 기준을 만든 2509 계열 경로만 유지한다. 정면 실행기는 `p7_5_7_qwen_edit_head_front_reference_t2i.py`, 회전 실행기는 `p7_5_7_qwen_camera_angle_2509_probe.py`로 관리한다.
