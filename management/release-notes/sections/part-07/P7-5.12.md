### v2026.09.16

- 입력·미적용·적용·목표 19쌍의 4열 비교표와 관리번호별 검수 의견을 본문에 통합했다. 기존 2쌍 샘플과 별도 비교표 파일을 대체하고 원본 이미지 링크를 유지했다.

- 이미지 생성 → 데이터셋 구성 → 학습 → 평가 생성 → 출력 검수의 순서로 본문을 재배치했다. 후속 목표 후보와 재개 학습은 평가 이후로 옮기고 제목·목차·학습 산출물 안내를 맞췄다.

- BFS Head V5의 얼굴·헤어 편집을 참고해 실습 콘셉트를 정했음을 도입부에 명시했다. Mira용 학습 목표·데이터셋·새 어댑터의 역할을 설명하고 화풍 표현을 Mira 목표 기준으로 맞췄다.

- 폐기한 5.11에서 LoRA 원리·편집 학습의 세 요소·분할·학습 설정·평가 개념을 통합했다. 필요한 후보·목표 이미지와 기록·목록·실행 코드를 sec-12로 이관하고 역사적 기록의 해시와 학습 상태 재사용을 보존했다.

- 참조 입력 후보·추가 목표 후보·193쌍 데이터셋 설명을 5.12로 통합하고 검수표 3개를 `sec-12/`로 이전했다. 5.11은 기존 40장 A/B 실험 흐름으로 정리하고 관련 링크를 갱신했다.

- 사용자 판단에 따라 실습 목표 달성을 본문 결론으로 통합했다. 미술관·회랑 2쌍을 4열 샘플로 제시하고 외형 변환 성과, 전처리 교훈, 보존 문제의 후속 개선 과제를 연결했다. 비교표·검수 기록의 판정 범위도 맞췄다.

- 참조 VAE 512 조건의 38장 생성·전체 시각 검수를 완료하고 4열 비교표와 검수 JSON을 연결했다. Mira 변환 관찰과 회랑 5쌍 배경 손실·표정 변화의 한계를 구분했다.

- 확대·잘림이 나타난 최초 평가 결과를 사용자 요청으로 폐기했다. 참조 VAE 크기를 학습과 같은 512로 맞추고 실제 전처리 크기 검사를 추가하여 별도 경로에서 재생성한다.

- 1600스텝 학습과 재개 상태 저장 완료를 반영하고, 검증 입력 19쌍의 실제 입력 기반 미적용·적용 평가를 시작했다. 생성 중 상태와 시각 품질 미판정을 구분했다.

- BFS 학습의 주기·종료 상태 저장과 별도 패키지 재개를 지원했다. 추가 스텝·누적 스텝을 구분하고 원래 데이터·설정 계승 및 상태 해시 검사를 반영했다.

- 확정 데이터셋 193쌍(학습 174·검증 19)의 고정 대응 학습 준비와 비교표를 연결했다. BFS 설정·준비 명령·실행 계획, 쌍별 캐시 충돌 방지와 미학습 상태를 안내했다. 번역 반영 상태: 대응 번역본 없음.
