### v2026.09.15

- 생성 후보 디렉터리를 `sec-11/input-images/`와 `sec-11/target-images/`로 구분했다. 원본 해시를 유지하면서 카탈로그·기록·원고·생성 재개 경로를 갱신했다. 기존 기준 목표는 대응 목록의 경로로 연결하며 중복 복사하지 않는다. 번역 반영 상태: 대응 번역본 없음.

- 이미지 본문을 샘플 중심으로 정리했다. 기존 학습 40장 표는 대표 8장으로 줄이고, 같은 목표와 입력 변형 3장을 4열로 제시했다. 전체 자료는 JSON 목록으로 추적하고 생성 후보·학습 채택·본문 샘플 수를 구분했다. 5.12에서는 5.11의 공용 생성 자산과 샘플을 연결한다. 번역 반영 상태: 대응 번역본 없음.

- 학습용 참조 입력 후보 220장과 생성 기록·카탈로그를 `sec-11/candidate-inputs-v2/`로 통합했다. 원본 이미지 해시를 보존하고 현재 경로와 기록 해시를 갱신했으며, 원고의 실행 경로·폴더 안내를 동기화했다. 공용 생성·선택 Python과 참조 입력 생성 조건 JSON도 5.11 자산으로 통합했다. 조건 파일은 `p7-5-11-bfs-input-*.json`으로 이름을 맞추고 원고·재실행 경로를 갱신했다. 후보의 학습 채택은 별도 검수로 결정한다. 번역 반영 상태: 대응 번역본 없음.

### v2026.09.14

- 입력 후보 220장과 후속 Mira 목표 후보 128장의 생성 계획을 분리하고, 공용 생성 코드에 GPU 대기·부분 실행·후보 카탈로그를 추가했다. 별도 검수 목록에서 채택한 결과만 데이터셋 JSON으로 내보내며 해시·중복·목표별 분할 누수를 검사한다. 계획 수와 실제 생성·채택 수를 구분했다. 번역 반영 상태: 대응 번역본 없음.

- BFS 얼굴·헤어·그림 전체 화풍 변환을 독립 절로 작성했다. 기존 Mira 목표에서 변환 전 입력을 생성하는 방향과 학습 방향을 구분하고, 40개 학습·4개 검증 후보의 생성·쌍 검수·패키지 준비 필요사항·실제 장면 평가를 연결했다. 생성 목록을 `sec-12/p7-5-12-bfs-input-generation-v1.json`으로 옮기고 목차·학습 체크포인트를 연결했다. 입력·목표 쌍마다 카메라·원근·프레이밍·인물 위치와 크기를 고정하도록 생성 지시와 검수 기준을 보강하고, 얼굴·헤어의 의도된 윤곽 변화와 구도 이탈을 구분했다. 생성·학습·평가는 미실행이다. 번역 반영 상태: 대응 번역본 없음.
