### v2026.08.01
- 변경 이유: P7-3.3 본문에서 표시하는 입력 표현 비교 PNG가 일부 환경에서 한글 글꼴을 찾지 못해 라벨이 깨지는 문제를 바로잡았다.
- 본문 반영: 공용 차트 자산의 Version 기준을 갱신했다. 차트 스크립트는 Noto Sans CJK 또는 Nanum 글꼴을 직접 등록하고, 글꼴이 없으면 생성 중단하도록 바꿨다. 평가 정확도 `0.75`는 제목의 공통 기준으로 분리하고, 차트는 오류 수·낮은 확신 수·샘플별 margin만 보여 주도록 축을 정리했다. 본문에는 표현별 입력 shape, 오류 수, 낮은 확신 수, 다음 판단을 비교하는 표와 학습 점검을 추가했다.
- 번역 동기화 메모: 영문 초안에도 정확도 공통 기준, 오류·낮은 확신 신호의 분리, 비교표와 추가 점검 문항을 영어 차트·해설로 반영했다. 다른 언어판은 별도 자산·용어 대조가 필요하다.
- 번역 반영 상태: 영문 초안 반영됨; 다른 언어판 및 후속 원문 변경 대조 필요.
- 관련 자산: `docs/assets/part-07/chapter-03/p7_3_input_representation_report.py`, `docs/assets/part-07/chapter-03/p7-3-input-representation-report-ko.png`, `docs/assets/part-07/chapter-03/p7_3_input_representation_report_en.py`, `docs/assets/part-07/chapter-03/p7-3-input-representation-report-en.png`
