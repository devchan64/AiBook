### v2026.09.05

- P7-5.2의 정면 identity·상반신 멀티뷰 설명을 반복하지 않도록 경계를 분명히 하고, P7-5.3 고유의 단계별 입력 역할·편집 모델·LoRA·OpenPose renderer·메모리 배치 역할을 다시 정리했다.
- 1·2단계 착장, 관계 맵, 15방향 회전, 앨리웁 생성기의 실제 옵션·입력 순서·조작값·각 `result.json` 기록 항목을 원고의 각 코드 링크 바로 뒤에 보강했다.
- 이전 2509 4방향 yaw 실험 표와 실행 기록을 `Qwen/Qwen-Image-Edit-2511`, Multiple-Angles LoRA, Lightning 4-step으로 생성한 960×1440 15방향 결과로 대체했다. 저각·아이레벨·엘리베이티드와 yaw −90°·−45°·0°·+45°·+90°의 각 결과 PNG를 원고에 배치하고, 개별 `result.json` 15개를 lazy-source 링크로 연결했다.
- 회전 생성기의 기본 실행 조건을 960×1440, 순차 CPU offload, 4-step Lightning으로 본문 설명과 맞췄다. 단일 입력은 2단계 정면 착장이고, OpenPose와 별도 얼굴 참조는 회전 단계에서 사용하지 않는다.
- 앨리웁 생성기를 2509 Nunchaku FP4 경로에서 `Qwen/Qwen-Image-Edit-2511` 공식 BF16 `DiffusionPipeline`과 순차 CPU offload 경로로 전환했다. 원고에서 2509·Nunchaku를 현재 앨리웁 실행 조건으로 설명하거나 연결한 이전 산출물은 분리했다.
- 새 2511 앨리웁 결과(1024×1536, 20-step)와 개별 `result.json`을 동적 장면 문단에 반영했다.
- 1단계 기준 이미지를 새 OpenPose 맵을 사용한 10-step v9 결과로 교체했다. 기존 압축 prompt에는 양팔·양손이 보인다는 긍정 지시만 추가해, 팔과 손을 끝까지 생성한 결과를 원고에 반영했다.
- 착장 생성기의 공통 fallback과 1·2단계 기본 추론 스텝을 10으로 낮췄다.
- 2단계 생성기의 첫 입력을 원고 반영 1단계 v9으로 교체하고, 새 10-step 자켓 결과를 2단계 기준 이미지와 실행 기록으로 반영했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.05`.

### v2026.09.04

- 1·2단계 복장 생성기의 머리 참조를 이전 Q4 Comfy 출력에서 P7-5.2 BF16 정면 Mira 머리 결과(1280×1280)로 교체하고, 입력 역할의 해상도 표기를 함께 정정했다.
- 원고의 1·2단계 입력 설명도 같은 정면 머리 결과와 1280×1280 기준으로 맞췄다.
- 1·2단계 생성기를 Nunchaku FP4 transformer 대신 공식 Qwen-Image-Edit-2511 BF16 pipeline과 순차 CPU offload 경로로 전환하고, 원고의 런타임 설명을 갱신했다.
- 1단계는 OpenPose를 첫 입력, P7-5.2 정면 Mira 머리를 두 번째 입력으로 둔 채, 회색 마이크로 크롭티·딥틸 와이드 팬츠·흰 로우탑 스니커즈만 한 문장으로 지시하는 압축 착장 프롬프트로 정리했다.
- 전신 BODY_18 OpenPose 맵을 960×1440으로 다시 렌더링하고, 전체 키를 10% 축소했다. 좌표는 유지한 채 선 반폭과 관절 반지름도 각각 7px로 키워 전신 생성 입력에서 읽기 쉽게 했다.
- 같은 OpenPose 비례 템플릿에서 다리 비중의 10%를 상체·허리 구간으로 옮겨, 전체 키와 목·얼굴 위치는 유지하면서 허리를 길게 하고 다리를 짧게 조정했다.
- 번역 반영 상태: 한국어 원문만 반영됨. 원문 기준 버전: `v2026.09.04`.
