### v2026.09.20

- 후속 정리: 사용자 요청에 따라 현재 multiref 결과만 보존하고 MoMask v4·전신 기준 등 나머지 결과 파일을 삭제했다. 과거 실험 결론을 본문 표로 통합하고 비교판·기준 영상 링크를 현재 결과 표본으로 교체했다. 재사용 입력·모델 근거는 multiref 폴더로 이관했다. 아래 비교판·두 영상 연결 설명은 정리 전 이력이다.

- 변경 이유: 완료한 SCAIL-2 전신·근접 참조 실험을 원고에 보존한다.
- 본문 반영: 전신 참조 기준과 근접 크롭·동일 인물 마스크 추가 조건, 704p·33프레임·79.8분 실행 결과와 메모리 측정값, 동일 크기 표본 비교 및 두 결과 영상 링크를 추가했다. SeedVR2의 디테일 개선 없음·잔상·폐기 이력은 비교 배경으로 요약했다.
- 판정 범위: 표본의 이동·큰 외형 유지와 얼굴·손 디테일 부족을 구분했다. 원고 반영을 품질 개선 승인으로 해석하지 않으며 전체 영상의 시간축 품질은 확정하지 않았다.
- 관련 자산: `sec-15/2026-09-20-scail2-multiref-v1/`, 전신 기준 `2026-09-20-scail2-native-ref-v1/`, 폐기 요약 `2026-09-20-seedvr2-v1/README.md`.
- 원문 기준 버전: `v2026.09.20`.
- 번역 동기화 메모 및 반영 상태: 이 Section의 영어·중국어 본문은 없으며 추후 번역 시 이번 조건·판정 범위를 함께 반영한다.

### v2026.09.19

- 사용자 지시로 StableAnimator v4 정면·측면 실험을 캐릭터 외형·팔다리 구조 유지 실패로 확정하고 전체 자산을 삭제했다. 원고의 활성 결과 링크와 모델 인벤토리의 실행 소스 참조를 제거하고 폐기 기록을 갱신했다. MoMask v4·공용 참조 원본·모델 가중치는 유지한다. 깊이 부족은 원인 후보로 구분한다. 아래 StableAnimator 실행·보관 기록은 폐기 전 이력이다.

- 사용자 관찰에 따라 팔 뒤바뀜·뭉개짐을 외형 변화와 별도의 구조 연속성 실패로 기록했다. 10~21번 팔 영역 연속 대조와 검수 JSON을 추가하고 정확한 좌우 전환·원인 미확정 범위를 명시했다.

- StableAnimator v4 정면/측면 정렬 참조 두 조건을 각 32프레임으로 실행했다. 유효한 얼굴 임베딩과 가로 이동을 확인했지만 후반 머리·소매 변화가 남아 전체 캐릭터 유지 실패로 기록했다. 측면의 초반 부분 개선과 일반화 한계를 구분했다.

- 사용자 지시로 StableAnimator v3를 폐기하고 새 v4에서 참조의 시작 위치·크기를 정렬했다. 기존 정면/오른쪽 측면 자산과 동일 전진 포즈를 사용하며 실제 입력의 얼굴 검출·임베딩을 사전 확인했다.

- StableAnimator v3 가로지르기 32프레임을 실행했다. 초기 메모리 부족과 할당 설정 변경 후 완료를 구분하고, 수평 이동 전달·전신 유지와 재킷/머리 변화·초기 잔상에 따른 캐릭터 유지 실패를 기록했다. 영상·입력 대조·전체 프레임·실행/검수 JSON을 새 폴더에 보관한다.

- 사용자 지시로 StableAnimator v2 준비 자료 74개를 폐기했다. 새 v3는 MoMask v4 전진 구간 28~59번과 고정 측면 카메라를 사용하며 원 모션의 수평 이동을 보존한다.

- MoMask v4 새 프롬프트 2개·3시드의 6개 모션을 실행했다. 공통 화면 범위, 독립 루트 적분 검사, 높이·전진량·근접 발 속도 분석을 추가했다. 짧은 전진 지시의 2.55~3.02m 이동과 시작/종료 정지, 상세 지시의 제자리 동작을 구분해 기록했다. 과거 폐기는 유지한다.

- 사용자 지시로 MoMask v3 및 기존 MoMask·StableAnimator 두 실험 묶음을 실패로 폐기하고 전체 자산을 삭제했다. 원고는 폐기 이력으로 정리하고 인벤토리의 활성 소스 경로를 제거했다. 후속 구도 비교는 원 입력 삭제로 실행 불가 처리했다. 아래 항목은 폐기 전 이력이다.

- v3 제자리 걷기와 좁은 앞뒤 화면 공간에 관한 사용자 관찰을 기록했다. 모델 입력의 공간 제약과 클립별 관절 범위로 정하는 출력 화면 폭을 구분했다.

- MoMask v3 걷기 3개를 실행했다. v2의 96프레임·시드·가중치를 유지하고 프롬프트만 바꿔 부유·하강 개선과 전진 이동 부족을 분리해 기록했다. 전체 288프레임·영상·원 관절·실행/비교/검수 JSON을 단일 v3 자산 폴더에 보관했다.

- 사용자가 연속 포즈 영상에서 의심했던 발 교대 문제가 관측되지 않는다고 확인했다. 해당 우려에 따른 추론 보류를 해제하고 준비 상태를 갱신했다. 캐릭터 유지 실패와 v2 걷기 실패는 별도 판정으로 유지한다.

- v2 걷기도 지면 위에서 내려온다는 사용자 관찰을 원 관절 수치로 재확인했다. 세 시드의 초기 발 높이 약 14.6~15.4cm와 후반 하강을 기록하고 지면 보행 실패·기준 동작 제외로 판정했다. 산출물은 보존한다.

- 사용자 지시에 따라 MoMask v1 및 이를 입력으로 만든 StableAnimator 걷기 산출물을 폐기했다. v2·파생 달리기와 후속 준비 자료는 보존하고 원고·자산 목록·실행 기본값을 갱신했다. 아래 최초 실행 기록은 당시 이력이다.

- 입력 포즈의 부자연스러운 발 교대에 관한 사용자 관찰을 추가했다. 연속 32프레임·발 궤적·검수 기록을 준비하고 원 모션 검수 전 영상 추론을 보류했다.

- 캐릭터 유지 실패에 관한 사용자 관찰을 반영해 동작 전달과 외형 유지 판정을 분리했다. 다음 실험의 중앙 추적 1배·2배 포즈 64개, 계획·해시·실행 코드를 별도 자산 폴더에 준비했으며 추론 전임을 명시했다.

- 사용자 평가를 반영해 로컬 연결 실행과 개선 지점 확보를 첫 실험의 의미로 정리했다. 이번 산출물을 `sec-15/2026-09-19-momask-stableanimator-v1/`로 모으고 원고·인벤토리·코드 경로 및 자산 목록을 정리했다. 실행 당시 JSON은 보존했다.

- StableAnimator로 참조 캐릭터의 걷기·달리기 각 32프레임을 생성했다. 걷기 부분 성공과 달리기 후반 신체 소실 실패, 선택 구간·fps·CPU 경로·실행 비용 및 전체 프레임 검수를 기록했다.

- MoMask 최초 로컬 GPU 실험 12개(걷기·달리기, 48/96프레임, 각 3시드)를 실행하고 원 관절·전체 프레임·영상·진단 JSON·비교표와 실행 소스를 연결했다. BVH/IK 미적용과 NumPy 호환 처리, 탐색 조건의 교란 요인과 부유를 공중 구간 성공으로 오인할 위험을 기록했다.
- 번역 동기화 메모: 한국어 원문만 반영. 최초 실행 결과와 연구 단계 설명의 동기화 필요. 원문 기준 버전: `v2026.09.19`.

### v2026.09.18

- 측면 걷기의 팔다리 교대와 달리기의 공중 구간에 관한 사용자 관찰을 기록하고, 원본·조건 미대조 상태를 명시했다.
- Kimodo·StableAnimator·FramePack·DART·HY-Motion의 공식 입력·출력·메모리 조건과 HumanScore·PhyMotion의 평가 관점을 출처와 함께 추가했다. 3D 모션과 캐릭터 영상의 단계별 비교를 제안하고 로컬 미실행 상태를 구분했다.
- 기존 MoMask 준비 코드와 48→12 추출 조건은 보존했다. 전체 프레임 검수·발 접촉·가림·공중 구간과 실행 기록 항목을 보강했다. 조사 원고 작성 시점에는 모델 다운로드·추론 및 자산 생성 없음. 이후 사용자 요청으로 MoMask·Kimodo·StableAnimator의 가중치 사전 다운로드를 진행하며 MoMask도 미실험 비교군임을 명시했다. 다운로드 상태는 모델 인벤토리와 로컬 기록에서 추적하고, 추론은 실행하지 않는다.
- 번역 동기화 메모: 한국어 원문만 반영. 대응 번역본에는 새 조사·검수 기준 동기화 필요. 원문 기준 버전: `v2026.09.18`.
