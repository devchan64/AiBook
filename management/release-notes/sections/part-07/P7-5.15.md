# Section Release Note

- Section ID: `P7-5.15`

### v2026.09.19

- 사용자가 연속 포즈 영상에서 의심했던 발 교대 문제가 관측되지 않는다고 확인했다. 해당 우려에 따른 추론 보류를 해제하고 준비 상태를 갱신했다. 캐릭터 유지 실패와 v2 걷기 실패는 별도 판정으로 유지한다.

- v2 걷기도 지면 위에서 내려온다는 사용자 관찰을 원 관절 수치로 재확인했다. 세 시드의 초기 발 높이 약 14.6~15.4cm와 후반 하강을 기록하고 지면 보행 실패·기준 동작 제외로 판정했다. 산출물은 보존한다.

- 사용자 지시에 따라 MoMask v1 및 이를 입력으로 만든 StableAnimator 걷기 산출물을 폐기했다. v2·파생 달리기와 후속 준비 자료는 보존하고 원고·자산 목록·실행 기본값을 갱신했다. 아래 최초 실행 기록은 당시 이력이다.

- 입력 포즈의 부자연스러운 발 교대에 관한 사용자 관찰을 추가했다. 연속 32프레임·발 궤적·검수 기록을 준비하고 원 모션 검수 전 영상 추론을 보류했다.

- 캐릭터 유지 실패에 관한 사용자 관찰을 반영해 동작 전달과 외형 유지 판정을 분리했다. 다음 실험의 중앙 추적 1배·2배 포즈 64개, 계획·해시·실행 코드를 별도 자산 폴더에 준비했으며 추론 전임을 명시했다.

- 사용자 평가를 반영해 로컬 연결 실행과 개선 지점 확보를 첫 실험의 의미로 정리했다. 이번 산출물을 `sec-15/2026-09-19-momask-stableanimator-v1/`로 모으고 원고·인벤토리·코드 경로 및 자산 목록을 정리했다. 실행 당시 JSON은 보존했다.

- StableAnimator로 참조 캐릭터의 걷기·달리기 각 32프레임을 생성했다. 걷기 부분 성공과 달리기 후반 신체 소실 실패, 선택 구간·fps·CPU 경로·실행 비용 및 전체 프레임 검수를 기록했다.

- MoMask 최초 로컬 GPU 실험 12개(걷기·달리기, 48/96프레임, 각 3시드)를 실행하고 원 관절·전체 프레임·영상·진단 JSON·비교표와 실행 소스를 연결했다. BVH/IK 미적용과 NumPy 호환 처리, 탐색 조건의 교란 요인과 부유를 공중 구간 성공으로 오인할 위험을 기록했다.
- 번역 동기화 메모: 한국어 원문만 반영. 최초 실행 결과와 연구 단계 설명의 동기화 필요. 원문 기준 버전: `v2026.09.19`.

### v2026.09.18

- 측면 걷기의 팔다리 교대와 달리기의 공중 구간에 관한 사용자 관찰을 기록하고, 원본·조건 미대조 상태를 명시했다.
- Kimodo·StableAnimator·FramePack·DART·HY-Motion의 공식 입력·출력·메모리 조건과 HumanScore·PhyMotion의 평가 관점을 출처와 함께 추가했다. 3D 모션과 캐릭터 영상의 단계별 비교를 제안하고 로컬 미실행 상태를 구분했다.
- 기존 MoMask 준비 코드와 48→12 추출 조건은 보존했다. 전체 프레임 검수·발 접촉·가림·공중 구간과 실행 기록 항목을 보강했다. 조사 원고 작성 시점에는 모델 다운로드·추론 및 자산 생성 없음. 이후 사용자 요청으로 MoMask·Kimodo·StableAnimator의 가중치 사전 다운로드를 진행하며 MoMask도 미실험 비교군임을 명시했다. 다운로드 상태는 모델 인벤토리와 로컬 기록에서 추적하고, 추론은 실행하지 않는다.
- 번역 동기화 메모: 한국어 원문만 반영. 대응 번역본에는 새 조사·검수 기준 동기화 필요. 원문 기준 버전: `v2026.09.18`.
