# Section Release Note

- Section ID: `P6-3.5`
- Source File: `docs/parts/part-06/chapter-03/section-05.md`

### v2026.07.18
- 본문 반영: 기존 `P6-3.4`에 함께 있던 sparse attention과 long-context 설명을 새 보충학습으로 분리해, `연결 수 조절`과 `장문맥 유지`를 한 질문 축 안에서 따로 읽게 정리했다.
- 추가 반영: 현재 절은 긴 로그 분석, 계약서 읽기, 길이 증가와 핵심 단서 유지 구분 사례를 통해 sparse attention과 long-context를 같은 최적화 이름이 아니라 다른 층위의 문제로 구분하도록 구성했다.
- 추가 반영: 같은 날짜 재수정에서 `모든 연결을 줄이는 문제`와 `긴 문맥에서 핵심 단서를 유지하는 문제`를 더 또렷하게 나누기 위해, 기본 self-attention 대비 sparse attention이 무엇을 줄이려는지, long-context가 왜 단순 길이 숫자보다 넓은 설계 문제인지, 둘이 막으려는 실패 장면이 무엇인지 초심자 기준 문장과 비교표로 보강했다.
- 추가 반영: 같은 날짜 후속 재검토에서 `긴 입력 문제` 안에 `비교 수 증가`, `핵심 단서 유지`, `context window 숫자 증가`가 다시 뭉개지지 않도록, 실제 실패 장면을 `먼저 던질 질문 -> 더 직접 연결되는 것`으로 가르는 `바로 적용해 보면` 표를 추가했다.
- 추가 반영: 제목 아래 `Section ID`, `Version` 표기를 저장소 규칙 형식으로 바로잡았다.
- 번역 동기화 메모: 대응 번역본이 생기면 새 Section 추가와 함께 sparse attention/long-context 분리 구조를 같이 반영해야 한다.
