## v2026.07.22

- 변경 이유: Part 6 본문에서 진행 메타형 소제목을 구체 개념, 비교 대상, 판단 기준이 드러나는 제목으로 정리하기 위함.
- 본문 반영: `여기서 남겨야 할 구분`, `여기까지를 한 줄로 묶으면`, `보는 순서`, `이 예제를 ... 다시 보면` 계열 제목을 현재 절의 실제 구분 축과 설명 흐름이 보이는 소제목으로 바꾸었다.

- 토큰 문자열과 token ID를 뜻풀이로 과잉 해석하지 않고 모델 입력 층위로 읽는 해설을 보강했다.

- 번역 반영 상태: 한국어 원문만 수정했다.
- 원문 기준 버전: `v2026.07.22`

## v2026.07.21

- Part 6 개편 기준에 따라 Section ID, 파일 위치, 제목을 새 목차 구조에 맞춰 재정렬했다.
- 생성형 AI 산출물에서 시작해 LLM을 대표 사례로 읽는 흐름 안에서 이 Section의 위치를 다시 잡았다.
- 집필 메타 문장과 중간 출처 블록을 정리해 토큰 정의에서 token ID 순서열 설명으로 이어지는 원고 흐름을 개선했다.
- 중복되어 보이던 토큰 정의 소제목을 계산 조각과 세는 대상의 구분으로 나누고, 적용 구간 제목을 층위 구분 연습으로 바꾸었다.
- 후반 적용 구간 제목을 토큰 순서열 판독 중심으로 바꿔 입력과 출력이 같은 순서 위에서 이어진다는 핵심을 드러냈다.
- 개편 전 릴리즈노트 원문은 `management/authoring/archive/part-06-before-restructure-2026-07-21/management/release-notes/sections/part-06/`에 보존했다.
- 중간의 첫 `연습 및 예제` 블록을 tokenizer 출력값 판독 예시로 바꾸고, token ID 순서열 설명으로 이어지는 연결 문장을 정리해 섹션이 중간에서 닫힌 것처럼 보이지 않게 했다.
- 중심축을 tokenizer 출력값 판독과 token ID 순서열 입력으로 재배치하고, 단어·symbol 비교를 보조 오해 정리로 축소했다.
- P6-2.2 전용 Mermaid 도식을 추가해 원문 문자열, 토큰 문자열, 토큰 수, token ID 순서열, 임베딩 벡터의 관계를 한 흐름으로 보이게 했다.
- 반복되던 오해 정리와 사례 소제목을 정리하고, 체크리스트를 tokenizer 출력값 판독과 ID 순서열 입력 기준으로 맞췄다.
