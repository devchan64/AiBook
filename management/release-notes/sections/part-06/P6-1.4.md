# Section Release Note

- Section ID: `P6-1.4`
- Source File: `docs/parts/part-06/chapter-01/section-04.md`

### v2026.07.19
- 연습 학습밀도 보강: 기존 개념 확인형 연습을 설명용 tokenizer 출력표 기반의 `경계 차이`, `토큰 문자열-ID 대응`, `ID 순서 완성`, `잘못된 해석 고치기` 연습으로 교체했다.
- 사례 중심축 보강: 사례 표를 `오해 비교` 중심에서 `경계 선택 -> vocabulary 연결 -> ID 변환` 절차 추적 중심으로 바꿔, 각 사례가 중심 질문을 직접 지지하도록 정리했다.
- 학습밀도 보강: 토큰화 판독 기준을 `어디서 끊겼는가`, `어떤 vocabulary 조각으로 인정됐는가`, `어떤 ID가 붙었는가`의 세 질문으로 세분화했다.
- 예시 보강: `환불정책`, `10시에`, `Authorization`의 설명용 토큰 문자열·ID 표를 추가해 `원문 -> 토큰 문자열 -> 토큰 ID` 변환을 더 직접 확인하게 했다.
- 중심축 정리: 중심 질문을 `원문 문자열은 어떤 절차로 토큰 시퀀스와 토큰 ID가 되는가`로 고정하고, 비용·청크·출력 길이 예고를 다음 절로 넘겼다.
- 사례 보완: `환불정책`, `10시에`, `환불정책을 요약해 줘` 사례를 `사람이 보는 기준 -> tokenizer 경계 -> 확인할 결과` 흐름으로 다시 정리했다.
- 연습 보강: 질문형 연습을 세 문항으로 나누고 각 문항 바로 뒤에 해설을 붙여, 사람이 보는 단위와 tokenizer가 확인하는 경계를 직접 대조하게 했다.

### v2026.07.18
- 본문 반영: 사례 뒤에 `바로 적용해 보면` 표를 추가해, 사람이 보는 단위와 모델이 계산에 넘기는 단위를 나란히 비교하며 토큰화의 자리를 직접 확인하게 했다.
- 추가 반영: 마지막 닫힘 문장을 보강해, 이 절에서는 `문자열을 어떻게 계산 입력으로 넘기는가`까지만 붙잡으면 된다는 범위 감각을 더 분명히 했다.
- 구조 보강: `연습 및 예제` 절을 추가해, 사람이 보는 단위와 토큰화가 확인해야 하는 단위를 직접 나눠 적게 했다.
- 번역 동기화 메모: 대응 번역본이 생기면 적용 표와 마지막 범위 닫힘 문장도 함께 반영해야 한다.

### v2026.07.13
- 본문 반영: 해당 소제목을 `지금 절에서 먼저 붙잡을 기준`으로 바꾸고, 토큰화의 역할을 좁혀 잡는 문장으로 도입을 다시 정리했다.
- 번역 동기화 메모: 대응 번역본이 생기면 범위 안내보다 현재 절의 핵심 기준을 앞세우는 흐름을 유지한다.

### v2026.07.12
- 본문 반영: `P6-1.4`를 `토큰화(tokenization)는 무엇인가` 절로 재작성했다. 문자열이 토큰 시퀀스로 바뀌는 절차, vocabulary와 분절 규칙의 자리, `문자열 -> 계산 입력`으로 넘어가는 첫 관문이라는 역할만 남기도록 범위를 줄였다.
- 추가 반영: 정의 절이 지나치게 얇아진 문제를 보완하기 위해, 문자열 -> 조각 -> vocabulary -> ID 변환의 단계 표와 짧은 사례, 다음 절로 이어지는 정리 표를 다시 덧붙였다.
- 번역 동기화 메모: 대응 번역본이 생기면 `P6-1.4`는 영향 설명보다 앞에 오는 토큰화 정의 절로 유지해야 한다.
