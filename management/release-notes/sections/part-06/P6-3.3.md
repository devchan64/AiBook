- 추가 반영: KV cache, sparse attention, long-context는 새 `P6-3.4`로 분리하고, 현재 절은 `관계 읽기`와 `순서 정보 공급`을 구분하는 데 집중하도록 사례와 연습 구조를 다시 썼다.; 같은 날짜 재수정에서 `P6-3.4`도 다시 둘로 나누면서, 현재 절의 후속 연결도 `P6-3.4 KV cache`, `P6-3.5 sparse attention/long-context`로 더 세밀하게 조정했다.; 초심자가 두 이름을 모두 `Transformer 내부 부품 이름`으로만 외우며 다시 압축적으로 읽는 문제를 줄이기 위해, `지금 막힌 장면 -> 먼저 던질 질문 -> 더 직접 연결되는 것`으로 가르는 `바로 적용해 보면` 표를 보강했다.
- 정리 반영: `둘 다 중요하다`에서 설명이 다시 뭉개지지 않도록, `multi-head attention` 또는 `위치 표현` 감각이 약할 때 각각 어떤 빈칸과 오해가 남는지 비교하는 표를 덧붙였다.; 제목 아래 `Section ID`, `Version` 표기를 저장소 규칙 형식으로 바로잡았다.; `초심자 기준에서는` 같은 독자 표지를 줄이고, `관계 읽기`와 `순서 읽기`를 어떻게 가를지 바로 드러나는 문장으로 도입 구분을 다듬었다.
- 사례 보강: 적용 표보다 사례가 먼저 나오도록 순서를 조정하고, 여러 관계가 겹치는 문장, 단어는 같지만 순서가 달라지는 문장, head와 위치 표현을 섞어 읽는 오해가 각각 `관계 읽기`와 `순서 정보 공급` 구분을 직접 지지하도록 사례 문단을 보강했다.
- 번역 동기화 메모: 대응 번역본이 생기면 기존 단일 보충학습을 두 개의 보충학습으로 나눈 구조와 현재 절의 새 범위 축을 함께 반영해야 한다.
