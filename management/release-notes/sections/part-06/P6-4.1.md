### v2026.07.18
- 추가 반영: `커리큘럼 관점에서 이 절은 다음 절의 ... 구조 설명입니다` 같은 안내 문장을 더 직접적인 연결 설명으로 낮춰, GPT를 생성 구조로 읽는 역할이 집필 안내보다 먼저 보이게 정리했다.
- 추가 반영: `## 이 절의 범위`, `## 이 절의 목표`, `## 이 절을 읽는 순서` 같은 메타 제목을 `순차 생성 구조가 다루는 질문`, `여기서 남겨야 할 구분`, `생성 구조 비교를 보는 순서`로 바꿔, 제품 안내보다 GPT의 decoder 기반 생성 구조가 먼저 보이게 정리했다.
- 본문 반영: 사례 요약 뒤에 `바로 적용해 보면` 표를 추가해, 초심자가 `첫 표현이 뒤 문장을 민다`, `자동완성은 되는데 형식 준수는 약하다`, `초반 코드 토큰 오류가 뒤 구조를 흔든다` 같은 장면을 볼 때 무엇을 `GPT의 누적 생성 구조`로 먼저 읽어야 하는지 바로 점검하게 했다.
- 추가 반영: 예제 뒤에도 `첫 표현이 왜 뒤 문장 전체를 미는가`, `왜 자동완성은 되는데 챗봇 형식은 약한가`, `왜 BERT와 GPT를 같은 Transformer라고만 묶으면 부족한가`를 다시 묻는 정리 표를 덧붙여, 이 절의 닫힘을 `순차 생성 구조`와 `다음 절의 조정층` 구분 쪽에 더 강하게 고정했다.
- 추가 반영: 도입부의 `이 절은 ...`, `구조적 위치 축` 같은 메타 문장을 줄이고, GPT를 `순차 생성 구조`로 읽는 현재 절 핵심이 먼저 보이도록 정리했다.
- 추가 반영: 사례와 예제 사이에 `지금 먼저 보이는 신호 -> 먼저 의심할 층위 -> 바로 다음에 붙여 볼 질문` 표를 덧붙여, 초심자가 `누적 생성 구조`와 `다음 절의 조정층`을 더 짧게 가르도록 보강했다.
- 추가 반영: 제목 아래 `Section ID`, `Version` 표기를 저장소 규칙 형식으로 바로잡았다.
- 추가 반영: `초심자가 여기서 자주 섞는 것` 같은 독자 해설 표지를 낮추고, 누적 생성 구조와 대화형 조정층을 구분하는 본문 문장이 직접 남도록 다듬었다.
- 추가 반영: 사례 본문과 비교표에 남아 있던 `초심자가 ...` 독자 표지를 `여기서 바로잡아야 할 오해`, `먼저 떠올리기 쉬운 오해` 중심 표현으로 낮춰, GPT 생성 구조 설명이 메타 독자 안내보다 누적 생성 판단 기준에 더 직접 붙게 다듬었다.
- 번역 동기화 메모: 대응 번역본이 생기면 적용 표와 예제 뒤 정리 표도 함께 반영해야 한다.
