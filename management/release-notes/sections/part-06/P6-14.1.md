### v2026.07.12

- 번역 동기화 메모: 대응 번역본이 생기면 같은 메타 표지 제거와 단일 checklist 구조를 함께 반영해야 한다.

### v2026.07.17
- 본문 반영: `이 절의 범위`에서 프로토콜 포맷, SDK 비교, 인증 체계 전체 설계 같은 생략 목록을 걷어내고, 이번 절이 `도구와 자원을 어떤 공통 형식으로 연결할 것인가`를 닫는 자리라는 점이 먼저 보이도록 다시 정리했다.

- 번역 동기화 메모: Future translations should preserve the scope handoff where P6-14.1 closes the connection-interface role first and hands execution management to P6-14.2.

### v2026.07.18
- 본문 반영: `이 절이 맡는 역할` 같은 설명 밖 문장을 줄이고, 모델 능력과 연결 인터페이스를 왜 분리해 읽어야 하는지가 본문 문장 자체로 보이게 다듬었다.; `Part 6에서 ... 첫 상세 설명은 이 절에서 잡습니다` 같은 위치 설명형 메타 문장을 걷고, MCP를 `도구와 자원을 덜 제각각으로 연결하는 공통 인터페이스 관점`으로 바로 읽게 도입부를 더 직접적으로 정리했다.; `커리큘럼 관점에서 ...`, `이 절에서 먼저 가를 장면 ...` 같은 진행 표지를 더 직접적인 역할·판단 문장으로 낮춰, MCP를 읽는 흐름이 메타 안내보다 연결 문제 장면 중심으로 보이게 정리했다.; `## 이 절의 범위`, `## 이 절의 목표` 같은 메타 제목을 `공통 연결 형식이 다루는 질문`, `여기서 남겨야 할 구분`으로 바꿔, MCP의 위치 설명보다 연결 형식 판단이 먼저 보이게 정리했다.; `초심자 기준에서는`과 `초심자가 이 절에서`처럼 독자층을 다시 표지하던 문장을 줄이고, MCP를 어떤 문제 장면에서 떠올려야 하는지가 바로 보이도록 설명 문장을 더 직접적으로 다듬었다.
- 추가 반영: 제목 아래 `Section ID`, `Version` 표기를 저장소 공통 형식에 맞춰 blockquote 대신 일반 메타데이터 줄로 정리했다.; MCP 장이 `무엇이 부족해서 왜 공통 연결 형식이 필요한가`를 먼저 보여 주도록, `지금 부족한 것 -> 이번 장이 붙이는 구조 -> 아직 남는 문제 -> 바로 이어지는 위치` 비교 블록을 추가했다.; `이 절은 다음 질문에 답합니다` 문장을 `이 절에서 먼저 붙잡을 질문`으로 바꿔, 연결 인터페이스 설명의 도입 톤을 더 자연스럽게 낮췄다.; `이 절은 Part 6에서 ...`와 `이 절에서는 ...로 설명합니다` 같은 메타 서술을 더 직접적인 설명 문장으로 바꿔, MCP의 연결 역할이 바로 읽히게 정리했다.; `지금 읽는 층위는`으로 절의 역할을 다시 말하던 문장을 줄이고, 반복 루프에서 공통 연결 형식으로 넘어가는 질문이 바로 보이도록 앞부분을 더 직접적으로 정리했다.
- 정리 반영: `이 절을 읽는 순서` 안내를 걷고, `입력 형식 혼선`, `응답 형식 불일치`, `도구 설명 분산`, `권한 경계 혼선`을 먼저 가르는 장면별 분기 표로 바꿔 초심자 첫 질문이 공통 연결 형식 판단으로 바로 이어지게 정리했다.; 세 사례 요약 뒤에 `바로 적용해 보면` 블록을 추가해, 초심자가 모델 성능 문제와 연결 형식 문제를 분리하고 `도구 설명`, `자원 접근`, `요청 형식`의 공통 규칙을 먼저 점검하도록 보강했다.; 같은 날짜 재검토에서 `공통 연결 형식`이 여전히 추상적으로 읽히는 압축을 줄이기 위해, 검색 도구·파일 읽기 도구·일정 조회 도구를 한 목표 흐름에 함께 붙일 때 어디서 먼저 흔들리는지 보여 주는 짧은 실패 장면과 비교표를 초반에 덧붙였다.; 같은 날짜 후속 재검토에서 본문이 세운 `요청/응답 형식` 축 가운데 `응답 형식`이 직접 적용 질문에서는 약하게 보인다는 점을 보완하려고, `호출은 됐지만 반환값 모양 때문에 다음 단계가 멈추는 장면`을 먼저 묻게 하는 행과 실무 질문을 추가했다.; `초심자가 가장 자주 놓치는 것은`처럼 독자 표지를 다시 세우는 문장을 `자주 생기는 오해` 중심 설명으로 낮춰, `바로 적용해 보면` 블록도 메타 진행보다 연결 문제 해석이 먼저 읽히게 다듬었다.
- 번역 동기화 메모: Future translations should preserve the new comparison block that separates interface normalization from later harness and operations concerns.
