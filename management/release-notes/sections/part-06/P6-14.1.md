## v2026.07.21

- Part 6 개편 기준에 따라 Section ID, 파일 위치, 제목을 새 목차 구조에 맞춰 재정렬했다.
- 생성형 AI 산출물에서 시작해 LLM을 대표 사례로 읽는 흐름 안에서 이 Section의 위치를 다시 잡았다.
- agent를 더 똑똑한 챗봇이나 도구를 많이 쓰는 시스템이 아니라, 중간 관찰과 다음 행동 선택을 포함하는 목표 흐름 구조로 읽도록 도입부와 판단 표를 정리했다.
- function calling, agent 목표 흐름, MCP/harness 관리의 층위를 분리해 단일 호출 구조와 여러 단계 상태 관리가 섞이지 않게 문장을 다듬었다.
- 도입부의 반복 표와 진행형 소제목을 줄이고, 단일 호출에서 목표 흐름으로 관점이 바뀌는 지점을 본문 문단 안에서 바로 설명하도록 정리했다.
- 업무 자동화 에이전트 사례를 요청 장면, 중간 관찰, 확인 결과로 나누어 판단 순서를 더 분명하게 만들었다.
- P6-14 전용 agent 도식과 상태 진행 그래프 참조로 바꿔, P6-13 function calling 자산과 agent 자산의 경계를 분리했다.
- 개편 전 릴리즈노트 원문은 `management/authoring/archive/part-06-before-restructure-2026-07-21/management/release-notes/sections/part-06/`에 보존했다.
- 제목을 `에이전트는 언제 다음 행동을 다시 고르는 목표 흐름이 되는가`로 바꾸고, 도입부와 사례 요약의 반복 표를 문단으로 압축해 agent를 도구 개수가 아니라 중간 관찰에 따른 다음 행동 선택으로 읽게 정리했다.
- 도입부의 범위 설명 반복을 줄여, 중심축을 `중간 결과를 보고 다음 행동이 바뀌는 목표 흐름`으로 고정했다.
