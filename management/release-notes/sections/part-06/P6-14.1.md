### v2026.07.12
- 본문 반영: 집필 순서만 예고하는 `다음 ... 연결` 계열 표지를 제거했다; `이 절에서 기억할 관점`, `짧은 점검`, `언제 ... 먼저 떠올려야 하는가`를 `체크리스트` 하나 아래로 통합했다. 본문 메타데이터 버전도 함께 갱신했다.
- 추가 반영: 한국어 본문이 참조하는 Mermaid 도식의 내부 라벨을 한글화하고, 대응 영문 원본(`-en.mmd`)은 별도 유지하도록 정리했다.
- 번역 동기화 메모: 대응 번역본이 생기면 같은 메타 표지 제거와 단일 checklist 구조를 함께 반영해야 한다.

### v2026.07.17
- 본문 반영: `이 절의 범위`에서 프로토콜 포맷, SDK 비교, 인증 체계 전체 설계 같은 생략 목록을 걷어내고, 이번 절이 `도구와 자원을 어떤 공통 형식으로 연결할 것인가`를 닫는 자리라는 점이 먼저 보이도록 다시 정리했다.
- 추가 반영: 실행 관리 handoff는 `P6-14.2`, 인증·권한이 실패 대응과 만나는 운영 handoff는 `P6-16.2`로 이어지게 분명히 했다.
- 번역 동기화 메모: Future translations should preserve the scope handoff where P6-14.1 closes the connection-interface role first and hands execution management to P6-14.2.

### v2026.07.18
- 본문 반영: MCP 장이 `무엇이 부족해서 왜 공통 연결 형식이 필요한가`를 먼저 보여 주도록, `지금 부족한 것 -> 이번 장이 붙이는 구조 -> 아직 남는 문제 -> 바로 이어지는 위치` 비교 블록을 추가했다.
- 본문 반영: `이 절은 다음 질문에 답합니다` 문장을 `이 절에서 먼저 붙잡을 질문`으로 바꿔, 연결 인터페이스 설명의 도입 톤을 더 자연스럽게 낮췄다.
- 추가 반영: `이 절은 Part 6에서 ...`와 `이 절에서는 ...로 설명합니다` 같은 메타 서술을 더 직접적인 설명 문장으로 바꿔, MCP의 연결 역할이 바로 읽히게 정리했다.
- 추가 반영: `지금 읽는 층위는`으로 절의 역할을 다시 말하던 문장을 줄이고, 반복 루프에서 공통 연결 형식으로 넘어가는 질문이 바로 보이도록 앞부분을 더 직접적으로 정리했다.
- 추가 반영: 세 사례 요약 뒤에 `바로 적용해 보면` 블록을 추가해, 초심자가 모델 성능 문제와 연결 형식 문제를 분리하고 `도구 설명`, `자원 접근`, `요청 형식`의 공통 규칙을 먼저 점검하도록 보강했다.
- 번역 동기화 메모: Future translations should preserve the new comparison block that separates interface normalization from later harness and operations concerns.
