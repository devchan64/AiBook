### v2026.07.12

- 변경 이유: 메타형 연결 예고 표지가 현재 절 이해보다 집필 순서를 먼저 드러내고 있었음; 말미의 회상·점검·적용 시점 표지가 여러 갈래로 나뉘어 `체크리스트`와 역할이 겹치고 있었음.
- 본문 반영: 집필 순서만 예고하는 `다음 ... 연결` 계열 표지를 제거했다; `이 절에서 기억할 관점`, `짧은 점검`, `언제 ... 먼저 떠올려야 하는가`를 `체크리스트` 하나 아래로 통합했다. 본문 메타데이터 버전도 함께 갱신했다.
- 추가 반영: 한국어 본문이 참조하는 Mermaid 도식의 내부 라벨을 한글화하고, 대응 영문 원본(`-en.mmd`)은 별도 유지하도록 정리했다.
- 추가 반영: MCP 설명부의 `장난감 구조` 표현을 `축약된 연결 구조`로 바꿔 연결 계층 예제 톤을 정리했다.
- 번역 동기화 메모: 대응 번역본이 생기면 같은 메타 표지 제거와 단일 checklist 구조를 함께 반영해야 한다.
- 번역 반영 상태: 향후 번역 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.12`

### v2026.07.09

- 변경 이유: 문단구조 검토 리포트 기준으로 MCP 절의 후반 전환부를 압축하고 종결 표지를 일관된 순서로 맞추기 위해.
- 본문 반영: `커리큘럼 관점` 문단을 목표 뒤로 옮기고, `언제 MCP 관점을 먼저 떠올려야 하는가`를 종결부 단일 표지로 정리했으며, 마무리 구조 표지를 원칙 기준에 맞춰 통일함.
- 번역 동기화 메모: 대응 번역본 없음. 향후 번역 시 반영 필요.
- 번역 반영 상태: 향후 번역 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.09`

### v2026.07.11

- 변경 이유: 외부 커리큘럼 기준으로 MCP가 `연결 층`이라는 점을 더 또렷하게 읽게 만들고, 하네스/평가/운영과의 경계를 한 번 더 고정할 필요가 있었음.
- 본문 반영: MCP가 직접 정리하는 것과 아직 하네스나 운영으로 넘겨야 하는 것을 나누는 비교표를 추가했고, 종결 표지를 `체크리스트`로 통일함. 이어서 독자용 표 설명에 남아 있던 `run record` 표현은 `요청 실행 기록`으로 일반화해 공용 서술 톤을 맞춤. 추가로 인라인 Mermaid 도식을 외부 `.mmd` 자산으로 분리하고, 본문은 snippet include로 참조하도록 정리함.
- 번역 동기화 메모: 대응 번역본 없음. 향후 번역 시 반영 필요.
