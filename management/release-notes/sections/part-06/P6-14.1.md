## v2026.07.23

- 변경 이유: P6-14.1의 Python 예제가 정해진 성공 순서를 따라가는 파이프라인처럼 보이며, Section 중심축인 `중간 관찰에 따른 다음 행동 선택`을 충분히 보여 주지 못했기 때문.
- 본문 반영: 도입부의 학습목표형 목록을 설명 문단으로 바꾸고, 프롬프트·RAG·tool use·function calling·agent 비교표의 반복을 줄여 agent의 중심을 `목표 흐름`과 `다음 행동 선택`으로 고정했다.
- 예제 반영: 관찰 상태 CSV `p6-14-1-agent-observation-states.csv`를 추가하고, Python 예제를 고정 성공 경로가 아니라 관찰 신호에 따라 `재검색`, `근거 보강`, `재시도`, `검토 전환`, `출처 부착`, `종료`가 갈라지는 구조로 바꾸었다.
- 그래프 반영: `agent-state-progress-ko.png`와 `agent-state-progress-en.png`를 완료율 진행 그래프에서 도메인별 다음 행동 분기 그래프로 갱신했다.
- 추가 정리: 본문 예제에서 출력 해석에 쓰지 않는 보조 함수를 제거하고, 예제 뒤 해설을 단일 성공 경로가 아니라 관찰 신호별 다음 행동 분기 중심으로 다시 맞추었다.
- 추가 정리: 사례 요약표와 판단 기준표의 반복을 줄이고, P6-14.1은 agent를 목표 흐름으로 읽는 데 집중하도록 P6-14.2의 계속·종료·사람 검토 세부 판단과 경계를 다시 맞추었다.
- 예제 재구성: Python 예제를 규칙 기반 다음 행동 계산에서 Ollama 로컬 LLM이 관찰 문장을 읽고 다음 행동을 제안하는 모델 사용 예제로 바꾸었다. 모델 입력용 `model_observation_en` 열을 CSV에 추가하고, 애플리케이션 guard가 모델 제안을 상태 신호로 다시 점검하는 구조를 본문 출력과 해설에 반영했다.
- 그래프 재정렬: P6-14.1 차트를 도메인별 guard 분기 분포에서 `qwen2.5:1.5b` 모델 제안과 guard 최종 행동의 비교 그래프로 바꾸어, 모델 제안과 상태 점검층의 차이가 보이게 했다.
- 제목 정리: Section 제목과 소제목을 진행 안내형 표현에서 관찰, 다음 행동, 목표 흐름의 판단 축이 드러나는 표현으로 다시 맞추었다.
- 제목 보강: 목차에서 바로 중심축을 잡을 수 있도록 Section 제목을 `중간 결과에 따라 다음 작업을 바꾸는 에이전트`로 다시 정리했다.
- 번역 동기화 메모: 영어·중국어 번역본을 갱신할 때 CSV 입력 설명, 출력 예시, 그래프 해석을 새 관찰 분기 구조에 맞춘다.
- 번역 반영 상태: 한국어 원문과 공용 자산만 수정했다.
- 원문 기준 버전: `v2026.07.23`

## v2026.07.21

- Part 6 개편 기준에 따라 Section ID, 파일 위치, 제목을 새 목차 구조에 맞춰 재정렬했다.
- 생성형 AI 산출물에서 시작해 LLM을 대표 사례로 읽는 흐름 안에서 이 Section의 위치를 다시 잡았다.
- agent를 더 똑똑한 챗봇이나 도구를 많이 쓰는 시스템이 아니라, 중간 관찰과 다음 행동 선택을 포함하는 목표 흐름 구조로 읽도록 도입부와 판단 표를 정리했다.
- function calling, agent 목표 흐름, MCP/harness 관리의 층위를 분리해 단일 호출 구조와 여러 단계 상태 관리가 섞이지 않게 문장을 다듬었다.
- 도입부의 반복 표와 진행형 소제목을 줄이고, 단일 호출에서 목표 흐름으로 관점이 바뀌는 지점을 본문 문단 안에서 바로 설명하도록 정리했다.
- 업무 자동화 에이전트 사례를 요청 장면, 중간 관찰, 확인 결과로 나누어 판단 순서를 더 분명하게 만들었다.
- P6-14 전용 agent 도식과 상태 진행 그래프 참조로 바꿔, P6-13 function calling 자산과 agent 자산의 경계를 분리했다.
- 개편 전 릴리즈노트 원문은 `management/authoring/archive/part-06-before-restructure-2026-07-21/management/release-notes/sections/part-06/`에 보존했다.
- 제목을 `에이전트는 언제 다음 행동을 다시 고르는 목표 흐름이 되는가`로 바꾸고, 도입부와 사례 요약의 반복 표를 문단으로 압축해 agent를 도구 개수가 아니라 중간 관찰에 따른 다음 행동 선택으로 읽게 정리했다.
- 도입부의 범위 설명 반복을 줄여, 중심축을 `중간 결과를 보고 다음 행동이 바뀌는 목표 흐름`으로 고정했다.
