### v2026.07.12
- 본문 반영: 집필 순서만 예고하는 `다음 ... 연결` 계열 표지를 제거했다; `이 절에서 기억할 관점`, `짧은 점검`, `언제 ... 먼저 떠올려야 하는가`를 `체크리스트` 하나 아래로 통합했다. 본문 메타데이터 버전도 함께 갱신했다.
- 추가 반영: 한국어 본문이 참조하는 Mermaid 도식의 내부 라벨을 한글화하고, 대응 영문 원본(`-en.mmd`)은 별도 유지하도록 정리했다.
- 번역 동기화 메모: 대응 번역본이 생기면 같은 메타 표지 제거와 단일 checklist 구조를 함께 반영해야 한다.

### v2026.07.17
- 본문 반영: `이 절의 범위`에서 벤치마크 점수, 통계적 유의성, 평가 플랫폼 구현 같은 생략 목록을 걷어내고, 이번 절이 `무엇을 나눠 평가해야 하는가`를 닫는 자리라는 점이 먼저 보이도록 다시 정리했다.
- 추가 반영: 평가 축 handoff는 `P6-15.2`, 운영 제약과 실패 대응 handoff는 `P6-16.1`, `P6-16.2`로 이어지게 분명히 했다.
- 번역 동기화 메모: Future translations should preserve the scope handoff where P6-15.1 closes the evaluation axes first and hands evaluator-role split to P6-15.2.

### v2026.07.18
- 본문 반영: 실행 기록과 최종 답을 남기는 것만으로는 왜 품질 판단이 닫히지 않는지 먼저 보이게 하려고, `지금 부족한 것 -> 이번 장이 붙이는 구조 -> 아직 남는 문제 -> 바로 이어지는 위치` 비교 블록을 추가했다.
- 본문 반영: `이 절은 다음 질문에 답합니다` 같은 메타 도입을 `이 절에서 먼저 붙잡을 질문`으로 낮춰, 평가 장의 공개 본문 호흡을 더 자연스럽게 정리했다.
- 추가 반영: `이 절은 Part 6에서 ...`, `여기서 먼저 남겨야 할 것은 ...`, `이 절에서는 ...로 설명합니다` 같은 메타 서술을 더 직접적인 설명 문장으로 바꿔, 평가 축과 기록 기준이 바로 읽히게 정리했다.
- 추가 반영: 빈 `지금 읽는 층위` 표지를 없애고, 실행 기록에서 품질 판정 기준으로 넘어가는 질문이 바로 이어지도록 앞부분 구조를 더 직접적으로 정리했다.
- 번역 동기화 메모: Future translations should preserve the new comparison block that separates evaluation axes from later evaluator-role split and operations.
