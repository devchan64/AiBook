# Section Release Note

- Section ID: `P6-1.5`
- Source File: `docs/parts/part-06/chapter-01/section-05.md`

### v2026.07.12
- 본문 반영: `P6-1.5`를 `토큰화는 무엇을 바꾸는가` 절로 재구성했다. 같은 문장도 토큰 수와 경계가 달라질 수 있다는 점, 비용·청크·출력 길이 변화, 사례 도식과 짧은 재정리 표를 중심으로 정리했다.
- 추가 반영: 재구성 뒤 실제 운영 장면 설명이 약해진 문제를 보완하기 위해, 비용 오판, 검색 청크 분리, 출력 마지막 문장 잘림의 세 사례를 다시 덧붙였다.
- 번역 동기화 메모: 대응 번역본이 생기면 `P6-1.5`는 토큰화 영향 절로 독립 유지해야 한다.

### v2026.07.13
- 본문 반영: 해당 소제목을 `운영 판단이 바로 흔들리는 장면`으로 바꾸어, 비용·청크·출력 길이 문제가 실제 선택으로 이어진다는 축을 더 직접 드러냈다.
- 번역 동기화 메모: 대응 번역본이 생기면 메타 질문형 표지보다 운영 장면을 직접 드러내는 소제목을 우선 반영한다.

### v2026.07.18
- 본문 반영: 사례 뒤에 `바로 적용해 보면` 표를 추가해, 겉보기 변화가 실제로 어떤 운영 판단 변경으로 이어지는지 한 번에 읽게 했다.
- 추가 반영: 토큰화 차이를 전처리 세부로 끝내지 않고 비용·청크·출력 선택으로 연결해 읽어야 한다는 적용 문장을 덧붙여 초심자용 닫힘을 보강했다.
- 번역 동기화 메모: 대응 번역본이 생기면 적용 표와 운영 판단 연결 문장도 함께 반영해야 한다.
