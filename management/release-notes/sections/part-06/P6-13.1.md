## v2026.07.31

- 변경 이유: 원고별 수정 방향 리포트와 최신 원고 작성 가이드에 따라 `사례 및 예시`, `연습 및 예제` 같은 분류형 소제목 구조를 폐기하고, 도구 사용 사례와 예제의 실행 판단 역할이 제목에서 보이게 정리했다.
- 본문 반영: 사례 구간 제목을 설명만으로 닫히지 않는 실행 요청으로 바꾸고, 예제 구간 제목을 요청 분기를 실행 기록으로 확인하기로 바꾸었다. 계산기, 일정 조회, 파일 수정 사례와 CSV 기반 도구 분기 예제 내용은 유지했다.
- 번역 동기화 메모: 영어판과 중국어 간체판도 분류형 소제목 통일 기준을 폐기하고 내용형 제목으로 맞췄다.
- 번역 반영 상태: 한국어, 영어, 중국어 간체판 반영 완료.
- 번역 반영 파일: `docs/parts/part-06/chapter-13/section-01.en.md`, `docs/parts/part-06/chapter-13/section-01.zh.md`
- 관련 자산: 변경 없음.
- 원문 기준 버전: `v2026.07.31`

## v2026.07.25-zh

- 변경 이유: Part 6 중국어판 순차 번역에서 P6-13.1을 최신 한국어 원문과 같은 Section ID·Version 기준으로 제공하기 위함.
- 본문 반영: `docs/parts/part-06/chapter-13/section-01.zh.md`를 추가하고, tool use를 모델 밖의 조회·계산·실행 결과와 연결하는 실행 구조로 읽는 설명 흐름을 중국어 간체로 옮겼다.
- 예제 반영: 중국어판 노출용 `p6-13-1-tool-use-requests-zh.csv`를 추가하고, Python 예제가 해당 중국어 CSV를 읽어 모델 route 제안, application guard 보정, tool call, tool result, approval pending, missing information 상태를 분리 출력하도록 정리했다.
- 자산 반영: 중국어판 Mermaid 도식 `p6-c13-s01-tool-use-flow-zh.mmd`, `p6-c13-s01-tool-delegation-zh.mmd`를 추가하고, 차트는 `tool-use-decision-check-zh.png`를 참조하도록 정리했다. 차트 생성 스크립트에는 중국어 라벨 세트를 추가했다.
- 검수 반영: 한국어 원문과 중국어판의 빈 줄 제외 줄 수 차이가 5% 미만임을 확인하고, `.venv` Python 실행 결과가 본문 출력과 일치함을 확인했다. 중국어판에서 한국어 전용 자산을 참조하지 않음도 확인했다.
- 실행 환경 메모: 현재 검수 환경에서는 Ollama 서버가 실행 중이지 않아 `model_route`는 `None`으로 남고 application guard가 최종 route를 확정하는 fallback 출력으로 본문을 맞추었다.
- 번역 동기화 메모: 중국어판은 한국어 원문 `v2026.07.23`을 기준으로 최신 반영했으며, 한국어 요청 CSV는 중국어판용 `-zh.csv`로 분리 관리한다.
- 번역 반영 상태: 중국어 번역 완료.
- 원문 기준 버전: `v2026.07.23`

## v2026.07.21

- Part 6 개편 기준에 따라 Section ID, 파일 위치, 제목을 새 목차 구조에 맞춰 재정렬했다.
- 생성형 AI 산출물에서 시작해 LLM을 대표 사례로 읽는 흐름 안에서 이 Section의 위치를 다시 잡았다.
- 도구 사용을 모델이 스스로 실행 능력을 갖는다는 설명이 아니라 애플리케이션이 외부 기능을 연결해 조회, 계산, 실행 결과를 가져오는 구조로 읽도록 도입부와 판단 표를 정리했다.
- RAG의 문서 근거 연결, tool use의 실행 연결, function calling의 구조화 요청, agent의 목표 흐름을 층위별로 분리해 학습 흐름을 보강했다.
- P6-13.1 전용 tool use 도식과 판단 차트를 chapter-13 자산 경로로 분리하고, 진행 안내식 표현을 개념 기준 문장으로 정리했다.
- 개편 전 릴리즈노트 원문은 `management/authoring/archive/part-06-before-restructure-2026-07-21/management/release-notes/sections/part-06/`에 보존했다.
- `바로 적용해 보면` 제목을 실행 연결이 필요한 장면으로 바꾸어 문서 읽기와 실제 조회·계산·실행의 차이를 더 직접 드러냈다.
- 계산기, 일정 조회, 파일 수정 사례에서 설명만으로 충분해 보이는 오해와 외부 도구 실행이 필요한 기준을 문단으로 분리했다.
- 제목을 `도구 사용은 언제 실제 조회·계산·실행이 필요한가`로 바꾸고, 도입부와 사례 요약의 반복 표를 문단으로 압축해 RAG의 문서 읽기와 tool use의 실행 연결 차이를 더 직접 드러냈다.
- 도입부의 후속 구조 예고 반복을 줄여, 중심축을 `외부 기능을 실제로 호출해 결과를 가져오는 실행 연결`로 고정했다.
