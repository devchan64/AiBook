- Python 예제 보강: 고정 점수표 출력에 그치지 않도록 단서 조작 시나리오, softmax 확률, 1·2위 점수 차이를 추가해 후보 분포와 순위 변화가 직접 보이게 했다.

- 추가 반영: Chapter 3 보충학습을 둘로 나누면서, 현재 절의 후속 참조도 `P6-3.3`의 문맥 읽기 보강과 `P6-3.4`의 긴 문맥/반복 생성 보강으로 분리해 다시 적었다.; 같은 날짜 재수정에서 `P6-3.4`를 KV cache 단독 절로, `P6-3.5`를 sparse attention/long-context 절로 다시 나누고 현재 절의 handoff 문장도 그 구조에 맞춰 조정했다.; `## 바로 적용해 보면` 표를 추가해, 초심자가 자동완성·코드 생성·긴 문서 요약 장면에서 `바로 앞 조각만 붙이는 문제`와 `앞 문맥 전체를 반영하는 구조 문제`를 먼저 가르게 했다.
- 정리 반영: 도입부의 `이 절은 ...`, `구조 지도 축` 같은 메타 문장을 줄이고, `입력 토큰이 어떤 계산 흐름을 거쳐 다음 토큰 점수로 이어지는가`가 먼저 보이도록 정리했다.; 제목 아래 `Section ID`, `Version` 표기를 저장소 규칙 형식으로 바로잡았다.; 사례 해설에 남아 있던 `초심자가 ...` 독자 표지를 `이 표가 바로잡는 오해`, `중요한 기준` 중심 표현으로 낮춰, Transformer 설명이 메타 독자 안내보다 앞 문맥 전체 반영이라는 구조 판단에 더 직접 붙게 다듬었다.
