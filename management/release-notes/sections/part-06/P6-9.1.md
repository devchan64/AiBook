### v2026.07.18

- 체크리스트 정리: 체크리스트 안에 섞여 있던 요약 표, 전환 문단, 중복 요약 항목을 걷고 현재 Section 중심 질문을 닫는 자기 확인 항목만 남겼다.
- 본문 반영: 사례·적용 문장에 남아 있던 `초심자가 ...` 표지를 더 줄여, 같은 문서의 요약 목적 차이와 `문장을 더 길게 쓰는 일` 대 `흔들리는 기준 고정`의 차이가 입력 설계 문제로 바로 읽히게 다듬었다.; 분류 사례 정리 문장의 `초심자가 여기서 꼭 붙잡아야 할 기준`을 `여기서 꼭 붙잡아야 할 기준`으로 낮춰, 예시가 운영 규칙을 입력에 심는 장치라는 점이 독자 라벨 없이 먼저 보이게 다듬었다.; `Part 6에서 ... 첫 상세 설명은 이 절에서 잡습니다` 같은 위치 설명형 메타 문장을 걷고, 프롬프트를 `현재 모델 반응을 관찰하고 조정하는 입력 설계`로 바로 읽게 도입부를 더 직접적으로 정리했다.; `커리큘럼 관점에서 ...`, `초심자가 이 절에서 ...` 같은 진행 표지를 `이 절이 맡는 역할`, `먼저 가를 장면`으로 낮춰, 프롬프트를 읽는 흐름이 집필 안내보다 실제 판단 장면 중심으로 보이게 정리했다.
- 추가 반영: `## 이 절의 범위`, `## 이 절의 목표` 같은 메타 소제목을 `입력 설계가 맡는 일`, `여기서 남겨야 할 구분`으로 바꾸고, 절의 역할이 소제목 자체에서 바로 보이게 정리했다.; 제목 아래 `Section ID`, `Version` 표기를 저장소 공통 형식에 맞춰 blockquote 대신 일반 메타데이터 줄로 정리했다.; 세 사례 요약 뒤에 `바로 적용해 보면` 블록을 추가해, 초심자가 요약·분류·문서 질의응답 장면에서 무엇을 먼저 명시해야 하는지 `작업 지시`, `예시`, `문맥` 기준으로 바로 대응해 읽도록 보강했다.; `바로 적용해 보면`과 점검 질문에 `사실관계보다 형식과 길이 쪽이 먼저 흔들리는 장면`을 덧붙여, `새 구조 추가`와 `입력 지시 보강`을 초심자 첫 질문에서 먼저 가르도록 보강했다.
- 정리 반영: 도입부에서 `이 절은 ... 답합니다`, `손잡이` 같은 메타 설명을 줄이고, 프롬프트를 `입력 설계`로 읽는 핵심 전환이 실제 설명 문장으로 먼저 드러나도록 정리했다.; 본문 중간의 `첫 손잡이`, `실무 손잡이` 같은 표현도 `첫 제어 지점`, `실무 제어 지점`으로 바꿔, 프롬프트를 설명 도구보다 실제 입력 조정 위치로 읽게 다듬었다.; `이 절을 읽는 순서` 안내를 걷고, `형식 흔들림`, `독자 수준/말투 불일치`, `최신성·근거 불안`, `실행 구조 필요`를 먼저 가르는 장면별 분기 표로 바꿔 초심자 첫 질문이 프롬프트 층 판단으로 바로 이어지게 정리했다.; `이 절이 맡는 역할` 같은 설명 밖 문장을 줄이고, 입력 설계가 왜 RAG·tool use·agent 앞의 첫 제어 지점인지 본문 문장 자체로 보이게 다듬었다.
- 번역 동기화 메모: 대응 번역본이 생기면 같은 직접 적용 표와 질문 표를 함께 반영해야 한다.
