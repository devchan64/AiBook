### v2026.07.18

- 체크리스트 정리: 체크리스트 안에 섞여 있던 요약 표, 전환 문단, 중복 요약 항목을 걷고 현재 Section 중심 질문을 닫는 자기 확인 항목만 남겼다.
- 본문 반영: `## 이 절의 범위`, `## 이 절의 목표` 같은 메타 제목을 `벡터 표현 전환이 다루는 질문`, `여기서 남겨야 할 구분`으로 바꿔, 임베딩의 위치 설명보다 `번호가 어떻게 계산 가능한 벡터로 바뀌는가`가 먼저 보이게 정리했다.; 사례 뒤에 `바로 적용해 보면` 표를 추가해, 초심자가 `토큰 ID`, `임베딩 벡터`, `가까운 후보 결과`를 볼 때 각각 무엇을 `번호`, `표현 좌표`, `후보 비교 결과`로 읽어야 하는지 바로 연습해 볼 수 있게 했다.; 예제 뒤에도 `토큰 ID`, `임베딩 벡터`, `가까운 후보 순서`를 각각 어떤 질문으로 읽어야 하는지 정리 표를 덧붙여, 이 절의 닫힘을 정의 암기보다 `번호 -> 좌표 -> 후보 비교` 층위 구분 쪽에 더 강하게 고정했다.; 도입부의 `이 절은 ...`, `지금 읽는 층위` 같은 메타 문장을 줄이고, `토큰 번호`와 `계산 가능한 벡터 표현`의 차이가 먼저 보이도록 정리했다.
- 추가 반영: 제목 아래 메타데이터 표기를 저장소 규칙 형식으로 바로잡고, 같은 장 보충학습 handoff를 `P6-2.3 임베딩 학습`, `P6-2.4 ANN 검색`으로 분리해 연결했다.; `Part 6에서 ...`와 `초심자가 여기서 ...` 같은 집필 해설 문장을 덜어내고, 토큰 설명에서 벡터 표현 설명으로 넘어가는 전환과 `번호 -> 좌표 -> 비교 결과` 구분이 본문 문장 자체로 보이게 다듬었다.; 사례 해설과 비교표에 남아 있던 `초심자가 ...` 독자 표지를 `이 표가 바로잡는 오해`, `중요한 기준`, `먼저 떠올리기 쉬운 오해` 중심 표현으로 낮춰, 임베딩 설명이 메타 독자 안내보다 표면 철자와 문맥 관계 구분에 더 직접 붙게 다듬었다.
- 번역 동기화 메모: 대응 번역본이 생기면 적용 표와 예제 뒤 마무리 표도 함께 반영해야 한다.
