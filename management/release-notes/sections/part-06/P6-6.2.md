## v2026.07.24

- 변경 이유: 기존 temperature 예제가 고객 지원 답변 슬롯 조합처럼 보여, 실제 다음 토큰을 어떻게 뽑느냐가 안정성, 다양성, 재현성을 바꾼다는 Section 중심축을 충분히 지지하지 못했기 때문.
- 본문 반영: 36행 후보 토큰 CSV `p6-6-2-next-token-candidates.csv`를 추가하고, 한 행이 특정 출력 위치의 다음 토큰 후보와 기본 확률을 뜻하도록 설명했다.
- 본문 반영: Python 예제를 답변 슬롯 조합에서 다음 토큰 후보를 한 위치씩 뽑아 문장을 완성하는 디코딩 실험으로 교체했다.
- 본문 반영: 출력이 `greedy outputs by temperature`, `sampling summary`, `first token counts`, `high temperature preview`로 이어지게 하여 안정성, 다양성, 재현성을 분리해 읽게 했다.
- 자산 반영: `p6_6_2_temperature_diversity_chart.py`가 후보 토큰 CSV를 읽어 temperature별 상위 토큰 선택 비율, 서로 다른 출력 수, 첫 토큰 분포를 계산하도록 재작성했다.
- 자산 반영: 그래프를 3패널 구조로 바꾸어 토큰 선택 안정성, 출력 다양성, 첫 토큰 분포를 함께 보이게 했다.
- 학습 기준: 그래프를 답변 품질 향상이 아니라 같은 후보 분포에서 실제 토큰 선택 폭이 넓어지는 신호로 읽게 했다.
- 근거 보강: 자기회귀 모델의 다음 토큰 분포와 decoding 방식, temperature 설정, seed 재현성 한계를 확인할 수 있는 공개 자료를 출처에 추가했다.
- 정합성 보강: 본문 예제의 seed 재현성은 로컬 Python 난수 생성기 기준이며, 실제 API에서는 seed와 설정이 같아도 완전한 결정성을 보장하지 않을 수 있다는 경계를 추가했다.
- 번역 동기화 메모: 향후 번역본도 후보 토큰 CSV, temperature별 상위 토큰 선택 비율, 출력 다양성, 첫 토큰 분포의 역할을 분리해 설명한다.
- 번역 반영 상태: 한국어 원문과 공용 자산만 수정했다.
- 원문 기준 버전: `v2026.07.24`
