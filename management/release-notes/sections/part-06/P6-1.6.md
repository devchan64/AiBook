# Section Release Note

### v2026.07.12

- 변경 이유: Chapter 1을 8절 구조로 다시 나누면서, `대표 토크나이저 계열 소개`를 `차이가 언제 드러나는가` 및 `어디에 활용되는가`와 분리할 필요가 있었다.
- 본문 반영: `P6-1.6`을 `대표 토크나이저 계열은 무엇인가` 절로 재배치했다. BPE, WordPiece, SentencePiece를 `무엇의 이름인가`, `왜 모델 카드와 강의에서 반복되는가` 중심으로 소개하고, 비교와 활용은 뒤 절로 넘겼다.
- 추가 반영: 이름 소개만 남아 `왜 알아야 하는가`가 약해진 문제를 보완하기 위해, BPE, WordPiece, SentencePiece 각각의 조각 형성 감각과 초심자 기준 비교표를 보강했다.
- 추가 반영: 대표 토크나이저를 `왜 학습해야 하는가`, `왜 직접 써 봐야 하는가`, `아주 작게 어떻게 사용해 볼 수 있는가`를 별도 단락으로 추가해 이 절이 단순 이름 암기에 머물지 않게 조정했다.
- 추가 반영: `transformers` 기반의 최소 실습 예제를 추가해 BPE, WordPiece, SentencePiece 예시 모델에 같은 문자열을 넣고 토큰 조각과 토큰 수를 직접 비교해 볼 수 있게 했다.
- 추가 반영: 로컬 환경에서 `gpt2`, `bert-base-uncased`, `google/mt5-small` 토크나이저를 실제로 실행한 결과를 반영해, 입력별 토큰 수와 대표 조각 예시를 본문 표에 고정했다.
- 추가 반영: Section 제목 아래 메타데이터 줄이 인용 블록으로 남아 있던 형식을 저장소 원칙에 맞춰 일반 `Section ID`, `Version` 두 줄 형식으로 바로잡았다.
- 번역 동기화 메모: 대응 번역본이 생기면 `P6-1.6`은 이름 소개 절로 유지하고 비교/활용은 뒤 번호에서 분리해야 한다.
- 번역 반영 상태: 향후 번역 반영 필요

### v2026.07.13

- 번역 동기화 메모: 대응 번역본이 생기면 이름 소개 자체보다 토큰 경계 차이와 해석 기준이 먼저 보이는 흐름을 유지한다.
