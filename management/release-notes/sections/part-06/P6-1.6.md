# Section Release Note

- Section ID: `P6-1.6`
- Source File: `docs/parts/part-06/chapter-01/section-06.md`

### v2026.07.19
- 사례 중심축 보강: BPE, WordPiece, SentencePiece 사례를 `사람이 먼저 쓰는 기준 -> 기준의 한계 -> 계열 이름이 바꾸는 질문 -> 확인할 결과` 흐름으로 재정렬해, 세 이름을 문자열 절단 기준으로 읽게 했다.
- 예제 해설 보강: Python 예제의 관찰 질문마다 해설을 붙여, 출력 차이가 `반복 조각`, `사전 조각`, `공백 포함 문자열`이라는 Section 중심 판단으로 닫히게 했다.
- 경계 조정: 실행 결과 해석 문장을 비용·context window·청크 설계로 너무 빨리 넘기지 않고, P6-1.6의 중심인 대표 계열 이름과 절단 기준 해석으로 닫도록 다듬었다.

### v2026.07.12
- 본문 반영: `P6-1.6`을 `대표 토크나이저 계열은 무엇인가` 절로 재배치했다. BPE, WordPiece, SentencePiece를 `무엇의 이름인가`, `왜 모델 카드와 강의에서 반복되는가` 중심으로 소개하고, 비교와 활용은 뒤 절로 넘겼다.
- 추가 반영: 이름 소개만 남아 `왜 알아야 하는가`가 약해진 문제를 보완하기 위해, BPE, WordPiece, SentencePiece 각각의 조각 형성 감각과 초심자 기준 비교표를 보강했다.
- 번역 동기화 메모: 대응 번역본이 생기면 `P6-1.6`은 이름 소개 절로 유지하고 비교/활용은 뒤 번호에서 분리해야 한다.

### v2026.07.13
- 본문 반영: 도입을 `왜 모델마다 문자열이 다르게 잘리는가`라는 질문에서 시작하도록 다시 쓰고, 관련 소제목을 `토큰 경계가 갈리는 기준`, `세 계열을 어떻게 읽기 시작하면 좋은가`, `먼저 구분해 둘 오해`, `이 구분이 뒤 절에서 바로 쓰이는 이유`, `작은 비교로 먼저 보면`으로 재정리했다.
- 번역 동기화 메모: 대응 번역본이 생기면 이름 소개 자체보다 토큰 경계 차이와 해석 기준이 먼저 보이는 흐름을 유지한다.

### v2026.07.18
- 본문 반영: `초심자 기준 한 줄 설명`, `초심자가 붙잡아야 할 핵심`, `초심자가 자주 다시 막히는 지점` 같은 독자 라벨을 줄여, BPE·WordPiece·SentencePiece를 읽는 질문이 계열 차이 자체로 바로 보이게 다듬었다.; `## 바로 적용해 보면` 표를 추가해, 초심자가 세 이름을 고유명사로만 외우지 않고 `반복 조각`, `사전 조각 선택`, `공백 경계 처리` 가운데 지금 무엇을 먼저 확인해야 하는지 직접 고르게 했다.; 모델 카드나 토크나이저 설명을 읽을 때 `현재 입력에서 먼저 눈에 띄는 문제`를 질문으로 바꾸게 하는 닫힘 문장을 덧붙였다.
- 추가 반영: `이 절의 목표는` 같은 메타 목표 문장을 내용 중심 문장으로 바꿔, 이름 암기보다 문자열 절단 기준을 읽는 판단이 먼저 보이게 정리했다.; `초심자 기준에서는` 같은 독자 해설 표지를 줄이고, 세 계열이 무엇을 더 강하게 의식하는지 바로 남기는 문장으로 닫힘을 정리했다.
- 사례 보강: `모델 카드`, `강의 슬라이드`, `비용표`처럼 주변 장면에 머물던 사례를 BPE의 반복 조각 병합, WordPiece의 subword 사전 설명, SentencePiece의 공백 경계 처리 사례로 바꿔 Section의 중심 질문을 직접 지지하게 했다.
- 구조 보강: 사례 블록을 실행 예제 뒤가 아니라 계열 설명 뒤로 옮기고, `바로 적용해 보면`을 사례 뒤로 재배치해 사례가 먼저 Section 질문을 지지한 뒤 적용 질문과 실습으로 이어지게 했다.
- 번역 동기화 메모: 대응 번역본이 생기면 적용 표와 질문 전환 문장도 함께 반영해야 한다.
