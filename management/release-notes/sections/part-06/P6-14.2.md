- 소제목 정리: 질문형·진행형 소제목을 계획·행동·관찰 분리, 종료 조건, 실패 유형, 관찰 뒤 루프 분기처럼 Section 중심축이 드러나는 표현으로 바꾸었다.
- 원고 재정리: 학습 목표형 목록과 중복 분기표를 줄이고, 예제 뒤에는 계획·행동·관찰 재요약 대신 CSV 열과 결정 조건의 연결 표를 배치했다.
- 예제 재구성: 정해진 세 결론을 하나씩 보여 주던 Python 예제를 36행 관찰 로그 CSV `p6-14-2-agent-loop-observations.csv`와 Ollama 모델 제안을 함께 쓰는 실험형 예제로 바꾸고, 모델 계획 후보, guard 최종 결정, 라운드별 결정 분포, 목표별 마지막 결정, 결정 변화 사례를 출력하도록 했다.

- 예제 해설 조정: 모델이 모든 관찰 로그에 응답했다는 사실보다 guard가 15건에서 모델 후보를 그대로 쓰지 않고 루프 종료 조건으로 다시 분기시킨 점을 먼저 읽도록 해설 초점을 바꾸었다.

## v2026.07.21

- Part 6 개편 기준에 따라 Section ID, 파일 위치, 제목을 새 목차 구조에 맞춰 재정렬했다.
- 생성형 AI 산출물에서 시작해 LLM을 대표 사례로 읽는 흐름 안에서 이 Section의 위치를 다시 잡았다.
- 계획, 행동, 관찰을 단순 반복 용어가 아니라 계속 진행, 종료, 사람 검토 전환을 가르는 분기 루프 구조로 읽도록 도입부와 판단 표를 정리했다.
- agent loop가 직접 다루는 판단과 MCP/harness로 넘겨야 할 연결 규칙·기록 환경을 구분해 후속 흐름의 경계를 보강했다.
- P6-14 전용 plan-action-observation 도식과 agent loop 결정 그래프 참조로 바꿔, 이전 장 자산을 빌려 쓰던 혼선을 줄였다.
- 개편 전 릴리즈노트 원문은 `management/authoring/archive/part-06-before-restructure-2026-07-21/management/release-notes/sections/part-06/`에 보존했다.
- `바로 적용해 보면` 제목을 루프 분기 판단이 필요한 장면으로 바꾸어 계속 진행, 종료, 사람 검토 전환의 기준이 더 직접 보이게 정리했다.
- 제목을 `계획·행동·관찰은 어떻게 계속·종료·사람 검토를 가르는가`로 바꾸고, 도입부의 반복 표를 문단으로 압축해 agent 목표 흐름에서 루프 분기, P6-15의 연결 규칙·기록 환경으로 이어지는 흐름을 더 선명하게 했다.
- 도입부의 루프 설명 반복을 줄여, 중심축을 `관찰 결과에 따라 계속·종료·사람 검토로 갈라지는 반복 구조`로 고정했다.
