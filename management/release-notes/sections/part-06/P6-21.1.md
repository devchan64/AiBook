## v2026.08.11

- 변경 이유: 공개 범위 설명이 표와 정의에 머물지 않고, 독자가 목적·공개 범위·운영 책임을 함께 판단하게 보강할 필요가 있었다. 공개 API와 오픈웨이트의 차이를 근거 범위 안에서 더 정확히 표현할 필요가 있었다.
- 본문 반영: 내부 실행, 교육 재현, 상업 서비스의 세 상황을 비교해 먼저 확인할 공개 범위와 다음 판단을 정리하고, 체크리스트에 목적과 책임을 함께 판단하는 항목을 추가했다. 데이터 통제, 검증과 재현, 목적별 조정, 공급자 의존성 완화 관점의 오픈웨이트 선택 주장을 소개하고, 그 책임 조건을 함께 제시했다. 7단계 공개 범위 검토 Mermaid는 좁은 화면에서도 읽을 수 있도록 세로 흐름으로 정리했다.
- 번역 동기화 메모: 한국어 원문 `v2026.08.11` 기준으로 영문·중문 본문을 새로 작성했다. 공개 범위, 책임 비교표, Mermaid 흐름, Part 7 기록 질문, 체크리스트와 출처를 같은 학습 순서로 맞췄다.
- 번역 반영 상태: 한국어 원문 / 영문 / 중문 번역 반영 완료
- 외부 근거 반영: OSI 정의, Model Openness Framework 원문, Hugging Face FAQ, OpenAI와 Linux Foundation의 공개 모델 자료를 재확인하고 확인일을 갱신했다.
