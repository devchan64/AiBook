# P6-18.1 릴리즈 노트

- Section ID: `P6-18.1`
- Source File: `docs/parts/part-06/chapter-18/section-01.md`

## v2026.07.23

- 변경 이유: Part 6 목차에서 질문형 제목이 반복되어 Section 중심축이 한눈에 구분되기 어려웠기 때문.
- 본문 반영: 제목을 `질문·근거·답변·기록을 묶는 작은 생성형 AI 기능`으로 바꾸어 구현 흐름의 구성 요소가 목차에서 보이게 했다.
- 목차 반영: `mkdocs.yml`, 독자용 목차, Part 6 개편안의 제목을 같은 표현으로 맞추었다.
- 도식 반영: 요청 라우팅 도식에 확답 위험 또는 근거 부족을 확인한 뒤 사람 검토나 추가 질문으로 넘기는 경로를 추가했다.
- 그래프 반영: 요청 구조 매트릭스의 한국어 열 라벨을 `프롬프트`, `검색`, `도구 사용`, `사람 검토`로 맞추었다.
- 본문 보강: 설계 문장 예시에 현재 상태 조회가 필요한 기능의 도구 호출과 조회 결과 기록을 추가했다.
- 번역 동기화 메모: 향후 번역본도 작은 생성형 AI 기능을 질문, 근거, 답변, 기록의 결합 흐름으로 제목화한다.
- 번역 반영 상태: 한국어 원문과 목차만 수정했다.
- 원문 기준 버전: `v2026.07.23`

## v2026.07.22

- 변경 이유: Part 6 본문에서 진행 메타형 소제목을 구체 개념, 비교 대상, 판단 기준이 드러나는 제목으로 정리하기 위함.
- 본문 반영: `여기서 남겨야 할 구분`, `여기까지를 한 줄로 묶으면`, `보는 순서`, `이 예제를 ... 다시 보면` 계열 제목을 현재 절의 실제 구분 축과 설명 흐름이 보이는 소제목으로 바꾸었다.
- 번역 동기화 메모: 향후 번역본도 진행 안내형 제목보다 현재 절의 구체 개념, 비교 대상, 판단 기준이 보이는 소제목으로 맞춘다.
- 번역 반영 상태: 한국어 원문만 수정했다.
- 원문 기준 버전: `v2026.07.22`

## v2026.07.21

- Part 6 개편 기준에 따라 Section ID, 파일 위치, 제목을 새 목차 구조에 맞춰 재정렬했다.
- 생성형 AI 산출물에서 시작해 LLM을 대표 사례로 읽는 흐름 안에서 이 Section의 위치를 다시 잡았다.
- 프롬프트, retrieval, tool use, 평가, 실패 대응을 요청 하나의 상태값으로 묶는 흐름을 보강했다.
- 진행 메타 중심 문장을 줄이고, `답변 초안 가능`, `근거 보강 필요`, `상태 조회 필요`, `사람 검토 필요`가 요청 실행 기록으로 이어지는 구조를 정리했다.
- P6-18 전용 요청 흐름 도식과 요청 구조 매트릭스 그래프 참조로 바꿔, P6-17 운영 자산과 요청 통합 자산의 경계를 분리했다.
- 개편 전 릴리즈노트 원문은 `management/authoring/archive/part-06-before-restructure-2026-07-21/management/release-notes/sections/part-06/`에 보존했다.
- `바로 적용해 보면` 제목을 요청 상태를 먼저 남겨야 하는 장면으로 바꾸어 prompt, retrieval, tool use 선택을 요청 닫힘 상태와 연결해 읽게 정리했다.
- 문장 다듬기, 사내 정책 안내, 잔여 휴가 조회 사례에서 현재 입력만으로 닫히는지, 최신 근거가 필요한지, 실제 상태 조회가 필요한지를 문단으로 분리했다.
- 제목을 질문형 중심축으로 바꾸고, 사례 후반과 요청 상태 판단부의 반복 표를 줄여 작은 기능을 요청 흐름과 상태값으로 묶는 기준을 더 직접 드러냈다.
