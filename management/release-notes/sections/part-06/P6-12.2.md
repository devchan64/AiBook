### v2026.07.17

- 번역 동기화 메모: Future translations should preserve the scope handoff structure where this section closes function-calling structure first and leaves loop orchestration and implementation detail to later sections.

### v2026.07.18

- 체크리스트 정리: 체크리스트 안에 섞여 있던 요약 표, 전환 문단, 중복 요약 항목을 걷고 현재 Section 중심 질문을 닫는 자기 확인 항목만 남겼다.
- 본문 반영: `## 이 절의 범위`, `## 이 절의 목표`, `## 이 절을 읽는 순서` 같은 메타 제목을 `구조화된 호출이 다루는 질문`, `여기서 남겨야 할 구분`, `구조화 전환을 보는 순서`로 바꿔, 설명 안내보다 `자연어가 이름·인자 구조로 어떻게 바뀌는가`가 먼저 보이게 정리했다.; 제목 아래 `Section ID`, `Version` 표기를 저장소 공통 형식에 맞춰 blockquote 대신 일반 메타데이터 줄로 정리했다.; `도구를 써야 한다는 판단`만으로는 왜 실행이 안정되지 않는지 먼저 보이게 하려고, `지금 부족한 것 -> 이번 장이 붙이는 구조 -> 아직 남는 문제 -> 바로 이어지는 위치` 비교 블록을 추가했다.; `이 절은 다음 질문에 답합니다` 같은 메타 도입을 `이 절에서 먼저 붙잡을 질문`으로 낮춰, 함수 호출 장의 공개 본문 호흡을 더 자연스럽게 정리했다.
- 추가 반영: `이 절은 Part 6에서 ...`, `여기서 먼저 남겨야 할 것은 ...` 같은 메타 서술을 더 직접적인 설명 문장으로 바꿔, 구조화된 호출과 기록 기준이 바로 읽히게 정리했다.; `지금 읽는 층위는`으로 절의 역할을 따로 설명하던 문장을 줄이고, tool use에서 구조화된 실행 요청으로 넘어가는 연결이 더 바로 보이도록 앞부분을 다듬었다.; 세 사례 요약 뒤에 `바로 적용해 보면` 블록을 추가해, 초심자가 `자연어 요청`, `함수 이름`, `필수 인자`, `결과 형식`을 분리해 읽고 `구조화됐다`와 `실행 가능하다`를 구분하도록 보강했다.; `이 절이 맡는 역할` 같은 설명 밖 문장을 줄이고, 자연어 요청과 검증 가능한 실행 구조를 왜 갈라야 하는지가 본문 문장 자체로 보이게 다듬었다.
- 정리 반영: 사례와 적용 문단에 남아 있던 `초심자가 ...` 독자 표지를 줄이고, 자연어 이해와 실행 준비의 차이가 인자·검증·추적 기준으로 바로 드러나게 다듬었다.
- 번역 동기화 메모: Future translations should preserve the new comparison block that separates structured calls from later loop orchestration.
