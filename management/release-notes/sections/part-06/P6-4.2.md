## v2026.07.24

- 변경 이유: Part 6 Python 예제 개선 방안에 따라 context window 예제의 토큰 길이 값을 수작업 추정치가 아니라 실제 tokenizer 관찰값으로 바꾸기 위함.
- 본문 반영: `tiktoken`의 `o200k_base` 인코딩으로 각 문맥 항목의 토큰 수를 계산한 뒤, 입력 순서 선택과 우선순위 선택을 비교하도록 Python 예제를 수정했다. 실제 tokenizer 산출값과 독자가 조작할 운영 예산값을 구분해 설명했다.
- 관련 자산: `docs/assets/part-06/chapter-04/p6_4_2_context_selection_chart.py`와 `context-selection-budget-ko.png`, `context-selection-budget-en.png`를 같은 tokenizer 계산 기준으로 갱신했다.
- 본문 반영: 도입부의 진행 메타형 질문 목록을 줄이고, attention과 context window의 역할 차이를 본문 설명으로 바로 연결했다.
- 본문 반영: RAG 설명은 후속 연결 수준으로 압축하고, 현재 Section의 중심을 `윈도우 안에 남길 근거를 먼저 고른다`는 입력 선택 문제로 유지했다.
- 관련 자산: 문맥 선택 그래프를 단일 토큰 예산 비교에서 24, 32, 40 예산 변화에 따른 필수 상태 보존 수와 relevance 합계 비교로 재구성했다.
- 의존성 반영: P6-2.3에서 추가한 `tiktoken==0.13.0`을 이 절 예제에서도 사용한다.
- 원문 기준 버전: `v2026.07.24`

## v2026.07.22

- 본문 반영: Python 예제를 단일 토큰 예산 비교에서 여러 예산 비교로 확장해, 입력 선택 방식과 예산 변화에 따라 보존되는 핵심 단서가 어떻게 달라지는지 더 분명하게 보이도록 했다.
- 본문 반영: 실행 결과 예시와 해설을 `많이 넣는가`보다 `핵심 상태가 실제로 남는가`를 확인하는 방향으로 보강했다.
- 번역 동기화 메모: 향후 번역본도 진행 안내형 제목보다 현재 절의 구체 개념, 비교 대상, 판단 기준이 보이는 소제목으로 맞춘다.
- 번역 반영 상태: 한국어 원문만 수정했다.
- 원문 기준 버전: `v2026.07.22`
