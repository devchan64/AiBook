### v2026.07.18

- 체크리스트 정리: 체크리스트 안에 섞여 있던 요약 표, 전환 문단, 중복 요약 항목을 걷고 현재 Section 중심 질문을 닫는 자기 확인 항목만 남겼다.
- 본문 반영: `이 절이 맡는 역할` 같은 설명 밖 문장을 줄이고, 벡터 데이터베이스가 저장소를 넘어 검색 저장 계층으로 왜 읽혀야 하는지가 본문 문장 자체로 보이게 다듬었다.; `Part 6에서 ... 첫 상세 설명은 이 절에서 잡습니다` 같은 위치 설명형 메타 문장을 걷고, 벡터 데이터베이스를 `임베딩, 원문, 메타데이터를 함께 두는 검색 저장 구조`로 바로 읽게 도입부를 더 직접적으로 정리했다.; `이 절에서 먼저 가를 장면`, `커리큘럼 관점에서 ...` 같은 진행 표지를 더 직접적인 문장으로 낮춰, 저장 구조 설명이 안내 문구보다 실제 검색 판단 장면 중심으로 읽히게 정리했다.; 남아 있던 `커리큘럼 관점에서 이 절이 중요한 이유` 표지도 `이 절이 맡는 역할`로 낮춰, Chapter 11의 저장 구조 설명이 메타 안내보다 역할 설명 중심으로 읽히게 맞췄다.; `## 이 절의 범위`, `## 이 절의 목표` 같은 메타 소제목을 `검색 저장 구조가 맡는 일`, `여기서 남겨야 할 구분`으로 바꾸고, 도입부 반문형 연결도 직접 설명형으로 다듬었다.
- 추가 반영: 제목 아래 `Section ID`, `Version` 표기를 저장소 공통 형식에 맞춰 blockquote 대신 일반 메타데이터 줄로 정리했다.; Chapter 11~14의 후반 실행 구조 전환을 더 선명하게 읽게 하려고, `지금 부족한 것 -> 이번 장이 붙이는 구조 -> 아직 남는 문제 -> 바로 이어지는 위치` 비교 블록을 추가했다.; `이 절은 다음 질문에 답합니다` 같은 메타 도입 문장을 `이 절에서 먼저 붙잡을 질문` 형식으로 낮춰, 공개 본문 호흡을 더 자연스럽게 정리했다.; `이 절은 Part 6에서 ...` 같은 한 겹 감싸는 메타 문장을 더 직접적인 설명 문장으로 바꿔, 저장 구조 설명이 바로 본론으로 읽히게 정리했다.; `이 절을 읽는 순서` 안내를 걷고, `표현 차이`, `원문 부재`, `메타데이터 부재`, `후보 선택 기준 부족`을 먼저 가르는 장면별 분기 표로 바꿔 초심자 첫 질문이 저장 구조 판단으로 바로 이어지게 정리했다.
- 정리 반영: 사례 요약 뒤에 `바로 적용해 보면` 블록을 추가해, 초심자가 벡터 데이터베이스를 `벡터만 찾는 곳`이 아니라 `원문`과 `메타데이터`까지 함께 돌려주는 검색 저장 구조로 바로 점검해 읽도록 보강했다.; `바로 적용해 보면`과 실무 질문에 `질문 표현과 문서 표현이 달라도 같은 의미 문단이 실제 벡터 후보로 올라오는가`를 먼저 묻는 행을 덧붙여, `왜 텍스트만이 아니라 벡터를 저장하는가`라는 축이 초심자 첫 질문까지 직접 내려오도록 보강했다.; 예제 결과 뒤에 `refund/settings/api` 질문을 각각 `정책 공지 회수`, `매뉴얼 회수`, `SDK 가이드 회수` 장면으로 다시 묶는 표를 덧붙여, 초심자가 각 query를 어떤 검색 장면으로 읽어야 하는지 더 빨리 붙잡게 했다.; 사례와 `바로 적용해 보면`에 남아 있던 `초심자가 ...` 독자 표지를 `여기서 바로잡아야 할 오해`, `자주 생기는 오해` 중심 표현으로 낮춰, 저장 구조 설명이 메타 독자 안내보다 회수 기준과 원문·메타데이터 판단에 더 직접 붙게 다듬었다.
- 번역 동기화 메모: Future translations should preserve the new handoff block that distinguishes storage role from later execution layers.
