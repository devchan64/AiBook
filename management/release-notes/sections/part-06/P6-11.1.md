## v2026.07.22

- 변경 이유: Part 6 본문에서 진행 메타형 소제목을 구체 개념, 비교 대상, 판단 기준이 드러나는 제목으로 정리하기 위함.
- 본문 반영: `여기서 남겨야 할 구분`, `여기까지를 한 줄로 묶으면`, `보는 순서`, `이 예제를 ... 다시 보면` 계열 제목을 현재 절의 실제 구분 축과 설명 흐름이 보이는 소제목으로 바꾸었다.
- 본문 반영: Python 예제를 하드코딩된 키워드·정답 점검에서 `TfidfVectorizer` 기반 미니멀 검색 모델과 CSV 입력 자산을 사용하는 구조로 바꾸어, RAG가 답변 전에 근거 문서를 실제로 고르는 흐름을 보여 주도록 개선했다.
- 본문 반영: CSV 입력 설명을 한 문단에서 파일별 목록과 핵심 열 설명으로 나누어, 질문 목록과 문서 후보의 역할이 먼저 보이도록 가독성을 개선했다.
- 본문 반영: `current_signal` 포함 여부가 유일한 성공 기준처럼 보이지 않도록 판정 이름을 보조 신호 중심으로 바꾸고, 상위 문서의 질문 주제 일치·현재 버전·유사도·근거 연결 준비 여부를 함께 출력하도록 조정했다.
- 본문 반영: 검색 후보에 맞는 현재 문서가 없는 `pricing` 질문을 추가해, 문서 두 개가 검색되더라도 주제와 버전이 맞지 않으면 RAG 근거 연결이 실패한다는 경계 사례를 보강했다.
- 본문 반영: Python 예제 아래 출력 블록을 실제 실행 결과로 읽히게 문구를 조정하고, `pricing` 실패 사례까지 포함한 출력 결과를 본문에 유지했다.
- 자산 반영: `rag-grounding-check-ko.png` / `rag-grounding-check-en.png` 그래프를 사례별 통과 매트릭스에서 상위 검색 문서 유사도 막대그래프로 바꾸어, `pricing` 사례가 낮은 유사도의 보관 문서를 잡아 근거 재검토로 남는 흐름을 보이도록 했다.
- 번역 동기화 메모: 향후 번역본도 진행 안내형 제목보다 현재 절의 구체 개념, 비교 대상, 판단 기준이 보이는 소제목으로 맞춘다.
- 번역 반영 상태: 한국어 원문만 수정했다.
- 원문 기준 버전: `v2026.07.22`

## v2026.07.21

- Part 6 개편 기준에 따라 Section ID, 파일 위치, 제목을 새 목차 구조에 맞춰 재정렬했다.
- 생성형 AI 산출물에서 시작해 LLM을 대표 사례로 읽는 흐름 안에서 이 Section의 위치를 다시 잡았다.
- RAG를 긴 프롬프트 작성 요령이 아니라 답변 전에 외부 근거 문서를 연결하는 구조로 읽도록 도입부와 판단 표를 정리했다.
- 프롬프트 조정, RAG 근거 연결, tool use 실행 연결의 층위를 분리해 후속 검색·실행 구조와 자연스럽게 이어지도록 문장을 보강했다.
- P6-11.1 전용 RAG 도식과 근거 점검 차트를 chapter-11 자산 경로로 분리하고, 후속 Section 연결 번호를 현재 목차에 맞게 정리했다.
- 개편 전 릴리즈노트 원문은 `management/authoring/archive/part-06-before-restructure-2026-07-21/management/release-notes/sections/part-06/`에 보존했다.
- `바로 적용해 보면` 제목을 근거 연결이 필요한 장면으로 바꾸어 RAG를 질문 표현보다 답의 재료를 현재 문서로 고르는 구조로 읽게 정리했다.
- 제목을 `RAG는 왜 답변 전에 외부 근거를 붙이는가`로 바꾸고, 도입부의 반복 표를 문단으로 압축해 답의 출발점이 모델 기억에서 문서 근거로 이동한다는 중심축을 더 선명하게 했다.
- 도입부의 RAG 경계 설명 반복을 줄여, 중심축을 `답하기 전에 어떤 문서를 먼저 붙일 것인가`로 고정했다.
