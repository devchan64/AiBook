# Section Release Note

- Section ID: `P6-1.3`
- Source File: `docs/parts/part-06/chapter-01/section-03.md`

### v2026.07.19
- 연습 보강: 기존 표 재진술형 연습을 `순서 차이 찾기`, `같은 토큰의 위치 읽기`, `출력 토큰 누적 추적하기`의 세 연습으로 교체해 독자가 먼저 판단하고 바로 해설과 대조하게 했다.
- 사례 정리: 세 사례를 가이드라인의 `문제 장면 -> 사람이 쓰던 기준 -> 기준의 한계 -> 순서열 관점 -> 확인 가능한 결과` 흐름에 맞춰 다시 정리했다.
- 사례 보완: `환불 가능/불가능`, 반복되는 `회의`, 입력 뒤 출력 토큰 누적 사례의 표를 같은 판독 구조로 맞추고, 각 사례 마지막에 더 안전한 판단 기준을 명시했다.
- 근거 정리: OpenAI Help Center의 토큰 처리 흐름, OpenAI `tiktoken` README, Jurafsky & Martin `Speech and Language Processing` 2026 초안 링크를 출처에 반영해 토큰 ID 순서열과 출력 토큰 누적 설명의 근거를 확인 가능한 문서 단위로 좁혔다.

### v2026.07.18
- 학습밀도 보강: 토큰 ID 순서열을 `ID`, `순서`, `위치`, `앞뒤 문맥`으로 나눠 읽는 표를 추가해, 순서열 설명이 직관 문장에 머물지 않도록 보강했다.
- 사례·연습 보강: `환불 가능/불가능`을 단순화한 ID 순서로 다시 보여 주고, 반복 토큰의 위치 차이와 출력 토큰 누적 과정을 표로 보강해 모델 입력 판독 기준을 더 촘촘하게 만들었다.
- 중심축 재정렬: P6-1.3이 비용·한도·청크 판단 절로 기울어 P6-1.1과 P6-1.5를 반복하던 문제를 고치고, P6-1.2의 토큰 정의에서 P6-1.4의 토큰화 절차로 넘어가는 다리로 다시 썼다.
- 제목 조정: 제목을 `토큰은 모델 입력에서 어떻게 쓰이나`로 바꾸고, 중심 질문을 `모델은 토큰을 어떤 순서의 입력으로 받는가`로 고정했다.
- 사례 교체: 비용과 context window 사례를 걷고, `환불 가능/불가능`, 반복되는 `회의`, 입력 뒤에 출력 토큰이 이어지는 장면으로 바꿔 토큰이 순서열의 자리로 쓰인다는 점을 보이게 했다.
- 연습 보강: 연습 표를 `장면 -> 먼저 답해야 할 질문 -> 이유` 구조로 바꿔, 토큰화 규칙을 맞히기보다 토큰이 순서열의 한 자리로 쓰인다는 점을 확인하게 했다.
- 번역 동기화 메모: 대응 번역본이 생기면 제목, 중심 질문, 사례와 연습의 순서열 중심 구조를 함께 반영해야 한다.

### v2026.07.12
- 본문 반영: `P6-1.3`을 입력 길이, context window, 비용, 문서 분할, 출력 길이를 토큰 기준으로 읽는 사용 절로 다시 작성했다. `대표 토크나이저 계열 소개`와 비교 연습은 뒤 절로 분리하고, 이 절에는 운영 판단의 첫 기준만 남겼다.
