# Section Release Note

- Section ID: `P6-1.3`
- Source File: `docs/parts/part-06/chapter-01/section-03.md`

### v2026.07.12
- 본문 반영: `P6-1.3`을 입력 길이, context window, 비용, 문서 분할, 출력 길이를 토큰 기준으로 읽는 사용 절로 다시 작성했다. `대표 토크나이저 계열 소개`와 비교 연습은 뒤 절로 분리하고, 이 절에는 운영 판단의 첫 기준만 남겼다.
- 추가 반영: 재구성 뒤 운영 장면 설명이 얇아진 문제를 보완하기 위해, 긴 문서 입력, 비용 오판, 검색 청크 문제를 짧은 사례와 운영 메모 표로 다시 보강했다.
- 번역 동기화 메모: 대응 번역본이 생기면 `P6-1.3`은 종류 소개가 아니라 사용 장면을 닫는 절로 유지해야 한다.

### v2026.07.18
- 본문 반영: 사례 뒤에 `바로 적용해 보면` 표를 추가해, 긴 문서 입력·비용 오판·검색 청크 문제에서 `먼저 버릴 질문`과 `먼저 붙잡을 질문`을 토큰 기준으로 다시 읽게 했다.
- 추가 반영: 이 절의 적용 수준이 계산식 암기가 아니라 `장면마다 질문을 바꾸는 일`이라는 점을 명시해 초심자용 닫힘을 보강했다.
- 추가 반영: `이 절의 목표는`처럼 메타 진행을 드러내는 문장을 걷고, 길이와 비용 설명을 바로 `토큰 기준` 판단 문장으로 연결했다.
- 구조 보강: 기존 `작게 확인해 보면` 블록을 `연습 및 예제`로 재배치해, 사용 장면별 토큰 질문 전환이 체크리스트 전에 적용 연습으로 닫히게 했다.
- 중심축 정리: P6-1.3의 역할을 `토큰 수를 길이·비용·문맥 예산 판단에 쓰는 법`으로 좁히고, P6-1.4의 토큰화 절차 설명과 P6-1.5의 토큰화 결과 변화 설명을 앞당겨 쓰지 않도록 도입·소제목·닫힘을 정리했다.
- 연습 보강: 연습을 질문 확인표에서 `전체 입력 토큰 길이와 context window`, `입력·출력 토큰 수`, `chunk size와 overlap` 중 먼저 조정할 판단값을 고르는 형식으로 바꿨다.
- 사례 재보강: 사례가 일반 장면 설명에 머물던 문제를 줄이고, 입력 7,600 토큰과 context window 8,192 토큰, 출력 1,200 토큰, chunk size 500 토큰 같은 작은 관찰값을 넣어 `토큰 수가 보이면 어떤 판단값을 먼저 바꾸는가`가 드러나게 했다.
- 연습 재보강: 연습 표도 `관찰한 값 -> 먼저 조정할 판단값 -> 이유` 구조로 바꿔, 사례와 같은 중심축으로 닫히게 했다.
- 번역 동기화 메모: 대응 번역본이 생기면 적용 표의 질문 전환 구조도 같이 유지해야 한다.
