- 가이드라인 반영: 직관 위주 연습은 비코드로 닫을 수 있지만 P6-2.4는 `coarse_window` 값 변화에 따른 후보 수와 누락 차이를 확인해야 하므로 실험형 Python 예제를 유지한다는 판단 근거를 본문에 명시했다.
- 순서 정리: `연습 및 예제` 구간을 실행 전 예상 연습 -> Python 실험 예제 -> 출력 해석과 운영 판단 연습 순서로 재배치해, 예제가 답을 먼저 보여 주기보다 중심축을 예상하고 검증하게 했다.
- 본문 재배치: 본문 메타데이터 버전을 `v2026.07.19`로 맞추고, `연습 및 예제` 구간을 실행 전 예상 연습, Python 실험 예제, 출력 해석과 운영 판단 연습으로 나누어 흐름이 순서대로 보이게 정리했다.
- 연습/예제 가이드라인 정리: Python 예제를 실험형으로 명시하고 `full_top5`, `candidates`, `recall@5`, `missed`의 관찰 목적을 표로 보강했으며, `coarse_window` 값을 바꿨을 때 후보 누락과 비교 후보 수가 어떻게 달라지는지 묻는 연습을 추가했다.
- Python 예제 적합성 보강: P6-2.4의 Python 예제를 `coarse_window` 값을 바꿔 완만한 후보 축소와 공격적인 후보 축소를 비교하는 실험형 예제로 조정해, 속도 이득과 후보 누락을 함께 관찰하게 했다.
- 사례 중심축 보강: FAQ 규모 변화, 문서 수 증가, 공격적인 ANN 설정 사례를 `사람이 먼저 보는 기준 -> 기준의 한계 -> ANN이 바꾸는 판단 -> 확인할 결과` 표로 닫아, 빠른 후보 탐색이라는 보충학습 중심축을 직접 지지하게 했다.
- 연습 해설 보강: 전수 비교와 빠른 후보 축소의 실행 결과 예시를 추가하고, 비교 후보 수·ANN 핵심 감각·속도 이득과 후보 누락·`coarse_window` 조정 효과를 해설하는 연습 5개로 정리했다.
- 추가 반영: 체크리스트 직전의 반복 요약 표를 줄이고, 탐색 비용과 후보 누락을 함께 보라는 마지막 판단 문장으로 압축했다.
- 근거 정리: 본문 Python 예제 출력을 로컬 `.venv`에서 재검산하고, Arya et al. 1998, Malkov & Yashunin 2016 링크와 확인 날짜를 2026-07-19 기준으로 갱신해 ANN 근사 탐색 설명의 근거를 좁혔다.
