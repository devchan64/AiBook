### v2026.07.17

- 번역 동기화 메모: Future translations should preserve the scope handoff where P6-15.2 closes the evaluator split first and hands service-operation consequences to P6-16.

### v2026.07.18
- 본문 반영: 평가 축을 세운 뒤에도 왜 자동 게이트와 사람 검토 분업이 더 필요해지는지 먼저 보이게 하려고, `지금 부족한 것 -> 이번 장이 붙이는 구조 -> 아직 남는 문제 -> 바로 이어지는 위치` 비교 블록을 추가했다.
- 본문 반영: `이 절은 다음 질문에 답합니다` 문장을 `이 절에서 먼저 붙잡을 질문`으로 바꿔, 평가 분업 장의 도입 톤을 더 자연스럽게 낮췄다.
- 추가 반영: `이 절은 Part 6에서 ...` 같은 메타 서술을 더 직접적인 설명 문장으로 바꿔, 평가 분업 기준이 바로 읽히게 정리했다.
- 추가 반영: `지금 읽는 층위는`으로 절의 역할을 다시 말하던 문장을 줄이고, 평가 축에서 분업 판단으로 넘어가는 질문이 바로 보이도록 연결을 더 직접적으로 다듬었다.
- 번역 동기화 메모: Future translations should preserve the new comparison block that separates evaluator split from later service-constraint and failure-routing decisions.

### v2026.07.11
