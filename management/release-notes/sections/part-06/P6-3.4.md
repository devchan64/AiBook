# Section Release Note

- Section ID: `P6-3.4`

### v2026.07.18
- 본문 반영: 기존 `P6-3.3`에서 분리했던 `KV cache, sparse attention, long-context` 묶음도 다시 나누어, 현재 절은 `KV cache` 단독 보충학습으로 다시 좁혔다.
- 추가 반영: 현재 절은 `같은 결과를 유지하면서 무엇을 다시 계산하지 않을 것인가`라는 질문에 집중하도록 범위, 사례, Python 예제를 모두 KV cache 중심으로 다시 정리했다.
- 추가 반영: 같은 날짜 재수정에서 `재사용 장치`라는 정의를 더 생활 장면으로 풀어, 긴 대화·긴 코드 생성·긴 문서 초안 수정에서 왜 `이미 본 앞부분을 새 토큰마다 또 계산하는가`가 핵심 질문이 되는지, context window가 길어질수록 왜 체감 차이가 커지는지, KV cache가 막으려는 실패 장면이 무엇인지 초심자 기준 문단과 비교표로 보강했다.
- 추가 반영: 제목 아래 `Section ID`, `Version` 표기를 저장소 규칙 형식으로 바로잡았다.
- 번역 동기화 메모: 대응 번역본이 생기면 현재 절을 KV cache 단독 보충학습으로 읽히게 맞추고, sparse attention과 long-context는 새 `P6-3.5`로 분리한 구조를 함께 반영해야 한다.
