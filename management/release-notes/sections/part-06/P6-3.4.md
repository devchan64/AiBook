## v2026.07.24

- 변경 이유: ANN 절충 예제가 수작업 거리 계산 중심이라 실제 검색 라이브러리의 기준선과 축소 후보 비교 감각이 약했기 때문.
- 본문 반영: `scikit-learn`의 `NearestNeighbors`로 전수 기준 상위 후보를 만들고, `coarse_window`로 줄인 후보에도 같은 검색 API를 적용하도록 Python 예제를 갱신했다.
- 출력 반영: 유클리드 거리 기준의 `full_top5` 출력값을 본문 실행 결과와 맞추고, 후보 수와 `recall@5` 해석은 기존 절충 설명과 이어지게 유지했다.
- 자산 반영: `p6_3_4_ann_window_tradeoff_chart.py`도 `NearestNeighbors` 기반으로 후보 수와 `recall@5`를 다시 계산하게 했다.
- 번역 동기화 메모: 향후 번역본도 ANN 인덱스 구현이 아니라 검색 API 기준선과 후보 축소 절충을 비교하는 예제로 설명한다.
- 번역 반영 상태: 한국어 원문과 공용 차트 스크립트만 수정했다.
- 원문 기준 버전: `v2026.07.24`
