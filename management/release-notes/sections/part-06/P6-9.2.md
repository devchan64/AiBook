## v2026.07.24

- 변경 이유: Python 예제의 후보명이 `direct_but_risky`, `balanced`처럼 결과 해석을 미리 담고 있어 정렬 판단을 실험하기보다 정답지를 다시 확인하는 구조로 보일 수 있었기 때문.
- 본문 반영: 후보 응답 CSV를 36행 응답 로그로 늘리고, 응답 ID를 중립형으로 바꾸어 작업별 통과·탈락 수, 실패 축, 겉보기 점수는 높지만 정책 기준에서 탈락한 응답을 출력하도록 바꾸었다.
- 자산 반영: `p6_9_2_alignment_axis_chart.py`가 같은 CSV를 읽어 후보 유형 평균이 아니라 작업별 통과·탈락 분포와 안전성·사실성·겉보기 상위 탈락 실패 축을 그리도록 재작성했다.
- 차트 반영: `alignment-axis-average-ko.png` / `alignment-axis-average-en.png`를 통과·탈락 분포와 실패 축 비교 그래프로 다시 생성했다.
- 정합성 반영: 겉보기 상위 기준을 `surface_score_threshold = 4`로 분리하고, 실패 축 그래프가 중복 집계된 실패 신호 수임을 본문과 차트 축 라벨에 명시했다.
- 예제 보강: Python 예제 출력에 `response phrase signals` 블록을 추가해, 응답 전체 점수만 보지 않고 출력 안의 위험 표현, 안전 경로, 판단 조건 신호가 어떤 축으로 읽히는지 확인하게 했다. 실제 토큰 선택과 샘플링에 따른 안정성, 다양성, 재현성 문제는 디코딩과 샘플링 절의 중심 질문으로 분리했다.
- 해설 보강: `axis misses`가 응답 개수가 아니라 축별 실패 신호의 중복 집계라는 점을 실행 결과 해설 쪽에도 고정하고, 직접 위험 문구가 없어도 필요한 조건과 안전 경로가 빠진 응답은 탈락할 수 있음을 `code_r05` 사례로 보강했다.
- 번역 동기화 메모: 향후 번역본은 동일 CSV 구조를 유지하되, 언어별 차트 라벨은 `-ko`, `-en` 파일에서 분리 관리한다.
- 번역 반영 상태: 한국어 원문과 공용 자산만 수정했다.
