- 본문 반영: `여기서 남겨야 할 구분`, `여기까지를 한 줄로 묶으면`, `보는 순서`, `이 예제를 ... 다시 보면` 계열 제목을 현재 절의 실제 구분 축과 설명 흐름이 보이는 소제목으로 바꾸었다.
- 본문 반영: Python 예제 앞에 학습 문장 묶음의 입력 표와 n-gram 축소 모델 주의를 추가해, 입력 데이터가 어떤 후보 분포를 만들도록 설계되었는지 먼저 읽을 수 있게 했다.
- 본문 반영: 긴 실행 결과 뒤에 프롬프트별 첫 후보 분포, 선택된 첫 토큰, 뒤 생성 경로를 요약하는 표를 추가했다.
- 본문 반영: 모든 후보 확률이 0.5로 동일해 요약 표보다 학습 기여가 낮은 첫 후보 분포 그래프를 본문에서 제거했다.
- 번역 동기화 메모: 향후 번역본도 진행 안내형 제목보다 현재 절의 구체 개념, 비교 대상, 판단 기준이 보이는 소제목으로 맞춘다.
- 번역 반영 상태: 한국어 원문만 수정했다.
- 원문 기준 버전: `v2026.07.22`
