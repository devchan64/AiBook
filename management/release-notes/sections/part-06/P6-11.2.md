- Part 6 개편 기준에 따라 Section ID, 파일 위치, 제목을 새 목차 구조에 맞춰 재정렬했다.
- 생성형 AI 산출물에서 시작해 LLM을 대표 사례로 읽는 흐름 안에서 이 Section의 위치를 다시 잡았다.
- RAG 예제 CSV를 단순 반복 행에서 관련 문서, 경계 문서, 무관 문서, 정상 검색, 검색 오염, 생성 과장이 구분되는 입력 데이터로 개선했다.
- 검색 결과와 생성 결과를 한 덩어리로 보지 않고 검색 실패와 생성 실패를 따로 읽는 기준이 드러나도록 도입부, 적용 표, 예제 해설을 정리했다.
- CSV 기반 예제 설명을 실제 열 구조와 연결해 `검색어`, `문서 역할`, `정상 검색`, `검색 오염`, `생성 과장`이 코드 출력에서 어떻게 갈라지는지 읽을 수 있게 보강했다.
- CSV 보조열을 `source_role`, `scenario_pattern`, `reader_hint`로 정리해 최종 판정을 미리 주기보다 검색어·문서 역할·생성 스타일을 관찰하게 다듬었다.
- P6-11.2 RAG CSV, 도식, 실패 분리 차트를 chapter-11 전용 이름으로 분리하고 본문 코드와 csv-preview 링크를 새 경로로 맞췄다.
- 개편 전 릴리즈노트 원문은 `management/authoring/archive/part-06-before-restructure-2026-07-21/management/release-notes/sections/part-06/`에 보존했다.
- `바로 적용해 보면` 제목을 검색 실패와 생성 실패가 갈리는 장면으로 바꾸어 RAG 점검의 두 단계 분리 기준이 더 직접 보이게 정리했다.
- RAG 실패 예제의 CSV 안내 문단을 문서 파일 설명과 실험 파일 설명으로 나누어 검색 실패와 생성 과장 관찰 기준이 덜 압축되게 했다.
