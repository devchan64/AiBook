- 본문 반영: 사례·적용 표에 남아 있던 `초심자가 ...` 표지를 더 줄여, 사실 정확성과 요청 형식 준수의 차이가 독자 라벨보다 응답 습관 차이로 먼저 읽히게 다듬었다.; `Part 6에서 ... 첫 상세 설명은 이 절에서 잡습니다`, `이 절은 Part 6에서 ...` 같은 위치 설명형 메타 문장을 걷고, `같은 생성 구조가 어떤 응답 습관을 갖게 되는가`가 바로 보이도록 도입부를 더 직접적으로 정리했다.; `## 이 절의 범위`, `## 이 절의 목표`, `## 이 절을 읽는 순서` 같은 메타 제목을 `응답 습관 조정이 다루는 질문`, `여기서 남겨야 할 구분`, `조정 축을 보는 순서`로 바꿔, 지시 튜닝의 위치 설명보다 `무엇을 말할까/어떻게 답할까` 조정 문제가 먼저 보이게 정리했다.; 제목 아래 `Section ID`, `Version` 표기를 저장소 공통 형식에 맞춰 blockquote 대신 일반 메타데이터 줄로 정리했다.
- 추가 반영: 사례 요약 뒤에 `바로 적용해 보면` 표를 추가해, 초심자가 `핵심 사실은 맞지만 세 줄 형식을 자주 어기는 장면`, `설명 내용은 맞는데 단계 수와 전개 순서가 흔들리는 장면`, `할 수 없는 요청에도 끝까지 답을 이어 가는 장면`을 볼 때 무엇을 `지시 형식 조정`, `응답 구조 조정`, `거절·한계 고지 습관 조정` 문제로 먼저 읽어야 하는지 바로 점검하게 했다.; `바로 적용해 보면`에 `형식은 맞지만 최신 규정이나 근거 사실이 자주 틀리는 장면`을 덧붙여, `지시 튜닝 문제`와 `새 지식·근거 연결 문제`를 초심자 첫 질문에서 먼저 가르도록 보강했다.; 지시 튜닝을 `새 지식 추가`가 아니라 `무엇을 말할까`와 `어떻게 답할까`를 가르는 응답 습관 조정층으로 다시 붙잡는 직접 적용 닫힘을 보강했다.
- 정리 반영: 도입부의 `이 절은 ...`, `학습 후 조정 층위`, `assistant-like ... 축` 같은 메타 문장을 줄이고, `같은 생성 구조가 어떤 응답 습관을 갖게 되는가`가 먼저 보이도록 정리했다.; 본문 중간의 `assistant-like behavior` 표현을 `대화형 조수 같은 반응` 중심으로 바꿔, 영어식 작업 메모보다 독자용 설명이 먼저 보이도록 다듬었다.; `이 절이 맡는 역할`, `초심자가 여기서 ...` 같은 해설 표지를 줄이고, 사실성 문제와 응답 형식 문제를 어디서 가를지 본문 문장 자체로 보이게 다듬었다.
