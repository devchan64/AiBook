## v2026.07.24

- 변경 이유: 기존 Python 예제가 키워드와 단어 겹침 규칙으로 이해 중심 태스크를 흉내내어, BERT 계열 표현 모델의 `읽은 입력 -> 판단값` 흐름보다 규칙 실패 분석으로 읽힐 수 있었기 때문.
- 본문 반영: CSV 기반 예제를 TF-IDF 벡터 표현과 cosine similarity를 사용하는 구조로 바꾸고, 분류·문장쌍·검색 랭킹이 모두 라벨·점수·순위 같은 판단값을 낸다는 점을 더 직접 보이게 했다.
- 그래프 반영: `understanding-output-types` 그래프를 고정값이 아니라 P6-20.2 CSV에서 태스크별 사례 수와 출력 형식별 등장 수를 계산해 그리도록 바꾸었다.
- 근거 반영: 예제에서 사용하는 scikit-learn `TfidfVectorizer`, `cosine_similarity` 공식 문서 출처를 추가했다.
- 번역 동기화 메모: 향후 번역본도 규칙 기반 예제보다 로컬 재현 가능한 벡터 표현 예제로 맞춘다.
- 번역 반영 상태: 한국어 원문과 공용 그래프 생성 스크립트, 한국어·영어 그래프 자산을 수정했다.
- 원문 기준 버전: `v2026.07.24`
