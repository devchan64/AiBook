## v2026.07.22

- 변경 이유: Part 6 본문에서 진행 메타형 소제목을 구체 개념, 비교 대상, 판단 기준이 드러나는 제목으로 정리하기 위함.
- 본문 반영: `여기서 남겨야 할 구분`, `여기까지를 한 줄로 묶으면`, `보는 순서`, `이 예제를 ... 다시 보면` 계열 제목을 현재 절의 실제 구분 축과 설명 흐름이 보이는 소제목으로 바꾸었다.
- 본문 반영: Section 제목과 도입 질문을 기술 선택보다 실패 원인 진단 중심으로 바꾸어, `형식`, `근거`, `실행`, `지속 적응` 중 무엇이 부족한지 먼저 나누는 전환 절로 재정렬했다.
- 본문 반영: P6-9.4와 P6-9.5를 파인튜닝 축으로 판단이 갔을 때 이어지는 효율적 조정 보충학습으로 연결하고, 프롬프트·RAG·도구 사용의 세부 설명은 다음 Module에서 본격화된다는 경계를 보강했다.
- 본문 반영: Python 예제에 복합 실패 사례와 2순위 보강 경로 출력을 추가하고, 해결 수단 점수 그래프와 도식을 부족 신호별 보강 경로 중심으로 갱신했다.
- 본문 반영: Python 예제의 내부 신호명을 `knowledge`에서 `evidence`로 바꾸어 본문의 `근거` 축과 맞추고, 점수가 실제 자동 선택 결과가 아니라 진단 연습용 가중치라는 해설을 보강했다.
- 본문 반영: `형식`, `근거`, `실행`, `지속 적응`이 서로 다른 손댈 위치라는 점을 예시와 비교표로 풀고, Python 예제 전에 손으로 먼저 부족 신호를 표시하는 흡수구간을 추가했다.
- 본문 반영: 애매한 실패 기록을 요구, 실제 답의 어긋남, 1순위 보강, 남는 2순위 문제로 쪼개는 판정 순서를 추가하고, 복합 실패 장면을 직접 표시한 뒤 해설과 대조하는 연습을 보강했다.
- 본문 반영: `프롬프트를 먼저 볼 때`, `RAG를 붙여야 할 때`처럼 수단을 앞세우던 소제목을 `형식 신호`, `근거 신호`, `실행 신호`, `지속 적응 신호` 중심으로 바꾸어 실패 원인 진단축을 강화했다.
- 본문 반영: 사례와 예제 해설에 남아 있던 `붙인다`, `해결 수단 선택` 계열 표현을 `근거 연결`, `실행 신호`, `보강 경로`, `부족 신호 진단` 중심 문장으로 정리했다.
- 번역 동기화 메모: 향후 번역본도 진행 안내형 제목보다 현재 절의 구체 개념, 비교 대상, 판단 기준이 보이는 소제목으로 맞춘다.
- 번역 반영 상태: 한국어 원문만 수정했다.
- 원문 기준 버전: `v2026.07.22`
