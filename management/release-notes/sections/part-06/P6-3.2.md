### v2026.07.18
- 본문 반영: `초심자가 자주 하는 실수`, `초심자가 실제 실패 장면`, `초심자가 먼저 기대하기 쉬운 것` 같은 라벨을 줄여, context window와 attention을 어떤 실패 질문으로 가를지가 직접형 설명으로 먼저 보이게 다듬었다.; `커리큘럼 관점에서 이 절에서 확인해야 할 결과는 ...` 같은 안내 문장을 `이 절에서 확인해야 할 결과는 ...`로 낮춰, context window 제약이 실제 입력 선택 문제로 이어지는 축이 집필 안내보다 먼저 보이게 정리했다.; `## 이 절의 범위`, `## 이 절의 목표`, `## 이 절을 읽는 순서` 같은 메타 제목을 `입력 범위 제약이 다루는 질문`, `여기서 남겨야 할 구분`, `범위와 선택을 보는 순서`로 바꿔, 안내문보다 context window 제약과 attention 역할 구분이 먼저 보이게 정리했다.
- 추가 반영: Chapter 3 보충학습을 둘로 나누면서, 긴 문맥 보강 장치 회수 위치를 기존 `P6-3.3` 단일 참조에서 새 `P6-3.4` 참조로 갱신했다.; 같은 날짜 재수정에서 긴 문맥 보강 handoff를 `P6-3.4 KV cache`, `P6-3.5 sparse attention/long-context` 두 갈래로 다시 세분화했다.; `## 바로 적용해 보면` 표를 추가해, 초심자가 긴 문서 요약·코드 도우미·대화형 챗봇 장면에서 `윈도우 안에 무엇이 남았는가`와 `남은 범위 안에서 무엇이 더 중요했는가`를 먼저 가르게 했다.
- 정리 반영: 도입부의 `이 절은 ...`, `입력 범위 제약 축` 같은 메타 문장을 줄이고, `입력 범위가 먼저 제한되고 attention은 그 안에서만 작동한다`는 핵심이 먼저 보이도록 정리했다.; 제목 아래 `Section ID`, `Version` 표기를 저장소 규칙 형식으로 바로잡았다.; 사례 해설에 남아 있던 `초심자가 ...` 독자 표지를 `이 표가 바로잡는 오해`, `중요한 기준` 중심 표현으로 낮춰, context window 설명이 메타 독자 안내보다 입력 선별 기준에 더 직접 붙게 다듬었다.
- 번역 동기화 메모: 대응 번역본이 생기면 같은 독자 라벨 축소와 긴 문맥 보강 handoff도 `P6-3.4 KV cache`, `P6-3.5 sparse attention/long-context`의 두 갈래 구조로 함께 맞춰야 한다.
