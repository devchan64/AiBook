## v2026.07.24

- 변경 이유: Part 6 Python 예제 개선 방안에 따라 가까운 벡터 후보와 최종 근거 후보의 차이를 실제 검색 출력으로 확인하게 하기 위함.
- 본문 반영: `TfidfVectorizer`와 cosine similarity로 top-k 후보를 만들고, 최신성·예외 조건 메타데이터를 함께 보아 최종 근거 후보를 분리하는 Python 예제를 추가했다.
- 본문 반영: 의존성 추가 가능 조건에 맞춰 Ollama `nomic-embed-text`를 사용하는 선택 실행 예제를 보강하고, 실제 로컬 실행 출력으로 embedding 후보와 최종 근거 후보를 다시 구분하게 했다.
- 본문 반영: 수동 거리 표는 준비 관찰로 압축하고, TF-IDF 기준선과 Ollama embedding 출력의 순위 차이를 비교하는 연습으로 재구성했다.
- 본문 반영: 실제 embedding 모델에서도 무관하거나 약한 후보가 높은 유사도로 함께 올라올 수 있음을 해설에 반영하고, 유사도와 최종 근거 확정을 분리해 읽도록 보강했다.
- 의존성 반영: `requirements.txt`에 `ollama==0.6.2`를 추가했다.
- 원문 기준 버전: `v2026.07.24`
