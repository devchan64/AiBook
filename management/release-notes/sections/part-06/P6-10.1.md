### v2026.07.18

- 체크리스트 정리: 체크리스트 안에 섞여 있던 요약 표, 전환 문단, 중복 요약 항목을 걷고 현재 Section 중심 질문을 닫는 자기 확인 항목만 남겼다.
- 본문 반영: `Part 6에서 ... 첫 상세 설명은 이 절에서 잡습니다`, `이 절은 Part 6에서 ...` 같은 위치 설명형 메타 문장을 걷고, `답의 출발점을 외부 근거 문서로 바꾸는 구조`가 바로 보이도록 도입부를 더 직접적으로 정리했다.; `커리큘럼 관점에서 이 절이 중요한 이유` 표지를 `이 절이 맡는 역할`로 낮춰, RAG 필요성 설명이 집필 안내보다 근거 연결 역할 중심으로 읽히게 정리했다.; `## 이 절의 범위`, `## 이 절의 목표` 같은 메타 제목을 `외부 근거 연결이 다루는 질문`, `여기서 남겨야 할 구분`으로 바꿔, 장의 역할 설명보다 `무엇을 외부 문서로 바꾸는가`가 먼저 보이게 정리했다.; `## 이 절을 읽는 순서`를 제거하고, 도입부에 `프롬프트 조정 문제 / RAG가 먼저 필요한 문제 / 문서를 봐도 실행·계산이 더 중요한 문제 / 검색 품질과 근거 기록을 함께 봐야 하는 문제`를 가르는 표를 넣어 초심자가 RAG를 붙이기 전에 먼저 배제할 장면을 바로 구분하도록 정리했다.; 제목 아래 `Section ID`, `Version` 표기를 저장소 공통 형식에 맞춰 blockquote 대신 일반 메타데이터 줄로 정리했다.
- 추가 반영: 도입부에 `지금 부족한 것 -> 이번 장이 붙이는 구조 -> 아직 남는 문제 -> 바로 이어지는 위치` 비교 블록을 추가해, Chapter 10이 `모델 기억 한계 -> 근거 연결 구조 -> 결합/저장 구조 확장` 흐름으로 읽히도록 고정했다.; 사례 요약 뒤에 `바로 적용해 보면` 블록을 추가해, 초심자가 정책·매뉴얼·SDK 문서 장면에서 프롬프트 조정 문제와 문서 근거 연결 문제를 바로 가르고 `최신 문서`, `현재 버전 매뉴얼`, `공식 예제`를 먼저 확인하도록 보강했다.; `바로 적용해 보면`과 점검 질문에 `사실관계는 맞지만 말투·표 형식만 아쉬운 장면`을 덧붙여, `새 문서 근거가 필요한가`와 `프롬프트/조정층 문제인가`를 초심자 첫 질문에서 바로 가르도록 보강했다.; 첫 비교표 아래에 `같은 재료를 더 잘 말하면 되는가`와 `재료 자체를 현재 문서로 다시 가져와야 하는가`를 먼저 가르는 문장을 넣어, 초심자가 RAG를 `문서가 보이면 일단 붙이는 기술`로 오해하지 않게 정리했다.
- 정리 반영: 도입부의 `이 절은 ...`, `손잡이`, `층위` 중심 문장을 줄이고, `답변을 만들기 전에 어떤 문서를 먼저 연결하는가`가 핵심 변화로 바로 드러나도록 정리했다.; 본문 중간 표 제목의 `먼저 바꿀 손잡이`를 `먼저 바꿀 초점`으로 바꿔, Chapter 10도 같은 용어 체계로 맞췄다.; `이 절이 맡는 역할` 같은 설명 밖 문장을 줄이고, 프롬프트 조정 문제와 근거 문서 연결 문제를 왜 갈라야 하는지가 본문 문장 자체로 보이게 다듬었다.; 세 사례에 남아 있던 `초심자가 ...` 독자 표지를 `여기서 바로잡아야 할 오해` 중심 표현으로 낮춰, RAG 필요성 설명이 메타 독자 안내보다 최신 근거 확인 기준에 더 직접 붙게 다듬었다.
- 추가 정리: 도입부의 `이 절에서는 다음 질문을 다룹니다`를 내용 중심 문장으로 낮추고, 남은 `초심자가 ...` 표지를 질문 경계와 최신 근거 확인 기준이 먼저 보이도록 다시 정리했다.
- 번역 동기화 메모: 대응 번역본이 생기면 같은 직접 적용 표와 질문 표를 함께 반영해야 한다.
