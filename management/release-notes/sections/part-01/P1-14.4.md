- 번역 반영 상태: 영어판 `v2026.07.20` 반영, 중국어 간체판 `v2026.07.20` 반영.

### v2026.07.19
- 변경 이유: MCP의 호스트·클라이언트·서버, 도구·리소스·프롬프트, 보안 주의점 설명의 공식 문서 근거를 현재 기준으로 다시 확인했다.
- 본문 반영: MCP 공식 문서 참고 자료 확인 날짜를 `2026-07-19`로 갱신하고 한국어 원문 `Version`을 `v2026.07.19`로 올렸다.
- 번역 반영 상태: 영어판 v2026.07.19 반영, 중국어 간체판 v2026.07.19 반영.
- 원문 기준 버전: `v2026.07.19`
- 저작권 검토: MCP 공식 문서는 호스트·클라이언트·서버와 도구 연결 개념의 재서술 근거로만 사용했고, 원문 문장·프로토콜 설명·목차 구조를 대체할 정도의 복제는 확인되지 않았다.
- 구조 정리: 한국어판, 영어판, 중국어 간체판의 `이 절의 범위`/`Scope of This Section`/`本节范围` 진행 메타 제목을 제거했다.
