# Section Release Note

- Section ID: `P1-1.1`
- Source File: `docs/parts/part-01/chapter-01/section-01.md`

### v2026.07.06

- 변경 이유: 초반 설명이 정의와 분류표 중심으로 흘러, 독자가 실제 장면에서 AI 범위를 어떻게 구분할지 바로 연습하기 어려웠고, 대표 상세 설명 위치로서 핵심 용어 요약과 도식 해설도 더 보강될 필요가 있었다.
- 본문 반영: `간단한 구분 연습` 표를 추가해 규칙 기반 심사, 추천 모델, 문서 요약 챗봇을 `입력-출력-판단 방식` 질문으로 비교하게 했고, `AI`를 Part 1의 대표 상세 설명 위치로 명시하며 핵심 용어 요약 표와 AI 범위 도식 해설 문단을 추가했다.
- 번역 동기화 메모: 이후 번역본도 같은 세 사례와 `입력/출력/판단 방식` 비교 구조, `분야/시스템/입력/출력/목표` 요약 구조, AI 범위 도식 해설을 유지해 첫 Section의 대표 설명 역할을 같은 방식으로 보존해야 한다.
- 번역 반영 상태: 번역본 없음
- 관련 자산: `docs/reference/concept-glossary.md`
- 원문 기준 버전: `v2026.07.06`
- 추가 정리: Section 본문 버전을 `v2026.07.06`으로 갱신했고, 같은 Part 안에서 `AI` 범위의 상세 정의는 이 Section를 대표 위치로 삼고 뒤 Section에서는 필요한 최소 연결만 남긴다는 원칙을 본문에 반영했다.
