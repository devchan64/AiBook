- 본문 반영: 특히 `LLM`, `BERT`, `GPT`, `대화형 LLM`, `BPE`, `비전 트랜스포머`, `레이어 정규화`, `배치 정규화`, `병렬 처리`, `넘파이`, `newaxis`, `노트북`, `드롭아웃`, `dtype`, `규칙 기반 시스템`, `강화학습`, `강화학습 에이전트`, `가상환경`, `고정 길이 벡터`, `게이트 순환 유닛`, `자료구조`, `벡터화`, `검색 증강 생성`, `검색 인덱스`, `그레이더`, `근거`, `환각`, `확률 모델`, `확률 추정값`, `Figure`, `Axes`, `groupby`, `Git` 등에서 `무엇을 뜻하는가`뿐 아니라 `무엇과 구분해야 하는가`, `왜 다음 Part 이해에 다시 등장하는가`를 더 분명히 적었다.
- 본문 반영: `브로드캐스팅`, `바운딩 박스`, `분산 표현`, `매핑`, `말뭉치`도 추가로 풀어 써서, 배열 축 정렬 해석 흐름, 검출과 분류 출력 구조 구분 흐름, 희소 기호와 연속 표현 구분 흐름, 표현 체계 변환 흐름, 학습 자료 성격과 모델 성향 연결 흐름을 더 선명하게 읽을 수 있게 했다.
- 본문 반영: `문장·문단·문서 임베딩`, `멀티헤드 어텐션`, `미세조정`, `LoRA`, `adapter`, `QLoRA`도 추가로 보강해, 긴 텍스트 단위 표현 해석 흐름, 다중 관계 시선 해석 흐름, 사전학습-적응 단계 구분 흐름, 효율적 조정 전략 비교 흐름을 더 또렷하게 연결했다.
- 본문 반영: `반복`, `셸`, `셸 스크립트`, `앱`, `옵티마이저`도 추가로 보강해, 반복 제어와 벡터화 대비 흐름, 명령 해석기와 터미널 구분 흐름, 운영 절차 자동화 해석 흐름, 모델-제품 경험 구분 흐름, gradient 방향과 업데이트 규칙 구분 흐름을 더 분명하게 읽을 수 있게 했다.
- 본문 반영: `WaveNet`, `YOLO`, `업무 자동화`, `언어 모델`, `정보 검색`도 추가로 보강해, 직접 계보와 주변 근거 구분 흐름, 검출 파이프라인과 end-to-end 예측 구분 흐름, 업무 단계 분해 기반 자동화 흐름, 언어 모델과 대화형 제품 구분 흐름, 검색과 생성 역할 분리 흐름을 더 또렷하게 연결했다.
- 본문 반영: 중복으로 남아 있던 `불리언 마스크` 블록도 정리해, 모델-제품-도구 층위 구분 흐름, 토큰 분절 기준 해석 흐름, 배치 통계와 위치별 정규화 구분 흐름, 이미지 패치 토큰화 해석 흐름, 행렬 중심 대량 계산 해석 흐름, 서비스형 대화 LLM 층위 해석 흐름, 배열 shape 조정 해석 흐름, 상호작용 문서 실행 상태 해석 흐름, 장기 보상과 연속 선택 해석 흐름, 서비스형 에이전트와 강화학습 에이전트 층위 구분 흐름을 더 안정적으로 연결했다.
- 번역 동기화 메모: 영어판 개념사전에도 이번에 보강한 모델·데이터·평가·검색·운영·도구 사용·기초 프로그래밍·기초 수학/통계 계열 표제어의 설명 밀도를 같은 수준으로 맞출 필요가 있다. 특히 `LLM`, `BPE`, `Vision Transformer`, `layer normalization`, `parallel processing`, `NumPy`, `np.newaxis`, `notebook`, `conversational LLM`, `dropout`, `dtype`, `rule-based system`, `reinforcement learning`, `reinforcement learning agent`, `virtual environment`, `fixed-length vector`, `GRU`, `search index`, `grader`, `retrieval-augmented generation`, `evidence`, `hallucination`, `Figure`, `Axes`, `groupby`, `Git` 주변의 구분 설명과 해석 흐름을 한국어판과 대응되게 반영해야 한다.
