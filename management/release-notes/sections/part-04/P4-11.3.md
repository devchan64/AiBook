# Section Release Note

- Section ID: `P4-11.3`
- Source File: `docs/parts/part-04/chapter-11/section-03.md`

### v2026.07.09

- 변경 이유: P4-11.1에서 언급된 log-odds, 최대우도추정(MLE), 다중 클래스, solver와 regularization이 후속 회수 없이 남아 있어, 초심자 기준 학습 경로를 닫는 보충학습이 필요했다.
- 본문 반영: 새 `P4-11.3 보충학습: 로지스틱 회귀를 한 단계 더 이해하는 법`을 추가해 log-odds, MLE, multinomial 확장, solver와 regularization의 입문 설명, 구조 요약 표, 상황 비교 표, 사례, Python 예제를 구성했다. 같은 날 재보강으로 `왜 이 네 주제가 한 묶음으로 따라오는가`, `one-vs-rest와 multinomial을 어떻게 읽는가`, `예제에서 무엇을 바로 비교해야 하는가`를 더 분명히 하는 표를 추가했고, 이어서 log-odds 유도 흐름, 이진 로그우도와 음의 로그우도 식, softmax 기반 multinomial 확률식, 다중 클래스 로그우도 합 형태, solver별 multinomial·penalty 지원 표, L1/L2/Elastic-Net regularization의 수식형 비교, solver 선택과 규제 해석 기준 문장, 확장 체크리스트까지 보강했다. 추가 검토에서는 사례 비교 프레임 표, 사례 판단 흐름 Mermaid, 예제 입력 표, 값을 바꿔 다시 볼 관찰 포인트를 더해 사례·예시·예제 원칙을 보강했고, 도식 관점 재검토로 사례 판단 흐름 Mermaid의 박스 문구를 더 짧게 줄여 압축 역할을 분명히 했다.
- 번역 동기화 메모: 향후 번역본에서도 `log-odds -> MLE -> 다중 클래스 -> solver/regularization`의 설명 순서와 예시 역할을 유지해야 한다.
