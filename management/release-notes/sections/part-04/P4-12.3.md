### v2026.07.09

- 변경 이유: Chapter 12 재구성안에 따라 `k-NN의 직관`, `거리와 스케일` 사이에 섞여 있던 적용/점검 가이드를 독립 Section으로 분리할 필요가 있었다.
- 본문 반영: `P4-12.3 k-NN을 사용할 때 무엇을 먼저 점검할까`를 새로 추가하고, k-NN을 먼저 후보로 올릴 조건, 거리/스케일 문제를 의심할 신호, `거리 규칙 -> k -> 데이터 표현` 점검 순서, 검토(review) query 해석 주의를 정리했다. 스케일/표현 문제를 의심할 때는 `P4-7.2 전처리(preprocessing)`로 돌아가 기준을 다시 확인하도록 연결 문장도 보강했다.
- 추가 반영: 같은 query를 끝까지 다시 읽는 표 아래에 `이웃 구성 -> k -> 거리 규칙 -> 스케일과 표현` 순서의 작은 점검 흐름과 Mermaid 도식을 더해, 적용/점검 절이 체크리스트에 머물지 않고 실제 해석 순서를 닫도록 보강했다.
- 번역 동기화 메모: 향후 번역본에서도 Chapter 12의 적용/점검 가이드를 별도 Section으로 유지하고, 전처리 일반론과 모델 선택 일반론으로 과도하게 넓어지지 않게 해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
