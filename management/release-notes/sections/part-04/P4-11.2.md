- 본문 반영: 도입부에 있던 후속 학습 연결을 세 갈래 보충학습 구조에 맞게 갱신해, `P4-11.3 log-odds와 MLE`, `P4-11.4 다중 클래스`, `P4-11.5 solver와 regularization`으로 이어지도록 정리했다. 같은 날 사례·예시·예제 관점의 재검토로 사례 비교 프레임 표, 사례 묶음 도식의 판단 순서 조정, Python 예제 입력 표와 값을 바꿔 다시 볼 관찰 포인트를 보강했다. 이어서 도식 관점 재검토로 1차원 경계, 2차원 경계, threshold 이동, 사례 묶음 Mermaid의 박스 문구를 줄여 경계 읽기 흐름이 더 빨리 들어오게 다듬었다. 추가 보강에서는 1차원 경계 도식을 `축 위의 순서`만 보여 주는 형태에서 `점수 증가 -> score 0.50 경계 -> class 전환`이 함께 보이는 형태로 다시 그려 이해를 직접 떠받치게 수정했고, 다시 한 번 Mermaid 구조를 재정리해 긴 LR 일렬 배치 대신 `class 0 side -> boundary -> class 1 side`의 세로 구조가 먼저 읽히게 바꿨다. 이어서 threshold 이동 도식도 `0.5 -> 0.7` 순서만 적는 형태에서 `같은 점수 축 -> 더 오른쪽 경계 -> 더 작은 class 1 영역`이 비교로 보이게 다시 구성했다. 사례로 보기 보강에서는 합격 예측, 고객 이탈, 의료 위험, 대출 심사, 스팸 분류마다 작은 입력 조합 표와 경계 해석 문장을 추가해 요약형 사례를 실제 판단 장면으로 다시 풀어 썼다. 추가 정리에서는 현재 MkDocs 수식 렌더링 형식에 맞게 이중 이스케이프된 블록 수식 구문을 바로잡았다. Section 버전을 갱신했다.
