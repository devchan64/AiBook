### v2026.07.08

- 변경 이유: 챗봇 경험에서 곧바로 `AI = LLM`으로 뛰는 오해를 사례 수준에서 더 빠르게 끊어 주는 시각적 흐름이 필요했다.
- 본문 반영: 사례 1 아래에 `도구 경험 -> LLM 동일시`와 `서비스 구조 분해 -> LLM은 한 구성요소`를 대비하는 Mermaid 도식을 추가하고 본문 버전을 갱신했다.
- 번역 동기화 메모: 향후 번역본에서도 LLM 경험을 AI 전체와 동일시하지 않도록 서비스 구성요소 분해 흐름을 같은 도식으로 유지해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.08`

### v2026.07.11

- 변경 이유: P4-1.1의 관계도와 서비스 흐름도는 좌표 정밀도보다 개념 관계가 중심이라, 외부 SVG 자산보다 본문 Mermaid 코드블록으로 유지하는 편이 수정과 검토에 더 유리했다.
- 본문 반영: `AI-머신러닝-딥러닝-생성형 AI-LLM` 관계도, 서비스 구성도, `AI = LLM` 오해 대비 도식을 모두 Mermaid로 다시 넣고 SVG 참조를 제거했다. / 같은 작업에서 말미 표지를 `체크리스트`로 통일하고 Section 버전을 갱신했다. / 이어서 한국어 본문에서 학습 흐름을 더 직접 읽을 수 있도록 Mermaid 노드 라벨도 한글 중심으로 다시 정리했다.
- 번역 동기화 메모: 한국어판은 다시 Mermaid 원본을 직접 쓰도록 바뀌었으므로, 영문·중국어 간체판도 동일한 Mermaid 구조를 기준으로 유지할지 추후 동기화 확인이 필요하다.
- 번역 반영 상태: 확인 필요
- 관련 자산: 기존 SVG 자산은 현재 보존 상태이며, 이번 버전의 기준 원본은 본문 Mermaid 코드블록이다.
- 원문 기준 버전: `v2026.07.11`
