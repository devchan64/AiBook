### v2026.07.09

- 변경 이유: 기존 `P4-11.3` 안의 solver와 regularization 설명은 구현 설정 설명의 성격이 강해, log-odds와 MLE 중심 흐름을 끊고 있었다. 같은 로지스틱 회귀라도 설정 차이를 비교 조건으로 읽게 하는 별도 보충학습이 필요했다.
- 본문 반영: 새 `P4-11.5 보충학습: solver와 regularization을 처음 읽는 법`을 추가했다. solver, penalty, `C`의 역할 표, scikit-learn 기준 solver 비교표, L1/L2/Elastic-Net 수식과 방향성 설명, 희소 텍스트 분류와 정형 표 데이터 사례, 설정 비교 기록용 Python 예제를 구성했다. 이어서 레포 원칙 재검토에 따라 solver 표가 특정 라이브러리 버전 설명이라는 점과 버전 재확인 필요를 본문에 명시했고, Python 예제에 실행 결과 예시를 추가했으며, `다루지 않는다` 문장 바로 뒤에 범위 밖 판단을 붙이고 `출처와 참고 자료`를 추가했다.
- 번역 동기화 메모: 향후 번역본에서도 solver와 regularization을 단순 옵션 나열이 아니라 `비교 조건`으로 읽게 하는 설명 방향을 유지해야 한다.
