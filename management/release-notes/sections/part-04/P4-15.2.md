### v2026.07.12

- 변경 이유: `연습 및 예제` 블록을 점검한 결과, Python 예제는 있었지만 독자가 `중요도 숫자를 어떻게 해석해야 하는가`를 직접 판단해 보는 연습이 약했고, 자기 확인 표지도 현재 저장소의 `체크리스트` 기준과 어긋나 있었다.
- 본문 반영: permutation importance 예제에 `baseline accuracy` 출력을 추가해 `기준 성능 -> 특징 섞기 -> 성능 흔들림 해석` 흐름이 더 직접 보이게 정리했다.
- 추가 반영: `직접 판단해 보기` 표를 `연습 및 예제` 안에 추가해, `MDI가 높다`, `permutation 값이 낮다`, `두 중요도 값이 다르다`는 관찰을 각각 어떤 문장으로 읽어야 안전한지 독자가 바로 점검하게 보강했다.
- 추가 반영: 절 말미 자기 확인 표지를 `짧은 점검`에서 `체크리스트`로 바꿔 현재 집필 규칙과 맞췄다.
- 번역 동기화 메모: 영어판과 중국어판에도 permutation example의 `baseline accuracy` 출력과 `직접 판단해 보기` 연습표, `체크리스트` 표지 정리가 같은 위치에 반영되어야 한다.
- 번역 반영 상태: 향후 번역 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.12`
- 추가 반영: 말미의 `이 절에서 기억할 관점`과 `언제 이 관점을 먼저 떠올려야 하는가`를 제거하고 `체크리스트` 하나로 통합했다. 중요도 해석 경계, MDI/permutation 차이, 상관 특성·high-cardinality 경계를 자기 점검 질문으로 다시 정리했다.

### v2026.07.10

- 변경 이유: 특징 중요도 절이 해석 경계는 설명하고 있었지만, 상관 특성과 낮은 중요도 해석에서 독자가 실제로 어떤 질문 순서로 판단해야 하는지와 생략된 주제의 현재 처리 상태가 충분히 드러나지 않았다.
- 본문 반영: `이 절의 범위` 아래 구조를 다시 정리해 `PDP`, `SHAP`, 인과 추론 관점, 강한 상관 특성의 해석 전략을 현재 절 안에서 어떻게 회수할지 명시했다.
- 본문 반영: 상관 특성이 importance를 어떻게 갈라 보이게 하는지 작은 표와 설명을 추가하고, `중요도 숫자를 보고 바로 무엇을 해야 하나`, `중요도가 높거나 낮을 때 바로 내리기 쉬운 잘못된 결론` 구간으로 해석 순서를 보강했다.
- 본문 반영: `중요도는 낮아 보이는데 왜 바로 지우면 안 될까` 사례와 `importance를 본 뒤 남기는 최소 해석 메모`를 추가해 `관찰 -> 경계 -> 비교 실험` 흐름을 더 분명히 했다.
- 추가 반영: `PDP와 SHAP는 중요도와 무엇이 다른가`, `중요도와 인과 추론은 왜 다른가`, `상관 특성이 매우 강한 실제 데이터에서는 어떻게 읽는가` 소절을 추가해 요청된 세 항목을 현재 절 안에서 직접 회수했다.
- 추가 반영: 문단 재배치 리포트 기준으로 중복되던 두 번째 `사례 및 예시` 표지를 하위 소제목으로 내려 사례 묶음이 하나의 연속 블록으로 읽히게 정리했다. 내용 추가 없이 구조 경계만 조정했다.
- 번역 동기화 메모: 향후 번역본에서도 `PDP/SHAP와 중요도의 질문 차이`, `중요도와 인과 해석의 경계`, `강한 상관 특성 데이터의 보수적 해석 전략`을 함께 유지해야 한다. 향후 번역본이나 다른 언어 원고가 생기면 같은 위치의 구조 표지도 `사례 및 예시` 축으로 맞춰야 한다.
- 번역 동기화 메모: 상관 특성 장면, 안전한 해석 문장, 후속 비교 실험 메모 구조도 같은 밀도로 유지해야 한다.
- 번역 반영 상태: 향후 반영 필요
