# Section Release Note

- Section ID: `P4-6.1`
- Source File: `docs/parts/part-04/chapter-06/section-01.md`

### v2026.07.19
- 근거 보강: 본문이 precision/recall의 정보 검색 평가 역사와 van Rijsbergen의 평가 논의를 언급하므로, C. J. van Rijsbergen의 `Foundation of Evaluation` 출처를 `출처와 참고 자료`에 추가하고 Section 버전을 갱신했다.
- Python 예제 점검: 모델별 accuracy, precision, recall 값이 이미 고정된 목록을 코드가 그대로 출력하던 블록은 실험형 예제로 보기 어렵다고 판단해, 같은 정확도에서 다른 오류 해석을 바로 비교하는 표로 대체했다.
- 번역 동기화 메모: 영어·중국어 간체 번역본을 갱신할 때도 정보 검색 평가 역사 단락과 출처 목록을 같은 기준으로 맞춰야 한다.

### v2026.07.12
- 본문 반영: 말미 구조를 `체크리스트` 하나로 통합하고, 정확도 한계, precision/recall/F1의 질문 차이, 혼동 행렬 선행 읽기를 자기 점검 질문으로 다시 정리했다. 같은 작업에서 Section 버전을 갱신했다.
- 번역 동기화 메모: 영어·중국어 간체 번역본도 말미의 회상/적용 시점 블록을 제거하고 한국어 원문과 같은 `Checklist` 단일 구조로 정렬했다. 중국어 간체 번역본의 개념사전 링크도 상대 경로로 바로잡았고, 번역본 버전을 `v2026.07.12`로 맞췄다.

### v2026.07.11
- 본문 반영: 이 Section의 Mermaid 도식을 `docs/assets/part-04/chapter-06/` 아래 외부 `.mmd` 자산으로 분리하고, 한국어 본문은 include 방식으로 참조하도록 정리했다. 영문·중국어 간체 본문도 같은 자산 패턴으로 동기화했다. 같은 작업에서 Section 버전을 갱신했다.
- 번역 동기화 메모: English and Simplified Chinese translations now use the same external `.mmd` asset pattern for the corresponding Mermaid diagrams in this section.
- 본문 반영: 평가 지표 선택 흐름, 혼동 행렬 흐름, 불량 검사 사례 도식의 보이는 라벨을 한국어로 바꾸고 Section 버전을 갱신했다.

### v2026.07.08
- 본문 반영: 불량 검사 사례 아래에 혼동 행렬에서 false alarm과 missed defect가 각각 precision, recall 판단으로 이어지는 Mermaid 도식을 추가하고 Section 버전을 갱신했다.
- 번역 동기화 메모: 향후 번역본에서도 오류 방향과 지표 선택의 연결 구조를 유지해야 한다.

### v2026.07.07

### v2026.07.10
- 본문 반영: `사례로 보기` 표지를 `사례 및 예시`로 통일하고 Section 버전을 갱신했다. 내용 추가 없이 구조 표지만 정리했다.

- 번역 동기화 메모: 향후 번역본이나 다른 언어 원고가 생기면 같은 위치의 구조 표지도 `사례 및 예시` 축으로 맞춰야 한다.
