# Section Release Note

- Section ID: `P4-19.5`
- Source File: `docs/parts/part-04/chapter-19/section-05.md`

### v2026.07.12

- 변경 이유: 보충학습 절 말미에 기본형 `이 절에서 기억할 관점` 표지가 남아 있어, 현재 기준서의 `체크리스트` 단일 구조와 어긋나고 있었다.
- 본문 반영: 말미 표지를 `체크리스트`로 바꾸고, 벨만 방정식, 수렴, 함수 근사, DQN의 위치를 자기 점검 질문으로 다시 정리했다. 같은 작업에서 Section 버전을 갱신했다.
- 추가 반영: `연습 및 예제`를 새로 추가해 `reward + gamma * next_value`를 직접 계산하는 작은 Python 예제와, 작은 상태 공간과 큰 상태 공간을 비교해 Q-table과 함수 근사 전환을 읽게 하는 해설을 넣었다.
- 추가 반영: 연습 예제가 고정된 숫자 한 번 출력에서 멈추지 않도록 다시 설계했다. 이제 작은 미로와 화면 게임 두 장면을 같은 벨만식으로 읽게 하고, 상태 수를 바꿔 보며 `가치 해석은 유지되지만 표현 방식은 q_table -> function_approximator로 바뀐다`는 점을 직접 확인하게 했다.
- 추가 반영: `직접 판단해 보기` 표를 넣어 벨만식, 수렴, 함수 근사를 각각 따로 외우지 않고 `현재 보상 + 미래 가치 -> 반복 갱신 안정화 -> 표에서 함수로 이동` 흐름으로 다시 읽게 보강했다.
- 추가 반영: 사례 1이 `작은 미로에서는 표가 되고 큰 게임에서는 어렵다`는 배경 설명에서 멈추던 문제를 보강했다. 사람의 첫 기준, 그 기준이 무너지는 이유, 함수 근사로 해석이 바뀌는 지점, 독자가 마지막에 확인해야 할 결론을 한 표와 마무리 문장으로 다시 묶었다.
- 추가 반영: 사례 1 바로 아래에 `작은 미로 -> 상태값 표 -> 화면 게임 확장 -> 상태 폭증 -> 함수 근사 전환` 흐름의 Mermaid 도식을 추가해, 표 기반 직관이 어디서 무너지고 무엇으로 넘어가는지 한 번 더 압축해서 읽게 했다.
- 검토 메모: 이번 점검에서는 구조 준수, 예제의 개념 검증력, 독자 직접 판단 지점, 사례-예제 역할 분리, 학습 밀도 다섯 관점으로 재검토했다.
- 번역 동기화 메모: 한국어 원문 말미 구조만 정리했다. 영어·중국어 번역본은 향후 같은 `Checklist` 구조로 맞춘다.
- 번역 동기화 메모: 영어판과 중국어판에도 새 Python 예제, `직접 판단해 보기`, `체크리스트` 구조를 같은 위치에 반영해야 한다.
- 번역 동기화 메모: 영어판과 중국어판 사례 1에도 `사람이 먼저 쓰는 기준 -> 표가 무너지는 이유 -> 함수 근사로의 해석 전환` 흐름과 사례 표를 같은 위치에 반영해야 한다.
