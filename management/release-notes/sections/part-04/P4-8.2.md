### v2026.07.09
- 본문 반영: `P4-8.2`를 baseline의 필요성, 해석 원리, 준비 조건에 더 집중하도록 재배치하고, 대표 baseline 방법과 실제 설정 절차는 새 `P4-8.3 보충학습`으로 넘겼다.
- 본문 반영: `baseline을 세우기 전에 무엇을 먼저 고정해야 하는가` 표를 추가해, 문제 유형, 샘플 단위, 평가 지표, 데이터 분포, 중요한 실패 장면이 설정의 선행 조건이라는 점을 다시 묶었다.
- 번역 동기화 메모: 향후 번역본에서도 `P4-8.2`는 필요성과 해석 원리에, `P4-8.3`은 설정 절차와 대표 방법에 중심을 나누는 구조를 유지해야 한다.

### v2026.07.08
- 본문 반영: baseline 설계 순서를 `문제 유형 고정 -> 가장 단순한 규칙 선택 -> 같은 지표로 측정 -> 오류 장면 확인 -> 다음 단계 결정`으로 정리한 방법론 표와, 대조군·기본 기준선·공정 비교 관점의 최소 이론 배경 표를 추가했다.
- 본문 반영: baseline 설명 뒤에 `churn dataset -> baseline model / candidate model -> same metric -> error check -> meaningful gain?` 흐름의 Mermaid 도식을 추가해, baseline이 점수 해석과 오류 해석의 출발점이라는 점을 사례 수준에서 보강했다.
- 번역 동기화 메모: 향후 번역본에서도 baseline 설계 절차 표, 최소 이론 배경 표, churn 비교 도식을 함께 유지해 방법론과 비교 논리가 끊기지 않게 해야 한다.
