### v2026.07.09

- 변경 이유: baseline의 필요성, 설정 절차, 대표 방법, 예시와 예제가 한 절에 함께 몰리면서 중심 질문이 흐려지고 있었다.
- 본문 반영: `P4-8.2`를 baseline의 필요성, 해석 원리, 준비 조건에 더 집중하도록 재배치하고, 대표 baseline 방법과 실제 설정 절차는 새 `P4-8.3 보충학습`으로 넘겼다.
- 본문 반영: `baseline을 세우기 전에 무엇을 먼저 고정해야 하는가` 표를 추가해, 문제 유형, 샘플 단위, 평가 지표, 데이터 분포, 중요한 실패 장면이 설정의 선행 조건이라는 점을 다시 묶었다.
- 연결 정리: 다음 절 연결을 `P4-8.3 보충학습` 기준으로 명시해, 왜 필요한가와 어떻게 세우는가의 학습 흐름이 분명해지도록 조정했다.
- 추가 정리: `대조군(control)`, `유효성(validity)`처럼 근거보다 넓게 읽힐 수 있는 표현을 줄이고, 직접 확인한 문서에서 안전하게 일반화할 수 있는 범위로 문장을 보수적으로 조정했다.
- 추가 정리: `baseline reference` 구간도 외부 표준 용어처럼 읽히지 않게, 이 책 안에서의 해석 구분이라는 점이 드러나도록 문장을 낮췄다.
- 번역 동기화 메모: 향후 번역본에서도 `P4-8.2`는 필요성과 해석 원리에, `P4-8.3`은 설정 절차와 대표 방법에 중심을 나누는 구조를 유지해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.09`

### v2026.07.08

- 변경 이유: baseline의 필요성은 설명되었지만, baseline을 어떤 절차로 세우는지와 왜 그런 비교가 이론적으로 필요한지가 현재 본문에서는 충분히 직접적이지 않았다.
- 본문 반영: baseline 설계 순서를 `문제 유형 고정 -> 가장 단순한 규칙 선택 -> 같은 지표로 측정 -> 오류 장면 확인 -> 다음 단계 결정`으로 정리한 방법론 표와, 대조군·기본 기준선·공정 비교 관점의 최소 이론 배경 표를 추가했다.
- 추가 정리: 이론 배경 표의 표현을 특정 문서 메모처럼 보이지 않게 `최소 가정`, `공정 비교` 같은 일반화된 기준 언어로 정리해, baseline 이론이 보편적인 실험 원리로 읽히게 다듬었다.
- 추가 정리: scikit-learn의 `DummyClassifier`, `DummyRegressor`, 교차검증 가이드와 모델 평가 문헌을 근거로 연결해, baseline 방법론과 일반 비교 원리가 출처와 함께 보이도록 본문 문장과 참고 자료를 보강했다.
- 변경 이유: baseline의 일반 의미와 추상 도식은 있었지만, 고객 이탈 사례에서 baseline과 후보 모델을 같은 지표와 오류 사례 위에 올려 비교하는 예시 도식이 부족했다.
- 본문 반영: baseline 설명 뒤에 `churn dataset -> baseline model / candidate model -> same metric -> error check -> meaningful gain?` 흐름의 Mermaid 도식을 추가해, baseline이 점수 해석과 오류 해석의 출발점이라는 점을 사례 수준에서 보강했다.
- 번역 동기화 메모: 향후 번역본에서도 baseline 설계 절차 표, 최소 이론 배경 표, churn 비교 도식을 함께 유지해 방법론과 비교 논리가 끊기지 않게 해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.08`
- 변경 이유: 사기 탐지 사례 바로 아래에도 높은 정확도 착시와 recall/F1 비교 흐름을 붙여 baseline의 역할을 더 즉시 보이게 할 필요가 있었다.
