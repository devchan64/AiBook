### v2026.07.07

- 변경 이유: 일반화 판단표 도입과 핵심 정의를 따로 세우는 메타 표지 문장을 줄이기 위해 수정했다.
- 본문 반영: 일반화 범위를 먼저 확인하는 기준을 직접 설명하는 문장으로 바꾸고, 핵심 정의를 별도 표지 없이 본문 문장으로 바로 잇도록 정리했다.
- 번역 동기화 메모: 향후 번역본에서도 일반화 판단과 핵심 요약을 메타 표지 없이 직접 설명하는 구조를 유지해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.07`

### v2026.07.08

- 변경 이유: 익숙한 사용자 성능과 새 사용자 성능의 차이가 일반화 유지 여부로 어떻게 읽히는지 사례 수준에서 더 직접 보강할 필요가 있었다.
- 본문 반영: 사례 1 아래에 `familiar users -> new users -> gap 비교 -> generalization stable / weak` 흐름의 Mermaid 도식을 추가하고 본문 버전을 갱신했다.
- 번역 동기화 메모: 향후 번역본에서도 일반화를 학습 점수 자체가 아니라 새 사용자 성능 차이로 읽게 하는 같은 도식을 유지해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.08`
