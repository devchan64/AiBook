# Section Release Note

- Section ID: `P4-7.1`
- Source File: `docs/parts/part-04/chapter-07/section-01.md`

### v2026.07.08

- 변경 이유: Chapter 7 재배치로 전처리 문제 구분 보충학습과 특징 선택·차원 축소 구분 보충학습의 역할이 갈라져, 후속 참조 문장을 새 구조에 맞게 정리할 필요가 있었다.
- 본문 반영: `P4-7.1` 말미의 후속 참조를 `P4-7.3`은 전처리 종류 구분, `P4-7.4`는 통계 검정 기반 선택과 RFE 비교로 나눠 가리키도록 정리했다.
- 변경 이유: 칼럼이 많을수록 좋아 보이는 착시와, 실제 예측 시점에 쓸 수 있는 특징만 남겨야 하는 흐름을 사례 수준에서 더 직접 보여 줄 필요가 있었다.
- 본문 반영: 사례 1 아래에 `many churn columns -> leakage risk`와 `usable signals only -> recheck validation`을 대비하는 Mermaid 도식을 추가하고 본문 버전을 갱신했다.
- 변경 이유: `좋은 특징은 무엇을 가져야 하는가`가 신호, 잡음, 중복 수준에 머물러, 예측 시점 사용 가능성과 운영 재현성까지 포함한 판단 기준으로는 다소 가벼웠다.
- 본문 반영: 좋은 특징의 기준을 신호, 잡음, 시점 정당성, 중복 관리, 운영 재현성의 다섯 관점으로 확장하고, 특징 후보 비교표와 보강된 Mermaid 흐름으로 판단 기준을 더 구체화했다.
- 변경 이유: 다섯 기준을 제시한 뒤에도 `좋은 특징`과 `강해 보이지만 위험한 특징`의 차이가 아직 즉시 대비되지는 않았다.
- 본문 반영: 겉으로 좋아 보이지만 실제로는 위험한 특징과 더 나은 특징 방향을 짝지은 비교표를 추가하고, 좋은 특징이 `모델과 운영이 함께 버틸 수 있는 특징 묶음`이라는 설명과 마지막 점검 질문을 보강했다.
- 번역 동기화 메모: 향후 번역본에서도 특징 선택을 정보 추가가 아니라 누수 제거와 운영 가능 신호 선별로 읽게 하는 같은 도식을 유지해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.08`
