### v2026.07.09
- 본문 반영: 고객 이탈 예측 트리가 review 기준보다 소수 고객 조합을 더 자세히 외우기 시작하는 사례를 `사례 2`로 추가했다. 사람이 먼저 보던 기준과 지나치게 깊어진 트리가 붙잡기 쉬운 조합을 비교 표로 붙였고, 과적합을 `잔질문이 새 고객에서도 반복될 만한가`라는 질문으로 다시 읽게 하는 해설을 보강했다. 추가 보강에서는 고객 A-D의 작은 입력 장면 표, `얕은 읽기 vs 지나치게 깊은 읽기` 비교 표, `review rule becomes fragile`로 끝나는 짧은 Mermaid 흐름도를 더해 review 기준이 어떻게 흔들리는지 더 직접적으로 보이게 했다. 같은 날 제조 불량 탐지 `사례 1`도 제품 A-D의 센서 장면 표, `비교적 단순한 읽기 vs 지나치게 깊은 읽기` 비교 표, `큰 기준 vs 드문 센서 조합` 대비 해설을 더해 공장 데이터의 예외 leaf가 어떤 식으로 만들어지는지 더 직접 보이게 보강했다. 이어서 `pruning은 무엇을 하는가` 단락에는 `pre-pruning vs pruning` 비교 표, pruning 전후 가지 상태 표, 좁은 leaf를 다시 볼 때의 해석 문장, `ccp_alpha` 방향성 설명을 추가해 초심자가 `무엇이 잘리고 무엇이 남는가`를 더 직접 읽게 보강했다. 추가로 `과적합을 데이터 흐름으로 보기` 단락에는 앞쪽 분기, 중간 분기, 뒤쪽 분기, 마지막 leaf를 나누어 보는 흐름 표와 `큰 패턴 설명 -> 소수 사례 외우기` 전환 해설을 더해, 과적합이 데이터 흐름 안에서 어디서 시작되는지 더 직접 읽게 보강했다. `Python 예제로 깊이에 따른 과적합 보기`에는 입력 비교 표, `train-test gap` 출력, 깊이 구간별 읽기 표, 값을 바꿔 다시 볼 질문을 추가해 예제에서 무엇을 바로 비교해야 하는지 더 직접 보이게 했다. Section 버전을 갱신했다.
