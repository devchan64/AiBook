### v2026.07.12

- 변경 이유: 학습 밀도 검토 결과 `P4-18.1`은 범위가 넓은 반면 첫 실제 학습 장면과 예제가 뒤쪽에 밀려 있어, PCA의 핵심 판단을 익히기보다 개념 목록을 훑는 절처럼 읽힐 위험이 있었다.
- 본문 반영: 장난감 데이터 1개를 절 초반으로 당겨 `차원 -> 특징 중복 -> PCA 직관 -> 분산과 직교 -> 고유값/고유벡터`를 같은 장면으로 왕복하게 다시 묶었다. 이에 따라 앞부분의 오버뷰성 서술을 줄이고, PCA를 `축 회전 비유`에서 멈추지 않고 `큰 흐름 축과 남은 차이 축을 나누는 계산`으로 읽게 본문 흐름을 재구성했다.
- 추가 반영: 연습 예제를 단순 평균 요약 비유 중심에서 `중심화 -> pc1_like -> pc2_like`를 직접 계산해 보는 형태로 다시 설계했다. 이를 통해 첫 번째 성분이 큰 함께-변화 방향, 두 번째 성분이 작은 엇갈림 방향이라는 감각을 예제에서 바로 확인하게 바꿨다.
- 추가 반영: 공통 장난감 데이터의 `원래 특징 -> 중심화 -> 큰 흐름 축/작은 차이 축` 흐름과 `공분산 행렬 -> 고유벡터/고유값` 연결을 각각 별도 Mermaid 도식으로 추가해, PCA 직관과 수식 연결이 표와 문장만으로 흩어지지 않게 보강했다.
- 추가 반영: `연습 및 예제`를 `pc1_like / pc2_like` 수동 근사 예제에서 실제 `sklearn.decomposition.PCA` 실행 예제로 교체해, `2차원 -> 1차원 투영 -> explained variance ratio -> inverse transform 복원`까지 한 번에 보게 바꿨다. 같은 흐름에서 마지막 샘플의 패턴을 일부러 어긋나게 만든 두 번째 예제로 복원 오차가 커지는 장면도 직접 확인하게 했다.
- 추가 반영: 절 말미의 `짧은 점검`, `언제 이 관점을 먼저 떠올려야 하는가` 같은 메타 구조를 걷어내고 `이 절에서 기억할 관점`과 `체크리스트`로 정리했다.
- 검토 메모: 이번 재구성에서는 구조 흐름, 개념 연결, 예제 밀도, 초심자 해석, 메타데이터 정합성의 다섯 패스를 기준으로 점검했다.
- 번역 동기화 메모: 영어판과 중국어판도 같은 날짜에 예전 보조 섹션을 걷어내고, 현재 원문 기준의 toy data 흐름과 `Checklist` 구조에 맞춰 정리했다. 공통 장난감 데이터, PCA 설명 축, 마지막 자기 확인 질문을 같은 순서로 유지한다.
- 번역 반영 상태: 영어·중국어 반영

### v2026.07.10

- 변경 이유: 절의 범위에서 생략한 주제들이 실제로 어디서 다시 이어지는지 불분명했고, 일부 항목을 `이 책에서 다루지 않는다`는 식으로 남긴 표현도 원칙에 맞지 않았다.
- 본문 반영: `다루지 않는 내용` 아래 회수 위치 표를 다시 정리해 PCA의 고유값·고유벡터, kernel PCA·Truncated SVD, t-SNE·UMAP, 재구성 오차를 현재 장 안에서 어떻게 이어 읽는지 명시했다.
- 추가 반영: `이 책에서 다루지 않는다`는 식의 표현이 원칙에 맞지 않아 범위 문장을 다시 정리했다. PCA에서 왜 고유벡터가 새 축이 되고 고유값이 설명 분산으로 읽히는지, kernel PCA와 Truncated SVD를 어떤 감각으로 구분해야 하는지까지 현재 절 안에서 직접 회수했고, t-SNE·UMAP과 재구성 오차는 P4-18.2 본편 회수로 다시 명시했다.
- 추가 반영: 후속 갈래를 절 범위 안에서 너무 길게 예고하던 회수 표를 걷어내고, 현재 절에서 실제로 닫는 질문과 다음 절로 넘기는 질문을 짧게 다시 정리했다. 이에 따라 18.1은 `왜 차원을 줄이는가`, `PCA의 직관`, `고유벡터와 갈래 차이`에 더 집중하고, 시각화 중심 기법과 재구성 오차는 P4-18.2 연결 한 줄만 남기도록 조정했다.
- 추가 반영: `이 절은 다음 내용은 깊게 다루지 않습니다` 목록은 항목별 회수 경계가 불충분해 원고 작성 가이드라인과 어긋날 소지가 있어 제거했다. 현재 절 안에서 직접 다루는 질문과 P4-18.2로 실제로 이어지는 질문만 범위 문장에 남겨, 애매한 생략 예고 없이 절의 초점을 더 선명하게 정리했다.
- 추가 반영: 문단 재배치 리포트 기준으로 `사례 및 예시 -> 연습 및 예제 -> 이 절에서 기억할 관점 -> 짧은 점검` 순서로 다시 묶었다. 이에 따라 차원 축소를 먼저 실제 표현 재구성 장면으로 읽고, 그다음 요약 축 예제로 확인하도록 독서 흐름을 정리했다.
- 번역 동기화 메모: 향후 번역본에서도 PCA 고유값·고유벡터 설명, kernel PCA·Truncated SVD 비교 표, P4-18.2 본편 회수 연결을 함께 유지해야 한다. 향후 번역본이나 다른 언어 원고가 생기면 같은 위치의 구조 표지도 `사례 및 예시` 축으로 맞춰야 한다.
