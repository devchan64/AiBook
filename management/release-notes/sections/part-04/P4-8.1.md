# Section Release Note

- Section ID: `P4-8.1`

### v2026.07.24
- 핵심 변경: 한국어, 영어, 중국어 간체판에 logistic regression, k-NN, decision tree, random forest 후보를 `cross_validate`로 비교하는 모델 선택 예제를 추가했다.
- 변경 이유: 모델 선택이 유명한 모델 하나를 고르는 일이 아니라, 후보군을 같은 비교 절차에 올려 train score, CV score, 흔들림, 설명 가능성을 함께 읽는 일임을 실제 출력으로 확인하게 하기 위해서다.
- 본문 반영 내용: `make_classification` 데이터에서 네 모델 후보의 train score, CV score, CV score spread를 비교하고, 모델 선택 메모에 남길 판단 축을 해설했다.
- 번역 동기화 메모: 영어판과 중국어 간체판도 같은 코드, 출력, 해설 구조로 반영했다.
- 번역 반영 상태: 한국어, 영어, 중국어 간체판 반영 완료.
- 원문 기준 버전: `v2026.07.24`
