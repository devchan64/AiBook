### v2026.07.08

- 변경 이유: baseline의 필요성은 보이지만, baseline을 만들려면 어떤 선행 판단이 먼저 고정되어야 하는지가 현재 본문에서는 충분히 직접적이지 않았다.
- 본문 반영: `baseline은 무엇을 알아야 만들 수 있는가`에 답하는 연결 문단과 준비 지식 표를 추가해, 문제 유형, 샘플 단위, 평가 지표, 데이터 분포, 운영상 중요한 실패가 baseline 설계의 선행 조건이라는 점을 보강했다.
- 변경 이유: 모델 선택의 일반 흐름과 추상 도식은 있었지만, 구독 서비스 이탈 예측 사례에서 설명 가능성·배치 운영 같은 제약이 후보군을 어떻게 갈라놓는지 사례 도식이 부족했다.
- 본문 반영: 사례로 보기 절에 `churn prediction task -> tabular data / need explanation / daily batch inference -> linear / tree / random-forest candidates -> compare shortlist` 흐름의 Mermaid 도식을 추가해, 문제와 제약이 후보군 설계로 번역되는 과정을 보강했다.
- 번역 동기화 메모: 향후 번역본에서도 baseline 준비 지식 표와 churn 후보군 도식을 함께 유지해, 모델 선택과 baseline 설계의 연결이 끊기지 않게 해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.08`

### v2026.07.12

- 변경 이유: 원고 원칙 기준으로 보면 P4-8.1은 `모델 선택의 주요 학습내용`을 설명하고 있으면서도, 독자가 `문제 유형 -> 샘플 단위 -> 후보군 -> baseline -> 먼저 볼 오류`를 직접 적용해 보는 연습 회수가 약했다.
- 본문 반영: `연습 및 예제`를 5회 검토 관점으로 다시 읽고, 비코드 연습 중심으로 재구성해 주요 학습내용을 실제로 써 보게 정리했다. 새 연습은 문제 장면을 후보군 메모로 바꾸기, 어떤 후보를 먼저 빼야 하는지 설명하기, 잘못된 후보 메모와 더 나은 후보 메모 비교하기, 같은 후보군이어도 먼저 볼 오류가 달라지면 메모가 어떻게 달라지는지 확인하기로 구성했다.
- 추가 반영: 중복으로 나뉘어 있던 `사례 및 예시` 표지를 하나의 흐름으로 정리하고, 자기 확인 블록 표지를 `짧은 점검`에서 `체크리스트`로 바로잡았다.
- 추가 반영: 기존 Python 예제는 `표 재진술` 성격이 강해 이해 중심 연습으로서 효과가 약하다고 판단해 제거했다. 이 절은 코드를 돌리는 절보다 판단 순서를 붙잡는 절이므로, 코드보다 메모 비교와 오류 관점 연습을 우선하도록 조정했다.
- 번역 동기화 메모: 한국어 원문에만 이번 연습 보강과 구조 정리를 반영했다. 영어·중국어 간체 번역본에는 같은 연습 블록과 `체크리스트` 구조 반영이 후속으로 필요하다.
- 번역 반영 상태: 향후 번역 반영 필요
