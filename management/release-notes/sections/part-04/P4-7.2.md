### v2026.07.11

### v2026.07.08
- 본문 반영: 주요 학습내용 첫머리에 `전처리를 처음 들으면 이렇게 잡으면 된다` 소제목을 추가해, 전처리 전 표와 전처리 후 입력 형태를 대비시키고 결측치 처리, 스케일 조정, 인코딩의 세 대표 장면으로 이어지게 보강했다.
- 본문 반영: 사례로 보기 절에 `customer table -> missing rule / numeric rule / category rule -> same transform rules -> comparable model input` 흐름의 Mermaid 도식을 추가해, 전처리를 컬럼 상태별 규칙 묶음으로 읽게 했다.
- 번역 동기화 메모: 향후 번역본에서도 train 단계에서 배운 전처리 규칙을 validation/test에 그대로 재사용하는 흐름과 규칙 병합 도식을 유지해야 한다.

### v2026.07.07
- 본문 반영: 범주형 인코딩 설명 도입부의 `이해하면 됩니다` 표현을 개념 설명 문장으로 교체했고, 전처리 점검 질문 도입도 다음 질문 진행을 앞세우지 않는 설명형 문장으로 바꿨다.
- 번역 동기화 메모: 한국어 원문 톤 수정이므로 향후 번역본이 생기면 설명형 문장으로 같은 톤을 맞춰야 한다.

### v2026.07.10
- 본문 반영: `사례로 보기` 표지를 `사례 및 예시`로 통일하고 Section 버전을 갱신했다. 내용 추가 없이 구조 표지만 정리했다.
- 추가 반영: `체크리스트` 기준 원칙과 문단 재배치 리포트에 맞춰 말미의 자기 확인 질문을 `이 절에서 기억할 관점` 뒤로 옮기고, 흩어져 있던 질문 목록은 `체크리스트` 표지 아래로 다시 모았다.
- 번역 동기화 메모: 향후 번역본이나 다른 언어 원고가 생기면 같은 위치의 구조 표지도 `사례 및 예시` 축으로 맞춰야 한다.
