### v2026.07.10

- 변경 이유: 그래디언트 부스팅 절이 순차 보정의 큰 그림은 설명하고 있었지만, residual이 다음 단계 지시문처럼 어떻게 읽히는지와 `learning_rate`·`n_estimators` 조합이 실제로 어떤 다른 보정 행동을 만드는지는 더 촘촘히 드러날 필요가 있었다.
- 본문 반영: residual의 방향과 의미를 짧은 표로 다시 정리하고, weak learner를 `작아서 역할이 제한된 보정 도구`로 읽는 오해 교정 표를 추가했다.
- 본문 반영: learning rate 비교 예제 뒤에 `보정 한 번의 강도` 표를 추가하고, `learning_rate`와 `n_estimators`를 한 조합으로 읽는 질문 표를 보강해 `적은 단계로 빨리 움직일지, 많은 단계로 천천히 움직일지` 감각을 더 직접적으로 연결했다.
- 본문 반영: `같은 residual이라도 보정 강도를 다르게 두면 왜 다른 모델처럼 보일까` 사례를 추가해, 같은 residual을 보더라도 반영 강도와 단계 수가 다르면 이후 모델 행동이 달라진다는 점을 더 분명히 했다.
- 추가 반영: 사례 블록을 원칙 기준으로 다시 보강했다. 고객 이탈 사례에 `사람이 먼저 쓰기 쉬운 1차 규칙`과 경계 사례 표, 확인 가능한 결과 문장을 추가했고, 보정 강도 사례에는 설정별 장면 비교 표와 확인 가능한 결과 문장을 더해 `문제 장면 -> 기존 기준 -> 한계 -> 부스팅이 바꾸는 점 -> 확인 결과` 흐름이 더 분명하게 닫히도록 정리했다.
- 추가 반영: `XGBoost, LightGBM, CatBoost 같은 구현 차이`를 `현재 본편 범위 밖`으로 닫던 문장을 수정했다. 구현 차이는 P4-16.2에서 직접 이어 읽고, 더 넓은 비교가 필요할 때는 이 장의 보충학습으로 분리해 회수한다는 방향으로 범위 안내를 정리했다.
- 추가 반영: `additive model` 설명이 정의 수준에서 짧게 끝나던 부분을 보강했다. 단계별 보정값이 실제로 어떻게 누적되는지 작은 숫자 표로 풀고, 랜덤포레스트의 집계와 그래디언트 부스팅의 누적을 대비하는 표를 추가해 `여러 독립 의견의 평균`과 `여러 작은 수정의 합` 차이가 더 직접적으로 보이게 했다.
- 추가 반영: `weak learner` 설명도 정의 수준을 넘어 보강했다. 작은 트리, 중간 크기 트리, 큰 트리가 한 단계에서 맡게 되는 역할을 비교하는 표와 고객 이탈 장면 비교 표를 추가해, 왜 부스팅이 작은 트리를 기본 부품처럼 쓰는지와 `약하다`가 `무능하다`를 뜻하지 않는다는 점을 더 직접적으로 드러냈다.
- 추가 반영: `이 연습이 Part 4 목표를 어떻게 회수하는가` 같은 메타형 소제목을 원고 작성 가이드 기준으로 정리했다. 집필자 설명 대신 `이 예제에서 같이 읽어야 할 것`으로 바꾸고, residual 감소와 learning rate 해석을 독자 관점의 해설 문단으로 다시 묶었다.
- 추가 반영: `n_estimators` 설명도 정의 수준을 넘어 보강했다. 적은 단계와 많은 단계에서 남는 residual, underfitting/overfitting 신호가 어떻게 달라지는지 표로 정리하고, `learning_rate`와의 조합을 함께 읽는 비교 표를 추가해 `보정의 길이와 속도`를 같이 설계한다는 감각이 더 직접적으로 보이게 했다.
- 추가 반영: `실무에서 어떤 장면으로 떠올리면 좋은가` 도입 문장을 문단 구조 기준으로 정리했다. 직전 절의 추상 요약을 반복하던 문장을 줄이고, `큰 흐름은 잡히지만 남는 오류 패턴을 더 줄이고 싶은 장면`이라는 더 구체적인 실무 상황으로 바로 들어가게 바꿨다.
- 추가 반영: 문단 재배치도 함께 진행했다. `사례 및 예시`를 `연습 및 예제`보다 앞에 두어, 핵심 설명 뒤에 실제 문제 장면으로 먼저 감각을 잡고 그다음 Python 예제로 확인하는 흐름이 되도록 Section 구조를 정리했다.
- 번역 동기화 메모: 향후 번역본에서도 residual 방향 표, weak learner 오해 교정, learning rate와 단계 수 조합 질문, 보정 강도 사례를 같은 밀도로 유지해야 한다.
- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
- 원문 기준 버전: `v2026.07.10`
