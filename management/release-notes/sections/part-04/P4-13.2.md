### v2026.07.09

- 변경 이유: Module 4가 개별 모델 설명은 충분해도, 같은 문제 장면에서 어떤 질문 구조로 모델을 다시 비교해야 하는지 한눈에 묶는 통합 비교 장면이 약했다.
- 본문 반영: `같은 작은 데이터 장면으로 Module 4를 다시 비교하면` 절을 추가해 선형회귀, 로지스틱 회귀, k-NN, 선형 SVM, 커널 SVM을 `먼저 보는 비교축`과 `다음 질문` 기준으로 다시 묶고 본문 버전을 갱신했다.
- 본문 반영: 같은 날짜 후속 보강으로 `학습 배경` 앞부분의 운영형 기록 표와 kernel 후보 판단 표를 뒤쪽 사례 블록으로 옮기고, `P4-11.2의 선형 경계`, `P4-12.2의 표현과 계산 기준`, `P4-13.1의 같은 공간 안의 경계 개선`과 현재 절의 차이를 앞에서 직접 연결했다. 또한 `직접 특징 추가`와 `kernel의 우회 계산` 관계, `좋은 선형 경계 조정`과 `표현 공간 변경`의 차이를 별도 문단과 표로 보강해, 재배치 뒤에도 남아 있던 학습 공백을 메우도록 수정했다.
- 번역 동기화 메모: 향후 번역본에서도 모델 목록이 아니라 문제 구조 비교표로 읽히도록 같은 통합 비교 절을 유지해야 한다.
