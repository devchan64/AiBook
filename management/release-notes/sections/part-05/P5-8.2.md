### v2026.07.14
- 변경 이유: dropout 예제는 `before_dropout`, `train_mask`, `train_mode_values`, `eval_mode_values`, 합계 차이를 출력하지만, 텍스트 출력만으로는 어떤 경로가 꺼지고 전체 반응이 어떻게 달라졌는지 즉시 보이지 않았다.
- 본문 반영: 예제 출력 뒤에 노드별 활성값 변화와 활성값 합 비교를 각각 분리 PNG 그래프로 추가했다. 그래프는 본문 Python 예제의 고정 입력과 `random.seed(11)` 결과를 그대로 사용한다.
- 추가 변경 이유: 기존 사례는 큰 은닉층, 적은 데이터, 큰 완전연결층을 나열해 dropout이 실제로 바꾸는 판단 순서가 흐려질 수 있었다.
- 추가 본문 반영: 사례를 리뷰 분류 모델이 지름길 단서에 기대는 하나의 장면으로 좁히고, `훈련 지름길 -> 경로 의존 -> dropout으로 경로 흔들기 -> 검증 간극 확인` 흐름을 Mermaid 도식으로 압축했다.
- 추가 검토 반영: 리뷰 문장의 단서를 지우는 것이 아니라 그 단서를 처리하는 내부 표현 경로를 학습 중 흔든다는 연결 문장을 보강하고, 사례 흐름도도 같은 의미로 수정했다.
- 번역 동기화 메모: 향후 번역 시 dropout 산출물 그래프 순서와 `before -> train -> eval` 해설 구조를 유지하고, 사례 도식도 `dropout-case-reading-flow` 언어쌍으로 동기화해야 한다.
- 번역 반영 상태: 향후 반영 필요
