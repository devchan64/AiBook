### v2026.07.15
- 변경 이유: 예제 재검토 결과, 현재 Python 블록은 수치 안정성 직관에는 유효하지만 `초기화 스케일 실험`인지 `반복 곱셈 증폭 실험`인지 경계가 약했고, 독자가 무엇을 바꿔 보고 어떤 출력을 읽어야 하는지도 더 직접적으로 닫을 필요가 있었다.
- 본문 반영: 스칼라 가중치를 `각 층 가중치 스케일을 단순화해 대표한 장난감 실험값`으로 설명하는 경계 문장을 추가했다. `weight_cases`, `layer` 반복 횟수, 입력 활성값, `eps`를 바꿔 볼 실험 표도 추가해 예제를 더 명시적인 실험형으로 정리했다.
- 본문 반영 추가: batch normalization 뒤 범위 해설은 `항상 같은 숫자로 고정된다`는 인상을 줄이지 않도록 `비슷한 규모로 다시 정리된다`는 표현으로 조정했고, `small_init` 해설도 실제 출력이 직접 보여 주는 범위를 넘지 않도록 `신호와 gradient가 약해지는 방향으로 이어질 수 있다` 수준으로 보수적으로 정리했다.
- 본문 반영 추가: 코드 블록의 구분선 출력 위치를 실제 예시 출력과 맞추고, batch normalization 뒤 범위가 케이스마다 거의 같아 보이는 이유가 `샘플의 상대적 모양은 유지한 채 스케일만 바꾸는 장난감 설정` 때문이라는 해석 문장을 덧붙였다.
