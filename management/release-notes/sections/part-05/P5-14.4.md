# Section Release Note

- Section ID: `P5-14.4`
- Source File: `docs/parts/part-05/chapter-14/section-04.md`

### v2026.07.19
- 신규 분리: 기존 P5-14.1의 residual connection과 layer normalization 설명을 `residual과 normalization은 깊은 반복을 어떻게 안정화하는가` Section으로 독립시켰다.
- 본문 반영: residual을 원래 정보 흐름 보존 장치로, layer normalization을 값 범위 안정화 장치로 설명하고, action token residual 비교 그래프와 오해 바로잡기 연습을 배치했다.
- 제목 정리: Section 제목을 `왜`보다 `어떻게`에 맞춰 정보 흐름 보존과 값 범위 안정화라는 작동 관점이 보이게 다듬었다.
- 메타데이터 정리: 본문 제목 아래 `Section ID`와 `Version`을 현재 Section 메타데이터 가이드 형식에 맞춰 blockquote 표기로 정리했다.
- 도입 문장 정리: `이 절의 중심`형 표현을 줄이고, 깊은 반복을 견디는 정보 흐름이라는 판단 기준이 바로 보이도록 다듬었다.
- 사례 보강: 조치 토큰 사례에 새 문맥만 강하게 반영하면 된다는 빠른 판단의 한계를 추가하고, residual과 normalization이 조치 축과 다음 계산 안정성을 지키는 장치라는 확인 결과를 명시했다.
- 연습 보강: residual과 normalization을 빼면 무엇이 비는지 묻는 연습을 질문별 답·해설 표로 바꿔, 각 질문이 정보 흐름 보존과 값 범위 안정화로 바로 닫히게 했다.
- 사례·연습 재보강: action token 사례를 `새 계산만 남김`, `residual 이후`, `normalization 이후` 단계로 나누어 숫자 비교가 정보 흐름 보존과 값 범위 안정화 중심축을 지지하게 했다. 또한 action token 축 진단 연습을 추가해 원래 정보 손실과 값 범위 흔들림을 구분하게 했다.
- 연습 정리: 네 부품 역할표를 다시 묻는 성격이 강한 `단계별 오해 바로잡기` 연습을 삭제해, Section 연습이 residual과 normalization의 안정화 축에 집중되도록 했다.
- 그래프 검증: `p5_14_1_transformer_block_charts.py` 재실행으로 `transformer-block-action-residual-compare` PNG가 다시 생성됨을 확인했고, 한국어 PNG의 수치 라벨과 축 표기가 잘리지 않는지 확인했다.
- 번역 동기화 메모: 기존 영어·중국어 번역본은 재분해 전 구조이므로, 향후 번역 시 P5-14.4를 별도 Section으로 추가해야 한다.
