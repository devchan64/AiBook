- 본문 재배치: 기존 P5-14.2의 병렬 처리와 긴 문맥 설명은 병합 뒤 P5-14.4와 P5-14.5으로 넘기고, 현재 P5-14.2는 `Transformer 블록의 네 부품은 각각 무엇을 맡는가`라는 역할 분담 Section으로 다시 작성했다.
- 본문 반영: self-attention, feed-forward network, residual connection, layer normalization을 `관계 읽기`, `위치별 표현 가공`, `정보 흐름 보존`, `값 범위 안정화`로 나누어 설명하고, 연습도 부품별 역할 매칭으로 좁혔다.
- feed-forward 보강: feed-forward network가 attention 이후의 단순 후처리가 아니라, 문맥이 섞인 현재 위치 표현을 각 위치 안에서 다시 가공하는 장치라는 점을 작업 허가 사례와 연습 문항에 반영했다.
- feed-forward 차트 보강: `feed-forward-position-update` Mermaid 자산을 추가해 같은 feed-forward network가 각 위치에 공유 적용되지만, 위치마다 다른 입력 표현을 위치 안에서 따로 가공한다는 점을 시각화했다.
- 보충학습 연결: feed-forward network의 위치별 가공과 공유 가중치 설명을 새 P5-14.6 보충학습 Section으로 넘기는 연결 문장을 추가했다.
- residual 보강: residual connection을 단순 덧셈이 아니라 `새 계산 결과 + 원래 입력 표현`을 함께 남겨 원래 정보 흐름을 보존하는 경로로 설명하고, feed-forward 및 layer normalization과의 역할 차이를 표와 사례에 반영했다.
- residual 차트 보강: `residual-connection-skip-path` Mermaid 자산을 추가해 새 계산 경로와 원래 입력 표현의 우회 경로가 더해지는 구조를 시각화했다.
- 보충학습 연결: residual connection의 우회 경로, 깊은 반복에서의 정보 흐름 보존, layer normalization과의 차이를 새 P5-14.7 보충학습 Section으로 넘기는 연결 문장을 추가했다.
- layer normalization 보강: 의미 판단이나 정보 보존이 아니라, residual 이후 표현값의 평균과 퍼짐을 다시 맞춰 다음 계산의 기준선을 안정화하는 장치로 설명하고 사례·연습 해설에 반영했다.
- layer normalization 차트 보강: `layer-normalization-value-scale` Mermaid 자산을 추가해 한 위치 표현의 흔들린 값 범위가 평균과 퍼짐 정리를 거쳐 다음 계산 기준선으로 이어지는 흐름을 시각화했다.
- 보충학습 연결: layer normalization의 값 기준선 정리, batch normalization과의 차이, residual connection과의 역할 경계를 새 P5-14.8 보충학습 Section으로 넘기는 연결 문장을 추가했다.
- 사례 보강: 기존 작업 허가 사례가 네 부품 역할을 한 문단에 함축해 Section 중심축을 충분히 지지하지 못하므로, `재기동` 위치 표현을 시작 표현, self-attention, feed-forward, residual connection, layer normalization 단계로 풀어 역할별 질문과 직접 맡지 않는 일을 함께 보이게 했다.
- 학습 밀도 정리: 네 부품을 `직접 보는 것`과 `직접 맡지 않는 것`으로 대조하는 표를 추가하고, 역할이 섞인 오해 문장을 고치는 연습을 넣어 개념 경계를 적용하게 했다.
