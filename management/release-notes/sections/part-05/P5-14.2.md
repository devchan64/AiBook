### v2026.07.12

- 변경 이유: 병렬 처리와 긴 문맥 절의 말미 회상·적용 시점·점검 구조가 `체크리스트`와 중복되어 있었고, 학습 밀도 기준으로 다시 보니 `상태 전달 읽기`와 `직접 재참조 읽기`의 차이, 그리고 Part 5 운영 사례 축 통일이 더 필요했다.
- 본문 반영: 병렬 관계 계산, GPU 적합성, 긴 문맥 재참조 감각, LLM 장으로 이어지는 기준을 `체크리스트` 하나로 통합했다. `연습 및 예제`에는 실행 전 예측 표를 넣고, `순차 상태 출력만 보면 쉬운 판단 vs 직접 재참조 출력을 읽고 바뀌는 판단` 비교 표와 action-level 해설을 추가해 `support` 차이가 실제 운영 차단 판단으로 어떻게 이어지는지 더 직접 연결했다.
- 본문 반영 추가: 사례 구간에 남아 있던 일반 긴 번역 문장, 긴 문서 요약, 코드 생성과 분석 장면을 `다국어 작업 지시 번역`, `긴 장애 보고서 요약`, `운영 스크립트 생성과 분석`으로 교체했다. 이에 맞춰 사례 비교 표와 공통 결과 문장도 `금지 조건`, `핵심 근거`, `차단 조건`을 다시 불러오는 운영 판단 축으로 정리하고, 예제 입력 설명의 `마지막 사용자 요청` 표현도 `마지막 운영 요청`으로 맞췄다.
- 변경 이유 추가: 후속 점검에서 예제 변수와 결정 이름에 `block_air_shipping` 같은 잔여 물류 문맥이 남아 있었고, 각 사례도 `현재 위치가 무엇을 다시 직접 참조해야 하는가`를 결과 문장으로 닫지 않아 절 전체 전달력이 완전히 맞물리지 않았다.
- 본문 반영 추가 2: 긴 문맥 Python 예제의 규칙 문장, 상태 문장, 요청 문장, 상태 변수, 결정 이름을 `압력 미복귀 상태에서는 재기동 금지`와 `restart line 3 now` 맥락으로 다시 정리했다. 출력 예시와 해설 표도 이에 맞춰 `재기동 차단` 기준으로 갱신했다.
- 본문 반영 추가 3: 다국어 작업 지시 번역, 긴 장애 보고서 요약, 운영 스크립트 생성과 분석 세 사례 각각에 `그래서 이 사례에서 확인해야 할 결과` 문장을 추가해 금지 조건, 핵심 근거, 먼 앞쪽 정의를 현재 위치가 다시 참조하는지를 명시적으로 정리했다.
- 본문 반영 추가 4: `P5-14.1`과의 사례 중복을 줄이기 위해 `다국어 작업 지시 번역`, `긴 장애 보고서 요약`, `운영 스크립트 생성과 분석`을 각각 `긴 작업 허가 질의응답`, `긴 교대 인수인계 로그 요약`, `긴 설정 파일 검토`로 교체했다. 사례 설명 안에는 `현재 위치가 여러 관련 위치를 한꺼번에 비교하기 쉬운가`라는 병렬 계산 감각을 더 직접 넣었고, 대응 Mermaid 과업 도식도 같은 사례축으로 함께 갱신했다.
- 본문 반영 추가 5: 사례 2를 `긴 교대 인수인계 로그 요약`에서 `긴 교대 인수인계 위험 판단`으로 더 좁혀, 긴 문맥 재참조 목표는 유지하되 attention 계열에서 누적되던 `요약` 장면 피로를 줄였다. 이에 맞춰 비교 표와 공통 결과 문장도 `현재 판단 위치가 초반 경보와 중간 점검 근거를 다시 끌어오는가`로 조정했다.
