### v2026.07.21
- 학습밀도 보강: 질문 목록형 도입을 줄이고, 후보 분포를 `지금 입력 뒤에 이어질 수 있는 후보들의 상대적 그럴듯함`으로 바로 정의하도록 원문·영문·중문을 수정했다.
- 개념 구분: 데이터 분포와 후보 분포의 층위를 분리해, 학습 데이터 전체의 패턴과 현재 입력 뒤 후보 목록을 구분하도록 설명을 보강했다.
- 예제 정합성: Python 작성 판단이 드러나는 메타 문장을 제거하고, 표를 통해 분포를 먼저 읽는다는 독자 관점 설명으로 바꾸었다.
- 연습 보강: 상황별 일반 비교표를 후보 비중이 주어진 적용형 연습으로 바꾸어 `most_likely`와 `probabilities`의 차이를 직접 판단하게 했다.
- 도식 보강: `generative-model-flow-ko/en/zh.mmd`를 일반 생성 흐름에서 후보 분포, `most_likely`, `probabilities` 비교가 드러나는 Mermaid 도식으로 수정했다.
- 제목 정합성: `데이터 분포를 배운다는 말` 소제목을 데이터 분포와 후보 분포의 연결이 보이는 제목으로 조정했다.
- 출처 정리: 현재 본문에서 직접 다루지 않는 VAE/GAN 개별 논문 출처를 제거하고, `Deep Learning` Chapter 20 확인 기준으로 출처 범위를 구체화했다.
