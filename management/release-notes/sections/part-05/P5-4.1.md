### v2026.07.12
- 변경 이유: 손실 함수 도입 절의 말미 자기 확인 표지가 여러 갈래로 나뉘어 있어 기준서와 충돌했다.
- 본문 반영: 손실과 metric 구분, 손실의 학습 기준 역할, 일반화 비자동성, 다음 절과 역전파로 이어지는 경계선을 `체크리스트` 하나로 재구성했다.
- 추가 반영: 집필 순서만 예고하는 메타형 연결 표지를 제거했다.
- 변경 이유: 학습 밀도 재점검 결과, 분류 사례와 Python 예제가 `오답의 정도`와 `평균 손실에 더 크게 기여하는 샘플`을 독자가 먼저 비교해 볼 장면은 약했다.
- 본문 반영: `동물 분류` 사례에 `사람 기준 vs 손실 관점` 비교 표를 추가했다. `연습 및 예제`에는 실행 전 예측 표를 넣어 어떤 샘플이 평균 손실을 가장 크게 끌어올릴지 코드 전에 가늠하게 만들었다.
- 변경 이유: 추가 재검토 결과, `주택 가격 예측` 사례는 설명 자체는 맞지만 `사람 기준 -> 손실 숫자 비교 -> 확인 결과`가 표 형태로 직접 닫히지 않아 저장소 사례 원칙을 충족한다고 보기 어려웠다.
- 본문 반영: `주택 가격 예측` 사례에 `예측 A vs 예측 B` 비교 표와 `사람 기준 vs 손실 관점` 표를 추가해, 같은 오답 안에서도 `덜 나쁜 예측 vs 훨씬 더 나쁜 예측`이 왜 다른 손실로 읽혀야 하는지 직접 대비하게 했다. 사례 말미에는 회귀와 분류 사례를 함께 묶는 정리 문장도 덧붙였다.
- 변경 이유: 같은 사례를 다시 점검한 결과, `A가 B보다 덜 틀렸다`는 직관 비교는 생겼지만 손실 숫자가 실제로 얼마나 벌어지는지 바로 확인하는 단계가 비어 있어 `확인 가능한 결과`가 충분히 닫히지 않았다.
- 본문 반영: `주택 가격 예측` 사례에 오차(error), 제곱 오차(squared error), 업데이트 신호 해석을 한 표로 묶은 손실 계산 예시를 추가했다. 사례 끝에는 `더 멀리 빗나간 예측이 훨씬 큰 손실을 받아 먼저 더 강하게 수정된다`는 결과 문장을 명시했다.
- 변경 이유: 분류 사례는 설명상 방향은 맞았지만, 회귀 사례와 달리 `같은 오답 안에서 손실이 어떻게 벌어지는가`를 숫자로 확인하는 단계가 없어 사례 원칙을 충분히 충족하지 못했다.
- 본문 반영: `동물 분류` 사례에 `출력 A vs 출력 B` 직접 비교 표와 `정답 확률 -> cross-entropy 손실 예시 -> 업데이트 신호` 표를 추가했다. 사례 말미에는 `정답 클래스에 거의 확률을 주지 않은 오답이 더 큰 손실로 먼저 더 강하게 수정된다`는 결과 문장을 명시했다.
- 변경 이유: 사례 재점검 결과, 회귀·분류 사례 각각의 내부 비교는 생겼지만 `왜 loss가 metric과 별개로 필요한가`가 사례 묶음 수준에서 직접 닫히지 않아 학습용 결론이 약했다.
- 본문 반영: 두 사례 뒤에 `문제 유형 -> 사람 기준/metric 기준 -> loss가 추가로 드러내는 것 -> 더 먼저 고칠 예측` 비교표를 추가했다. 이어서 `같은 오답처럼 보여도 loss가 업데이트 우선순위를 가른다`는 짧은 Mermaid 도식을 넣어 사례 결론을 압축했다.
- 번역 동기화 메모: 한국어 기준 원고의 말미 구조 정리, 손실 해석 비교 표, 샘플별 예측 표, 회귀/분류 사례 비교 표, 신규 Mermaid 자산 쌍을 향후 번역에도 같은 의미 구조로 반영해야 한다.
