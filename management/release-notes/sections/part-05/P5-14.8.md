# Section Release Note

- Section ID: `P5-14.8`
- Source File: `docs/parts/part-05/chapter-14/section-08.md`

### v2026.07.19
- 근거 보강: residual connection 보충학습의 기준 출처에 Transformer 논문 NeurIPS 원문 페이지 링크와 확인 날짜를 추가했다.
- 번역 동기화 메모: 향후 번역본 작성 시 같은 출처 링크와 확인 날짜를 반영해야 한다.

### v2026.07.19
- 변경 이유: P5-14.2의 네 부품 역할 분담 안에서 residual connection 설명을 더 늘리면 Section 중심축이 무거워지므로, 원래 표현 흐름 보존만 따로 회수하는 보충학습 Section을 추가했다.
- 본문 반영: residual connection을 새 계산 생략이 아니라 원래 입력 표현과 새 계산 결과가 함께 다음 단계로 넘어가는 경로로 설명하고, 깊은 블록 반복에서 원래 표현 축이 왜 필요한지 사례와 연습으로 정리했다.
- 번역 동기화 메모: 영어·중국어 번역본을 새 9개 Section 구조의 P5-14.8에 맞춰 추가했다. 중복 예시 삭제와 `무엇을 남겨야 하는지 찾고 이유 설명하기` 연습 보강을 원문 기준으로 반영했다.
- 번역 반영 상태: 영어·중국어 반영 완료.
- 관련 자산: 기존 `residual-connection-skip-path-ko.mmd`를 재사용한다.
- 원문 기준 버전: `v2026.07.19`
- 번호 정리: P5-14.5~P5-14.8 병합에 따라 기존 P5-14.10 보충학습을 P5-14.8로 당겼다.
- Section 경계 정리: 미정 회수 표현을 줄이고, residual connection 보충학습의 중심을 수식 예고가 아니라 `원래 표현과 새 계산 결과가 함께 지나가는 구조 감각`으로 닫도록 조정했다.
- 연습 정리: residual 오해 문장 고치기 연습은 뒤 연습과 역할이 겹쳐 삭제하고, 남은 연습을 `무엇을 남겨야 하는지 찾고 이유 설명하기`로 보강해 원래 표현 축과 뒤 블록에서 필요한 이유를 함께 쓰게 했다.
- 사례 정리: 사례 결론을 반복하던 `두 가지 전달 방식 비교` 예시를 삭제해, 사례가 residual connection의 원래 표현 축 보존 역할만 직접 지지하도록 정리했다.
