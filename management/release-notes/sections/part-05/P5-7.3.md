# Section Release Note

- Section ID: `P5-7.3`
- Source File: `docs/parts/part-05/chapter-07/section-03.md`

### v2026.07.17
- 변경 이유: Chapter 7 재배치 과정에서 Adam 설명을 learning rate 절과 수렴 분석 보충절 사이에 놓고, `적응형 update의 직관`만 독립적으로 읽히게 할 필요가 생겼다.
- 본문 반영: P5-7.3을 `적응형 업데이트의 직관: Adam을 예로` 절로 다시 정리했다. 단순 update 기준을 먼저 두고, 적응형 업데이트가 최근 gradient 흐름과 좌표별 차이를 어떻게 더 반영하려 하는지 설명하도록 문단을 재배치했다. Adam-like 예제로 `현재 gradient에 바로 반응하는 update`와 `누적 정보를 반영하는 update`의 차이를 읽게 했다. 추가로 첫 도입 문장을 P5-7.2의 `같은 gradient라도 보폭이 달라진다`는 결론에서 자연스럽게 이어지도록 조정해, `모든 파라미터에 같은 보폭을 둘 것인가`라는 다음 질문이 더 직접 드러나게 했다. 또 `기본 직접 update 기준`만 남기고 SGD 명시는 걷어내, P5-7.2 전체가 SGD 설명처럼 역독해되거나 Adam 이해에 SGD 선행학습이 필요하다는 오해가 생기지 않도록 절 경계를 더 분명히 했다. 마지막으로 절을 직접 지지하지 못하던 사례 구간은 삭제하고, 도식과 예제가 적응형 업데이트의 핵심 직관을 바로 떠받치도록 흐름을 단순화했다. 이어서 본론 뒤에 남아 있던 역사·커리큘럼 성격의 해설은 걷어내고, `언제 Adam 관점을 먼저 꺼내는가` 표도 optimizer 이름 비교보다 `기본 직접 update 기준`과의 역할 구분이 드러나도록 정리했다. 이후 예제 도입부에는 `직관용 단순화 예제`라는 점을 더 앞에서 밝히고, 출력 해설과 체크리스트는 `시간축 누적`, `좌표축 조절`, `절대 우열 아님`이라는 현재 절의 핵심 질문에 더 밀착되게 축약했다. 추가로 절 첫 정의에서 `Adam(Adaptive Moment Estimation)`을 한 번 풀어, 약어 자체가 낯선 독자도 첫 문장부터 걸리지 않게 했다. 마지막으로 예제 변수명, 출력, 차트 범례, 차트 파일명까지 `direct_*`와 `direct-adam-*` 계열로 정리해, 본문뿐 아니라 차트 생성 스크립트와 자산 경로에서도 SGD가 설명 장치처럼 다시 호출되지 않도록 맞췄다. 이후 도입부와 핵심 해설 문장도 다시 엮어, `적응형 업데이트란 무엇인가 -> 왜 기준선이 필요한가 -> Adam은 그 직관을 어떻게 보여 주는가`의 순서가 문장 자체에서 더 직접 읽히도록 재구성했다. 마지막으로 중후반도 다시 조정해, `왜 Adam이 쓰이는가`보다 `적응형 업데이트의 두 축이 무엇인가`가 더 오래 남도록 예제 framing, 표 제목, 체크리스트 주어를 적응형 업데이트 중심으로 다시 맞췄다.
