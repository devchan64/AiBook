## 2026-07-16

### v2026.07.16
- 본문 반영: 실무 성능 주장과 수렴 보장 주장을 구분하고, adaptive optimizer 논문에서 먼저 확인할 objective 조건, gradient 조건, step size 조건, optimizer state 조건을 표와 사례로 정리했다. 사례 재검토 후 sparse feature 동기 사례를 줄이고, `실험 문장을 수렴 보장처럼 읽는 경우`와 `수렴 분석 문장을 실무 금지처럼 읽는 경우`로 조정해 중심축을 `주장 유형, 가정, 보장 범위 구분`에 맞췄다. 추가 재검토에서는 사례 앞에 읽기 순서를 명시하고, 연습을 `논문 읽기 카드` 형태로 바꿔 주장 유형, 반드시 찾을 조건, 넘어가면 안 되는 결론을 함께 쓰게 했다. Adam 원 논문, Adam 수렴 분석, AdaGrad 계열 JMLR 논문, AdamW 논문을 참고 자료로 연결했다.
