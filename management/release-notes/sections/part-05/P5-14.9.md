- 번호 정리: P5-14.5~P5-14.8 병합에 따라 기존 P5-14.11 보충학습을 P5-14.9로 당겼다.
- Section 경계 정리: layer normalization 보충학습에서 미정 회수 표현을 줄이고, 현재 Section의 중심을 `표현 의미`와 `값 스케일`의 구분으로 닫도록 조정했다.

- 연습 정리: P5-14.2의 역할 분담과 중복되어 실험 진입을 방해하던 `layer normalization 역할 구분하기`, `오해 문장 고치기` 연습을 삭제하고, 값 기준선 확인 예제와 값 범위 진단 연습만 남겼다.
- 예시 압축: 값 범위 문제를 표로 반복하던 예시를 Python 실험으로 들어가는 짧은 연결문으로 바꿔, 사례·예시·예제의 역할이 중복되지 않게 정리했다.
