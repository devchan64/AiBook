### v2026.07.19
- 근거 보강: layer normalization 보충학습의 기준 출처에 Transformer 논문 NeurIPS 원문 페이지 링크와 확인 날짜를 추가했다.

### v2026.07.19
- 변경 이유: P5-14.2의 네 부품 역할 분담 안에서 layer normalization 설명을 더 늘리면 Section 중심축이 무거워지므로, 값 기준선 정리와 normalization 용어 혼동만 따로 회수하는 보충학습 Section을 추가했다.
- 본문 반영: layer normalization을 의미 선택이 아니라 한 위치 표현 안의 값 평균과 퍼짐을 맞추는 안정화 장치로 설명하고, batch normalization 및 residual connection과의 차이를 사례와 연습으로 정리했다.
- 번역 동기화 메모: 영어·중국어 번역본을 새 9개 Section 구조의 P5-14.9에 맞춰 추가했다. 값 범위 예시를 Python 실험 연결문으로 압축한 최신 원문과 layer normalization 전후 기준선 확인 예제를 반영했다.
- 번역 반영 상태: 영어·중국어 반영 완료.
- 관련 자산: 기존 `layer-normalization-value-scale-ko.mmd`를 재사용한다.
- 원문 기준 버전: `v2026.07.19`
- 번호 정리: P5-14.5~P5-14.8 병합에 따라 기존 P5-14.11 보충학습을 P5-14.9로 당겼다.
- Section 경계 정리: layer normalization 보충학습에서 미정 회수 표현을 줄이고, 현재 Section의 중심을 `표현 의미`와 `값 스케일`의 구분으로 닫도록 조정했다.
- Python 실습 보강: Python 예제 작성 가이드 기준으로 P5-14.9를 실험형 예제 후보로 판단하고, 표현값의 평균·표준편차와 다음 계산 점수가 layer normalization 전후에 어떻게 달라지는지 확인하는 예제를 추가했다.
- 연습 정리: P5-14.2의 역할 분담과 중복되어 실험 진입을 방해하던 `layer normalization 역할 구분하기`, `오해 문장 고치기` 연습을 삭제하고, 값 기준선 확인 예제와 값 범위 진단 연습만 남겼다.
- 예시 압축: 값 범위 문제를 표로 반복하던 예시를 Python 실험으로 들어가는 짧은 연결문으로 바꿔, 사례·예시·예제의 역할이 중복되지 않게 정리했다.
