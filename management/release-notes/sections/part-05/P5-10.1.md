### v2026.07.14
- 변경 이유: 표현 학습 예제는 `risk_score`와 `representation` 좌표를 함께 출력하지만, 텍스트 숫자만으로는 한 줄 점수에서는 가까운 배치가 표현 좌표에서는 멀어지는 장면을 즉시 보기 어려웠다.
- 본문 반영: 예제 출력 뒤에 hand-crafted risk score 막대 그래프와 2차원 representation 좌표 그래프를 각각 분리 PNG로 추가했다.
- 변경 이유: 사례 네 개가 모두 같은 결론을 향해 가면서도 장문으로 나열되어, P5-10.1의 핵심인 `수작업 축에서 표현 좌표로 바뀐다`는 학습 초점이 분산될 수 있었다.
- 본문 반영: `사례 및 예시`를 정비 우선순위 추천 대표 사례 중심으로 재정렬하고, 이미지 검사·정비 로그 검색·품질 검사 자동화는 확장 예시 표로 압축했다.
- 변경 이유: 기존 Python 예제가 생산 배치 장면으로 분리되어, 대표 사례인 정비 우선순위 추천과 직접 이어지지 않았다.
- 본문 반영: Python 예제 입력을 설비 라인별 온도 경보 연속 횟수, 압력 불안정 횟수, 재작업 호출 횟수로 재구성하고, 같은 `risk_score`를 가진 `line_A`와 `line_B`가 표현 좌표에서는 다른 위험 유형으로 갈라지는 흐름으로 바꿨다.
- 변경 이유: 예제의 표현 축을 고정 가중치로 적어 두면 표현 학습을 `사람이 정한 축을 대입하는 일`로 오해할 위험이 있었다.
- 본문 반영: Python 예제를 입력 데이터에서 두 표현 축을 계산하는 방식으로 바꾸고, `line_b_rework_calls`를 조작값으로 두어 독자가 값 변경에 따른 점수와 표현 좌표 변화를 다시 확인할 수 있게 했다.
- 번역 동기화 메모: 향후 번역 시 `single score -> representation coordinate` 산출물 그래프 순서와 해설 구조를 유지해야 한다.

### v2026.07.12
- 변경 이유: 표현 학습 도입 절의 말미 자기 확인 구조가 여러 표지로 분산되어 기준서의 `체크리스트` 단일화 원칙과 맞지 않았다.
- 추가 반영: 집필 순서만 예고하는 메타형 연결 표지를 제거했다.
- 본문 반영: 표현 학습 정의, 특징 공학과의 차이, 다차원 표현 사례, CNN·임베딩·LLM 공통 축을 `체크리스트` 하나로 통합했다.
- 변경 이유: 기존 예제와 사례는 표현 학습의 의미를 보여 주고 있었지만, `왜 한 줄 점수나 수작업 규칙만으로는 부족한가`를 운영 장면에서 하나의 판단축으로 다시 읽게 하는 압력이 약했다.
- 본문 반영: `연습 및 예제`를 생산 배치의 마이크로 스톱 횟수와 온도 이탈 지속 시간 비교로 재구성하고, 거의 같은 `risk_score`를 가진 `batch_1`과 `batch_2`가 representation 좌표에서는 멀어지는 장면을 만들었다. 실행 전 예측 표, `score_gap`/`representation_gap` 비교, 출력 뒤 해설 표를 추가해 단일 점수와 다차원 표현의 차이를 다시 읽게 했다.
- 변경 이유: 사례 본문과 도입부 예시에 소비자 데이터 문구가 남아 있어 절 전체 톤이 운영 데이터 모델링 흐름과 어긋났다.
- 본문 반영: 사례 1을 포장 라인의 실링 상태 분류로, 사례 2를 정비 우선순위 추천으로, 사례 3을 정비 로그 임베딩으로 바꿨다. 도입부 표와 `표현이란 무엇인가` 절의 대표 입력 예시, 층위 표도 최근 온도 이탈, 압력 흔들림, 재기동 지연 같은 설비 운영 신호 기준으로 다시 정리했다. 내부 표현 예시도 `활동성/관심도` 대신 `열적 부담/운전 불안정성/후속 점검 시급도`처럼 현재 절의 운영 판단 흐름에 맞췄다.
- 변경 이유: 표현 학습 절의 사례들이 각각은 타당했지만, 네 사례와 예제를 묶어 `표현 좌표가 왜 필요한가`를 한 번 더 압축할 필요가 있었다.
