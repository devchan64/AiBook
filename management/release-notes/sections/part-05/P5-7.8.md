### v2026.07.17
- 변경 이유: Chapter 7 보충학습을 확장하면서, optimizer 설명 다음에 실제 로그에서 자주 만나는 `불안정한 update`와 clipping 안전장치를 구분하는 회수 절이 필요해졌다.
- 본문 반영: 새 보충학습 `P5-7.8 보충학습: gradient clipping과 불안정한 update`를 추가했다. gradient clipping을 optimizer와 다른 층위의 안전장치로 설명하고, learning rate 과대, gradient scale 폭주, optimizer state 문제를 분리해 이해하는 기준을 표와 사례로 정리했다. norm clipping과 value clipping의 차이도 입문 수준에서만 구분했다.
- 본문 반영: clipping 설명이 정의 중심으로만 읽히던 부분을 풀어 써, optimizer, learning rate, clipping이 서로 다른 층위라는 점을 더 직접 설명했다. 사례와 진단 문장도 확장해 `불안정하다`는 관찰을 왜 더 작은 질문으로 나눠야 하는지가 드러나도록 조정했다.
- 본문 반영: clipping을 방향 결정이 아니라 과격한 입력 제한으로 읽게 하는 작은 장면, learning rate 문제와 순간 gradient 폭주를 구분하는 작은 장면, 설정 파일에서 optimizer/lr/clip이 함께 보일 때의 해석 문단을 추가해 초심자용 설명 밀도를 더 올렸다.
- 본문 반영: gradient 크기와 update 크기를 단순 곱셈으로 다시 적어, clipping이 실제로는 `입력 규모를 줄여 update를 눌러 주는 장치`라는 점을 비전공 독자도 숫자로 확인할 수 있게 했다.
- 본문 반영: clipping을 `처음 읽는 개념`처럼 안내하던 표현을 줄이고, optimizer와 다른 층위의 안전장치라는 설명축이 더 직접 드러나도록 문장 톤을 정리했다.
- 본문 반영: 도입을 `P5-7.1부터 P5-7.7` 식의 Chapter 내부 회고보다 실제 학습 로그 진단으로 시작하도록 바꾸고, 뒤 Part의 깊은 모델 학습과 fine-tuning 로그에도 같은 진단 기준을 재사용한다는 문장을 추가했다.
- 본문 반영: 불안정한 update를 learning rate, gradient scale, clipping 문제로 나누어 보는 진단 순서를 새로 추가하고, norm clipping과 value clipping 차이도 짧은 비유로 다시 풀어 써 초심자 기준 학습 밀도를 높였다.
- 본문 반영: 불안정한 update를 볼 때 `전체 보폭 문제인지`, `순간 입력 문제인지`, `clipping을 먼저 볼지`를 고르는 Mermaid 진단 도식을 추가해, 사례 문단의 해석 순서를 시각적으로 다시 잡았다.
- 본문 반영: `clipping-spike-comparison-ko.png` 그래프를 추가해, 특정 step에서만 튄 raw update가 clipping 뒤에는 어떻게 눌리는지 시각적으로 비교할 수 있게 했다.
- 번역 동기화 메모: 대응 번역본 없음. 향후 번역 시 clipping이 방향을 새로 정하는 장치처럼 읽히지 않도록, `크기를 제한하는 안전장치`라는 핵심 문장을 유지해야 한다.
- 번역 반영 상태: 향후 번역 반영 필요
