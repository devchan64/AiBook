### v2026.07.19
- 신규 분리: 기존 P5-14.2의 RNN 대비 설명을 `RNN의 상태 전달과 Transformer의 관계 계산은 어떻게 다른가` Section으로 독립시켰다.
- 본문 반영: RNN을 순차 상태 전달, Transformer를 토큰 관계 계산으로 대비하고, 작업 허가 문장의 마지막 질문 사례와 계산 흐름 분류 연습을 추가했다.
- 병합 반영: 사용자 지시에 따라 기존 `P5-14.6 관계 계산은 왜 GPU 병렬 처리와 잘 맞는가`를 현재 Section에 합쳐, 계산 흐름 비교와 GPU 병렬 처리 적합성을 하나의 중심축으로 재구성했다.
- 제목 갱신: 병합 뒤 제목을 `RNN의 상태 전달과 Transformer의 관계 계산은 병렬 처리에서 어떻게 갈라지는가`로 바꿔, 상태 전달/관계 계산 대비가 병렬 처리 설명까지 이어짐을 드러냈다.
- 제목 정리: Section 제목에서 비교 대상을 `상태 전달`과 `관계 계산`으로 직접 드러내도록 조정했다.
- 메타데이터 정리: 본문 제목 아래 `Section ID`와 `Version`을 현재 Section 메타데이터 가이드 형식에 맞춰 blockquote 표기로 정리했다.
- 도입 문장 정리: 시간순 비교가 아니라 계산 흐름 차이라는 기준이 먼저 보이도록 메타 표현을 줄였다.
- 학습 밀도 보강: 관찰 신호별로 RNN식 상태 전달과 Transformer식 관계 계산을 비교하는 표를 추가하고, 마지막 판단에 필요한 단서 경로를 찾는 연습을 보강했다.
- 사례·연습 재보강: 작업 허가 문장을 6개 줄로 분해해 마지막 질문에 필요한 규칙·상태 단서가 어떤 계산 흐름으로 연결되는지 보이게 하고, 줄 표시하기·계산 경로 완성하기·장면별 계산 감각 고르기 연습으로 실습형 학습 밀도를 높였다.
- Section 경계 정리: P5-14.5는 긴 문맥의 단서 약화가 아니라 `기다려야 하는 순차 계산`과 `묶을 수 있는 행렬 계산`을 중심축으로 닫도록 사례와 해설을 조정했다. 먼 단서의 직접 재참조 문제는 P5-14.6으로 넘긴다.
- Python 실습 보강: Python 예제 작성 가이드 기준으로 P5-14.5를 실험형 예제 후보로 판단하고, 순차 상태 trace와 관계 score 행렬·배치 score 텐서 shape를 비교하는 예제를 추가했다.
- 연습 정리: Python 실습과 중복되어 흐름을 늦추던 `마지막 질문에 필요한 줄 표시하기`, `병렬 처리 관점으로 다시 말하기` 연습을 삭제하고, 계산 trace·행렬 shape 예제와 최종 분류 연습만 남겼다.
- 사례 압축: 작업 허가 문장 사례에서 긴 문맥 단서 설명과 배치 문장 나열을 줄이고, `기다려야 하는 step 계산`과 `묶을 수 있는 관계 행렬 계산`을 구분하는 중심축만 남겼다.
- 번역 동기화 메모: 영어·중국어 번역본을 새 9개 Section 구조의 P5-14.5에 맞춰 추가했다. RNN식 순차 trace, Transformer식 관계 score 행렬, 배치 score tensor shape 예제를 원문 기준으로 반영했다.
- 번역 반영 상태: 영어·중국어 반영 완료.
