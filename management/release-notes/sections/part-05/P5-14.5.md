### v2026.07.20
- 예제 의도 보강: Python 예제가 정해진 답을 판정하는 코드처럼 읽히지 않도록 순차·직접 재참조 양쪽의 결정 라벨을 제거하고, `sequential_support`와 현재 요청-앞 줄 단어 축 비교에서 어떤 줄이 상위 근거로 떠오르는지 관찰하는 예제로 조정했다.
- 설명 밀도 보강: 관계 점수를 마지막 요청 위치가 앞 단서들과 다시 비교해 얻는 관련도로 풀고, 규칙 줄·상태 줄·무관한 로그 줄을 다시 비교하는 장면을 원문·영문·중문에 추가했다.
- 사례 해설 보강: 순차 상태가 앞 단서를 없애는 것이 아니라 여러 중간 정보와 섞이며 마지막 판단에서 선명도가 약해질 수 있다는 설명을 추가했다.
- 본문 보강: self-attention의 직접 재참조 감각을 `현재 위치와 앞 위치 사이의 관계 점수를 다시 계산한다`는 표현으로 풀고, 원문·영문·중문에 동기화했다.
- 도식 해설 보강: 연속 Mermaid 두 개의 역할을 각각 긴 문맥 개념 경로와 같은 요청의 두 근거 경로 비교로 분리해 설명했다.
- 예제 경계 보강: `direct_reference_reader`가 실제 attention 구현이 아니라 키워드 점수로 앞 줄을 다시 찾는 축약 모델임을 명시했다.
- 근거 보강: RNN 순차 상태 전달과 긴 의존성 설명의 배경 출처로 Goodfellow et al. `Deep Learning`을 원문·영문·중문 참고 자료에 추가했다.
- 번호 정리: 옛 P5-14.3 삭제에 따라 기존 P5-14.6을 현재 P5-14.5로 당기고, 한국어·영어·중국어 간체판의 제목, Section ID, Version, 내부 참조를 새 번호 체계에 맞췄다.
- 본문 반영 내용: 한국어판 Python 예제 첫 줄에 긴 문맥에서 순차 상태가 약해지는 과정과 direct reference가 앞 규칙을 다시 찾는 과정을 비교하는 목적을 설명하는 주석을 추가했다.
- 저작권 검토: Part 5 Module 5 순차 검토 범위에서 긴 문맥, 순차 상태와 직접 재참조 대비, `sequential_support`와 상위 matched line Python 예제를 확인했다. 사례·표·예제 코드는 자체 작성 자료로 판단했다.
- 출처 사용 점검: Transformer 논문은 self-attention과 직접 재참조 배경 확인 용도로만 연결되어 있으며, 원문 실험·도식·코드·문단 재사용 정황은 찾지 못했다.
- 관련 자산: `long-context-*.mmd`, `sequential-state-decay-ko.png`, `direct-reference-match-scores-ko.png`는 자체 Mermaid와 로컬 생성 스크립트 기반 자산으로 판단했다.
