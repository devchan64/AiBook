### v2026.07.19
- 변경 이유: P5-14.2의 네 부품 역할 분담 안에서 feed-forward network 설명을 더 늘리면 Section 중심축이 무거워지므로, 위치별 표현 가공만 따로 회수하는 보충학습 Section을 추가했다.
- 본문 반영: feed-forward network를 self-attention 이후의 위치별 비선형 표현 가공으로 설명하고, 같은 FFN이 여러 위치에 공유 적용되지만 입력 표현 차이에 따라 출력이 달라지는 점을 사례와 연습으로 정리했다.
- 번역 동기화 메모: 현재 한국어 원문만 추가했다. 향후 영어·중국어 번역 시 P5-14.2의 역할 분담과 P5-14.3의 표현 이동 예제 사이를 잇는 보충학습으로 유지해야 한다.
- 번역 반영 상태: 미반영.
- 관련 자산: 기존 `feed-forward-position-update-ko.mmd`를 재사용한다.
- 원문 기준 버전: `v2026.07.19`
- 번호 정리: P5-14.5~P5-14.8 병합에 따라 기존 P5-14.9 보충학습을 P5-14.7로 당겼다.
- Section 경계 정리: 보충학습 본문에서 진행 메타에 가까운 표현을 줄이고, feed-forward network의 경계를 `관계 선택이 아니라 위치별 표현 가공`으로 닫도록 문장을 조정했다.
- Python 실습 보강: Python 코드로 설명할 때 효과적인 Section으로 판단하고, 같은 FFN 가중치를 여러 위치에 공유 적용해도 입력 표현 차이에 따라 hidden/output이 달라지는 예제를 추가했다.
- 연습 정리: P5-14.2의 역할 분담과 겹치던 attention/FFN 역할 구분 연습을 삭제하고, Python 예제와 현재 위치 표현을 말로 바꾸는 연습만 남겼다.
