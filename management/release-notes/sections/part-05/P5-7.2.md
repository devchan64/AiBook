### v2026.07.17
- 변경 이유: Chapter 7 재배치 과정에서 learning rate 설명을 Adam 설명과 분리해, `같은 gradient라도 update 보폭이 왜 달라지는가`를 독립 절로 닫을 필요가 생겼다.
- 본문 반영: P5-7.2를 `학습률(learning rate)과 update 보폭` 중심 절로 다시 정리했다. optimizer 역할을 전제로 learning rate가 update에 어디에 붙는지, 보폭이 너무 작거나 클 때 어떤 차이가 생기는지, 같은 gradient가 다른 결과로 이어지는 장면을 사례와 예제로 재배치했다. 추가로 핵심 설명, 사례, 예제 해설을 덜 압축된 문장으로 다시 풀어 써, `같은 gradient`, `다른 learning rate`, `달라진 update 결과`가 더 직접 읽히도록 보강했다. 예제 출력도 `shared state`와 `lr`별 결과 구간으로 나누어, 같은 출발점 위 비교라는 구조가 형식만 봐도 드러나게 정리했다. 이후 사례 구간은 두 개의 느슨한 장면 대신 `같은 gradient인데 learning rate만 다른 경우` 하나의 비교 장면으로 다시 묶어, 현재 절의 중심 질문을 더 직접 지지하게 조정했다. 마지막으로 사례 문단 자체도 `상황 -> 처음 해석 -> learning rate 관점으로 전환 -> 세 경우 비교 -> 현재 절과의 연결` 순서로 더 풀어 써, 문장만 읽어도 비교 장면이 살아나도록 다듬었다. 추가로 설명 초반의 가장 단순한 update 식은 MathJax 수식으로 정리해, 학습률이 실제 이동량 크기를 정하고 그 결과가 파라미터 반영으로 이어진다는 점이 텍스트 블록보다 더 또렷하게 읽히도록 다듬었다.
- 본문 반영: 범위 안내의 handoff 문장에 `P5-7.6 보충학습`을 추가해, learning rate를 학습 내내 어떻게 운영하는지에 대한 질문이 현재 절 밖에서 어디로 이어지는지 분명히 했다.
- 번역 동기화 메모: 대응 번역본 없음. 향후 번역 시 P5-7.2는 Adam 비교 절로 번지지 않게 하고, learning rate와 step size 설명 자체를 중심에 두어야 한다.
