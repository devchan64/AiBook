### v2026.07.19
- 신규 분리: 기존 P5-14.1의 블록 내부 표현 갱신 예제를 `토큰 표현은 Transformer 블록 안에서 어떻게 이동하는가` Section으로 독립시켰다.
- 본문 반영: `입력 표현 -> contextual tokens -> feed-forward output -> after residual -> normalization` 흐름을 중심축으로 삼고, action token 표현 이동 예제를 통해 같은 입력도 attention 가중치에 따라 다른 블록 출력으로 남는다는 점을 설명했다.
- 예제 보강: Python 예제 앞에 조작할 attention 비중, 관찰할 출력, 확인할 질문을 명시하고, action token 행을 바꿔 보는 연습과 해설을 추가해 실험형 예제의 학습 밀도를 높였다.
- 제목 정리: Section 제목에 `토큰 표현`과 `이동`을 명시해 표현 갱신 흐름 중심축을 더 직접 드러냈다.
- 메타데이터 정리: 본문 제목 아래 `Section ID`와 `Version`을 현재 Section 메타데이터 가이드 형식에 맞춰 blockquote 표기로 정리했다.
- 도입 문장 정리: 부정형 범위 안내를 줄이고, 표현 갱신 흐름 자체가 중심축으로 보이도록 문장을 다듬었다.
- 사례 보강: action token 사례에 사람이 먼저 쓰기 쉬운 기준과 표현 갱신 관점의 차이를 추가하고, 두 장면의 action token 출력이 달라지는 확인 결과를 표로 보강했다.
- 도식 정리: `transformer-representation-update` Mermaid 자산에서 residual과 normalization을 분리해, 본문 표의 `입력 표현 -> self-attention 이후 -> feed-forward 이후 -> residual 이후 -> normalization 이후` 흐름과 맞췄다.
- 그래프 검증: `p5_14_1_transformer_block_charts.py` 재실행으로 `transformer-block-action-stage-trace` PNG가 다시 생성됨을 확인했고, 한국어 PNG의 한글 라벨과 단계 표시를 직접 확인했다.
- 번역 동기화 메모: 기존 영어·중국어 번역본은 재분해 전 구조이므로, 향후 번역 시 P5-14.3을 별도 Section으로 추가해야 한다.
