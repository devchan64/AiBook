### v2026.07.17
- 변경 이유: Chapter 7 보충학습 구조를 확장하면서, Adam 하나만 대표 예로 본 뒤 optimizer 계열 이름을 어디서 회수할지 별도 절이 필요해졌다.
- 본문 반영: 새 보충학습 `P5-7.5 보충학습: momentum, AdaGrad, RMSProp, Adam`을 추가했다. optimizer 계열 비교를 우열표가 아니라 `무엇을 더 기억하는가`, `무엇을 더 조절하는가`, `무엇을 해결하려 했는가`의 세 축으로 설명하도록 재구성했다. momentum, AdaGrad, RMSProp, Adam이 서로 어떤 문제의식 위에 놓이는지 표, 사례, 연습으로 정리했다.
- 본문 반영: 압축도가 높았던 설명을 다시 풀어, `이름 계보를 외우는 절`이 아니라 `기준선에서 무엇이 하나씩 추가되는가`를 읽는 절이라는 점이 더 직접 보이도록 보강했다. momentum, AdaGrad/RMSProp, Adam을 설명하는 핵심 문단과 사례 해설도 확장해 독자가 표 이전에 문장만으로도 차이를 따라갈 수 있게 조정했다.
- 본문 반영: 각 optimizer 설명마다 초심자용 작은 장면을 더 넣어, 방향 기억, 좌표별 누적, 두 축의 결합이 실제로 어떤 상황에서 필요한지 문장만으로도 손에 잡히게 보강했다.
- 본문 반영: momentum과 AdaGrad/RMSProp 차이를 수치 흐름 표로 다시 적어, 비전공 독자도 `흔들림`, `누적`, `최근 평균`의 차이를 숫자 순서로 따라가 볼 수 있게 했다.
- 본문 반영: `처음 읽을 때` 같은 안내 표현을 걷어 내고, optimizer 이름 나열을 구조 비교로 바꾸는 절이라는 점이 더 직접 보이도록 도입, 목표, 소제목, 체크리스트의 표현을 정리했다.
- 본문 반영: 도입에 이 절의 세 질문이 뒤에서 다른 optimizer 계열을 다시 만날 때도 그대로 재사용된다는 문장을 더해, Chapter 7 한정 보조 절처럼 보이는 느낌을 줄였다.
- 본문 반영: 초심자가 네 optimizer를 한 번에 외우려다 막히지 않도록, `momentum / AdaGrad / RMSProp / Adam`을 한 줄씩 먼저 잡는 요약 표와 도입 해설을 추가해 비교 기준이 먼저 보이게 보강했다.
- 본문 반영: `기본 직접 update -> momentum -> AdaGrad/RMSProp -> Adam`의 추가 요소를 Mermaid 도식으로 압축해, 이름 나열이 아니라 구조 확장 흐름으로 다시 읽게 보강했다.
- 본문 반영: Chapter 7 자산 폴더의 `sgd-adam-gradient-history-ko.png`, `sgd-adam-delta-comparison-ko.png`, `sgd-adam-risk-weight-trajectory-ko.png`를 본문에 배치해, 같은 gradient history가 직접 update와 Adam-like update에서 다른 step 크기와 다른 parameter path를 만든다는 점을 그래프로 다시 읽게 보강했다.
- 번역 동기화 메모: 대응 번역본 없음. 향후 번역 시 optimizer 이름 비교가 성능 순위처럼 읽히지 않도록, `기억 방식과 조절 방식의 구분`을 중심 구조로 유지해야 한다.
- 번역 반영 상태: 향후 번역 반영 필요
