### v2026.07.06-2

- 변경 이유: 참조·복사 보충 설명의 구분 표와 본편 복귀 문장에 남아 있던 메타형 학습 안내를 줄이고, 원본 공유 판단 기준을 직접 설명하는 문장으로 정리할 필요가 있었다.
- 본문 반영: 참조/복사 요약 문단, Pandas 연결 문장, 절 마무리 복귀 문장에서 `충분합니다`류 표현을 제거하고, 대입·얕은 복사·깊은 복사 구분과 본편 복귀 시점을 직접 진술하도록 다듬었다.
- 번역 동기화 메모: 번역본이 생기면 같은 `Section ID` 기준으로 참조·복사 보충 설명 문장을 직접 진술형으로 유지하고, 메타형 학습 안내 표현을 다시 늘리지 않도록 맞춘다. / 향후 반영 필요.
