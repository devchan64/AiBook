# Section Release Note

- Section ID: `P2-3.3`
- Source File: `docs/parts/part-02/chapter-03/section-03.md`

### v2026.07.09

- 변경 이유: 한국어 본문이 영문 기준 도식을 직접 참조하고 있어, 도식 기준 원본은 영문으로 유지하되 한국어 본문에는 한글 파생 도식을 연결할 필요가 있었다. 같은 작업 안에서 Chapter 3 번역본도 함께 배포 경로에 추가했다.
- 본문 반영: 한국어 본문의 도식 참조를 `matrix-multiplication-position-change-ko.svg`로 교체하고, 영문 기준 자산 `matrix-multiplication-position-change-en.svg`를 분리했다. 또한 영어 `docs/en/parts/part-02/chapter-03/section-03.md`와 중국어 간체 `docs/zh/parts/part-02/chapter-03/section-03.md` 초안을 추가했다.
- 번역 동기화 메모: 행렬 곱을 `가중합 재사용`과 `표현 변환`으로 읽는 핵심 설명, 그리고 영문 기준 도식/한글 파생 도식 구조를 영어·중문 번역본에도 반영했다.
- 번역 반영 상태: 영문/중문 반영 완료
- 관련 자산: `docs/assets/part-02/chapter-03/matrix-multiplication-position-change-en.svg`, `docs/assets/part-02/chapter-03/matrix-multiplication-position-change-ko.svg`, `docs/en/parts/part-02/chapter-03/section-03.md`, `docs/zh/parts/part-02/chapter-03/section-03.md`, `mkdocs.yml`
- 원문 기준 버전: `v2026.07.09`

### v2026.07.09

- 변경 이유: 기존 영문·중문 번역본은 행렬 곱의 핵심 정의만 남은 축약본이어서, 가중합 예시, 배치 계산, 선형 변환 도식 해석, 사례 문단이 원문 수준으로 유지되지 않았다.
- 본문 반영: 영어판 `docs/en/parts/part-02/chapter-03/section-03.md`와 중국어간체판 `docs/zh/parts/part-02/chapter-03/section-03.md`를 한국어 원문 기준으로 다시 확장해, 위치별 곱과의 차이, `xW` 계산 예시, 배치 행렬 `XW`, 선형 변환 도식 설명, 사례와 점검 문항까지 같은 구조로 복원했다.
- 번역 동기화 메모: 표 3개, 수식 전개, 코드 블록 4개, 도식 참조, `행렬 곱은 무엇을 재사용하는가` 정리 문단을 영문·중문에 모두 같은 순서로 맞췄다.
- 번역 반영 상태: 영어 번역 반영, 중국어간체 번역 반영
- 관련 자산: `docs/en/parts/part-02/chapter-03/section-03.md`, `docs/zh/parts/part-02/chapter-03/section-03.md`
