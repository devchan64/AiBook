# Section Release Note

- Section ID: `P2-8.5`

### v2026.07.09

- 변경 이유: 함수 재사용의 핵심 설명은 충분했지만, 앞 절의 값/자료구조/반복 흐름에서 함수 절로 넘어오는 연결 신호가 도입부와 말미에서 더 분명할 필요가 있었다.
- 본문 반영:
  - `이번 절에서 먼저 붙잡을 흐름` 블록을 추가해 반복되는 처리에 이름을 붙이는 이유, `입력 -> 처리 -> 출력` 경계, `print`와 `return`의 차이를 먼저 잡게 했다.
  - 말미 요약에 앞 절의 값, 리스트/딕셔너리, 반복문이 함수로 어떻게 다시 묶이는지 연결 문장을 보강했다.
- 본문 반영: `이 절의 범위`에서 `이미 하던 처리를 어떻게 재사용 가능한 작은 단위로 묶을 것인가`라는 중심 질문을 먼저 세우고, `P2-8.6`과 이후 Python 예제 전반으로 이어지는 짧은 흐름을 보강했다.
- 본문 반영: 따로 떨어져 있던 `사례로 보기`를 기존 `사례 및 예시` 구간으로 옮겨 사례 축을 한곳으로 정리했다.
- 번역 동기화 메모: 함수 도입부의 `reuse of previous flow`와 `input-process-output contract` 연결을 영어·중문 번역본에도 유지하도록 반영했다.
- 번역 동기화 메모: 이번 문단 재배치는 한국어 원고의 구조 정리에 한정되며, 영문/중문 원고에는 같은 사례 축 분리 문제가 없어 추가 수정하지 않았다.
- 번역 반영 상태: 영문/중문 반영 완료
