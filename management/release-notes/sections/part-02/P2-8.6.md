# Section Release Note

- Section ID: `P2-8.6`
- Source File: `docs/parts/part-02/chapter-08/section-06.md`

### v2026.07.09

- 변경 이유: 클래스 보충학습이 내용은 충분했지만, 독자가 `value.method()`와 `object.attribute`를 한눈에 읽는 최소 기준을 더 빨리 잡게 할 구조 신호가 필요했다.
- 본문 반영: `먼저 붙잡을 기준` 표, 기억할 관점과 짧은 점검을 추가해 객체·클래스·메서드의 역할 차이를 더 전면에 두었다.
- 본문 반영: `이 보충학습의 범위`에서 `점(.)이 붙은 호출을 어떤 기준으로 읽어야 하는가`라는 중심 질문을 먼저 세우고, `P2-8.7`과 이후 라이브러리 메서드 읽기 구간으로 이어지는 흐름을 보강했다.
- 본문 반영: 본문 중간에 끼어 있던 `이 보충학습에서 기억할 관점`, `짧은 점검`을 말미 정리 구간으로 모아 흐름을 단일 마감으로 정리했다.
- 번역 동기화 메모: 메서드 호출과 속성 접근을 구분하는 시작 요약을 영어·중문 번역본에도 같은 대비 구조로 반영했다.
- 번역 동기화 메모: 이번 문단 재배치는 한국어 원고의 구조 정리에 한정되며, 영문/중문 원고에는 같은 중간 마감 블록 중복이 없어 추가 수정하지 않았다.
- 번역 반영 상태: 영문/중문 반영 완료
- 관련 자산: `docs/en/parts/part-02/chapter-08/section-06.md`, `docs/zh/parts/part-02/chapter-08/section-06.md`, `mkdocs.yml`
- 원문 기준 버전: `v2026.07.09`

### v2026.07.09

- 변경 이유: 기존 영문·중문 번역본은 객체·클래스 도입의 최소 요약만 남은 축약본이어서, dot 호출 예시, 딕셔너리와 클래스 비교, `self`, AI 라이브러리 메서드 해석이 원문 수준으로 유지되지 않았다.
- 본문 반영: 영어판 `docs/en/parts/part-02/chapter-08/section-06.md`와 중국어간체판 `docs/zh/parts/part-02/chapter-08/section-06.md`를 한국어 원문 기준으로 다시 확장해, 시작 기준 표, 타입/메서드 예시, 클래스 정의, 딕셔너리 대비, 상태와 동작, `self`, `model.fit()` 해석, 사례와 점검 문항까지 같은 구조로 복원했다.
- 번역 동기화 메모: 표 10개, 코드 블록 13개, 사례 1개, 출처 3개를 영문·중문에 모두 같은 순서로 반영했다.
- 번역 반영 상태: 영어 번역 반영, 중국어간체 번역 반영
- 관련 자산: `docs/en/parts/part-02/chapter-08/section-06.md`, `docs/zh/parts/part-02/chapter-08/section-06.md`
