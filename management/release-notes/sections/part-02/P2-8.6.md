# Section Release Note

### v2026.07.09

- 변경 이유: 클래스 보충학습이 내용은 충분했지만, 독자가 `value.method()`와 `object.attribute`를 한눈에 읽는 최소 기준을 더 빨리 잡게 할 구조 신호가 필요했다.
- 본문 반영: `먼저 붙잡을 기준` 표, 기억할 관점과 짧은 점검을 추가해 객체·클래스·메서드의 역할 차이를 더 전면에 두었다.
- 본문 반영: `이 보충학습의 범위`에서 `점(.)이 붙은 호출을 어떤 기준으로 읽어야 하는가`라는 중심 질문을 먼저 세우고, `P2-8.7`과 이후 라이브러리 메서드 읽기 구간으로 이어지는 흐름을 보강했다.
- 번역 동기화 메모: 메서드 호출과 속성 접근을 구분하는 시작 요약을 영어·중문 번역본에도 같은 대비 구조로 반영했다.
- 번역 반영 상태: 영문/중문 반영 완료
