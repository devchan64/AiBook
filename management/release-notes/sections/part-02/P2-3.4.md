# Section Release Note

- Section ID: `P2-3.4`
- Source File: `docs/parts/part-02/chapter-03/section-04.md`

### v2026.07.08

- 변경 이유: 벡터와 행렬은 복구했지만, 초심자가 `가깝다`, `비슷하다`, `내적`, `코사인 유사도`를 잇는 비교 기준을 갖기 전에는 k-NN, 임베딩, 벡터 검색 설명이 갑자기 추상적으로 뛰는 문제가 있었다.
- 본문 반영: `내적(dot product), 길이(norm), 거리(distance), 유사도(similarity)` Section을 `P2-3.4`로 재배치해, 행렬 곱 다음에 벡터 비교 기준이 바로 오도록 구조를 정렬했다.
- 추가 정리: 내적 계산 예시, 길이와 방향 구분, 거리와 유사도의 질문 차이, 코사인 유사도 비교 장면을 포함한 본문을 `P2-3.4`의 대표 설명 위치로 고정했다.
- 번역 반영 상태: 향후 번역 반영 필요

### v2026.07.09

- 변경 이유: 독자가 `가깝다`, `비슷하다`, `크다`, `같은 방향이다`를 같은 말처럼 읽으면 k-NN, 임베딩, 벡터 검색의 비교 질문이 다시 섞일 가능성이 있었다.
- 본문 반영: 같은 쿼리 벡터와 여러 비교 벡터를 한 장면으로 묶는 시작 표, `질문 -> 비교 기준` 표, 길이/방향 비교 표, 거리와 방향 유사성의 차이를 다시 읽는 비교 표, 기억할 관점과 짧은 점검을 추가했다.
- 번역 동기화 메모: 벡터 비교 질문을 `distance`, `similarity`, `dot product`, `norm`으로 분리하는 구조를 영어·중문 번역본에도 반영했다.
- 번역 반영 상태: 영문/중문 반영 완료
