# Section Release Note

- Section ID: `P2-4.3`
- Source File: `docs/parts/part-02/chapter-04/section-03.md`

### v2026.07.09

- 변경 이유: 미분, 편미분, 그래디언트의 정의는 충분했지만, 절 초반 메타 연결이 길어 `한 변수 기울기 기억이 여러 변수 그래디언트로 어떻게 확장되는가`라는 핵심 질문이 늦게 드러났다.
- 본문 반영: 초반 연결 표를 줄이고 `이 절의 범위`에서 중심 질문을 먼저 세운 뒤, `P2-4.4`, `P2-4.5`, Part 4로 이어지는 짧은 읽기 흐름을 추가해 개념 구분이 더 빨리 보이도록 다듬었다.
- 번역 동기화 메모: 기존 영문·중문 번역본이 개념 정의만 남긴 요약형 초안이어서, 한글 원문의 미분/편미분/그래디언트 구분, 미분계수와 도함수 구분, 작은 손실 함수 예시, 현장 사례, 반복해서 만나는 용어 표, 점검 문항까지 같은 구조와 질문 흐름으로 다시 보강했다.
- 번역 반영 상태: 영문/중문 반영 완료
- 관련 자산: `docs/en/parts/part-02/chapter-04/section-03.md`, `docs/zh/parts/part-02/chapter-04/section-03.md`, `mkdocs.yml`
- 원문 기준 버전: `v2026.07.09`
