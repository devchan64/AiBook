### v2026.07.20
- 변경 이유: 순차 저작권 검토 과정에서 고등학교 미분 기억에서 그래디언트·경사하강법·역전파로 이어지는 보충 설명, 다국어 SVG 자산, 외부 근거 연결을 재확인했다.
- 본문 반영 내용: 한국어, 영어, 중국어 간체판에서 집필 범위 안내 성격의 `이 보충학습의 범위` 계열 블록을 제거하고, 교육부 고시 페이지, OpenStax 그래디언트 절, KOCW 공개강의 확인 날짜와 `Version`을 `v2026.07.20`으로 갱신했다.
- 저작권 검토: 단변수 미분에서 다변수 변화율로 확장하는 설명, 믹서 패널 사례, 7종 SVG 도식은 Section 흐름에 맞춰 자체 구성한 입문 설명과 자체 벡터 자산이며, 교육부·OpenStax·KOCW 원문 문장·도표·강의 구성·예제 풀이 구조를 대체할 정도의 외부 자료 복제는 확인되지 않았다.
- 출처 확인: 교육부 고시 페이지와 OpenStax 그래디언트 절은 원문 페이지 접근을 확인했다. KOCW `미분적분학2 - 한양대학교` URL은 직접 열기에서 내부 오류가 있었으나 검색 결과의 동일 URL 캐시에서 강의명과 다변수 함수·편미분·벡터함수 범위를 확인했다.
- 번역 동기화 메모: 영어판과 중국어 간체판도 같은 구조 정리와 출처 확인일 갱신을 반영했다.
- 번역 반영 상태: 한국어, 영어, 중국어 간체판 반영 완료.
- 관련 자산: 변경 없음. `gradient-single-to-multiple-directions-*`, `partial-vs-directional-derivative-*`, `vector-calculus-context-*`, `gradient-direction-loss-contour-*`, `gradient-descent-steps-*`, `gradient-descent-update-intuition-*`, `backpropagation-gradient-flow-*` SVG는 검토만 했다.
- 원문 기준 버전: `v2026.07.20`
