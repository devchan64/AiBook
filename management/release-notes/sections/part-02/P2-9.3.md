- 번역 반영 상태: 한국어 원문 반영 완료, 영어판과 중국어 간체판 미반영.

### v2026.07.20
- 구조 정리: 한국어판, 영어판, 중국어 간체판에서 진행 메타 성격의 목표·범위·읽는 순서 제목을 구체적인 개념·판단 기준 제목으로 정리했다.
- 번역 반영 상태: 영어판과 중국어 간체판 반영 완료.
- 원문 기준 버전: `v2026.07.20`
- 변경 이유: 순차 저작권 검토 과정에서 NIST graph, NetworkX Graph, NetworkX DiGraph 문서의 근거 연결을 재확인했다.
- 본문 반영 내용: 한국어, 영어, 중국어 간체판에서 집필 범위 안내 성격의 `이 절의 범위` 계열 블록을 제거했다. 세 언어 본문 `Version`과 출처 확인 날짜를 `v2026.07.20` 및 2026-07-20으로 갱신했다.
- 저작권 검토: 친구 관계, 페이지 링크, 도시 거리, 추천 후보 점수 예시는 관계 표현을 설명하기 위한 자체 구성 예시이며, NIST와 NetworkX 문서의 예제 흐름이나 표현을 대체할 정도의 복제는 확인되지 않았다.
- 코드 주석 보강: 세 언어판의 NetworkX 예제에 그래프가 노드, 엣지, 방향, 가중치로 관계를 표현하는 구조라는 도메인 안내 주석을 추가했다.
- 출처 확인: NIST graph 원문에서 vertices/nodes와 edges/arcs 정의를, NetworkX Graph와 DiGraph 원문에서 무방향 그래프, 방향 그래프, 노드·엣지·인접·successor API 근거를 다시 확인했다.
- 번역 동기화 메모: 영어판과 중국어 간체판도 같은 구조 정리와 출처 확인일 갱신을 반영했다.
- 번역 반영 상태: 한국어, 영어, 중국어 간체판 반영 완료.
- 관련 자산: 내부 SVG 도식 4종 유지.
- 원문 기준 버전: `v2026.07.20`

### v2026.07.19
- 근거 보강: NIST graph와 NetworkX Graph 문서의 확인 날짜를 2026-07-19로 갱신하고, 그래프의 vertices/nodes와 edges/arcs 정의, 작은 무방향 그래프의 노드·엣지·인접 관계 설명 중 어느 내용을 뒷받침하는지 출처 항목에 명시했다.

- Python 예제 재설계: 작은 딕셔너리 출력과 반복문 예제는 정리하고, Python에서 그래프 관계를 다루는 대표 도구인 NetworkX를 사용해 `Graph`/`DiGraph`의 노드, 엣지, 이웃, 두 단계 이웃, 방향, 가중치 확인 흐름을 설명형 예제로 다시 구성했다.
- 의존성 반영: P2-9.3의 NetworkX 설명형 예제를 실행할 수 있도록 `requirements.txt`에 `networkx==3.6.1`을 추가했다.
- 도식 정합성 수정: `graph-neighbor-hop` SVG 3종에서 본문 표에 없는 `Han` 두 단계 이웃을 제거하고, 본문 설명과 반복되던 이미지 내부 제목·부제·하단 요약문을 줄였다. 중국어 SVG의 보이는 라벨과 접근성 설명도 중국어로 맞췄다.
- 번역 반영: 영어 `section-03.en.md`와 중국어 간체 `section-03.zh.md`의 범위 안내 문장을 한국어 원문의 노드·엣지·방향·가중치 중심 설명으로 맞추고, 세 언어 본문 Version을 `v2026.07.19`로 동기화했다.
