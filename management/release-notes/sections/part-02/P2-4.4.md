### v2026.07.09

- 변경 이유: 학습에서 미분이 필요한 이유 설명은 충분했지만, 이론형 절이 이어지는 흐름에서 독자가 사례의 판단 순서를 한 번 더 압축해 볼 회복 지점이 있으면 더 읽기 쉬웠다.
- 본문 반영:
  - 집값 예측 사례 아래에 `예측 오차 -> 손실 점수화 -> 그래디언트 신호 -> 작은 조정 -> 손실 재확인` 순서의 Mermaid 흐름도를 추가했다.
  - 사례 문단의 해석 순서를 다시 읽을 수 있게 해, 손실과 방향 정보의 역할 구분을 시각적으로 보강했다.
- 추가 정리: `세 가지 기준` 표 구분선을 바로잡고, 질문·사례 인용문을 일반 문장으로 흡수해 집필 톤 정합성을 맞췄다.
- 번역 동기화 메모: 향후 번역본에도 사례 흐름도의 `error -> loss -> gradient -> update -> recheck` 순서를 유지해 반영 필요.
