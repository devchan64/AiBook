# Section Release Note

- Section ID: `P2-4.4`
- Source File: `docs/parts/part-02/chapter-04/section-04.md`

### v2026.07.09

- 변경 이유: 학습에서 미분이 필요한 이유 설명은 충분했지만, 이론형 절이 이어지는 흐름에서 독자가 사례의 판단 순서를 한 번 더 압축해 볼 회복 지점이 있으면 더 읽기 쉬웠다.
- 본문 반영:
  - 집값 예측 사례 아래에 `예측 오차 -> 손실 점수화 -> 그래디언트 신호 -> 작은 조정 -> 손실 재확인` 순서의 Mermaid 흐름도를 추가했다.
  - 사례 문단의 해석 순서를 다시 읽을 수 있게 해, 손실과 방향 정보의 역할 구분을 시각적으로 보강했다.
- 본문 반영: `이 절의 범위`에서 `손실만으로는 왜 학습이 진행되지 않는가`라는 중심 질문을 먼저 세우고, `P2-4.5`, `P2-6.3`, Part 4로 이어지는 짧은 읽기 흐름을 보강했다.
- 추가 정리: `세 가지 기준` 표 구분선을 바로잡고, 질문·사례 인용문을 일반 문장으로 흡수해 집필 톤 정합성을 맞췄다.
- 번역 동기화 메모: 기존 영문·중문 번역본이 결론형 요약만 남긴 상태여서, 한글 원문의 학습-손실-방향-역전파 연결, 단일 파라미터 손실 예시, 다파라미터 그래디언트 설명, 값 전수 시험의 한계, 현장 표현 표, 집값 사례와 Mermaid 흐름도까지 같은 구조와 설명 밀도로 다시 보강했다.
- 번역 반영 상태: 영문/중문 반영 완료
