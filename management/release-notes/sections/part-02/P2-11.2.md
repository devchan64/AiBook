### v2026.07.09

- 변경 이유: Part 3 진입 전 `shape`, 행(row), 열(column), sample, feature를 서로 다른 표현으로 따로 기억해 독자가 `X.shape`와 데이터셋 구조를 바로 연결하지 못할 가능성이 남아 있었다.
- 본문 반영: `shape`, 행/열, 샘플/특징을 한 장면으로 다시 묶는 요약 블록과 데이터셋 언어 대응 표를 추가하고, `shape = (샘플 수, 특징 수)` 관점이 뒤의 `X`, `y` 읽기로 이어진다는 문장을 보강했다.
- 번역 동기화 메모: 기존 영문·중문 번역본이 요약본 수준에 머물러 있어, 배열 문법과 데이터셋 언어를 직접 연결하는 요약 표, 인덱싱·슬라이싱·축 설명, 행/열 선택 예제, 사례와 점검 문단까지 한국어 원문 구조에 맞춘 본문형 번역으로 다시 확장했다. 도식은 영문 원본과 한글 파생본 분리 정책을 유지한다.
- 번역 반영 상태: 영문/중문 반영 완료
