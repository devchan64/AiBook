# Section Release Note

- Section ID: `P2-5.2`

### v2026.07.09

- 변경 이유: 분포, 평균, 분산의 정의는 있지만 독자가 `읽는 순서`와 `평균만 보면 왜 부족한가`를 더 빨리 붙잡을 구조 신호가 필요했다.
- 본문 반영: `먼저 붙잡을 한 장면`, `분포 -> 평균 -> 분산` 읽기 순서 표, 평균 하나만 볼 때의 한계 요약 표, 뒤 Part 재등장 장면 표, 기억할 관점과 짧은 점검을 추가했다.
- 본문 반영: `이 절의 범위`에서 `왜 평균 하나만 보고 끝내면 안 되는가`라는 중심 질문을 먼저 세우고, `P2-5.3`, `P2-5.5`, Part 3, Part 6으로 이어지는 짧은 흐름을 보강했다.
- 추가 정리: `세 가지 기준` 표의 구분선을 바로잡아 표 렌더링 정합성을 맞췄다.
- 추가 정리: 본문 중간에 먼저 닫히던 `이 절에서 기억할 관점`, `짧은 점검` 블록을 종결부로 재배치해 한 절이 한 번만 닫히도록 정리했다.
- 번역 동기화 메모: `분포 -> 평균 -> 분산` 읽기 순서와 평균/분산 비교 도식의 영문 기준·한글 파생 구조를 영어·중문 번역본에도 반영했다.
- 번역 동기화 메모: 이번 변경은 한글 원고의 문단 위치 정리이며, 영어·중문 원고에는 같은 중복 종결 블록이 없어 추가 수정하지 않았다.
- 번역 반영 상태: 영문/중문 반영 완료
