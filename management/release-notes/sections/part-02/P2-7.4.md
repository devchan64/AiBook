- 번역 동기화 메모: 영어판과 중국어 간체판의 진행 메타 삭제, 소제목, 표, 사례 및 계산 설명을 최신 한국어 원문에 맞췄다. 빈 줄 제외 라인 수·소제목 수·수식·Python 코드 구조를 대조했다.
- 번역 반영 상태: 한국어·영어·중국어 간체판 동기화 완료.
- 검증: 임시 가상환경을 만들어 직접 지정한 Python의 격리와 NumPy 미설치 오류를 확인했다. Windows 명령은 공식 venv 문서의 Scripts 경로와 대조했으며 Windows 실행·신규 패키지 설치는 하지 않았다. 링크·수식 구분자·버전과 릴리즈노트 정합성을 확인했다.
- 원문 기준 버전: `v2026.09.08`
