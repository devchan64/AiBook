### v2026.07.09

- 변경 이유: 보충학습 절이 용어는 잘 나열하지만, 독자가 `표준편차`, `상관계수`, `표준오차`, `신뢰구간`, `가설검정`을 서로 다른 질문으로 분리해 읽는 구조 신호가 더 필요했다.
- 본문 반영: `먼저 붙잡을 기준` 표, 실험 표를 읽을 때의 해석 표, 막히면 다시 물을 질문 표를 추가해 용어별 역할 차이가 더 바로 보이게 정리했다.
- 본문 반영: `이 보충학습의 범위`에서 `평균과 분산만으로 부족해졌을 때 뒤 실험 표의 통계 용어들이 무엇을 더 보려는가`라는 중심 질문을 먼저 세우고, Part 3과 Part 6으로 이어지는 짧은 읽기 흐름을 보강했다.
- 추가 정리: 출처 외부 링크 속성을 보강하고, 인용문 형태의 정의 문장을 일반 문장으로 정리해 링크·서술 규칙을 맞췄다.
- 번역 동기화 메모: 기존 영문·중문 축약본을 한국어 원문 기준으로 다시 작성해 통계 보충 용어를 질문별로 분리하는 구조, 역할 비교 표, AI 재등장 맥락, 사례, 재질문 표까지 전체 절 흐름을 맞췄다.
- 번역 반영 상태: 영문/중문 반영 완료
- 관련 자산: `docs/en/parts/part-02/chapter-05/section-05.md`, `docs/zh/parts/part-02/chapter-05/section-05.md`, `mkdocs.yml`
- 원문 기준 버전: `v2026.07.09`
