- 본문 반영 내용: 한국어, 영어, 중국어 간체판에서 집필 범위 안내 성격의 `이 절의 범위` 계열 블록을 제거했다. 세 언어 본문 `Version`과 출처 확인 날짜를 `v2026.07.20` 및 2026-07-20으로 갱신했다.

- 코드 주석 보강: 세 언어판의 `!pwd` 예제에 Colab 코드 셀에서 현재 작업 폴더를 확인하는 셸 명령이라는 설명 주석을 추가했다.
- 출처 확인: Text-Terminal-HOWTO, GNU Bash Reference Manual, Microsoft Learn `Get-Location`/`Set-Location`, Python `os.getcwd` 원문을 다시 열람해 터미널 역사 맥락, 셸 정의, PowerShell 현재 위치 확인·변경, Python 현재 작업 폴더 확인 근거를 확인했다.
- 번역 동기화 메모: 영어판과 중국어 간체판도 같은 구조 정리와 출처 확인일 갱신을 반영했다.
- 번역 반영 상태: 한국어, 영어, 중국어 간체판 반영 완료.
