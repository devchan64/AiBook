# Section Release Note

- Section ID: `P2-8.3`

### v2026.07.09

- 변경 이유: 기존 영문·중문 `P2-8.3`가 한국어 원문에 비해 딕셔너리와 리스트의 차이, 매핑과 해시맵 구분, 키 누락 처리, 활용 사례 설명이 크게 축약된 요약본 상태라 원문 수준의 학습 흐름으로 다시 맞출 필요가 있었다.
- 본문 반영: 영어 `docs/en/parts/part-02/chapter-08/section-03.md`와 중국어 간체 `docs/zh/parts/part-02/chapter-08/section-03.md`를 한국어 원문의 리스트 대비 표, 매핑/해시맵 구분, `dict[key]`와 `get()` 설명, 설정값·라벨 맵·ID 조회 사례, 말미 점검 순서에 맞춰 전면 재작성했다.
- 번역 동기화 메모: `위치`와 `키`의 차이, 딕셔너리를 먼저 매핑으로 읽는 기준, 키가 없을 수 있는 입력 처리, 객체(object)와 딕셔너리의 구분을 영문·중문 번역본에 동일한 구조로 반영했다.
- 번역 반영 상태: 영문/중문 반영 완료
- 관련 자산: `docs/en/parts/part-02/chapter-08/section-03.md`, `docs/zh/parts/part-02/chapter-08/section-03.md`
- 원문 기준 버전: `v2026.07.07`

### v2026.07.10
