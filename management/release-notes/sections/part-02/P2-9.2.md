# Section Release Note

- Section ID: `P2-9.2`
- Source File: `docs/parts/part-02/chapter-09/section-02.md`

### v2026.07.09

- 변경 이유: 배열, 표, 트리, 그래프 비교 절이 설명은 충분했지만, 독자가 `이름`보다 `질문`을 먼저 떠올리는 구조 신호를 더 전면에 둘 필요가 있었다.
- 본문 반영: `먼저 붙잡을 기준` 표, `AI 실습 장면 -> 구조 감각` 표, 기억할 관점과 짧은 점검을 추가했다.
- 본문 반영: `이 절의 범위`에서 `위치, 행열, 계층, 관계 중 무엇을 보고 있는가에 따라 왜 자연스러운 구조가 달라지는가`라는 중심 질문을 먼저 세우고, `P2-9.3`, `P2-9.4`, 이후 실습 구간으로 이어지는 짧은 흐름을 보강했다.
- 추가 정리: 트리 단락 뒤에서 조기 등장하던 `이 절에서 기억할 관점`, `짧은 점검`을 사례 이후 종결부로 옮겨 본문과 마무리 블록이 섞이지 않게 정리했다.
- 번역 동기화 메모: 한국어 원문의 도식 설명, 표, 예제, 사례, 마무리 점검 구조를 기준으로 영어 `docs/en/parts/part-02/chapter-09/section-02.md`와 중국어 간체 `docs/zh/parts/part-02/chapter-09/section-02.md`를 요약본 상태에서 본문형 번역본으로 다시 확장했다.
- 번역 동기화 메모: 배열·표·트리·그래프를 `질문 중심 구조`로 비교하는 설명 순서와 세 개의 도식 참조를 영문·중문 번역본에도 같은 순서로 맞췄다.
- 번역 반영 상태: 영문/중문 반영 완료
