# Section Release Note

- Section ID: `P2-2.1`

### v2026.07.09

- 변경 이유: 챕터 2 첫 절의 영문·중문 번역본이 한국어 원문의 중심 질문, 변수와 코드 변수의 차이, 함수·식 예시 흐름을 충분히 보존하지 못하고 축약돼 있었다.
- 본문 반영: 영어 `docs/en/parts/part-02/chapter-02/section-01.md`와 중국어 간체 `docs/zh/parts/part-02/chapter-02/section-01.md`를 한국어 원문 구조에 맞춰 다시 작성하고, 변수-함수-식의 진입 질문, 배열 `shape`와 `dtype` 확인, `y = f(x)`와 제곱 오차 예시, AI 기본 관계, 사례와 재방문 기준까지 모두 반영했다.
- 번역 동기화 메모: 영문·중문 번역본의 `Version`은 반영일 기준 `v2026.07.09`로 유지하고, 원문 기준 버전 `v2026.07.09`를 별도로 추적한다.
- 번역 반영 상태: 영문/중문 반영 완료
- 관련 자산: `docs/en/parts/part-02/chapter-02/section-01.md`, `docs/zh/parts/part-02/chapter-02/section-01.md`
- 원문 기준 버전: `v2026.07.09`

### v2026.07.10

- 번역 반영 상태: 향후 반영 필요
- 관련 자산: 없음
