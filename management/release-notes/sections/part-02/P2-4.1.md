# Section Release Note

- Section ID: `P2-4.1`
- Source File: `docs/parts/part-02/chapter-04/section-01.md`

### v2026.07.09

- 변경 이유: 미분의 기억을 여는 역할은 충분했지만, 변화율·그래디언트·학습 업데이트로 이어지는 연결 구조가 앞부분에서 한 번 더 명시되면 독자의 복귀 경로가 더 분명해질 수 있었다.
- 본문 반영: `변화 질문 -> 변화율 -> 그래디언트 -> 학습 업데이트` 흐름을 압축한 연결 표와 설명 문단을 추가했다.
- 추가 정리: `세 가지 기준` 표의 구분선을 바로잡아 표 렌더링 정합성을 맞췄다.
- 번역 동기화 메모: 기존 영문·중문 번역본이 장 입구만 짧게 요약한 상태여서, 한글 원문의 연결 표, 미분 기억 복구 질문, 거리-속도-가속도, 점-선-면-부피 직관, 사례, 점검 문항까지 같은 구조와 설명 흐름으로 다시 보강했다.
- 번역 반영 상태: 영문/중문 반영 완료
- 관련 자산: `docs/en/parts/part-02/chapter-04/section-01.md`, `docs/zh/parts/part-02/chapter-04/section-01.md`, `mkdocs.yml`
- 원문 기준 버전: `v2026.07.09`

### v2026.07.10

- 변경 이유: 구조 표지가 현재 원칙의 `사례 및 예시` 축과 어긋난 부분을 정리할 필요가 있었다.
- 본문 반영: `사례로 보기` 표지를 `사례 및 예시`로 통일하고 Section 버전을 갱신했다. 내용 추가 없이 구조 표지만 정리했다.
- 번역 동기화 메모: 향후 번역본이나 다른 언어 원고가 생기면 같은 위치의 구조 표지도 `사례 및 예시` 축으로 맞춰야 한다.
- 번역 반영 상태: 향후 반영 필요
