# Section Release Note

- Section ID: `P2-4.1`
- Source File: `docs/parts/part-02/chapter-04/section-01.md`

### v2026.07.19
- 변경 이유: OpenStax 미분 정의 페이지 기준으로 접선, 할선, 도함수, 순간 변화율 설명의 근거를 재확인했다.
- 본문 반영 내용: 한국어, 영어, 중국어 간체판의 `Version`을 갱신하고 출처 확인 날짜와 출처 역할 설명을 보강했다.
- 번역 동기화 메모: 세 언어 본문을 같은 근거 설명 구조로 맞췄다.
- 번역 반영 상태: 한국어, 영어, 중국어 간체판 반영 완료.
- 관련 자산: 변경 없음.
- 원문 기준 버전: `v2026.07.19`

### v2026.07.09
- 핵심 변경: `변화 질문 -> 변화율 -> 그래디언트 -> 학습 업데이트` 흐름을 압축한 연결 표와 설명 문단을 추가했다.

### v2026.07.12
- 핵심 변경: 한국어 원문 말미의 `이 절에서 기억할 관점`, `짧은 점검`, `언제 이 관점을 먼저 떠올려야 하는가`를 `체크리스트` 하나로 통합하고, 메타형 다음 절 연결 표지도 제거했다.
- 번역 동기화 메모: 영어·중국어 번역본도 같은 말미 메타 블록을 제거하고 `Checklist` 하나로 구조를 맞췄다.

### v2026.07.17
- 핵심 변경: 한국어 원문 `이 절의 범위`에서 `미분 공식이나 계산법을 다루지 않는다`는 인라인 범위 문장을 제거하고, 예전 설명 기억이 어떤 질문으로 이어지는지 정리하는 현재 절 역할로 바로 들어가게 정리했다.
- 번역 반영: 영어판과 중국어 간체판도 같은 인라인 범위 문장을 제거하고 `Version`을 `v2026.07.17`로 동기화했다.
