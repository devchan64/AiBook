### v2026.07.09

- 변경 이유: 작은 데이터 실습 흐름은 충분했지만, 절 초반 연결 표가 길어 `앞 절의 개념이 실제 숫자와 코드 출력에서 어떻게 보이는가`라는 핵심 질문이 늦게 드러났다. 또한 기존 영문·중문 번역본이 원문 실습 흐름과 코드 해설을 충분히 반영하지 못한 축약본 상태였다.
- 본문 반영: 초반 연결 표를 줄이고 `이 절의 범위`에서 중심 질문을 먼저 세운 뒤, `P2-5.5`, Part 3, Part 6으로 이어지는 짧은 읽기 흐름을 추가해 실습형 절의 목적이 더 빨리 보이도록 다듬었다.
- 번역 동기화 메모: 영문·중문 번역본을 한국어 원문 기준으로 다시 작성해 실행 환경, 작은 데이터 실습, 평균·중위값·분산 코드 설명, 모집단/표본 분산 설정 차이, 표본 평균 변화, 사례, 체크리스트까지 전체 절 구조를 맞췄다.
- 번역 반영 상태: 영문/중문 반영 완료
