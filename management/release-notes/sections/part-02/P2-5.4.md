- 코드 주석 보강: 본문 세 언어판의 Python 코드 블록과 `p2_5_4_small_statistics.py`에 `data`, `skewed_data`, `centered`, `squared_deviations`, `population_like`, `samples`, `ddof=1`의 도메인 의미와 관찰 포인트를 설명하는 주석을 추가했다.
- 도식 검토: `small-data-statistics-check-*` 자산을 확인하고, 한국어 SVG의 혼합 영어 문장, 영어 SVG의 한국어 접근성 설명, 중국어 SVG 내부 영어 라벨을 본문 언어와 맞게 정리했다.
- 출처 확인: NumPy `numpy.array`, `numpy.ndarray.size`, `numpy.mean`, `numpy.median`, `numpy.var`와 OpenStax `Introductory Statistics, 1.2` 원문을 다시 열람해 코드 API와 표본·추정 배경 설명을 확인했다.
- 번역 동기화 메모: 영어판과 중국어 간체판도 같은 구조 정리와 출처 확인일 갱신을 반영했다.
