# brewing-shot-ai-notes 관리 기준

## 목적

이 디렉터리는 `동작 단위 원천데이터` 사례를 책 본문에 흡수하기 전에, 개념 소스와 공개 안전 원칙을 정리해 두는 작업 노트 묶음이다.

## 유지 원칙

- `01`부터 `07`까지는 Part 3과 이후 Part에서 반복 참조할 개념 소스 노트로 유지한다.
- `08`과 `09`는 사례 배치와 공개형 실습 자산을 준비할 때만 유지한다.
- 본문에 이미 회수되어 역할이 끝난 메타 계획 문서는 남기지 않는다.

## 현재 유지 대상

- `01-domain-opportunity-and-boundaries.md`
- `02-problem-framing-from-shot-to-dataset.md`
- `03-time-series-normalization-and-segmentation.md`
- `04-sensor-tokenization-and-explainable-features.md`
- `05-window-aggregation-baseline-drift.md`
- `06-sample-size-repeatability-and-false-alarms.md`
- `07-modeling-ladders-rules-statistics-ml.md`
- `08-book-integration-map-by-part.md`
- `09-exercises-datasets-and-visuals-plan.md`

## 삭제 기준

- Part 3 또는 다른 `docs/` 본문에 이미 흡수된 장문 작성 로드맵
- 다른 노트를 다시 요약만 하는 메타 계획 문서
- 현재 집필 판단보다 과거 작성 단계 설명이 중심인 메모
