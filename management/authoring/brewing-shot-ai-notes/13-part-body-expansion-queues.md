# Part별 본문 확장 작업 큐

## 이 문서의 역할

이 문서는 현재 기준에서 다시 시작하는 작업 큐다.

이 큐는 과거처럼 `어느 파일에 무엇을 이미 반영했다`는 완료 기록이 아니다.

대신 다음 순서로 실제 본문 작업을 열기 위한 준비 큐다.

1. 각 Part에서 다시 읽어야 할 Section을 고른다
2. 그 Section의 중심 질문을 짧게 적는다
3. 동작 단위 원천데이터 사례가 기여할 수 있는 질문만 남긴다
4. 필요한 예제와 자산을 분리한다

## 공통 작업 기준

모든 큐는 아래 네 항목을 먼저 확인한 뒤 진행한다.

- 현재 Section의 중심 질문
- 현재 Section의 설명 층위
- 기존 사례와의 충돌 여부
- 공개 안전성

## Queue A. Part 1 재검토

### 목표

문제 정의, 입력/출력, 라벨 부족이라는 질문에 이 사례가 정말 필요한지 다시 판단한다.

### 우선 확인할 것

- 문제 정의 관련 Section
- 지도/비지도 구분 관련 Section
- 생성형 AI가 모든 문제의 기본 해법이 아님을 보여 주는 Section

### 준비할 것

- 입력/출력 재정의 표 초안
- 동작 1건을 샘플로 보는 짧은 설명
- 라벨 부족 상황의 짧은 비교표

## Queue B. Part 2 재검토

### 목표

원시 로그, 동작 단위 묶기, 구간화, 집계, 시각화로 이어지는 최소 실습 흐름을 다시 설계한다.

### 우선 확인할 것

- 변화율과 기울기 설명 Section
- 평균, 분산, 표본 수 Section
- DataFrame, 집계, 시각화 Section

### 준비할 것

- 아주 작은 원시 로그 표
- 동작 단위 요약 표
- 구간 평균 계산 예제
- 같은 평균, 다른 패턴 예시

## Queue C. Part 3 재검토

### 목표

기준선, 특징 공학, 표본 수, 거짓 경보, 모델 선택을 이 사례로 가장 강하게 회수한다.

### 우선 확인할 것

- 평가 지표 Section
- 특징 선택 Section
- 모델 선택 Section
- baseline 설명 Section

### 준비할 것

- 기준선 비교 표
- `review_needed` 또는 이에 준하는 운영 라벨 직관
- 특징 후보 표
- 규칙 기반 vs 특징 기반 모델 비교표

## Queue D. Part 4 재검토

### 목표

순차 데이터와 표현 학습 설명에 필요한 최소 장면만 남긴다.

### 우선 확인할 것

- 순차 데이터 Section
- attention 또는 위치 정보 관련 Section
- 원시 시퀀스와 요약 특징의 대비가 필요한 Section

### 준비할 것

- 같은 마지막 값, 다른 흐름 예시
- 초기 구간과 후반 결과 연결 예시
- 요약 특징과 원시 시퀀스 대비 표

## Queue E. Part 5 재검토

### 목표

토큰, 설명 문장, 운영 비교라는 세 축만 제한적으로 사용한다.

### 우선 확인할 것

- 토큰화 설명 Section
- 프롬프트 또는 설명 생성 관련 Section
- 운영 평가 비교 Section

### 준비할 것

- 텍스트 토큰 vs 센서 토큰 비교표
- 기준선 비교 결과를 설명 문장으로 바꾸는 흐름
- 자동화 머신 운영과 LLM 운영의 평행 비교표

## Queue F. Part 6 재검토

### 목표

동작 단위 원천데이터 사례를 공개형 소규모 프로젝트로 회수한다.

### 우선 확인할 것

- 프로젝트 도입 Section
- 데이터 준비 Section
- 결과 해석 Section
- 회고 Section

### 준비할 것

- 원시 로그 -> 동작 단위 요약 -> 최근 구간 집계 흐름
- 기준선 비교 리포트 예시
- 검토 우선순위 출력 예시
- 짧은 설명 문장 예시

## 공통 자산 큐

본문 반영 전에 공통 자산으로 준비할 수 있는 항목은 다음과 같다.

- 소형 합성 원시 로그 CSV
- 동작 단위 요약 CSV
- 최근 구간 집계 CSV
- 기준선 비교 표 예시
- 토큰화 예시 표
- 3문장 설명 템플릿

## 후속 순서

추천 순서는 다음과 같다.

1. Part 3
2. Part 2
3. Part 6
4. Part 1
5. Part 5
6. Part 4

이 순서가 맞는 이유는 기준선, 특징, 표본 수, 집계, 프로젝트가 현재 노트 묶음의 핵심 강점을 가장 직접적으로 회수하기 때문이다.

## 현재 결론

이 작업 큐는 완료표가 아니라 재시작용 큐다.

후속 집필은 이 문서를 따라 바로 삽입하지 않고, 각 Part의 실제 Section을 다시 읽으면서 이 큐를 구체 작업으로 낮추는 방식으로 진행해야 한다.
