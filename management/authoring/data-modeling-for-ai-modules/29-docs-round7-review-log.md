# 실제 본문 편집 7차 반영 검토 메모

## 목적

이 문서는 `data-modeling-for-ai-modules`의 관점을 실제 `docs/` 본문에 7차로 반영하면서, 왜 이번 라운드에서 `SVM`, `kernel`, `RAG 목표`, `첫 회고` 절을 공통 review 기록 구조와 더 직접 연결했는지 기록한다.

이번 라운드 대상은 다음 네 파일이다.

- `docs/parts/part-03/chapter-13/section-01.md`
- `docs/parts/part-03/chapter-13/section-02.md`
- `docs/parts/part-06/chapter-05/section-01.md`
- `docs/parts/part-06/chapter-01/section-02.md`

## 이번 반영의 핵심 판단

### 1. SVM은 margin 근처 사례를 review 대상으로 남기는 구조여야 한다

`part-03/chapter-13/section-01.md`는 원래 좋은 경계와 margin을 설명하는 절이다. 이번 라운드에서는 여기에 다음 기록 구조를 붙였다.

- baseline과 SVM 비교
- margin 근처 사례
- support vector처럼 읽히는 점
- 다음 실험 질문

이 보강으로 SVM은 `좋은 선을 찾는 모델`에 그치지 않고, `어떤 사례가 경계를 가장 많이 흔드는가`를 review 대상으로 남기는 후보 모델로 읽히게 된다.

### 2. kernel 절은 수식보다 사례 재배치 기록으로 먼저 읽혀야 한다

`part-03/chapter-13/section-02.md`는 표현 공간을 바꾸는 발상을 설명한다. 이번 라운드에서는 여기에 다음 구조를 추가했다.

- 원래 공간의 애매한 사례
- 새 표현 공간에서의 재배치
- review 상태 변화
- 다음 질문

이 보강의 목적은 kernel 절을 `함수 이름 소개`보다 `같은 사례가 다른 공간에서 어떻게 다시 읽히는가`를 기록하는 절로 읽게 만드는 데 있다.

### 3. RAG 목표 절도 검색 후보와 review 질문을 앞단에서 같이 보여야 한다

`part-06/chapter-05/section-01.md`는 RAG 최소 구조를 소개한다. 이번 라운드에서는 질문, 검색 후보, 선택 근거, review 질문을 입구에서 같이 남기는 표를 추가했다.

이 보강으로 review 구조가 검증 절에서만 갑자기 등장하는 것이 아니라, RAG 프로젝트 시작 순간부터 `어떤 질문이 애매한가`가 문서에 드러난다.

### 4. 첫 회고 절은 Part 6 전체 공통 템플릿을 세우는 절이어야 한다

`part-06/chapter-01/section-02.md`는 사실, 해석, 다음 질문 구조를 다룬다. 이번 라운드에서는 여기에 `review_needed`를 붙여, 첫 회고가 이후 모든 프로젝트 회고 템플릿의 출발점으로 읽히게 만들었다.

이 보강으로 Part 6 전체의 회고 구조가 더 일관되게 연결된다.

## 파일별 반영 이유

### `part-03/chapter-13/section-01.md`

반영한 내용:

- margin 근처 사례와 review 필요 여부를 남기는 표
- SVM 후보를 프로젝트 메모 형식으로 적는 예시

반영 이유:

- SVM 절이 수학적 직관만이 아니라 `비교 후보 -> 애매한 사례 -> 다음 조정 질문` 구조를 갖추게 만들 필요가 있었다.

### `part-03/chapter-13/section-02.md`

반영한 내용:

- 표현 공간 변경 전후 사례 재배치를 남기는 표
- kernel 절을 `사례 재배치` 관점으로 먼저 읽게 하는 문장

반영 이유:

- kernel 절이 수식적 거리감 때문에 흐려지지 않도록, 실제 사례가 다른 공간에서 어떻게 다시 읽히는지 기록 구조를 먼저 두는 편이 적절했다.

### `part-06/chapter-05/section-01.md`

반영한 내용:

- 검색 후보, 선택 근거, review 질문을 입구에서 남기는 표
- 단계별 review 상태와 다음 행동을 잇는 간단한 표

반영 이유:

- RAG 프로젝트 입구에서부터 `검색 후보 -> 근거 -> review 질문` 구조가 보여야 뒤 절의 retrieval 검증과 더 자연스럽게 이어진다.

### `part-06/chapter-01/section-02.md`

반영한 내용:

- fact, interpretation, review_needed, next_question을 함께 남기는 표
- 이 절이 Part 6 전체 공통 회고 템플릿이라는 연결 문장

반영 이유:

- 첫 회고 절이 뒤의 예측, 텍스트, agent, 배포 프로젝트 회고까지 이어지는 공통 형식을 미리 세우는 위치이기 때문이다.
