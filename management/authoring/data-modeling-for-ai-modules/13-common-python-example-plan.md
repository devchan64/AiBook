# 데이터 모델링 모듈 공통 Python 예제 계획

## 목적

이 문서는 데이터 모델링 모듈을 책 본문에서 설명할 때 반복 사용할 수 있는 공통 Python 예제의 구조를 정리한다.

핵심은 복잡한 구현을 보여 주는 것이 아니라, `원시 시계열 -> 동작 1회 요약 -> 최근 구간과 기준선 비교`를 독자가 직접 실행해 볼 수 있게 만드는 데 있다.

## 예제 1. 원시 로그를 동작 1회 단위로 묶기

### 중심 질문

- 여러 행으로 된 원시 로그를 어떻게 샘플 1건으로 볼 것인가

### 입력

- `action_id`
- `time_step`
- `control_level`
- `sensor_a`
- `sensor_b`

### 보여 줄 동작

- 같은 `action_id`를 기준으로 여러 행을 묶는다.
- 한 동작이 몇 개의 시점으로 구성되는지 센다.
- 동작 1회가 원시 행 여러 개의 묶음이라는 점을 확인한다.

### 출력 예시

- 전체 행 수
- 고유 `action_id` 수
- 각 `action_id`별 행 수

### 독자가 확인해야 할 것

- 한 행이 샘플 1건이 아니라는 점
- 동작 1회가 분석 단위가 될 수 있다는 점

## 예제 2. 동작 1회 요약 특징 만들기

### 중심 질문

- 원시 시계열 여러 행을 어떤 요약 행으로 바꿀 수 있는가

### 입력

- 예제 1의 원시 로그

### 보여 줄 동작

- `groupby(action_id)`로 묶는다.
- `duration_steps`, `control_mean`, `sensor_a_peak`, `sensor_b_mean` 같은 열을 계산한다.
- 필요하면 초반 구간 평균과 후반 구간 평균도 계산한다.

### 출력 예시

- 동작 1회당 한 행으로 된 표
- 생성된 특징 열 목록
- 요약 전 행 수와 요약 후 행 수

### 독자가 확인해야 할 것

- 특징은 임의 숫자가 아니라 표현 설계라는 점
- 요약 행이 모델 입력 표가 될 수 있다는 점

## 예제 3. 최근 구간과 기준선 비교하기

### 중심 질문

- 최근 동작이 평소와 다른지 어떻게 비교할 것인가

### 입력

- 예제 2에서 만든 동작 1회 요약 표

### 보여 줄 동작

- 최근 5건과 이전 20건을 나눈다.
- 각 구간의 평균을 계산한다.
- 차이값(`delta`)을 계산한다.

### 출력 예시

- 최근 평균 표
- 기준선 평균 표
- 차이 비교 표

### 독자가 확인해야 할 것

- 절대값만 보는 것이 아니라 비교 프레임이 필요하다는 점
- 차이값은 관찰 결과이지 원인 확정이 아니라는 점

## 예제 4. 같은 평균, 다른 패턴 만들기

### 중심 질문

- 평균이 같은데도 패턴이 달라질 수 있다는 점을 어떻게 보여 줄 것인가

### 입력

- 두 개의 짧은 장난감 시계열

### 보여 줄 동작

- 두 시계열의 평균을 계산한다.
- 표준편차, 초반 평균, 후반 평균을 계산한다.
- 평균은 같지만 변동성과 구간 패턴이 다름을 출력으로 보여 준다.

### 출력 예시

- 두 시계열의 평균 비교
- 표준편차 비교
- 초반/후반 구간 평균 비교

### 독자가 확인해야 할 것

- 단일 평균값만으로는 패턴 차이를 놓칠 수 있다는 점
- 특징을 여러 개 설계해야 하는 이유

## 코드 작성 원칙

- 가능하면 `pandas` 중심의 짧은 예제로 작성한다.
- 코드 앞에 입력 표의 의미를 먼저 설명한다.
- 코드 아래에 실제 출력 예시를 함께 둔다.
- 출력은 행 수, 요약 표, 비교 표처럼 눈으로 바로 읽을 수 있는 값을 우선한다.
- 아직 설명하지 않은 고급 모델 학습 코드는 넣지 않는다.

## 현재 결론

공통 Python 예제는 모델 학습보다 먼저, 샘플 정의와 요약 구조, 비교 구조를 독자가 직접 확인하게 만드는 데 초점을 둬야 한다.
