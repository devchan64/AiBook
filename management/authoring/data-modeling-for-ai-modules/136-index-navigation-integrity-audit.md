# 인덱스 내비게이션 무결성 감사

## 목적

이 문서는 `README.md`, `110-document-role-map.md`, `118-minimum-restart-packet.md`, `128-canonical-doc-index.md`가 서로 다른 역할을 맡으면서도 현재 파일 집합과 재개 흐름을 빠짐없이 안내하는지 점검하기 위해 만든다.

문서 수가 많아진 상태에서는 목록 인덱스, 역할 인덱스, 최소 재개 패킷, 기준본 인덱스가 서로 다른 책임을 가져야 한다. 이 문서는 그 분업이 현재도 유지되는지 확인한다.

## 감사 대상

- `README.md`
- `110-document-role-map.md`
- `118-minimum-restart-packet.md`
- `128-canonical-doc-index.md`
- 보조 근거:
  - `132-readme-coverage-audit.md`
  - `134-role-map-coverage-audit.md`

## 역할 분리 점검

### 1. `README.md`

현재 역할:

- 전체 파일 목록 인덱스
- 빠른 진입 경로 제공

점검 결과:

- `132-readme-coverage-audit.md` 기준으로 `README.md` 자신을 제외한 모든 Markdown 파일을 목록에 포함한다.

판정:

- 전체 목록 인덱스 역할 정상

### 2. `110-document-role-map.md`

현재 역할:

- 전체 파일을 역할 단위로 재분류
- 읽기 순서 제안

점검 결과:

- `134-role-map-coverage-audit.md` 기준으로 `README.md` 자신을 제외한 모든 Markdown 파일이 역할 묶음 안에 포함된다.

판정:

- 역할 인덱스 역할 정상

### 3. `118-minimum-restart-packet.md`

현재 역할:

- 재개 첫 단계의 최소 문서 집합 제시
- 조건부 보조 문서 진입점 제공

점검 결과:

- `105 -> 100 -> 25 -> 51 -> 112` 순서를 일관되게 제시한다.
- 사건 대응은 `126`, 증거 최신화는 `122`, `124`, 기준본 집합 확인은 `128`로 분기시킨다.

판정:

- 최소 재개 패킷 역할 정상

### 4. `128-canonical-doc-index.md`

현재 역할:

- 현재 판단에 직접 쓰는 기준본 문서와 보조 문서를 분리

점검 결과:

- 목표, 계획, 큐, 커밋 경계, 증거, 사건 대응 기준본을 분리한다.
- `132`, `134`를 보조 문서로 연결해 목록/역할 인덱스 감사 근거를 포함한다.

판정:

- 기준본 인덱스 역할 정상

## 상호 연결 점검

현재 확인된 연결:

- `README`는 빠른 진입 경로에서 `128`을 직접 가리킨다.
- `110`은 `132`, `134`를 포함해 현재 상태/감사 문서 역할을 확장한다.
- `118`은 조건별로 `122`, `124`, `126`, `128`을 호출한다.
- `128`은 `132`, `134`를 보조 문서로 둔다.

현재 누락 여부:

- 직접 확인된 누락 없음

## 현재 의미

- `README`는 `무엇이 있는가`를 보여 준다.
- `110`은 `각 문서가 무엇을 위한가`를 보여 준다.
- `118`은 `지금 무엇부터 볼 것인가`를 보여 준다.
- `128`은 `현재 판단에 직접 쓰는 기준본은 무엇인가`를 보여 준다.

이 네 문서는 같은 인덱스 문서처럼 보이지만 책임이 다르다.

## 현재 결론

현재 인덱스 구조는 `README`가 전체 목록, `110`이 역할 분류, `118`이 최소 재개 시작점, `128`이 기준본 집합을 맡는 분업으로 충돌 없이 유지되고 있다. 또한 `132`, `134` 감사 문서 덕분에 목록 커버리지와 역할 커버리지도 별도 검증 가능하다.
