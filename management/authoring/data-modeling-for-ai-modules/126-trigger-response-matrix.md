# 트리거-대응 매트릭스

## 목적

이 문서는 `재개 조건이 생겼을 때 어떤 문서를 어떤 순서로 열고 어떤 문서를 갱신해야 하는가`를 트리거별로 한 표에 고정하기 위해 만든다.

기존 문서들은 각각 `재개 시작점`, `증거 갱신`, `본문 검토 순서`, `참조 노트 재개 조건`을 잘 설명하지만, 실제 사건이 생겼을 때 무엇부터 열어야 하는지는 여러 문서에 나뉘어 있다. 이 문서는 그 대응 경로를 한 장으로 묶는다.

## 읽는 방법

- `트리거`는 실제로 작업을 다시 열게 만드는 사건이다.
- `먼저 볼 문서`는 재개 첫 단계에서 바로 열어야 하는 문서다.
- `다음 행동`은 실제로 수행할 작업 방향이다.
- `갱신 문서`는 작업 후 상태를 다시 반영해야 하는 문서다.

## 사용 원칙

- 트리거가 생기면 먼저 이 문서에서 해당 행을 찾는다.
- `118`은 재개 시작점, `126`은 사건별 대응표, `124`는 증거 갱신 절차로 구분한다.
- 작업이 끝나면 마지막에 `105`와 필요 시 `122`를 다시 맞춘다.

## 현재 결론

현재 재개 구조는 `118`로 시작하고, 실제 사건이 생기면 `126`에서 대응 경로를 고른 뒤, 증거 최신화가 필요할 때 `124`를 호출하는 방식으로 읽는 편이 가장 안정적이다.
