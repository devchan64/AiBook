# 본문 범위 스냅샷 추가 로그

## 대상

- `management/authoring/data-modeling-for-ai-modules/107-current-manuscript-scope-snapshot.md`

## 이번 추가의 목적

상태 문서와 큐 문서는 완료 범위와 재개 조건을 잘 설명하지만, 현재 워크트리에서 실제로 어떤 본문 파일들이 수정 상태인지 한 번에 보여 주지는 않는다. 이번 추가는 Part 2, Part 3, Part 6의 비커밋 본문 범위를 관리 문서 안에 직접 고정하는 것이 목적이었다.

## 반영 내용

- `git status --short` 기준의 Part 2, Part 3, Part 6 수정 파일 목록을 문서로 정리했다.
- 각 파일 범위에 대응하는 검토 로그 번호 대역도 같이 적었다.
- 이 문서는 `현재 비커밋 범위 확인용`이며, 실제 재개 순서는 `106-current-working-set-guide.md`를 우선한다는 점을 명시했다.

## 판단 이유

- 작업을 재개할 때 완료 범위와 재개 조건만 보는 것보다, 실제 수정 상태 파일 범위까지 바로 확인할 수 있으면 판단 비용이 줄어든다.
- 특히 `docs/` 본문을 커밋하지 않는 정책 아래에서는, 워크트리 범위를 문서로 고정해 두는 편이 추적에 더 유리하다.
