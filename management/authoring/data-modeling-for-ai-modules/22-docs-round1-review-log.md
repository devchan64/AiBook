# 실제 본문 편집 1차 반영 검토 메모

## 목적

이 문서는 `data-modeling-for-ai-modules`에서 준비한 공통 자산을 실제 `docs/` 본문 파일에 1차로 반영하면서 어떤 판단으로 넣었는지 기록한다.

이번 라운드 대상은 다음 네 파일이다.

- `docs/parts/part-02/chapter-12/section-01.md`
- `docs/parts/part-02/chapter-13/section-01.md`
- `docs/parts/part-03/chapter-07/section-01.md`
- `docs/parts/part-06/chapter-01/section-01.md`

## 이번 반영의 원칙

### 1. 절의 중심 질문을 바꾸지 않는다

각 Section은 이미 기존 학습 흐름을 갖고 있으므로, 사례를 넣더라도 현재 질문을 더 선명하게 만드는 범위에서만 넣는다.

### 2. 긴 사례 서술보다 표와 짧은 코드로 연결한다

이번 라운드에서는 새 소절을 크게 추가하기보다:

- 짧은 표
- 짧은 Python 예제
- 2~4문장 해석

형태를 우선 사용했다.

### 3. 본문은 아직 커밋하지 않는다

사용자 요구에 맞춰 본문 편집은 비커밋 상태로 유지한다.

## 파일별 반영 이유

### `part-02/chapter-12/section-01.md`

반영한 자산:

- 원시 로그 여러 행이 `동작 1회`로 다시 읽힌다는 표
- `groupby("event_id")` 예제

반영 이유:

- 이 절은 DataFrame에서 `한 행`, `한 열`, `한 사례`를 읽는 법이 중심이다.
- 따라서 `여러 행이 한 사례를 이루는 원시 로그`를 바로 보여 주는 것이 가장 맞다.

### `part-02/chapter-13/section-01.md`

반영한 자산:

- 같은 평균, 다른 패턴 표
- 두 선 그래프 비교 예제

반영 이유:

- 이 절은 그래프가 표에서 안 보이는 모양을 보여 준다는 점이 중심이다.
- 따라서 `평균은 같지만 패턴은 다른 경우`를 넣는 것이 기존 설명과 가장 잘 맞는다.

### `part-03/chapter-07/section-01.md`

반영한 자산:

- 동작 단위 요약 표
- 최근 구간/기준선 비교 표
- 특징 표 생성 후 비교표로 이어지는 짧은 Pandas 예제

반영 이유:

- 이 절은 특징 선택이 단순 칼럼 제거가 아니라 입력 표현 설계라는 점을 설명한다.
- 따라서 원시 로그 -> 동작 단위 특징 -> 최근 구간 비교라는 흐름을 바로 보여 주는 편이 좋다.

### `part-06/chapter-01/section-01.md`

반영한 자산:

- 최근 구간/기준선 비교 표
- 경계 문장 세트
- 프로젝트 흐름을 동작 단위 시계열 기준으로 다시 읽는 보조 표

반영 이유:

- 이 절은 프로젝트의 첫 질문과 첫 산출물을 잡는 곳이다.
- 따라서 모델보다 먼저 `비교표`와 `관찰 메모`를 만드는 구조를 넣는 것이 적절하다.

## 이번 라운드에서 의도적으로 하지 않은 것

- 새 Chapter를 만들지 않았다.
- 장문의 도메인 배경 설명을 본문에 추가하지 않았다.
- 실제 합성 CSV 파일이나 별도 자산 파일을 아직 만들지 않았다.
- 본문 파일을 커밋하지 않았다.

## 현재 결론

이번 1차 본문 편집은 `사례를 설명하기 위해 본문을 바꾸는 것`이 아니라, `기존 절의 질문을 더 분명하게 만드는 표와 코드 자산을 최소한으로 삽입하는 것`에 초점을 두었다. 이 방향은 저장소 규칙과 사용자 요구에 모두 맞는다.
