# 사례와 예제 주제 확장 지도

## 목적

데이터 모델링 모듈이 실제 책 원고로 확장되려면, 한 사례만 반복하는 대신 같은 구조를 다른 문제 장면에도 옮겨 볼 수 있어야 한다.

이 문서는 `같은 모듈을 다른 예제 주제로 확장하는 방법`을 정리한다.

## 확장 축 1. 같은 구조, 다른 장비

다음과 같은 주제로 옮겨 적을 수 있다.

- 자동 세척 장치의 1회 동작 로그
- 포장 장비의 1회 사이클 로그
- 온도 제어 장치의 1회 제어 로그
- 혼합 공정의 1회 배치 로그

핵심은 장비 이름이 아니라 `자동으로 실행되는 동작 1회`를 샘플 단위로 잡는 구조다.

## 확장 축 2. 같은 구조, 다른 질문

하나의 원천데이터라도 질문을 달리할 수 있다.

- 정상 범위에서 벗어났는가
- 최근 구간이 평소와 달라졌는가
- 같은 평균인데 패턴이 달라졌는가
- 반복성이 줄어들고 있는가
- 사람이 검토해야 할 건은 무엇인가

즉 예제 확장은 도메인 변경뿐 아니라 질문 변경으로도 가능하다.

## 확장 축 3. 같은 구조, 다른 표현 수준

같은 데이터를 다음 수준으로 다시 표현할 수 있다.

- 원시 시계열
- 구간별 요약값
- 동작 1회 요약 행
- 최근 N건 집계
- 기준선 대비 차이값
- 경고용 문장 표현

이 축을 통해 데이터 모델링이 저장 구조를 넘어 표현 설계라는 점을 보여 줄 수 있다.

## 책에 넣기 좋은 예제 유형

### 표 예제

- 동작 1회당 한 행으로 요약한 작은 표
- 최근 5건과 이전 20건 평균 비교 표
- 같은 평균이지만 다른 변동성을 가진 두 사례 비교 표

### 시각 예제

- 짧은 시계열 선 그래프
- 구간별 분할 도식
- 원시 로그에서 요약 행으로 가는 변환 도식

### Python 예제

- 원시 로그를 동작 1회 단위로 묶는 예제
- 최근 구간 평균과 기준선 평균을 비교하는 예제
- 간단한 특징 열을 만드는 예제

## 피해야 할 예제 유형

- 내부 운영 규칙을 유추할 수 있는 상세 임계값 예제
- 특정 기업 데이터 구조를 거의 그대로 드러내는 표
- 장비 고장 원인을 단정하는 과장된 예제
- 실제 현업 리포트 문장을 그대로 복제한 예제

## 현재 결론

이 사례는 하나의 산업 도메인 설명으로 묶기보다, `자동 동작 1회와 그 원천 시계열을 어떻게 AI용 데이터로 재구성하는가`를 보여 주는 공통 예제 축으로 확장하는 편이 좋다.
