# 데이터 모델링 모듈 자산 정리 라운드 2 로그

## 이번 라운드의 목적

라운드 1에서 공통 어휘, 표, Python 예제의 뼈대를 고정했다면, 이번 라운드의 목적은 그 자산을 실제 삽입 단위로 더 가깝게 만드는 것이었다.

즉 `어느 Part에 어떤 문단을 어떻게 붙일지`와 `과장 방지 문장을 어디에 어떻게 반복 사용할지`를 관리 문서 차원에서 먼저 정리했다.

## 이번 라운드에서 수정한 문서

- `12-part-draft-paragraphs.md`
- `45-overstatement-guard-sentences.md`

## 판단과 수정 이유

### 1. 후보 문단은 있었지만 즉시 삽입 단위로는 아직 모호했다

기존 `12-part-draft-paragraphs.md`는 Part별 후보 문단은 있었지만, 각 문단에 어떤 표와 어떤 Python 예제가 함께 붙어야 하는지, 어느 성격의 Section에 넣는 것이 맞는지까지는 적혀 있지 않았다.

그래서 각 Part 후보 문단마다 아래 항목을 추가했다.

- 함께 붙일 자산
- 삽입 위치 성격

이렇게 해 두면 다음 실제 원고 편집에서는 `문단만 복사`하는 것이 아니라 `문단 + 표 + 해석 문장` 묶음으로 옮기기 쉬워진다.

### 2. 과장 방지 문장은 있었지만 흩어져 있었다

기존 `10-next-writing-actions.md`에는 과장 방지 문장 후보가 있었지만, 실제로 어떤 상황에서 어떤 문장을 선택할지와 피해야 할 문장이 별도로 정리되어 있지 않았다.

그래서 `45-overstatement-guard-sentences.md`를 새로 만들어 다음을 정리했다.

- 핵심 문장 세트
- 표 아래, Python 해석 아래, Part 3, Part 6에 맞는 배치 위치
- 상황별 문장 선택 기준
- 피해야 할 과장 문장
