# P3-11.2 검토 로그

## 대상

- `docs/parts/part-03/chapter-11/section-02.md`

## 이번 검토의 목적

결정 경계 절에서 시각화 설명이 곧 원인 설명처럼 읽히지 않도록, 경계 근처 사례와 threshold 이동의 해석 경계를 보강하는 것이 목적이었다.

## 반영 내용

- 경계 근처 사례는 `변화 신호`와 `검토 우선순위`를 먼저 보여 주는 사례라는 문장을 추가했다.
- threshold 이동 설명 뒤에 `정책 변화`와 `원인 설명`을 분리하는 문장을 보강했다.

## 판단 이유

- 이 절은 입력 공간과 경계 직관이 중심이므로, 새 예시를 더 늘리기보다 경계 해석의 안전선을 짧게 명시하는 편이 적절하다.
- 경계와 threshold는 운영 행동과 바로 연결되기 쉬워서, `경계 이동 = 원인 설명`으로 읽히지 않게 막아 둘 필요가 있었다.
