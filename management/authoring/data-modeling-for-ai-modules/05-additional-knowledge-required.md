# 이 주제를 책 예제로 쓰기 위해 추가 학습해야 하는 지식

## 목적

이 문서는 데이터 모델링 주제를 AI 활용 관점으로 충분히 설명하려면, 집필자가 추가로 확보해야 할 지식이 무엇인지 정리한다.

## 추가 학습이 필요한 지식 묶음

### 1. 문제 정의 지식

- 입력과 출력 정의
- 경고, 비교, 진단의 차이
- 샘플 단위 설계

### 2. 시계열 정렬 지식

- 절대 시간축
- 진행도축
- 세그먼트 분할
- 위치 비교

### 3. 특징 공학 지식

- 평균, 기울기, 변동성
- 구간 특징
- 설명 가능한 표현
- 토큰화와 정보 손실

### 4. 기준선 비교 지식

- 최근 구간 집계
- 평소 기준선
- 차이값 해석
- 구조 변화와 평균 변화 구분

### 5. 통계 해석 지식

- 표본 수
- sampling variation
- repeatability
- false alarm

### 6. 모델 선택 지식

- 규칙 기반 접근
- 통계 기반 비교
- 특징 기반 ML
- 시계열 모델
- 설명 생성 보조

### 7. 공개형 실습 자산 설계 지식

- 합성 데이터 생성
- 공개 안전한 예시 스키마
- 초심자용 표와 그래프 설계

### 8. 편집 배치 지식

- 어느 Part에 어느 깊이로 넣을지
- 어디서 멈출지
- 보충학습으로 분리할지

## 우선순위

가장 먼저 더 공부해야 하는 것은 다음 다섯 가지다.

1. 샘플 단위 정의
2. 시계열 정렬과 세그먼트 분할
3. 기준선과 최근 구간 비교
4. 표본 수와 반복성 해석
5. 공개형 합성 데이터 설계

## 현재 결론

이 주제를 책에서 제대로 쓰려면, 단순한 데이터베이스 설계 지식보다 `현실 사건을 샘플, 특징, 기준선, 비교 구조로 다시 표현하는 지식`을 더 강하게 확보해야 한다.
