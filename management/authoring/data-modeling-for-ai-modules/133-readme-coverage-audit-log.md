# README 커버리지 감사 로그

## 목적

이 문서는 `132-readme-coverage-audit.md`를 추가한 이유를 기록한다.

## 추가 이유

- `README.md`가 여전히 전체 문서 목록 인덱스를 맡고 있으므로, 압축 여부와 별개로 목록 정확성은 별도 근거 문서로 유지할 필요가 있었다.
- 이번 대조에서 실제 Markdown 파일 140개 가운데 README 자신만 목록에서 제외되어 있고, 나머지 139개는 모두 열거됨을 확인했다.
- 새로 추가된 `138`, `139`도 README 목록에 포함되어 있음을 함께 확인했다.
- 이 결과를 문서로 남겨 두면 이후 README를 더 줄이더라도 `빠른 진입 경로`와 `전체 목록 커버리지`를 분리해 점검할 수 있다.
