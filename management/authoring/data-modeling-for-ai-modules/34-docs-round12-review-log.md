## 이번 반영의 핵심 판단

### 1. 가치 기반 절은 Q-value 정의보다 상태-행동 후보와 실패 비용을 같이 남겨야 한다

`part-03/chapter-19/section-01.md`는 가치 기반 강화학습과 Q-learning, SARSA를 설명한다. 이번 라운드에서는 여기에 다음 구조를 붙였다.

- 상태-행동 후보
- 누적 보상 기준
- 실패 비용
- 다음 조정 질문

이 보강으로 가치 기반 절은 `값 정의`를 넘어서 `어떤 행동 비교를 어떤 비용 구조 안에서 읽을 것인가`를 남기는 절로 읽히게 된다.

### 2. 정책 기반 절은 행동 분포와 실패 비용 경계를 같이 적어야 한다

`part-03/chapter-19/section-02.md`는 정책 기반 강화학습과 actor-critic을 다룬다. 이번 라운드에서는 여기에 다음 구조를 더했다.

- 정책 제안
- 기대 보상 기준
- 실패 비용 경계
- 다음 검증 질문

이 보강의 목적은 정책 기반 절을 `행동 확률 소개`가 아니라 `확률을 높인 행동이 현실에서 어떤 위험을 만드는가`까지 같이 읽게 만드는 데 있다.

### 3. 적용 주의점 절은 보상, 탐험, 현실 검증을 실제 점검 메모로 바꿔야 한다

`part-03/chapter-19/section-03.md`는 보상 설계, 탐험 비용, sim-to-real gap을 다룬다. 이번 라운드에서는 여기에 다음 구조를 붙였다.

- 먼저 보인 신호
- 바로 붙일 해석
- 배포 전 다시 볼 항목
- 다음 질문

이 보강으로 적용 주의점 절은 `강화학습은 어렵다`는 일반론이 아니라, 실제 배포 직전 검토 순서를 적는 절로 더 또렷해진다.

### 4. 보충학습 절도 알고리즘 이름보다 문제 신호 중심으로 다시 묶어야 한다

`part-03/chapter-19/section-04.md`는 DQN, PPO, safe RL, RLHF를 큰 흐름 안에서 정리한다. 이번 라운드에서는 여기에 다음 구조를 더했다.

- 이름 묶음
- 먼저 보인 문제 신호
- 왜 그 분기가 필요했는가

이 보강으로 보충학습 절은 `후속 이름 목록`이 아니라 `어떤 현실 문제와 학습 불안정이 어떤 알고리즘 분기를 만들었는가`를 남기는 지도로 읽힌다.

## 파일별 반영 이유

### `part-03/chapter-19/section-01.md`

반영한 내용:

- 상태-행동 후보, 누적 보상 기준, 실패 비용, 다음 조정 질문 표
- 창고 로봇 사례를 review 메모 형식으로 다시 적는 표
- 기억할 관점 표에 실패 비용 항목 추가

반영 이유:

- 가치 기반 강화학습을 단순 점수판이 아니라, 장기 보상과 탐험 위험을 함께 보는 구조로 읽히게 만들 필요가 있었다.

### `part-03/chapter-19/section-02.md`

반영한 내용:

- 정책 제안, 기대 보상 기준, 실패 비용 경계, 다음 검증 질문 표
- 로봇 팔 사례를 project memo 형식으로 다시 적는 표
- 기억할 관점 표에 실패 비용 경계 항목 추가

반영 이유:

- 정책 기반 강화학습이 연속 행동에 자연스럽다는 설명만으로 끝나지 않고, 정책 분포가 실제 환경에서 만드는 리스크까지 같이 읽게 할 필요가 있었다.

### `part-03/chapter-19/section-03.md`

반영한 내용:

- 먼저 보인 신호, 해석, 배포 전 확인 항목, 다음 질문 표
- 기억할 관점 표에 배포 전 검증 순서 항목 추가

반영 이유:

- 보상 설계와 sim-to-real 설명을 실제 적용 검토 언어로 옮겨, 강화학습 절이 Part 6 회고 구조와 바로 이어지게 만들 필요가 있었다.

### `part-03/chapter-19/section-04.md`

반영한 내용:

- 알고리즘 이름 뒤의 문제 신호 표
- DQN, PPO, RLHF를 handoff 메모 형식으로 다시 적는 표
- 기억할 관점 표에 문제 신호, 현실 제약 분기, LLM 연결 항목 추가

반영 이유:

- 강화학습 후속 이름들이 무엇을 해결하려고 나온 분기인지 더 분명하게 남길 필요가 있었다.
