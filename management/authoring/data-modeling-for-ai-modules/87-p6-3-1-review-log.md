# P6-3.1 검토 로그

## 대상

- `docs/parts/part-06/chapter-03/section-01.md`

## 이번 검토의 목적

이미지 분류 프로젝트 입문 절에서도 `애매한 예측`, `오분류`, `다음 절 연결`이 원인 확정처럼 읽히지 않도록, 묶음 E의 `검토 신호`와 `다음 확인 질문` 구조를 더 분명히 고정하는 것이 목적이었다.

## 반영 내용

- `[0.5, 0.5]` 확률 설명을 `현재 모델이 뚜렷하게 가르지 못했다는 신호`로 바꾸고, 다음 절 검토 우선순위와 직접 연결했다.
- `데이터/모델/표현 가설 기록` 문구를 `데이터/모델/표현 확인 질문 기록`으로 조정했다.
- 다음 절 연결 문장에서 `왜 틀렸는가`보다 `어떻게 흔들렸는가`와 `무엇을 더 확인해야 하는가`를 남긴다는 흐름으로 다듬었다.

## 판단 이유

- P6-3.1은 이미지 프로젝트의 입구이므로, 해석보다 기록 구조를 먼저 익히게 하는 편이 더 적절하다.
- 묶음 E의 핵심인 `경고/애매함 -> 검토 우선순위 -> 다음 질문` 구조를 이미지 예제 첫 절에서도 바로 보이게 할 필요가 있었다.
