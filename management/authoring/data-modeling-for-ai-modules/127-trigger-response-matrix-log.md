# 트리거-대응 매트릭스 로그

## 목적

이 문서는 `126-trigger-response-matrix.md`를 추가한 이유를 기록한다.

## 추가 이유

- 지금까지는 재개 조건 자체는 `25`, `51`, `99`, `118`, `124`에 잘 나뉘어 있었지만, 실제 사건이 생겼을 때 어떤 문서 순서로 대응해야 하는지는 한 장으로 정리돼 있지 않았다.
- 현재 목표는 새 본문 확장과 관리 정리를 조건부로 다시 여는 구조이므로, `트리거 -> 대응 문서 -> 갱신 문서` 표가 있으면 재개 비용이 더 줄어든다.
- 이번 문서는 특히 `새 본문 확장`, `증거 최신화`, `관리 문서 역할 재정리`, `참조 노트 재개`를 구분해 이후 판단을 더 빠르게 만들기 위해 추가했다.

## 연결 문서

- `118-minimum-restart-packet.md`
- `124-evidence-refresh-protocol.md`
- `126-trigger-response-matrix.md`

## 현재 결론

이 로그는 재개 조건이 실제 사건으로 바뀌는 순간의 대응 경로를 별도 문서로 고정해, 조건과 행동 사이의 거리를 줄이기 위해 남긴 기록이다.
