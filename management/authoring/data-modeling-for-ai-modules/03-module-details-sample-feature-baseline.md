# 모듈 상세: 샘플, 특징, 기준선을 어떤 순서로 가르칠 것인가

## 기본 순서

책에서는 다음 순서가 가장 안전하다.

1. 샘플 단위 정의
2. 원시 로그와 요약 표 구분
3. 특징 만들기
4. 최근 구간 집계
5. 평소 기준선 비교
6. 경고와 검토 후보 해석

이 순서를 뒤집으면 초심자는 다음처럼 오해하기 쉽다.

- baseline은 평가 지표 절의 용어다
- feature는 모델 입력 칸 이름일 뿐이다
- 데이터셋은 원시 로그를 조금 정리한 표다

## 샘플 단위를 먼저 가르쳐야 하는 이유

샘플 단위가 정해지지 않으면:

- 행 의미가 흔들리고
- 특징 의미가 흔들리고
- 라벨 의미가 흔들리고
- 평가 단위도 흔들린다

따라서 먼저 `한 시점`, `한 동작 기록`, `최근 구간`, `평소 기준선`을 구분해야 한다.

## 특징을 두 번째가 아니라 세 번째에 두는 이유

초심자는 특징을 데이터셋 열 이름 정도로 오해하기 쉽다.

그래서 먼저 원시 로그와 요약 표의 차이를 본 뒤,
그 다음에 `요약값과 특징은 사람이 설계한 표현`이라는 점을 연결하는 편이 낫다.

## 기준선을 뒤로 미루면 생기는 문제

기준선을 너무 늦게 다루면 다음 같은 오해가 생긴다.

- 모든 판단은 절대 임계값으로 한다
- baseline은 분류기 하나의 이름이다
- 운영 데이터 비교는 모델 이후 단계다

책에서는 기준선을 `비교 구조 설계`로 더 일찍 보여 줄 필요가 있다.

## 실습 설계 원칙

각 모듈은 다음 산출물을 하나씩 남겨야 한다.

- 샘플 단위 모듈: 행 의미 비교표
- 원시 로그 모듈: 작은 로그 표
- 특징 모듈: 특징 표
- 기준선 모듈: 최근 구간 vs 평소 기준선 비교표
- 경고 해석 모듈: 검토 필요 리포트 문장

## 현재 결론

이 주제를 AI 활용용으로 충분히 가르치려면 `샘플 -> 요약 -> 특징 -> 기준선 -> 해석`의 순서를 책 안에서 반복적으로 고정해야 한다.
