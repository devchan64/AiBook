## 다음 큐를 다시 여는 조건

다음 `docs/` 검토 큐는 아래 조건에서만 다시 연다.

- 새 본문 확장 위치가 생겨 같은 자산 묶음을 다시 호출해야 할 때
- 기존 문장이 과장되거나 현재 공통 어휘와 충돌하는 사례가 새로 발견될 때
- 수정 본문 범위와 검토 로그 범위가 어긋났을 가능성이 생길 때
- 관리 문서 역할 재정리로 완료 범위를 다시 묶어야 할 때

대응 경로는 `51-section-level-review-sequence.md`, `118-minimum-restart-packet.md`, `126-trigger-response-matrix.md`를 따른다.
