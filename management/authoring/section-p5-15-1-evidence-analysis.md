# P5-15.1 근거 검토 메모

## 절의 역할

- agent를 목표 중심 작업 흐름으로 설명한다.
- 프롬프트, RAG, tool use와 다른 상위 구조라는 점을 정리한다.

## 이번 절의 핵심 주장

- 에이전트는 목표를 하위 단계로 이어 가는 실행 구조다.
- agent는 프롬프트, RAG, tool use를 포함할 수 있지만 그 자체로는 상위 작업 구조다.
- 상태, 재시도, 관찰이 중요하다.

## 반영한 근거

- ReAct 논문
- OpenAI Agents 문서
- 관련 agent engineering 교육 자료

## 집필 판단

- 챗봇과 같은 말로 오해하지 않도록 workflow 관점을 강조했다.
- 코딩 에이전트 사례를 넣어 독자의 현재 작업 경험과 연결했다.
