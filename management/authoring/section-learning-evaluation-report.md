# Section별 학습 평가 리포트

작성일: 2026-07-31

이 리포트는 한국어 Section 원고 364개를 `Section ID` 기준으로 대조한 1차 학습 평가 리포트다. 평가는 본문 전체를 수정하지 않고, 각 Section이 독자에게 남겨야 할 중심 학습 산출물과 확인 장치를 갖추었는지 판단하기 위한 작업 기준으로 작성한다.

## 평가 기준

- `유지`: 중심 학습 산출물, 체크리스트 또는 적용 장치, 출처 절이 기본 구조로 연결되어 있다.
- `보강`: 중심은 유지되지만 체크리스트, 예제 연결, 소제목, 초심자 확인 장치 중 일부 점검이 필요하다.
- `재구성`: 중심 질문이 섞였거나 Section 경계 자체를 다시 잡아야 한다. 이번 1차 자동 대조에서는 확정 재구성 판정은 보류한다.
- `검증 필요`: 출처 절이 없거나 근거 안정성을 먼저 확인해야 한다.
