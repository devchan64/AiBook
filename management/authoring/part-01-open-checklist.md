# Part 1 체크포인트 노트

이 문서는 Part 1을 목차 순서대로 읽을 때 각 Section이 반드시 붙잡아야 할 중심 주제를 개괄식으로 정리한 체크포인트 노트입니다.

## 사용 원칙

- 이 노트는 `docs/table-of-contents.md`를 기준으로 Part 1의 시작/마무리 페이지, Chapter, Section을 같은 순서로 훑기 위한 개요 문서입니다.
- 이 노트는 작업 상태표가 아니라 Part 1 원고가 유지해야 할 중심선 문서입니다.
- 순차 점검 기록, 품질 상태 메모, 작업 로그는 이 문서에서 운영하지 않습니다.
- 체크포인트는 `이 Section이 어떤 질문을 닫아야 하는가`와 `어떤 개념 연결을 맡는가`만 짧게 적습니다.
- `학습 관점 누락 점검`은 Part 원고가 잃기 쉬운 설명 흐름을 점검하고, `목차 기준 체크포인트`는 Part 원고가 유지해야 할 구조 흐름을 관리합니다.
- Section ID 기반 자동 대조는 문서 전체가 아니라 `목차 기준 체크포인트` 이후 구간을 기준으로 삼습니다.

## 학습 관점 누락 점검

- 각 Chapter를 볼 때 `왜 이 장이 지금 필요한가`가 Part 전체 흐름 안에서 바로 보이는지 먼저 확인합니다.
- 각 Section를 볼 때 정의만 있고 `예시`, `연습 또는 예제`, `오해하기 쉬운 대비` 가운데 하나라도 비어 있지 않은지 확인합니다.
- 처음 등장하는 핵심 용어는 한국어와 영어 원어가 함께 제시되고, 뒤 Section에서 반복 설명을 과도하게 늘리지 않는지 확인합니다.
- 독자가 바로 막힐 선행지식이 있으면 현재 Section 안에서 짧게 보강할지, `보충학습`으로 분리할지 회수 위치가 잡혀 있는지 확인합니다.
- Section 말미에서 `이번 절에서 닫힌 질문`과 `다음 절에서 이어질 질문`이 구분되어 있는지 확인합니다.
- Part 1에서는 특히 `용어 지도`, `직접 계보와 주변 사례 구분`, `전망과 사실의 구분`이 빠지지 않는지 다시 봅니다.
- `AI 개론 커리큘럼`, `휴리스틱과 불확실성`, `규칙에서 표현 학습으로의 전환`, `Codex와 에이전트형 작업 방식`이 Part 1의 중심선으로 회수되는지 확인합니다.
- 체크포인트 문장은 집필 기준이며, 본문에는 `오픈체크리스트`, `중심축` 같은 관리 표현으로 노출하지 않습니다. 본문 보강은 문제 장면, 개념 대비, 독자용 판단 문장으로 풀어 씁니다.

## Section 경계 정리

- Part 1의 전체 경계는 `AI 지형도`, `용어 층위`, `규칙에서 학습으로의 전환`, `LLM 사용 구조`, `사회적 판단 기준`을 입문 수준에서 닫고, 수식·구현·고급 알고리즘은 뒤 Part로 넘기는 구조로 유지합니다.
- `먼저 연결할 개념`, `주요 학습내용`, `세부 학습내용`, `세부 학습내용 보충` 계열 소제목은 오래된 진행 메타 형식입니다. 본문 정밀 수정 때는 현재 Section이 설명하는 구체 개념이나 판단 기준이 드러나는 제목으로 바꾸는지 확인합니다.
- P1-3.3의 `이 절의 경계: 학습 전체가 아니라 표현을 본다`처럼 경계 자체를 제목으로 세운 곳은, 표나 연결 문장은 유지하되 소제목은 `규칙과 표현이 맡는 질문의 차이`처럼 설명 대상 중심으로 바꿀 후보입니다.
- P1-5.2의 `이 절에서는 어떻게 받아들이면 좋은가` 같은 진행 안내형 제목은 `inference를 모델 실행으로 읽는 기준`처럼 개념 중심 제목으로 바꿀 후보입니다.
- P1-8.1~P1-8.3은 학습 유형의 기본 구분을 닫는 장입니다. 지도학습, 비지도학습, 강화학습의 차이를 설명하되, 각 절 앞뒤의 범위 안내 표가 본문 설명보다 길어지지 않는지 확인합니다.
- P1-9.1~P1-11.3은 딥러닝 확산 사례와 LLM 직접 계보를 나누는 구간입니다. 이미지 인식, 객체 검출, 음성 생성은 딥러닝 확산의 주변 근거이고, 통계적 언어 모델, Seq2Seq, Attention, Transformer는 LLM 직접 계보라는 구분을 계속 유지합니다.
- P1-12.1~P1-14.6은 사용 경험에서 서비스 구조로 넘어가는 구간입니다. 프롬프트로 조정할 문제, RAG·도구 사용으로 구조화할 문제, 에이전트·MCP·하네스에서 실행 환경으로 넘길 문제를 서로 반복 설명하지 않는지 확인합니다.
- P1-15.1~P1-17.3은 사회적 쟁점과 전망을 다루되, 법률·보안·시장 전망을 확정 설명처럼 쓰지 않고 `근거`, `맥락`, `작업 가설` 기준으로 분리해야 합니다.
- Part 1 안에서 자세히 다루지 않는다고 언급한 항목은 회수 위치가 실제로 잡혀 있어야 합니다. 현재 확인된 주요 회수 축은 Part 2의 수학·소프트웨어 기초, Part 4의 머신러닝 평가와 강화학습/RLHF 큰 그림, Part 5의 실전 프롬프트 보충학습, Part 6의 LLM·생성형 AI 심화, Part 7의 작은 시스템 관점입니다.
- 다국어 본문이 이미 함께 있으므로, 한국어 원문에서 Section 경계나 소제목을 바꾸면 영어·중국어 번역본도 같은 `Section ID` 기준으로 후속 동기화 대상에 올려야 합니다.

## 목차 기준 체크포인트

- `P1-index`: Part 1이 책 전체의 지형도를 다시 잡는 입구라는 점, 뒤 Part로 이어질 핵심 질문 묶음을 분명히 제시해야 합니다.
- Part 흐름: Module 4는 `딥러닝 확산 사례`, `생성형 AI의 일반 구조`, `LLM 직접 계보 미리보기`를 서로 다른 층위로 구분한 채 이어져야 합니다.
- Part 흐름: Module 5와 Module 6은 LLM 사용 구조와 사회적 판단이 분리되지 않게, 실제 사용 맥락으로 다시 연결되어야 합니다.
- `P1-summary`: Part 1의 지형도를 다음 학습 진입 질문으로 다시 묶어야 합니다.

### Module 1. AI의 범위와 역사

#### Chapter 1. AI란 무엇인가 `개념 정의`

- 중심축: AI라는 말의 범위와 문제 유형을 먼저 나눠, 이후 Part에서 쓸 기본 지도를 세웁니다.
- `P1-1.1`: AI라는 말의 범위를 과장된 사용례와 구분하고, 어떤 문제를 AI 문제로 볼지 기준선을 세워야 합니다.
- `P1-1.2`: 인식, 탐색, 예측, 생성처럼 AI가 다루는 문제 유형을 입력과 출력 관점에서 정리해야 합니다.
- `P1-1.3`: AI, 머신러닝, 딥러닝, 생성형 AI의 포함 관계와 차이를 뒤 Part 연결까지 염두에 두고 잡아야 합니다.

#### Chapter 2. AI의 역사와 패러다임 변화 `역사와 패러다임`

- 중심축: 규칙 중심 접근에서 데이터 기반 학습으로 넘어간 이유를 역사 흐름 안에서 압축해 읽게 합니다.
- `P1-2.1`: 기호 기반 AI와 규칙 기반 접근이 무엇을 잘했고 어디서 막혔는지 보여 주어야 합니다.
- `P1-2.2`: 탐색, 지식 표현, 확률 추론이 서로 다른 문제를 어떻게 맡았는지 구분해야 합니다.
- `P1-2.3`: 데이터 기반 학습이 중심이 된 이유와 생성형 AI로 이어지는 흐름을 압축하되, 외부 커리큘럼에서 반복되는 개론 축과 개인 해석을 섞지 않게 정리해야 합니다.

### Module 2. 규칙, 모델, 학습

#### Chapter 3. 규칙에서 학습으로 `역사와 패러다임`

- 중심축: 사람이 직접 규칙을 쓰는 방식과 데이터에서 표현을 배우는 방식의 차이를 대비시킵니다.
- `P1-3.1`: 사람이 규칙을 직접 쓰는 방식의 강점과 한계를 실제 판단 장면으로 설명해야 합니다.
- `P1-3.2`: 데이터에서 패턴을 배운다는 전환이 무엇을 바꾸는지 직관적으로 보여 주어야 합니다.
- `P1-3.3`: 규칙 기반 접근과 표현 학습의 차이를 `규칙은 밖에 있고 표현은 안에 있다`는 축으로 정리해야 합니다.

#### Chapter 4. 문제를 모델로 바꾼다는 것 `모델링 관점`

- 중심축: 현실 문제를 입력, 출력, 특징, 파라미터가 있는 계산 문제로 바꾸는 관점을 세웁니다.
- `P1-4.1`: 모델을 서비스 전체가 아니라 현실 문제를 계산 가능하게 바꾼 모형으로 이해시키는 역할을 해야 합니다.
- `P1-4.2`: 입력, 출력, 데이터가 문제 정의의 최소 단위라는 점을 예시와 함께 잡아야 합니다.
- `P1-4.3`: 특징, 표현, 파라미터를 같은 층위로 섞지 않게 구분해야 합니다.
- `P1-4.4`: 좋은 모델 선택보다 먼저 문제 정의가 구조를 결정한다는 점을 분명히 해야 합니다.

#### Chapter 5. 학습(learning)과 모델 실행(inference) `학습 원리`

- 중심축: 학습이 무엇을 바꾸고 실행이 무엇을 적용하는지 분리해 이후 계산 흐름의 기준선을 만듭니다.
- `P1-5.1`: 학습이 파라미터와 표현을 바꾸는 과정이라는 점을 닫아야 합니다.
- `P1-5.2`: 모델 실행은 학습된 구조를 실제 입력에 적용하는 단계라는 점을 분리해야 합니다.
- `P1-5.3`: 한국어 `추론`이 가리키는 서로 다른 영어 개념을 문맥별로 나눠 주어야 합니다.

### Module 3. 불확실성과 문제 해결

#### Chapter 6. 불확실성과 확률적 판단 `수학 기초`

- 중심축: 규칙만으로 닫히지 않는 문제에서 확률적 판단이 왜 필요한지 이해시킵니다.
- `P1-6.1`: 정보 부족, 예외, 잡음 때문에 규칙만으로 닫히지 않는 문제 장면을 보여 주어야 합니다.
- `P1-6.2`: 확률, 불확실성, 확률적 과정의 차이를 혼동 없이 정리해야 합니다.
- `P1-6.3`: 분류, 예측, 생성에서 확률적 판단이 실제로 어떻게 쓰이는지 연결해야 합니다.

#### Chapter 7. 탐색과 휴리스틱 `실무 휴리스틱`

- 중심축: 모든 후보를 다 볼 수 없는 문제에서 탐색과 휴리스틱이 계산을 어떻게 줄이는지 보여 줍니다.
- `P1-7.1`: 탐색 공간이 왜 너무 커지는지와 계산 한계가 왜 생기는지 설명해야 합니다.
- `P1-7.2`: 휴리스틱이 시간을 줄이고 후보를 줄이는 실용적 기준이면서, 초기 AI의 문제 해결 방식과 연결되는 핵심 방법 중 하나라는 점을 잡아야 합니다.
- `P1-7.3`: 휴리스틱과 확률 모델을 같은 것으로 읽지 않게 차이를 분명히 하고, 휴리스틱은 검증해야 할 작업 가설이라는 관점을 남겨야 합니다.
- `P1-7.4`: 탐색과 휴리스틱이 길찾기와 경로 계획 같은 실제 문제로 이어지는 흐름을 보강해야 합니다.

#### Chapter 8. 학습 유형의 기본 구분 `학습 원리`

- 중심축: 지도학습, 비지도학습, 강화학습을 학습 신호의 차이로 구분하게 합니다.
- `P1-8.1`: 지도학습이 입력과 라벨의 관계를 배우는 구조라는 점을 닫아야 합니다.
- `P1-8.2`: 비지도학습이 정답 없이 구조와 표현을 찾는다는 점을 분명히 해야 합니다.
- `P1-8.3`: 강화학습이 행동과 보상 신호를 통해 정책을 바꾼다는 점을 보여 주어야 합니다.

### Module 4. 딥러닝과 생성형 AI로의 전환

#### Chapter 9. 딥러닝 패러다임의 확산 `역사와 패러다임`

- 중심축: 표현 학습이 딥러닝 확산을 어떻게 만들었는지와 LLM 계보와의 거리를 함께 정리합니다.
- `P1-9.1`: 딥러닝이 특징을 사람이 직접 만들지 않고 표현을 학습하는 방향으로 바꿨다는 점을 설명하되, `인간 직관 자체의 구현`이 아니라 패턴 판단과 표현 학습의 전환으로 다뤄야 합니다.
- `P1-9.2`: 이미지 인식, 객체 검출, 음성 생성 사례가 딥러닝 확산의 주변 근거라는 점을 보여 주어야 합니다.
- `P1-9.3`: LLM의 직접 계보와 다른 딥러닝 성공 사례를 구분하는 읽기 기준을 세워야 합니다.

#### Chapter 10. 생성형 AI 개론 `개념 정의`

- 중심축: 생성형 AI를 분류·예측과 구분하고 생성 결과의 품질과 위험까지 함께 읽게 합니다.
- `P1-10.1`: 분류, 예측, 생성의 차이를 출력 형식과 판단 방식 관점에서 나눠야 합니다.
- `P1-10.2`: 다음 출력 생성이라는 공통 직관을 텍스트, 이미지, 음성에 걸쳐 잡아야 합니다.
- `P1-10.3`: 생성 결과의 품질과 위험을 환각, 근거, 저작권, 안전 문제와 연결해야 합니다.

#### Chapter 11. LLM은 어디에서 왔는가 `역사와 패러다임`

- 중심축: 통계적 언어 모델에서 Transformer와 사전학습 LLM으로 이어지는 직접 계보를 미리 잡습니다.
- `P1-11.1`: 통계적 언어 모델과 임베딩이 LLM 이전의 배경이라는 점을 짧게 정리해야 합니다.
- `P1-11.2`: RNN, Seq2Seq, Attention이 왜 언어 모델 발전의 전환점이 되었는지 보여 주어야 합니다.
- `P1-11.3`: Transformer와 사전학습 LLM이 현재 흐름의 직접 계보라는 점을 잡아야 합니다.
