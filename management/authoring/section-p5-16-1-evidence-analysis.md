# P5-16.1 근거 검토 메모

## 절의 역할

- MCP를 모델과 도구/데이터 연결을 일관되게 만드는 인터페이스 관점으로 설명한다.
- 모델 능력과 연결 문제를 구분하게 한다.

## 이번 절의 핵심 주장

- MCP는 모델 능력 자체보다 연결 표준화 문제를 다룬다.
- agent와 tool use가 커질수록 도구 연결의 일관성이 중요해진다.
- 연결 표준이 있다고 해서 운영 품질이 자동 해결되지는 않는다.

## 반영한 근거

- OpenAI의 MCP 관련 문서
- 관련 tool integration 교육 자료

## 집필 판단

- 프로토콜 세부보다 역할 중심으로 정리했다.
- harness와의 차이를 다음 절 연결로 남겼다.

## 제외한 내용

- 메시지 포맷 세부
- 인증 체계 상세
