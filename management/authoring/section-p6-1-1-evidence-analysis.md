# P6-1.1 근거 검토 메모

## 이 절의 역할

- 프로젝트 파트의 첫 절로서 `작은 데이터 표를 읽고 질문을 세우는 흐름`을 보여 준다.
- 모델 없는 프로젝트도 유효한 학습 단위라는 점을 설명한다.

## 핵심 주장

- 데이터 분석 프로젝트는 질문 -> 표 확인 -> 요약 -> 다음 질문 흐름으로 시작할 수 있다.
- 평균, 최대값, 비율 같은 기본 요약값이 뒤 프로젝트의 기준점 역할을 한다.
- 코드 출력은 프로젝트 문서의 근거가 된다.

## 반영한 근거

- Python `csv` 문서: 표 형식 데이터를 표준 라이브러리로 읽는 기본 근거
- Python `statistics` 문서: 평균 계산 등 기본 요약 통계의 표준 라이브러리 근거

## 집필 메모

- 데이터는 외부 원문이 아니라 자체 장난감 데이터로 구성했다.
- 외부 데이터 저작권 문제를 피하고, 초심자가 구조를 먼저 읽게 하는 데 목적이 있다.
