# P5-7.2 근거 검토 메모

## 절의 역할

- 스케일을 데이터, 모델, 계산량의 동시 확대라는 관점으로 정리한다.
- 성능 향상과 비용/품질 문제를 함께 설명한다.

## 이번 절의 핵심 주장

- 스케일은 성능 가능성을 높이지만 비용과 위험도 함께 키운다.
- 데이터 양이 많아져도 품질과 검증 책임은 사라지지 않는다.

## 반영한 근거

- Brown et al., `Language Models are Few-Shot Learners`
- Kaplan et al., `Scaling Laws for Neural Language Models`
- OpenAI API Docs의 비용/길이 관련 문서

## 집필 판단

- 수학적 scaling law 세부는 넣지 않고, 초심자 기준의 서비스·품질 관점을 우선했다.
- 성능 찬양 서술을 피하고 비용/검증 책임을 함께 적었다.

## 제외한 내용

- 최신 상용 모델 수치 비교
- 학습 클러스터 설계
