# Part 2 메타 표현 위반 검토

## 검토 범위

- 대상: `docs/parts/part-02/` 아래 한국어 본문, 시작 페이지, 마무리 페이지
- 제외: `*.en.md`, `*.zh.md`
- 점검 초점: 진행 순서, 설명 순서, 절 운영 의도를 앞세우는 메타 표현

## 전체 판단

- 판정: `높음`
- 메모: Part 2는 Python, 배열, 실행 환경을 설명하는 실용 파트라 절차 설명이 필요하지만, 현재는 `이 절의 범위`, `이 절의 목표`, `먼저 붙잡을 기준`, `어떤 환경을 먼저 선택할까` 같은 진행형 표지가 지나치게 많습니다. 절차 자체를 설명하는 파트여도 메타 표지가 본문보다 앞서는 구간이 넓습니다.

## 핵심 위반 패턴

### 1. 공통 메타 템플릿이 강하게 반복된다

- 대표 표현:
  - `## 이 절의 범위`
  - `## 이 절의 목표`
  - `먼저 붙잡을 ...`
- 대표 위치:
  - `docs/parts/part-02/chapter-03/section-01.md`
  - `docs/parts/part-02/chapter-08/section-02.md`
  - `docs/parts/part-02/chapter-14/section-02.md`
- 판단:
  - Part 2는 실습 파트이므로 단계성이 필요하지만, 현재는 단계 설명이 아니라 절 운영 표지가 반복되는 모양에 가깝습니다.

### 2. `왜 필요한가`보다 `무엇을 먼저 할까`가 앞선다

- 대표 표현:
  - `어떤 환경을 먼저 선택할까`
  - `설치 뒤에는 버전을 먼저 확인한다`
  - `먼저 작은 Python 반복문으로 옮긴다`
- 대표 위치:
  - `docs/parts/part-02/chapter-10/section-02.md`
  - `docs/parts/part-02/chapter-07/section-07.md`
  - `docs/parts/part-02/chapter-15/section-01.md`
- 판단:
  - 실제 문제 장면이나 오류 장면보다 학습 진행 순서가 먼저 전면에 나옵니다.
  - 실습 파트라도 `왜 이 판단이 필요한가`를 문제 상황으로 먼저 열고 절차를 붙이는 편이 현재 원칙에 더 맞습니다.

### 3. 개념 설명 대신 학습 안내 문장이 남아 있다

- 대표 표현:
  - `왜 AI 학습에서 NumPy를 먼저 만나는가`
  - `전통적인 자료구조 개론은 무엇을 먼저 보여 주는가`
  - `질문이 먼저이고 차트 종류는 나중이다`
- 대표 위치:
  - `docs/parts/part-02/chapter-11/section-01.md`
  - `docs/parts/part-02/chapter-09/section-01.md`
  - `docs/parts/part-02/chapter-13/section-01.md`
- 판단:
  - 설명 대상이 개념이나 오류가 아니라 `학습 순서 자체`로 읽히는 구간이 있습니다.
