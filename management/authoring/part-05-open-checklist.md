# Part 5 미반영 체크리스트

이 문서는 Part 5 관련 재배치·보강 메모에서 아직 끝나지 않은 항목만 모은 체크리스트입니다.

## 체크리스트

- [ ] Part 5 순서를 실제로 재배치할지, 현재 순서를 유지하되 index와 장 제목으로 독서 경로를 보정할지 결정한다.
- [ ] Chapter 3과 Chapter 5의 역사/BERT 배경 축을 더 줄이거나 `보충학습`으로 보낼지 재검토한다.
- [ ] Chapter 4, 6, 8, 10을 더 앞쪽 본류로 재배치할지 구체 안을 확정한다.
- [ ] 임베딩 설명 일부를 RAG/벡터 검색 장과 더 밀접하게 재배치할지 검토한다.
- [ ] Chapter 9는 현재의 `실무 감각 + 보충학습` 구조를 유지하되, 본편 재배치 시 어느 위치를 맡길지 정한다.
- [ ] 토큰 수가 비용, 지연, 문맥 길이와 왜 연결되는지 더 작은 입력 예시로 보강할지 점검한다.
- [ ] 자동 평가와 사람 평가, 운영 제약과 실패 대응을 더 현실적인 서비스 체크리스트로 묶을지 검토한다.
- [ ] 역사·계보 예제의 Python 비중을 더 줄일 필요가 있는지 점검한다.
- [ ] Chapter 17, 18의 운영 설명을 통합 미니 실습 회고와 더 직접 연결할지 검토한다.
