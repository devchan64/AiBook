# Part 2, 새 데이터 모델링 Part, Part 3 연결 문단 초안

## 목적

이 문서는 새 데이터 모델링 Part가 들어올 때 앞뒤 Part가 어색하게 끊기지 않도록 연결 문단 초안을 준비하기 위해 만든다.

## Part 2 마무리에서 새 Part로 넘어가는 문단 초안

Part 2에서 우리는 수식, 배열, 표, 그래프, Python 실행 환경을 다시 읽는 기초를 복구했습니다. 이제 남은 질문은 이 도구들로 `무엇을 어떤 구조로 표현할 것인가`입니다. 실제 원천데이터를 만나면 먼저 부딪히는 문제는 모델 이름보다 샘플 단위, 요약 방식, 비교 기준을 정하는 일에 가깝습니다. 다음 Part에서는 데이터를 AI가 읽을 수 있는 샘플, 특징, 기준선 구조로 바꾸는 데이터 모델링을 다룹니다.

## 새 Part 시작에서 Part 2를 회수하는 짧은 연결 문장

앞 Part에서 복구한 표, 배열, 요약 통계, 시각화는 여기서 비로소 `문제 표현 도구`로 쓰입니다. 이제는 값을 계산할 수 있다는 사실보다, 어떤 값을 남기고 어떤 값을 비교할지를 결정하는 일이 더 중요해집니다.

## 새 Part 마무리에서 Part 3로 넘어가는 문단 초안

이제 우리는 원천데이터를 어떻게 샘플로 묶고, 어떤 특징을 만들고, 어떤 기준선과 비교해야 하는지의 기본 구조를 세웠습니다. 다음 Part에서는 이 구조 위에서 실제로 모델이 무엇을 학습하는지, 왜 train/validation/test를 나누는지, 점수와 일반화를 어떻게 읽어야 하는지를 다룹니다. 즉 다음 Part의 머신러닝은 데이터 모델링이 끝난 자리에서 시작합니다.

## Part 3 시작에서 새 Part를 회수하는 짧은 연결 문장

앞 Part에서 이미 feature, sample, baseline, label candidate가 어떤 뜻인지 정리했습니다. 이제 이 Part에서는 그 표현을 바탕으로 어떤 모델이 어떤 규칙을 배우는지, 그 학습 결과를 어떻게 검증해야 하는지에 집중합니다.

## 편집 메모

- Part 2의 끝에서는 `도구 복구`에서 `표현 설계`로 넘어간다는 점을 분명히 적는다.
- 새 Part의 끝에서는 `표현 설계`에서 `학습과 평가`로 넘어간다는 점을 분명히 적는다.
- Part 3 시작에서는 데이터 모델링 설명을 다시 길게 반복하지 않는다.

## 현재 결론

연결 문단의 역할은 새 Part의 존재를 정당화하는 데 있다. Part 2와 Part 3 사이의 공백을 `데이터 모델링`이 메운다는 구조가 문단 수준에서도 바로 보이게 해야 한다.
