# 데이터 모델링 Part 공통 자산과 경계 문장

## 목적

이 문서는 데이터 모델링 Part 집필에 반복 사용할 공통 표 자산, Python 예제 자산, 공통 어휘, 과장 방지 문장을 한곳에 모아 둔 기준 문서다.

## 공통 자산 묶음

### 1. 표 자산

- 행 의미 비교표
- 원시 로그, 요약 표, 집계 표 비교표
- 최근 구간과 기준선 비교표
- 같은 평균이지만 다른 패턴을 가진 사례 비교표

### 2. Python 예제 자산

- 원시 시계열 여러 행을 동작 1회 요약 행으로 묶는 예제
- 최근 구간 평균과 기준선 평균을 비교하는 예제
- 평균, 기울기, 변동성 같은 특징 열을 만드는 예제
- 같은 평균이라도 분산과 구간 패턴이 다른 사례를 만드는 예제

## 공통 어휘

| 권장 표현 | 뜻 | 주의점 |
| --- | --- | --- |
| 자동으로 실행되는 동작 1회 | 제어 명령 하나가 시작되어 종료될 때까지의 1건 | 특정 도메인 표현을 표준어처럼 쓰지 않는다 |
| 샘플 1건 | 모델이나 비교 표에서 한 행으로 다룰 분석 단위 | 한 행이 항상 샘플 1건이라고 가정하지 않는다 |
| 원시 시계열 | 제어 파라미터와 센서 관측이 시간 순서로 쌓인 원천 데이터 | `원본값`처럼 범위가 모호한 표현만 단독으로 쓰지 않는다 |
| 동작 1회 요약 행 | 원시 시계열 여러 행을 하나의 분석용 행으로 묶은 결과 | 단순 집계값으로만 축소하지 않는다 |
| 특징 | 요약 행이나 원시 구간에서 계산해 남긴 설명용 값 | `토큰`은 실제 이산화 규칙을 설명할 때만 제한적으로 쓴다 |
| 최근 구간 | 지금 검토 대상이 되는 최근 몇 건의 동작 묶음 | `실시간 이상`처럼 과장하지 않는다 |
| 기준선 | 비교를 위해 남겨 둔 평소 구간, 기준 집단, 또는 기본 모델 값 | baseline을 모델 이름처럼 오해하게 두지 않는다 |
| 변화 신호 | 최근 구간과 기준선 차이에서 먼저 보인 변화 | 원인 확정처럼 쓰지 않는다 |
| 경고 | 사람의 검토 우선순위를 올리기 위한 신호 | 자동 진단 확정처럼 쓰지 않는다 |
| 검토 필요 | 추가 확인이 필요하다는 보수적 판단 | 이상 확정이나 원인 규명으로 건너뛰지 않는다 |

## 반복 사용할 연결 문장

- 원시 시계열의 한 행은 측정 시점 하나일 뿐이고, 비교 대상은 그 행들이 모인 동작 1회다.
- 동작 1회 요약 행은 여러 시점을 모델과 사람이 함께 읽기 쉬운 한 행으로 바꾼 결과다.
- 최근 구간과 기준선을 나란히 두어야 변화가 보이고, 그 뒤에야 검토 우선순위를 정할 수 있다.
- 변화는 관찰되었지만 원인은 아직 확정되지 않았다.
- 경고는 자동 진단 결과라기보다 사람이 먼저 볼 대상을 좁히는 신호에 가깝다.
- 같은 평균이라도 구간 패턴과 변동성은 다를 수 있다.

## 과장 방지 문장 세트

- 변화는 관찰되지만 원인은 아직 확정되지 않았다.
- 경고는 검토 우선순위를 올리기 위한 신호다.
- 적은 표본에서는 해석을 보수적으로 해야 한다.
- 같은 평균이라도 패턴은 다를 수 있다.
- 최근 구간과 기준선의 차이는 설명 후보를 좁혀 주지만, 자동으로 원인까지 말해 주지는 않는다.
- 요약 행은 비교를 쉽게 만들지만, 원시 시계열의 모든 맥락을 대체하지는 않는다.

## 피해야 할 문장

- 이 패턴은 특정 고장을 의미한다.
- 이 경고는 문제 원인을 보여 준다.
- 이 수치 차이만으로 이상 여부를 확정할 수 있다.
- 이 예제는 실제 운영 규칙을 그대로 설명한다.
