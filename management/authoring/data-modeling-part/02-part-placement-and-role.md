# 데이터 모델링 Part의 배치와 역할

## 권장 배치

현재 기준으로 가장 자연스러운 위치는 `Part 3`이다.

즉 책의 큰 흐름은 아래처럼 재정렬된다.

1. Part 1: AI와 문제 지형도
2. Part 2: 수학, Python, 배열, 표, 시각화 기초 복구
3. Part 3: 데이터 모델링
4. Part 4 이후: 머신러닝, 딥러닝, 생성형 AI, 프로젝트

## 왜 이 위치가 맞는가

### Part 2 다음이어야 하는 이유

Part 2를 마친 독자는 이미 다음 도구를 다시 읽을 수 있다.

- 표와 행, 열
- 배열과 shape
- 요약 통계
- 시각화
- 간단한 Python 데이터 처리

데이터 모델링은 바로 이 도구들을 사용해 `무엇을 한 건의 데이터로 만들 것인가`를 정하는 단계다. 따라서 Part 2 바로 뒤가 가장 자연스럽다.

### 기존 머신러닝 Part보다 먼저 와야 하는 이유

머신러닝은 feature, label, baseline, split, evaluation을 전제로 한다. 그런데 데이터 모델링이 먼저 정리되지 않으면 독자는 다음 질문에 답하지 못한다.

- 지금 한 행은 무엇을 뜻하는가
- 어떤 열이 의미 있는 feature인가
- 최근 구간과 기준선 비교는 데이터셋 안에서 어떻게 표현되는가
- 어떤 라벨은 만들 수 있고 어떤 라벨은 아직 만들 수 없는가

따라서 데이터 모델링 Part는 현재 번호 체계에서 `Part 4 머신러닝`의 선행 Part가 되어야 한다.

## 이 Part의 역할

이 Part는 데이터베이스 설계 단원을 대체하는 것이 아니다. 또 머신러닝 알고리즘 Part도 아니다.

이 Part의 역할은 다음 한 문장으로 정리할 수 있다.

`현실에서 발생한 원천데이터를, 사람이 비교하고 AI가 활용할 수 있는 샘플·표현·비교 구조로 다시 만드는 법을 가르치는 Part`

## 앞뒤 Part와의 경계

### 앞 Part와의 경계

앞 Part에서는 주로 계산 도구와 표현 수단을 복구한다. 아직 여기서는 `어떤 현상을 어떤 데이터 구조로 정의할 것인가`를 깊게 다루지 않는다.

### 뒤 Part와의 경계

뒤 Part에서는 이미 설계된 데이터 표현을 바탕으로 학습, 평가, 일반화, 딥러닝, 생성형 AI 응용을 다룬다.

즉 새 Part는 `도구 복구`와 `학습 알고리즘` 사이의 빈 구간을 메운다.

## 독립 Part가 가져가는 핵심 질문

- 측정값 하나와 샘플 하나는 어떻게 다른가
- 원시 시계열은 왜 바로 데이터셋이 아닌가
- 요약 표와 특징은 어떤 기준으로 설계하는가
- 최근 구간과 기준선 비교는 왜 데이터 모델링의 일부인가
- 적은 표본에서 어떤 해석은 보류해야 하는가
- 어떤 문제는 경고 후보 생성으로 다루고, 어떤 문제는 분류 문제로 다루는가

## 현재 결론

새 데이터 모델링 Part는 `Part 3`으로 배치해, `Part 4` 이후의 학습 설명이 기대는 데이터 표현 전제를 먼저 가르치는 역할을 맡는 편이 맞다.
