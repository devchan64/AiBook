# P7-5.11 재생성본 검수와 첫 LoRA 학습 구성

검수일: 2026-09-13. v2 원본 40개를 게시된 방향별 참조와 시각 비교하고 입력·출력 SHA-256을 확인했다. AI의 시각 판정이며 정량적 정체성 검증이나 사용자 최종 승인을 뜻하지 않는다.

보충본은 학습 28개, 평가 4개, 보류 8개다. 5.2의 재검수된 방향 우선 후보 12개를 합쳐 학습 40개·평가 4개로 준비했다. 기존 5.9 후보 39개와 5.2 예비 5개는 이번 패키지에 넣지 않았다. 보류는 영구 폐기와 다르다.

- 의상 01–08: 채택.
- 배경 01–04, 07–08: 채택. 05는 큰 검은 좌우 여백으로 전처리 전 보류, 06은 대합실 대신 검은 단색 배경이어서 보류.
- 조명 01–04, 06–08: 채택. 05는 강한 주황색과 명암으로 피부·헤어의 기준색 판독이 어려워 보류. 광원의 효과를 피부 고유색 변화라고 단정하지 않는다. 기준 이미지에서 이어진 흰 측면 여백은 정체성 결함으로 판정하지 않는다.
- 표정 01–07: 채택. 06은 실제 눈을 내리깐 걱정/슬픔 표정으로 캡션 수정. 08은 열린 눈과 홍채의 과도한 확대 때문에 보류.
- 평가 02, 04, 05, 06: 학습에서 분리. 04는 전신 구도·보행 평가에 한정하고 작은 얼굴을 세밀한 정체성 정답으로 사용하지 않는다.
- 평가 01, 03, 07, 08: 눈매·헤어·화풍 차이로 정답용 보류. 특히 03은 참조와 반대 방향 측면으로 생성됐다.

평가 이미지는 동일 생성 모델과 동일 캐릭터 참조에서 파생되었다. 따라서 독립된 실제 정답이 아니며, 새로운 의상·장면 조합의 질적 비교에 사용한다. 원본 5.2 참조도 함께 보고 LoRA 미적용/적용 결과를 비교해야 한다. 평가 이미지는 학습 타깃과 제어 이미지 양쪽에서 제외한다.

학습 캡션에는 캐릭터 토큰 `mira_person`과 실제 장면·의상·시점·표정을 적고, 눈동자색이나 얼굴 비율을 다시 정의하는 문구를 넣지 않았다. 기존 준비 코드의 다른 학습 이미지와의 제어/타깃 짝 구성은 인물 유지 실험용이며, 무참조 인물 생성 성능을 보장하지 않는다.

## 실행 진행

2026-09-13: `.tmp/p7-5-11/run_reviewed.py`를 실행했다. 현재 단일 BF16 DiT와 텍스트 인코더 다운로드를 기다리며, 완료 후 SHA-256 계산 → 실행 전용 설정·패키지 생성 → latent 캐시 → 텍스트 캐시 → 100스텝 LoRA 학습으로 이어진다. 기존 다운로드 자료는 보존한다.

실제 GPU 메모리는 약 8GB이므로 실행 설정은 타깃·제어 해상도 512, 블록 스왑 55, rank/alpha 16, DiT 실행 시 FP8 변환, 텍스트 캐시 CPU BF16이다. 이는 메모리 절약을 위한 시도이며 실행 성공이나 최종 학습 품질은 아직 확인하지 않았다. CPU 텍스트 캐시와 블록 교환 때문에 오래 걸릴 수 있다. 100스텝은 첫 실행 점검용이고 충분한 학습량으로 확정한 값이 아니다.

진행 상태: `.tmp/p7-5-11/lora-v2-execution-state.json`. 실제 학습 단계 로그는 실행 패키지가 만들어진 뒤 `.tmp/p7-5-11/lora-v2-run100/logs/`에 기록된다. 체크포인트는 같은 패키지의 `checkpoints/`에 생성되어야 완료로 판단한다. 아직 가중치 생성 완료 상태가 아니다.

학습용 단일 파일 선택 근거: [고정 Musubi 버전 안내](https://github.com/kohya-ss/musubi-tuner/blob/e0cbd8f3dfe38365b10f8bc790b980f8894e8ba1/docs/qwen_image.md), [Comfy-Org Edit 모델 파일](https://huggingface.co/Comfy-Org/Qwen-Image-Edit_ComfyUI), [텍스트 인코더·VAE](https://huggingface.co/Comfy-Org/Qwen-Image_ComfyUI). 모델 인벤토리의 라이선스 검토 상태는 원문 라이선스 확인 전까지 유지한다.

진행 확인: 가중치 다운로드 완료 후 VAE snapshot 심볼릭 링크가 확장자 없는 blob 경로로 해석되어 실행 전 검사가 실패했다. 가중치의 명시된 파일명을 유지하고 해시는 링크 대상 내용으로 검증하도록 수정했다. 회귀 테스트를 포함한 9개 테스트를 통과했으며 같은 패키지를 재실행했다. 재시도 로그는 `.tmp/p7-5-11/lora-v2-retry.log`다.

VAE 해시 검사 및 가중치 로딩은 통과했다(`All keys matched successfully`). 이어진 latent 캐시 생성은 Musubi의 `ThreadPoolExecutor`가 `num_workers=0`을 허용하지 않아 중단됐다. latent·text 캐시 작업자 수를 1로 수정하고 실패 로그를 보존한 채 `.tmp/p7-5-11/lora-v2-run100-retry1/` 패키지로 재실행했다. 최신 실행 로그는 `.tmp/p7-5-11/lora-v2-retry1.log`다.
