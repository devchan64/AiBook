## 학습 관점 누락 점검

- 각 Chapter를 볼 때 `수학·코드·도구를 왜 지금 복구해야 하는가`가 뒤 Part와 연결되어 보이는지 확인합니다.

- Part 2에서는 특히 `수식-코드-데이터 연결`, `shape와 반복 단위`, `재현 가능한 실행 환경`이 빠지지 않는지 다시 봅니다.

- Part 2의 전체 경계는 `AI 계산 문해력 복구`입니다. 수학은 증명 중심으로, Python은 일반 프로그래밍 강의로, Git과 실행 환경은 도구 매뉴얼로 확장하지 않고 Part 3 이후의 데이터 모델링을 읽기 위한 공통 언어로 닫습니다.

- P2-3.5와 P2-7, P2-10은 실행 위치를 함께 다루므로 경계가 겹치기 쉽습니다. P2-3.5는 선형대수 예제를 실행할 때 Colab과 로컬 PC의 위치 차이를 짧게 잡고, P2-7은 로컬 실행 환경 구성, P2-10은 노트북 기록과 재실행 기준으로 나눠 둡니다.
- P2-3.6과 P2-11은 모두 NumPy를 다룹니다. P2-3.6은 선형대수 개념을 배열 계산으로 확인하는 다리 역할이고, P2-11은 NumPy 자체의 배열, 축, 브로드캐스팅, 원본 공유를 읽는 도구 학습 역할입니다.
- P2-4.5와 P2-4.6은 미분 보충 구간입니다. P2-4.5는 고등학교식 한 변수 미분에서 다변수 그래디언트로 넘어갈 때의 막힘을 메우고, P2-4.6은 합성함수와 연쇄 법칙을 역전파 입구로만 연결합니다. 역전파 전체나 딥러닝 학습 알고리즘은 뒤 Part로 넘깁니다.
- P2-5.4와 P2-5.5는 통계 계산과 통계 용어 보충을 나눕니다. P2-5.4는 작은 데이터로 평균, 분산, 분포를 직접 계산하는 절이고, P2-5.5는 표준편차, 상관, 신뢰구간을 처음 읽을 때의 해석 기준을 보충하는 절입니다.
- P2-7.1~P2-7.5는 재현 가능한 실행 환경의 본류이고, P2-7.6~P2-7.9는 운영체제별 진입, 설치 필요성, 셸 흐름, 로컬 문제 점검을 보충합니다. 보충학습은 초심자가 막히는 지점을 읽는 기준으로 남기고, 셸 스크립트나 패키징 전문 과정으로 확장하지 않습니다.
