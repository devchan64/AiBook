# P6-4.1 근거 검토 메모

## 이 절의 역할

- 텍스트 분류 프로젝트의 최소 구조를 보여 준다.
- 문장 -> 토큰 -> 벡터 -> 라벨 예측 흐름을 작은 예제로 재현한다.

## 핵심 주장

- 텍스트 분류 프로젝트는 입력 문장을 토큰화해 벡터로 바꾸는 표현 단계가 핵심이다.
- vocabulary와 label 구조를 문서에 함께 적어야 한다.
- 작은 성공 사례도 일반화와 분리해서 읽어야 한다.

## 반영한 근거

- NumPy 공식 문서: count vector와 거리 계산을 위한 기본 근거
- Part 3의 classification 개념과 Part 5의 token 개념을 연결하는 자체 실습

## 집필 메모

- 외부 NLP 라이브러리 없이 공백 기준 토큰화로 흐름을 단순화했다.
- 실제 고객 문장 로그를 쓰지 않고 자체 장난감 데이터로 구성했다.
