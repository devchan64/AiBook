# Part 7 Character Reference Pack 관찰·명세 양식

이 양식은 웹툰 컷 생성에 쓰는 자체 제작 캐릭터 일러스트의 입력 역할, 관찰 가능한 특징, 생성 조건과 한계를 기록한다. 한 장의 인물 이미지를 여러 컷의 identity reference로 바로 일반화하지 않는다. 이 양식은 승인·미승인 상태를 관리하지 않는다.

## 기본 정보

```text
character_id:
revision:
creator_or_source:
rights_confirmation:
style_anchor:
reference_role:
known_limits:
```

`rights_confirmation`에는 직접 제작, 사용 허락, 라이선스 확인 중 해당 근거를 적는다. 상업 캐릭터나 권리 불명 이미지는 이 팩에 넣지 않는다.

## 사용·변형 메모

```text
reference_usage:
observed_variation:
known_limits:
next_experiment_question:
```

전신 turnaround와 face sheet의 필수 view가 모두 있더라도 품질 상태를 부여하지 않는다. 의상·소품·화풍의 관찰값과 알려진 한계를 함께 기록해, 다음 실험에서 어떤 입력이 무엇을 담당하는지 판단한다.
