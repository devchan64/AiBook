# Part 3 설명 개선안과 근거 검토

작성일: 2026-09-18  
대상: 한국어 Part 3 원고 `v2026.09.15`  
성격: 본문 개정 전 집필 판단과 근거를 정리하는 관리문서

## 1. 개선 목적과 적용 범위

Part 3의 상위 목적은 **AI를 이해하기 위해 필요한 데이터 이해와 취급 방법을 설명하는 것**으로 잡는다. 데이터 모델링은 그 안에서 사례와 기록을 질문에 맞는 샘플·표·특징·목표로 구성하는 역할을 맡는다. 지표 설명 보강은 이 전체 흐름을 독자가 이해하도록 돕는 개선 과제다. 이 목적 설정은 이 책의 교육적 범위이며, 외부 자료에서 정한 유일한 커리큘럼이라고 주장하지 않는다.

독자가 남겨야 할 이해는 `AI에 데이터를 넣는다`는 말 안에 어떤 선택이 들어 있는가이다. 무엇을 기록했는지, 무엇을 한 사례로 묶었는지, 어떤 정보를 남기거나 잃었는지, 무엇을 목표로 삼았는지에 따라 AI가 활용할 입력과 결과의 의미가 어떻게 달라지는지 설명할 수 있어야 한다. 문제·데이터의 연결은 [S5](#s5), 목표·출력·대리 라벨의 관계는 [S6](#s6), 입력 처리와 평가 정보의 경계는 [S9](#s9)를 근거로 삼는다.

| Part 3에서 다룰 축 | 독자가 이해할 질문 | 현재 원고와 연결 |
| --- | --- | --- |
| 현상과 기록 | 현실의 무엇을 어떤 조건·시점·단위로 기록했는가 | Chapter 1~3 |
| 샘플과 데이터 구조 | 무엇을 한 건으로 보고 어떤 행·열·구간으로 구성하는가 | Chapter 2~5 |
| 데이터의 범위와 품질 | 빠진 값·조건, 겹친 기록, 측정 방식의 차이는 어떤 판단을 제한하는가 | P3-4.5, P3-5.4~5.6, P3-6.6 |
| 표현과 특징 | 어떤 정보를 남기고 무엇을 압축하며, 그 표현으로 무엇을 비교할 수 있는가 | Chapter 5~6 |
| 탐색과 비교·해석 | 질문에 맞는 지표와 기준선을 어떻게 고르고 결과를 어디까지 해석하는가 | Chapter 7~8 |
| AI 학습 문제로의 연결 | 입력, 목표, 라벨, 관측 시점과 평가 범위를 어떻게 구분하는가 | Chapter 9와 Part 4 인계 |

따라서 개선 검토는 지표의 정의뿐 아니라 각 축에서 `데이터를 다루는 이 선택이 뒤의 AI 이해와 어떻게 이어지는가`도 확인한다. 데이터 수집 시스템 구축, 통계학 전 과정, 모델 학습 알고리즘을 모두 추가하는 방향으로 범위를 넓히지는 않는다. 현재 Section의 학습 질문에 필요한 데이터 취급 원리와 작은 사례를 보강한다.

Part 3의 설명을 `관찰한 사례와 현상 → 확인할 질문 → 기록할 데이터 → 비교 기준과 지표 → 계산 결과 → 해석과 다음 확인`으로 연결한다. 지표를 사전식으로 정의하는 데서 끝내지 않고, 그 지표가 현상의 어떤 면을 살피기 위해 선택되었는지 독자가 따라갈 수 있게 한다.

이 순서는 아래 자료의 문제 정의, 탐색, 수치 요약, 평가 원칙을 이 책의 학습 흐름에 맞게 종합한 **집필 설계**다. 특정 출처에 있는 보편적 단일 절차를 그대로 옮긴 것이 아니다. Part 3의 `데이터 모델링`도 현재 원고가 정한 넓은 집필 범위를 유지하며, 데이터베이스 모델링·통계적 모델링·기계학습 전체의 표준 정의로 확대하지 않는다.

이번 문서는 본문 수정 완료 기록이 아니다. 원고와 번역본, 코드, 자산, Section 버전은 변경하지 않는다. 실제 개정 시에는 이 문서의 절별 계획을 적용하고 대응 릴리즈노트에 반영한다. [Part 3 체크포인트](part-03-open-checklist.md)는 중심 학습 산출물을 관리하며, 이 개선안의 작업 목록으로 대체하지 않는다.

## 2. 작업 가설을 일반적인 설명으로 바꾸는 기준

검토의 출발점은 다음 두 가지 독자 피드백이다.

- 사례와 현상을 기록하고 경험에서 나온 예상으로 확인할 대상을 좁혀 가면 불필요한 시행착오를 줄일 수 있을 것이라는 생각.
- 지표는 현상을 살피는 기준이므로, 선택 이유와 의미가 설명되지 않으면 뒤의 비교와 판단도 따라가기 어렵다는 문제 제기.

이를 그대로 표준 이론으로 선언하지 않고 다음처럼 분리한다.

| 구분 | 근거 검토 결과 | 원고에 적용할 표현 |
| --- | --- | --- |
| 표준적 설명 | 문제와 목표를 명확히 하고 데이터의 구조·가정을 살피는 접근은 공식 자료에서 확인된다. [S1](#s1), [S2](#s2), [S5](#s5) | 무엇을 알고 싶은지 정한 뒤 필요한 기록과 비교 방법을 선택한다. 탐색 결과에 따라 처음의 가정을 다시 살핀다. |
| 표준적 설명 | 중심 수준, 흩어짐, 분류의 정답 비율은 서로 다른 특성을 요약한다. [S3](#s3), [S4](#s4), [S7](#s7) | 지표마다 답하는 질문과 읽는 방법이 다르다. 어떤 질문에 쓸 수 있는지 사례에 연결한다. |
| 이 책의 집필 판단 | 구체 표현과 추상 개념을 연결하고 풀이 예시와 연습을 함께 제시하는 교육 권고를 Part 3에 적용한다. [S12](#s12) | 현상과 작은 기록을 먼저 보이고, 지표 선택·계산·해석을 연결한 뒤 독자가 한 값을 바꿔 확인하게 한다. |
| 작업 가설 | 경험이나 직관은 조사할 질문을 제안하는 출발점이 될 수 있다. 이 사실만으로 그 설명이 맞다고 확정할 수는 없다. | `끝부분 하강이 관련 있을 수 있다`를 확인할 질문으로 바꾼다. 맞지 않는 사례와 다른 설명도 살핀다. |
| 검증 필요 | 직관을 사용하면 시행 횟수가 일반적으로 감소한다는 보장은 이번 자료에서 확립하지 못했다. | 시행 횟수 감소를 데이터 모델링의 정의·필수 성과·보장으로 쓰지 않는다. 필요하다면 동일 조건의 비교 실험으로 별도 검증한다. |

탐색에서 발견한 차이, 이후 자료에서 확인한 예측 성능, 원인에 대한 설명도 구분한다. 이 문서에서 제안하는 작은 예시는 비교 방법을 설명하기 위한 것이며 실제 설비의 고장 원인을 입증하지 않는다.

## 4. 주요 개선 방안

### 4.1 사례의 질문에서 지표를 선택한다

`평균, 표준편차, 기울기를 계산한다`로 시작하지 않는다. 먼저 하나의 현상에서 서로 다른 질문을 만든다.

| 관찰에서 생긴 질문 | 비교할 면 | 지표 후보 | 함께 남길 경계 |
| --- | --- | --- | --- |
| 전체적으로 낮아졌는가 | 수준 | 평균·중앙값 | 어느 구간·어느 집합을 요약했는가 |
| 같은 수준 주변에서 값들이 더 벌어졌는가 | 흩어짐 | 표준편차 | 상승·하강 추세도 흩어짐을 만들 수 있다 |
| 끝부분에서 더 빠르게 내려가는가 | 방향과 속도 | 구간 기울기 | 시간 간격과 계산 구간이 필요하다 |
| 평소 조건과 얼마나 다른가 | 기준 대비 차이 | 현재값 − 기준값 | 기준 기간·조건·단위가 맞아야 한다 |
| 여러 동작에서도 나타나는가 | 관측 횟수·비율 | 해당 건수 / 전체 건수 | 비율만으로 연속성·독립성은 알 수 없다 |
| 무엇부터 확인할 것인가 | 운영상 우선순위 | 명시한 정렬 규칙·등급 | 고장 확률이나 원인 확정과 다르다 |

수준·흩어짐에 대한 표준적 근거는 [S3](#s3)·[S4](#s4), 문제에서 조사할 항목을 고르는 근거는 [S1](#s1)·[S5](#s5)다. 이 표의 유량 사례와 배열은 자체 집필안이다. 표준편차가 크다는 사실을 바로 `고장`, `불안정`, `나쁨`으로 번역하지 않는다.

### 4.2 지표 이름과 측정 정의를 함께 도입한다

지표 첫 설명에는 아래 항목이 사례의 문장이나 표 안에 있어야 한다. 모든 절에 같은 양식의 큰 표를 반복할 필요는 없다.

1. **질문과 선택 이유:** 현상의 어떤 차이를 보고 싶은가. 기존 값 하나로는 무엇을 놓치는가.
2. **기록 대상과 구간:** 한 동작의 원시 시점인가, 구간 평균인가, 여러 동작의 집계인가.
3. **뜻과 계산:** 쉬운 말로 설명한 뒤 작은 숫자로 원래 기록에서 계산한다.
4. **단위와 방향:** 초·L/min·L/min/s·건수·비율 중 무엇인가. 음수·0·큰 값은 무엇을 뜻하는가.
5. **분모와 예외:** 비율의 전체 집합, 결측 제외, 0으로 나누는 경우, 표본 표준편차의 최소 개수를 확인한다.
6. **비교와 해석:** 무엇과 비교하면 어떤 관찰 문장을 쓸 수 있는가. 아직 무엇은 말할 수 없는가.
7. **독자 확인:** 값이나 조건 하나를 바꾸어 해석이 어떻게 달라지는지 답하게 한다.

`mean`, `std`, `diff`, `rate`는 첫 사례에서 한국어 의미와 연결한다. `rate`는 비율이나 시간당 변화 등 여러 뜻으로 쓰이므로 열 이름으로 단위를 추정하게 하지 않는다. `baseline_gap`, `repeatability_score`, `priority_score`는 이 책의 사례별 열 이름이며 이름만으로 계산법이 정해지는 표준 지표처럼 소개하지 않는다.

### 4.3 수치의 역할을 구분한다

| 종류 | 예 | 설명의 초점 |
| --- | --- | --- |
| 현상을 요약한 값 | 평균 유량, 표준편차, 후반 기울기 | 어떤 상태·모양을 보존하는가 |
| 비교값 | 기준선 차이, 상대 변화율 | 무엇과 어떤 방향으로 비교했는가 |
| 기록 범위를 보여 주는 값 | 조건별 건수, 라벨 확보 비율 | 어떤 사례가 포함·제외되었는가 |
| 운영 규칙의 결과 | 검토 등급, 우선순위, 큐 순위 | 어떤 정책으로 행동 순서를 정했는가 |
| 모델의 출력 | 예측 라벨, 모델 점수 | 한 사례에 대해 무엇을 예측했는가 |
| 모델 평가 지표 | 정확도 | 정답이 있는 어떤 집합에서 성능을 요약했는가 |

이 분류는 Part 3의 혼동을 줄이기 위한 집필 구분이다. 같은 수치가 모델의 입력으로 쓰이면 특징이 될 수 있지만, 숫자라는 이유만으로 모두 특징이나 성능 지표가 되는 것은 아니다. 목적의 성취와 모델 평가를 구분하는 일반 근거는 [S6](#s6), 정확도의 정의는 [S7](#s7), 예측 점수와 판정의 구분은 [S8](#s8)에서 확인한다.

### 4.4 첫 등장에서는 풀고, 재등장에서는 현재 사례와 연결한다

P3-1.1에서 실제로 필요한 평균·흩어짐·후반 기울기·기준선 차이를 설명한다. 통계 지표 전체를 첫 절에 모으지 않는다. 구간·분포 요약은 Chapter 5, 특징의 단위는 Chapter 6, 여러 사례의 반복과 검토 규칙은 Chapter 7~8에서 필요한 순간 확장한다.

후속 절에서는 정의를 다시 길게 복제하기보다 `앞에서 본 표준편차를 이번에는 구간 평균 세 개에 적용한다`처럼 계산 대상의 변화를 말한다. 상세 정의 위치와 개념사전 링크는 보조 탐색 수단이며 본문 설명을 대신하지 않는다. 지금 필요하지 않은 지표는 열거에서 빼거나 실제 설명이 있는 후속 절로 보낸다.

### 4.5 가상 규칙도 독자가 재현할 수 있게 만든다

`가상 값이므로 확률이 아니다`라는 주석만으로는 지표의 뜻이 설명되지 않는다. P3-8.4~8.5, P3-9.3~9.5의 점수는 아래 둘 중 하나로 정리한다.

- 숫자가 꼭 필요하면 분자·분모나 가중치·조건·동률 규칙을 명시하고 표 한 행을 직접 계산한다.
- 순서만 필요하면 `안전 관련 먼저 → 같은 조건에서 차이의 절댓값 순 → 동률이면 식별자 순`처럼 해석 가능한 정렬 규칙을 사용한다. 근거 없는 0.82 같은 정밀한 숫자는 제거한다.

임계값은 지표가 아니라 지표를 행동으로 바꾸는 규칙이라는 점도 구분한다. 경계값 포함 여부를 명시한다. [S8](#s8)의 분류 임계값 설명은 이 구분을 뒷받침하지만, 이 책의 가상 안전 규칙·가중치를 검증해 주지는 않는다. 0~1 범위나 백분율 표기만으로 고장 확률이 되지 않으며, 확률 해석은 모델과 보정 상태의 별도 문제다. [S11](#s11)

### 4.6 코드보다 먼저 손으로 읽을 수 있는 예를 둔다

표 한두 행의 의미를 이해하기 위해 긴 Python 코드를 먼저 해독하게 하지 않는다. `작은 기록 → 한 번의 계산 → 한 문장의 해석`을 먼저 제공한 뒤 코드는 여러 사례에 같은 규칙을 적용하는 역할을 맡긴다. 기존 실행 가능한 기준 소스는 유지하며, 나눠야 할 것은 설명이지 소스 자체가 아니다.

모델이 나오는 P3-4.2·P3-4.5·P3-6.1·P3-6.5·P3-8.6·P3-9.7에서는 모델 코드보다 입력·출력과 사례의 비교 목적을 먼저 설명한다. 정확도는 현재 첫 등장인 P3-4.2에서 맞힌 건수와 평가 대상의 뜻을 설명하고 후속 절에서 재사용한다. 알고리즘 튜닝은 Part 4의 영역으로 둔다. P3-8.6의 학습 자료에서 얻은 높은 정확도는 선택적 라벨 문제와 함께 학습 자료 재평가의 영향도 받으므로, 선택 편향 하나만의 효과를 입증하는 실험으로 서술하지 않는다. 평가에 쓰면 안 되는 정보가 학습·전처리에 들어갈 때 생기는 문제는 [S9](#s9)로 확인한다.

교육적 근거인 [S12](#s12)는 구체·추상 표현의 연결, 풀이 예시와 문제 풀이의 병행을 권고한다. 이 책의 독자에게 특정 배열이 반드시 가장 효과적이라는 주장까지 입증하는 것은 아니므로 실제 독자 확인으로 보완한다.

### 4.7 데이터 취급의 선택을 AI의 입력과 목표에 연결한다

지표의 계산이 끝났을 때 설명도 끝내지 않는다. 예를 들어 평균만 남기면 상승·하강 순서가 사라지고, 시점별 기록을 각각 별도 사건으로 세면 같은 동작이 여러 사례처럼 보이며, 검토 여부를 라벨로 삼으면 실제 고장과 다른 대상을 목표로 삼을 수 있다. 각 사례에서 데이터 구성의 선택과 남는 정보·사라지는 정보를 확인하고, 뒤의 모델이 무엇을 입력받고 무엇을 맞히게 되는지 연결한다. 데이터 처리와 목표 정의의 일반 근거는 [S6](#s6)·[S9](#s9)이며, 구체적인 설명 배치는 이 책의 집필 판단이다.

센서·유량 사례는 기록에서 특징과 비교표가 만들어지는 과정을 이어 보여 주는 중심 사례로 활용한다. 다만 이를 데이터 취급의 유일한 형태로 읽게 하지 않는다. 샘플 단위를 설명한 뒤 `이미지 한 장`, `문서 한 건`에서는 어떤 경계와 부가 정보가 필요한지 짧게 묻는 등 같은 원리가 다른 데이터에도 적용되는지 확인한다. 이미지나 텍스트도 반드시 평균·기울기로 요약해야 한다는 인상을 주지 않으며, 수작업 특징과 원시 입력·학습된 표현의 관계는 P3-6.3과 연결한다.

Part 시작과 마무리에서는 데이터 이해·구성·품질·표현·해석·학습 문제 연결이라는 전체 역할을 먼저 보여 준다. 개별 절에서는 현재 주제에 필요한 연결만 남겨 모든 단락에 모델 학습 설명을 반복하지 않는다.

## 5. 본문에 적용할 작은 설명 예시

다음은 외부 자료의 예제나 표를 복제하지 않고 만든 **집필용 가상 예시**다. 실제 개정에서는 기존 사례와의 연결을 먼저 검토한다. 지표 설명을 위해 새 데이터셋을 대량 생성할 필요는 없다.

### 5.1 평균은 같은데 모양이 다른 경우

세 번의 동작에서 시작 뒤 0초·1초·2초의 유량을 기록했다고 하자. 단위는 L/min이다.

| 동작 | 0초 | 1초 | 2초 | 평균 | 표본 표준편차 | 마지막 1초의 기울기 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A | 24 | 24 | 24 | 24 | 0 | 0 L/min/s |
| B | 23 | 24 | 25 | 24 | 1 | +1 L/min/s |
| C | 25 | 24 | 23 | 24 | 1 | −1 L/min/s |

원고의 설명 순서는 다음과 같이 잡는다.

1. **현상:** A는 일정하고, B는 올라가고, C는 내려간다. 어느 면에서 다른지 원시값에서 먼저 확인한다.
2. **평균 질문:** 전체 수준만 비교하면 셋 모두 `(세 값의 합)/3 = 24`다. 평균만으로 방향을 구분할 수 없다.
3. **흩어짐 질문:** B의 평균에서 차이는 −1·0·1이다. 제곱해 더한 2를 `3−1`로 나누고 제곱근을 구하면 표본 표준편차 1 L/min이다. C도 1이다. 이는 평균 주변의 흩어짐이지 상승·하강의 구분이 아니다. [S4](#s4)
4. **방향 질문:** C의 마지막 기울기는 `(23−24)/(2−1) = −1 L/min/s`다. B는 +1이다. 구간과 시간을 정해야 방향과 속도가 드러난다.
5. **해석:** 끝부분 하강을 살피려면 기울기가 필요하고, 전체 수준이나 흩어짐을 살피려면 다른 값이 필요하다. 이 표만으로 C가 고장이라고 판단하지 않는다.
6. **연습:** C의 마지막 값을 24로 바꾸면 마지막 기울기는 0이다. 평균은 약 24.33, 표본 표준편차는 약 0.58이 된다. 한 지표가 같아져도 다른 면은 달라질 수 있다.

기울기와 표준편차를 동시에 `흔들림`으로 부르지 않는 것이 이 사례의 핵심이다. 표본 표준편차의 공식 전체를 외우게 하기보다, 무엇을 구별하고 무엇을 구별하지 못하는지 설명하게 한다.

### 5.2 같은 숫자도 분모가 다르면 질문이 다르다

기존 P3-8.6의 출력은 다음처럼 건수와 연결해 설명할 수 있다.

| 값 | 계산 | 답하는 질문 |
| --- | --- | --- |
| 라벨 확보 비율 40% | 검토되어 라벨이 있는 4건 / 전체 10건 | 전체 중 결과를 확인한 범위는 얼마인가 |
| 검토된 사건의 고장 비율 75% | 고장 3건 / 검토된 4건 | 확인한 사건 중 실제 고장은 얼마인가 |
| 검토된 사건의 정확도 100% | 예측 일치 4건 / 검토된 4건 | 이 집합에서 예측이 몇 건 맞았는가 |
| 데모 전체 정확도 70% | 예측 일치 7건 / 전체 10건 | 숨겨 둔 전체 정답을 열었을 때 몇 건 맞았는가 |

현재 코드의 `label coverage` 출력은 비율 자체가 아니라 검토 여부별 건수 `{0: 6, 1: 4}`다. 본문에서 40%를 설명하려면 이 건수에서 계산했다고 밝혀야 한다. 검토된 4건은 모델 학습에 사용된 자료이므로 그 집합의 100%를 새 사건에 대한 성능으로 읽지 않는다. 정확도의 정의와 집합 해석은 [S7](#s7), 평가 정보 분리 원칙은 [S9](#s9)를 참조한다.

### 5.3 차이·상대 변화·반복 비율을 분리한다

P3-7.2의 type-A를 사용하면 후반 평균 유량은 기준선 2.8에서 최근 2.2 L/min으로 바뀌고, 최근 20건 중 하강 규칙 충족은 14건이다.

- **평균 차이:** `2.2−2.8 = −0.6 L/min`. 얼마만큼 낮아졌는가를 말한다.
- **기준선 대비 상대 변화:** `(2.2−2.8)/2.8 × 100 ≈ −21.4%`. 기준 수준에 비해 얼마나 달라졌는가를 말한다. 이 계산은 양수인 기준선 2.8에 대한 사례이며, 기준이 0이거나 부호가 달라지는 자료에는 같은 해석을 무조건 적용하지 않는다.
- **하강 규칙 충족 비율:** `14/20 = 70%`. 몇 건에서 정한 현상이 관측되었는가를 말한다. 70%만으로 시간상 연속되었는지는 알 수 없다.

여기에 필요한 개선은 공식을 더 많이 나열하는 것이 아니라, 각각 다른 질문과 분모를 갖는다는 설명이다. 원고 개정 시에는 먼저 하강 규칙을 정의해 14건을 무엇으로 셌는지도 밝힌다.

- **P0 — 먼저 수정:** 뒤 절의 이해를 막는 기초 정의, 서로 충돌하는 설명, 계산·평가 대상의 혼동.

- **P2 — 유지·연결:** 이미 구체적인 설명을 유지하고 앞뒤 사례와 표기만 정렬.

분석 결과는 P0 19개, P1 29개, P2 6개다. 54개 모두 개별 수정 방향과 완료 기준을 기록했으며, Section ID·원고 경로 대응, 누락·중복, 로컬 링크와 출처 앵커를 확인했다. 이는 관리문서의 범위·정합성 검수 결과이며 본문 수정이나 코드 실행 검증 결과는 아니다.

`현상 → 질문 → 기록 → 계산·표현 → 해석`은 전체 편집 방향이다. 모든 절에 다섯 단계를 똑같이 반복하지 않는다. 각 절의 중심 산출물은 [기존 체크포인트](part-03-open-checklist.md)와 대조했으며, 아래 계획은 그 문서를 작업 로그로 바꾸지 않는다. 실제 집필에서는 Part의 목적 문구를 먼저 정렬하고, 중심 질문이 달라지는 항목만 체크포인트에 후속 반영한다.

### 9.2 시작 페이지 — 전체 데이터 취급의 지도

#### [P3-index](../../docs/parts/part-03/index.md) · P0

- **현재 진단·유지:** 원시 기록도 데이터셋이라는 구분과 보편적 필수 절차가 아니라는 단서는 좋다. 다만 목적이 `문제 표현 구조`에 집중되고 평균·기울기·변동성이 설명 전에 나열되어, 데이터의 범위·품질·표현을 왜 배우는지 덜 보인다.
- **수정 방향:** 1절의 여섯 축을 쉬운 질문으로 소개한다. 센서 기록 한 장면에서 `무엇을 기록했나 → 어떻게 묶나 → 무엇을 남기나 → 무엇을 알 수 있나`를 보여 주고 상세 지표 계산은 P3-1.1로 넘긴다. 데이터 모델링이라는 현재 제목과 이 책에서 쓰는 범위는 구분해 설명한다. 질문에 따라 원시 시계열·이미지·문서도 입력이 될 수 있다는 짧은 안내를 둔다.
- **완료 기준:** 독자가 Part 3을 “모델에 앞서 데이터를 이해하고 다루는 방법”으로 설명하고, 지표·품질·라벨을 배우는 이유를 각각 한 문장으로 말할 수 있다.

### 9.3 Chapter 1 — 현상에서 질문과 작업 순서로

근거 연결: 탐색과 문제 정의는 [S1](#s1)·[S2](#s2)·[S5](#s5), 기초 통계량은 [S3](#s3)·[S4](#s4). 아래 사례 배열은 이 책의 집필 판단이다.

#### [P3-1.1](../../docs/parts/part-03/chapter-01/section-01.md) · P0

- **현재 진단·유지:** 원시값에서 요약 행으로 바뀌는 사례와 계산 규칙은 있다. 그러나 평균·표준편차·후반 기울기·기준선 차이가 첫 표에 한꺼번에 나오고 질문별 필요성이 뒤따른다. DB 모델링과의 범위 구분, `no_flag`가 정상 확정은 아니라는 설명은 유지한다.
- **수정 방향:** 관측된 두 동작의 차이를 먼저 말하고 수준·흩어짐·끝부분 방향 질문을 나눈다. 5.1절의 작은 예처럼 지표 하나씩 의미와 계산을 보인 뒤 기존 요약 표로 합친다. 시간당 기울기와 기준선 차이에 단위를 붙인다. 네 구성 요소를 모든 데이터셋의 필수 열로 읽게 하지 않는다.
- **완료 기준:** 독자가 첫 요약 행의 각 값이 답하는 질문과 답하지 못하는 질문을 코드 없이 설명한다. 큰 표준편차나 음수 기울기만으로 고장을 확정하지 않는다.

#### [P3-1.2](../../docs/parts/part-03/chapter-01/section-02.md) · P1

- **현재 진단·유지:** 질문·샘플·표·특징·비교·출력의 지도와 되돌아갈 수 있다는 설명은 유용하다. 비슷한 단계 목록이 반복되며 어느 관찰 때문에 이전 결정을 바꾸는지는 추상적이다.
- **수정 방향:** P3-1.1의 한 사건을 단계마다 이어 쓴다. 예를 들어 후반 기록이 없어 기울기를 계산할 수 없으면 입력 범위나 수집 상태로 돌아가는 장면을 넣는다. 단계마다 생기는 작은 산출물을 표시하고 중복 목록을 줄인다. 탐색·정리는 계속 반복될 수 있으며 직관이 시행 횟수를 줄인다는 보장은 하지 않는다.
- **완료 기준:** 독자가 작업 순서를 재현하고, 정보가 부족할 때 어느 결정으로 돌아갈지 이유와 함께 고른다.

#### [P3-1.3](../../docs/parts/part-03/chapter-01/section-03.md) · P1

- **현재 진단·유지:** 모호한 질문을 대상·조건·출력으로 바꾸는 연습, 동작별 비교와 일별 집계의 구분은 유지한다. `이상`, `흔들림`이 관찰 가능한 어떤 차이를 뜻하는지 한 단계 더 풀 수 있다.
- **수정 방향:** `이상한가`를 `같은 운전 조건에서 동작 끝의 유량이 더 빠르게 내려가는가`로 구체화한다. 관찰 질문과 다음 7일 결과 예측 질문을 나란히 두되 모든 질문에 기준선이 필수라는 인상은 줄인다. 문서 한 건을 분류하는 짧은 전이 질문을 더한다.
- **완료 기준:** 대상, 시점, 필요한 기록, 원하는 산출물이 드러나는 질문을 독자가 직접 쓰고 현재 자료로 답할 수 없는 부분을 표시한다.

### 9.4 Chapter 2 — 저장된 기록의 의미 읽기

근거 연결: 데이터의 구조와 가정을 살피는 관점은 [S1](#s1), 문제에 맞는 입력·목표 정의는 [S6](#s6). 키·기록 단위의 구체적 편집은 원고 사례 분석에 따른다.

#### [P3-2.1](../../docs/parts/part-03/chapter-02/section-01.md) · P1

- **현재 진단·유지:** 원시 기록도 데이터셋이고 라벨이 없어도 분석할 수 있다는 설명은 중심 기준으로 유지한다. `min_points`로 집계 후보를 고르는 사례는 관측점 수와 동작 완전성을 같은 것으로 오해할 여지가 있다.
- **수정 방향:** 원시 기록 한 묶음과 요약 한 행을 `event_id`로 연결하고 남는 정보·사라지는 정보를 표시한다. 최소 점 수는 이 예제의 계산 가능 조건으로 한정하고 종료 기록·측정 간격과 별도로 읽는다. 추종 오차는 목표값과 관측값이 있는 예를 제시할 때만 남긴다.
- **완료 기준:** 독자가 요약값의 원래 기록을 찾아가고, 점 수 기준을 통과해도 동작 전체를 관찰했다고 단정할 수 없는 이유를 말한다.

#### [P3-2.2](../../docs/parts/part-03/chapter-02/section-02.md) · P0

- **현재 진단·유지:** 샘플·특징·기준선·출력의 역할 구분은 유지한다. 특징을 `계산해 남긴 값`으로만 정의하는 표와 원래 값을 사용할 수 있다는 설명이 맞지 않는다. 본문 표와 코드의 기준선 값도 서로 다른 예여서 연결이 끊긴다.
- **수정 방향:** 원래 관측값·범주도 특징 후보가 될 수 있게 표현을 맞춘다. `baseline_gap`이 어느 기울기에서 어느 기울기를 뺀 값인지 명시하고 `−0.32−(−0.05)=−0.27`을 현상·단위와 연결한다. 본문 표와 코드 자료를 통일하거나 별도 사례임을 명시한다. 임계값 변경은 관측 사실이 아닌 검토 규칙 변경으로 설명한다.
- **완료 기준:** 독자가 특징과 비교값, 규칙 출력의 역할을 나누고 표의 차이값 한 행 및 경계값 포함 여부를 재현한다.

#### [P3-2.3](../../docs/parts/part-03/chapter-02/section-03.md) · P1

- **현재 진단·유지:** 행·식별자·시간·비교 조건·출처의 다섯 질문은 좋은 점검 틀이다. 코드의 `has_time_order`는 사건 안에서 기록 순서가 엄격히 증가하는지 확인하지만, 정상 출력만으로는 중복 시각과 역순의 차이를 경험하기 어렵다.
- **수정 방향:** 기존 표 일부로 중복 식별자/시각, 역순, 누락의 작은 대조를 만든다. 정렬하면 해결되는 경우와 동일 시각의 충돌값처럼 원문 확인이 필요한 경우를 구분한다. 관측점 수를 완전성 인증으로 읽지 않게 하고 출처·수정 이력을 보존한다.
- **완료 기준:** 독자가 새 표의 다섯 줄 메모를 작성하고 이상 기록 하나에 대해 정렬·보류·원문 확인 중 다음 행동을 고른다.

### 9.5 Chapter 3 — 질문에 맞는 데이터셋 설계

근거 연결: 문제·목표와 입력 구조는 [S5](#s5)·[S6](#s6). 라벨 의미의 안정성은 열 존재만으로 검증되지 않으며 뒤의 P3-9.4~9.6으로 연결한다.

#### [P3-3.1](../../docs/parts/part-03/chapter-03/section-01.md) · P0

- **현재 진단·유지:** 원천 기록에서 바로 사건 분류를 시작할 수 없는 이유는 유지한다. `아직 데이터셋이 아니다`로 읽히는 표현은 P3-2.1과 충돌한다. 코드의 `stable_label_meaning_known = same_unit_as_sample`은 단위 일치만으로 라벨 의미까지 확인된 것처럼 만든다.
- **수정 방향:** `현재 지도학습 질문에 필요한 입력·결과 정의가 미완성`으로 한정한다. 라벨 열 존재, 사건 단위 결합, 판정 기준 확인을 별도 항목으로 나누고 모르는 항목은 미확인으로 남긴다. `flow`도 미래값 예측에서는 결과가 될 수 있으므로 현재 사건 분류 사례에 한정해 설명한다.
- **완료 기준:** 독자가 데이터셋의 존재와 특정 학습 문제의 준비 상태를 구분한다. 라벨 단위가 맞아도 판정 기준의 일관성은 별도로 확인해야 함을 설명한다.

#### [P3-3.2](../../docs/parts/part-03/chapter-03/section-02.md) · P1

- **현재 진단·유지:** 질문에 따라 동작·구간 표가 달라지는 대비는 유지한다. 여러 개념표에 비해 같은 기록이 실제로 어떻게 두 행 구조로 바뀌는지 약하고 원천데이터/데이터셋 구분도 앞 절과 정렬이 필요하다.
- **수정 방향:** P3-3.1의 일부 기록으로 동작 비교용 행과 최근 구간 비교용 행을 각각 만든다. 각 열의 원시 근거와 사라진 정보를 표시한다. `불안정`을 묻는데 평균·최댓값만 남기는 경우에는 그 값으로 확인하지 못하는 면을 밝힌다. 원시 시퀀스를 유지하는 선택도 인정한다.
- **완료 기준:** 같은 원천 기록에서 두 질문에 맞는 표 초안을 만들고, 두 표의 한 행과 필요한 열이 다른 이유를 설명한다.

#### [P3-3.3](../../docs/parts/part-03/chapter-03/section-03.md) · P1

- **현재 진단·유지:** A의 `2.4−2.8=−0.4`, B의 기준선 누락을 0으로 채우지 않는 연습은 유지한다. 동작 한 건의 첫 표에 `repeatability_score`·우선순위 점수가 먼저 나와 설계 범위를 넓힌다.
- **수정 방향:** 식별·관측·파생·비교·결과 후보를 빈 서식에서 실제 한 행으로 채운다. 단위와 아직 모르는 항목을 함께 적는다. 여러 사건을 모아야 하는 반복 점수는 Chapter 8로 넘기거나 계산 집합을 밝힌다. 첫 표에 필요한 열만 남긴다.
- **완료 기준:** 독자가 원시값과 계산값을 구분해 초안 한 행을 만들고 기준선이 없는 행을 미확인으로 남긴다.

### 9.6 Chapter 4 — 샘플·집계·평가 대상의 구분

근거 연결: 정확도와 분모는 [S7](#s7), 평가 정보 분리는 [S9](#s9). 구체적인 분할은 새 사건·새 개체·미래 중 무엇을 평가할지에 맞춰야 하며 세부 설계는 P3-9.13과 Part 4로 넘긴다.

#### [P3-4.1](../../docs/parts/part-03/chapter-04/section-01.md) · P0

- **현재 진단·유지:** 질문별 샘플 선택과 자동 최적화가 아니라 예시 규칙이라는 설명은 유지한다. 입력 설명은 일부 이벤트가 불완전하거나 라벨이 없다고 하지만, 현재 측정 CSV의 12개 이벤트는 모두 3행이고 대응 검토 결과가 있다. 기본 출력에서 그 차이를 볼 수 없다.
- **수정 방향:** 기본 자료의 실제 상태에 맞게 서술한다. 필요하면 기존 사례 하나의 끝 기록이나 검토 결과를 제외한 별도 조작으로 차이를 보여 준다. `expected_rows_per_event`는 점 수 기준이며 종료 경계 확인과 다름을 설명한다. 질문·경계·특징·결과의 대응을 손으로 읽는 한 사건을 먼저 둔다.
- **완료 기준:** 본문 주장과 CSV·출력이 일치한다. 독자가 점 수 부족과 라벨 미확인을 별도 상태로 표시하고 샘플 경계를 정한다.

#### [P3-4.2](../../docs/parts/part-03/chapter-04/section-02.md) · P0

- **현재 진단·유지:** 동일 사건이 학습·평가에 겹치는 표는 유용하다. 이 절이 정확도의 첫 등장이다. `event split` 코드는 사건별로 분리하되 시점 행별 예측의 정확도를 계산하므로 사건 단위 점수와 구분해야 한다. 안내한 `features` 변수는 코드에 없다.
- **수정 방향:** 관측 행, 분석 샘플, 분할 그룹, 평가 건수를 나눈다. 정확도는 맞힌 평가 행/전체 평가 행으로 먼저 계산하고, 사건별 평가를 하려면 별도 집계 규칙이 필요하다고 설명한다. `late_drop = 앞값−뒷값`은 하강 크기이고 앞의 음수 기울기와 부호·단위가 다름을 밝힌다. 코드 조작 안내를 실제 변수와 맞춘다.
- **완료 기준:** 독자가 1.0과 0.5의 분모를 알고 `새 사건으로 나누었다`와 `사건당 한 번 채점했다`를 구분한다. 점수 하락을 모든 자료에서 보장하지 않는다.

#### [P3-4.3](../../docs/parts/part-03/chapter-04/section-03.md) · P1

- **현재 진단·유지:** 행은 저장 형식, 샘플은 질문의 단위이며 구간도 샘플이 될 수 있다는 설명과 9행·3사건·2구간 출력은 유지한다. `late_drop_rate`가 예시 설명 없이 다시 나오고 평균을 두 번 내는 대상이 흐려질 수 있다.
- **수정 방향:** 같은 작은 기록을 세 표로 연속 표시하고 각 표의 행 단위·식별자·집계 대상을 적는다. A의 평균 한 번과 최근 구간 평균 한 번을 검산한다. 상세 가중치 차이는 P3-5.1에 맡기고 여기서는 무엇을 세는지에 집중한다.
- **완료 기준:** 독자가 각 출력의 한 행을 원래 사건에 연결하고 최근 구간 자체가 샘플이 되는 질문을 만든다.

#### [P3-4.4](../../docs/parts/part-03/chapter-04/section-04.md) · P1

- **현재 진단·유지:** 반복 라벨은 무조건 오류가 아니라는 단서는 유지한다. 다만 `더 자주 있는 원인은 샘플 단위`라는 빈도 주장은 근거가 없고, 출력은 최대 반복 수 기준의 yes/no여서 임계값 1→3 조작의 효과를 바로 확인하기 어렵다.
- **수정 방향:** 진단 신호와 확정 오류를 구분한다. 18개 행의 양성 합과 양성 사건 1건을 대조한다. 임계값을 바꿀 때 실제 경고 대상 사건 목록·건수가 변하는지 보여 주거나 변화 없는 이유를 설명한다. 데이터 모델 오류와 설비 이상을 구분한다.
- **완료 기준:** 독자가 중복 저장 자체와 잘못된 중복 집계를 구분하고, 경고에서 원래 사건의 단위 점검으로 돌아간다.

#### [P3-4.5](../../docs/parts/part-03/chapter-04/section-05.md) · P0

- **현재 진단·유지:** 대표성은 균등 건수가 아니며 0건 조건·교차 조건도 봐야 한다는 설명은 유지한다. `coverage summary`의 조건 종류·부족 조건 수와 모델 정확도는 서로 다른 집계인데 원래 건수에서 읽는 과정이 부족하다.
- **수정 방향:** 대상 운영 분포와 수집 분포를 나란히 놓고 `minimum_count=9`를 설명용 관찰 기준으로 한정한다. `shift`의 26건/10건에서 부족 조건 0개가 나오는 과정을 먼저 보인다. 모델 예를 유지하면 정확도 5/12와 9/12, 조건별 전체 건수와 오류 수를 함께 읽는다. 규칙으로 만든 `needs_review`는 실제 고장 정답이 아님을 앞에서 밝힌다.
- **완료 기준:** 독자가 건수 기준 통과와 대표성 확보를 구분하고, 전체 정확도만으로 알 수 없는 조건 공백을 찾는다.

### 9.8 Chapter 6 — 특징의 의미와 표현 선택

근거 연결: 평균·흩어짐은 [S3](#s3)·[S4](#s4), 입력·목표의 연결은 [S6](#s6), 학습 자료로 변환 기준을 정하는 원칙은 [S9](#s9). 토큰 경계·가상 점수는 표준 통계량이 아닌 사례별 규칙이다.

#### [P3-6.1](../../docs/parts/part-03/chapter-06/section-01.md) · P0

- **현재 진단·유지:** A/B의 평균 2.2, 차이 0.8/0.2, 기울기 0.4/0.1은 좋은 대조다. 구간 평균 사이의 변동과 구간 안 변동을 구분하는 설명이 뒤에 있어 앞의 `안정성` 해석을 먼저 오해할 수 있다.
- **수정 방향:** `0.8/2`의 2는 구간 인덱스 간격이며 초가 아님을 계산 직전에 밝힌다. 표준편차의 대상도 구간 평균 세 개라고 먼저 적는다. 뒤의 2·2 대 0·4 반례를 앞에 연결한다. 두 테스트 사건의 정확도 차이는 입력 정보 손실을 보여 주는 가상 실험이며 특징 추가의 일반적 우월성으로 확대하지 않는다.
- **완료 기준:** 독자가 차이·기울기·표준편차의 대상과 단위를 각각 쓰고, 구간 평균의 표준편차가 0이어도 구간 안 변동이 남을 수 있음을 설명한다.

#### [P3-6.2](../../docs/parts/part-03/chapter-06/section-02.md) · P0

- **현재 진단·유지:** 경계값 두 설정으로 같은 기울기가 다른 토큰이 되는 예는 유지한다. 원시 기울기의 단위와 약함/강함의 기준이 코드보다 먼저 충분히 설명되지 않는다. 기호화만으로 일정 길이가 보장되는 것처럼 읽히는 문장도 있다.
- **수정 방향:** 구간 기울기 한 개의 계산과 단위를 먼저 고정한다. 다섯 토큰의 구간 조건과 경계값 포함 여부를 표로 쓰고 0.92·0.31·0.05·−0.42·−1.00을 직접 분류한다. `FLAT`은 정확한 0이 아닌 규칙상 범위다. 토큰화와 구간 수 맞추기는 별도 선택이며 반복 길이도 실제 시간과 다를 수 있음을 설명한다.
- **완료 기준:** 독자가 토큰 하나를 재현하고 경계 변경 때 바뀌는 사례를 찾는다. 같은 토큰이 된 서로 다른 수치에서 무엇이 사라졌는지 말한다.

#### [P3-6.3](../../docs/parts/part-03/chapter-06/section-03.md) · P0

- **현재 진단·유지:** `모든 모델이 내부 표현을 학습하는 것은 아니며 수작업 특징은 필수가 아니다`라는 단서는 맞는 방향이다. 반면 앞뒤의 `앞뒤 단계`, `사람은 먼저 특징과 중간 표현을 만든다`는 서술은 필수 직렬 과정처럼 읽힌다.
- **수정 방향:** 필수인 문제·입력 경계와 선택인 수작업 요약을 분리한다. 동일 원시값을 수작업 특징으로 주는 경로와 순서를 유지해 모델이 표현을 학습하는 경로를 나란히 둔다. 이미지 한 장/문서 한 건의 입력 경계도 짧게 대응시킨다. 내부 표현의 상세 학습 원리는 뒤 Part로 넘긴다.
- **완료 기준:** 독자가 두 경로에서 사람이 정하는 것과 모델이 학습하는 것을 구분하며, 수작업 특징→토큰→딥러닝을 필수 순서로 답하지 않는다.

#### [P3-6.4](../../docs/parts/part-03/chapter-06/section-04.md) · P1

- **현재 진단·유지:** 열 역할은 배타적이지 않고 예측 시점 가용성이 필요하다는 후반 사례는 유지한다. 앞 표의 `event_id/captured_at는 아니오`, `평균은 예`가 고정 판정처럼 읽히고 `review_score=87`은 뜻이 없다.
- **수정 방향:** 후반의 목적·가용시점 조건을 첫 표 앞으로 옮긴다. `비교에 사용/입력 후보/그때 사용 가능`을 별도 표시하고 2.40−3.05=−0.65를 직접 잇는다. 87점은 정의 가능한 결과나 실제 검토 여부로 대체한다.
- **완료 기준:** 같은 차이 열이 비교값이면서 입력 후보일 수 있음을 설명하고, 미래 자료를 섞은 기준선으로 만든 경우를 제외한다.

#### [P3-6.5](../../docs/parts/part-03/chapter-06/section-05.md) · P1

- **현재 진단·유지:** 단위 표와 기준선 차이, 표준화는 향상을 보장하지 않는다는 단서는 유지한다. 단위가 숫자 첫 등장보다 늦고 거리 기반 모델의 이웃 변경을 이해하려면 추가 계산 연결이 필요하다.
- **수정 방향:** 첫 표부터 초·kPa·L/min·L/min/s를 붙인다. 0.18−0.03=0.15의 의미를 같은 열 안에서 읽고, 다른 단위의 차이끼리 크기를 비교하지 않는다. k-NN 예를 유지하면 가까운 사례를 고르는 뜻과 한 열의 눈금 변환을 먼저 보여 준다. 예측 0→1 변경은 개선 증거가 아니다.
- **완료 기준:** 독자가 단위 변환과 통계적 표준화의 목적을 구분하고 새 샘플에 기존 학습 변환을 적용하는 이유를 말한다.

#### [P3-6.6](../../docs/parts/part-03/chapter-06/section-06.md) · P1

- **현재 진단·유지:** 41 mL/s→2.46 L/min 변환과 운영 규칙만 바뀌면 물리 특징은 같을 수 있다는 설명은 유지한다. 코드의 정의 필드 일치 그룹을 물리적으로 비교 가능한 그룹과 곧바로 같은 것으로 읽을 여지가 있다.
- **수정 방향:** `문자열 정의가 같음`, `단위 변환 후 비교 가능`, `센서·구간 차이로 추가 확인 필요`를 나눈다. 운영 판정 버전은 측정 정의와 별도 관리할 수 있음을 표에 반영한다. 원래 값·단위·변환 규칙을 보존한다.
- **완료 기준:** 독자가 단위 통일만으로 회복되는 비교와 별도 보정·정의 확인이 필요한 비교를 나누고 필드를 줄여 그룹 수를 합치는 것만으로 문제가 해결되지 않음을 설명한다.

### 9.10 Chapter 8 — 증거와 운영 판단의 경계

근거 연결: 탐색의 역할은 [S1](#s1), 지표·목표 구분은 [S6](#s6), 평가 집합은 [S7](#s7)·[S9](#s9), 점수의 확률 해석은 [S11](#s11). 선택적 라벨·개입의 세부 일반화는 각 원고의 기존 전문 출처를 실제 개정 때 재검토한다.

#### [P3-8.1](../../docs/parts/part-03/chapter-08/section-01.md) · P0

- **현재 진단·유지:** 반복 비율과 시간상 연속은 다르고 20건이 보편적 충분 조건이 아니라는 단서는 유지한다. 그 뒤에는 다시 `충분하므로 강한 경고`로 읽히는 서술과 효과 보장이 나온다.

#### [P3-8.2](../../docs/parts/part-03/chapter-08/section-02.md) · P1

- **현재 진단·유지:** 관찰과 원인 주장의 구분, 상자그림은 분산 자체가 아니라는 설명은 유지한다. 실제 그림을 읽는 사례 없이 그래프 종류를 열거하고 체크리스트에서는 중앙값·사분위 범위 읽기를 요구한다.

#### [P3-8.3](../../docs/parts/part-03/chapter-08/section-03.md) · P1

- **현재 진단·유지:** 관측·불확실성·다음 행동의 문장 골격과 소표본이어도 필요한 조치는 할 수 있다는 설명은 유지한다. 예문 다수가 실제 숫자 없이 어휘 사다리로 남는다.

#### [P3-8.5](../../docs/parts/part-03/chapter-08/section-05.md) · P0

#### [P3-8.6](../../docs/parts/part-03/chapter-08/section-06.md) · P0

#### [P3-8.7](../../docs/parts/part-03/chapter-08/section-07.md) · P1

- **현재 진단·유지:** 검토 후 조치가 결과를 바꿀 수 있다는 A·B·C 표는 적절하다. 조치가 실패를 줄였을 가능성과 실제 효과가 입증되었다는 주장을 더 분명히 나눌 수 있다.
