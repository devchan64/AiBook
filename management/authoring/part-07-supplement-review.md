# Part 7 내용 개선 및 Section 보충 검토

작성일: 2026-07-23

## 목적

이 메모는 Part 7의 예제와 연습을 점검해, 실제 모델, 실제 라이브러리, 벡터 데이터베이스를 붙이면 학습밀도가 올라가는 위치와 보류할 위치를 정리한다.

검토 기준은 다음 세 가지다.

- Section의 중심 질문이 실제 입력, 모델 출력, 후보 순위, 오류 샘플 변화로 더 잘 드러나는가
- 새 라이브러리 사용이 설치, API, 제품 사용법보다 학습 목표를 더 선명하게 만드는가
- 기존 수작업 예제의 교육적 역할을 없애지 않고 프로젝트 실행 감각을 보강하는가

## 다음 보충 후보

1. P7-3.1 이미지 분류 입력 기록
   - 보충 방향: 현재 NumPy softmax 뒤에 `LogisticRegression` 비교를 짧게 추가한다.
   - 목표: 같은 8x8 펼친 입력을 실제 classifier에 넣어도 `입력 shape`, `오류 샘플`, `추가 검토 샘플` 기록 축이 유지되는지 확인한다.
   - 주의: CNN, PyTorch, TensorFlow까지 확장하지 않는다.

2. P7-4.2 token coverage 검토
   - 보충 방향: 실제 모델 예제가 아니라, P7-4.1 보충 예제와 연결되는 짧은 해설을 추가한다.
   - 목표: TF-IDF 같은 라이브러리를 써도 OOV와 coverage 검토가 사라지는 것이 아니라, 다른 형태의 입력 해석으로 남는다는 점을 설명한다.

3. P7-5.1 검색 근거 흐름
   - 보충 방향: ChromaDB를 반복하지 않고, 현재 수작업 점수표의 결과 해석을 P7-5.4의 vector DB 설정 기록과 연결한다.
   - 목표: 검색 후보 기록과 벡터 DB 검색 설정 기록의 역할 분담을 분명히 한다.
