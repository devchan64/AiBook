# P6-5.1 근거 검토 메모

## 이 절의 역할

- Part 6 Module 3의 첫 절로서 RAG 프로젝트의 최소 구조를 만든다.
- 검색과 답변을 분리해 기록하는 프로젝트 문서 관점을 제시한다.

## 핵심 주장

- RAG는 검색과 생성의 결합 구조다.
- 답변보다 먼저 검색 근거를 기록해야 한다.
- 작은 예제에서도 doc_id와 retrieved text를 남길 수 있다.

## 반영한 근거

- OpenAI Retrieval 문서: semantic search, vector store, retrieval + model 결합 설명

## 집필 메모

- 실제 API 호출 없이도 구조를 이해할 수 있도록 자체 문서 조각 예시를 사용했다.
