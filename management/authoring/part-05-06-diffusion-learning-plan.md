## 기존 원고 상태와 통합 이력

2026-08-03에는 `stable-diffusion-section-proposal.md`에서 Stable Diffusion을 사례로 삼아 P5-15.4를 신설하는 계획을 관리했다. 그 결과 현재 P5-15.4에는 텍스트 조건, 잠재 노이즈, 반복 복원, 이미지 변환, U-Net, scheduler, VAE의 최소 구성이 반영되어 있다.

그러나 이 설명은 특정 구현 사례에 무게가 실려 있고, 정방향 확산·노이즈 예측 학습·역방향 생성이라는 알고리즘의 전체 흐름과 Transformer 기반 복원 네트워크의 위치를 충분히 독립적으로 다루지 않는다. 이 문서는 그 기존 제안을 흡수하고 다음 기준으로 대체한다.

- 설명의 주어는 Stable Diffusion이 아니라 디퓨전 모델이다.
- Stable Diffusion, latent diffusion, U-Net, DiT는 일반 알고리즘과 구조 선택을 보여 주는 사례다.
- 디퓨전 알고리즘 학습과 실제 모델 테스트는 Part 5·6에서 끝낸다.
- Part 7의 프로젝트 원고·목차·자산은 이 계획의 범위 밖이다.

기존 `stable-diffusion-section-proposal.md`는 이 통합으로 제거한다. 과거 문서에 있던 P5-15.4의 반영 이력, 설명 경계, 자료 기준은 아래의 반영 구조·범위 밖 항목·근거 자료에서 계속 관리한다.

## 학습 완료 기준

독자는 디퓨전 학습 뒤에 다음을 할 수 있어야 한다.

1. 정방향 확산, 학습, 역방향 생성을 서로 다른 과정으로 설명한다.
2. 시간 단계 `t`, 원본 상태 `x_0`, 노이즈 `epsilon`, 노이즈 섞인 상태 `x_t`가 무엇을 뜻하는지 설명한다.
3. 모델이 완성 이미지를 직접 예측하는 것이 아니라, 주어진 `x_t`와 `t`에서 노이즈 또는 동등한 복원 방향을 예측하도록 학습된다는 점을 설명한다.
4. scheduler가 학습된 모델 자체가 아니라, 생성 때 다음 상태로 이동하는 규칙이라는 점을 구분한다.
5. autoencoder의 재구성과 VAE의 latent 분포 학습을 구분하고, latent diffusion에서 VAE, 조건 인코더, 복원 네트워크, decoder의 역할을 구분한다.
6. self-attention과 cross-attention을 각각 이미지 상태 내부 관계와 조건-이미지 연결의 관점에서 구분한다.
7. U-Net 기반과 Transformer/DiT 기반 복원 네트워크가 모두 가능하다는 점을 설명한다.
8. 실제 모델 테스트에서 seed, steps, scheduler, guidance, 조건 입력을 한 번에 하나씩 바꾸고 결과 차이를 기록·해석한다.

## 핵심 설명 원칙

### 알고리즘을 먼저, 개별 모델은 사례로만

디퓨전 모델은 특정 이미지 생성 제품이나 하나의 구현과 동일시하지 않는다. Part 5는 먼저 `데이터에 노이즈를 더하는 과정 -> 노이즈 예측 학습 -> 노이즈에서 데이터를 향한 반복 생성`을 설명한다. latent diffusion, Stable Diffusion, DiT 같은 이름은 이 일반 구조가 어떤 구현 선택으로 나타나는지 보여 주는 사례로만 사용한다.

입문용 수식은 다음 한 식으로 시작한다.

\[
x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon
\]

수식 암기가 목표는 아니다. 원본 `x_0`와 무작위 노이즈 `epsilon`를 시간 단계 `t`에 따라 섞어 `x_t`를 만들고, 학습 중에는 모델이 그때 섞인 노이즈를 예측해 오차를 줄인다는 관계를 읽게 한다. 이어서 생성 때는 무작위 노이즈에서 출발해 예측을 이용하여 여러 단계로 상태를 갱신한다는 점을 연결한다.

### attention은 하나의 역할로 뭉뚱그리지 않는다

- self-attention: 이미지 잠재 표현의 위치·패치 사이 관계를 함께 반영하는 구조로 소개한다.
- cross-attention: 텍스트 같은 조건 표현과 현재 이미지 잠재 표현을 연결하는 구조로 소개한다.
- 복원 네트워크: U-Net은 대표 구조이지만 필수 구조가 아니다. Transformer/DiT도 잠재 패치와 조건을 처리하며 노이즈 또는 복원 방향을 예측할 수 있다.

### 실제 모델 테스트는 학습 검증이다

실제 모델 테스트의 목표는 멋진 이미지를 고르거나 프로젝트 산출물을 만드는 일이 아니다. 같은 조건에서 값 하나를 바꾸어 알고리즘 설명이 출력과 실행 기록에서 어떻게 드러나는지 확인하는 일이다.

## 반영 구조

### Part 5: 디퓨전 알고리즘과 구조

#### P5-15.4 디퓨전 모델은 노이즈를 어떻게 학습하고 복원하는가

현재 P5-15.4의 내용을 이 Section의 기초 알고리즘 중심으로 재구성한다.

| 전개 | 중심 질문 | 학습 산출물 |
| --- | --- | --- |
| 정방향 확산 | 원본 데이터는 어떻게 노이즈 상태가 되는가? | 같은 작은 이미지 또는 격자의 `x_0 -> x_t` 관찰 |
| 학습 입력과 정답 | 모델은 무엇을 보고 무엇을 맞히는가? | `x_t`, `t`, 실제 노이즈, 예측 노이즈를 구분한 표 |
| 손실과 update | 왜 노이즈 예측 오차가 학습 신호가 되는가? | MSE 손실이 Part 5의 loss·gradient·update와 이어지는 설명 |
| 역방향 생성 | 무작위 노이즈가 어떻게 이미지 쪽으로 이동하는가? | 한 단계 갱신과 반복 복원 의사코드 |
| scheduler | 반복 규칙은 무엇을 바꾸는가? | 학습된 가중치와 생성 경로 규칙의 구분 |

포함할 최소 실험은 작은 합성 이미지 또는 경량 사전학습 모델에서 시간 단계별 노이즈 상태를 관찰하는 것이다. 이 실험은 모델을 새로 훈련하거나 품질을 겨루지 않으며, `노이즈를 섞는 과정`과 `복원 단계`가 실제 상태 변화로 보이게 한다.

#### P5-15.5 디퓨전 모델에서 attention과 Transformer는 무엇을 맡는가

새 Section으로 추가한다. P5-15.4의 알고리즘을 조건부 이미지 생성 구조에 연결하되, 특정 제품의 사용법으로 흐르지 않게 한다. latent diffusion은 이 구조를 계산 효율을 위해 잠재 공간에서 구현하는 대표 사례로 둔다.

| 구성요소 | 먼저 설명할 역할 | 혼동하지 않을 경계 |
| --- | --- | --- |
| 조건 인코더 | 텍스트·참조 조건을 계산 가능한 표현으로 바꾼다 | 프롬프트를 픽셀 배치표로 바꾸는 장치가 아니다 |
| U-Net 또는 DiT | 현재 상태와 시간·조건에서 노이즈 또는 복원 방향을 예측한다 | U-Net만이 디퓨전의 필수 구조는 아니다 |
| self-attention | 이미지 잠재 위치 사이의 전역 관계를 반영할 수 있다 | 텍스트 조건 연결과 같은 말이 아니다 |
| cross-attention | 조건 표현과 현재 이미지 상태를 연결할 수 있다 | 이미지 내부 관계만 처리하는 self-attention과 구분한다 |

학습 산출물은 `조건 -> 노이즈 상태 -> 복원 네트워크의 반복 예측 -> 생성 결과`의 일반 도식과 U-Net 기반·DiT 기반 구조 비교표다.

#### P5-15.6 VAE는 이미지를 어떤 잠재 표현으로 바꾸는가

VAE를 latent diffusion의 부품 목록으로만 남기지 않고, autoencoder의 재구성과 VAE의 분포 학습을 설명하는 별도 Section으로 둔다.

| 전개 | 중심 질문 | 학습 산출물 |
| --- | --- | --- |
| autoencoder | 입력을 다시 만들 수 있는 latent 표현은 어떻게 배우는가 | encoder·latent·decoder·재구성 손실 표 |
| VAE | 왜 좌표 하나가 아니라 `mu`, `sigma` 분포를 만드는가 | 재매개변수화 식과 값 역할 표 |
| KL divergence | 왜 latent 분포를 기준 분포와 연결하는가 | 재구성 손실과 KL 손실의 역할 비교 |
| latent diffusion | VAE와 디퓨전 복원기는 어디서 역할이 갈리는가 | 이미지 -> VAE -> latent diffusion -> VAE -> 이미지 도식 |

### Part 6: 생성 방식 비교와 실제 모델 테스트

#### P6-1.4 생성은 하나의 반복 방식이 아니다

P6의 LLM 중심축을 유지하면서 Module 1 끝에 짧은 비교 Section을 추가한다. 목적은 Part 5의 디퓨전 설명을 반복하는 것이 아니라, 텍스트 생성의 설명을 모든 생성형 AI에 일반화하는 오해를 막는 데 있다.

| 관점 | 자기회귀 LLM | 이미지 디퓨전 |
| --- | --- | --- |
| 반복 단위 | 다음 토큰 하나 | 전체 잠재 상태의 한 복원 단계 |
| 출발 상태 | 앞에서 생성된 토큰 문맥 | 무작위 초기 노이즈 |
