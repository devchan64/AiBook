# P7-5.11 100스텝 LoRA 품질 평가

**평가 설계 철회:** 사용자 지적에 따라 얼굴 참조 비교를 정체성 LoRA 평가로 사용하는 설계를 중단했다. 아래는 이전 실행 기록이다. 새 평가는 얼굴 없는 단색 캔버스와 3개 조건으로 진행하며 `.tmp/p7-5-11/identity-evaluation-run100/`에 저장한다. 이전 결과는 성공 근거로 채택하지 않는다.

평가일: 2026-09-13. 학습 40개, 평가 4개를 분리한 100스텝 체크포인트를 평가한다. 생성 파일의 존재나 학습 손실만으로 정체성 학습 성공을 판정하지 않는다.

## 비교 조건

- 체크포인트: `.tmp/p7-5-11/lora-v2-run100-retry1/checkpoints/mira_identity.safetensors`
- SHA-256: `d76b96198d210ef27a9d97955315e4dfec8f688044d9a832520281a10698d0f3`
- Qwen-Image-Edit-2511 BF16, 512×512, 20스텝, true CFG 4.0, 추가 가속 LoRA 없음.
- 장면별 동일 참조·프롬프트·시드. LoRA 비활성화와 강도 1.0 활성화를 비교한다. 병합하지 않고 같은 파이프라인에서 전환한다.
- 강가(02), 중정 보행(04), 박물관(05), 발코니(06)의 평가 전용 장면 캡션을 사용한다. 기준 참조는 원고 5.2의 해당 방향 얼굴이다.
- 캐릭터 토큰 `mira_person`은 양쪽 모두 동일하게 사용한다. 눈동자색·피부색·얼굴 비율을 다시 지정하는 프롬프트는 넣지 않는다.

## 판정 기준과 한계

각 쌍에서 기준 얼굴의 눈매·코·입·턱, 홍채색, 피부색, 가르마·단발 끝을 비교한다. 조명에 따른 색조와 고유색 변화를 구분하고, 새 의상·행동·배경 반영 및 해부학적 오류도 함께 본다. 전신의 작은 얼굴은 세밀한 눈동자색 판정에 사용하지 않는다.

합성 평가 이미지를 픽셀 정답으로 간주하지 않는다. 참조를 받는 편집 모델 자체도 인물을 유지할 수 있으므로 LoRA가 만든 추가 개선을 미적용 결과와 비교해야 한다. 이 평가는 참조가 있는 장면 편집의 4개 단일 시드 사례에 한정한다. 무참조 생성 성능, 모든 방향의 일반화, 통계적 성공률을 뜻하지 않는다.
