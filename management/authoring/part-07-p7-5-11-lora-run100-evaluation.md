# P7-5.11 얼굴 참조 평가의 제외 범위

확인일: 2026-09-13. 얼굴 참조를 평가 입력에 넣었던 설계는 얼굴 없이 Mira의 정체성을 생성한다는 목표의 판정 근거에서 제외한다. 참조 자체의 인물 보존과 LoRA 학습 효과를 혼동할 수 있기 때문이다. 이 설계의 실행 안내와 미완료 작업 문구는 폐기한다.

원본 실행 폴더 `.tmp/p7-5-11/evaluation-run100-v1/`는 실행 증거이며 정체성 성공 근거로 사용하지 않는다. 현재 평가는 얼굴 없는 단색 입력·동일 프롬프트·동일 시드를 사용한다. 기준 얼굴은 독자의 시각 대조에만 사용한다.

이 실험과 5.11 원고는 폐기했다. 현재 실습은 [5.10 BFS LoRA](../../docs/parts/part-07/chapter-05/section-10.md)에서 확인한다.
