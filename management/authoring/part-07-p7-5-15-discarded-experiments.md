# P7-5.15 실험 폐기 기록

2026-09-19 사용자 지시로 다음 두 실험 묶음을 실패로 폐기하고 자산 폴더 전체를 삭제했다. 재생성·후속 입력·기준군으로 사용하지 않는다.

모델 가중치는 삭제 대상이 아니므로 유지했다. 사용자가 별도로 지정하지 않은 `2026-09-19-stableanimator-framing-v2/`의 준비 포즈·검수 자료는 보존하되, 원 모션·참조·실행 기준이 삭제되어 `blocked_source_discarded` 상태로 전환했다. 새 기준 입력과 새 계획 없이는 실행할 수 없다. 연속 포즈 영상에서 발 교대 우려가 관측되지 않았다는 사용자 평가와 이번 실험 묶음의 폐기 결정은 별개 기록이다.

## StableAnimator v2 폐기

사용자 지시로 `2026-09-19-stableanimator-framing-v2/` 전체 74개 파일을 삭제했다. 영상 추론 전 준비 자료였으며, 보존·실행 불가라는 위 상태를 폐기로 갱신한다. 새 전진 실험은 MoMask v4를 입력으로 별도 구성한다.

## StableAnimator v3 폐기

사용자 지시로 `2026-09-19-stableanimator-travel-v3/` 전체 82개 파일을 삭제했다. 가로 이동은 전달됐으나 캐릭터의 머리·재킷 변화와 초기 잔상으로 폐기했다. 새 v4는 기존 sec-03 정면/측면 참조를 첫 입력 포즈 크기·위치에 맞춘 뒤 비교한다. 과거 출력은 재사용하지 않는다.

## StableAnimator v4 실패 및 폐기

2026-09-19 사용자 지시로 `2026-09-19-stableanimator-reference-v4/` 전체 132개 파일을 삭제했다. 정면·측면 각 32프레임과 입력 사본·비교 영상·검수판·실행 코드·JSON을 포함한다. 기존 v1~v3 폐기를 유지하며 활성 StableAnimator 결과는 남기지 않는다.

- 입력: MoMask v4 `travel-10107`의 28~59번, 고정 측면 카메라, 시작 포즈에 크기·위치를 근사 정렬한 정면/측면 참조.
- 설정: 512×512, 각 32프레임, 25스텝, CFG 3, 시드 23123134. 정면/측면 약 267.15/262.01초, 최대 PyTorch 할당 약 5.48GiB.
- 실패 사유: 가로 이동·전신은 유지됐으나 머리 길이·소매가 바뀌었고 팔 겹침 구간에서 손·전완 윤곽과 신체 부위의 대응이 불안정했다. 측면 참조의 초반 개선은 전체 캐릭터 보존 성공으로 채택하지 않는다.
- 판단 범위: 얼굴 검출·유효 임베딩을 확인한 조건에서도 실패했다. 2D 포즈의 깊이·가림 정보 부족은 원인 후보이며, 정확한 좌우 팔 교환과 모델 자체의 생성 오류를 분리 검증하지 않았다. StableAnimator 전체의 불가능성으로 일반화하지 않는다.
- 보존: MoMask v4 원 모션·산출물, sec-03 공용 참조 원본, 다운로드한 모델 가중치. 폐기 조건은 재생성·재사용 대상에서 제외한다.

위 수치와 관찰은 삭제 전 이력이며 삭제된 폴더는 활성 자산 경로가 아니다.
