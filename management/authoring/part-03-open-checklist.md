# Part 3 미반영 체크리스트

이 문서는 새로 추가된 데이터 모델링 Part에서 아직 남아 있는 후속 항목만 모은 체크리스트입니다.

## 품질 상태 메모

- Part 3은 문제-데이터-표현-비교-해석 경계를 세우는 구조가 비교적 안정적인 Part입니다.
- 현재 남은 과제는 큰 재배치보다 대표 예시와 비교 장면의 밀도를 높여 `데이터 모델링 판단`이 더 직접적으로 보이게 하는 일입니다.
- 특히 샘플 단위, 원시 로그와 요약 표 구분, 기준선 비교, 경고 후보 해석이 실제 표와 사례로 더 손에 잡혀야 합니다.

## 체크리스트

- [ ] Part 3 시작 페이지 원고를 더미에서 본문 초안으로 확장한다.
- [ ] Chapter 2와 Chapter 3 핵심 절을 실제 예시와 표까지 포함해 보강한다.
- [ ] 기준선 비교와 경고 후보 해석 절의 예시를 일반화된 자동화 장비 사례로 정리한다.
- [ ] Part 4와의 연결 문단을 새 번호 체계 기준으로 다시 점검한다.

## 다음 유지 점검

- 샘플 단위와 표 구조 설명이 추상 정의보다 실제 예시와 표 중심으로 읽히는지 점검합니다.
- 기준선 비교와 경고 후보 해석이 `통계 판단` 이전에 `데이터 표현 판단`으로 먼저 읽히는지 점검합니다.
- Part 4로 넘기는 feature, target, split, baseline, evaluation 전제가 번호 체계와 문장 흐름에서 계속 직접적으로 연결되는지 점검합니다.
