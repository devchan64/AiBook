# action-unit-sensor-notes 관리 기준

## 목적

이 디렉터리는 `동작 단위 원천데이터` 사례를 책 본문에 흡수하기 전에, 개념 소스와 공개 안전 원칙을 정리해 두는 작업 노트 묶음이다.

현재 기준 문서는 `../action-unit-sensor-aibook-update-preparation.md`이며, 이 README는 해당 준비 문서가 참조하는 노트 묶음의 유지 범위를 요약한다.

Part 7 연습 Section에 실제로 반영할 순서와 자산 준비 기준은 `../action-unit-sensor-part-07-exercise-section-plan.md`를 따른다.

## 유지 원칙

- `01`부터 `07`까지는 Part 7 연습 Section에서 필요한 개념 소스 노트로 유지한다.
- `08`과 `09`는 Part 7 사례 배치와 공개형 실습 자산을 준비할 때만 유지한다.
- `10`은 Part 7 반영 순서를 잡는 운영 노트로 유지하되, 실제 작업 큐가 다른 관리 문서로 흡수되면 폐기 후보로 다시 본다.
- 본문 또는 기준 관리 문서에 이미 회수되어 역할이 끝난 메타 계획 문서는 남기지 않는다.
