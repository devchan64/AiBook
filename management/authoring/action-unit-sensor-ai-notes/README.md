# action-unit-sensor-notes 관리 기준

## 목적

이 디렉터리는 `동작 단위 원천데이터` 사례를 Part 7 연습 Section에 반영하기 전에, 개념 소스와 공개 안전 원칙을 정리해 두었던 작업 노트 묶음이다.

Part 7 본문 반영과 공개 합성 자산 작성은 완료되었으므로, 이 README는 남은 노트 묶음의 유지 범위만 요약한다.

## 유지 원칙

- `01`부터 `07`까지는 Part 7 연습 Section의 배경 개념을 확인할 수 있는 소스 노트로 유지한다.
- `08`과 `09`는 Part 7에만 반영하기로 결정한 이유와 공개형 실습 자산 설계 근거를 확인할 때 유지한다.
- `10`은 장문 확장 로드맵의 과거 메모로 남기되, 새 작업 큐의 기준 문서로 사용하지 않는다.
- 본문 또는 기준 관리 문서에 이미 회수되어 역할이 끝난 메타 계획 문서는 남기지 않는다.
