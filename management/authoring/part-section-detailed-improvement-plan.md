# Part·Section별 세부 개선 계획

작성일: 2026-07-31

## 목적

이 문서는 Part별 개선 계획을 Section ID 기준의 실행 목록으로 더 쪼갠다. 공개 본문을 바로 수정하는 문서가 아니라, 이후 원고 편집 시 어떤 Section을 먼저 열고 어떤 문단 추가·재배치·용어 점검을 할지 정리하는 작업표다.

## 우선순위 기준

| 등급 | 의미 | 처리 방식 |
| --- | --- | --- |
| A | 뒤 Part 학습 전제를 만드는 Section | 먼저 열어 본문 문단 추가와 재배치를 함께 검토한다. |
| B | 학습 흐름을 안정화하는 Section | 핵심 예시 뒤 해설, 용어 층위, 코드 관찰 문단을 보강한다. |
| C | Part 경계와 참조 흐름을 정리하는 Section | 시작·마무리 문단, 개념사전 링크, 후속 안내 남용 여부를 점검한다. |

## 공통 적용 규칙

1. 본문은 체크리스트 역할을 대신하지 않는다. 예시 뒤에는 실제 적용, 코드 관찰, 출력 해석, 다음 개념 연결에 필요한 해설을 둔다.
2. Python 기준 소스는 유지한다. 긴 예제는 코드가 아니라 해설을 단계화한다.
3. 다른 Part로 넘기는 안내는 현재 Section에서 자세히 설명하면 중심 질문이 흐려지는 경우에만 짧게 둔다.
4. 개념 층위가 섞일 수 있는 용어는 개념사전 대표 표제어와 영어 기준 용어를 먼저 확인한다.
5. 공개 본문을 수정하는 단계에서는 Section ID, Version, 릴리즈노트 연결을 함께 확인한다.
