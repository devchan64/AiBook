# P7-5.11 입력 후보 217쌍 교차 확인

확인일: 2026-09-15

**사용자 판단:** 비교표의 217개 항목 모두 사용 가능.

**독립 교차 확인:** 217쌍은 파일 무결성과 입력·목표 대응, 기존 분할 조건을 통과한다. 다만 기존 제외 의견 24건을 다시 비교한 결과 표정·배경 차이가 남아 있다. 이를 허용하여 사용한다는 판단과, 모든 쌍이 표정·배경 보존 조건을 충족한다는 판단은 구분한다. 후자는 확인되지 않았다.

## 파일 및 목록 확인

- 비교표·카탈로그·검수 JSON의 활성 후보 217개 및 관리번호가 일치한다.
- 입력·목표 이미지 디코딩, 이미지·생성 기록 해시, 결과 기록의 출력 해시를 확인했다.
- 입력 이미지의 동일 해시 중복과 목표별 학습/검증 분할 누수는 발견되지 않았다.
- 기존 분할을 유지하면 학습 197쌍, 검증 20쌍이며 고유 목표는 44장이다.
- 폐기 확정 3개 ID가 활성 목록에서 제외되어 있다.
- 선택 함수에 임시 채택 상태를 전달하여 217쌍 구성이 가능한지 검사했다. 실제 검수 상태와 학습 목록은 변경하지 않았다.

## 시각적 차이 재확인

기존 제외 의견 24쌍을 이미지당 320px의 비교표로 다시 확인했다. 전체 217쌍을 원본 해상도로 재검수한 결과는 아니다. 아래는 재확인한 관찰이며 자동 폐기 지시가 아니다.

- **P711-IN-026, P711-IN-070, P711-IN-114, P711-IN-158, P711-IN-202:** 입을 벌린 하품은 이어지나 목표에서 감긴 눈이 입력에서 열려 있다.
- **P711-IN-028, P711-IN-072, P711-IN-116, P711-IN-160, P711-IN-204:** 목표의 아래로 내린 눈꺼풀·거의 감긴 눈과 입력의 열린 눈이 다르다. 기존 기록의 일괄적인 완전한 눈 감김 표현보다 이 구분이 정확하다.
- **P711-IN-023, P711-IN-067, P711-IN-111, P711-IN-155, P711-IN-199:** 목표의 다문 입 미소와 입력의 입 벌림에 차이가 있다.
- **P711-IN-048, P711-IN-092, P711-IN-136, P711-IN-180:** 낮은 시점은 이어지지만 입력에서 입을 더 벌린 모습이 보인다.
- **P711-IN-017:** 단순 배경에 반복 무늬가 추가되었다.
- **P711-IN-065:** 미술관의 전시물·방문객 배경이 사라졌다.
- **P711-IN-075:** 창틀과 창가 배경이 단순 여백으로 대체되었다.
- **P711-IN-032, P711-IN-120:** 배경의 창틀 그림자가 사라졌다.

최종 기준: 입력 표정을 보존한다. 방향 3건·배경 5건에 더해 표정 불일치 19건도 사용자 확정 폐기했다. 총 폐기 27건, 현재 보관 193개다. 위 217쌍 검사 및 24건 관찰은 폐기 전 시점의 기록이다. 폐기한 입력·기록은 삭제했으며 재생성을 금지한다.
