# Part 2 원고 대조 리포트

> 작성일: 2026-07-30
> 범위: `management/authoring/part-02-open-checklist.md`와 Part 2 한국어 원고

## 요약 판단

Part 2는 `AI 계산 문해력 복구`라는 체크리스트 중심선과 대체로 맞는다. 수학, Python, 실행 환경, NumPy, Pandas, 시각화, Git을 도구 목록이 아니라 Part 3 이후를 읽기 위한 공통 계산 언어로 묶으려는 흐름이 확인된다.

수정 후보는 내용 결손보다 Python·자료구조 구간의 진행 메타형 제목과 길이 조정이다. 특히 P2-8과 P2-9 일부 Section은 설명과 예제가 충분하지만, `주요 학습내용`, `세부 학습내용` 같은 제목이 남아 있어 Part 1에서 확인한 오래된 형식과 같은 문제가 반복된다.

## 수정 필요 항목

### 1. P2-8 일부 Section의 진행 메타형 제목 정리

- 대상:
  - `docs/parts/part-02/chapter-08/section-04.md:84`
  - `docs/parts/part-02/chapter-08/section-05.md:50`, `:225`
  - `docs/parts/part-02/chapter-08/section-07.md:37`, `:49`
- 확인된 원고 근거: Python 반복, 함수, 참조·복사 구간에 `## 주요 학습내용`, `## 세부 학습내용`이 남아 있다.
- 수정 필요 이유: Part 2 체크리스트는 Python을 일반 프로그래밍 강의가 아니라 데이터 계산을 읽기 위한 최소 문법으로 닫도록 요구한다. 제목도 문법 진행표가 아니라 `반복은 여러 값에 같은 처리를 적용하는 방식`, `함수는 처리 단위를 이름으로 분리하는 방법`, `참조와 복사는 값 변경 위험을 가르는 기준`처럼 개념 판단을 드러내는 편이 맞다.
- 수정 방향: 본문 예제는 유지하되, 진행 메타 제목을 Section별 중심 개념 제목으로 바꾼다. 한국어 원문 제목 변경 뒤 `*.en.md`, `*.zh.md` 동기화가 필요하다.

### 2. P2-9.4 자료구조 보충학습의 제목 체계 정리

- 대상: `docs/parts/part-02/chapter-09/section-04.md:79`, `:155`
- 확인된 원고 근거: 전통 자료구조 보충학습에도 `## 주요 학습내용`, `## 세부 학습내용`이 남아 있다.
- 수정 필요 이유: 체크리스트는 P2-9.4를 자료구조 구현 과제가 아니라 사고 흐름 중심 보충학습으로 제한한다. 현재 본문은 이 경계를 잘 설명하지만, 제목이 독자에게 구현 강의 단원처럼 보일 여지가 있다.
- 수정 방향: `자료구조 이름은 질문을 대표한다`, `Python 자료형과 전통 자료구조를 연결해 읽기`처럼 판단 기준 중심 제목으로 바꾼다.

### 3. P2-8.4, P2-8.5, P2-9.4의 길이와 반복 예제 밀도 점검

- 대상:
  - `docs/parts/part-02/chapter-08/section-04.md`
  - `docs/parts/part-02/chapter-08/section-05.md`
  - `docs/parts/part-02/chapter-09/section-04.md`
- 확인된 원고 근거: 한국어 원고 기준 P2-8.4는 761줄, P2-8.5는 531줄, P2-9.4는 638줄이다.
- 수정 필요 이유: 체크리스트는 Python과 자료구조를 Part 3 이후를 읽기 위한 손잡이로 제한한다. 긴 Section 자체가 문제는 아니지만, 초심자에게 문법 강의처럼 읽히면 Part 2의 경계가 흐려질 수 있다.
- 수정 방향: 예제를 줄이기보다 각 예제가 `입력 -> 처리 -> 출력 -> 다음 Part 연결`을 실제로 맡는지 확인한다. 같은 판단을 반복하는 예제가 있으면 대표 예제와 연습으로 나누거나 압축한다.

## 유지 확인 항목

- P2-3.5, P2-7, P2-10은 모두 실행 위치를 다루지만, 체크리스트가 제시한 경계대로 `선형대수 예제 실행 위치`, `로컬 실행 환경`, `노트북 기록과 재실행`으로 역할을 나눌 수 있다.
- P2-3.6과 P2-11은 모두 NumPy를 다루지만, 전자는 선형대수 개념 확인, 후자는 배열 도구 학습으로 분리되어 있다.
- P2-12와 P2-13은 표 조작과 시각화를 Part 3 진입 전 데이터 계산 확인 도구로 배치한다.
