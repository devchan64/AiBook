# Part 2 상세 품질 분석

## 목적

이 문서는 `part-quality-analysis.md`의 요약 판정을 Part 2 편집용 작업 문서로 확장한 것입니다.
현재 Part 2는 대규모 재구성보다 `수학, Python, 데이터 도구, Git을 한 준비 흐름으로 실제로 읽히게 하는가`가 핵심 과제입니다.

따라서 이 문서의 목적은 다음 네 가지입니다.

1. 독자가 Part 2를 실제로 어떤 순서로 읽어야 덜 흔들리는지 다시 명시한다.
2. 수학 축, 실행 환경 축, 데이터 도구 축, Git 축이 어디에서 과밀하거나 흩어지는지 장면 단위로 적는다.
3. 바로 문단 보강으로 해결할 수 있는 지점과, 다음 라운드 구조 검토가 필요한 지점을 구분한다.
4. 이후 커밋 단위를 Part 2 안에서 더 작게 설계할 수 있게 한다.

## 현재 독서 경로 진단

### 현재 구조 판단

현재 Part 2는 `수학 복구 -> 실행 환경과 Python -> 데이터 도구 -> 기록과 Part 3 진입`으로 읽는 구조가 가장 안정적입니다.
index와 summary는 이 방향을 비교적 잘 잡고 있고, 최근 작업으로 보충학습 재진입 기준과 Part 3 준비선도 더 분명해졌습니다.

현재 본류는 다음 다섯 묶음으로 읽는 편이 가장 자연스럽습니다.

| 읽기 묶음 | Chapter | 지금 읽는 층위 |
| --- | --- | --- |
| 계산 언어 복구 | 1-2 | 수식과 기호를 다시 읽는 기준 |
| 핵심 수학 감각 | 3-6 | 선형대수, 미분, 확률/통계, 최적화의 직관 |

### 현재 강점

- index와 summary가 모두 `수학, 코드, 데이터, Git은 따로가 아니라 같은 준비물`이라는 방향을 비교적 선명하게 잡고 있습니다.
- P2-7, P2-8 앞머리에 `왜 지금 이 말을 배우는가`가 비교적 짧게 고정되어 있어 도구열이 덜 흩어집니다.
- P2-15.2가 Part 3 진입 전 질문을 실전형 점검으로 정리해 `기초를 끝낸다`보다 `다음 Part를 읽을 준비를 한다`는 방향을 분명히 합니다.

### 현재 핵심 리스크

현재 리스크는 `내용이 부족하다`보다 `한 Part 안에 너무 많은 준비물이 길게 이어져 피로가 누적되는가`에 더 가깝습니다.

구체적으로는 다음이 남아 있습니다.

1. 수학 축이 길게 이어진 뒤 실행 환경과 Python 축으로 넘어갈 때 독자가 `새 과목이 또 시작된다`고 느낄 수 있습니다.
2. Chapter 7~10은 실행 환경, 터미널, Python 기초, 노트북이 모두 중요하지만, 초심자에게는 `도구 이름 목록`처럼 읽힐 위험이 있습니다.
3. Chapter 11~14는 NumPy, Pandas, Matplotlib, Git이 모두 실전 도구지만, 왜 이 순서로 묶였는지 약해지면 다시 개별 도구 강좌처럼 보일 수 있습니다.
4. 보충학습이 적절히 분리돼 있어도, 본문 중간에 여러 번 보이면 독자가 `본편과 우회 절`을 같은 우선순위로 읽어 피로를 느낄 수 있습니다.

즉, 이 문서의 초점은 `무엇을 더 넣을까`보다 `현재 본류를 더 짧고 안정적으로 읽히게 만드는가`에 둡니다.
