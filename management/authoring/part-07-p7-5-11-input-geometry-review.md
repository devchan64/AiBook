# P7-5.11 입력 후보 방향·구도 재검수

검수일: 2026-09-15

이 보고서는 기존 1차 검수에서 얼굴 방향 변화를 지적한 3쌍을 확대 대조한 결과다. 관리코드 IPR-001~003은 이 보고서와 검수 JSON에서 같은 이미지를 가리킨다. 폐기한 후보의 ID·해시는 후보 카탈로그 및 검수 JSON의 discarded_items로 추적한다. 입력 PNG와 생성 기록 JSON은 삭제했다.

**정정:** 카메라 구도·몸 전체 포즈가 바뀌었다는 포괄적 판단은 근거가 부족하다. 아래 3건에서 관찰한 핵심은 얼굴 방향 차이다. 체형, 얼굴 형태, 표정, 의상, 배경 요소의 변화는 각각 별도 항목이며 자동으로 구도·포즈 변화에 포함하지 않는다. 얼굴 방향은 학습 캡션의 보존 조건이므로 이 사유로 사용자 확인을 받아 3건 모두 폐기로 확정했으며, 정량 회전각이나 카메라 이동을 추정하지 않는다.

검수 범위는 기존 의심 3쌍이며, 나머지 전체 후보의 구도·포즈가 완전히 동일하다고 보증하는 결론도 내리지 않는다.

## IPR-001 — bfs-input-01-oil-painting

**관찰:** 목표는 양쪽 눈·볼이 정면에 가깝게 보인다. 입력은 코끝이 화면 오른쪽으로 향하고 화면 왼쪽 귀와 볼 측면이 더 드러난다.

**판단 경계:** 목표는 어깨 상단만 보이는 얼굴 중심 화면이고 입력에는 옷을 입은 상체가 더 드러난다. 의상 추가·머리 크기·보이는 신체 범위 차이가 함께 있어 카메라 이동이나 몸 회전을 따로 확정할 수 없다.

**처리:** 사용자 확정 폐기. 입력 이미지·생성 기록 삭제, 활성 후보 목록에서 제거.

## IPR-002 — bfs-input-13-soft-photo

**관찰:** 목표의 얼굴은 정면에 가깝지만 입력은 코와 턱이 화면 오른쪽을 향한다. 눈동자 방향만의 변화보다 머리 회전이 의심된다.

**판단 경계:** 책장·스탠드·인물의 중앙 배치와 양팔을 내린 자세는 대체로 유지된다. 몸 전체 포즈나 카메라 구도 변화의 근거로 사용하지 않는다.

**처리:** 사용자 확정 폐기. 입력 이미지·생성 기록 삭제, 활성 후보 목록에서 제거.

## IPR-003 — bfs-input-40-watercolor

**관찰:** 목표의 얼굴은 정면에 가깝지만 입력은 코끝이 화면 왼쪽으로 향하고 화면 오른쪽 귀가 더 드러난다.

**판단 경계:** 재킷을 입고 서 있는 상반신 배치와 팔 방향은 대체로 유지된다. 화풍·체형 차이를 몸 포즈나 카메라 변화로 확정하지 않는다.

**처리:** 사용자 확정 폐기. 입력 이미지·생성 기록 삭제, 활성 후보 목록에서 제거.
