# Part 4 체크포인트 노트

이 문서는 Part 4를 목차 순서대로 읽을 때 각 Section이 담아야 할 중심 주제를 개괄식으로 정리한 체크포인트 노트입니다.

## 사용 원칙

- 이 노트는 `docs/book/table-of-contents.md`를 기준으로 Part 4의 시작/마무리 페이지, Chapter, Section을 같은 순서로 훑기 위한 개요 문서입니다.
- 순차 점검 기록, 품질 상태 메모, 작업 로그는 이 문서에서 운영하지 않습니다.
- 체크포인트는 `문제 구조 -> 데이터 분리 -> 평가 기준 -> baseline -> 알고리즘 선택` 흐름을 각 Section이 어떻게 지지하는지 확인하는 데 목적을 둡니다.
- `학습 관점 누락 점검`은 Part 원고가 잃기 쉬운 설명 흐름을 점검하고, `목차 기준 체크포인트`는 Part 원고가 유지해야 할 구조 흐름을 관리합니다.

## 학습 관점 누락 점검

- 각 Chapter를 볼 때 알고리즘 이름보다 `어떤 문제 구조와 어떤 평가 질문을 다루는 장인가`가 먼저 보이는지 확인합니다.
- 각 Section를 볼 때 `기준선 비교`, `오류 사례`, `언제 쓰고 언제 피할까` 가운데 최소 한 가지는 실제 판단 장면으로 드러나는지 확인합니다.
- 평가와 일반화 관련 장에서는 점수 정의만 있고 `새 데이터에서 왜 달라지는가` 설명이 비어 있지 않은지 확인합니다.
- 보충학습 절은 본편의 핵심 판단을 반복하기보다, 낯선 수식·지표·알고리즘 용어를 처음 읽는 손잡이를 제공하는지 확인합니다.
- 후반 알고리즘 장에서도 `모델 소개`로 끝나지 않고 `Part 5로 넘어가기 전 무엇을 이해해야 하는가`가 드러나는지 확인합니다.
- Part 4에서는 특히 `baseline 없이 성능만 읽는 문제`, `지표와 운영 비용 혼동`, `알고리즘 카탈로그화`가 빠지지 않는지 다시 봅니다.

## 목차 기준 체크포인트

- `index.md`: Part 4가 알고리즘 목록이 아니라 머신러닝 공통 구조를 읽는 Part라는 점을 분명히 해야 합니다.
- Part 흐름: Module 1과 Module 2는 `학습 유형`, `데이터 분리`, `일반화`, `지표`가 알고리즘 소개보다 먼저 닫혀야 합니다.
- Part 흐름: Module 3은 `전처리`, `baseline`, `튜닝`을 한 실험 흐름으로 묶어야 합니다.
- Part 흐름: Module 4부터 Module 6까지는 각 알고리즘이 `baseline 대비 언제 남고 언제 빠지는가`를 같은 비교 틀로 보여 주어야 합니다.
- `summary.md`: Part 5로 넘어가기 전 `표현을 사람이 만들던 단계`에서 `모델이 학습하는 단계`로의 전환을 남겨야 합니다.
