## 결론

Part 2에는 외부 AI SDK, LLM API, vector DB, 모델 학습 라이브러리를 새로 끼워 넣지 않는다. Part 2의 역할은 Part 3 이후 실제 모델 예제를 이해하기 위한 기초 도구를 복구하는 것이다.

패치 방향은 다음 네 가지다.

1. 설명형 예제는 유지하되, 코드 앞뒤에 `무엇을 바꾸고 무엇을 관찰할지`가 약한 곳을 보강한다.
2. 반복되는 작은 인라인 데이터는 필요한 곳에서 별도 `.py` 자산 또는 CSV 자산으로 분리한다.
3. 그래프 예제는 `plt.show()`만 두지 않고, 필요하면 `Agg`, `fig.savefig(...)`, 결과 이미지 링크까지 포함해 재현성을 높인다.
4. pandas, NumPy, Matplotlib 예제는 Part 3 이후 모델 입력, feature, split, metric, plot 해석으로 이어지는 관찰 포인트를 명시한다.

- 독자가 실행하면 이미지 파일이 생기고, 본문에서는 그 이미지에서 무엇을 봐야 하는지 설명한다.

주의:
