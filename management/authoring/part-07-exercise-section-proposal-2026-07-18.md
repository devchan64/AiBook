# Part 7 연습 섹션 추가 제안

작성일: 2026-07-18

## 문제 인식

현재 Part 7은 각 절 안에 `Python 예제`, `결과를 어떻게 읽는가`, `직접 바꿔 보며 확인할 것`을 붙이며 실습성을 높이고 있다. 이 방향은 유효하지만, 실습 강도를 더 올리려면 `설명 절`과 `연습 절`을 구조적으로 분리하는 편이 더 강하다.

지금 구조에서는 한 절 안에 다음 역할이 모두 몰려 있다.

- 개념과 프로젝트 질문 설명
- 입력 파일 소개
- 실행 코드
- 결과 해석
- 회고 문장
- 직접 바꿔 볼 실험

이렇게 한 절에 역할이 많아지면 초심자는 `지금 읽는 것이 설명인가`, `지금 해야 하는 것이 실행인가`, `지금 해야 하는 것이 연습인가`를 놓치기 쉽다. 따라서 Part 7 목표인 `초심자가 실제로 동작시켜 보며 AI의 동작을 이해한다`를 더 강하게 만족시키려면, 일부 Chapter에는 `설명 절` 뒤에 `연습 절`을 별도로 두는 편이 적합하다.

## 제안 원칙

- 연습 절은 개념 설명을 새로 길게 반복하지 않는다.
- 연습 절은 `값을 바꿔 본다 -> 결과가 달라진다 -> 왜 달라졌는지 적는다` 구조로만 밀어 준다.
- 연습 절은 정답 암기보다 `비교 기준`, `실패 신호`, `다음 수정 질문`을 직접 써 보게 해야 한다.
- 연습 절은 코드만 추가하는 자리가 아니라, `실행 과제`, `관찰 포인트`, `기록 템플릿`을 함께 주는 자리여야 한다.
- 연습 절이 생기면 기존 `section-01`, `section-02`는 설명과 해석 중심을 유지하고, 새 절이 실습 반복을 맡는 구조가 좋다.

## 가장 적합한 추가 위치

### Chapter 1 뒤

현재:

- `P7-1.1` 질문과 기준선 읽기
- `P7-1.2` 결과와 회고

추가 후보:

- `P7-1.3` 기준선 재설계 연습

이 절에 포함할 주제:

- `cutoff` 날짜를 바꿨을 때 회고 우선순위가 어떻게 달라지는가
- 채널 단위와 전체 단위가 다른 결론을 만드는 장면 다시 쓰기
- `campaign`, `browser`, `release_version` 열을 추가한다고 가정하고 다음 분석 질문 쓰기
- 회고 문장을 `사실 / 해석 / 다음 질문`으로 직접 작성하기

추가 이유:

- Part 7 첫 장은 실습 파트의 입구이므로, 여기서 `직접 바꿔 보고 직접 적는 절`이 하나 더 있으면 이후 장들의 기대치가 훨씬 또렷해진다.

### Chapter 2 뒤

현재:

- `P7-2.1` baseline과 raw 1-NN
- `P7-2.2` 정규화와 개선 회고

추가 후보:

- `P7-2.3` 비교 실험 연습

이 절에 포함할 주제:

- raw / normalized / 다른 스케일 축소판 비교 실험
- 어떤 샘플이 계속 실패하는지 표로 남기기
- 정확도는 올라가도 남는 실패를 회고 문장으로 쓰기
- `더 많은 데이터가 필요하다`와 `전처리가 더 필요하다`를 구분해 적기

추가 이유:

- 현재는 개선 설명은 강화되었지만, 독자가 여러 개선 버전을 나란히 놓고 비교하는 반복 훈련은 아직 약하다.

### Chapter 4 뒤

현재:

- `P7-4.1` 텍스트 분류 baseline
- `P7-4.2` OOV, coverage, 검토 우선순위

추가 후보:

- `P7-4.3` 표현 정규화 연습

이 절에 포함할 주제:

- `캔슬 -> 취소`, `스케줄 -> 일정` 같은 동의어 정규화 전후 비교
- coverage가 낮지만 정답인 샘플과 coverage가 낮고 오답인 샘플 대비
- 토큰화 규칙 변경 전후의 회고 문장 비교
- 어떤 표현을 사전에 추가할지 우선순위 정하기

추가 이유:

- 텍스트 프로젝트는 초심자가 가장 쉽게 손댈 수 있는 영역이므로, 별도 연습 절 효과가 크다.

- `P7-5.2` 근거 부족 / 답변 과장 위험

이 절에 포함할 주제:

- 답변을 멈춰야 하는 질문의 공통 특징을 적기

추가 이유:

- RAG는 설명만으로는 금방 그럴듯하게 읽히므로, 별도 연습 절에서 `멈춤 규칙`을 직접 써 보는 편이 중요하다.

현재:

추가 이유:

- 공개 URL 확인, 링크 404, Version 미반영 중 무엇을 먼저 처리할지 쓰기

추가 이유:

- Part 7 마무리는 설명보다 `실제 운영 판단을 써 보는 절`이 하나 더 있어야 전체 파트가 프로젝트답게 닫힌다.

## 추천 추가 순서

모든 장에 한 번에 절을 늘리기보다, 아래 순서로 추가하는 편이 안전하다.

1. `P7-4.3` 표현 정규화 연습
2. `P7-5.3` 질문-근거 경계 연습
3. `P7-6.3` 승인 정책 연습
4. `P7-1.3` 기준선 재설계 연습
5. `P7-2.3` 비교 실험 연습
6. `P7-7.3` 운영 점검 시뮬레이션

이 순서를 추천하는 이유:

- 텍스트, RAG, 에이전트는 직접 값을 바꿨을 때 변화가 눈에 잘 보인다.
- Part 7 후반 장들에 별도 연습 절이 생기면, 앞 장에도 같은 패턴을 확장하기 쉬워진다.

## 최소 구현 방식

연습 절을 실제로 만들 때는 아래 구조를 공통 템플릿으로 삼는 편이 좋다.

```text
## 이 절에서 직접 할 일
- 무엇을 바꿀 것인가
- 무엇을 다시 실행할 것인가
- 무엇을 기록할 것인가

## 실습 과제
1. ...
2. ...
3. ...

## 관찰 포인트
- 결과가 어떻게 바뀌는가
- 어떤 실패가 남는가
- 어떤 문장을 회고 앞줄에 올릴 것인가

## 기록 템플릿
- 사실:
- 해석:
- 다음 질문:
```

## 현재 판단

- Part 7을 진짜 실습 파트로 끌어올리려면, 기존 절 안의 실험 지시만으로는 충분하지 않다.
- 가장 효과적인 다음 단계는 Chapter별 `연습 절(section-03)` 추가다.
- 특히 `P7-4.3`, `P7-5.3`, `P7-6.3`은 현재 구조와도 가장 자연스럽게 이어지고, 초심자가 직접 바꿔 보며 배울 장면을 크게 늘릴 수 있다.
