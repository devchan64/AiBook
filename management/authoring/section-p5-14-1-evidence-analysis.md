# P5-14.1 근거 검토 메모

## 절의 역할

- 도구 사용을 모델과 외부 기능 연결 구조로 설명한다.
- RAG와 tool use의 역할 차이를 분리한다.

## 이번 절의 핵심 주장

- 도구 사용은 모델이 외부 기능을 통해 조회, 계산, 실행을 하게 하는 구조다.
- 실제 실행은 보통 애플리케이션/실행 환경이 담당한다.
- 도구 사용은 권한, 승인, 실패 처리 문제를 함께 데려온다.

## 반영한 근거

- OpenAI의 tools/function calling 문서
- Anthropic의 tool use 문서
- 관련 교육 자료

## 집필 판단

- 코딩 에이전트 사례를 넣어 독자가 서비스 구조를 실제로 연결해 볼 수 있게 했다.
- RAG와의 차이를 표로 분리했다.

## 제외한 내용

- agent loop 전체
- 권한 시스템 상세
