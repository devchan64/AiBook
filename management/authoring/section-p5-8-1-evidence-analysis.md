# P5-8.1 근거 검토 메모

## 절의 역할

- LLM의 기본 학습 목표를 다음 토큰 예측으로 설명한다.
- 자동완성 비유의 유효 범위와 한계를 초심자 수준에서 구분한다.

## 이번 절의 핵심 주장

- LLM은 다음 토큰을 예측하도록 학습된다.
- 이 목표는 순차적 언어 패턴 학습과 연결된다.
- 다음 토큰 예측만으로 LLM 전체를 모두 설명할 수는 없지만, 가장 중요한 출발점이다.

## 반영한 근거

- Bengio et al., `A Neural Probabilistic Language Model`
- Mikolov et al., `Recurrent Neural Network Based Language Model`
- Radford et al., `Improving Language Understanding by Generative Pre-Training`
- Brown et al., `Language Models are Few-Shot Learners`

## 집필 판단

- 수식 대신 순차 생성 직관을 우선했다.
- 자동완성과의 공통점/차이점을 별도로 분리했다.

## 제외한 내용

- cross-entropy 수식
- decoding 전략 세부 비교
