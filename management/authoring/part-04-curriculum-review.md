# Part 4 커리큘럼 재검토 메모

## 검토 목적

- Part 4가 `딥러닝을 실제로 설명하는 파트`라는 역할을 충분히 수행하는지 점검한다.
- Part 1, Part 2, Part 3에서 후속으로 넘긴 개념을 Part 4가 실제로 회수하고 있는지 확인한다.
- Part 5의 LLM 설명이 Part 4의 구조 설명 위에 자연스럽게 올라갈 수 있는지 점검한다.

## 핵심 판단

### 1. Part 4는 여전히 `딥러닝 키워드 소개`로 읽히는 구간이 남아 있다

- 앞선 파트들은 손실 함수, 역전파, 표현 학습, CNN, Transformer를 `후속 파트에서 자세히 다룬다`고 예고했다.
- 따라서 Part 4의 책임은 용어를 다시 보여 주는 것이 아니라, 왜 필요한지와 어떻게 연결되는지를 실제로 설명하는 데 있다.
- 현재는 많은 절이 이전 파트보다 분명해졌지만, Part 4 전체를 보면 아직도 `본격 설명을 시작했다`는 감각보다 `구조 이름을 넓게 훑는다`는 인상이 남는 장이 있다.

### 2. Part 4의 가장 중요한 계약은 `학습 구조 설명`이다

- 퍼셉트론, activation, loss, backpropagation, optimizer는 서로 따로 떨어진 장식이 아니다.
- 이 다섯 축이 하나의 학습 루프로 묶여 보여야, 독자가 딥러닝을 계산 구조로 이해할 수 있다.
- 특히 역전파와 optimizer는 Part 3에서 넘긴 대표 후속 주제이므로, Part 4에서 설명 밀도가 약하면 파트 역할이 무너진다.

### 3. 후반 구조 장은 `Part 5로 넘어가기 위한 실제 기반`이 되어야 한다

- CNN, RNN, Attention, Transformer는 단순 모델 열거가 아니라 `어떤 데이터 구조 문제에서 이런 설계가 나왔는가`로 설명되어야 한다.
- 그렇지 않으면 Part 5에서 Transformer와 LLM을 다시 설명할 때 `또 새로 시작한다`는 느낌이 강해진다.

### 4. 생성과 샘플링은 Part 5의 예고가 아니라 Part 4의 마무리 설명이어야 한다

- 생성형 AI 본류는 Part 5에서 다루더라도, `생성과 분류의 차이`, `샘플링이 결과를 바꾸는 이유` 정도는 Part 4에서 실제로 잡혀야 한다.
- 이 부분이 약하면 Part 5 초반의 next-token, decoding 설명도 다시 공중에 뜬다.

## Part 4가 실제로 회수해야 하는 앞선 예고

| 앞선 파트에서 미룬 주제 | Part 4에서 반드시 채워야 하는 설명 |
| --- | --- |
| 표현 학습 | 특징 공학과 표현 학습의 차이, 계층 표현이 왜 중요한가 |
| 손실 함수 | 문제 유형과 출력 해석이 왜 손실 선택과 연결되는가 |
| 역전파 | 오차가 왜 뒤로 전달되고, gradient가 왜 필요한가 |
| optimizer | SGD와 Adam이 무엇을 다르게 보정하는가 |
| CNN / RNN / Transformer | 데이터 구조에 따라 왜 모델 축이 갈라지는가 |
| 생성 / 샘플링 | 생성 출력은 왜 확률 분포와 선택 규칙의 영향을 받는가 |
