# 동작 단위 센서 사례 Part 7 연습 Section 추가 계획

작성일: 2026-07-18

## 목적

이 문서는 동작 단위 센서 사례를 AiBook 본문에 반영할 때 Part 7의 연습 Section에만 작성하기 위한 실행 계획이다.

기준 문서는 `action-unit-sensor-aibook-update-preparation.md`이며, 이 문서는 실제 본문 편집 순서와 필요한 자산을 더 구체화한다.

## 현재 결정

동작 단위 사례는 Part 1-6 본문에는 직접 넣지 않는다.

이유는 다음과 같다.

- 앞선 Part의 개념 흐름이 특정 도메인 사례 중심으로 흔들릴 수 있다.
- Part 7은 이미 실행, 비교, 실패 해석, 운영 회고를 묶는 프로젝트 실습 Part다.
- 동작 단위 사례는 설명용 사례보다 조건을 바꿔 결과와 회고가 달라지는 연습 재료에 더 적합하다.

따라서 본문 반영은 Part 7의 기존 연습 Section 안에서만 진행한다.

## 추가 대상 Section

| 우선순위 | Section | 역할 | 핵심 연습 |
| --- | --- | --- | --- |
| 1 | `P7-1.3` 기준선 재설계 연습 | 같은 센서 요약을 기준선 경계와 최근 구간 크기에 따라 다시 읽기 | 기준선 경계, 최근 윈도우, 동작 단위 묶음 변경 |

| 3 | `P7-4.3` 표현 정규화 연습 | 센서 값을 사람이 읽을 수 있는 설명 특징으로 바꾸는 방식 비교 | exact token, shape token, density feature 비교 |

`P7-1.1`은 필요할 때만 짧은 선행 회수 문장을 추가한다. 본격 연습은 `P7-1.3`부터 시작한다.

## 공통 합성 자산

Part 7의 여러 연습 Section에서 같은 합성 데이터 계열을 재사용한다.

필수 자산 후보는 다음 세 가지다.

| 자산 | 용도 | 후보 경로 |
| --- | --- | --- |
| 원시 로그 CSV | 동작별 시간 순서 센서 기록 | `docs/assets/part-07/chapter-01/p7-action-unit-sensor-log.csv` |
| 동작 요약 CSV | 동작 단위 구간 평균, 변화율, 패턴 라벨 | `docs/assets/part-07/chapter-01/p7-action-unit-summary.csv` |
| 운영 신호 CSV | drift, false alarm, 반복성 부족 신호 | `docs/assets/part-07/chapter-07/p7-action-unit-ops-signals.csv` |

파일명은 특정 도메인을 직접 암시하지 않도록 짓고, 실제 장비 식별자나 운영 규칙을 떠올리게 하는 이름은 쓰지 않는다.

## Section별 반영 설계

### `P7-1.3`

추가 위치:

- 기존 `입력 파일` 뒤 또는 `직접 바꿔 보며 확인할 것` 앞

추가 내용:

- 센서 요약 CSV를 기준선 구간별로 나누는 짧은 예제
- 최근 5회 vs 이전 12회, 최근 3회 vs 이전 14회 같은 비교 조건
- 회고 문장: 기준선을 짧게 잡으면 민감도는 올라가지만 표본 수 해석은 약해진다는 점

### `P7-2.3`

추가 위치:

- 기존 비교 실험 표 뒤의 별도 `동작 단위 센서 비교 실험 확장` 절

추가 내용:

- 원시 값 비교, 진행도 구간 평균, 정규화 후 비교를 나란히 둔다.
- 전처리로 줄어드는 실패와 여전히 남는 경계 실패를 구분한다.
- 더 복잡한 모델로 가기 전에 특징과 비교 기준을 다시 보는 흐름으로 닫는다.

### `P7-4.3`

추가 위치:

- 기존 정규화 예제 뒤의 짧은 확장 연습

추가 내용:

- `exact token`: 특정 구간 값이 임계 범위에 들어왔는지
- `shape token`: 초반 상승, 중반 안정, 후반 하강 같은 모양
- `density feature`: 특정 패턴이 최근 구간에서 얼마나 자주 반복됐는지
- 이 셋이 같은 센서 데이터를 서로 다른 표현으로 읽는다는 점을 비교한다.

주의:

- 센서 토큰과 텍스트 토큰을 같은 개념으로 단정하지 않는다.
- 여기서의 token은 사람이 해석하기 위해 만든 이산 표현이라는 점을 짧게 밝힌다.

### `P7-7.3`

추가 위치:

- 기존 운영 시나리오 분류표 뒤의 별도 운영 카드 연습

추가 내용:

- false alarm: 한 번 튄 값이지만 반복되지 않는 신호
- 반복성 부족: 표본 수가 적어 단정하기 어려운 신호
- 기준선 drift: 최근 구간에서 같은 방향 변화가 반복되는 신호
- 각 신호를 `즉시 수정`, `재현 확인`, `다음 반복 개선`으로 분류한다.

## 본문 편집 순서

1. 합성 CSV 3개를 먼저 만든다.
2. `P7-1.3`에 기준선 재설계 확장 연습을 넣는다.
3. `P7-2.3`에 같은 자산을 쓰는 비교 실험 확장을 넣는다.
4. `P7-4.3`에 표현 선택 비교 확장을 넣는다.
5. `P7-7.3`에 운영 점검 카드 확장을 넣는다.
6. 각 Section의 `Version`을 `v2026.07.18` 기준으로 확인한다.
7. 대응 릴리즈노트 `P7-1.3`, `P7-2.3`, `P7-4.3`, `P7-7.3`에 동작 단위 센서 연습 추가 내용을 남긴다.

- Part 1-6에는 동작 단위 사례를 직접 추가하지 않는다.

- 기존 예제를 전부 교체하지 않는다. 동작 단위 사례는 확장 연습으로 추가한다.
- 실제 로그, 장비 식별자, 내부 운영 규칙, 구현 전용 경로는 쓰지 않는다.
- 공개형 합성 데이터임을 본문이나 출처 메모에서 분명히 밝힌다.
