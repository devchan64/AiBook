# P6-3.2 근거 검토 메모

## 이 절의 역할

- 이미지 프로젝트에서 점수보다 오류 사례가 왜 중요한지 설명한다.
- 데이터, 입력 표현, 모델 구조를 분리해 회고하는 습관을 만든다.

## 핵심 주장

- 오류 사례는 프로젝트 문서의 핵심 자산이다.
- 애매한 확률 출력은 모델 한계와 데이터 범위를 동시에 보여 줄 수 있다.
- 개선 계획은 데이터 추가, 표현 변경, 모델 구조 확장으로 나누어 적는 편이 좋다.

## 반영한 근거

- P6-3.1의 test 확률 출력과 오분류 사례를 직접 근거로 사용
- 이미지 프로젝트 회고를 일반화한 자체 정리

## 집필 메모

- explainability 기법으로 넓히지 않고 초심자용 오류 분석 습관에 집중했다.
