# P5-3.2 근거 검토 메모

## 절의 역할

- LLM의 직접 계보와 딥러닝 확산의 주변 근거를 구분한다.
- 사용자의 기존 직관을 더 안전한 일반화 문구로 정리한다.

## 이번 절의 핵심 주장

- language modeling, embeddings, Attention, Transformer는 직접 계보로 설명할 수 있다.
- YOLO, Deep Voice, 비전/음성 돌파 사례는 중요한 주변 근거이지만 직접 구조사와는 구분해야 한다.
- 이 구분은 LLM 역사를 과장 없이 설명하게 해 준다.

## 반영한 근거

- Vaswani et al., `Attention Is All You Need`
- Radford et al., `Improving Language Understanding by Generative Pre-Training`
- Devlin et al., `BERT`
- Krizhevsky et al., `ImageNet Classification with Deep Convolutional Neural Networks`
- Redmon et al., `You Only Look Once`
- Arik et al., `Deep Voice`

## 집필 판단

- 특정 사례를 배제하지 않고 `역사적 분위기/인프라 근거`로 재배치했다.
- 직접 계보와 주변 근거를 섞지 않도록 별도 절로 분리했다.

## 제외한 내용

- 모든 관련 모델 계열의 전수조사
- 멀티모달 모델의 직접 계보 논쟁
