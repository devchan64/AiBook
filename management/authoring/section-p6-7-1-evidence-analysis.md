# P6-7.1 근거 검토 메모

## 이 절의 역할

- 정적 사이트 배포를 하나의 서비스 배포 프로젝트로 설명한다.
- GitHub Pages와 기본 모니터링 관점을 연결한다.

## 핵심 주장

- build 성공과 공개 페이지 정상 동작은 같은 말이 아니다.
- GitHub Pages는 정적 사이트 호스팅 서비스다.
- 배포 후 기본 확인 항목과 운영 신호가 필요하다.

## 반영한 근거

- GitHub Pages 공식 문서
- Google SRE Monitoring Distributed Systems 문서

## 집필 메모

- 정적 사이트 운영에 맞게 golden signals를 과도하게 확장하지 않고 기본 확인 항목 중심으로 정리했다.
